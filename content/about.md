## 本站定位

**考证宝典** 是一个按「证书」成体系组织的职业资格考试备考站：

- 每个证书是一个独立体系：**证书百科 → 报考指南 → 大纲教材 → 书籍库 → 题库 → 政策动态**；
- **书籍与题库一体**：考点精讲章节与题库按章节打通，读完一章即可练对应习题，做错的题也能一键回到书中对应考点；
- 内容定位为**原创整理的考点精讲与自编练习题**，帮助你建立知识框架、检验掌握程度，**不能替代官方教材与官方真题**。

## 内容组织方式

| 板块 | 说明 |
|------|------|
| 证书主页 | 该证书是什么、考什么、怎么考，以及全部资源入口 |
| 考点精讲（书籍） | 原创整理的章节式考点讲解，含记忆要点与易错提醒 |
| 题库 | 章节练习 / 历年真题（示例）/ 模拟考试 / 错题本 |
| 报考指南与动态 | 报名时间、流程、合格标准等信息（**以官方通知为准**） |

## 免责声明

站内报考时间、合格线、教材版本等信息仅供参考，**请以各考试官方管理机构当次发布的正式通知为准**。本站书籍正文为原创整理或用户投稿，如涉及版权问题请联系我们处理。

## 纠错与投稿

本站欢迎一切让内容更准确的反馈。**发现错题、错误考点、过期的政策数据或失效的链接**，或想投稿原创笔记与题目，欢迎发邮件至 {{< contact-email >}}。

来信时建议附上：

1. **所在页面**（证书名称 + 章节名或题号，如「一建 · 建筑实务 · 第 4 章 · 习题 jz-04-002」）；
2. **问题描述**（你认为哪里不对、依据是什么，能附官方教材页码、法规条文号或官网链接最好）；
3. **修改建议**（如有）。

我们会在核对官方来源后修订，并在章节或题目中更新内容。**对于政策类数据（报名时间、合格标准、教材版本、税率与社保比例等），请以官方当次发布为准**；本站会在核实后尽快同步。

## 内容质量承诺

- **每题必带错因**：所有练习题的每个错误选项都写明「为什么错」，而不是只给正确答案；
- **每章必带记忆工具**：口诀、对比表或流程图，先帮记忆再谈理解；
- **政策必附来源**：动态类内容一律标注官方来源名称与链接，**未核验不发布**；
- **开源资源必核验**：学习资源页收录的 GitHub 仓库均人工核对星标、最近更新、许可证与内容相关性，**并诚实标注生态薄弱处**，宁缺毋滥。
