## 本站定位

**考证宝典** 是一个按「证书」成体系组织的职业资格考试备考站：

- 每个证书是一个独立体系：**证书百科 → 报考指南 → 大纲教材 → 书籍库 → 题库 → 政策动态**；
- **书籍与题库一体**：考点精讲章节与题库按章节打通，读完一章即可练对应习题，做错的题也能一键回到书中对应考点；
- 内容定位为**原创整理的考点精讲与自编练习题**，帮助你建立知识框架、检验掌握程度，**不能替代官方教材与官方真题**。

## 内容组织方式

| 板块 | 说明 |
|------|------|
| 证书主页 | 该证书是什么、考什么、怎么考，以及全部资源入口 |
| 考点精讲（书籍） | 原创整理的章节式考点讲解，含记忆要点与易错提醒 |
| 题库 | 章节练习 / 历年真题（示例）/ 模拟考试 / 错题本 |
| 报考指南与动态 | 报名时间、流程、合格标准等信息（**以官方通知为准**） |

## 免责声明

站内报考时间、合格线、教材版本等信息仅供参考，**请以各考试官方管理机构当次发布的正式通知为准**。本站书籍正文为原创整理或用户投稿，如涉及版权问题请联系我们处理。
