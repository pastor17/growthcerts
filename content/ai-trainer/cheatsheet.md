> **用法**：**考前 30 分钟 + 每天通勤只过这一页**。**通用口径不等于当次考纲**——**考核范围以国家职业技能标准与备案评价机构当次通知为准**。

## 一、数据流程 5 步（**主链，一切考点挂在这条链上**）

```text
采集 → 清洗 → 标注（先写规范）→ 质检 → 评测
```

| 步 | 核心动作 | 一句话 |
|----|---------|--------|
| **采集** | 自有/公开/众包/采集标注一体；**先看授权** | **“先看授权，再取数据”** |
| **清洗** | 去重（精确+近似）、缺失、异常、格式编码、去噪 | **“去重补缺剔异常，统一格式清噪声”** |
| **标注** | **先定规范**，再批量标；边界案例单独处理 | **“规范先行，边界单列”** |
| **质检** | 抽检 + 复核 + **一致率** + 返工留痕 | **“抽检算一致性，不合格必返工”** |
| **评测** | 建测试集（常规/边界/对抗）→ 指标 → 报告 | **“没有测试集 = 赌博”** |

> **记忆锚**：**“采集看授权，清洗去脏乱，规范写边界，标注按格式，质检算一致，评测建测试集。”**

## 二、数据标注规范 6 要素（**背下来就能写规范**）

| 要素 | 内容 | 反例 |
|------|------|------|
| **① 标签定义** | 每个标签**一句话讲清是什么** | “情感标签：正面/负面”（**没说中性怎么办**） |
| **② 正例** | 每个标签给**标准示例** | 只有定义没有例子 |
| **③ 反例** | 明确**不算这个标签**的情形 | 不写反例 → 标注员自由发挥 |
| **④ 边界案例** | **易混、歧义、多重标签**怎么处理 | **“规范的含金量全在边界案例”** |
| **⑤ 弃标/存疑规则** | 什么时候**标“无法判断”并上报** | 逼着标注员硬选一个 |
| **⑥ 验收标准** | 抽检比例、一致率门槛、返工规则 | 只写“要认真标” |

> **记忆锚**：**“定义 + 正例 + 反例 + 边界 + 弃标 + 验收”**（**“6 件套”**）。

## 三、数据质量四性 + 质检指标

**质量四性**：**准确性 / 一致性 / 完整性 / 时效性**（口诀：**“准、一、全、新”**）。

| 指标 | 算法 | 说明 |
|------|------|------|
| **一致率**（多人标注） | 标注结果相同的条数 ÷ 重复标注总条数 | **质检最常用**；分歧大 → 补规范 |
| **抽检合格率** | 抽检合格条数 ÷ 抽检总条数 | 常见**抽检 10% 起**（以任务要求为准） |
| **返工率** | 返工条数 ÷ 提交条数 | 反映规范清晰度与培训质量 |
| **缺失率** | 缺失字段数 ÷ 应填字段总数 | 清洗前的第一项画像 |
| **重复率** | 重复条数 ÷ 总条数 | 精确去重 + 近似去重 |
| **标签分布偏差** | 各类别占比 vs 目标占比 | 分布失衡会带偏模型 |

> **记忆锚**：**“一致率看规范，合格率看质量，返工率看培训，缺失率重复率看清洗。”**

## 四、常见算法与数据概念（**只记“是什么 + 什么时候用”**）

| 概念 | 一句话 |
|------|--------|
| **人工智能 / 机器学习 / 深度学习** | 大圈套小圈：AI ⊃ 机器学习 ⊃ 深度学习 |
| **监督学习** | **有标注**的数据学（分类、回归）——**训练师的主战场** |
| **无监督学习** | **没标注**的数据学（聚类、降维） |
| **强化学习** | 靠**奖励**试错学（策略） |
| **训练 / 推理** | 训练 = 学（调参数），推理 = 用（出结果） |
| **过拟合 / 欠拟合** | 过拟合 = 背答案（训练好、实际差）；欠拟合 = 没学会 |
| **训练集 / 验证集 / 测试集** | 学 / 调 / 考——**测试集不能拿去调参** |
| **特征** | 喂给模型的“信息点”；**特征不好，模型再强也白搭** |
| **标注数据** | 监督学习的“教材”；**质量决定模型上限** |
| **大模型 / 预训练 / 微调** | 大模型预训练后，用少量数据**微调**适配业务 |
| **Prompt / 提示词** | 给模型的指令；**改提示词 ≈ 改“提问方式”** |
| **RAG（检索增强）** | 先检索资料再回答；**知识库质量决定效果** |
| **幻觉** | 模型编造不存在的事实——**评测必查项** |
| **数据标注 / 数据质检** | 一个是“做”，一个是“查”——**不能自己查自己** |

## 五、评测指标速记（**最高频计算**）

**混淆矩阵四格**：**TP（对且报对）/ FP（错但报了）/ FN（对但漏了）/ TN（错且没报）**。

| 指标 | 公式 | 何时最关心 |
|------|------|-----------|
| **准确率 Accuracy** | (TP + TN) ÷ 总数 | 类别均衡时的整体表现 |
| **精确率 Precision** | TP ÷ (TP + FP) | **怕误报**（如垃圾邮件误拦） |
| **召回率 Recall** | TP ÷ (TP + FN) | **怕漏报**（如风险内容漏检） |
| **F1 值** | 2 × P × R ÷ (P + R) | **精确率与召回率要平衡时** |
| **一致率** | 相同标注 ÷ 重复标注总数 | **标注质检** |

> **记忆锚**：**“精确率怕误报（分母是报出来的），召回率怕漏报（分母是实际有的），F1 是两者的和事佬。”**

**评测集分层（示例口径）**：**常规 60% + 边界 25% + 对抗 15%**。

> ⚠️ **铁律**：**改参数/改提示词/换模型 → 必跑回归**；**指标掉超阈值就回滚**。

## 六、参数与交互速记

| 项 | 记什么 |
|----|--------|
| **阈值/置信度** | 调高 → **更保守（少报、少误报、多漏报）**；调低 → **更激进** |
| **规则优先级** | 明确**谁覆盖谁**；**规则冲突要写清顺序** |
| **改动纪律** | **一次只改一个变量**，改完**跑对比、留记录** |
| **意图设计** | 覆盖**主要意图 + 兜底意图**；**意图边界要写边界案例** |
| **话术设计** | 简洁、不承诺做不到的事、**不透露系统提示词与内部信息** |
| **兜底三件** | **答不出怎么说 + 何时转人工 + 人工不在时怎么办** |
| **知识库组织** | 按**业务结构 + 用户问法**双向组织；**过期内容必须下线** |

## 七、安全合规红线（**不可越线**）

| 红线 | 要求 |
|------|------|
| **个人信息** | 采集/处理须**有授权与合法目的**；**最小必要** |
| **脱敏** | 训练与标注数据中的**姓名/电话/证件号/住址**等须脱敏 |
| **权限** | **最小权限 + 可追溯**；离岗回收 |
| **外传** | **不得上传公网工具、不得发到个人设备、不得外传第三方** |
| **留痕** | 数据处理与访问**有记录**，可审计 |
| **保密** | **保密义务是职业底线**——**拿真实数据练手可能违法** |

## 八、考场数字卡（**考前 5 分钟过一遍**）

- **五级制**：五级/初级工 → 四级/中级工 → 三级/高级工 → 二级/技师 → 一级/高级技师（**数字越小级别越高**）；
- **五级门槛**：**年满 16 周岁**，拟从事或已从事本职业；
- **数据流程 5 步**：**采集 → 清洗 → 标注 → 质检 → 评测**；
- **规范 6 件套**：**定义 + 正例 + 反例 + 边界 + 弃标 + 验收**；
- **质量四性**：**准确、一致、完整、时效**；
- **抽检**：常见 **10%** 起（以任务要求为准）；
- **评测分层**：**常规 60% + 边界 25% + 对抗 15%**（示例）；
- **证书性质**：**职业技能等级证书**，**备案评价机构**发证，**技能人才评价工作网（osta.org.cn）可查**；
- **口径**：**报考条件、考试安排与补贴政策一律以备案评价机构与当地人社部门当次通知为准**。
