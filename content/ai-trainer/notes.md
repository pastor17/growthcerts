## 该记什么（理论与实操清单）

**① 理论清单**

| 类别 | 必记内容 | 记忆抓手 |
|------|---------|---------|
| **AI 基础** | AI / 机器学习 / 深度学习的关系；训练与推理；监督、无监督、强化学习；分类/检测/生成等任务类型 | **“数据 → 训练 → 模型 → 推理 → 评估”**一条链 |
| **数据与模型** | 数据质量决定模型上限；垃圾进垃圾出；标注数据是监督学习的“教材” | **“模型是学生，数据是教材，标注是批改”** |
| **数据采集** | 自有数据 / 公开数据集 / 众包采集 / 采集标注一体；授权与合规边界 | **“先看授权，再取数据”** |
| **数据清洗** | 去重（精确 + 近似）、缺失处理、异常值、格式与编码统一、去噪 | **“去重、补缺、剔异常、统格式、清噪声”** |
| **数据标注类型** | 分类、序列标注（实体）、关系抽取、框选（检测）、多边形（分割）、转写（语音） | **按“任务形态”对号入座** |
| **标注规范** | 标签定义 + 正例 + 反例 + **边界案例** + 歧义处理 + 弃标规则 + 验收标准 | **“规范的含金量在边界案例”** |
| **质量检测** | 准确性 / 一致性 / 完整性 / 时效性；抽检、复核、一致率、返工与留痕 | **“四性 + 抽检 + 一致率”** |
| **参数设置** | 阈值与置信度、规则优先级、参数与业务效果的对应关系、改动必对比 | **“改一个、测一次、留一条记录”** |
| **人机交互** | 意图分类、话术与提示设计、知识库组织、追问、**兜底与转人工** | **“答不出怎么办 = 交互设计的核心”** |
| **性能测试** | 测试集（常规/边界/对抗）、指标计算、回归测试、问题跟踪 | **“没有测试集的改动 = 赌博”** |
| **安全合规** | 个人信息保护、脱敏、权限最小化、保密义务、不得外传与私自留存 | **“数据不出门”是底线** |

**② 实操清单**

| 实操环节 | 关键动作（评分看这个） | 常见失分点 |
|---------|---------------------|-----------|
| **采集与清洗** | 按方案取数 → 统计画像 → 去重/缺失/异常/格式 → **输出清洗报告** | 不看去重口径、清洗无记录 |
| **标注** | **先读规范** → 处理边界案例 → 按提交格式输出 | 按自己理解标、格式错 |
| **质检** | 抽检比例 → 一致率计算 → 不合格返工 → 留记录 | 只看“我觉得对”，不给数字 |
| **参数设置** | 明确业务目标 → 设阈值/规则 → **跑对比** → 说明理由 | 只给数值不给理由 |
| **交互设计** | 意图覆盖 → 话术 → **兜底与转人工条件** | 只写正常路径，不写兜底 |
| **性能测试** | 建测试集 → 跑评测 → 算指标 → 写结论与建议 | 测试集全是常规样本、无对抗样本 |

**③ 必背数字与结构（一般口径，具体以机构为准）**

- **五级制**：五级/初级工 → 四级/中级工 → 三级/高级工 → 二级/技师 → 一级/高级技师（**数字越小级别越高**）；
- **五级门槛**：**年满 16 周岁**，拟从事或已从事本职业；
- **数据流程 5 步**：**采集 → 清洗 → 标注 → 质检 → 评测**；
- **质量四性**：**准确性 / 一致性 / 完整性 / 时效性**；
- **评测样本分层**：**常规 60% + 边界 25% + 对抗 15%**（示例口径）；
- **抽检比例**：常见 **10%** 起（**以任务与机构要求为准**）；
- **查询入口**：**技能人才评价工作网（osta.org.cn）**。

## 记忆方法

**① 流程链记忆法（最有效）**

把一切知识点挂到**一条主链**上，考试时就按链条走：

```text
业务目标 → 数据采集 → 清洗 → 标注规范 → 标注 → 质检 → 参数/交互 → 评测 → 上线跟踪
```

> **口诀**：**“目标定标准，采集看授权，清洗去脏乱，规范写边界，标注按格式，质检算一致，参数要对比，交互留兜底，评测建测试集，上线看追踪。”**

**② 对比表记忆法**

凡是容易混的概念，**一律做成两列表**：

| 易混对 | 一句话区分 |
|--------|-----------|
| **准确率 vs 召回率** | 准确率看“报出来的对不对”，召回率看“该报的有没有漏” |
| **精确率 vs 准确率** | 精确率是“报出的里面对的占比”（面向预测为正），准确率是“全部里对的占比” |
| **训练 vs 推理** | 训练是“学”，推理是“用” |
| **标注 vs 质检** | 标注是“做”，质检是“查”，**不能同一个人自查了事** |
| **兜底 vs 转人工** | 兜底是“答不出时怎么说”，转人工是“什么条件交给人工” |
| **数据清洗 vs 数据质检** | 清洗改数据（去重/补缺），质检评数据（合格率/一致率） |

**③ 场景锚点法（把抽象变画面）**

- **标注规范** 想象成 **“考试评分标准”**——**你不看评分标准就答题，写得再多也没分**；
- **数据清洗** 想象成 **“洗菜”**——**烂叶子不摘，炒出来整盘都苦**；
- **质量检测** 想象成 **“出厂质检”**——**抽检 + 记录 + 返工，缺一不可**；
- **评测集** 想象成 **“体检套餐”**——**只量身高不查血，等于没体检**（**测试集要有边界与对抗样本**）；
- **兜底设计** 想象成 **“客服的‘我帮您转接’”**——**不设计兜底的 AI 产品 = 死胡同**。

**④ 数字卡法**

把关键数字与结构写在一张小卡上（见 [一页速记](/ai-trainer/cheatsheet/)），**每天过一遍，考前只看卡片**。

**⑤ 错题归因法**

每道错题只写一句：**“错在概念 / 错在流程 / 错在看错题”**——**只错在“看错题”的，才是会做的题**；**错在概念的，回书上原文核对定义**。

## 10 条避坑清单

| # | 坑 | 正确做法 |
|---|----|---------|
| 1 | **把本证当“国家职业资格证”** | 它是**职业技能等级证书**，由**备案评价机构**认定发证；**能上技能人才评价工作网查才作数** |
| 2 | **以为有“全国统考、统一时间”** | **没有统考**，由**各备案机构按批次组织**，**以当次通知为准** |
| 3 | **信“包过/免考/内部题库”** | **一律是骗局**；按国家职业技能标准与备案机构通知备考 |
| 4 | **信“挂靠赚钱”** | **技能等级证书没有挂靠市场**，**任何挂靠提议直接拒绝** |
| 5 | **不读标注规范就动手** | **先读规范 + 边界案例**，**规范不清就问，别靠猜** |
| 6 | **先标注后清洗** | **先清洗再标注**——**脏数据标两遍 = 白干** |
| 7 | **改参数/提示词不跑对比** | **改动必跑评测**，指标掉超阈值就回滚；**“我测过”才是合格回答** |
| 8 | **测试集只放常规样本** | **分层建集：常规 + 边界 + 对抗**；**只测简单样本 = 假安全感** |
| 9 | **交互设计不写兜底** | **必须写“答不出/不会做”的路径与转人工条件** |
| 10 | **忽略数据安全合规** | **脱敏、权限最小化、不外传、不留存**——**这是职业红线，不是加分项** |

## 冲刺阶段安排

**考前四周（可按实际时间等比压缩）**：

| 阶段 | 时间 | 做什么 |
|------|------|--------|
| **第 1 周｜扫框架** | 7 天 | 通读《人工智能基础与数据素养》4 章 + 整理**流程链笔记**；每天 10 分钟过 [一页速记](/ai-trainer/cheatsheet/) |
| **第 2 周｜攻实操** | 7 天 | 通读《数据标注与训练实操》4 章 + **动手做 1 个完整小项目**（清洗 → 标注 → 质检） |
| **第 3 周｜补短板** | 7 天 | 做 [题库练习](/ai-trainer/practice/)；错题按“概念/流程/看错题”归因，**回原文核对** |
| **第 4 周｜模拟冲刺** | 7 天 | **限时模拟实操**（按任务要求 + 提交格式）；背数字卡；过一遍 10 条避坑清单 |

**考前 3 天清单**：

- [ ] 确认**考试时间、地点/线上入口、证件与准考证**（**以机构通知为准**）；
- [ ] 过一遍**流程链口诀**与**数字卡**（不学新内容）；
- [ ] 复习**实操提交格式**（文件命名、字段、目录结构）——**格式错=白做**；
- [ ] 复习**易混对比表**（准确率/召回率、标注/质检、兜底/转人工）；
- [ ] 复习**安全合规红线**（哪些数据绝对不能外传）；
- [ ] 早点睡——**实操考试拼的是清醒，不是熬夜**。

> **最后一句**：**这张证的分数主要在“能不能按规范做出来”**——**背得再熟，不如完整做过一遍**。考完记得**上技能人才评价工作网自查证书信息**。
