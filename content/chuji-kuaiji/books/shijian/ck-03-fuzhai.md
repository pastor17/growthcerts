## 考点梳理

### 3.1 短期借款

取得时：借"银行存款" 贷"短期借款"；**利息按期计提**：借"财务费用" 贷"应付利息"（或直接支付）；到期还本付息。

### 3.2 应付及预收款项

- **应付账款**：赊购商品/材料形成的债务；享受现金折扣时，通常按**总价法**入账，实际付款时折扣冲减财务费用（示例口径，以最新教材为准）；
- **预收账款**：预先收取客户货款形成的负债；不含预收款项的企业可设"合同负债"核算；
- 应付票据（商业汇票）、其他应付款（押金、暂收款等）。

### 3.3 应付职工薪酬

内容包括：**工资、奖金、津贴和补贴；职工福利费；社会保险费（养老、医疗、失业、工伤、生育）；住房公积金；工会经费与职工教育经费；非货币性福利；辞退福利**（示例口径）。

核算思路：计提（按受益对象计入成本费用）→ 发放（代扣个税、社保个人部分）。

### 3.4 应交税费

| 税种/项目 | 框架要点 |
|-----------|---------|
| **增值税** | 一般纳税人：购进取得扣税凭证记入"应交税费—应交增值税（**进项税额**）"；销售计提"**销项税额**"；应纳税额＝销项−进项（抵扣规则以最新政策为准） |
| 消费税 | 生产/委托加工/进口应税消费品环节缴纳（涉及税目与税率，以最新教材为准） |
| 企业所得税 | 按期预缴、年度汇算清缴（税率与优惠以最新政策为准） |
| 个人所得税 | 单位代扣代缴（工资薪金等，扣除标准以最新政策为准） |
| 其他 | 城市维护建设税、教育费附加、房产税、印花税等（计入税金及附加或相关资产成本） |

> ⚠️ **税率、起征点、扣除标准与优惠政策每年可能调整**，本书只讲会计处理逻辑，具体数字请以最新官方教材与政策为准。

## 🧠 记忆工具箱

### 分录模板

| 业务 | 分录 |
|------|------|
| 取得短期借款 | 借：银行存款　贷：短期借款 |
| 计提短期借款利息 | 借：财务费用　贷：应付利息 |
| 计提工资（管理部门） | 借：管理费用　贷：应付职工薪酬 |
| 发放工资（代扣个税） | 借：应付职工薪酬　贷：银行存款、应交税费—应交个人所得税 |
| 购进材料（一般纳税人、取得专用发票） | 借：原材料、应交税费—应交增值税（进项税额）　贷：应付账款 |
| 销售商品 | 借：银行存款/应收账款　贷：主营业务收入、应交税费—应交增值税（销项税额） |
| 预收货款 | 借：银行存款　贷：合同负债（或预收账款） |

### 口诀速记

- 职工薪酬**六大块**：`工资奖金津贴、福利、社保、公积金、工会与教育经费、非货币性福利`（+辞退福利）；
- 增值税一句话：**进项记借方（可抵）、销项记贷方（应交）**；
- 短期借款利息：**财务费用**（不是管理费用）。

## ⚠️ 易错提醒

- 支付给**股东的股利**属于"应付股利"，**不属于**应付职工薪酬；
- 增值税**进项税额**记在"应交税费"的**借方**（相当于可抵扣资产性质），别与销项记反；
- 预收货款在**尚未交付商品**前是**负债**，不能直接确认收入（收入确认以控制权转移为准）；
- 涉及税率、社保比例、扣除标准的题目，务必按**最新教材给出的数字**作答（考试以教材为准）。
