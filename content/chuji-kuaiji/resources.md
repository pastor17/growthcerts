> **先说结论**：会计类考试在 GitHub 上的**开源资料明显少于软考**——检索"初级会计"多被无关高星仓库占据，真正对口的仓库数量少、星标低。因此本站建议：**官方大纲 + 正版教材/题库为主**，开源仓库仅作补充参考。下载后请遵守作者许可，仅供个人学习。

## 已核验的可用资源

### 1. 注册会计师（CICPA）备考笔记（可作进阶参考）
- 仓库：[fanchile/CPANote](https://github.com/fanchile/CPANote) ｜ 核验：**5★ · CC-BY-SA-4.0 许可 · 最近更新 2026-03-20**
- 内含：中国注册会计师考试学习笔记（会计、审计等科目知识点整理）
- 适合：初级考完后想继续深造的考生；**初级考生可参考其中"会计基础与分录"相关章节**
- 注意：属**注会**难度，内容与初级大纲不完全一致；CC-BY-SA-4.0 许可要求署名并以相同方式共享

### 2. 注册会计师笔记与公众号文章备份
- 仓库：[KKKaniel/cicpa-notes](https://github.com/KKKaniel/cicpa-notes) ｜ 核验：**1★ · 未标注许可证 · 最近更新 2026-06-24**
- 内含：CICPA 备考笔记与知识点整理文档
- 适合：作为知识点扩展阅读；**无许可证，仅个人学习使用，请勿转载**

> 检索说明：GitHub 对"初级会计""会计 题库"等中文关键词的检索结果混杂大量无关内容（编程教程、书籍合集等），本页只收录**经人工核验确实与会计考试相关**的仓库；若后续发现更好的初级会计资料，会持续补充。

## 官方渠道（强烈建议优先使用）

| 渠道 | 用途 |
|------|------|
| [财政部会计财务评价中心](http://kzp.mof.gov.cn) | **考试大纲、考试公告、报名入口、成绩查询、合格信息查询**（全流程官方入口） |
| 全国会计资格评价网报名系统 | 网上报名、缴费、准考证打印 |
| 官方教材（经济科学出版社 / 中国财政经济出版社） | 与当年度大纲完全对应的**唯一权威内容**，税法数字每年更新 |

## 使用建议

1. **不要依赖第三方题库**：会计题目涉及分录与税法细节，错题本来源不可靠会带偏判断；
2. 官方教材 + 本站精讲建框架 → 本站题库练章节 → 正版辅导书/官方模拟系统做完整卷；
3. 税法部分（增值税、企业所得税、个人所得税）**每年可能调整**，考前务必核对当年教材与政策；
4. 开源笔记只用于"换个角度看知识点"，不作为标准答案。
