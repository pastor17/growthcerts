## 考点梳理

### 2.1 销售与收款循环（**"收入确认"是重中之重**）

**常见风险**：高估收入（提前确认/虚构销售）、低估应收账款（坏账）。

**五步法收入确认**（审计视角逐条核对）：

| 步骤 | 审计关注 | 典型错报 |
|------|---------|---------|
| ① 识别合同 | 合同是否成立、条款是否明确 | 无书面合同即确认 |
| ② 识别履约义务 | 商品/服务是否可区分 | 捆绑销售拆分错误 |
| ③ 确定交易价格 | 可变对价（折扣/退款/返利）估计 | 返利计提不足 |
| ④ 分摊交易价格 | 按单独售价比例分摊 | 分摊比例随意 |
| ⑤ 确认收入 | **控制权转移时点** | 提前确认（发运即确认 vs 签收确认） |

**实质性程序**（必背组合）：

```text
① 细节测试：抽样核查销售合同 → 出库单/签收单 → 发票 → 银行回单（"四单匹配"）
② 截止测试：资产负债表日前后各 10 天的发货单，核对入账期间
③ 函证：应收账款函证（积极式为主，回函不符要追查）
④ 期后收款：期后收到银行回单，验证真实性
```

> **记忆锚**：**"四单匹配 + 前后 10 天截止 + 函证 + 期后收款"**。

### 2.2 采购与付款循环

**常见风险**：高估应付账款/存货（虚构采购）、未入账负债。

| 程序 | 内容 |
|------|------|
| **控制测试** | 三单匹配（请购单 → 采购订单 → 入库单/验收单） |
| **细节测试** | 抽样核对采购合同 → 发票 → 入库单 → 付款 |
| **未入账负债** | **期后付款测试**（资产负债表日后 1~2 个月付款，倒查是否应计入当期） |

> **记忆锚**：**"采购三单匹配，负债靠期后付款倒查"**——**未入账负债是采购循环的经典考点**。

### 2.3 生产与存货循环

| 程序 | 内容 |
|------|------|
| **存货监盘** | **核心程序**：观察盘点过程、抽盘（双向：账 → 实物；实物 → 账）、关注截止 |
| **计价测试** | 成本计算复核（料工费分摊）、可变现净值（跌价准备） |
| **分析程序** | 毛利率、存货周转率（与上期/行业比） |

> **监盘三关注**：**"存在性（账 → 实物）+ 完整性（实物 → 账）+ 截止（盘点日 = 账载日"）。

### 2.4 货币资金循环（**"函证 + 截止"双核心**）

| 程序 | 内容 |
|------|------|
| **银行函证** | **必做**（由注册会计师直接发函、直接收函）；未回函 → 替代程序（核对银行对账单 + 期后流水） |
| **现金盘点** | 突击盘点库存现金（编制现金盘点表） |
| **截止测试** | 资产负债表日前后银行流水（大额收支） |
| **大额异常** | 关注：大额整数转账、临近期末的大额进出、关联方资金往来 |

> **记忆锚**：**"函证要直接发收，现金要突击盘点，流水要查前后"**。

## 🧠 记忆工具箱

### 口诀速记

- 销售：**"四单匹配截十天，函证期后验收入"**；
- 采购：**"三单匹配防虚构，期后付款查漏账"**；
- 存货：**"监盘双向抽，跌价看市价"**；
- 货币：**"函证直接发收，现金突击盘点"**。

### 场景锚点

- 循环审计想象"**"查账的侦探"**"：你**不是会计**（**不需要记账**），**你是侦探**（**"找线索"**）——每个循环就是一类"案件"：**销售循环查"收入是不是真赚到的"，采购循环查"负债是不是漏记了"，存货循环查"仓库里是不是真有这么多货"，货币循环查"账上的钱是不是真在银行"**。

## ⚠️ 易错提醒

- **收入"控制权转移"不是"风险报酬转移"**（旧准则表述已改）——主观题写旧表述可能失分；
- **应收账款函证**：未回函**不能直接认定为错报**，必须追查替代程序（期后收款 + 合同单据）；
- **存货监盘**：监盘是**对"盘点日的存在与状况"**，**不能替代对完整性的测试**（完整性靠期后入库倒查）；
- **银行函证**：**必须由注册会计师控制发函与收函**——"由被审计单位代发" = 程序无效（高频陷阱题）。
