## 考点梳理

### 2.1 应纳税所得额（与会计利润的桥）

**应纳税所得额 = 收入总额 − 不征税收入 − 免税收入 − 各项扣除 − 允许弥补的以前年度亏损**

或简化：**应纳税所得额 = 会计利润 + 纳税调增 − 纳税调减**

### 2.2 高频调增/调减项目（数字卡，以当年度政策为准）

| 项目 | 规则 | 方向 |
|------|------|------|
| **业务招待费** | 发生额 **60%** 与**营收 5‰** 取**小**，超出部分调增 | 调增 |
| **广告费/业务宣传费** | 营收 **15%** 以内（化妆品/医药/饮料 **30%**），超过**结转以后年度** | 调增（可结转） |
| **职工教育经费** | 工资总额 **8%** 以内，超过**结转** | 调增（可结转） |
| **工会经费** | 工资总额 **2%** 以内，超过**不得扣除** | 调增（不可结转） |
| **补充医疗保险** | 工资总额 **5%** 以内 | 调增 |
| **公益性捐赠** | 年度利润总额 **12%** 以内，超过**结转 3 年** | 调增（可结转） |
| **罚款/滞纳金** | 行政罚款、税收滞纳金、赞助支出 | **全额调增**（不可结转） |
| **国债利息** | 免税 | **全额调减** |
| **居民企业分红** | 直接投资股息（连续持有上市公司 12 个月以上） | 免税（调减） |
| **研发费用加计** | 未形成无形资产：按 **100%** 加计扣除（形成无形资产按 **200%** 摊销）（以当年度政策为准） | **调减**（额外扣） |
| **固定资产加速折旧** | 500 万以下一次性扣除；高新技术/制造业 100% 加速（以政策为准） | 调增（当年）/ 调减（以后年度） |

> **记忆锚**：**"招待 60 与 5‰ 取小，广告 15 教育 8 工会 2，罚款全额加，国债全额减，研发 100% 加计"**。

### 2.3 资产损失（税前扣除规则）

- **实际资产损失**：实际发生时扣除（如存货被盗、应收账款核销）；
- **预期资产损失**：年末**汇算清缴前**扣除（如预计不能收回的应收账款）；
- **扣除凭证**：内部证据（会计记录、盘点表）+ 外部证据（公安/消防/法院文书）——**无凭证不得扣除**；
- 应收账款核销：需**逐项**确认（单笔 5000 万以下可清单申报，以政策为准）。

### 2.4 税收优惠（综合题必考）

| 优惠 | 内容（示例口径，以当年度政策为准） |
|------|--------------------------------|
| **高新技术企业** | 税率 **15%**（需认定，有效期 3 年） |
| **小型微利** | 应纳税所得额 ≤ 300 万 + 从业 ≤ 300 人 + 资产 ≤ 5000 万 → 实际税负 **5%**（2027 年底前，以政策为准） |
| **研发加计** | 未形成无形资产 **100% 加计**；形成无形资产 **200% 摊销**（制造业/科技型中小企业 120% 加计，以政策为准） |
| **固定资产一次性** | 500 万以下设备器具**当年一次性扣除**（可分年也可一次性） |
| **技术转让** | 500 万以内**免征**，超过部分**减半**（单个项目） |
| **三免三减半** | 农、林、牧、渔项目：前 3 年免、后 3 年减半 |
| **环保/节能/节水** | 第一年起**10 年**减半征收（专用设备投资额 **10%** 抵免） |
| **安置残疾/退役军人** | 加计 **100%** 扣除 / 定额税額抵免（以政策为准） |

> **记忆锚**：**"高新 15 小微 5，研发 100 加计，技术 500 万免减半"**。

### 2.5 亏损弥补（数字卡）

- 一般企业：**5 年**内弥补（税前利润）；
- **高新/科技型中小企业**：**10 年**内弥补（以政策为准）；
- 亏损年度**往后**弥补（不是往前）；**先亏先补**（按时间顺序）。

## 🧠 记忆工具箱

### 口诀速记

- 调增三兄弟：**"招待广告教育费"**（都看比例，超了调增）；
- 全额调增：**"罚款滞纳赞助费"**（永远不能扣）；
- 优惠：**"高新 15 小微 5，研发 100 加计，技术 500 免减半"**；
- 亏损：**"一般 5 年高新 10，先亏先补往后走"**。

### 场景锚点

- 研发加计想象"**花 100 万研发，税法让你扣 200 万**"：实际支出 100 万 + 加计 100 万 = 税前可扣 200 万——**省了 25 万税**（100×25%），这就是"加计"的福利。

## ⚠️ 易错提醒

- 业务招待费是**双重限制取小**（60% 与 5‰），**不是**"超 60% 调增"——算错是综合题第一坑；
- 广告费/教育经费/公益捐赠**超部分可结转**，工会经费**超部分不可结转**——"可结转"与"不可结转"是高频陷阱；
- 研发加计是**调减**（额外扣），不是调增——方向别搞反；
- 小型微利**三个条件必须同时满足**（所得/人数/资产），缺一个就不能享受；
- 亏损弥补是**税前利润**弥补（不是会计利润），**先亏先补**——顺序错了数字全错。
