> **用法**：考前 3 天起只过这一页 + 错题笔记。**专业阶段 6 科必须 5 年内全部合格**，任何一科拖过 5 年都要重考——别偏科。

## 一、税法数字卡（以当年度政策为准）

| 事项 | 数字 |
|------|------|
| 增值税税率 | **13%**（货物/加工修理）/ **9%**（交通运输/建筑/不动产/农产品）/ **6%**（现代服务/金融/生活服务）；简易计税 **3%**（部分 **5%**） |
| 企业所得税 | **25%**；高新 **15%**；小型微利优惠（以当年度政策为准） |
| 个税综合所得 | **3%~45%** 七档（3/10/20/25/30/35/45） |
| 增值税纳税申报 | 次月 **15 日**内（遇节假日顺延） |
| 企业所得税汇算清缴 | 年度终了 **5 月 31 日**前 |
| 个税年度汇算 | **6 月 30 日**前 |
| 税收滞纳金 | 日 **万分之五** |
| 发票保管期限 | **30 年**（会计凭证）；**年度财务报告永久** |
| 税收行政复议 | 对征税行为：先复议再诉讼（**复议前置**）；对处罚/保全：复议或诉讼二选一 |

## 二、会计高分公式与分录要点

- **长期股权投资**：成本法（子公司）按成本计量 + 分红进投资收益；权益法（合营/联营）按份额调整长投 + 投资收益；**转换**是综合题必考；
- **金融工具减值**：预期信用损失（ECL），**三阶段**（信用风险显著增加/已发生信用减值/正常）；
- **递延所得税**：资产账面 < 计税基础 → **可抵扣暂时性差异**（确认递延所得税资产）；反之 → 应纳税暂时性差异（递延所得税负债）；
- **收入五步法**：识别合同 → 识别义务 → 确定价格 → 分摊价格 → 履约时点确认。

## 三、财管计算流程（步骤分要写全）

- **NPV** = Σ 现金流 / (1+r)^t − 初始投资；**NPV>0 投资，NPV<0 放弃**；
- **IRR** = 使 NPV=0 的折现率（机考用计算器"IRR"键或插值法）；
- **WACC** = E/V×Re + D/V×Rd×(1−T)——**别忘了 (1−T)**；
- 机考：公式编辑器**逐步输入**，变量先列后算；**计算器按键练熟**（财管允许带指定型号）。

## 四、机考注意事项

- **财管带计算器**：指定型号（以准考证为准），提前练好按键；
- **税法/经济法**：法条检索功能（机考系统内置）——**不要求精确条号**，但要会查；
- 综合题**时间分配**：60~80 分钟/题（综合阶段 5 小时 4 题）——**先做有把握的**；
- 多选题规则：**错选不得分、少选得部分分**——拿不准就少选；
- 两卷（综合阶段）**不能跳卷**：试卷一/二分别计时，一卷结束才能做二卷。
