> 考试大纲以**中注协当年度发布**为准；下方为模块结构整理（示例口径）。

## 专业阶段 6 科模块

### 1 会计（全书之王）

| 模块 | 重要度 |
|------|--------|
| 存货、固定资产、无形资产 | ★★★★（分录基础） |
| **长期股权投资与合营安排** | ★★★★★（全书最难） |
| **金融工具**（分类、减值、套期） | ★★★★★ |
| 收入（五步法）、租赁 | ★★★★★ |
| **所得税**（递延所得税） | ★★★★★ |
| **合并财务报表** | ★★★★★（综合题必考） |
| 外币折算、政府补助、非货币性资产交换 | ★★★ |

### 2 审计

| 模块 | 重要度 |
|------|--------|
| 审计准则、职业道德、独立性 | ★★★★ |
| 审计风险与重要性 | ★★★★★ |
| 风险评估与应对、控制测试 | ★★★★★ |
| 各类循环审计（销售/采购/生产/货币资金） | ★★★★ |
| **审计报告**（意见类型） | ★★★★★ |

### 3 财务成本管理

| 模块 | 重要度 |
|------|--------|
| 财务管理基础（时间价值、风险收益） | ★★★★ |
| **投资决策（NPV/IRR/内含报酬率）** | ★★★★★ |
| 资本结构（WACC、MM 定理） | ★★★★★ |
| 营运资本、股利政策 | ★★★ |
| 成本管理、本量利分析 | ★★★★ |
| 期权与衍生品 | ★★★ |

### 4 税法

| 模块 | 重要度 |
|------|--------|
| **增值税**（进项/销项/特殊业务） | ★★★★★ |
| **企业所得税**（纳税调整、优惠） | ★★★★★ |
| **个人所得税**（综合所得、专项扣除） | ★★★★★ |
| 关税、消费税、土地增值税、契税、印花税 | ★★★ |
| 税收征管（期限、处罚、复议诉讼） | ★★★ |

### 5 经济法

| 模块 | 重要度 |
|------|--------|
| 物权、合同（效力/履行/担保） | ★★★★★ |
| **公司、企业**（治理/股权/破产） | ★★★★★ |
| 证券法（发行/交易/投资者保护） | ★★★★ |
| 票据、外汇、反垄断 | ★★★ |
| 破产、期货 | ★★ |

### 6 公司战略与风险管理

| 模块 | 重要度 |
|------|--------|
| 战略分析（PEST/五力/价值链/SWOT） | ★★★★ |
| 战略选择（总体/业务/职能战略） | ★★★★ |
| 战略实施与变革管理 | ★★★ |
| **风险管理**（识别/评估/应对） | ★★★★ |
| **内部控制**（COSO 五要素） | ★★★★ |

## 综合阶段

- 试卷一：会计 + 审计 + 税法（**3 道综合题**，跨科联动）；
- 试卷二：财管 + 经济法 + 战略（**3 道综合题**）；
- 考法：**一个业务场景贯穿多科**（如"某公司并购"同时考会计合并、税法企业所得、经济公司法、战略分析）。

## 备考路线（2~3 科/年）

```text
① 基础轮（3~5 月）：会计 → 税法/财管（按搭配）每天 2~3 小时
   ↓
② 强化轮（6 月）：章末题 + 真题按年做 → 错因分类
   ↓
③ 冲刺轮（7~8 月）：套卷限时 + 综合题跨科串联 → 考前 1 周只过数字卡与错题
```
