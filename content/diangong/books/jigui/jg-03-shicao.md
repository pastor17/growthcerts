## 考点梳理

### 3.1 电气安装（**"安全红线"优先**）

**布线规范**（**必记**）：

| 项目 | 规范（示例口径，以国标为准） |
|------|---------------------------|
| **导线选择** | 按**载流量**选截面（如 1.5mm²/2.5mm²/4mm²） |
| **颜色** | **相线：黄/绿/红（A/B/C）；零线：淡蓝；地线：黄绿双色** |
| **敷设** | 明敷用穿管/线槽；暗敷走墙内（**强弱电分槽，间距 ≥ 30cm**） |
| **接地** | **保护接地（PE）**：设备外壳接黄绿线；**接地电阻一般 ≤ 4Ω** |

**配电箱接线**（**顺序不能乱**）：

```text
进线 → 总开关（断路器）→ 分路开关（漏电保护器）→ 用电器
```

> **记忆锚**：**"相线黄绿红，零线淡蓝地黄绿；先总后分，漏电必装"**。

### 3.2 调试（**"仪表 + 参数"**）

**万用表使用**（**必会**）：

| 档位 | 用途 | 注意 |
|------|------|------|
| **电压档（V）** | 测交/直流电压 | **并联**接入；先选大量程 |
| **电流档（A）** | 测电流 | **串联**接入；严禁带电换档 |
| **电阻档（Ω）** | 测电阻/通断 | **必须断电**；两手不碰表笔金属 |
| **通断档** | 查线路通断（蜂鸣） | 断电操作 |

**断路器整定**：

| 参数 | 说明 |
|------|------|
| **额定电流（In）** | 按负载电流选（一般 = 1.2~1.5 倍负载电流） |
| **瞬时脱扣** | 短路保护（**I = 数 × In**，按线路选） |
| **漏电保护（RCD）** | **30mA 人身保护级**（家用/潮湿场所必装） |

> **记忆锚**：**"电压并、电流串、测电阻先断电；漏保 30mA 保人身"**。

### 3.3 排故（**"从大到小，从外到内"**）

**短路**（**"一测就跳"**）：

| 步骤 | 操作 |
|------|------|
| ① 隔离 | 断开电源（**先断总开关**） |
| ② 目测 | 查烧焦/鼓包/异味（**先眼看**） |
| ③ 测量 | 万用表**电阻档**逐段测（**从电源到负载**） |
| ④ 定位 | **电阻为 0 处 = 短路点** |
| ⑤ 修复 | 换线/换件 → 复测 → 送电 |

**断路**（**"一送就断"**）：

| 步骤 | 操作 |
|------|------|
| ① 隔离 | 断电 |
| ② 目测 | 查断线/松线/烧断的保险 |
| ③ 测量 | 通断档**分段测**（**分压法**：测各点电压，电压突变处 = 断点） |
| ④ 修复 | 换线/紧固 → 复测 → 送电 |

**漏电**（**"漏保总跳"**）：

| 步骤 | 操作 |
|------|------|
| ① 隔离 | 断总开关 |
| ② 分路排查 | **逐路送电**：哪路送电漏保跳 = 问题在那一路 |
| ③ 绝缘测试 | **兆欧表（摇表）**测线路绝缘电阻（**< 0.5MΩ 视为绝缘不良**） |
| ④ 定位 | 分段摇表，**绝缘电阻骤降段 = 漏电点**（多为受潮/破皮） |
| ⑤ 修复 | 换线/干燥/做防水 → 复测 → 送电 |

> **记忆锚**：**"短路测电阻找零，断路分压找断点，漏电摇表找低阻"**。

### 3.4 安全红线（**"一条不能碰"**）

1. **带电作业 = 违规**（除持证带电作业外）——**先断电、验电、挂接地线、挂牌**；
2. **验电**：用**相应电压等级**的验电器，**先在有电处验证**再验目标；
3. **一人操作一人监护**（危险场所）；
4. **火灾**：电气火灾用**干粉/CO₂ 灭火器**，**严禁用水**（先断电）。

> **记忆锚**：**"断电验电挂接地，干粉灭火不用水"**。

## 🧠 记忆工具箱

### 场景锚点

- 实操想象"**"修车"**"：你**不是乘客**（**不需要坐车**），**你是修理工**（**"诊断 + 动手"**）——**安装 = 装新零件（顺序不能错）；调试 = 调发动机参数（仪表是"仪表盘"）；排故 = 听异响找故障（"从大到小"像"先查发动机再查轮胎"）**。

## ⚠️ 易错提醒

- **颜色规范**：**地线必须是黄绿双色**（不能挪用）——**地线接错 = 触电风险**；
- **电流表**：**严禁带电换档**（会烧表 + 触电）——**先断电再换档**；
- **漏电保护 30mA** 是**人身保护级**（工业/线路保护用 100~300mA）——**别混淆等级**；
- **排故必须断电**（绝缘测试用摇表时线路也需停电）——**"带电排故"是事故主因**；
- **电气火灾先断电**——**带电泼水 = 触电**（**干粉/CO₂ 是正确答案**）。
