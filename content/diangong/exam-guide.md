> 本节按应急管理部/人社部历年公告整理；**当次报名与考试安排以各省应急管理厅/人社厅公告为准**。

## 特种作业操作证时间线（示例口径）

| 环节 | 大致时间 |
|------|---------|
| **安全培训** | **8 学时**（**"报名前"**） |
| **报名** | **全年可考**（**各省应急管理厅/安监局**） |
| **理论考** | **机考**（**100 题/120 分钟**） |
| **实操考** | **现场操作**（**停送电/接地/工作票**） |
| **成绩公布** | 考后 **1 周** |
| **领证** | 成绩合格后 **1 个月** |
| **复审** | **6 年一复审**（**"逾期需重新考试"**） |

## 电工职业资格时间线（示例口径）

| 环节 | 大致时间 |
|------|---------|
| **报名** | 一般 **2~3 月/9~10 月**（**各省人事考试网/人社厅**） |
| **理论考** | **机考**（**单选 + 多选 + 判断**） |
| **实操考** | **现场操作**（**安装/调试/排故**） |
| **成绩公布** | 考后 **1 个月** |
| **领证** | 成绩合格后 **1~2 个月** |

> **注意**：**"特种作业操作证"必须**（**"没有证 = 不能上岗"**）；**"电工职业资格"加分**（**"职称/补贴/落户"**）。

## 报名条件（官方口径，示例结构）

**特种作业操作证**：

- **年满 18 周岁**；
- **身体健康**（**无妨碍从事电工作业的疾病**）；
- **初中及以上文化**（**以各省为准**）；
- **安全培训 8 学时**（**"报名前"**）。

**电工职业资格**：

- **初中及以上文化**（**初级**）；
- **中级/高级**需**工作年限**（**以各省为准**）；
- 政治素质等通用条件。

## 考试形式与合格标准

**特种作业操作证**：

- **理论**：**机考**（**100 题/120 分钟**，**单选 + 多选 + 判断**）；
- **实操**：**现场操作**（**停送电/接地/工作票**）；
- 合格标准：理论 **80 分**（**100 分制**）；实操 **80 分**。

**电工职业资格**：

- **理论**：**机考**（**单选 + 多选 + 判断**）；
- **实操**：**现场操作**（**安装/调试/排故**）；
- 合格标准：理论 **60 分**；实操 **60 分**。

## 复审（**"特种作业操作证"**）

- **6 年一复审**（**"逾期需重新考试"**）；
- **复审内容**：**安全培训 + 理论考**（**"实操不考"**）；
- **复审周期**：**6 年**（**"每 6 年 1 次"**）。

## 备考建议

1. **特种作业"实操不规范 = 丢分"**：**"停送电/接地/工作票"**（**"3 种操作"**）必须会；
2. **职业资格"电路基础"**：**"欧姆定律/基尔霍夫定律/串并联"**（**"3 种"**）必须会；
3. **机考"必须练"**：**理论机考**（**"输入 + 时间"**是失分重灾区）；
4. **安全培训"8 学时"**：**"报名前"**必须完成（**"逾期不能报名"**）；
5. **考前 1 周"只过数字卡 + 错题"**：**"触电急救/电气火灾"** + **"停送电/接地/工作票"** + **"欧姆定律/基尔霍夫"**。
