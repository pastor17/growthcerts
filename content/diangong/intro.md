## 是什么

**电工特种作业操作证**（**应急管理部**，**准入类**）与**电工职业资格**（**人社部**，**水平类**）是电工行业的**"双证"**。**"特种作业操作证"必须**（**"没有证 = 不能上岗"**），**"电工职业资格"加分**（**"职称/补贴/落户"**）。

## 特种作业操作证 vs 电工职业资格（核心区别）

| 对比项 | **特种作业操作证** | **电工职业资格** |
|--------|------------------|----------------|
| **组织方** | **应急管理部**（原安监局） | **人社部** |
| **类型** | **准入类**（**必须**） | **水平类**（**加分**） |
| **科目** | **《安全生产技术》**（**实操**）+ **《安全生产法规》**（**理论**） | **《电气基础》**（**理论**）+ **《实操》**（**安装/调试/排故**） |
| **形式** | **实操 + 理论**（**理论机考**） | **理论 + 实操**（**理论机考**） |
| **合格标准** | 理论 **80 分**；实操 **80 分** | 理论 **60 分**；实操 **60 分** |
| **复审** | **6 年一复审**（**"逾期需重新考试"**） | **无复审**（**"一次通过"**） |
| **适合谁** | **电工上岗**（**"必须"**） | **职称/补贴/落户**（**"加分"**） |

> **记忆锚**：**"特种作业"必须，"职业资格"加分**——**"准入 + 水平"**。

## 考什么

### 特种作业操作证（**"实操 + 理论"**）

**《安全生产技术》**（**实操**）：

| 模块 | 核心内容 |
|------|---------|
| **电气安全** | **触电/电弧/静电/雷击**（**"4 种危害"**） |
| **安全用具** | **绝缘手套/绝缘鞋/验电器**（**"3 种"**） |
| **安全操作** | **停送电/装拆接地线/工作票**（**"3 种操作"**） |
| **应急处置** | **触电急救/电气火灾**（**"2 种"**） |

**《安全生产法规》**（**理论**）：

| 模块 | 核心内容 |
|------|---------|
| **《安全生产法》** | **企业责任/从业人员权利/法律责任**（**"3 块"**） |
| **《特种作业安全》** | **电工/焊工/高处作业**（**"3 种"**） |
| **《电气安全规程》** | **停送电/接地/工作票**（**"3 种"**） |

> **题型**：**单选 + 多选 + 判断**（**理论机考**，**100 题/120 分钟**）。

### 电工职业资格（**"理论 + 实操"**）

**《电气基础》**（**理论**）：

| 模块 | 核心内容 |
|------|---------|
| **电路基础** | **欧姆定律/基尔霍夫定律/串并联**（**"3 种"**） |
| **电机** | **变压器/电动机/发电机**（**"3 种"**） |
| **电气控制** | **接触器/继电器/PLC**（**"3 种"**） |
| **电气测量** | **万用表/钳形表/兆欧表**（**"3 种"**） |

**《实操》**（**安装/调试/排故**）：

| 模块 | 核心内容 |
|------|---------|
| **安装** | **配电柜/控制柜/照明**（**"3 种"**） |
| **调试** | **电压/电流/功率**（**"3 种"**） |
| **排故** | **短路/断路/漏电**（**"3 种"**） |

> **题型**：**单选 + 多选 + 判断**（**理论机考**）+ **实操**（**安装/调试/排故**）。

## 含金量与难度（职场人决策参考）

| 维度 | 说明 |
|------|------|
| **岗位用途** | 电工：**工厂/物业/电力/建筑**（**"特种作业操作证"必须**） |
| **行业地位** | **准入类**（**"没有证 = 不能上岗"**）+ **水平类**（**"职称/补贴/落户"**） |
| **职称对应** | **电工职业资格**（**初级/中级/高级**）可对应**技能等级**（**"1~5 级"**） |
| **个税与补贴** | **特种作业操作证**：**"准入类"**（**一般不能申报个税继续教育专项附加扣除**）；**电工职业资格**：**"水平类"**（**可申报，480 元/年，以税务规定为准**） |
| **难度评级** | **特种作业操作证**：★★★☆☆（**"实操 + 理论"**）；**电工职业资格**：★★★☆☆（**"理论 + 实操"**） |
| **建议总学时** | **特种作业操作证**：**100~200 小时**；**电工职业资格**：**200~400 小时** |
| **主要难点** | **特种作业**：**"实操不规范"**（**"停送电/接地/工作票"**）；**职业资格**：**"电路基础"**（**"欧姆定律/基尔霍夫"**） |
| **适合谁** | **电工上岗**（**"特种作业操作证"**）；**职称/补贴/落户**（**"电工职业资格"**） |
| **建议先别考的情形** | 仅因"想转行"（**"安全培训 8 学时"**必须）；时间无法保证每周 10 小时以上 |
