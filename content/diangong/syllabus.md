> 考试大纲以**应急管理部/人社部当次公告**为准；下方为模块结构整理（示例口径）。

## 特种作业操作证（**"实操 + 理论"**）

### 1 《安全生产技术》（**实操**）

| 模块 | 重要度 |
|------|--------|
| **电气安全**（**触电/电弧/静电/雷击**） | ★★★★★（**"4 种危害"**） |
| **安全用具**（**绝缘手套/绝缘鞋/验电器**） | ★★★★（**"3 种"**） |
| **安全操作**（**停送电/装拆接地线/工作票**） | ★★★★★（**"3 种操作"**） |
| **应急处置**（**触电急救/电气火灾**） | ★★★★★（**"2 种"**） |

### 2 《安全生产法规》（**理论**）

| 模块 | 重要度 |
|------|--------|
| **《安全生产法》**（**企业责任/从业人员权利/法律责任**） | ★★★★（**"3 块"**） |
| **《特种作业安全》**（**电工/焊工/高处作业**） | ★★★（**"3 种"**） |
| **《电气安全规程》**（**停送电/接地/工作票**） | ★★★★★（**"3 种"**） |

## 电工职业资格（**"理论 + 实操"**）

### 1 《电气基础》（**理论**）

| 模块 | 重要度 |
|------|--------|
| **电路基础**（**欧姆定律/基尔霍夫定律/串并联**） | ★★★★★（**"3 种"**） |
| **电机**（**变压器/电动机/发电机**） | ★★★★（**"3 种"**） |
| **电气控制**（**接触器/继电器/PLC**） | ★★★★（**"3 种"**） |
| **电气测量**（**万用表/钳形表/兆欧表**） | ★★★（**"3 种"**） |

### 2 《实操》（**安装/调试/排故**）

| 模块 | 重要度 |
|------|--------|
| **安装**（**配电柜/控制柜/照明**） | ★★★★★（**"3 种"**） |
| **调试**（**电压/电流/功率**） | ★★★★（**"3 种"**） |
| **排故**（**短路/断路/漏电**） | ★★★★★（**"3 种"**） |

## 备考路线

### 特种作业操作证（1~2 个月）

```text
① 安全培训（**8 学时**，**"报名前"**）
   ↓
② 基础轮（**电气安全 + 安全用具 + 安全操作**）
   ↓
③ 强化轮（**应急处置 + 安全生产法规**）
   ↓
④ 冲刺轮（**套卷限时 + 实操模拟**）
```

### 电工职业资格（2~4 个月）

```text
① 基础轮（**电路基础：欧姆定律/基尔霍夫/串并联**）
   ↓
② 强化轮（**电机 + 电气控制 + 电气测量**）
   ↓
③ 实操轮（**安装 + 调试 + 排故**）
   ↓
④ 冲刺轮（**套卷限时 + 实操模拟**）
```
