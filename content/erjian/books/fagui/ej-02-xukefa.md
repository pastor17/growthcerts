## 考点梳理

### 2.1 施工许可证（高频数字）

- **申领主体**：建设单位（工程开工前向工程所在地县级以上住建主管部门申请）；
- **申领条件（要点）**：用地批准手续、**建设工程规划许可证**、拆迁进度符合施工要求、已确定施工企业、施工图设计文件审查合格、**有保证工程质量和安全的具体措施**、建设资金已落实（示例口径）；
- **有效期**：自领取之日起 **3 个月内**开工，可申请**延期 2 次、每次不超过 3 个月**；既不开工又不延期 → 许可证**自行废止**（示例口径）；
- **不需/无需办理**：工程投资额与建筑面积较小的工程、抢险救灾工程等按法定情形（示例口径）；
- **开工报告替代**：按规定批准开工报告的工程，可不再申领施工许可证（示例口径）。

### 2.2 从业资格与注册执业

| 主体 | 要求 |
|------|------|
| 施工企业 | 应具备相应**资质等级**并在许可范围内承揽工程 |
| 建造师 | 取得执业资格证书并**注册**后方可执业；不得同时受聘于两个及以上单位 |
| 其他专业人员 | 特种作业人员须持证上岗 |

### 2.3 发包与承包

- **发包方式**：招标发包（依法必须招标的项目）、直接发包；
- **禁止行为**：
  | 行为 | 含义 |
  |------|------|
  | **转包** | 承包单位将其承包的**全部**工程转给他人，或肢解后以分包名义分别转给他人 |
  | **违法分包** | 分包给不具备资质者、未经建设单位认可擅自分包、**主体结构施工分包**、分包单位再分包等 |
  | 挂靠/借用资质 | 无资质单位借用有资质单位名义承揽工程 |
- **合法分包条件**：经建设单位认可（合同约定除外）、分包单位具备相应资质、**分包工程不得再次分包**、**主体结构施工不得分包**（示例口径）；
- 总承包单位与分包单位就分包工程对建设单位承担**连带责任**（示例口径）。

### 2.4 建设工程合同的效力

无效情形（示例口径）：承包人未取得资质或超越资质等级、应招标未招标或中标无效、**转包与违法分包**等；合同无效但工程经验收合格的，可参照合同约定折价补偿（示例口径）。

## 🧠 记忆工具箱

### 口诀速记

- 施工许可有效期：**3 个月开工、可延期 2 次、每次 3 个月**；
- 分包三红线：**有资质、经认可、不再次分包**；**主体结构不得分包**；
- 连带责任：**总包与分包对建设单位承担连带责任**；
- 从业两要求：**企业有资质、个人要注册**。

### 例题（带解析）

**例题**：关于建设工程分包，下列说法正确的是？
A. 分包单位可以将分包工程再分包给他人
B. 经建设单位认可后，可将主体结构施工分包给其他单位
C. 分包单位应具备相应资质，且分包工程不得再次分包
D. 总承包单位对分包工程不承担责任
**答案 C**。解析：合法分包需具备资质、经认可且不得再分包；**主体结构施工不得分包**；总承包与分包单位对建设单位承担连带责任。

## ⚠️ 易错提醒

- **主体结构施工不得分包**是硬性红线，无论是否经建设单位认可；
- **转包**针对"全部工程或肢解后全部转出"，与"合法分包"性质完全不同；
- 施工许可证"3 个月 + 延期 2 次×3 个月"是必考数字组合；
- 分包需经**建设单位认可**（合同有约定的除外），不是"监理同意即可"。
