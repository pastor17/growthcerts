## 考点梳理

### 3.1 施工质量控制

- 控制要点：**原材料与设备进场检验**（见证取样送检）、工序交接检查、**隐蔽工程验收**（隐蔽前必须验收并形成记录）、技术交底、样板引路；
- **验收层次**：**检验批 → 分项工程 → 分部工程 → 单位工程**（逐级验收，前一层次合格方可进行后续）；
- 质量事故处理原则：查清原因、明确责任、制定处理方案、实施处理、验收确认（示例口径）；
- 质量记录：施工日志、检验记录、隐蔽验收记录、试验报告等应真实完整并归档。

### 3.2 安全管理

- **安全生产责任**：施工单位主要负责人对单位安全生产全面负责；项目负责人对项目安全生产负责；专职安全员负责监督检查；
- **三级安全教育**：公司级、项目级、班组级；
- **危险性较大的分部分项工程（危大工程）**：应编制**专项施工方案**；超过一定规模的危大工程，专项方案须**组织专家论证**（示例口径）；
- 安全检查：日常检查、专项检查、季节性检查；隐患整改应做到"定人、定时、定措施"；
- **事故等级与报告**：特别重大/重大/较大/一般（按死亡人数 30/10/3 为主线记忆）；单位负责人接到报告后**1 小时内**上报县级以上主管部门；
- 事故处理"四不放过"原则：事故原因未查清不放过、责任人员未处理不放过、整改措施未落实不放过、有关人员未受到教育不放过。

### 3.3 环境与绿色施工

- **扬尘控制**：现场围挡、覆盖、洒水、车辆冲洗、道路硬化；
- **噪声控制**：合理安排作业时间，夜间施工须按规定审批；
- **污水与固废**：沉淀处理后排放、分类收集与合规处置；
- **绿色施工"四节一环保"**：**节能、节地、节水、节材 + 环境保护**。

## 🧠 记忆工具箱

### 口诀速记

- 验收四层：**检验批 → 分项 → 分部 → 单位工程**（由小到大）；
- 事故处理：**"四不放过"**（原因、责任、整改、教育）；
- 报告时限：单位负责人**1 小时内**上报；
- 绿色施工：**四节一环保**（节能、节地、节水、节材 + 环保）；
- 危大工程：**专项方案**；超规模者**专家论证**。

### 例题（带解析）

**例题 1**：施工质量验收的正确层次顺序是？
A. 单位工程 → 分部工程 → 分项工程 → 检验批
B. 检验批 → 分项工程 → 分部工程 → 单位工程
C. 分项工程 → 检验批 → 分部工程 → 单位工程
D. 检验批 → 分部工程 → 分项工程 → 单位工程
**答案 B**。解析：工程施工质量验收按"检验批 → 分项工程 → 分部工程 → 单位工程"逐级进行，前一级合格是后一级验收的前提。

**例题 2**：某危大工程专项施工方案按规定需要组织专家论证。该工程最可能属于？
A. 一般分部分项工程　B. 超过一定规模的危险性较大的分部分项工程　C. 常规装饰工程　D. 临时设施工程
**答案 B**。解析：危大工程须编制专项施工方案；**超过一定规模**的危大工程，专项方案还应组织专家论证（示例口径，以现行规定为准）。

### 补充：质量与安全常见数字速查

| 数字 | 含义 |
|------|------|
| 3 / 10 / 30 | 一般/较大/重大/特别重大事故的死亡人数分界（<3、3–9、10–29、≥30） |
| 1 小时 | 单位负责人上报事故的时限 |
| 三级 | 安全教育层级（公司、项目、班组） |
| 四不放过 | 事故处理原则 |
| 四节一环保 | 绿色施工要求 |

## ⚠️ 易错提醒

- **隐蔽工程必须在隐蔽前验收**并留存记录，事后补验常被判定为程序违规；
- 验收层次顺序**由小到大**（检验批最小），颠倒即为错误；
- 危大工程"编制专项方案"与"专家论证"是**两个层次**的要求，别混为一谈；
- 绿色施工是"**四节一环保**"（不含"节电"之外的重复项），记忆时按"能、地、水、材 + 环保"。
