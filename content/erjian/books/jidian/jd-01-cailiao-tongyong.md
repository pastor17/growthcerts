## 考点梳理

### 1.1 常用材料

**金属材料**
- **黑色金属**：碳素钢（按含碳量分低/中/高碳钢）、合金钢、铸铁；
- **有色金属**：铜及铜合金（导电导热好，用于电缆、管道）、铝及铝合金（密度小、耐蚀）、钛及钛合金（耐蚀性优，用于化工设备）。

**非金属材料**
- **塑料**：PVC（给排水管）、PE（燃气与给水管）、PPR（热水管）、ABS、聚四氟乙烯（耐腐蚀衬里）；
- **橡胶**：用于密封、减振、衬里；
- **绝热材料**：岩棉、玻璃棉、聚氨酯泡沫、橡塑（按使用温度与防火要求选）。

**电工线材与电缆**
- 常用导线：BV（铜芯聚氯乙烯绝缘）、BLV（铝芯）、BVR（铜芯软线）、YJV（交联聚乙烯绝缘电力电缆）；
- 电缆选择考虑：**电压等级、载流量、敷设方式与环境（直埋、桥架、穿管、潮湿与腐蚀）**。

**阀门**
| 类型 | 作用 |
|------|------|
| 闸阀 | 全开全关，阻力小，不宜调节流量 |
| 截止阀 | 可调节流量，**有方向性**（低进高出） |
| 止回阀 | 防止介质倒流 |
| 安全阀 | 超压泄放（**须铅封与定期校验**） |
| 减压阀 | 降低并稳定介质压力 |
| 蝶阀 | 结构紧凑，用于大口径与快速启闭 |

### 1.2 机电工程测量

| 仪器 | 主要用途 |
|------|---------|
| **水准仪** | 测量**高程**与标高控制 |
| **经纬仪** | 测量**水平角与竖直角**、点位放样 |
| **全站仪** | 同时测**角度与距离**，可测坐标与高程，效率高 |
| **激光准直仪** | 长距离、大直径设备的**同心度与直线度**控制 |

**测量程序**：**先整体后局部、先控制后细部**；建立测量控制网（平面控制与高程控制）→ 交接桩与复测 → 施工放样 → 竣工测量。

### 1.3 起重技术

- **索具**：钢丝绳（按受力选择直径与安全系数）、卸扣、吊耳、吊带、卷扬机；
- **起重机具**：自行式起重机（汽车吊、履带吊）、塔式起重机、桅杆式起重机（受限空间或超大件）；
- **吊装方案内容**：工程概况、吊装工艺与参数、受力计算（吊重、幅度、起升高度）、机具选型与站位、**地基承载能力处理**、安全技术措施与应急预案；
- **吊装关键控制**：
  - **吊装载荷**应含设备重量 + 吊索具重量 + 加固件重量，必要时乘动力系数；
  - **地基承载力**不足时应铺设钢板/路基箱或加固处理（防止支腿下沉倾覆）；
  - 多机抬吊时应进行**载荷分配**计算，统一指挥、同步起升；
  - **严禁超载**、严禁斜拉斜吊、严禁吊物上站人。

### 1.4 焊接技术

**焊前准备**
- **焊接工艺评定**（评定合格后才能编制焊接作业指导书）；
- **焊工资格**：须持有效合格项目范围内的资格证；
- **焊材**：按母材与工艺要求选用，焊条使用前按规定烘干；
- **坡口与组对**：坡口尺寸、间隙、错边量符合规范；
- **预热**：厚壁、高碳当量或有淬硬倾向材料焊前应预热（按工艺评定确定温度）。

**焊接过程控制**
- 控制**焊接线能量**（避免过大导致晶粒粗大、过小导致未熔合）；
- 多层多道焊应**控制层间温度**、逐层清渣检查；
- 室外作业应有防风、防雨措施，低温环境需采取保温措施。

**焊后处理**
- **焊后热处理**（消除应力、改善组织）：用于厚壁容器、管道等；
- 焊缝检验顺序：**外观检查 → 无损检测**（RT 射线、UT 超声、MT 磁粉、PT 渗透）→ 必要时**硬度与金相检验**；
- 检验比例与合格级别按设计与规范要求确定，**不合格部位应返修，同一部位返修次数不宜超过规定**。

**焊接变形控制**
- 合理确定**焊接顺序**（对称焊、分段退焊）；
- 采用**刚性固定**、**反变形法**；
- 控制线能量与层间温度，必要时采用锤击（限打底层）等工艺措施。

## 🔍 深度精讲

### 深讲 1：为什么吊装事故多与"地基"有关

起重机倾覆事故中，相当比例并非超载，而是**支腿或履带下方的地基承载力不足**导致下沉、机身倾斜。因此吊装方案必须包含：

1. **地基承载力验算**：按起重机支腿最大反力与地面承载力比较；
2. **地基处理措施**：铺设路基箱、钢板、枕木，或对软弱地基进行换填、夯实、混凝土硬化；
3. **排水措施**：避免雨水浸泡软化地基；
4. **站位与幅度复核**：作业半径越大，倾覆力矩越大，应严格按方案站位，**不得随意增大作业半径**；
5. **统一指挥与警戒**：设专人指挥、设警戒区，严禁无关人员进入吊装区域。

**案例判错信号**："为赶工期在雨后松软地面直接支车吊装""司机凭经验加大幅度够取远处设备""吊装区域未设警戒"——**均属不妥**。

### 深讲 2：焊接工艺评定的意义与链条

**焊接工艺评定（PQR）**是用试验验证拟定焊接工艺是否能使焊接接头性能满足要求的过程。其逻辑链条为：

**焊接工艺评定（试验验证）→ 编制焊接作业指导书（WPS）→ 焊工按 WPS 施焊（资格覆盖）→ 过程检验（外观 + 无损检测）→ 合格验收**

**为什么不能省**：不同母材、厚度、焊接方法、焊材与位置组合下的接头性能差异很大，凭经验施焊无法保证质量；评定合格后方可推广到同类工程。

**案例答题要点**：出现"未做焊接工艺评定即开始焊接承压管道""焊工证书项目与施焊位置不符""焊材未按规定烘干直接使用"等描述，一律判为不妥，并写出正确做法。

### 深讲 3：无损检测方法的选用逻辑

| 方法 | 检出缺陷类型 | 适用 |
|------|------------|------|
| **射线检测 RT** | 内部体积型缺陷（气孔、夹渣） | 对接焊缝，需安全防护 |
| **超声检测 UT** | 内部面积型缺陷（裂纹、未熔合） | 厚壁对接焊缝，效率高 |
| **磁粉检测 MT** | 表面与近表面缺陷 | 铁磁性材料表面 |
| **渗透检测 PT** | 表面开口缺陷 | 非铁磁性材料（不锈钢、铝）表面 |

**选用逻辑**：先看**缺陷位置（内部/表面）**，再看**材料磁性**，最后看**构件形状与现场条件**。答题时写出"依据设计与规范要求，对接焊缝采用射线或超声检测，表面检测按材料磁性选择磁粉或渗透检测"即可拿到要点分。

## ⚠️ 易错提醒

- 水准仪测**高程**、经纬仪测**角度**，二者不要互换；
- 截止阀**有方向性**（低进高出），安装方向错误会影响使用；
- 安全阀须**铅封并定期校验**，不得随意调整；
- 吊装载荷要计入**索具与加固件重量**，不能只算设备净重；
- **焊接工艺评定是前提**，未评定不得施焊承压件；
- 无损检测选用要区分**内部/表面缺陷**与**材料磁性**；
- 焊缝返修次数**有规定上限**，不能反复多次返修。
