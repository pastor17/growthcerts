## 考点梳理

### 3.1 交通导行与占路施工

- 占路施工应编制**交通导行方案**并报**交通管理部门批准**；
- 分阶段布置：**警告区 → 上游过渡区 → 缓冲区 → 作业区 → 下游过渡区 → 终止区**；
- 设置围挡、警示标志、夜间照明与反光设施，必要时设专人疏导交通；
- 施工结束后及时恢复路面与交通设施。

### 3.2 地下管线保护（市政案例必答）

1. **查资料**：施工前查阅并核实管线资料（位置、埋深、材质、产权单位）；
2. **现场探**：采用**物探（管线探测仪）+ 坑探**确认实际位置与埋深；
3. **定方案**：制定保护或改移方案；重要管线（燃气、高压电力、给水干管）**约请产权单位到场监护**；
4. **人工开挖**：在管线保护范围内**禁止机械开挖，改用人工开挖**；
5. **悬吊加固**：对暴露管线进行悬吊加固、设置警示标志与临时支撑。

**管线破坏的应急处置**：立即**停止作业、撤离人员、划定警戒区、严禁烟火**，通知产权单位与消防、燃气等专业部门抢险，**严禁一切可能产生火花的作业**（不得随意启停机械与电闸），随后配合抢修与责任认定。

### 3.3 施工组织设计与专项方案

- **施工组织设计**内容：工程概况、施工部署与方案、进度计划、资源配置、施工现场平面布置、技术经济指标；
- 审批：一般由项目技术负责人审批，规模大或特殊工程按规定报企业技术负责人审批或组织专家论证；
- **危大工程**应编制**专项施工方案**；达到"超过一定规模"标准的（如深基坑、高大模板支架、大跨度吊装等）须组织**专家论证**（专家不少于 5 名，本项目参建人员不得以专家身份参加）。

### 3.4 进度控制与工期索赔

- 流水施工参数与工期计算（等节拍、成倍节拍、无节奏）；
- 网络计划：关键线路、总时差与自由时差（**总时差 ≥ 自由时差**）；
- **工期索赔判断**：
  - 事件责任**非承包方**；
  - 结合该工作**总时差**判断：拖延 ≤ 总时差 → **工期不索赔**（费用可索赔）；拖延 > 总时差 → 可索赔工期 = 拖延天数 − 总时差；
  - 索赔应在合同约定期限内提出（一般为 **28 天**）并提供证据。

### 3.5 合同与变更管理

- 变更指令权一般属**发包人（或经授权的监理人）**，承包人不得擅自变更；
- 现场额外工作与费用应及时办理**书面签证**（监理与发包人代表签认）；
- 索赔费用归类：人工费（窝工按约定单价）、机械费（自有按不变费用、租赁按租赁费）、材料保管与退货损失、措施费按实计取；**利润一般在发包人违约时可主张**。

### 3.6 质量验收与安全生产

**验收层次**：检验批（专业监理工程师组织）→ 分项工程（专业监理工程师）→ 分部（子分部）工程（总监理工程师）→ 单位（子单位）工程（建设单位项目负责人组织，五方参加）。

**安全生产要点**
- 三级安全教育、书面安全技术交底并双方签字、特种作业持证上岗；
- 临电：**TN-S 系统、三级配电两级保护、一机一闸一漏一箱**；
- 安全防护：**"四口"**（楼梯口、电梯井口、预留洞口、通道口）与**"五临边"**（基坑边、楼层边、屋面边、阳台边、卸料平台边）；
- 基坑与管道沟槽作业注意**防坍塌**（支撑、放坡、监测）与**防中毒窒息**（有限空间作业先通风、再检测、后作业）。

### 3.7 绿色文明施工

- **扬尘控制**：洒水降尘、覆盖、场地硬化、车辆冲洗、渣土密闭运输；
- **噪声控制**：低噪声设备、隔声屏障、夜间施工须审批并公告附近居民（夜间一般指 22:00 至次日 6:00）；
- **废水与泥浆**：沉淀处理后排放，泥浆外运合规处置；
- 现场围挡、材料堆放、临时设施与卫生管理。

## 🔍 深度精讲

### 深讲 1：市政案例题的"标准答题块"

市政案例问"指出不妥之处并说明正确做法"时，可按四个固定块检索：

| 答题块 | 检查要点 |
|--------|---------|
| **程序合规** | 交通导行是否报批、专项方案是否审批/论证、交底是否书面签字、验收是否按层次组织 |
| **工序顺序** | 先撑后挖、随挖随撑、对称回填、连续灌注、分层压实、试验后回填 |
| **环境保护** | 管线探测与监护、周边监测与预警、夜间施工审批与公告、扬尘与泥浆处理 |
| **安全防护** | 临电三级配电两级保护、四口五临边防护、有限空间先通风再检测后作业、持证上岗 |

**答题句式**：① 该做法不妥；② 依据（规范/法规名称或管理要求）；③ 正确做法应为……；④ 还应……（补充监测、验收、记录等）。

### 深讲 2：有限空间作业为什么是市政"隐形杀手"

市政管道、检查井、污水池、暗挖隧道都属于**有限空间**：通风不良、可能积聚**硫化氢、甲烷、一氧化碳**等有毒有害或易燃气体，且氧含量可能不足。正确程序是：

1. **先通风**（机械通风，不得用纯氧通风）；
2. **再检测**（检测氧含量、可燃气体、有毒气体浓度，合格后方可进入，作业中持续检测）；
3. **后作业**（办理审批、专人监护、佩戴防护用品、设置安全带与提升装置、配备应急设备）；
4. **严禁盲目施救**——事故统计显示，大量伤亡发生在**未防护的救援人员**身上，必须由具备防护条件的专业人员施救。

**案例提示**：出现"作业人员未检测即下井""有人晕倒后同事直接下井救人"等描述，标准答案是"**违反有限空间作业规定，且盲目施救会导致事故扩大**"。

### 深讲 3：工期索赔与费用索赔为什么经常"结论不一致"

同一个事件，**工期索赔**与**费用索赔**可以一个成立、一个不成立，原因在于判断依据不同：

- **工期索赔**看**是否影响总工期**（只认总时差）；
- **费用索赔**看**责任归属与是否造成实际损失**（与总时差无关）。

**示例**：非关键工作（总时差 5 天）因发包人原因拖延 3 天 → 未超总时差，**工期索赔 0 天**，但停工造成的窝工人工费、机械停置费**可索赔**。

**答题要点**：先判断工作是否在关键线路上、总时差多少，再分别给出工期与费用的结论，并写出索赔时限（28 天）与证据要求。

### 例题（带解析）

**例题 1**：市政道路占路施工前，施工单位应当？
A. 自行决定围挡范围后开工
B. 编制交通导行方案并报交通管理部门批准
C. 只需口头告知附近居民
D. 夜间施工无需任何手续
**答案 B**。解析：占路施工应编制交通导行方案并报交通管理部门批准，按警告区至终止区分阶段布置导行设施，夜间施工还须按规定办理审批并公告。

**例题 2**：某非关键工作总时差 5 天，因发包人原因拖延 3 天，承包人可索赔？
A. 工期 3 天　B. 工期 0 天，费用可索赔　C. 工期 2 天　D. 工期与费用均不可索赔
**答案 B**。解析：拖延 3 天未超过总时差 5 天，不影响总工期，故工期索赔不成立；但责任在发包人且造成实际损失，费用索赔成立。

**例题 3**：进入市政污水管道等有限空间作业前，正确的作业顺序是？
A. 先作业再检测　B. 先通风、再检测、后作业　C. 由作业人员凭经验判断是否安全　D. 有人陪同即可不检测
**答案 B**。解析：有限空间作业必须坚持"先通风、再检测、后作业"，作业中持续检测并设专人监护，严禁盲目施救。

## ⚠️ 易错提醒

- 占路施工必须**报交通管理部门批准**，不是"自行围挡"；
- 管线保护范围内必须**人工开挖 + 悬吊加固**，并**约请产权单位监护**；
- 燃气泄漏处置首要是**严禁烟火、撤离警戒**，不是立即回填；
- 工期索赔只认**总时差**，费用索赔看**责任归属**，结论可以不一致；
- 有限空间作业顺序是**先通风、再检测、后作业**，且**严禁盲目施救**；
- 验收组织者按层次区分，检验批与分项是**专业监理工程师**。
