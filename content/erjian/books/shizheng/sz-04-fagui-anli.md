## 考点梳理

### 4.1 市政工程相关法规与标准要点

| 领域 | 要点 |
|------|------|
| 施工许可 | 领证后 **3 个月内**开工；延期以两次为限、每次不超过 **3 个月**；中止施工 **1 个月内**报告、满 **1 年**恢复前核验 |
| 招标投标 | 依法必须招标的项目应采用公开招标；中标通知书**发出即生效**；订立书面合同应在中标通知书发出后 **30 日内** |
| 合同 | 主体结构**不得分包**；分包须经建设单位认可；转包与违法分包合同无效 |
| 安全生产 | 总承包单位对施工现场安全生产负**总责**并对分包工程**连带**；特种作业持证上岗；危大工程专项方案与专家论证 |
| 质量管理 | 建设单位应在竣工验收合格后 **15 日内**备案；保修期自**竣工验收合格之日**起算 |
| 环境保护 | 夜间施工（**22:00—6:00**）原则上禁止，抢修抢险、工艺要求等例外须取得证明并公告居民 |

### 4.2 危险性较大的分部分项工程（市政常见）

| 项目 | 危大工程 | 超过一定规模（须专家论证） |
|------|---------|--------------------------|
| 基坑开挖 | ≥3m（或地质条件复杂） | **≥5m** |
| 模板支撑体系 | 高度 ≥5m / 跨度 ≥10m / 总荷载 ≥10kN/m² | 高度 **≥8m** / 跨度 **≥18m** / 总荷载 **≥15kN/m²** |
| 起重吊装 | 单件 ≥10kN | 单件 **≥100kN** |
| 脚手架 | ≥24m 落地式 | **≥50m** |
| 其他 | 拆除、暗挖、顶管、水下作业等 | 幕墙 ≥50m、人工挖孔桩 ≥16m 等 |

**管理要点**：编制专项施工方案 → 施工单位技术负责人审核签字（总承包时总包与专业承包单位技术负责人签字）→ 达超危大标准组织专家论证（专家 ≥5 名，参建人员不得以专家身份参加）→ 按论证报告修改 → 经施工单位技术负责人、总监理工程师、建设单位项目负责人签字后实施 → **专人现场监督 + 按规定监测**。

### 4.3 验收与保修

- 验收层次与组织者：检验批/分项（专业监理工程师）、分部（总监理工程师）、单位工程（建设单位项目负责人）；
- 隐蔽工程验收：隐蔽前应通知监理及相关方验收并形成记录；
- **保修期限**（最低）：地基基础与主体结构为设计文件规定的合理使用年限；**屋面防水、有防水要求的房间与外墙面防渗漏 5 年**；供热供冷 **2 个采暖期/供冷期**；电气管线、给排水管道、设备安装与装修工程 **2 年**。

### 4.4 案例分析题的四类提问与答法

| 提问类型 | 答法要点 |
|---------|---------|
| **指出不妥之处并说明正确做法** | 逐条编号；每条写"判断 + 依据 + 正确做法 + 补充措施" |
| **原因分析** | 从材料、工艺、设备、环境、管理五个角度排查，写出可核查的具体原因 |
| **计算题**（工期、费用、索赔） | 写算式与取数来源；工期索赔先看总时差，费用索赔看责任归属 |
| **工艺/构造做法** | 写出工序顺序、关键参数与控制指标（如埋深 2~6m、超灌 0.5~1.0m、回填 500mm） |

**标准句式模板**
- 不妥：① 该做法不妥；② 依据《××规范/条例》关于××的规定（或管理要求）；③ 正确做法应为××；④ 还应××（监测、验收、交底、记录）。
- 计算：① 依据题意取数（列出已知量）；② 代入公式或累加计算；③ 得出结论（能否索赔工期/费用及数量）。

### 4.5 常见失分点

1. 只写"不妥"不写**正确做法**；
2. 混用**总时差与自由时差**判断工期索赔；
3. 工序顺序颠倒（先挖后撑、先回填后试验、面层先终压）；
4. 漏掉**环境与安全**类考点（管线保护、监测、导行审批、有限空间作业）；
5. 数字张冠李戴（埋深、超灌、回填厚度、保修年限、危大门槛）。

## 🔍 深度精讲

### 深讲 1：一道综合案例的完整答法示范

**题干**：某市政道路改造工程，施工单位在未办理占路审批的情况下设置围挡施工；机械开挖时挖断一根燃气管道，造成泄漏；同时因开挖深度 5.5m 的基坑未组织专家论证即施工，监理单位发现后要求整改。

**标准答法**

**问题 1：指出不妥之处**
1. **未办理占路审批即设置围挡施工**——不妥。占路施工应编制交通导行方案并报**交通管理部门批准**，按警告区至终止区布置导行设施并设专人疏导。
2. **机械开挖挖断燃气管道**——不妥。施工前应查阅并核实管线资料、采用物探与**坑探**确认位置；在管线保护范围内**禁止机械开挖，改为人工开挖**，并对暴露管线**悬吊加固**，重要管线约请**产权单位到场监护**。
3. **开挖深度 5.5m 的基坑未组织专家论证即施工**——不妥。开挖深度 **≥5m** 的基坑属**超过一定规模的危大工程**，其专项施工方案应组织**专家论证**（专家不少于 5 名，参建人员不得以专家身份参加），并按论证报告修改后经施工单位技术负责人、总监理工程师、建设单位项目负责人签字实施。

**问题 2：燃气泄漏的应急处置**
1. **立即停止作业、撤离人员**，划定警戒区，**严禁烟火**与一切可能产生火花的作业（不得随意启停机械设备与电闸）；
2. 通知**燃气与消防等专业部门**抢险，通知产权单位到场；
3. 配合抢修与检测，确认安全后方可复工；
4. 保护现场、做好记录，配合事故调查与责任认定。

**问题 3：后续管理措施**
1. 补办占路与交通导行审批手续，完善现场导行设施；
2. 编制并论证基坑专项方案，落实**专人现场监督**与**监测预警**（地表沉降、支撑轴力、周边管线与建筑）；
3. 完善**开工前管线交底制度**，对机械操作人员进行培训与交底；
4. 组织安全技术交底（书面 + 双方签字）与隐患排查整改闭环。

> 观察这道答案的**结构**：每条都"判断 + 依据 + 正确做法 + 补充措施"，且**数字与规范动作齐全**——这就是得分点密集的标准写法。

### 深讲 2：为什么"工序顺序"类题目必须写后果

只写顺序不给分或少给分，写清**顺序 + 后果 + 依据**才能拿满：

| 工序 | 写清后果的答法 |
|------|---------------|
| 先撑后挖 | 支撑未形成即下挖会大幅增加围护结构悬臂高度与弯矩，导致变形超限甚至失稳、周边管线破裂 |
| 试验后回填 | 先回填后试验会掩盖接口渗漏，且无法对管道进行有效检验，渗漏将侵蚀路基结构 |
| 连续灌注 | 灌注中断易造成断桩或夹泥，需返工成桩，代价极高 |
| 分层压实 | 一次填筑过厚下部压不实，后期必然沉陷开裂 |

### 深讲 3：验收与保修"数字题"的通用记法

- **时间类**：开工 3 个月、延期 2×3 个月、中止 1 个月报告/1 年核验、备案 15 日、索赔 28 天——可串成"**3、2×3、1、1、15、28**"一条链；
- **年限类**：合理使用年限（基础主体）、5 年（防水）、2 个采暖供冷期、2 年（管线装修）；
- **构造数字类**：埋深 2~6m、超灌 0.5~1.0m、回填 500mm、满水三次各 1/3。

**复习方法**：把这三类数字写在卡片上，考前每天过一遍；考试时若记不清具体数字，就**写出判断方向 + 应遵循的规范类别**，至少能拿部分分。

### 例题（带解析）

**例题 1**：某市政工程深 5.5m 的基坑，其专项施工方案应如何处理？
A. 由项目技术负责人审批后施工
B. 由施工单位技术负责人审核签字后施工
C. 应组织专家论证，按论证报告修改并经三方签字后实施
D. 由监理单位组织专家论证
**答案 C**。解析：开挖深度 ≥5m 的基坑属超过一定规模的危大工程，专项方案应组织专家论证（施工单位组织、专家不少于 5 名），修改后经施工单位技术负责人、总监理工程师、建设单位项目负责人签字实施。

**例题 2**：市政道路工程竣工验收合格后，建设单位办理备案的期限是？
A. 7 日内　B. 15 日内　C. 30 日内　D. 60 日内
**答案 B**。解析：建设单位应自竣工验收合格之日起 15 日内，将竣工验收报告及有关部门出具的认可或准许使用文件报建设行政主管部门备案。

**例题 3**：实务案例题中「指出不妥之处」最易得分的作答方式是？
A. 笼统写"管理不规范"
B. 逐条写出不妥之处、依据与正确做法，并补充应落实的措施
C. 只写正确做法不作判断
D. 只判断不妥不写依据
**答案 B**。解析：案例按点给分，应逐条编号、判断明确、写出依据与正确做法，并补充监测、验收、交底等措施，形成完整的得分链。

## ⚠️ 易错提醒

- 专家论证会由**施工单位组织**，专家 **≥5 名**，参建人员**不得以专家身份参加**；
- 竣工验收备案是**建设单位**在 **15 日内**办理；
- 保修期自**竣工验收合格之日**起算，屋面防水为 **5 年**；
- 案例"不妥"题**必须写正确做法**，只判断不得分；
- 数字类考点要串成链条记忆（3、2×3、1、1、15、28）；
- 燃气泄漏、有限空间作业等安全类考点，**先撤离警戒、再专业抢险**，顺序不能错。
