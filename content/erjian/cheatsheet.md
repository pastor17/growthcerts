> **用法**：考前 3 天起只过这一页 + 错题笔记；**先确认本省考试时间、批次与合格标准**（二建为省级考试）。

## 一、公共课数字链条（法规 + 施工管理）

| 事项 | 数字/要点 |
|------|----------|
| 施工许可 | 领证后 **3 个月内**开工；延期 **2 次 × 3 个月**；中止 **1 个月内报告**、满 **1 年核验** |
| 竣工验收备案 | 验收合格之日起 **15 日内**（建设单位办理） |
| 索赔意向 | 事件发生后 **28 天内** |
| 保修期 | 基础主体=**合理使用年限**；防水 **5 年**；供热供冷 **2 个采暖/供冷期**；管线装修 **2 年** |
| 中标与签约 | 中标通知书**发出即生效**；**30 日内**订立书面合同 |
| 投标/履约保证金 | **≤2% 且 ≤80 万** / **≤10%** |
| 事故等级 | 死亡 **3/10/30**；重伤 **10/50/100**；损失 **1000 万/5000 万/1 亿**（三项**取最高档**） |
| 事故报告时限 | 单位负责人接到报告后 **1 小时内**上报 |
| 经济补偿 | 每满 1 年 **1 个月**；不满 6 个月 **半个月**；高于社平 3 倍按 3 倍且年限 **≤12 年** |
| 加班工资 | 工作日 **150%**、休息日不能补休 **200%**、法定节假日 **300%**（不得以补休替代） |

## 二、实务参数（建筑 / 市政 / 机电）

| 专业 | 必背数字 |
|------|---------|
| **建筑** | 拆模强度 **50/75/100%**（>8m 与悬臂 100%）；砌体水平灰缝饱满度 **≥80%**；厕浴蓄水 **24h**、淋浴墙 **1.8m**；外保温防火隔离带每层 **≥300mm**；抗震钢筋强屈比 **≥1.25**、屈标比 **≤1.30** |
| **市政** | 压实"**先轻后重、先慢后快、先边后中**"；**复压定压实度**；纵缩**加拉杆**、胀缝**上传力**；水下混凝土导管埋深 **2~6m**、超灌 **0.5~1.0m**；管顶 **500mm** 内人工回填；试验三对应（**有压水压 / 无压闭水 / 构筑物满水**）；满水**三三制**；盾构控沉降＝**土仓压力 + 同步注浆**；喷锚暗挖**十八字方针** |
| **机电** | 垫铁每组 **≤5 块**、斜垫铁成对；管道试验顺序 **强度→严密性→吹扫清洗→防腐绝热**；试运行顺序 **单机→联动→负荷**；特种设备 **告知 + 监督检验 + 使用登记** |

## 三、案例骨架（占 60 分）

```
① 不妥之处：判断 → 依据 → 正确做法 → 补充措施
② 原因分析：人的不安全行为 + 物的不安全状态 + 管理原因
③ 工期索赔：是否关键线路 → 是否超总时差 → 应索赔天数
④ 费用索赔：责任归属 → 人工/机械/材料/措施/管理费（利润看责任）
⑤ 计算：列式 → 代入 → 结论
```

**救急三句话**（写不出细节时也要写）：
1. **先撑后挖**、**随挖随撑**、**对称回填**、**试验后回填**、**连续灌注**；
2. **交通导行报批**、**管线四步**（查资料→现场探→定方案→人工开挖+悬吊加固）、**有限空间先通风再检测后作业**；
3. **验收组织者**：检验批/分项=专业监理工程师、分部=总监、单位工程=建设单位。

## 四、本省考前必查四件事（二建特有）

1. **考试时间与批次**（各省不同，以准考证为准）；
2. **合格标准**（各省自行划定，**不要用外省线判断自己**）；
3. **是否需要纸质/电子证书领取与验证流程**；
4. **专业方向**（建筑/市政/机电/公路/水利…）与答题卡/机考形式（按本省通知）。

## 五、考场分配

- 客观题平均 **≤1 分钟/题**，先易后难，不留空；
- 案例题**先写判断与措施**（按点给分），计算题写过程；
- 最后 10 分钟：补条数、检查答题卡填涂/作答区域。

> 考前 3 天只看：**本页 + 错题笔记 + 各章"易错提醒"**；**不要在考前一晚换资料**。
