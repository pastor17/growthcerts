## 是什么

**二级建造师**是建设工程领域的**执业资格**（省级），取得后可担任中小型工程施工项目的项目负责人（项目经理），并作为施工管理岗位的重要资历。

考试科目三科：

- **《建设工程施工管理》**：施工成本、进度、质量、安全与环境、合同与信息管理；
- **《建设工程法规及相关知识》**：建设工程法律体系、施工许可与发承包、合同与劳动、安全与质量法规；
- **《专业工程管理与实务》**：分建筑、市政公用、机电、公路、水利水电、矿业 6 个专业，含**案例分析题**。

## 证书价值（示例要点，请自行核实）

- **上岗与执业**：施工企业项目负责人岗位常要求持证；
- **企业资质与投标**：企业申请/维护资质、参与投标需配备一定数量建造师；
- **增项与升级**：可增项其他专业，也可继续报考一级建造师；
- **个税/补贴**：部分地区对技能/职业资格有补贴（以当地政策为准）。

## 适合人群

- 工程类/工程经济类专业在校生与毕业生；
- 施工企业技术员、施工员、资料员等一线管理人员；
- 想转岗项目经理或提升投标竞争力的从业者。

## 与一级建造师的关系

二建为**省级执业资格**，报考学历与年限门槛低于一建；一建为**全国执业资格**，考试难度与执业范围更大。**二建是一建的自然跳板**。

> ⚠️ 报考条件（学历、专业、工作年限）**各省有差异且多年调整**，请以本省人事考试网当次报名通知为准。

## 含金量与难度（职场人决策参考）

### 一、含金量：它能给你带来什么

| 维度 | 说明 |
|------|------|
| **岗位用途** | **中、小型工程项目负责人（项目经理）**；施工企业资质、投标与项目备案的常用证书 |
| **招聘认可度** | 建筑/市政/机电等行业**直接对口**；不少岗位明确要求二级建造师 |
| **职称对应** | 多地二级建造师可对应**助理工程师**职称（以本省人社部门规定为准） |
| **个税与补贴** | 取得证书当年可按 **3600 元**申报继续教育专项附加扣除；技能提升补贴一般不在其范围 |
| **落户/人才政策** | 部分省市对建造师有积分与人才政策倾斜（以当地为准） |
| **长期价值** | 一级建造师的**必经台阶**；可与安全员、造价等岗位证书组合使用 |
| **它的局限** | **省级证书**（本省注册执业为主）；职业天花板明显低于一级建造师 |

### 二、难度：需要投入多少

| 维度 | 评估 |
|------|------|
| **考试结构** | 三科：建设工程法规及相关知识 + 建设工程施工管理 + 专业工程管理与实务（**选专业方向**） |
| **难度评级** | ★★★☆☆ — 公共课偏记忆，**实务案例分析是主要分水岭** |
| **合格标准** | **各省自行划定**，同一分数在不同省份结论可能不同（**不要用外省分数线判断自己**） |
| **建议总学时** | 约 **150~300 小时**（在职约 3~6 个月） |
| **主要难点** | ① 实务案例题需要"工序 + 规范 + 责任"三件套作答；② 法规数字与期限多；③ 各省政策与考务差异大 |
| **考试频次** | 一年一次，**由各省组织**（报名与考试时间以本省人事考试网通知为准） |
| **适合谁** | 施工现场技术与管理岗人员、想走工程管理路线者 |
| **建议先别考的情形** | 无工程相关学历与从业背景（报考条件通常受专业与年限限制） |

### 三、一句话结论

> **工程行业的入门执业证**：性价比高、能直接用于岗位与投标；建议**与一建同方向**规划，避免重复学习。

> ⚠️ **关于数据的说明**：官方一般不公布统一通过率，上表「难度评级」与「建议学时」为本站依据考试结构、科目数与题型给出的**经验估计**，用于排期参考；**职称对应、补贴标准、落户积分等政策均以国家与你所在省份的最新规定为准**。
