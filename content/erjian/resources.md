> **先说结论**：建造师类考试在 GitHub 上的**开源资源非常稀少**（检索"一级建造师""二级建造师"多被无关高星仓库占据），且现有仓库多为一建口径、年份较早。本站建议：**官方大纲 + 正版教材（中国建筑工业出版社）+ 本省政府指定渠道**为主，开源仓库仅作参考。下载后请遵守作者说明，仅供个人学习。

## 官方与正版渠道（务必优先）

| 渠道 | 用途 |
|------|------|
| [住房和城乡建设部](https://www.mohurd.gov.cn) | 建造师**考试大纲、制度文件、注册管理规定** |
| **本省人事考试网 / 住建厅官网** | **报名通知、报考条件、考试时间、合格标准（二建由各省组织，差异大）** |
| 中国建筑工业出版社正版教材 | 与当年度大纲对应的权威内容（法规条文以现行有效版本为准） |
| 全国建筑市场监管公共服务平台（四库一平台） | 企业资质与注册建造师信息查询 |

## 使用建议

1. **二建报考条件各省不同**（学历、专业、年限、是否放宽），务必以本省当年通知为准，不要照搬其他省份口径；
2. 法规科目优先记忆"**数字 + 期限 + 责任主体**"三类考点，本站精讲已按此组织；
3. 实务科目必须结合**现场做法与规范条文**练习案例分析，仅刷客观题难以通过；
4. 开源资料多为一建口径且年份较旧，**不能替代当年度正版教材**。
