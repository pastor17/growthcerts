> 大纲以住房和城乡建设部发布的**考试大纲**为准；下方为模块结构整理（示例口径）。

## 科目一《建设工程施工管理》

| 模块 | 主要内容 |
|------|---------|
| 施工管理 | 项目管理组织、施工组织设计、目标动态控制 |
| 施工成本管理 | 成本计划、成本控制（挣值思路）、成本核算与分析 |
| 施工进度管理 | 网络计划（关键线路、时差计算）、进度控制措施 |
| 施工质量管理 | 质量体系、施工质量控制、质量事故处理 |
| 职业健康安全与环境 | 安全生产管理、危险源辨识、环境保护 |
| 合同与信息管理 | 施工合同、索赔、信息管理 |

**题型**：单选 + 多选（客观题为主）。

## 科目二《建设工程法规及相关知识》

| 模块 | 主要内容 |
|------|---------|
| 建设工程基本法律知识 | 法律关系、代理、物权、债权、知识产权、法律责任、诉讼时效 |
| 施工许可与发承包 | 施工许可证、从业资格、发包承包、**禁止转包与违法分包** |
| 建设工程合同与劳动 | 合同订立与履行、违约责任、价款优先受偿、劳动合同 |
| 安全与质量法规 | 安全生产制度、事故等级、质量管理与保修、竣工验收 |

**题型**：单选 + 多选。

## 科目三《专业工程管理与实务》

- 六个专业方向：**建筑、市政公用、机电、公路、水利水电、矿业**；
- 含**案例分析题**（分值占比高），考查"技术 + 管理 + 法规"综合运用；
- 备考要求：结合所选专业的技术规范与施工工艺，答题时**先定性（是否符合规范）再给依据与措施**。

## 备考路线

```text
① 先学《法规》（记忆型、见效快）→ 做章节题
   ↓
② 再学《施工管理》（网络图与成本计算是关键）
   ↓
③ 主攻《实务》：技术+管理+案例分析综合训练
   ↓
④ 真题限时训练 + 案例书写练习（手写要点）
```
