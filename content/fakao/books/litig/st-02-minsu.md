## 考点梳理

### 2.1 管辖（与刑诉对照记忆）

- **地域管辖基本规则**：**原告就被告**（被告住所地法院）；
- 例外（原告住所地/合同履行地等可管）：
  - 合同纠纷 → **被告住所地或合同履行地**；
  - 侵权纠纷 → **侵权行为地（含结果发生地）或被告住所地**；
  - 不动产纠纷 → **不动产所在地**（专属管辖）；
  - 港口作业、遗产继承 → 各自所在地（专属管辖）；
- **级别管辖**：基层法院一审为主，重大涉外、在本辖区有重大影响的案件上提一级；
- 记忆：**"原告就被告，合同看履行，侵权看行为地，不动产找专属"**。

### 2.2 举证责任（主观题高频）

- 一般规则：**"谁主张，谁举证"**——主张法律关系存在/变更/消灭的一方举证；
- 特殊侵权（举证责任倒置/减轻）：
  - 医疗损害（部分情形）：医疗机构需证明无过错（以民法典侵权责任编与司法解释为准）；
  - 环境污染：污染者需证明**其行为与损害之间不存在因果关系**（原告只需证明排污 + 损害）；
  - 高度危险作业、无/限责能力人致害等：按法律规定分配；
- 证据种类：与刑诉八种类似，另有**当事人陈述**独立成类。

### 2.3 审限与程序（数字必背）

| 程序 | 审限（示例口径） |
|------|----------------|
| **简易程序**（基层，事实清楚权利义务明确争议不大） | **3 个月** |
| **普通程序** | **6 个月**（可延长 6 个月，特殊情况再报延） |
| **二审（判决）** | **3 个月**（可延长） |
| 立案 | 符合起诉条件 **7 日内立案** |
| 执行申请时效 | **2 年** |

### 2.4 财产保全与先予执行

- **诉前保全**：情况紧急，先保全后起诉（保全后 **30 日内**不起诉则解除）；
- **诉中保全**：提供担保（法院可责令）；
- 先予执行：追索**赡养费/扶养费/抚育费/抚恤金/医疗费用/劳动报酬**等，权利义务明确且不先予执行将严重影响生活的；
- 记忆：**"先予执行=先给救命的钱"**。

### 2.5 与行政诉讼对照（一张表）

| 对比项 | 民事诉讼 | 行政诉讼 |
|--------|---------|---------|
| 被告 | 平等主体（个人或单位） | **行政机关（恒为被告）** |
| 举证责任 | 谁主张谁举证 | **被告（行政机关）对行政行为合法性负举证责任** |
| 起诉期限 | 诉讼时效 3 年 | 一般 **6 个月**（知道或应当知道起） |
| 调解 | 可以调解（离婚等除外情形有限） | **行政赔偿/补偿及自由裁量权案件可调解**，一般不调解 |
| 复议关系 | 无 | 复议前置（部分）/ 复议与诉讼二选一 |

## 🧠 记忆工具箱

### 口诀速记

- 审限：**"简三普六，二审三月，执行两年"**；
- 管辖：**"原就被告，合同履行，侵权两地，不动产专属"**；
- 行政诉讼灵魂：**"民告官，官举证"**。

### 场景锚点

- 环境污染倒置想象"**你排污我受伤**"：你（原告）只要证明"他排了 + 我伤了"，**证明"没因果关系"的活儿归排污企业**——因为他掌握排放数据。

## ⚠️ 易错提醒

- 行政诉讼**举证责任在被告**是最大考点：原告不需要证明行政行为违法，被告要证明**证据确凿、适用法律正确、程序合法**；
- 简易程序**只能由基层法院**适用，且标的额、案情要简单——不是所有基层案件都走简易；
- 诉前保全后 **30 日**内必须起诉，否则解除——数字别与"先予执行"混淆；
- 合同"履行地"有约定按约定，**没有约定按争议标的**（给付货币的接收方所在地、交付不动产的所在地、其他标的履行义务一方所在地）——规则细，真题爱挖坑。
