## 考点梳理

### 3.1 行政行为（先定性，再判断可诉性）

| 类型 | 内容 | 典型例子 |
|------|------|---------|
| **具体行政行为** | 针对**特定对象 + 特定事项** | 对某公司罚款 10 万 |
| **抽象行政行为** | 针对**不特定对象**（规章/规范性文件） | 某市发布《管理办法》 |
| **内部行政行为** | 机关内部（人事/考核） | 公务员处分 |
| **国家行为** | 国防/外交 | 不受理 |

> **可诉性记忆**：**"具体可诉，抽象不可诉（但可附带审查规范性文件）；内部、国家行为不可诉"**。

### 3.2 行政处罚（数字 + 程序）

| 事项 | 规则（示例口径，以《行政处罚法》为准） |
|------|--------------------------------------|
| **种类** | 警告、罚款、没收、责令停产停业、暂扣/吊销许可证、行政拘留等 |
| **简易程序** | 对公民 **≤200 元**、对法人 **≤3000 元**罚款或警告（当场作出） |
| **听证范围** | 较大数额罚款、没收较大数额、降低资质等级、吊销许可证、责令停产停业等 |
| **程序** | 告知（事实/理由/陈述申辩权）→ 听取意见 → 决定 → 送达 |
| **执行** | **罚缴分离**（2 日内到指定银行缴纳）；**逾期不加处罚款每日按罚款数额 3% 加处**（以法律为准） |

> **记忆锚**：**"先告知后决定，陈述申辩不能省；罚缴分离，听证是大事"**。

### 3.3 行政复议（"60 日"）

| 事项 | 规则 |
|------|------|
| **申请期限** | 自知道行政行为之日起 **60 日**内（法律另有规定除外） |
| **复议机关** | 一般为**上一级主管部门**或**本级政府**（以组织法为准） |
| **复议前置** | **纳税争议**（对征税行为不服）：**先复议，后诉讼** |
| **复议期间** | 具体行政行为**不停止执行**（例外情形除外） |
| **决定期限** | 一般 **60 日内**作出复议决定（可延长 30 日） |

### 3.4 行政诉讼（"民告官"，被告举证）

| 对比项 | 行政诉讼 | 民事诉讼 |
|--------|---------|---------|
| **被告** | **行政机关（恒为被告）** | 平等主体 |
| **举证责任** | **被告对行政行为合法性负举证责任** | 谁主张谁举证 |
| **起诉期限** | 知道行为之日起 **6 个月**（不动产 20 年、其他 5 年最长） | 诉讼时效 3 年 |
| **调解** | 一般**不适用**（赔偿/补偿/裁量权案件可调解） | 可以调解 |
| **判决类型** | 驳回诉讼请求/撤销/履行/确认违法/确认无效/变更 | 给付/确认/形成 |

> **记忆锚**：**"民告官，官举证；复议 60 日，起诉 6 个月；征税先复议"**。

### 3.5 高频陷阱（选择题重灾区）

1. **行政复议 vs 行政诉讼的衔接**：一般**自由选择**（除复议前置外）；**对复议决定不服**再起诉，起诉期限 **15 日**（收到复议决定书之日）；
2. **被告确定**：经复议的案件，**复议机关决定维持**的 → **原机关 + 复议机关为共同被告**；**改变**的 → **复议机关为被告**；
3. **举证责任**：原告只需证明"起诉符合条件"，**行为合法性由被告证明**（被告不提供证据 = 视为没有证据 → 撤销）；
4. **起诉期限**：一般 **6 个月**，但**不知道行政行为内容**的，自知道或应当知道之日起算（最长 5 年/不动产 20 年）。

## 🧠 记忆工具箱

### 口诀速记

- 可诉性：**"具体可诉抽象不，内部国家不能告"**；
- 处罚程序：**"告知申辩先，听证是大事，罚缴要分离"**；
- 复议诉讼：**"复议六十日，起诉六个月，征税先复议，民告官举证"**。

### 场景锚点

- 行政诉讼想象"**"告城管"**"：你**不是城管**（**不需要证明自己对**），**你是市民**（**"告"**）——**"城管要证明它罚款合法"**（证据 + 程序 + 依据），你只需要证明"它罚了我 + 我按期告了"。

## ⚠️ 易错提醒

- **复议前置只限"征税行为"**（对纳税决定不服）——**对税务处罚不服可以直接起诉**（别扩大化）；
- **复议维持 → 共同被告**（原机关 + 复议机关）——这是 2014 年修法后的新规则，**高频考点**；
- **被告举证 = 合法性举证**：不是"原告证明违法"，而是**被告证明合法**——**举证责任倒置**是行政诉讼的灵魂；
- **行政处罚"陈述申辩权"不能放弃**：机关因当事人申辩而加重处罚 = **违法**。
