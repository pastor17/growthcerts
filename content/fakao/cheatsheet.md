> **用法**：考前 3 天起只过这一页 + 错题笔记。**客观题两卷必须同时合格**，主观题必须在客观题合格当年参加——任何一环断掉都是全年白考。

## 一、高频数字卡（以现行法条为准）

| 事项 | 数字 |
|------|------|
| 普通诉讼时效 / 最长保护期 | **3 年** / **20 年** |
| 离婚冷静期 | **30 日** |
| 保证期间未约定（一般保证） | 主债务履行期届满起 **6 个月** |
| 行政复议 / 行政诉讼（一般起诉） | **60 日** / **6 个月** |
| 公司减资：通知债权人 / 公告 | **10 日** / **30 日** |
| 劳动仲裁申请时效 | **1 年**；**拖欠劳动报酬在劳动关系存续期间不受 1 年限制** |
| 女职工四期保护 | 经期/孕期/产期/哺乳期：**不得降低工资、辞退或解除合同** |

## 二、程序要点速记

- **刑诉**：立案 → 侦查（拘留 24h 内讯问、逮捕需检察院批准）→ 审查起诉 → 审判（一审 2 个月，可延长）→ 执行；
- **民诉**：起诉（符合条件）→ 立案 7 日 → 审限（普通程序 6 个月 / 简易程序 3 个月）→ 二审 3 个月 → 执行（申请时效 2 年）；
- **行政诉讼**：对行政处罚等不服 → 复议（60 日）或直接起诉（6 个月）→ **举证责任在被告（行政机关）**；
- **劳动争议**：协商 → **仲裁前置（1 年）** → 起诉。

## 三、主观题答题结构（每题通用模板）

```text
① 结论先行：甲的行为构成 X（或不构成 / 应当承担 X 责任）
② 要件逐项：（1）主体…（2）主观…（3）客体…（4）客观…
③ 结合案情：本案中……符合/不符合第 X 要件，因为……
④ 法条精神：依据民法典/刑法相关规定（不要求精确条号）
```

## 四、机考注意事项

- 客观题可**标记 + 回头检查**，不定项拿不准就少选（漏选得分、错选 0 分）；
- 主观题**输入效率**决定上限：考前至少 3 次完整机考模拟（汉字输入 + 法条检索习惯）；
- 两卷/单卷时间分配：**先做有把握的科目**，避免在单题上耗死；
- 进场提前 30 分钟：身份证、准考证、考场机考规则（是否允许草稿纸以准考证为准）。
