## 是什么

**法考（国家统一法律职业资格考试）** 是原"司法考试"的升级版（2018 年起更名），由**司法部**组织，是从事**法官、检察官、律师、公证员**以及**行政机关法律职位、仲裁员、企业法务核心岗位**的准入类资格考试。通过客观题与主观题两阶段考试后，由司法部颁发**法律职业资格证书**。

## 证书分级（示例口径）

| 证书 | 取得情形 | 执业范围 |
|------|---------|---------|
| **A 证** | 全国合格线 + 学历专业均满足新办法 | 全国执业 |
| **B 证** | 放宽地区合格线（原司法考试过渡政策） | 放宽地区执业 |
| **C 证** | 放宽地区合格线 + 学历不满足新办法（"老人老办法"） | 放宽地区执业 |

> 具体分级与放宽政策以**司法部当年度公告**为准；近年政策有调整趋势，报名前务必核对最新文件。

## 考什么（两阶段）

**客观题（卷一 + 卷二，共 200 题）**：

- 卷一：法理、宪法、法制史、刑法、刑诉、行政法与行政诉讼、国际法、司法制度与法律职业伦理；
- 卷二：民法、知产、商法、经济法、环境资源法、劳动法与社保、国际私法、国际经济法、民诉；
- 形式：机考，单选 + 多选 + 不定项；**两卷均须达到合格线（一般各 180 分，示例口径）**。

**主观题**：

- 案例分析（刑法、刑诉、民法、民诉、行政法为主）+ 一道论述题（含法治思想选做）；
- 满分 180，一般 108 分合格（示例口径）；**必须在客观题合格当年 6 个月内参加**。

## 含金量与难度（职场人决策参考）

| 维度 | 说明 |
|------|------|
| **岗位用途** | 律师、公司法务、法官/检察官（需通过公务员考试 + 法考 A 证）、公证员、仲裁员 |
| **行业地位** | **法律职业的硬性门槛**，不是"加分项"而是"入场券" |
| **薪资参考** | 通过 A 证是律师执业的前提；企业法务岗位招聘普遍标注"法考 A 证优先/必须" |
| **职称对应** | 不属于职称序列，但通过法考可申报**法律系列专业技术职称**评审（以当地规定为准） |
| **个税与补贴** | 属国家职业资格，**可申报个税继续教育专项附加扣除（480 元/年，以税务规定为准）**；部分地区有考试补贴（以当地为准） |
| **难度评级** | ★★★★★ — 公认国内难度最高的职业考试之一：知识面横跨 8 大部门法、客观题量大、主观题要会写 |
| **建议总学时** | 零基础约 **800~1200 小时**；法本/法硕背景约 **500~800 小时** |
| **主要难点** | ① 知识点体量巨大（"得刑民者得法考"）；② 多选与不定项得分率低；③ 主观题案例写作训练不足 |
| **适合谁** | 法本/法硕应届生、想转法律行业的在职人员、企业法务、想考公（法律岗）者 |
| **建议先别考的情形** | 仅因"想学点法律常识"（可先读入门读物）；学历条件不满足且不符合"老人老办法"者 |
