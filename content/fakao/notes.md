## 一、本证该记什么（三类笔记）

### ① 法条数字卡（最常考、最容易错）

| 事项 | 数字 |
|------|------|
| 诉讼时效（普通/最长） | **3 年** / **20 年** |
| 保证期间约定不明 / 连带保证 | 主债务履行期届满之日起 **6 个月** / **6 个月** |
| 离婚冷静期 | **30 日**（任意一方撤回） |
| 合同解除权除斥期间（约定不明） | **1 年** |
| 行政处罚（一般程序）听证范围 | 较大数额罚款、没收较大数额违法所得、降低资质等级、吊销许可证、责令停产停业等（以《行政处罚法》为准） |
| 刑事诉讼：逮捕后羁押审查起诉期限 | **1 个月**（可延长） |
| 行政复议期限 / 行政诉讼起诉期限 | **60 日** / **6 个月**（一般） |
| 公司减资通知债权人 / 公告 | **10 日**通知 / **30 日**公告 |

> 法条会修订（如民法典配套解释），**每轮复习前用国家法律法规数据库核对一遍数字**。

### ② 罪名与要件卡（刑法主观题核心）

每个高频罪名写一行：**构成要件 + 易混罪名 + 一个案例锚点**。

| 高频罪名 | 一行卡 |
|---------|--------|
| 盗窃 vs 诈骗 | 骗=被害人"处分"了财产；盗=趁其不知取走——**有没有"自愿交付"是分界线** |
| 正当防卫 | 起因（不法侵害正在进行）→ 对象（侵害人）→ 限度（明显超过必要）→ **特殊防卫**（针对行凶、杀人等严重危及人身安全） |
| 自首 | 自动投案 + 如实供述（**"自动"与"如实"缺一不可**）；坦白≠自首 |
| 共同犯罪 | 共同故意 + 共同行为；**教唆犯按作用处罚**；胁从犯按情节减轻/免除 |

### ③ 程序时间线（刑诉/民诉/行政）

把每个程序画成**一张流程图**（立案 → 侦查/审理 → 裁判 → 执行），每个节点标注期限与救济途径。主观题问"该怎么做"时，**按流程节点答题**最不容易漏。

## 二、避坑清单（法考专属 10 条）

| # | 坑 | 正确做法 |
|---|----|---------|
| 1 | 只听课不做题，"听懂了≠会做" | 每章听完当天做 30 题，**错误率 > 40% 的章节必须二轮** |
| 2 | 多选碰运气（少选得分、多选不得分规则不熟） | 客观题多选规则：**漏选得部分分、错选 0 分**——不确定就少选 |
| 3 | 法条记旧版（刑法修正案、民法典更新） | 报名后先下载当年度**法规汇编**，与笔记逐条对 |
| 4 | 轻视理论法（法理/宪法/法制史/职业伦理） | 理论法共约 40+ 分，**性价比极高**，考前 1 个月集中背 |
| 5 | 主观题等到 10 月才练 | **客观题中期就每天 1 道案例**，写作能力练不出来 |
| 6 | 主观题只写结论不写要件 | 标准结构：**结论 → 要件逐项 → 结合案情**，缺要件=白写 |
| 7 | 不定项"求全"心态 | 不定项可能只有 1~2 个正确项，**按选项独立判断** |
| 8 | 忽视"法律职业伦理" | 题量少但好拿分，**考前 2 周背一遍** |
| 9 | 客观题没过就放弃全年 | 客观题与主观题是两场，**客观题不过=全年归零**，两阶段都要投入 |
| 10 | 轻信"押题密卷" | 法考命题稳定，**真题 > 一切押题** |

## 三、官方入口与社区检索

- 官方：司法部（moj.gov.cn）年度公告、报名系统；国家法律法规数据库（flk.npc.gov.cn）；
- 社区检索词（知乎/B站/小红书）：**"法考 客观题 经验帖""法考 刑法 体系""法考 主观题 案例 模板"**；
- 使用规范：经验帖用于**排计划**，知识点以官方教材与现行法条为准。
