> 考试大纲以**司法部当年度公告**为准；下方为科目结构整理（示例口径）。

## 客观题·卷一（满分 300）

| 科目 | 核心考点方向 | 重要度 |
|------|-------------|--------|
| 法理学 | 法的渊源、效力、法律推理、法治理论 | ★★★ |
| 宪法 | 国家机构、公民基本权利、选举制度 | ★★★★ |
| 法制史 | 历代法制演变脉络（题量小） | ★★ |
| **刑法** | 犯罪构成、具体罪名（侵犯人身/财产/破坏经济秩序）、刑罚制度 | ★★★★★ |
| **刑事诉讼法** | 管辖、证据、强制措施、审判程序、特别程序 | ★★★★★ |
| 行政法与行政诉讼法 | 行政行为、行政处罚、复议、行政诉讼受案范围与程序 | ★★★★ |
| 国际法 | 国际公法、国际经济法基础（题量较小） | ★★ |
| 司法制度和法律职业伦理 | 律师制度、审判制度、职业伦理规范 | ★★★ |

## 客观题·卷二（满分 300）

| 科目 | 核心考点方向 | 重要度 |
|------|-------------|--------|
| **民法**（含总则、物权、合同、担保、人格权、婚姻家庭继承、侵权） | 法律行为、合同效力与履行、担保物权、侵权构成 | ★★★★★ |
| 知识产权法 | 著作权、专利、商标三大法（保护客体与权利内容） | ★★★ |
| 商法 | 公司法（重点）、合伙企业、破产、票据、保险 | ★★★★ |
| 经济法 | 反垄断、反不正当竞争、消费者权益、财税、金融监管 | ★★★ |
| 环境资源法 | 环境保护、土地与规划（题量较小） | ★★ |
| 劳动与社会保障法 | 劳动合同、工伤、社保 | ★★★ |
| 国际私法 / 国际经济法 | 冲突规范、WTO、国际商事仲裁 | ★★ |
| **民事诉讼法** | 管辖、证据、保全、审判程序、执行 | ★★★★ |

## 主观题（满分 180）

- **案例分析**：刑法/刑诉/民法/民诉/行政法各 1 道为主（每年有调整，示例口径）；
- **论述题**：1 道（含中国特色社会主义法治理论/法治思想选做模块）；
- 答题要点：**结论先行 → 构成要件逐项分析 → 引用条文精神（不要求精确条号）**。

## 备考路线

```text
① 框架轮：刑法 → 民法（两科各 6~8 周，听精讲课 + 章末题）
   ↓
② 部门法轮：刑诉 → 民诉 → 行政法 → 商经知 → 理论法（法理/宪法/法制史/职业伦理）
   ↓
③ 刷题轮：近 5 年真题按卷套卷做 → 错因分类复盘
   ↓
④ 主观题并行：第 3 个月起每天 1 道案例（刑民优先）→ 考前 2 周论述模板 + 热点背诵
```

> 📖 本站精讲为原创整理，**法规条文与解释请以现行有效文本为准**（刑法修正案、民法典配套司法解释更新频繁）。
