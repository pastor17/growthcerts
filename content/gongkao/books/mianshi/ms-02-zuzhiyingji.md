## 考点梳理

### 2.1 组织计划类（**"事前—事中—事后"**）

**通用框架**（**"3 段 9 点"**）：

```text
事前（为什么/准备什么）：
  ① 明确目的与意义（扣题：为什么做这件事）
  ② 确定对象/范围/时间/地点/形式
  ③ 组建团队、分工、预算、物资、报批
事中（怎么组织）：
  ④ 分阶段推进（按环节展开，体现"有序"）
  ⑤ 关键节点把控（预案、协调、突发应对）
  ⑥ 宣传动员（扩大参与/效果）
事后（成果/长效）：
  ⑦ 总结成果、形成材料
  ⑧ 评估反馈、改进
  ⑨ 长效机制（制度化/常态化）
```

**分题型侧重**：

| 题型 | 加分点 |
|------|--------|
| **调研类** | **对象有代表性**（分层抽样）、**方法多样**（问卷+访谈+实地）、**数据可信**（交叉验证）、**结论可落地**（建议针对问题） |
| **宣传类** | **渠道分层**（线上+线下）、**内容贴近受众**（不是自说自话）、**效果可量化**（覆盖/参与/转化） |
| **活动类** | **安全预案**（场地/消防/医疗）、**流程细节**（时间轴）、**应急兜底** |

### 2.2 应急应变类（**"先人后事，先稳后控"**）

**处置 6 步**（**"6 步"**）：

```text
① 控制局面/稳定情绪（先安抚当事人/群众）
② 了解情况（问清时间/地点/经过/损失）
③ 启动预案/上报（按程序报告，**不擅自决定重大事项**）
④ 分类处置（按轻重缓急，先救人/止损）
⑤ 协调资源（联动相关部门/单位）
⑥ 善后总结（补偿/安抚 + 复盘防再发）
```

**三类高频场景原则**：

| 场景 | 核心原则 | 禁忌 |
|------|---------|------|
| **突发事故**（火灾/伤人） | **先救人，再保物**；第一时间上报 + 疏散 | 擅自隐瞒/拖延上报 |
| **群众投诉/信访** | **换位共情**，先听后答；**记录→回应→跟踪** | 推诿/态度生硬/"按规定办"了事 |
| **舆情** | **快报事实，慎报原因**；统一口径，持续回应 | 删帖/删评/对抗/沉默 |

> **铁律**：**"应急先稳情绪再解决事；上报是程序，不是甩锅"**。

### 2.3 人际关系类（**"对事不对人，对己不对他"**）

**答题 3 原则**：

| 原则 | 含义 |
|------|------|
| **先反思自己** | "我先检讨我的工作/沟通方式"（**不指责对方**） |
| **换位理解** | "站在领导/同事角度，他的考虑是…" |
| **主动沟通** | "找合适时机当面沟通，澄清误会 + 改进" |

**禁忌**：**"把对方妖魔化""甩锅""冷处理""背后议论"**。

## 📝 深度精讲（3 道带解析模拟题）

### 题 1（组织·调研）
"单位要调研辖区独居老人的居家养老需求，你怎么组织？"

**答题要点**：
1. **目的**：摸清需求，为制定养老服务提供依据（**扣题**）。
2. **对象**：分层——按年龄（80+/70-79）、身体（自理/半失能/失能）、居住（社区/农村）抽样，**确保代表性**；结合居委会摸底名单。
3. **方法**：**问卷**（标准化，覆盖广）+ **入户访谈**（深挖，失能老人由子女/护理员补充）+ **实地观察**（适老化设施现状）；**多方法交叉验证**。
4. **推进**：先培训调研员（统一口径/话术）→ 居委会协助入户 → 数据清洗录入 → 交叉核对。
5. **成果**：分维度统计（医疗/护理/助餐/精神慰藉需求占比）→ **形成"需求清单 + 优先排序"建议**（可落地，不是空话）。
6. **长效**：建立需求动态更新机制（年度复测）。

> **解析**：高分点 = **对象分层有代表性** + **多方法交叉** + **结论可落地**（"需求清单+优先级"）。避免"发个问卷收回来就完"。

### 题 2（应急·群众投诉）
"一位群众到窗口反映'跑了三次没办成'，情绪激动，你怎么办？"

**答题要点**：
1. **稳情绪**：请入座、递水，**先共情**"让您三跑确实是我们没办好，我先帮您把这事理清楚"（**不辩解**）。
2. **了解**：问清每次办的进展、卡在哪、材料清单；**当场查系统/调记录**（让他看到你在查，不是敷衍）。
3. **处置**：
   - 若是**我们材料退回标准不清** → 道歉 + **一次性告知**全部所需材料（**"最多跑一次"**）；
   - 若确实**符合一次办结条件** → **当场帮办/代跑**内部流程；
   - 若**确实材料缺失** → 给**书面一次性告知单**，避免再跑。
4. **上报改进**：记录该案例，**复盘"为何三次"**（流程/话术/系统问题），**推动一次性告知制度**。
5. **跟踪**：办结后电话回访，确认满意。

> **解析**：高分点 = **先共情不辩解** + **当场查记录（行动>语言）** + **"最多跑一次"导向** + **事后复盘制度**。禁忌：推诿/"按规定就是这样"。

### 题 3（人际·领导批评）
"领导在会议上批评你方案有问题，但你认为方案没问题，怎么办？"

**答题要点**：
1. **先接受，不当场顶**：会议上当场听、记，**不辩解**（**维护会议秩序和领导权威**）。
2. **先反思**：会后**重新审视方案**，看是否真有问题（可能自己视角局限）；**"领导看到的可能有我看不到的"**。
3. **再沟通**：若**确实是我疏忽** → 道歉 + 修改；若**仍有不同看法** → 找**合适时机**（会后单独）带着**数据/依据**向领导汇报，**"我理解您的考虑，同时我补充两点依据…"**（**对事不对人**）。
4. **尊重决定**：若领导仍坚持 → **执行领导决定**（**"决策权在领导，执行权在我"**），执行中及时反馈。
5. **忌**：当面顶撞/背后议论/消极执行。

> **解析**：高分点 = **不当场对抗** + **先反思** + **带依据沟通** + **尊重决策**。核心是**"对事不对人，对己不对他"**。

## 🧠 记忆工具箱

### 口诀速记

- 组织：**"事前目的对象准备，事中有序预案宣传，事后总结长效"**；
- 应急：**"先稳情绪再解决，先救人后保物，上报是程序不是甩锅"**；
- 人际：**"先反思自己，换位理解对方，主动沟通改进，尊重最终决定"**。

### 场景锚点

- 组织计划想象"**"办婚礼"**"：你**不是宾客**（**不需要来吃席**），**你是"总策划"**——**"事前：确定宾客/场地/菜单/预算/流程（**不能漏项**）；事中：按时间轴推进，备好雨天预案（**有序**）；事后：发照片/收集反馈/记账（**闭环**）"**——**"公务员组织活动 = 办一场'不能出岔子的婚礼'"**。
- 应急想象"**"医院分诊台"**"：你**不是医生**（**不诊断**），**你是"分诊护士"**——**"先稳住病人情绪（**先安抚**），再问清病情轻重（**了解**），重的先送抢救（**先救人**），轻的排队（**分类**），全程按流程报给医生（**上报**）"**——**"应急的核心是'分诊'：分清轻重缓急，不慌不乱"**。

## ⚠️ 易错提醒

- **组织类"只说流程不说对象"**：**"调研必须答'调研谁、怎么保证代表'"**（**"对象代表性是高分线"**）；
- **应急类"先讲道理后安抚"**：**"先稳情绪再解决事"**（**"情绪没稳住，道理听不进去"**）；
- **舆情"删帖删评"**：**"快报事实慎报原因，持续回应"**（**"对抗/沉默 = 升级"**）；
- **人际类"当场顶领导"**：**"会议当场接受，会后带依据沟通"**（**"对事不对人"**）；
- **投诉"推诿/按规定办"**：**"当场查记录 + 一次性告知"**（**"最多跑一次"**）。
