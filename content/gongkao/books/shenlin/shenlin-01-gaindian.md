## 考点梳理

### 1.1 归纳概括（**"从材料中找答案"**）

**核心方法**：**标注材料**（**圈"关键词"**）+ **提炼要点**（**合并同类项**）+ **组织语言**（**"总 + 分"**）。

| 步骤 | 技巧 | 例子 |
|------|------|------|
| **标注材料** | **圈"关键词"**（**名词/动词/数据**） | "材料说'**基础设施薄弱**、**人才流失**、**资金短缺**'" → **圈 3 个关键词** |
| **提炼要点** | **合并同类项**（**"同义合并"**） | "基础设施薄弱" + "道路不通" → **"基础设施薄弱"**（**合并**） |
| **组织语言** | **"总 + 分"**（**总括句 + 分点 3~5 个**） | "该地区发展面临**三大问题**：**一是基础设施薄弱**……**二是人才流失**……**三是资金短缺**……" |

> **记忆锚**：**"圈 → 合 → 总 + 分"**（**3 步**，**80% 的答案在材料里**）。

### 1.2 提出对策（**"针对问题给方案"**）

**核心方法**：**"主体 + 措施"**（**谁 + 做什么**）+ **可执行**（**具体 + 落地**）。

| 主体 | 典型措施 | 例子 |
|------|---------|------|
| **政府** | **政策/资金/监管** | "**政府**应**出台政策**，**设立专项资金**，**加强监管**" |
| **企业** | **技术/管理/创新** | "**企业**应**引进技术**，**优化管理**，**推动创新**" |
| **个人** | **学习/意识/行动** | "**个人**应**加强学习**，**提高意识**，**付诸行动**" |
| **社会** | **宣传/监督/氛围** | "**社会**应**加强宣传**，**形成监督**，**营造氛围**" |

> **记忆锚**：**"主体 + 措施"**（**"政府/企业/个人/社会"** 4 个主体，**每个主体 1~2 条措施**）。

### 1.3 高频陷阱

| 陷阱 | 正确做法 |
|------|---------|
| **"背模板"**（**"假大空"**） | **"从材料中找答案"**（**标注材料** + **提炼要点** + **组织语言**） |
| **"假大空"**（**"我要高度重视、加强领导"**） | **"具体 + 可执行"**（**"设立专项资金 1000 万"**，**不是"加强资金"**） |
| **"漏要点"**（**材料说了 5 个，只写 3 个**） | **逐句对照**（**"原文没说 = 漏"**） |
| **"超字数"**（**要求 200 字，写了 300 字**） | **先列要点**（**"总 + 分"**），**再写**（**"总分" = 不超字数**） |

## 🧠 记忆工具箱

### 口诀速记

- 归纳概括：**"圈 → 合 → 总 + 分"**；
- 提出对策：**"主体 + 措施"**（**"政府/企业/个人/社会"**）；
- 高频陷阱：**"不背模板，不假大空，不漏要点，不超字数"**。

### 场景锚点

- 申论想象"**做阅读理解**"：你**不是"作者"**（**不需要"创造"**），**你是"读者"**（**"找答案"**）——**"标注材料 + 提炼要点 + 组织语言"**是**"找答案"**的**"3 步"**。

## ⚠️ 易错提醒

- **归纳概括"从材料中找答案"**：**80% 的答案在材料里**——**"背模板" = 丢分**；
- **提出对策"具体 + 可执行"**：**"设立专项资金 1000 万"**（**具体**），**不是"加强资金"**（**假大空**）；
- **"总 + 分"模板**：**总括句 + 分点 3~5 个**（**"一是……二是……三是……"**）——**"总 + 分" = 不超字数**；
- **申论"阅读 + 写作"**：**不是"背模板"**，而是**"从材料中找答案"**。
