## 考点梳理

### 1.1 五大公式（必背）

| 公式 | 表达式 | 典型场景 |
|------|--------|---------|
| **增长量** | 现期 − 基期 | "2024 年比 2023 年增长了多少" |
| **增长率** | 增长量 / 基期 | "2024 年比 2023 年增长了百分之几" |
| **比重** | 部分 / 整体 | "A 占 B 的百分之几" |
| **平均数** | 总量 / 份数 | "人均收入 = 总收入 / 总人口" |
| **倍数** | A / B | "A 是 B 的几倍" |

> **记忆锚**：**"增是减，长是除，比重平均倍数都是除"**——**"减"与"除"**是核心。

### 1.2 三大速算技巧（**"不是算，是估"**）

| 技巧 | 适用场景 | 例子 |
|------|---------|------|
| **首位法** | 增长率/比重（**选项差距大**） | 1234 / 5678 ≈ 1.2 / 5.7 ≈ **0.21**（只算前 1~2 位） |
| **截位法** | 比重/平均数（**保留 2 位小数**） | 1234.56 / 5678.90 ≈ 1234 / 5679 ≈ **0.217**（截位到 4 位） |
| **放缩法** | 增长率（**选项差距小**） | 1234 / 5678 > 1200 / 6000 = **0.2**（**放大分母 → 缩小结果**） |

> **记忆锚**：**"选项差距大 → 首位法；选项差距小 → 放缩法"**——**速算的核心是"估"，不是"算"**。

### 1.3 查找技巧（**"读题 > 计算"**）

- **先看"问什么"**（增长量/增长率/比重/平均数/倍数）；
- **再找"数据在哪"**（表格/柱状图/折线图/文字）；
- **最后"套公式"**（**不是"先算再找"**）；
- **记忆锚**：**"问 → 找 → 算"**（**3 步**，**不是"算 → 找 → 问"**）。

### 1.4 高频陷阱

| 陷阱 | 正确做法 |
|------|---------|
| **"增长量" vs "增长率"** | **增长量 = 现期 − 基期**（**绝对值**）；**增长率 = 增长量 / 基期**（**百分比**）——**"增长量"是"多少"，"增长率"是"百分之几"** |
| **"比重" vs "增长率"** | **比重 = 部分 / 整体**（**同一时点**）；**增长率 = 增长量 / 基期**（**两个时点**）——**"比重"是"占比"，"增长率"是"增速"** |
| **"基期"搞错** | **基期 = 现期 / (1 + 增长率)**——**"基期"是"过去的"**，**不是"现在的"** |
| **"倍数" vs "增长倍数"** | **A 是 B 的几倍 = A / B**；**A 比 B 增长了几倍 = (A − B) / B**——**"是几倍"与"增长几倍"差 1** |

## 🧠 记忆工具箱

### 口诀速记

- 五大公式：**"增是减，长是除，比重平均倍数都是除"**；
- 三大速算：**"差距大首位，差距小放缩，截位保两位"**；
- 查找三步：**"问 → 找 → 算"**；
- 高频陷阱：**"量是绝对长是比，比重同点增长跨点，基期过去现在比，倍数差一别搞混"**。

### 场景锚点

- 资料分析想象"**看财报**"：你**不是会计**（**不需要"精确算"**），**你是投资者**（**"估个大概"就行**）——**速算的核心是"估"**，**不是"算"**（**选项差距大 → 首位法，差距小 → 放缩法**）。

## ⚠️ 易错提醒

- **"增长量"是"绝对值"**（**多少亿**），**"增长率"是"百分比"**（**百分之几**）——**问"增长了多少" = 增长量，问"增长了百分之几" = 增长率**；
- **"基期"是"过去的"**（**2023 年**），**不是"现在的"**（**2024 年**）——**基期 = 现期 / (1 + 增长率)**；
- **"A 是 B 的几倍" = A / B**；**"A 比 B 增长了几倍" = (A − B) / B**——**差 1**（**"是 3 倍" = "增长了 2 倍"**）；
- **资料分析 20~30 题/25 分钟**，**90%+ 正确率**——**"读题 > 计算"**（**"问 → 找 → 算"**）。
