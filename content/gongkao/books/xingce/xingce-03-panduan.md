## 考点梳理

### 3.1 图形推理（**"找规律"**）

**核心方法**：**数"点/线/面/角/部分"** + **"对称/旋转/翻转"**。

| 规律类型 | 典型考点 | 技巧 |
|---------|---------|------|
| **数量** | **点/线/面/角/部分**（**数个数**） | **"数不出来 = 换一类"**（**点→线→面→角→部分**） |
| **位置** | **平移/旋转/翻转**（**位置变化**） | **"方向 + 步长"**（**上/下/左/右，1 格/2 格**） |
| **样式** | **叠加/去同存异/去异存同**（**样式变化**） | **"两图 → 一图"**（**"同"与"异"**） |
| **属性** | **对称/封闭/曲直**（**属性变化**） | **"轴对称/中心对称/封闭/开放"** |

> **记忆锚**：**"数量 → 位置 → 样式 → 属性"**（**4 类**，**数不出来 = 换一类**）。

### 3.2 定义判断（**"关键词对应"**）

**核心方法**：**从定义中找"关键词"**（**主体/行为/结果**）+ **逐一对应** + **排除法**。

| 题型 | 技巧 | 例子 |
|------|------|------|
| **主体** | **谁做的**（**"企业/政府/个人"**） | "定义说'企业'，**选项说'政府'** → **错**" |
| **行为** | **做什么**（**"投资/消费/生产"**） | "定义说'投资'，**选项说'消费'** → **错**" |
| **结果** | **什么结果**（**"盈利/亏损/破产"**） | "定义说'盈利'，**选项说'亏损'** → **错**" |

> **记忆锚**：**"主体 + 行为 + 结果"**（**3 个关键词**，**逐一对应**）。

### 3.3 类比推理（**"造句法"**）

**核心方法**：**造句**（**"A 是 B 的……"**）+ **找"词间关系"**（**并列/包含/因果/功能**）。

| 关系类型 | 典型考点 | 例子 |
|---------|---------|------|
| **并列** | **A 和 B 是同类**（**"苹果 : 水果"**） | "苹果 : 香蕉"（**并列**，**都是水果**） |
| **包含** | **A 是 B 的一种**（**"苹果 : 水果"**） | "苹果 : 水果"（**包含**，**苹果是水果**） |
| **因果** | **A 导致 B**（**"下雨 : 地湿"**） | "下雨 : 地湿"（**因果**，**下雨导致地湿**） |
| **功能** | **A 的功能是 B**（**"钥匙 : 开门"**） | "钥匙 : 锁"（**功能**，**钥匙用于开门**） |

> **记忆锚**：**"造句法"**（**"A 是 B 的……"**）——**"苹果是水果"（包含）**，**"苹果和香蕉"（并列）**。

### 3.4 逻辑判断（**"翻译 + 逆否"**）

**核心方法**：**翻译**（**"如果……那么……" → A→B**）+ **逆否**（**A→B = ¬B→¬A**）。

| 题型 | 技巧 | 例子 |
|------|------|------|
| **充分/必要** | **"如果 A 那么 B" → A 是 B 的充分条件**（**A→B**） | "如果下雨，**那么**地湿" → **下雨→地湿**（**下雨是充分条件**） |
| **逆否** | **A→B = ¬B→¬A**（**逆否等价**） | "下雨→地湿" = **"地不湿→没下雨"**（**逆否**） |
| **真假推理** | **"所有 A 都是 B" ↔ "有的 B 是 A"**（**换位**） | "所有苹果都是水果" ↔ **"有的水果是苹果"**（**换位**） |
| **矛盾** | **"所有 A 都是 B" ↔ "有的 A 不是 B"**（**矛盾**） | "所有苹果都是红的" ↔ **"有的苹果不是红的"**（**矛盾**） |

> **记忆锚**：**"A→B = ¬B→¬A"**（**逆否等价**）——**"如果 A 那么 B" = "如果不 B 那么不 A"**。

## 🧠 记忆工具箱

### 口诀速记

- 图形推理：**"数量位置样式属性，数不出来换一类"**；
- 定义判断：**"主体行为结果三，逐一对应排除法"**；
- 类比推理：**"造句法，A 是 B 的……"**；
- 逻辑判断：**"A→B = ¬B→¬A"**（**逆否等价**）。

### 场景锚点

- 判断推理想象"**找规律**"：你**不是"创造者"**（**不需要"发明"**），**你是"侦探"**（**"找线索"**）——**"数量/位置/样式/属性"**是**"线索"**，**"造句/翻译"**是**"推理"**。

## ⚠️ 易错提醒

- **图形推理"数不出来 = 换一类"**：**点→线→面→角→部分**（**5 类**，**逐一试**）；
- **定义判断"逐一对应"**：**主体/行为/结果**（**3 个关键词**，**缺一个 = 错**）；
- **逻辑判断"逆否等价"**：**A→B = ¬B→¬A**（**"如果下雨那么地湿" = "如果地不湿那么没下雨"**）——**"否前"推不出"否后"**（**"没下雨"推不出"地不湿"**，**可能"洒水车"**）；
- **判断 40 题/35 分钟**，**必须拿 70%+**（**刷题 1000+ 题后"手感"出来**）。
