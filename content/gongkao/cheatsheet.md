> **用法**：考前 3 天起只过这一页 + 错题笔记。**行测 135 题/120 分钟，时间不够是常态**——**策略性放弃**比"死磕"更重要。

## 一、行测速算卡（资料分析"性价比最高"）

| 公式 | 速算技巧 |
|------|---------|
| **增长量** = 现期 − 基期 | **直接减** |
| **增长率** = 增长量 / 基期 | **首位法**（只算前 1~2 位） |
| **比重** = 部分 / 整体 | **直接除**（**保留 2 位小数**） |
| **平均数** = 总量 / 份数 | **直接除** |
| **倍数** = A / B | **直接除** |

> **资料分析 20~30 题/25 分钟，必须拿 90%+**（**速算 + 查找**，**不是"算"**）。

## 二、申论模板卡（"从材料中找答案"）

| 题型 | 模板 |
|------|------|
| **归纳概括** | **"总 + 分"**（总括句 + 分点 3~5 个） |
| **提出对策** | **"主体 + 措施"**（谁 + 做什么，3~5 个主体） |
| **公文（通知）** | **标题**（关于……的通知）+ **主送**（各单位）+ **正文**（缘由 + 事项 + 要求）+ **落款**（单位 + 日期） |
| **公文（报告）** | **标题**（关于……的报告）+ **主送**（上级）+ **正文**（缘由 + 事项 + 结语）+ **落款** |
| **大作文** | **立意**（标题 + 总论点）+ **结构**（分论点 3~4 个）+ **论证**（事例 + 数据 + 理论） |

> **申论 = "阅读 + 写作"**：**不是"背模板"**，而是**从材料中找答案**（**80% 的答案在材料里**）。

## 三、面试框架卡（"说人话"）

| 题型 | 框架 |
|------|------|
| **综合分析** | **"是什么 → 为什么 → 怎么办"**（**3 段**） |
| **计划组织** | **"事前 → 事中 → 事后"**（**3 段**） |
| **应急应变** | **"控制局面 → 解决问题 → 总结反思"**（**3 段**） |
| **人际沟通** | **"理解 → 沟通 → 解决"**（**3 段**） |
| **情景模拟** | **"共情 → 解释 → 引导"**（**3 段**） |

> **面试 = "说人话"**：**不要"假大空"**，**用"具体 + 可执行"的表述**（**"我会先……再……最后……"**）。

## 四、体检自查清单（**"不合格 = 白考"**）

| 项目 | 标准（《公务员录用体检通用标准》） |
|------|-----------------------------------|
| **视力** | 裸眼视力 **≥ 4.8**（部分岗位放宽，如公安 **≥ 4.8**，法检 **≥ 4.8**） |
| **血压** | **≤ 140/90 mmHg**（**高血压 = 不合格**） |
| **肝功** | **ALT ≤ 40 U/L**（**转氨酶偏高 = 复检**） |
| **心电图** | 正常心电图（**心律失常 = 复检**） |
| **胸片** | 无肺部病变（**肺结核 = 不合格**） |

> **提前 1 个月自查**：**视力/血压/肝功**——**不合格 = 白考**（**复检机会仅 1 次**）。
