> 本节按国家公务员局与各省公告整理；**当次报名与考试安排以官方公告为准**。

## 国考时间线（示例口径）

| 环节 | 大致时间 |
|------|---------|
| **职位表发布** | 每年 **10 月中旬**（国家公务员局官网） |
| **报名** | **10 月中旬 ~ 10 月底**（国家公务员局报名系统 bm.scs.gov.cn） |
| **缴费** | 报名后 **3~5 天**（网上缴费，**不缴费 = 未报名**） |
| **准考证打印** | 考前 **1 周**（国家公务员局官网） |
| **笔试** | **11 月底/12 月初**（周六日，行测上午 9:00~11:00、申论下午 14:00~16:30） |
| **成绩公布** | 考后 **1 个月**（国家公务员局官网） |
| **面试** | **12 月 ~ 次年 1 月**（各地/各单位单独通知，**结构化面试**） |
| **体检考察** | **次年 1~3 月**（体检 + 调档 + 座谈） |
| **录用公示** | **次年 3~4 月**（国家公务员局官网公示 7 天） |
| **入职** | **次年 7 月**（新录用公务员报到） |

## 省考时间线（示例口径，各省不同）

| 环节 | 大致时间 |
|------|---------|
| **职位表发布** | 每年 **1~2 月**（各省人事考试网） |
| **报名** | **1~3 月**（多数省份参加"多省联考"，**统一笔试**） |
| **笔试** | **3 月**（联考省份：行测 + 申论，部分省份加"综合应用能力"） |
| **成绩公布** | 考后 **1 个月** |
| **面试** | **4~5 月**（结构化/无领导小组，**各省/市单独组织**） |
| **体检考察** | **5~6 月** |
| **录用公示** | **6~7 月** |
| **入职** | **7~8 月** |

> **注意**：**国考与省考可同年考**（国考 12 月笔试、省考 3 月笔试），**不冲突**——**多数人选"国考 + 省考"双保险**。

## 报名流程（示意）

1. **下载职位表**（Excel）：按**专业/学位/户籍/基层经验/政治面貌**筛选可报岗位；
2. **选岗**（**核心**）：选"限多不限少"的岗位（竞争比低）；
3. **注册报名**：填写个人信息（学历/学位/工作经历/政治面貌）；
4. **资格初审**：单位审核（**1~2 个工作日**），**初审通过 = 可缴费**；
5. **缴费**：100~150 元（各省不同）；
6. **打印准考证**：考前 1 周；
7. **笔试**：带**身份证 + 准考证**（**两证缺一不可**）；
8. **面试**：笔试后 **1 个月**（单位通知，**带身份证 + 准考证 + 学历证**）。

## 合格标准与递补

- **笔试合格线**：国考**中央/东部 105 分（行测 + 申论）**、西部 95 分（示例口径，以公告为准）；**面试合格线 60 分**；
- **综合成绩**：笔试 50% + 面试 50%（部分岗位笔试 60% + 面试 40%）；
- **递补**：录用公示前**体检/考察不合格** → **按综合成绩递补**（同岗位下一名）；
- **放弃**：录用后**放弃 = 取消 + 记入诚信档案**（**1~3 年内不得再考**，以公告为准）。

## 体检与考察（"灵魂"环节）

- **体检**：《公务员录用体检通用标准（试行）》——**视力/血压/肝功/心电图/胸片**等（**部分岗位放宽**，如公安/法检）；
- **考察**：
  - **调档**（档案审查：学历/学位/工作经历/处分）；
  - **座谈**（找单位/学校/社区了解：政治/道德/能力/业绩）；
  - **网络核查**（征信/犯罪记录/诉讼记录）；
- **考察不合格 = 取消录用**——**"灵魂"环节**，**别忽视**。

## 备考建议

1. **行测"得资料者得行测"**：资料分析 20~30 题/25 分钟，**必须拿满**（性价比最高）；
2. **申论"从材料中找答案"**：归纳/对策题 80% 的答案在材料里，**不是背模板**；
3. **面试"说人话"**：不要"假大空"，**用"具体 + 可执行"的表述**（"我会先……再……最后……"）；
4. **体检"提前自查"**：视力/血压/肝功**提前 1 个月查一次**（**不合格 = 白考**）；
5. **考察"别留黑点"**：档案/征信/犯罪记录**提前自查**（**有黑点 = 考察不过**）。
