## 是什么

**公考（公务员考试）** 是进入**体制内**（公务员 + 事业单位）的统一考试通道。**公务员**由国考（中央）/省考（地方）组织，**事业单位**由各地单独组织（无全国统考）。通过 = 获得**编制**（公务员编制/事业编制），享受**稳定性、福利、社会地位**等"体制内待遇"。

## 国考 vs 省考（核心区别）

| 对比项 | **国考** | **省考** |
|--------|---------|---------|
| **组织方** | 国家公务员局（中央机关及直属机构） | 各省（区、市）公务员局 |
| **岗位层级** | 中央/部委/海关/税务/银保监/证监会/法检（**跨省**） | 省/市/县/乡镇（**本省**） |
| **考试时间** | 每年 **10 月报名、11 月底/12 月初笔试** | 每年 **2~3 月联考**（多数省份） |
| **竞争比** | 热门岗位 **100:1~1000:1**（如"三不限"岗） | 热门岗位 **50:1~500:1**（各地差异大） |
| **落户** | 中央单位一般**北京落户**（部分岗位） | 本省落户（部分城市有积分/人才政策） |
| **待遇** | 中央单位（**北京**）：较高 | 地方（**各地差异大**：长三角/珠三角 > 中西部） |
| **适合谁** | 想进**中央/部委/央企**、想**北京落户** | 想进**本省/本市**、想**离家近** |

> **记忆锚**：**"国考进中央（北京），省考进地方（本省）"**——**多数人选省考**（离家近、竞争相对小）。

## 考什么（三阶段）

### 笔试（行测 + 申论）

**行测（行政职业能力测验）**：

| 模块 | 题量（国考） | 核心能力 |
|------|------------|---------|
| **常识判断** | 20 题 | 政治/法律/经济/科技/历史（**广而浅**） |
| **言语理解** | 40 题 | 逻辑填空/片段阅读/语句表达（**得言语者得行测**） |
| **数量关系** | 15~20 题 | 数学运算（**难但分值低，可策略性放弃**） |
| **判断推理** | 40 题 | 图形/定义/类比/逻辑（**规律性强，可刷题突破**） |
| **资料分析** | 20~30 题 | 速算 + 查找（**性价比最高，必须拿满**） |

> **总题量 135 题 / 120 分钟**（国考）——**平均 55 秒/题**，**时间不够是常态**，必须**策略性放弃**。

**申论**：

| 题型 | 分值（国考） | 核心能力 |
|------|------------|---------|
| **归纳概括** | 10~15 分 | 从材料中**提炼要点**（踩点给分） |
| **提出对策** | 10~15 分 | 针对问题**给可执行方案** |
| **公文写作** | 15~20 分 | **通知/报告/函/讲话稿**（格式 + 内容） |
| **大作文** | 35~40 分 | **议论文**（立意 + 结构 + 论证） |

> **申论 = "阅读 + 写作"**：不是"背模板"，而是**从材料中找答案**（归纳/对策题 80% 的答案在材料里）。

### 面试（结构化 / 无领导小组）

- **结构化面试**（主流）：3~5 题/15~20 分钟，**固定题型**（综合分析/计划组织/应急应变/人际沟通/情景模拟）；
- **无领导小组讨论**（部分岗位）：6~8 人一组，**讨论 + 汇报**（考察领导/沟通/团队协作）；
- **综合成绩**：笔试 50% + 面试 50%（部分岗位笔试 60% + 面试 40%，以公告为准）。

### 体检考察

- **体检**：《公务员录用体检通用标准（试行）》——**视力/血压/肝功/心电图**等（**部分岗位放宽**，如公安）；
- **考察**：政治/道德/能力/业绩——**调档 + 座谈**（找单位/学校/社区了解），**考察不合格 = 取消录用**；
- **记忆锚**：**"体检是底线，考察是'灵魂'**"——**体检不过 = 白考，考察不过 = 白录**。

## 岗位选择策略（"上岸"率的核心）

| 策略 | 说明 |
|------|------|
| **限多不限少** | 限专业/限学位/限户籍/限党员/限基层经验 = **竞争比低**（"三不限"= 竞争最惨） |
| **选基层** | 乡镇/县级岗位**竞争比 < 省市**（且离家近） |
| **选冷门专业** | 你的专业越"冷门"（如考古/哲学），可选岗位越少但**竞争比越低** |
| **法考 A 证** | 法检/公安/司法行政岗位**限法考 A 证** = **竞争比骤降**（与 [法考](/fakao/) 衔接） |
| **应届身份** | **应届生**可报"限应届"岗位（竞争比 < 社会人员）——**应届身份是"金身"** |

> **铁律**：**"岗位选对 = 上岸率翻倍"**——考 135 题不如选对岗位（**"考得好不如报得好"**）。

## 投入评估

| 维度 | 说明 |
|------|------|
| **建议总学时** | 笔试 **300~500 小时**（行测 200~300 + 申论 100~200）；面试 **50~100 小时**（结构化 30~50 + 模拟 20~50） |
| **备考周期** | 在职 **3~6 个月**（每天 2~3 小时）；脱产 **1~3 个月**（每天 6~8 小时） |
| **主要难点** | ① 行测**时间不够**（135 题/120 分钟）；② 申论**"材料依赖"**（不是背模板）；③ 面试**"说人话"**（不要"假大空"） |
| **适合谁** | 应届生（**应届身份是金身**）、想进体制内的社会人员、想"离家近"的省考考生 |
| **建议先别考的情形** | 仅因"父母让考"（**体制内不是"躺平"**，基层压力大）；时间无法保证每周 15 小时以上 |
