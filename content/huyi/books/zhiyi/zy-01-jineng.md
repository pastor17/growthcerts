## 考点梳理

### 1.1 第 1 站：病史采集（**"问诊"**）

**病史采集 4 块**（**"每块 1 行"**）：

| 块 | 内容 | 典型问题 |
|----|------|---------|
| **现病史** | **起病/症状/演变/诊疗** | "**什么时候开始？有什么症状？做过什么检查？**" |
| **既往史** | **疾病/手术/过敏** | "**以前得过什么病？做过什么手术？过敏吗？**" |
| **个人史** | **职业/吸烟/饮酒** | "**做什么工作？吸烟吗？饮酒吗？**" |
| **家族史** | **遗传/家族疾病** | "**家人有什么病？**" |

> **记忆锚**：**"现个家"**（**"现病史 + 个人史 + 家族史"**）+ **"既往"**（**"4 块"**）。

### 1.2 第 2 站：体格检查（**"视触叩听"**）

**视触叩听顺序**（**"4 步"**）：

```text
视（**看**）→ 触（**摸**）→ 叩（**敲**）→ 听（**听诊**）
```

> **记忆锚**：**"视触叩听"**（**"4 步"**，**顺序不能乱**）。

**典型检查**（**"必考"**）：

| 部位 | 视 | 触 | 叩 | 听 |
|------|----|----|----|----|
| **心脏** | **心尖搏动** | **震颤/抬举性心尖搏动** | **心界** | **心音/杂音** |
| **肺部** | **胸廓/呼吸运动** | **语颤** | **清音/浊音/鼓音** | **呼吸音/啰音** |
| **腹部** | **外形/肠型/腹壁静脉** | **压痛/反跳痛/肝脾** | **移动性浊音** | **肠鸣音** |

> **记忆锚**：**"心/肺/腹"**（**"3 个部位"**，**"视触叩听"**）。

### 1.3 第 3 站：临床思考（**"诊断/鉴别/治疗"**）

**临床思考 3 步**（**"诊断 + 鉴别 + 治疗"**）：

```text
① 诊断（**"最可能的诊断"**）
   ↓
② 鉴别（**"需要排除的诊断"**）
   ↓
③ 治疗（**"进一步检查 + 处理"**）
```

**典型例子**（**"胸痛"**）：

- **诊断**：**急性心肌梗死**（**"胸痛 2 小时，ST 段抬高"**）；
- **鉴别**：**心绞痛**（**"胸痛 < 30 分钟，ST 段压低"**）；**主动脉夹层**（**"撕裂样胸痛，双侧血压差"**）；
- **治疗**：**心电图 + 心肌酶**（**"进一步检查"**）+ **溶栓/介入**（**"处理"**）。

> **记忆锚**：**"诊断 + 鉴别 + 治疗"**（**"3 步"**）。

### 1.4 操作规范（**"三查七对 + 无菌"**）

**操作前**（**"3 个"**）：

- **核对**（**"床号/姓名/操作"**）；
- **解释**（**"向患者解释"**）；
- **准备**（**"物品 + 体位"**）。

**操作中**（**"3 个"**）：

- **无菌**（**"无菌操作"**）；
- **核对**（**"再次核对"**）；
- **观察**（**"患者反应"**）。

**操作后**（**"3 个"**）：

- **观察**（**"术后/操作后反应"**）；
- **记录**（**"操作记录"**）；
- **告知**（**"注意事项"**）。

> **记忆锚**：**"前中后各 3 个"**（**"3 + 3 + 3 = 9"**）。

### 场景锚点

- 体格检查想象"**"看病"**"：你**不是"患者"**（**不需要"感受"**），**你是"医生"**（**"检查"**）——**"视触叩听"**是**"医生"**的**"4 步"**（**"顺序不能乱"**）。

## ⚠️ 易错提醒

- **体格检查"视触叩听"**：**"顺序不能乱"**（**"视 → 触 → 叩 → 听"**）——**"顺序乱 = 丢分"**；
- **病史采集"4 块"**：**"现病史 + 既往史 + 个人史 + 家族史"**（**"每块 1 行"**）——**"漏块 = 丢分"**；
- **临床思考"3 步"**：**"诊断 + 鉴别 + 治疗"**（**"3 步"**）——**"漏鉴别 = 丢分"**；
- **操作规范"前中后各 3 个"**：**"3 + 3 + 3 = 9"**（**"前中后"**）——**"漏步骤 = 丢分"**。
