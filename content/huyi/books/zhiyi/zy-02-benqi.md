## 考点梳理

### 2.1 A1/A2/B1 题型（**"3 种"**）

| 题型 | 含义 | 技巧 |
|------|------|------|
| **A1** | **单句型最佳选择题**（**1 个病例，1 个问题**） | **"读题 → 找关键词 → 排除"** |
| **A2** | **病例摘要型最佳选择题**（**1 个病例，1 个问题**） | **"先读题再读病例"**（**"问题是什么"**） |
| **B1** | **配伍选择题**（**2~4 个共用选项**） | **"先定选项，再配病例"** |

> **记忆锚**：**"A1 单句，A2 摘要，B1 配伍"**（**"3 种"**）。

### 2.2 A2 病例（**"读题慢 = 丢分"**）

**A2 病例"3 步"**（**"读题 → 读病例 → 排除"**）：

```text
① 读题（**"问题是什么"**）
   ↓
② 读病例（**"找关键词"**）
   ↓
③ 排除（**"排除不对的"**）
```

**典型例子**（**"胸痛"**）：

- **题目**：**"最可能的诊断是？"**；
- **病例**：**"患者男，50 岁，胸痛 2 小时，放射至左肩，ST 段抬高"**；
- **关键词**：**"胸痛 2 小时"**（**"急性"**）+ **"ST 段抬高"**（**"心肌梗死"**）；
- **答案**：**急性心肌梗死**（**"排除心绞痛"**（**"ST 段压低"**））。

> **记忆锚**：**"先读题再读病例"**（**"问题是什么"**）——**"先找问题，再找答案"**。

### 2.3 内科学（**"心/肺/肝/肾/内分泌"**）

**心内科**（**"必考"**）：

| 疾病 | 典型表现 | 关键检查 |
|------|---------|---------|
| **心绞痛** | **胸痛 < 30 分钟**，**ST 段压低** | **心电图**（**"ST 段压低"**） |
| **心肌梗死** | **胸痛 > 30 分钟**，**ST 段抬高** | **心电图 + 心肌酶**（**"ST 段抬高 + 酶升高"**） |
| **心力衰竭** | **呼吸困难 + 水肿** | **BNP/NT-proBNP**（**"升高"**） |
| **心律失常** | **心悸/晕厥** | **心电图 + Holter**（**"心率/节律"**） |

**呼吸科**（**"必考"**）：

| 疾病 | 典型表现 | 关键检查 |
|------|---------|---------|
| **COPD** | **慢咳 + 呼吸困难** | **肺功能**（**"FEV1/FVC < 70%"**） |
| **哮喘** | **喘息 + 夜间加重** | **肺功能 + 激发试验**（**"可逆性"**） |
| **肺炎** | **发热 + 咳嗽 + 脓痰** | **胸片 + 血培养**（**"阴影 + 阳性"**） |
| **肺癌** | **咳嗽 + 咯血 + 消瘦** | **胸片 + CT + 活检**（**"占位 + 恶性"**） |

**消化科**（**"必考"**）：

| 疾病 | 典型表现 | 关键检查 |
|------|---------|---------|
| **消化性溃疡** | **周期性 + 节律性腹痛** | **胃镜 + 幽门螺杆菌**（**"溃疡 + 阳性"**） |
| **肝硬化** | **腹水 + 蜘蛛痣 + 肝掌** | **B 超 + 肝功能**（**"结节 + 异常"**） |
| **胰腺炎** | **暴饮暴食 + 上腹痛** | **血淀粉酶/脂肪酶**（**"升高"**） |
| **肠梗阻** | **痛吐胀闭**（**"4 个"**） | **腹片**（**"液气平面"**） |

**泌尿科**（**"必考"**）：

| 疾病 | 典型表现 | 关键检查 |
|------|---------|---------|
| **肾炎** | **水肿 + 血尿 + 高血压** | **尿常规 + 肾功**（**"蛋白 + 异常"**） |
| **肾病综合征** | **大量蛋白尿 + 低白蛋白** | **尿蛋白 + 白蛋白**（**"> 3.5g/天 + < 30g/L"**） |
| **肾功能不全** | **少尿 + 水肿 + 氮质血症** | **肾功**（**"肌酐升高"**） |

**内分泌**（**"必考"**）：

| 疾病 | 典型表现 | 关键检查 |
|------|---------|---------|
| **糖尿病** | **"三多一少"**（**"多饮多尿多食消瘦"**） | **血糖 + 糖化**（**"升高"**） |
| **甲亢** | **心悸 + 消瘦 + 突眼** | **TSH + T3/T4**（**"TSH 低 + T3/T4 高"**） |
| **甲减** | **怕冷 + 水肿 + 便秘** | **TSH + T3/T4**（**"TSH 高 + T3/T4 低"**） |
| **肾上腺皮质功能减退** | **乏力 + 低血压 + 皮肤色素沉着** | **皮质醇 + ACTH**（**"低 + 高"**） |

> **记忆锚**：**"心肺肝肾内分泌"**（**"5 个系统"**，**"每个系统 1 张病例卡"**）。

### 2.4 读题技巧（**"先读题再读病例"**）

**"3 步"**（**"读题 → 读病例 → 排除"**）：

1. **读题**：**"问题是什么"**（**"诊断/治疗/检查"**）；
2. **读病例**：**"找关键词"**（**"年龄/性别/症状/体征/检查"**）；
3. **排除**：**"排除不对的"**（**"选项 vs 关键词"**）。

> **记忆锚**：**"先读题再读病例"**（**"问题是什么"**）——**"先找问题，再找答案"**。

## ⚠️ 易错提醒

- **A2 病例"读题慢 = 丢分"**：**"先读题再读病例"**（**"问题是什么"**）——**"先找问题，再找答案"**；
- **B1 配伍"先定选项"**：**"2~4 个共用选项"**（**"先定选项，再配病例"**）——**"顺序反 = 丢分"**；
- **内科"5 个系统"**：**"心肺肝肾内分泌"**（**"每个系统 1 张病例卡"**）——**"漏系统 = 丢分"**；
- **读题"3 步"**：**"读题 → 读病例 → 排除"**（**"3 步"**）——**"漏步骤 = 丢分"**。
