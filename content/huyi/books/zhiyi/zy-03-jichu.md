## 考点梳理

### 2.1 生理学（**"3 个系统"**）

**心血管**（**"必考"**）：

| 知识点 | 内容 | 典型考点 |
|--------|------|---------|
| **心脏泵血** | **收缩/舒张/心输出量** | **"每搏输出量 60~80ml"** |
| **血压** | **收缩压/舒张压/脉压** | **"120/80 mmHg"** |
| **心电图** | **P 波/QRS/T 波** | **"P 波 = 心房除极"** |

**呼吸**（**"必考"**）：

| 知识点 | 内容 | 典型考点 |
|--------|------|---------|
| **肺通气** | **潮气量/补吸气/补呼气** | **"潮气量 500ml"** |
| **肺换气** | **O2/CO2 分压差** | **"O2：肺泡 104 > 静脉 40"** |
| **呼吸调节** | **延髓/化学感受器** | **"CO2 是主要刺激"** |

**消化**（**"必考"**）：

| 知识点 | 内容 | 典型考点 |
|--------|------|---------|
| **胃液分泌** | **胃酸/胃蛋白酶/内因子** | **"内因子 = 维生素 B12 吸收"** |
| **肠液分泌** | **胰液/胆汁/肠液** | **"胆汁 = 脂肪乳化"** |
| **吸收** | **葡萄糖/氨基酸/脂肪** | **"葡萄糖 = 主动运输"** |

> **记忆锚**：**"心血管 + 呼吸 + 消化"**（**"3 个系统"**，**每个系统 1 张生理卡**）。

### 2.2 生物化学（**"3 块"**）

**酶**（**"必考"**）：

| 知识点 | 内容 | 典型考点 |
|--------|------|---------|
| **酶的特性** | **高效性/专一性/可调节性** | **"专一性 = 一把钥匙一把锁"** |
| **酶促反应** | **Km/Vmax** | **"Km = 底物浓度（Vmax/2）"** |
| **酶 inhibitors** | **竞争性/非竞争性** | **"竞争性 = 可逆"** |

**代谢**（**"必考"**）：

| 知识点 | 内容 | 典型考点 |
|--------|------|---------|
| **糖代谢** | **糖酵解/糖异生/糖原合成** | **"糖酵解 = 胞质"** |
| **脂代谢** | **脂肪分解/合成/酮体** | **"酮体 = 肝脏生成"** |
| **氨基酸代谢** | **脱氨基/尿素合成** | **"尿素 = 肝脏合成"** |

**核酸**（**"必考"**）：

| 知识点 | 内容 | 典型考点 |
|--------|------|---------|
| **DNA 结构** | **双螺旋/碱基配对** | **"A=T，G≡C"** |
| **DNA 复制** | **半保留/引物** | **"DNA 聚合酶"** |
| **基因表达** | **转录/翻译** | **"mRNA = 信使"** |

> **记忆锚**：**"酶 + 代谢 + 核酸"**（**"3 块"**，**每块 1 张生化卡**）。

### 2.3 药理学（**"3 类"**）

**抗生素**（**"必考"**）：

| 类别 | 代表药 | 典型考点 |
|------|--------|---------|
| **β-内酰胺** | **青霉素/头孢** | **"青霉素 = 过敏性休克"** |
| **氨基糖苷** | **链霉素/庆大霉素** | **"耳毒性/肾毒性"** |
| **喹诺酮** | **诺氟沙星/左氧氟沙星** | **"18 岁以下禁用"** |

**心血管**（**"必考"**）：

| 类别 | 代表药 | 典型考点 |
|------|--------|---------|
| **强心苷** | **地高辛** | **"治疗窗窄/洋地黄中毒"** |
| **降压药** | **ACEI/ARB/CCB** | **"ACEI = 干咳"** |
| **调脂药** | **他汀类** | **"他汀 = 肌病"** |

**中枢**（**"必考"**）：

| 类别 | 代表药 | 典型考点 |
|------|--------|---------|
| **镇静催眠** | **苯二氮䓬类** | **"地西泮 = 呼吸抑制"** |
| **抗精神病** | **氯丙嗪** | **"氯丙嗪 = 锥体外系"** |
| **抗抑郁** | **SSRI** | **"氟西汀 = 5-HT 再摄取抑制"** |

> **记忆锚**：**"抗生素 + 心血管 + 中枢"**（**"3 类"**，**每类 1 张药理卡**）。

### 2.4 病理学（**"3 块"**）

**炎症**（**"必考"**）：

| 知识点 | 内容 | 典型考点 |
|--------|------|---------|
| **炎症介质** | **组胺/缓激肽/前列腺素** | **"组胺 = 血管扩张"** |
| **炎症类型** | **浆液性/纤维素性/化脓性** | **"化脓性 = 中性粒细胞"** |
| **炎症结局** | **痊愈/迁延/蔓延** | **"痊愈 = 再生修复"** |

**肿瘤**（**"必考"**）：

| 知识点 | 内容 | 典型考点 |
|--------|------|---------|
| **肿瘤命名** | **癌/肉/母细胞瘤** | **"癌 = 上皮，肉 = 间叶"** |
| **肿瘤分级** | **G1/G2/G3** | **"G3 = 高度恶性"** |
| **肿瘤分期** | **TNM** | **"T = 原发，N = 淋巴结，M = 转移"** |

**心血管**（**"必考"**）：

| 知识点 | 内容 | 典型考点 |
|--------|------|---------|
| **动脉粥样硬化** | **脂质沉积/纤维帽** | **"胆固醇 = 黄色条纹"** |
| **高血压** | **细动脉玻璃样变** | **"肾 = 良性小动脉肾硬化"** |
| **心瓣膜病** | **二尖瓣狭窄/关闭不全** | **"二尖瓣 = 风湿热"** |

> **记忆锚**：**"炎症 + 肿瘤 + 心血管"**（**"3 块"**，**每块 1 张病理卡**）。

## 🧠 记忆工具箱

### 口诀速记

- 生理：**"心血管 + 呼吸 + 消化"**（**"3 个系统"**）；
- 生化：**"酶 + 代谢 + 核酸"**（**"3 块"**）；
- 药理：**"抗生素 + 心血管 + 中枢"**（**"3 类"**）；
- 病理：**"炎症 + 肿瘤 + 心血管"**（**"3 块"**）。

### 场景锚点

- 基础医学想象"**"地基"**"：你**不是"盖楼者"**（**不需要"盖楼"**），**你是"地基"**（**"支撑"**）——**"生理 + 生化 + 药理 + 病理"**是**"临床"**的**"地基"**（**"地基不牢，地动山摇"**）。

## ⚠️ 易错提醒

- **生理"3 个系统"**：**"心血管 + 呼吸 + 消化"**（**每个系统 1 张生理卡**，**"必考"**）；
- **生化"Km"**：**"Km = 底物浓度（Vmax/2）"**（**"必背"**）——**"Km 越小，酶与底物亲和力越强"**；
- **药理"18 岁以下禁用"**：**"喹诺酮类"**（**"诺氟沙星/左氧氟沙星"**）——**"影响软骨发育"**；
- **病理"TNM"**：**"T = 原发，N = 淋巴结，M = 转移"**（**"必背"**）——**"M1 = 远处转移"**。
