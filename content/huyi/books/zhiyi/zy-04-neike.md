## 考点梳理

### 4.1 心内科（**"胸痛鉴别"是核心**）

**心绞痛 vs 心肌梗死**（**最高频鉴别**）：

| 鉴别点 | 心绞痛 | 急性心肌梗死 |
|--------|--------|-------------|
| **诱因** | 劳累/情绪 | 常无明显诱因 |
| **部位** | 胸骨后/心前区 | 同左（可更广泛） |
| **持续时间** | **< 15~30 分钟** | **> 30 分钟**，含服硝酸甘油**无效** |
| **心电图** | 一过性 ST 段压低 | **ST 段抬高**（STEMI）/压低（NSTEMI） |
| **心肌酶** | 正常 | **CK-MB/肌钙蛋白升高** |
| **治疗** | 休息 + 硝酸甘油 | **双抗（阿司匹林 + 氯吡格雷）+ 再灌注（PCI/溶栓）** |

> **记忆锚**：**"含服硝酸甘油缓解 = 心绞痛；不缓解 + ST 抬高 + 酶升高 = 心梗"**。

**心力衰竭**（左心衰 vs 右心衰）：

| 类型 | 核心表现 | 体征 |
|------|---------|------|
| **左心衰** | **呼吸困难**（劳力性 → 端坐呼吸 → 夜间阵发）、咳嗽粉红色泡沫痰 | 肺底湿啰音、S3 奔马律 |
| **右心衰** | **体循环淤血**：颈静脉怒张、肝大、下肢水肿 | 肝颈静脉回流征（+） |

> **治疗**：半卧位 + 吸氧 + **强心（西地兰）+ 利尿（呋塞米）+ 扩血管**。

### 4.2 呼吸科（**"喘息鉴别"是核心**）

**COPD vs 支气管哮喘**（**高频鉴别**）：

| 鉴别点 | COPD | 支气管哮喘 |
|--------|------|-----------|
| **好发** | 中老年、**长期吸烟** | 中青年、**过敏史/家族史** |
| **起病** | 缓慢、进行性 | 突发、**反复发作** |
| **特点** | 慢咳 + 进行性呼吸困难（**气流受限不完全可逆**） | 喘息 + **夜间/凌晨加重**（**气流受限完全可逆**） |
| **检查** | 肺功能：**FEV1/FVC < 70%**（支气管舒张试验阴性） | 舒张试验：**FEV1 改善 > 12% 且 > 200ml** |
| **治疗** | 支气管扩张剂（LAMA/LABA）+ 吸入激素（中重度） | **控制：ICS + LABA**；**缓解：沙丁胺醇（SABA）雾化** |

> **记忆锚**：**"吸烟 + 进行性 + 不完全可逆 = COPD；过敏 + 发作性 + 夜间加重 + 完全可逆 = 哮喘"**。

**肺炎**：

- **典型大叶性肺炎**（肺炎链球菌）：**高热 + 寒战 + 咳嗽 + 铁锈色痰**；
- **首选检查**：胸部 X 线（斑片状阴影）+ 血常规（WBC 升高）；
- **经验性抗感染**：青霉素类/头孢类（以药敏为准）。

### 4.3 消化科（**"腹痛定位"是核心**）

**消化性溃疡**（胃溃疡 vs 十二指肠溃疡）：

| 鉴别点 | 胃溃疡 | 十二指肠溃疡 |
|--------|--------|-------------|
| **疼痛节律** | 进食 → 痛 → 缓解（**餐后痛**） | 饥饿痛/夜间痛 → 进食缓解（**空腹痛**） |
| **好发年龄** | 中老年 | 青壮年 |
| **首选检查** | **胃镜 + 活检（金标准）** | 同左 |
| **并发症** | 出血/穿孔/幽门梗阻/癌变 | 出血/穿孔/幽门梗阻（**不癌变**） |
| **治疗** | **PPI（奥美拉唑）+ 根除 Hp（四联 14 天）** | 同左 |

**急性胰腺炎**：

- **诱因**：**暴饮暴食 / 胆道疾病（胆源性最常见）/ 高脂血症**；
- **表现**：**中上腹持续剧痛**（可向腰背部放射）+ 呕吐后不缓解；
- **诊断**：**血淀粉酶/脂肪酶升高**（脂肪酶特异性更高）；
- **处理**：**禁食 + 胃肠减压 + 补液 + 镇痛**（**忌吗啡**，用哌替啶）。

> **记忆锚**：**"餐后痛 = 胃溃疡，空腹痛 = 十二指肠；暴饮暴食 + 腰背放射痛 + 淀粉酶 = 胰腺炎"**。

### 4.4 内分泌（**"三多一少 + 心悸消瘦"双口诀**）

**糖尿病**（2 型为主）：

- **典型表现**：**"三多一少"**（多饮、多尿、多食、体重减少）；
- **诊断标准**（以指南为准）：**空腹血糖 ≥ 7.0 mmol/L 或 随机/OGTT 2h ≥ 11.1 mmol/L**（需两次确认或加症状）；
- **首选检查**：空腹血糖 + HbA1c（**近 2~3 个月平均水平**）；
- **治疗**：生活方式干预 + 二甲双胍（无禁忌首选）；**警惕低血糖**（心慌、手抖、出冷汗 → 立即补糖）。

**甲状腺功能亢进**（Graves 病）：

- **典型表现**：**心悸、多汗、怕热、消瘦、手抖** + **突眼** + 甲状腺肿大；
- **诊断**：**TSH 降低 + FT3/FT4 升高**（TSH 最敏感）；
- **治疗**：抗甲状腺药（**甲巯咪唑/丙硫氧嘧啶**）/ 碘-131 / 手术；
- **危象识别**：高热 + 心动过速 + 意识改变 → **立即处理**（碘剂 + 糖皮质激素 + 物理降温）。

> **记忆锚**：**"三多一少 = 糖，心悸消瘦突眼 = 甲亢；TSH 低 = 甲亢，TSH 高 = 甲减"**。

## 🧠 记忆工具箱

### 口诀速记

- 心：**"硝酸甘油缓解是心绞，不缓解 ST 抬高是心梗；左喘右肿"**；
- 肺：**"吸烟进行性 COPD，过敏发作夜哮喘"**；
- 消化：**"餐后胃溃疡，空腹十二指；暴食腰背痛胰腺炎"**；
- 内分泌：**"三多一少糖，心悸消瘦甲亢；TSH 低亢高减"**。

### 场景锚点

- 内科学病例卡想象"**"急诊分诊台"**"：你**不是病人**（**不需要感受症状**），**你是医生**（**"听症状 → 想诊断 → 开检查 → 给治疗"**）——**A2 题就是给你一段"病人主诉"，让你 30 秒内走完这条链路**。

## ⚠️ 易错提醒

- **心梗再灌注**：**PCI 优于溶栓**（有条件的医院首选），**溶栓时间窗 12 小时内**（以指南为准）；
- **哮喘急性发作**：**SABA（沙丁胺醇）是缓解首选**，ICS 是**长期控制**——两者角色不能颠倒；
- **消化性溃疡"金标准"是胃镜**，不是钡餐/呼气试验（呼气试验查 Hp）；
- **糖尿病诊断**：**单次血糖高不能确诊**（需重复确认或加典型症状）——A2 题常设"单次空腹 7.1"陷阱；
- **甲亢 TSH**：**TSH 是第一线筛查**（最敏感），不是 FT4——**"TSH 低 = 亢，TSH 高 = 减"**。
