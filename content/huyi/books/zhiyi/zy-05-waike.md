## 考点梳理

### 5.1 外科感染与休克（**"2 大急症"**）

**外科感染特点**（**"4 点"**）：

| 特点 | 内容 |
|------|------|
| **局部为主** | 红、肿、热、痛、功能障碍（**"炎症 5 征"**） |
| **混合感染多** | 常需氧 + 厌氧混合 |
| **可转为全身** | 处理不当 → 脓毒症/感染性休克 |
| **治疗 3 步** | 局部处理（切开引流）+ 抗生素 + 全身支持 |

**休克识别 4 信号**（**"必背"**）：

```text
① 意识改变（烦躁→淡漠→昏迷）
② 皮肤湿冷、花斑、紫绀
③ 尿量 < 30ml/h（**最敏感指标**）
④ 脉压差缩小（收缩压降、舒张压升）
```

**抗休克 3 原则**：**"先补液扩容（晶体为主）→ 纠正酸中毒 → 血管活性药（液体补足仍低血压才用）"**。

> **铁律**：**"尿量是休克复苏的'晴雨表'，目标 > 30ml/h"**。

### 5.2 急性腹痛鉴别（**"4 大病因"**）

| 病因 | 典型表现 | 关键鉴别 |
|------|---------|---------|
| **急性阑尾炎** | **转移性右下腹痛**（先脐周后 McBurney 点）、压痛反跳痛 | 麦氏点压痛、腰大肌试验 |
| **急性胆道感染** | **右上腹痛 + 发热 + 黄疸**（**Charcot 三联征**）、Murphy 征(+) | 结石梗阻 + 感染 |
| **急性胰腺炎** | **左上腹/中上腹剧痛 → 腰背部放射**、恶心呕吐、**血/尿淀粉酶↑** | 诱因（饮酒/高脂餐）、腹膜炎体征 |
| **肠梗阻** | **痛、吐、胀、闭**（停止排气排便） | 肠鸣音亢进（机械性）/消失（绞窄/麻痹） |

**急腹症处理原则**（**"3 不"禁忌**）：

```text
① 诊断未明前：禁止痛药（掩盖病情）
② 禁热敷（炎症扩散）
③ 禁泻药（穿孔风险）
→ "禁食 + 胃肠减压 + 补液 + 抗感染 + 严密观察 + 必要时手术"
```

> **记忆锚**：**"阑尾转移痛，胆道三联征，胰腺酶升高，梗阻痛吐胀闭"**。

### 5.3 创伤与骨折固定（**"3 原则"**）

**骨折急救 3 原则**（**"先救命后治伤"**）：

| 原则 | 内容 |
|------|------|
| **先救命** | 先处理休克/窒息/大出血（**ABC：气道-呼吸-循环**） |
| **再固定** | 现场固定（夹板/肢带），**不随意复位**（避免二次损伤） |
| **后转运** | 脊柱伤 → **轴线搬运**（疑颈椎/胸腰椎骨折**禁止坐起/屈曲**） |

**开放骨折特殊处理**：**"无菌敷料覆盖创面，不冲洗不涂药，尽快清创 + 抗生素"**。

### 5.4 急症初步处置（**"通用流程"**）

```text
① 评估 ABC（气道/呼吸/循环）→ 生命体征
② 分类（红/黄/绿/黑：危重/急/亚急/非急）
③ 危重先稳定（补液/给氧/止血/镇痛**诊断明确后**）
④ 辅助检查（血象/淀粉酶/影像）
⑤ 处理（保守 vs 手术）+ 记录 + 知情告知
```

## 🧠 记忆工具箱

### 口诀速记

- 感染：**"红肿热痛功能障，切开引流加抗生"**；
- 休克：**"意识皮肤尿脉压，先液后酸再升压"**；
- 腹痛：**"阑尾转移，胆道三联，胰腺酶升，梗阻痛吐胀闭"**；
- 急腹症：**"三不：不止痛、不热敷、不泻药"**；
- 骨折：**"先救命后固定，脊柱轴线不弯曲"**。

### 场景锚点

- 急性腹痛想象"**"分诊台分 4 个房间"**"：你**不是主治**（**不做最终诊断**），**你是"分诊护士"**——**"病人说'肚子痛'，你要快速分流到 4 个房间：右下腹转移痛 → 阑尾房；右上腹 + 黄 + 热 → 胆道房；中上腹剧痛放射后背 → 胰腺房；痛吐胀闭 → 梗阻房"**——**"分诊的关键是'定位 + 伴随症状'，别被'肚子痛'三个字困住"**。

## ⚠️ 易错提醒

- **休克"只看血压"**：**"尿量比血压更敏感"**（**"血压正常时尿量可能已下降"**）；
- **急腹症"先止痛"**：**"诊断未明禁用止痛"**（**"掩盖体征延误手术"**）；
- **阑尾炎"直接开腹"**：**"先鉴别"（宫外孕/胆囊/胰腺/肠系膜淋巴结）**（**"右下腹痛不止阑尾"**）；
- **脊柱伤"坐起搬运"**：**"轴线平抬，禁止屈曲"**（**"二次损伤 = 瘫痪"**）；
- **胰腺炎"只看腹痛"**：**"必查淀粉酶 + 诱因（饮酒/高脂）"**。
