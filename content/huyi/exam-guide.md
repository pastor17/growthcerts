> 本节按国家医学考试网历年公告整理；**当次报名与考试安排以国家医学考试网（nmec.org.cn）公告为准**。

## 护士时间线（示例口径）

| 环节 | 大致时间 |
|------|---------|
| **公告与报名** | 每年 **1~2 月**（国家医学考试网） |
| **准考证打印** | 考前 **1 周** |
| **考试** | **4 月**（**人机对话**，**分批次**） |
| **成绩公布** | 考后 **1~2 个月** |
| **执业注册** | 成绩合格后 **1 年内**（**护士执业注册**） |

## 执医时间线（示例口径）

| 环节 | 大致时间 |
|------|---------|
| **公告与报名** | 每年 **1~2 月**（国家医学考试网） |
| **实践技能考** | **6 月**（**现场操作**，**分批次**） |
| **技能成绩** | 考后 **1 周** |
| **医学综合笔试** | **8 月**（**机考**，**分批次**） |
| **笔试成绩** | 考后 **1 个月** |
| **执业注册** | 成绩合格后 **1 年内**（**医师执业注册**） |

> **注意**：**执医"技能不过 = 笔试不能考"**——**技能 60 分合格**，**技能不过 = 笔试白考**。

## 报名条件（官方口径，示例结构）

**护士**：

- 在中等职业学校/高等学校完成**护理专业**毕业；
- **8 个月以上护理实习**（**毕业前/后**均可，以公告为准）；
- 政治素质、身体健康等通用条件。

**执业医师**：

- **临床医学/口腔医学/中医学**专业毕业；
- **1 年试用期**（**医疗机构**，**毕业前/后**均可，以公告为准）；
- **助理医师考执业医师**：需 **2 年**（**执业助理医师** + **2 年**，以公告为准）；
- 政治素质、身体健康等通用条件。

## 考试形式与合格标准

**护士**：

- **人机对话**（**机考**，**120 分钟/科**，**4 科**）；
- 题型：**单选 + 案例 + 情景**（**A1/A2/B1**）；
- 合格标准：每科 **300 分满分，380 分合格**（**80%**）。

**执业医师**：

- **实践技能**：**3 站**（**病史采集/体格检查/临床思考**），**现场操作**（**60 分钟/站**）；
- **医学综合笔试**：**机考**（**A1/A2/B1 题型**，**300 题/600 分**，**240 分钟**）；
- 合格标准：技能 **60 分**；笔试 **360 分/600**（**60%**）。

## 执业注册（"双证"齐全）

- **资格证**（**通过考试**）+ **执业证**（**注册后**）= **完整执业**；
- **护士执业注册**：**成绩合格 1 年内**（**逾期需重新考试**）；
- **医师执业注册**：**成绩合格 1 年内**（**逾期需重新考试**）；
- **注册机构**：**县级以上卫生健康行政部门**（**医院/诊所/社区**）。

## 备考建议

1. **护士"量大面广"**：**4 科"背诵 + 理解"**，**"护理程序"4 步**（**评估 → 诊断 → 计划 → 评价**）是核心；
2. **执医"读题慢 = 丢分"**：**A2 病例长**，**"先读题再读病例"**（**"问题是什么"**）；
3. **技能"操作不规范 = 丢分"**：**"视触叩听"顺序**（**视 → 触 → 叩 → 听**）+ **"操作前/中/后"**（**"三查七对"**）；
4. **机考"必须练"**：**人机对话**（**护士**）+ **机考**（**执医笔试**）——**"输入 + 时间"**是失分重灾区；
5. **考前 2 周"只过数字卡 + 错题"**：**"护理程序 4 步"** + **"A1/A2/B1 题型"** + **"视触叩听顺序"**。
