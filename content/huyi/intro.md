## 是什么

**护士资格考试**与**执业医师资格考试**是医护行业的**准入类职业资格考试**，由**国家卫生健康委员会**组织，**国家医学考试网**统一报名。通过考试 = 获得**执业资格**，申请**执业证**后可以在医疗机构执业（**护士/医师**）。

## 护士 vs 执业医师（核心区别）

| 对比项 | **护士** | **执业医师** |
|--------|---------|------------|
| **专业** | 护理学 | 临床医学/口腔/中医 |
| **科目** | **4 科**（专业实务/专业基础/人文社会学/护理学） | **2 阶段**（实践技能 + 医学综合笔试） |
| **形式** | **人机对话**（机考） | **技能现场操作 + 笔试机考** |
| **合格标准** | 每科 **380/300**（80%） | 技能 **60 分**；笔试 **360/600**（60%） |
| **执业证** | **护士执业证** | **医师执业证** |
| **职称** | **护士 → 护师 → 主管护师 → 副主任护师 → 主任护师** | **医师 → 主治 → 副主任 → 主任** |
| **适合谁** | 护理专业毕业生、在职护士 | 临床医学/口腔/中医毕业生、在职医师 |

> **记忆锚**：**"护士 4 科机考，执医技能 + 笔试"**——**护士"简单"（4 科机考），执医"难"（技能 + 笔试）**。

## 考什么

### 护士（4 科，人机对话）

| 科目 | 核心内容 |
|------|---------|
| **专业实务** | 护理评估、护理诊断、护理措施（**"护理程序"4 步**） |
| **专业基础** | 基础护理学（**生命体征/给药/无菌/急救**） |
| **人文社会学** | 护理伦理、护理法律、护理心理学 |
| **护理学** | 内科/外科/妇产科/儿科护理（**专科护理**） |

> **题型**：**单选 + 案例 + 情景**（**人机对话**，**120 分钟/科**）。

### 执业医师（2 阶段）

**实践技能（3 站）**：

| 站 | 内容 | 形式 |
|----|------|------|
| **第 1 站** | **病史采集**（**问诊**）+ **病例分析** | **标准化病人（SP）** |
| **第 2 站** | **体格检查**（**视触叩听**） | **模型/SP** |
| **第 3 站** | **临床思考**（**诊断/鉴别/治疗**）+ **操作** | **笔试 + 操作** |

**医学综合笔试（A1/A2/B1 题型）**：

| 题型 | 含义 | 例子 |
|------|------|------|
| **A1** | **单句型最佳选择题**（**1 个病例，1 个问题**） | "患者男，50 岁，胸痛 2 小时……**最可能的诊断是？**" |
| **A2** | **病例摘要型最佳选择题**（**1 个病例，1 个问题**） | "患者女，30 岁，停经 2 月，阴道出血……**首先考虑？**" |
| **B1** | **配伍选择题**（**2~4 个共用选项**） | "A. 心绞痛 B. 心肌梗死 C. 心包炎 D. 心肌炎——**胸痛 2 小时，ST 段抬高？**" |

> **记忆锚**：**"A1 单句，A2 摘要，B1 配伍"**——**A1/A2 是"最佳选择"，B1 是"配伍"**。

## 含金量与难度（职场人决策参考）

| 维度 | 说明 |
|------|------|
| **岗位用途** | 护士：医院/社区/养老机构；医师：医院/诊所/体检中心 |
| **行业地位** | **准入类资格**——**"没有证 = 不能执业"**（**"入场券"**） |
| **职称对应** | 护士：**护士 → 护师 → 主管护师 → 副主任护师 → 主任护师**；医师：**医师 → 主治 → 副主任 → 主任**（**"以考代评"**） |
| **个税与补贴** | 属国家职业资格，**可申报个税继续教育专项附加扣除（480 元/年，以税务规定为准）** |
| **难度评级** | 护士：★★★☆☆（**4 科机考，"背诵 + 理解"**）；执医：★★★★★（**技能 + 笔试，"理解 + 记忆"**） |
| **建议总学时** | 护士：**300~500 小时**（4 科）；执医：**800~1200 小时**（技能 + 笔试） |
| **主要难点** | 护士：**"量大面广"**（**4 科，知识点碎**）；执医：**"A2 病例长"**（**"读题慢 = 丢分"**）+ **技能"操作不规范"** |
| **适合谁** | 护理专业毕业生（**护士**）；临床医学/口腔/中医毕业生（**执医**） |
| **建议先别考的情形** | 仅因"想转行"（**"专业不对口" = 不能报**）；时间无法保证每周 15 小时以上 |
