> 考试大纲以**国家医学考试网当次公告**为准；下方为模块结构整理（示例口径）。

## 护士（4 科，人机对话）

### 1 专业实务（护理学核心）

| 模块 | 重要度 |
|------|--------|
| **护理程序**（**评估 → 诊断 → 计划 → 评价**） | ★★★★★（**全书之王**） |
| 内科护理（**心/肺/肝/肾/内分泌**） | ★★★★★ |
| 外科护理（**术前/术后/急腹症**） | ★★★★ |
| 妇产科护理（**孕产/妇科**） | ★★★★ |
| 儿科护理（**新生儿/儿童**） | ★★★ |

### 2 专业基础（基础护理学）

| 模块 | 重要度 |
|------|--------|
| **生命体征**（**T/P/R/BP**） | ★★★★★（**必考**） |
| **给药**（**三查七对/给药途径**） | ★★★★★（**必考**） |
| **无菌技术**（**无菌操作/手卫生**） | ★★★★ |
| **急救**（**CPR/心肺复苏**） | ★★★★ |
| 静脉输液/输血 | ★★★★ |

### 3 人文社会学

| 模块 | 重要度 |
|------|--------|
| **护理伦理**（**尊重/保密/知情同意**） | ★★★ |
| **护理法律**（**侵权责任/医疗纠纷**） | ★★★ |
| **护理心理学**（**患者心理/沟通**） | ★★ |

### 4 护理学（专科护理）

| 模块 | 重要度 |
|------|--------|
| 内科/外科/妇产科/儿科护理（**专科**） | ★★★★★（**与"专业实务"重叠**） |
| 社区护理/老年护理 | ★★★ |
| 护理管理/护理教育 | ★★ |

## 执业医师（2 阶段）

### 实践技能（3 站，现场操作）

| 站 | 模块 | 重要度 |
|----|------|--------|
| **第 1 站** | **病史采集**（**问诊**）+ **病例分析** | ★★★★★ |
| **第 2 站** | **体格检查**（**视触叩听**） | ★★★★★ |
| **第 3 站** | **临床思考**（**诊断/鉴别/治疗**）+ **操作** | ★★★★★ |

### 医学综合笔试（A1/A2/B1 题型，机考）

| 模块 | 重要度 |
|------|--------|
| **生理学**（**心血管/呼吸/消化**） | ★★★★ |
| **生物化学**（**酶/代谢/核酸**） | ★★★ |
| **药理学**（**抗生素/心血管/中枢**） | ★★★★ |
| **病理学**（**炎症/肿瘤/心血管**） | ★★★★ |
| **内科学**（**心/肺/肝/肾/内分泌**） | ★★★★★（**A2 病例重灾区**） |
| **外科学**（**急腹症/创伤/肿瘤**） | ★★★★ |
| **妇产科学**（**孕产/妇科**） | ★★★★ |
| **儿科学**（**新生儿/儿童**） | ★★★ |
| **传染病学**（**肝炎/结核/艾滋病**） | ★★★ |
| **预防医学**（**传染病防控/职业卫生**） | ★★ |

## 备考路线

### 护士（3~6 个月）

```text
① 基础轮（1~2 月）：专业基础（**生命体征/给药/无菌/急救**）→ 专业实务（**护理程序 4 步**）
   ↓
② 强化轮（2~3 月）：内科/外科/妇产科/儿科（**专科护理**）→ 人文社会学（**伦理/法律**）
   ↓
③ 冲刺轮（考前 1 月）：套卷限时 + 错题二刷 → 考前 1 周只过"数字卡 + 护理程序 4 步"
```

### 执业医师（6~12 个月）

```text
① 基础轮（3~4 月）：生理/生化/药理/病理（**"基础 4 科"**）
   ↓
② 强化轮（3~4 月）：内/外/妇产/儿/传染（**"临床 5 科"**）
   ↓
③ 技能轮（考前 2 月）：3 站"操作 + 问诊"（**"视触叩听" + "病史采集"**）
   ↓
④ 冲刺轮（考前 1 月）：A1/A2/B1 套卷限时 → 考前 1 周只过"病例卡 + 操作规范"
```

> 📖 本站精讲为原创整理，**诊疗规范以最新指南为准**（**"指南更新" = "考点更新"**）。
