> 健康管理师是**健康服务领域**需求量较大的职业技能等级证书。它曾列入**国家职业资格目录**，后**退出目录**，转为**职业技能等级认定**：由**经人社部门备案的评价机构**组织实施、评价并颁发证书，证书**可在技能人才评价工作网（osta.org.cn）查询**。**评价机构、报考条件、考核方式、补贴与积分政策一律以备案评价机构与当地人社部门当次通知为准**。

**等级与考核（一般口径）**

| 项目 | 说明 |
|------|------|
| **证书性质** | **职业技能等级证书**（**已退出国家职业资格目录**） |
| **发证主体** | 经人社部门**备案的评价机构**（**非人社部门直接发证**） |
| **常见等级** | **三级（高级）**、**二级（技师）**、**一级（高级技师）**等 |
| **考核科目** | **理论知识 + 操作技能**（**两科**） |
| **查询渠道** | **技能人才评价工作网**（[osta.org.cn](http://www.osta.org.cn)） |

**考什么**

- **理论知识**：健康管理概论、临床医学与预防医学基础、常见慢性病（高血压/糖尿病/血脂异常/肥胖/痛风等）、营养与食品安全、身体活动与运动处方、心理健康、健康教育与健康促进、健康信息学、健康风险评估与分析、健康管理服务与营销、中医养生、康复医学、健康保险；
- **操作技能**：健康信息采集与健康档案、健康风险评估与分析、健康教育与健康促进、健康管理干预方案与随访、中医养生与康复指导等；
- 两科一般**均须合格**方可取得证书；具体题型、时长与合格标准**以当次评价机构通知为准**。

**就业方向**：体检中心、健康管理公司、社区卫生服务中心、养老/医养机构、保险公司健康险、药店、健身与运动康复、母婴与月子中心、餐饮与营养配餐、企业健康管理。

**本站已上线内容**：**2 本原创考点精讲共 8 章**（《健康管理基础与医学知识》《健康干预与实操技能》），以及**证书百科、职场需求、报考指南、大纲与教材、学习资源、备考笔记、一页速记**与**题库练习**入口。
