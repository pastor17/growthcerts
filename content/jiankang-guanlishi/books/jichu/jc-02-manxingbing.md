## 考点梳理

### 2.1 慢性病的概念与共同特点

<strong>慢性病（慢性非传染性疾病）</strong>是对一类**起病隐匿、病程长、迁延不愈、通常难以彻底治愈**的疾病的统称。

| 共同特点 | 含义与考点 |
|---------|-----------|
| **起病隐匿** | 早期常无明显症状，多靠体检或筛查发现，因此<strong>二级预防“三早”</strong>尤为关键 |
| **病程长** | 从数年到数十年，健康管理有充足介入空间 |
| **并发症多** | 长期控制不佳会累及心、脑、肾、眼、血管与神经等靶器官 |
| **需长期甚至终身管理** | 重点不是“治好”，而是**控制危险因素、延缓进展、减少并发症** |
| **多因素致病** | 由生活方式、环境、遗传等多种**危险因素长期共同作用**，而非单一病因 |

> 记忆锚：**“隐匿起病、病程长、并发症多、终身管理”**——记住这四条，慢病题就有了共同答案方向。

### 2.2 危险因素的分类（必背对比）

| 类别 | 具体内容 | 能否干预 |
|------|---------|---------|
| **不可改变危险因素** | **年龄、性别、遗传（家族史）、种族**等 | **不能改变**，只能用于风险分层与重点筛查 |
| **可改变危险因素（行为与生活方式）** | **吸烟、过量饮酒、不合理膳食、身体活动不足、超重与肥胖、心理压力过大、睡眠不足** | **健康管理的核心战场** |
| **可改变危险因素（中间指标）** | **血压升高、血糖升高、血脂异常、血尿酸升高、腰围增大**等 | 通过生活方式干预 + 规范治疗可改善 |
| **环境与社会因素** | 空气污染、职业暴露、居住与工作环境、社会经济状况、健康素养不足 | 部分可干预（可通过政策、健康教育改善） |

> 记忆锚：**“年龄性别和遗传改不了，烟酒吃动胖压力全都改得了”**——不可改变的用来分层，可改变的用来干预。

### 2.3 常见慢性病：危险因素与生活方式干预方向

| 常见慢病 | 主要危险因素 | 生活方式干预方向 |
|---------|-------------|-----------------|
| **高血压** | 高盐膳食、超重与肥胖、过量饮酒、精神紧张、缺乏运动、家族史、年龄 | 限盐、控重、限酒戒烟、规律有氧运动、减压与充足睡眠、**规律监测血压** |
| **糖尿病（以 2 型为主）** | 超重与肥胖（尤其中心性肥胖）、高糖高脂膳食、身体活动不足、家族史、年龄、妊娠期血糖异常史 | 控制总能量、均衡膳食、增加身体活动、控重、**规律监测血糖**、坚持随访 |
| **血脂异常** | 高饱和脂肪与反式脂肪摄入、肥胖、缺乏运动、吸烟、过量饮酒、遗传 | 减少饱和脂肪与反式脂肪、增加膳食纤维、规律运动、控重、戒烟限酒 |
| **超重与肥胖** | 能量摄入长期大于消耗、久坐、膳食结构不合理、睡眠不足、遗传 | 控制总能量、调整膳食结构、增加身体活动、行为与心理支持、长期监测体重与腰围 |
| **痛风与高尿酸血症** | 高嘌呤膳食（动物内脏、部分海产）、过量饮酒（尤其啤酒）、含糖饮料、肥胖、遗传 | 限制高嘌呤食物与酒精、多饮水、控重、避免暴饮暴食与剧烈减重 |
| **冠心病** | 高血压、血脂异常、糖尿病、吸烟、肥胖、缺乏运动、家族史、精神压力 | 戒烟、控压控糖调脂配合治疗、合理膳食、规律运动、控制情绪与压力 |
| **脑卒中** | 高血压（最重要）、心脏病（如房颤）、糖尿病、血脂异常、吸烟、过量饮酒、肥胖 | 控压为核心、戒烟限酒、控重、规律运动、识别早期预警症状并**及时就医** |
| **慢性阻塞性肺疾病** | 吸烟（首要）、职业粉尘与有害气体暴露、空气污染、反复呼吸道感染 | **戒烟为第一要务**、减少有害气体与粉尘暴露、注意保暖防感染、呼吸功能锻炼配合康复 |
| **恶性肿瘤** | 吸烟、过量饮酒、不合理膳食、肥胖、缺乏运动、感染因素（部分病毒）、职业暴露、家族史、年龄 | 戒烟限酒、均衡膳食、规律运动、控重、**按指南参加规范筛查**、接种相关疫苗、职业防护 |
| **骨质疏松** | 钙与维生素 D 摄入不足、身体活动不足、吸烟、过量饮酒、绝经后女性、年龄 | 足量钙与维生素 D、负重与抗阻运动、戒烟限酒、防跌倒、按医嘱评估骨健康 |

**共同危险因素要会“合并记忆”**：吸烟、过量饮酒、不合理膳食、身体活动不足、超重与肥胖、心理压力这六项，几乎同时出现在高血压、糖尿病、血脂异常、冠心病、脑卒中、恶性肿瘤的答案里；考场上先想这六项，再补该病特有的因素（如慢阻肺的吸烟、痛风的高嘌呤膳食、骨质疏松的钙与维生素 D 不足）。

> 记忆锚：慢病干预方向可归成<strong>“戒烟限酒、合理膳食、适量运动、控制体重、心理平衡、规律监测”</strong>六件事。

### 2.4 慢病防控策略（三级预防 + 筛—防—治—管）

| 层面 | 策略要点 |
|------|---------|
| **一级预防** | 面向全人群与高危人群，控制危险因素：健康教育、控烟限酒、合理膳食、全民健身、支持性环境建设 |
| **二级预防** | **“三早”**：机会性筛查、高危人群筛查、健康体检、早期发现与早期规范治疗 |
| **三级预防** | 规范治疗配合、并发症筛查与防治、康复训练、心理支持，防止**残疾与死亡** |
| **“筛—防—治—管”闭环** | **筛**（发现高危与早期）→ **防**（危险因素干预）→ **治**（转介医疗机构规范治疗）→ **管**（长期随访与自我管理支持） |
| **患者自我管理** | 教会患者**自我监测、按时服药、识别危险信号、记录指标、定期复诊**，健康管理师做的是“支持与督促”，不是“替代医生” |

> 记忆锚：**“筛出来、防得住、转得准、管得久”**——四步闭环里，健康管理师的强项在“防”和“管”。

**重点管理人群**（了解即可，场景题常考）

- **高危人群**：有家族史、超重肥胖、血压血糖血脂异常、长期吸烟饮酒者，以**一级预防**为主；
- **已患病人群**：重点是**依从性支持、并发症筛查提醒与随访**，即二、三级预防；
- **老年人群**：多重用药、功能下降、跌倒与营养不良风险高，需**综合评估 + 防跌倒 + 营养支持**；
- **职业人群**：久坐、倒班、应酬多，是**工作场所健康促进**的重点对象。

### 2.5 体格与生化常用指标的参考口径框架

下表**只讲口径与注意事项**，不列具体数值；**具体参考区间与控制目标以现行临床指南与教材为准，本站不提供诊断与治疗建议**。

| 指标 | 常用参考口径框架 | 解读注意 |
|------|-----------------|---------|
| **血压** | 通常按“正常 / 正常高值 / 升高”分层管理，切点以现行指南与教材为准 | 单次测量不能下结论，需安静休息后规范测量、非同日复测 |
| **血糖** | 常用口径包括空腹血糖、餐后血糖与糖化血红蛋白 | 三项含义不同、不能互相替代；参考区间与控制目标以现行指南为准 |
| **血脂** | 常看总胆固醇、低密度脂蛋白胆固醇、高密度脂蛋白胆固醇、甘油三酯 | 不同心血管风险人群的控制目标不同，以现行指南为准 |
| **BMI（体质指数）** | 体重（kg）÷ 身高²（m²），按低体重、正常、超重、肥胖分层 | 分层切点以现行教材与指南为准；孕妇、运动员、老年人需谨慎解读 |
| **腰围** | 反映**中心性肥胖**，与代谢与心血管风险关系密切 | 测量位置与方法要规范，切点以现行指南为准 |
| **尿酸、肝肾功能等** | 属于生化检查常用组合项目 | 结果需由医生结合病史综合判断，健康管理师只做解释与转介 |

> 记忆锚：**“参考区间是筛查口径，不是诊断标准”**——把这句话写进答题习惯里。

## 🧠 记忆工具箱

### 口诀速记

- **慢病四特点**：“**隐、长、并、终**”（起病隐匿、病程长、并发症多、终身管理）。
- **危险因素两分法**：**不可改变**（年龄、性别、遗传、种族）；**可改变**（烟、酒、吃、动、胖、压力、睡眠 + 血压血糖血脂尿酸腰围）。
- **六件事干预**：**戒烟限酒、合理膳食、适量运动、控制体重、心理平衡、规律监测**。
- **防控闭环**：“**筛—防—治—管**”＋患者自我管理。
- **指标态度**：分层看趋势、单位要统一、**以现行临床指南与教材为准**。

### 场景锚点

- **体检中心**：团检报告里血压、血糖、血脂、BMI、腰围成组出现，健康管理师的任务是把这些数字翻译成**危险因素清单 + 干预方向**，并提示需要进一步就医的项目。
- **社区卫生服务中心**：高血压、糖尿病患者的建档与随访是日常工作，重点是**规律监测、用药依从性提醒、生活方式指导与转介**，而不是调药。
- **健康管理公司**：为超重、血脂异常客户设计减重与运动方案，用**体重、腰围、血压**等可量化指标做阶段性效果评价。
- **企业健康管理**：针对吸烟率高、应酬多、久坐的团队做控烟、限酒、工间运动与压力管理项目，属于**工作场所一级预防**。
- **养老机构**：老年人常见跌倒、营养不良、骨质疏松、多重用药与情绪问题，管理重点是**功能维护、防跌倒与并发症预防**（三级预防）。
- **患者沟通场景**：患者问“我这个血糖算不算糖尿病、要不要加药”，正确回答是解释一般口径并建议**由医生结合检查判断**，**不提供诊断与用药建议**。

## ⚠️ 易错提醒

- **错误认知**：慢性病是“老年病”，年轻人不用担心。纠正：慢病危险因素（吸烟、肥胖、久坐、熬夜）在**中青年已普遍存在**，慢病防控重在**早预防、早干预**。
- **错误认知**：把危险因素直接当成病因。纠正：危险因素是**提高发病概率**的因素，慢病多为**多因素长期共同作用**，不等于单一病因。
- **错误认知**：体检指标在参考区间内就等于健康。纠正：参考区间是**筛查与分层口径**；还需结合症状、病史与动态变化，**以现行临床指南与教材为准**。
- **错误认知**：慢病管理就是“按时吃药”。纠正：规范治疗只是一部分，核心是**危险因素干预 + 长期随访 + 患者自我管理**。
- **错误认知**：健康管理师可以给患者调药、定诊断。纠正：诊断与用药属于医疗行为，健康管理师的职责是**监测、评估、指导与转介**，**本站不提供医疗建议**。
- **错误认知**：健康管理师证书的等级与补贴全国统一。纠正：证书性质、评价机构、报考条件、补贴与积分等，**以备案评价机构与当地人社部门当次通知为准**。
