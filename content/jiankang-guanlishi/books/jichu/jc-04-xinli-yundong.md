## 考点梳理

### 4.1 心理健康的概念与常用评价维度

**心理健康**不是「没有心理疾病」那么简单，而是指个体在**认知、情绪、意志行为、人格与人际关系**等方面处于良好状态，能够**适应环境、应对压力、发挥潜能**。它是一个**连续谱**，从良好状态到严重障碍之间有大量中间地带，而不是「有病 / 没病」的二分类。

**常用评价维度（一般口径，不涉及具体量表得分）**

| 维度 | 关注什么 |
|------|---------|
| **认知** | 感知、注意、记忆、思维是否清晰合理，有无明显歪曲或迟钝 |
| **情绪** | 情绪是否稳定、能否适度表达与调节，是否长期低落或紧张 |
| **意志与行为** | 有无目标感、自控力与行动力，行为是否与情境相符 |
| **人格与自我** | 自我认知是否客观、是否稳定，有无长期适应不良 |
| **人际关系** | 能否建立并维持关系、是否有社会支持网络 |
| **社会适应** | 工作、学习、家庭角色功能是否基本正常 |

> 记忆锚：**「认知清、情绪稳、行为当、人格正、关系顺、适应好」**——六个维度记成一串，别死抠量表分数。**健康管理师在心理健康板块只做健康教育与情绪支持、发现异常并转介**，不做心理诊断、不做心理治疗、不评价具体量表得分；涉及诊断标准、用药与治疗，**以现行临床指南与教材为准，本站不提供医疗建议**。

### 4.2 压力、应激与应激反应

- **压力（stress）**：个体面对内外环境要求时产生的一种**身心紧张状态**。适度的压力可以提升动机与表现，**长期或过强的压力**才会损害健康。
- **应激反应**的一般三阶段（一般性适应综合征框架）：**警觉期 → 抵抗期 → 衰竭期**。前两阶段机体尚能代偿，进入衰竭期则出现功能紊乱与疾病风险上升。
- **常见表现**：生理上心慌、失眠、食欲改变、疲劳、肌肉紧张；情绪上烦躁、易怒、低落、无助；认知上注意力不集中、记忆力下降、决策困难；行为上拖延、回避、烟酒增加、社交退缩。

**健康管理师可做的**：识别压力信号、做压力管理教育（规律作息、身体活动、放松训练、时间管理与沟通支持），帮助其梳理可改变的因素。**压力源属于疾病、创伤或严重心理危机时，直接转介。**

### 4.3 常见心理困扰的识别信号（只识别，不诊断）

| 困扰 | 常见的可观察信号 |
|------|-----------------|
| **焦虑情绪** | 持续过度担心、坐立不安、心慌出汗、肌肉紧张、注意力难以集中、睡眠变差、反复回避某些场合 |
| **抑郁情绪** | 持续情绪低落、兴趣与愉悦感减退、精力下降、自我评价过低、食欲或体重明显变化、睡眠障碍、社交退缩 |
| **睡眠障碍** | 入睡困难、易醒早醒、睡眠浅多梦、白天困倦、依赖助眠方式、作息紊乱 |

**需要立即转介、不得自行处理的情形（红旗信号）**：出现**自伤、自杀念头或计划**，提到**伤害他人**，出现**幻觉、妄想、意识或言语行为明显紊乱**，**完全丧失生活与工作能力**，或因躯体疾病、药物、酒精导致的急性精神症状。

> 记忆锚：**「自伤他伤、妄想幻觉、功能崩解、意识紊乱」——四条红线，一条就转介，不做任何观望与劝导式的拖延。**

### 4.4 转介边界：健康管理师能做什么、不能做什么

| 能做（健康教育与支持） | 不能做（越界） |
|----------------------|---------------|
| 普及心理健康常识、减少病耻感 | **心理诊断**（下判断、贴标签） |
| 情绪支持、倾听与陪伴 | **心理治疗**、任何形式的治疗性干预 |
| 压力管理与睡眠卫生教育 | 使用、解释**心理量表并给出诊断性结论** |
| 识别异常信号、**及时转介** | 开药、建议增减或停用精神类药物 |
| 记录与随访、协助链接专业资源 | 承诺「聊几次就能好」、隐瞒风险不上报 |

**转介的一般做法**：说明观察到的事实（不做评判与定性）→ 表达关心 → 建议专业途径（精神科 / 心理科门诊、心理咨询机构、当地心理援助热线、单位 EAP）→ 尊重自主决定，但**涉及自伤他伤等风险时按机构应急预案与法规要求上报并跟进**，不能以「保密」为由放任风险。**保密有例外**：涉及自伤他伤风险、法定报告情形时，保密要让位于安全，具体流程以所在机构制度与当地规定为准。

### 4.5 心理疏导与沟通技巧的一般原则

- **尊重与接纳**：不评判、不说教、不轻易给「你应该」。
- **倾听为先**：少打断、多回应感受，用「听起来你最近确实很累」这类**情感反映**代替追问细节。
- **共情而非同情**：理解对方的处境与情绪，而不是俯视式的怜悯。
- **开放式提问**：用「能多说说吗」代替「是不是因为你不够努力」。
- **具体化**：把模糊的「我很难受」落到时间、情境、身体感受与影响上。
- **支持自主**：一起梳理可选项，由对方决定，**避免包办代替**。
- **边界意识**：控制时长与频次，不把工作关系变成私人依赖；**不承诺超出能力范围的结果**。

> 记忆锚：**「尊、听、共、问、细、主、界」**——尊重、倾听、共情、开放提问、具体化、支持自主、守边界。

### 4.6 身体活动的分类

| 类型 | 特点 | 举例 |
|------|------|------|
| **有氧运动（耐力运动）** | 大肌群、节律性、持续时间较长，改善心肺耐力 | 快走、慢跑、游泳、骑行、广场舞 |
| **抗阻运动（力量训练）** | 对抗阻力、增强肌力与肌肉量、有助于维持骨健康与代谢 | 弹力带、哑铃、自重训练、器械训练 |
| **柔韧性练习** | 牵伸肌肉与关节周围组织，改善关节活动度 | 静态牵伸、动态牵伸、瑜伽、太极 |
| **日常身体活动（非运动性）** | 融入生活的活动，累积效应明显 | 步行通勤、爬楼梯、家务、站立办公 |

> **协调与平衡练习**（如太极、单腿站立）对老年人尤为重要，一般归入功能性练习一并考虑。

### 4.7 运动处方的 FITT 框架

**运动处方**是针对个体情况，按科学原则给出的**系统化身体活动安排**，核心要素是 **FITT**：

| 要素 | 含义 | 一般口径 |
|------|------|---------|
| **F — 频率（Frequency）** | 每周进行多少次 | 有氧一般每周多次、抗阻一般每周数次，**具体以现行指南与教材为准** |
| **I — 强度（Intensity）** | 运动的费力程度 | 常用**主观感觉（说话测试）、心率储备或最大心率百分比**等表达；**具体数值以现行临床指南与教材为准** |
| **T — 时间（Time）** | 每次持续多久 | 有氧以**累积**方式达成，可分段累计；**具体时长以指南为准** |
| **T — 类型（Type）** | 做什么运动 | 有氧 + 抗阻 + 柔韧/平衡的**组合**优于单一类型 |

**完整处方还应包括**：**总量（Volume）、进度（Progression，循序渐进）、以及热身与整理活动**。

> 记忆锚：**「FITT 是骨架，总量与进度是血肉，热身整理是保险」**。**本章只写 FITT 的框架与方向，不给任何具体疾病人群的运动强度数值；具体强度区间、禁忌与进阶方案，以现行临床指南与教材为准，本站不提供医疗建议。**

### 4.8 运动前风险筛查与禁忌的一般原则

- **筛查目的**：在开始或加量前，识别**心血管、代谢、骨关节**等方面的潜在风险，避免运动诱发不良事件。
- **一般做法**：了解既往病史与家族史、当前症状、用药情况、既往运动习惯与运动损伤史；对**久坐、超重肥胖、中老年、有慢病或症状者**，建议先经**医学评估**再制定方案。
- **需要先就医评估、不宜自行开始或加量的信号（一般口径）**：**静息或活动中胸痛胸闷、明显气促、心悸或晕厥、不明原因的极度疲劳、血压或血糖控制很差、急性感染发热期、未稳定的骨关节损伤**等。
- **一般禁忌原则**：急性期与不稳定期以**医学处理为先**；任何**诊断标准、禁忌清单与运动强度上限以现行临床指南与教材为准**。

> 记忆锚：**「先筛后动、带病先医、急性不动、循序渐进」**——筛查是运动处方的**第一步**，不是可选项。

### 4.9 不同人群身体活动的一般建议方向（只写方向）

| 人群 | 一般方向 |
|------|---------|
| **久坐人群** | **减少连续静坐时间、增加日常活动量**，从低强度、短时间起步，逐步累积到规律运动，重点在**养成习惯** |
| **超重与肥胖人群** | 以**增加身体活动总量 + 饮食行为调整**为核心，循序渐进、保护关节（可优先低冲击项目如快走、游泳、骑行），避免急于求成与极端做法 |
| **老年人** | 兼顾**有氧、抗阻、柔韧与平衡**，重视**防跌倒**、肌力维持与安全环境，强度保守、进度缓慢 |
| **慢病人群** | **须结合病情与医嘱**，在医学评估基础上安排活动；以稳定期、低风险项目起步，加强自我监测与随访，出现异常立即停止并就医 |

> **以上仅为方向性提示；具体强度、时长、禁忌与进阶方案，以现行临床指南与教材为准，本站不提供医疗建议。**

### 4.10 运动损伤的常见预防原则

- **充分热身与整理活动**：热身提升体温与关节活动度，整理活动帮助循环与代谢恢复。
- **循序渐进**：**总量与强度增幅不宜过快**（避免「周末勇士」式突然剧烈运动）。
- **技术动作正确**：规范动作模式，必要时请专业人员指导。
- **合适的装备与场地**：合脚鞋具、适合的场地与照明、必要的防护。
- **个体化与恢复**：保证休息与睡眠，避免带伤、带病、疲劳状态下硬练。
- **自我监测**：出现**关节疼痛、肿胀、活动受限**等信号应停止并评估，必要时就医。

> 记忆锚：**「热身、渐进、技术、装备、恢复、监测」**——六道防线，缺一道就容易受伤。

## 🧠 记忆工具箱

### 口诀速记

- **心理健康六维**：**「认知清、情绪稳、行为当、人格正、关系顺、适应好」**。
- **应激三阶段**：**「警觉 → 抵抗 → 衰竭」**。
- **转介四红线**：**「自伤他伤、妄想幻觉、功能崩解、意识紊乱」**——一条即转介。
- **沟通七字**：**「尊、听、共、问、细、主、界」**。
- **身体活动四类**：**「有氧、抗阻、柔韧、日常」**（＋协调平衡）。
- **运动处方 FITT**：**「频率、强度、时间、类型」**＋总量、进度、热身整理。
- **运动安全八字**：**「先筛后动、带病先医」**；**损伤预防六防线**：**「热身、渐进、技术、装备、恢复、监测」**。

### 场景锚点

- **体检中心**：客户自述「最近总失眠、心里发慌」，健康管理师做**睡眠卫生与压力管理教育**，了解作息、咖啡因、运动与工作负荷，给行为建议；若发现**持续情绪低落、兴趣丧失或提及自伤念头，立即转介精神心理专科**，绝不下诊断。
- **社区卫生服务中心**：组织慢病居民运动小组，先做**运动前风险筛查**，再按 **FITT 框架**给出方向性建议；强调**急性期与不稳定期不自行加量**，具体强度遵医嘱。
- **健康管理公司**：为客户做年度健康管理方案时，把**心理健康维度（情绪、睡眠、压力）与身体活动（有氧+抗阻+柔韧）**一起纳入，形成可跟踪的行为目标，而不是只给一个体重数字。
- **企业健康管理**：员工压力大、久坐多，可开展**压力管理讲座、工间操与步行挑战**；建立 **EAP 转介通道与心理援助热线**，并明确管理层与健康管理师的**边界与保密例外**。
- **月子中心**：产后情绪波动属常见现象，工作人员提供**倾听、情绪支持、休息与活动安排**的一般支持；出现**持续低落、兴趣丧失或自伤念头**，**立即转介并通知家属与专业机构**。
- **健身房 / 运动康复机构**：会员要求「快速加量」时，坚持**循序渐进、技术优先、热身与整理**；对有心血管症状、骨关节伤病史者要求**先出具医学评估**，不做超出资质的诊断与康复治疗。

## ⚠️ 易错提醒

- **错误认知**：把「没有心理疾病」等同于「心理健康」。纠正说明：心理健康是**连续谱**，包含认知、情绪、行为、人格、人际与社会适应的良好状态；「没病」只是底线，不等于状态良好。
- **错误认知**：认为健康管理师可以给客户做心理测评并给出诊断结论。纠正说明：健康管理师**只做健康教育、情绪支持与转介**，**不做心理诊断与心理治疗**；量表使用与结果解释属专业机构职责，具体诊断标准**以现行临床指南与教材为准**。
- **错误认知**：把运动处方等同于「多运动」「每天走一万步」。纠正说明：运动处方是按 **FITT（频率、强度、时间、类型）**加上总量、进度与热身整理给出的**个体化系统安排**，并且**必须从运动前风险筛查开始**；「多运动」既没有强度与进度概念，也忽略了风险。
- **错误认知**：忽视运动前风险筛查，直接给中老年或慢病客户开运动方案。纠正说明：筛查是运动处方的**第一步**；出现胸痛胸闷、气促、晕厥、急性感染发热或血糖血压控制很差等情况，应**先就医评估**，具体禁忌**以现行临床指南与教材为准**。
- **错误认知**：为了「保护隐私」，对透露自伤念头的人也不告诉任何人。纠正说明：**保密有例外**——涉及自伤他伤风险、法定报告情形时，安全优先于保密，应按所在机构应急预案与法规要求**上报并转介**。
- **错误认知**：认为慢性病患者只要运动就一定有好处，强度越大效果越好。纠正说明：慢病人群须**结合病情与医嘱**，稳定期低风险起步、加强自我监测；**具体强度与禁忌以现行临床指南与教材为准，本站不提供医疗建议**，异常立即停止并就医。

> ⚠️ **说明**：本章为**教材性知识框架**，**医学内容以现行临床指南与教材为准，本站不提供医疗建议**；涉及证书性质、评价机构、报考条件、补贴与积分等事项，**一律以备案评价机构与当地人社部门当次通知为准**。
