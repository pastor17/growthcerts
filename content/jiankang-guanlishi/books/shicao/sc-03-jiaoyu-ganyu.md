## 考点梳理

### 3.1 健康教育与健康促进：一字之差

**健康教育**：通过**信息传播 + 行为干预**，帮助个体和群体**自愿**采纳有利于健康的行为与生活方式。三个关键词：**有计划**（不是临时发传单）、**自愿**（不是命令）、**落脚在行为**（不是只让人知道）。

**健康促进**：范围更大，指**促使人们维护和改善自身健康的过程**，除健康教育外，还包括**政策支持、环境支持、服务支持**。

| 对比项 | 健康教育 | 健康促进 |
|--------|----------|----------|
| 性质 | 一种**教育活动 / 手段** | 一种**综合策略 / 过程** |
| 手段 | 传播、咨询、培训 | 教育 + 政策 + 环境 + 服务 |
| 关注点 | 知—信—行的改变 | 行为的**可持续**与健康公平 |
| 相互关系 | 是健康促进的**核心组成部分** | **包含**健康教育，范围更大 |

> 记忆锚：**健康教育是“一个手段”，健康促进是“一整套打法”**——前者讲道理，后者改环境。

### 3.2 健康素养

**健康素养**指个人**获取、理解、评价和应用健康信息**，并据此**做出判断和决策**以维护自身健康的能力。**功能性素养**是基础层：能读懂说明书、看懂食品标签、听懂医嘱；更高层次是能**评价**信息真伪（分辨养生谣言）、能**应用**信息做决策。健康素养低者常出现**用药错误、就诊延迟、依从性差**。

> 记忆锚：健康素养 = **“找得到、看得懂、信得过、用得上、做得到”**。

### 3.3 知信行（KAP）模式

**知—信—行**（知识 Knowledge → 态度 / 信念 Attitude-Belief → 行为 Practice）认为：**知识是基础，信念是动力，行为是目标**。三段**递进**但存在<strong>“断裂”风险</strong>：知而不信（觉得与我无关）、信而不行（缺条件、缺技能、缺支持）。因此干预不能只“讲知识”，还要**树立信念**（讲清风险与收益）并**提供行为条件**（技能训练、环境改造、同伴支持）。

> 记忆锚：**“知是地基、信是发动机、行是终点”**——光有地基车不动。

### 3.4 常用行为改变理论（三表对比）

| 理论 | 核心关键词 | 怎样解释“人为什么不改” | 适用场景 |
|------|-----------|----------------------|---------|
| **健康信念模式（HBM）** | 知觉**易感性**、知觉**严重性**、知觉**益处**、知觉**障碍**、**自我效能**、行动提示 | 觉得“我不会得病”“得病也不严重”“改起来太麻烦” | **一次性 / 预防性行为**：体检、疫苗接种、戒烟启动、筛查参与 |
| **行为分阶段转变（跨理论模型 TTM）** | **前意向期 → 意向期 → 准备期 → 行动期 → 维持期**（可复发回退） | 阶段不匹配：对毫无意图的人直接讲行动方案，等于无效 | **需要长期坚持的行为**：戒烟、减重、运动习惯养成 |
| **社会认知理论（SCT）** | **自我效能**、**观察学习**、**结果期望**、**环境与互惠决定论** | 缺榜样、缺自信、环境不支持 | **示范与技能训练**：同伴教育、小组操练、家庭与单位环境改造 |

三者要点：**HBM** 看“知觉”（易感性、严重性、益处、障碍）+ **自我效能**，干预重点是提高风险感知、强调收益、**降低障碍**并给“行动提示”；**TTM** 看**阶段**，干预重点是**先判阶段再选策略**（前意向期做意识唤醒，准备期做具体计划与承诺）；**SCT** 看**自我效能、观察学习、结果期望与环境**，干预重点是榜样示范、小目标拆解与及时反馈。

> 记忆锚：**HBM 管“愿不愿开始”，TTM 管“走到哪一步了”，SCT 管“能不能坚持”**。

### 3.5 健康教育方法与适用场景

| 方法 | 优点 | 局限 | 适用场景 |
|------|------|------|---------|
| **个别咨询 / 面对面指导** | 针对性强、保护隐私、便于答疑 | 耗时、人力成本高 | 体检报告解读、个体化膳食与运动指导 |
| **讲座 / 知识宣讲** | 覆盖面大、信息系统 | 单向灌输、难评估效果 | 社区健康大课堂、企业健康讲座 |
| **小组活动** | 互动多、可练技能、同伴支持 | 需带组技巧、人数受限 | 减重小组、慢病自我管理小组 |
| **同伴教育** | 信任度高、易模仿、语言相通 | 需培训同伴教育者、质量不稳 | 控烟同伴小组、青年人群、慢病互助 |
| **新媒体传播** | 传播快、形式多、可反复观看 | 信息真假混杂、触达不均 | 公众号、短视频、社群打卡 |

> 记忆锚：**“一对一讲深度、一对多讲广度、同伴讲温度、新媒体讲速度”**。

### 3.6 健康教育材料的制作原则

- **科学准确 + 通俗易懂**：说法与数据有依据，不夸大、不绝对化；少用术语，一份材料突出 **1~3 个核心信息**；
- **可操作 + 适宜人群**：写“怎么做”而不只写“应该做”；考虑**年龄、文化程度、语言、视力、文化习惯**，面向老年人要**加大字号、图文并茂**；
- **形式规范**：图文比例合理、重点突出、标注信息来源与制作日期。

### 3.7 健康管理干预方案的要素

| 要素 | 要求 | 反例 |
|------|------|------|
| **目标** | **具体、可测量、有时限**（如 3 个月减重一定比例、按要求复查） | “提高健康意识”（无法测量） |
| **内容** | 具体到做什么（膳食、运动、戒烟、随访） | “注意饮食” |
| **频次与强度** | 每周几次、每次多久、什么强度 | “经常锻炼” |
| **责任人与分工** | 健康管理师、医生、家属各做什么 | 谁都不负责 |
| **时间节点** | 起止时间、复评节点 | 没有终点 |
| **评价指标** | 过程指标 + 效果指标 | 只有口号没有指标 |
| **风险与转诊** | 明确**何时需转诊就医** | 一味让客户“再坚持” |

> 记忆锚：方案六问——**“目标是什么、做什么、做多少、谁来做、何时做、怎么评”**。

涉及具体诊断标准、用药调整与疾病人群的康复方案，一律**以现行临床指南与教材为准，本站不提供医疗建议**。

### 3.8 生活方式干预的五个方向

- **合理膳食**：食物多样、谷类为主，多吃蔬果、奶类、全谷与大豆，适量鱼禽蛋瘦肉，**少盐少油控糖**；
- **身体活动**：减少久坐，**有氧 + 抗阻 + 柔韧**结合，循序渐进、量力而行（具体运动安排按个体情况与指南）；
- **戒烟限酒**：**戒烟越早越好**，任何年龄戒烟都有获益；不饮酒或尽量少饮；
- **心理平衡**：识别压力信号，学会放松与求助，必要时**转介心理专业服务**；
- **充足睡眠**：规律作息、固定起床时间、睡前减少屏幕与咖啡因。

> 记忆锚：**“吃、动、戒、心、睡”**——五个字记住生活方式干预。

### 3.9 随访计划与依从性提升

**随访计划**要回答：**谁、多久一次、用什么方式、看什么指标、异常怎么办**。依从性提升可归为三条主线：

- **方案层面**：**简化方案**（先改 1~2 个行为，不贪多）+ **共同决策**（让客户参与定目标，嵌进他的生活节奏）；
- **机制层面**：**提醒机制**（短信 / 微信 / 电话、打卡、家庭支持）+ **正向反馈**（肯定微小进步，不只盯“没做到”）；
- **关系层面**：**降低门槛**（解决没时间、没场地、太贵、不会做）＋ **建立关系**（稳定、尊重、不评判的沟通本身就能提升依从性）。

### 3.10 干预效果评价

| 评价类型 | 评什么 | 举例 |
|---------|-------|------|
| **过程评价** | 干预**做了没有、做得怎么样** | 覆盖率、到课率、随访完成率、材料发放数、执行质量 |
| **效果评价** | 干预**产生了什么变化** | 知识知晓率、行为改变率、生理指标变化、满意度、生活质量 |

**近期效果**看知识、态度、行为的变化；**远期效果**看发病、并发症、生活质量等（多用于群体项目）。评价要**有基线**才能对比——干预前测一次是关键动作。

> 记忆锚：**过程评价看“我做了没有”，效果评价看“他变了没有”**。

### 3.11 客户沟通与健康服务营销的合规边界

**沟通一般框架**：建立关系 → 了解需求与期望 → 说明服务内容与边界 → 共同制定方案 → 定期反馈与调整。

- **可以做的**：讲清服务内容、频次、价格与团队资质；用真实体验做说明；
- **绝对不做的**：**不夸大疗效**、不承诺“包治”“根治”“保证见效”；不替代医生做诊断与用药建议；不制造焦虑、不恐吓式推销；不使用未经许可的“疗效数据”与客户隐私信息。

> 记忆锚：**“说清做什么可以，保证治好不行”**。

健康管理师的**证书效力、报考条件、补贴与评价安排，以备案评价机构与当地人社部门当次通知为准**。

## 🧠 记忆工具箱

### 口诀速记

- 概念层级：**“教育是手段，促进是打法”**；
- 知信行与三大理论：**“知是地基、信是发动机、行是终点”**，**“信念管开始、阶段管进度、认知管坚持”**；
- 方案与生活方式：**“目标、内容、频次、责任人、评价、转诊”**，**“吃、动、戒、心、睡”**；
- 两类评价：**“过程看做了没，效果看变了没”**。

### 场景锚点

- **体检中心**：用**个别咨询**解读报告，复查提醒靠短信 / 微信推送（相当于给“行动提示”）；
- **社区卫生服务中心**：**讲座 + 小组活动 + 同伴教育**做慢病自我管理，先判**跨理论阶段**再定策略；
- **健康管理公司 / 企业健康管理**：客户方案必须落成**可测目标 + 频次 + 责任人**；企业场景再加**环境支持**（食堂改菜品、工间操、戒烟支持），比只发手册有效；
- **养老与医养机构**：材料要**大字、图文、放慢语速**，充分考虑听力与认知状况；
- **月子中心**：以**个别咨询 + 小组课堂**为主，涉及母婴医学问题一律**协助转诊，不做医疗判断**。

## ⚠️ 易错提醒

- **错误认知**：健康教育就是“发传单、搞讲座”。纠正：健康教育是**有计划、有组织、有评价**的干预活动，核心是**行为改变**，只发材料不算完成干预；
- **错误认知**：讲清楚了人就会改（把知信行等同于“讲了就会改”）。纠正：知 → 信 → 行之间会**断裂**，还要解决信念与条件障碍，配合技能训练与环境支持；
- **错误认知**：健康促进只是健康教育的另一个名字。纠正：健康促进**包含**健康教育，还强调政策、环境与服务支持，范围更大；
- **错误认知**：评价就是发一张满意度问卷。纠正：满意度只是**过程 / 反馈指标之一**，效果评价要看知识、行为与生理指标的**前后对比**；
- **错误认知**：方案里写满“提高意识、加强锻炼”就算方案。纠正：没有**可测目标、频次与责任人**的口号既无法执行也无法评价；
- **错误认知**：为了客户依从性好就承诺效果。纠正：**不得夸大疗效、不得承诺治疗效果**，涉及诊疗一律转诊；证书与补贴政策**以备案评价机构与当地人社部门当次通知为准**。
