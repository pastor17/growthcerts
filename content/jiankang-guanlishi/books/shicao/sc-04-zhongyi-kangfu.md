## 考点梳理

### 4.1 中医基础常识框架（只考概念，不考方药）

- **阴阳**：对事物**相互对立又相互依存**两类属性的概括。四个要点：**对立制约、互根互用、消长平衡、相互转化**；
- **五行**：木、火、土、金、水五类属性及其**相生相克**关系。相生为木生火、火生土、土生金、金生水、水生木；相克为木克土、土克水、水克火、火克金、金克木；
- **脏腑**：**五脏**（心、肝、脾、肺、肾）主“藏精气”；**六腑**（胆、胃、小肠、大肠、膀胱、三焦）主“传化水谷”；
- **气血津液**：**气**主推动、温煦、防御、固摄、气化；**血**主濡养；**津液**滋润濡养。三者相互化生；
- **经络**：运行气血、联系脏腑肢节、沟通内外的**通道系统**，含**十二正经**与**奇经八脉**。

> 记忆锚：**“阴阳说关系、五行说联系、脏腑说功能、气血说物质、经络说通路”**。

本节只作**教材性常识框架**；涉及具体辨证标准、诊断与治疗，**以现行临床指南与教材为准，本站不提供医疗建议**。

### 4.2 中医养生的基本原则

| 原则 | 含义 | 落地做法（一般方向） |
|------|------|-------------------|
| **顺应四时** | 人与自然界相应，**春夏养阳、秋冬养阴** | 作息、衣着、饮食随季节调整 |
| **形神共养** | 既养**形体**又养**精神** | 运动与情志调摄并重 |
| **饮食有节** | 定时定量、寒热适宜、不偏嗜 | 三餐规律、七八分饱、少生冷肥甘 |
| **起居有常** | 作息规律、睡眠充足 | 固定起卧时间，不熬夜 |
| **不妄作劳** | 劳逸结合，**形劳而不倦** | 运动适度，避免过劳与久坐久视 |

> 记忆锚：**“顺四时、养形神、节饮食、常起居、不妄劳”**——五句话就是养生总纲。

### 4.3 四季养生的一般要点

| 季节 | 一般特点 | 养生方向（常识层面） |
|------|---------|-------------------|
| **春** | 万物生发 | **夜卧早起**、舒展形体、情志舒畅、饮食清淡升发 |
| **夏** | 阳气旺盛 | **夜卧早起**、适度出汗、不贪凉过食生冷、注意防暑 |
| **秋** | 燥气当令 | **早卧早起**、注意润燥、适度增衣、收敛情志 |
| **冬** | 阳气潜藏 | **早卧晚起**（待日光）、注意保暖、减少大汗、蓄养精气 |

> 记忆锚：**“春夏可稍晚睡早起，秋早睡早起，冬早睡晚起还要等太阳”**。

### 4.4 体质辨识与养生方向（一般口径）

**体质辨识**是对人群**生理与心理特征**的**分类描述**，用于养生与健康管理的**方向性指导**，**不是疾病诊断**。

| 体质类型 | 常见倾向（通俗描述） | 养生方向 |
|---------|-------------------|---------|
| **平和质** | 体形匀称、面色红润、精力充沛 | 饮食有节、规律运动、保持平衡 |
| **气虚质** | 易疲乏、气短、易感冒 | 健脾益气方向、避免过劳、缓和运动 |
| **阳虚质** | 畏寒怕冷、手足不温 | 温阳方向、注意保暖、少食生冷 |
| **阴虚质** | 手足心热、口燥咽干 | 滋阴润燥方向、避免辛辣燥热、规律作息 |
| **痰湿质** | 体形偏胖、腹部松软、易困倦 | 健脾化湿方向、控制体重、加强运动 |
| **湿热质** | 面垢油光、口苦口黏 | 清热利湿方向、少油腻辛辣、戒烟限酒 |
| **血瘀质** | 面色偏暗、易现瘀斑 | 活血方向、适度运动、避免久坐 |
| **气郁质** | 情绪低落、易紧张焦虑 | 疏肝解郁方向、多交流、增加户外活动 |
| **特禀质** | 易过敏、体质特殊 | 避免过敏原、饮食清淡、必要时就医 |

> 记忆锚：九种体质 = **“平、气、阳、阴、痰、湿（热）、血、郁、特”**——平和是理想型。

体质调理只写**生活与养生方向**，**不写方药与治疗**；具体调治**以现行临床指南与教材为准，本站不提供医疗建议**。

### 4.5 情志调摄与饮食调养

**情志调摄（一般原则）**

- 保持**心情舒畅、情绪稳定**，避免长期忧思恼怒；常用方法有倾诉交流、音乐书画、呼吸放松、规律运动、规律作息；
- 出现持续情绪低落、焦虑并影响生活时，**及时转介心理或医疗专业服务**。

**饮食调养（一般原则）**

- **定时定量、细嚼慢咽、七八分饱**，**寒热适宜**（少贪生冷，也不宜过食辛辣燥热）；
- **五味不偏、粗细搭配**，并结合**季节、体质与个人耐受**调整，不偏嗜、不暴饮暴食。

### 4.6 常用非药物调理方式的保健定位

| 方式 | 一般内容 | 定位 |
|------|---------|------|
| **食疗** | 用日常食物及其食性做搭配调理 | **日常保健**，不能替代药物治疗 |
| **穴位按摩** | 自我按压保健穴位、缓解疲劳 | **保健与放松**，不替代针灸与诊疗 |
| **八段锦** | 八节动作，柔和缓慢、配合呼吸 | **传统运动养生**，增强体质与柔韧 |
| **太极拳** | 以意导动、动作圆缓 | **运动养生与平衡训练**，适合中老年 |
| **五禽戏** | 模仿虎鹿熊猿鸟动作 | **传统运动养生**，活动关节与肌力 |

以上均属**保健与运动养生**范畴，**不替代医疗**；有基础疾病、运动禁忌或急性症状者，先咨询医生并**以现行临床指南与教材为准，本站不提供医疗建议**。

> 记忆锚：**“食疗、按穴、八段锦、太极、五禽戏——都是养生，不是治病”**。

### 4.7 康复医学基础（六个概念别混）

| 概念 | 做什么 | 一句话区分 |
|------|-------|-----------|
| **康复评定** | 评估功能水平与障碍（运动、认知、言语、日常生活能力） | **先评定，后康复** |
| **物理治疗（PT）** | 运动训练、手法与物理因子等 | 管**大运动与功能活动** |
| **作业治疗（OT）** | 训练**日常生活活动**与工作能力，必要时改造环境、适配辅具 | 管**生活与做事** |
| **言语治疗（ST）** | 言语、语言、吞咽与沟通训练 | 管**说话、吃饭、交流** |
| **康复护理** | 体位、皮肤、二便管理与并发症预防 | 管**护理与并发症预防** |
| **康复工程** | 假肢、矫形器、轮椅、助行器等辅具配置 | 管**用工具补功能** |

- **康复目标**：不是“治愈疾病”，而是**最大限度恢复功能、提高生活自理与社会参与能力**；
- **介入时机**：在医学条件允许的前提下**宜早期介入**，与临床治疗**并行**而非等病好之后。

> 记忆锚：**“评定打头，PT 管动、OT 管做、ST 管说、护理管照顾、工程管工具”**。

### 4.8 慢病康复与功能锻炼的一般原则

- **个体化**：按疾病类型、功能水平与耐受度定方案（具体方案**以现行临床指南与教材为准，本站不提供医疗建议**）；
- **循序渐进 + 功能导向**：强度由低到高、时间由短到长，先练**柔韧与平衡**，再增**力量与耐力**；优先训练**穿衣、进食、行走、如厕**等日常生活活动（对应作业治疗思路）；
- **安全第一**：识别**停止运动的信号**（胸闷胸痛、明显气促、头晕、心悸等），出现即停止并就医；
- **长期监测 + 多学科协作**：记录指标与主观感受并按随访计划动态调整；医生、护士、康复治疗师、营养师、心理与社工共同参与。

### 4.9 中医养生与现代健康管理结合的思路

- 用**健康管理流程**（信息采集 → 风险评估 → 干预 → 随访评价）承载中医养生的**理念与方法**；
- **体质辨识 + 常规体检指标**互为补充：体质给**养生方向**，指标给**客观评价**；
- 把**八段锦、太极拳**等作为**运动处方**的可选形式，纳入频次与强度管理；把**饮食有节、起居有常、情志调摄**转化为**可执行、可随访**的行为目标；
- 明确**分层边界**：养生保健属**健康管理服务**；诊断、用药、针灸推拿处方属**医疗行为**，须由具备资质的医疗机构与人员完成。

> 记忆锚：**“中医给方向，管理给流程，医院管治病”**。

### 4.10 明确边界（必读）

- 本章**不提供针灸方药处方、不提供诊断与用药建议、不替代临床诊疗**；内容属**教材性常识框架**，体质分类与调理方向**仅供养生参考**；
- 涉及具体诊断标准、用药、治疗与疾病人群的康复方案，**以现行临床指南与教材为准，本站不提供医疗建议**；
- 健康管理师的**证书性质、报考条件与评价安排，以备案评价机构与当地人社部门当次通知为准**；
- 发现异常症状或指标，正确做法是**建议就医并协助转诊**，而不是“先用养生方法调一调”。

## ⚠️ 易错提醒

- **错误认知**：体质辨识相当于中医诊断。纠正：体质辨识是**人群分类与养生方向**工具，**不能作为疾病诊断**，也不用于开方用药；
- **错误认知**：养生保健可以替代治疗。纠正：食疗、穴位按摩、八段锦等属**保健与运动养生**，**不替代医疗**，有病症应就医；
- **错误认知**：康复就是按摩、推拿、扎针。纠正：康复是**以功能恢复为目标**的综合体系，含**评定、PT、OT、ST、康复护理与康复工程**，按摩只占很小一部分；
- **错误认知**：康复要等病完全好了再开始。纠正：康复**宜早期介入**、与临床治疗并行，前提是医学条件允许并由专业人员实施；
- **错误认知**：阴虚就该吃补阴的药、阳虚就该吃补阳的药。纠正：本章**只讲养生方向、不讲方药**，用药必须由医生辨证决定，**以现行临床指南与教材为准**；
- **错误认知**：考了证就能上岗诊治。纠正：健康管理师从事的是**健康管理与养生保健服务**，诊疗行为需相应执业资质；证书与评价安排**以备案评价机构与当地人社部门当次通知为准**。
