> ⚠️ **必读声明（请先看这三条）**
> 1. 本页数值均为**教材与公开指南中的常见参考口径，仅供学习与记忆**，**不是诊断标准，也不构成本站结论**；
> 2. **一切指标判断、控制目标与治疗建议，以现行临床指南与教材为准，并须由专业医务人员个体化判断**——**本站不提供医疗建议**；
> 3. **考核范围、题型与合格标准以备案评价机构与当地人社部门当次通知为准**。

## 一、核心主线与三级预防（最先记）

```text
健康管理流程：信息采集 → 健康风险评估 → 健康干预 → 随访与效果评价
              （了解健康）  （认识风险）    （改善健康）   （盯住结果）
```

| 三级预防 | 做什么 | 典型动作 |
|---------|-------|---------|
| **一级（病因预防）** | 防发病 | 健康教育、控烟限酒、合理膳食、身体活动、疫苗接种 |
| **二级（三早）** | 早发现早诊断早治疗 | 健康体检、筛查、风险人群随访 |
| **三级（临床预防）** | 防并发症、促康复 | 规范治疗配合、康复训练、并发症监测、健康管理随访 |

## 二、常见慢病指标与控制目标（**一般参考口径**）

| 指标 | 常见参考口径（**教材/指南通用，非诊断标准**） | 说明 |
|------|------------------------------------------|------|
| **血压** | 理想血压常用口径 **<120/80 mmHg**；**≥140/90 mmHg** 为高血压常用的诊断界值口径 | **控制目标个体化**（合并糖尿病、肾病等人群可能更严格）；**以现行指南为准** |
| **空腹血糖** | 常用参考区间 **3.9~6.1 mmol/L**；糖尿病诊断界值口径 **≥7.0 mmol/L** | **以现行指南与教材为准** |
| **餐后 2 小时血糖** | 糖尿病诊断界值口径 **≥11.1 mmol/L**（OGTT） | **以现行指南与教材为准** |
| **糖化血红蛋白（HbA1c）** | 常用控制目标口径 **<7%** | **按年龄与并发症个体化**，**以现行指南为准** |
| **总胆固醇（TC）** | 常用参考上限口径约 **5.2 mmol/L** | **按心血管风险分层管理**，**以现行指南为准** |
| **甘油三酯（TG）** | 常用参考上限口径约 **1.7 mmol/L** | 同上 |
| **低密度脂蛋白（LDL-C）** | **目标值按危险分层设定**（越低危越宽、越高危越严） | **具体目标以现行指南为准**，不适合统一背一个数 |
| **高密度脂蛋白（HDL-C）** | 常用口径 **≥1.0 mmol/L**（男性）/ **≥1.3 mmol/L**（女性） | 同上 |
| **血尿酸** | 高尿酸血症常用界值口径：男 **>420 μmol/L**、女 **>360 μmol/L** | **以现行指南与教材为准** |
| **体质指数（BMI）** | 中国成人常用标准见下表 | **中国标准**，非 WHO 标准 |

> ⚠️ **记忆原则**：**记“口径方向与量级”，不背死“治疗目标”**；考试若问控制目标，**优先答“个体化、以现行指南为准”**。

## 三、体质指数（BMI）与腰围标准（中国成人常用口径）

**BMI = 体重（kg）÷ 身高（m）²**

| 分类 | BMI 常用界值（中国标准） |
|------|----------------------|
| **体重过低** | **< 18.5** |
| **正常** | **18.5 ~ 23.9** |
| **超重** | **24.0 ~ 27.9** |
| **肥胖** | **≥ 28.0** |

**中心型肥胖（腰围）常用界值（中国标准）**

| 性别 | 腰围常用界值 |
|------|-------------|
| **男性** | **≥ 90 cm**（中心型肥胖口径） |
| **女性** | **≥ 85 cm**（中心型肥胖口径） |

> **记忆锚**：**“BMI 18.5 / 24 / 28 三关口，腰围男 90 女 85”**（**中国标准，以现行指南与教材为准**）。

## 四、营养素与膳食参考（**一般口径**）

| 项目 | 常见参考口径 | 说明 |
|------|-------------|------|
| **三大产能营养素供能比** | 蛋白质 **10%~15%**、脂肪 **20%~30%**、碳水化合物 **50%~65%** | **以最新版《中国居民膳食指南》与教材为准** |
| **膳食纤维** | 成人常用建议约 **25~30 g/天** | 同上 |
| **食盐** | 建议 **< 5 g/天** | 同上 |
| **添加糖** | 建议 **< 25 g/天**（不超过 50 g/天） | 同上 |
| **饮水** | 成人常用建议约 **1500~1700 mL/天** | 视气候、活动量与身体状况调整 |
| **身体活动** | 一般成人建议**每周 150 分钟中等强度**有氧活动 + **每周 2 次**抗阻练习 | **一般人群口径**；**慢病人群须个体化，以现行指南为准** |

**六大营养素 + 膳食纤维（功能与来源速记）**

| 营养素 | 主要功能 | 主要来源 |
|--------|---------|---------|
| **蛋白质** | 构成与修复组织、酶与激素 | 鱼禽肉蛋奶、豆类、谷类 |
| **脂类** | 供能、构成细胞膜、必需脂肪酸 | 植物油、坚果、动物性食物 |
| **碳水化合物** | 主要供能 | 谷薯类、水果、糖类 |
| **维生素** | 参与代谢与生理调节 | 蔬菜水果、动物性食物（**脂溶性需脂肪协助吸收**） |
| **矿物质** | 构成骨骼与调节生理功能 | 奶类、豆类、蔬果、海产品 |
| **水** | 溶剂与运输、调节体温 | 饮水与食物中的水 |
| **膳食纤维** | 促肠道蠕动、调节血糖血脂 | 全谷物、蔬菜、水果、豆类 |

## 五、健康风险评估流程（技能高频）

| 步骤 | 具体动作 | 产出 |
|------|---------|------|
| **① 信息采集** | 问卷、体测、体检报告、生活方式 | 基础数据 |
| **② 危险因素识别** | 分**可改变 / 不可改变** | 危险因素清单 |
| **③ 风险计算与分层** | 按评估工具打分、分层（低/中/高） | 风险分层结论 |
| **④ 报告生成** | 汇总指标、风险等级、主要问题 | 评估报告 |
| **⑤ 解读与风险沟通** | 讲清“风险在哪、先改什么” | 客户共识 |
| **⑥ 干预建议 + 随访复评** | 定可测目标、约定复评时间 | 干预方案 + 随访表 |

**关键概念速记**

| 概念 | 一句话 |
|------|-------|
| **相对危险度** | 与参照人群相比，**风险高多少倍** |
| **绝对危险度** | 一段时间内**实际发生的概率** |
| **风险年龄/生物年龄** | 把风险换算成<strong>“相当于多大年龄的健康风险”</strong>，更易沟通 |

> **记忆锚**：**“采集 → 识别 → 分层 → 报告 → 沟通 → 建议随访”**——**技能题少写任何一步都可能丢分**。

## 六、行为改变与健康教育速记

| 理论 | 关键词（答题写出即得分） |
|------|----------------------|
| **知信行（KAP）** | 知识 → 信念/态度 → 行为（**知而不行是常态**） |
| **健康信念模式** | 易感性、严重性、收益、障碍、自我效能、行动提示 |
| **跨理论模型** | 前意向 → 意向 → 准备 → 行动 → 维持（**分阶段干预**） |
| **社会认知理论** | 自我效能、观察学习、环境与行为互动 |

**健康教育方案五要素**：**对象 → 目标（可测）→ 内容与形式 → 实施步骤 → 效果评价**。

## 七、健康档案 SOAP（技能必写）

```text
S（Subjective 主观）：客户自述的症状、生活习惯、主诉
O（Objective 客观）：身高体重、BMI、腰围、血压、血糖、体检结果等测量与检查
A（Assessment 评估）：基于 S+O 的风险方向判断（不做临床诊断）
P（Plan 计划）  ：干预目标、具体动作、频次、复评时间、需转诊/就医的事项
```

> **记忆锚**：**“客户说 → 测出来 → 判断方向 → 定计划”**。

## 八、技能答题四套骨架

| 题型 | 骨架 |
|------|------|
| **评估类** | 采集内容 → 危险因素（可改变/不可改变）→ 风险分层 → 主要问题 → 建议 → 复评时间 |
| **干预类** | 目标（可测）→ 膳食 → 身体活动（**FITT 四要素**）→ 戒烟限酒 → 心理与睡眠 → 频次与随访 → 效果评价 |
| **教育类** | 需求评估 → 目标 → 内容（知信行）→ 形式与材料 → 实施步骤 → 效果评价 |
| **档案类** | **按 SOAP 四段写**，补**时间、签名、隐私与授权说明** |

> **动作化原则**：把“加强运动”改成 **“每周 3 次、每次 30 分钟快走（以个人耐受为准），4 周后复评”**。

## 九、中医养生与康复速记

| 项目 | 速记 |
|------|------|
| **养生原则** | 顺应四时、形神共养、饮食有节、起居有常、不妄作劳 |
| **九种体质** | 平和、气虚、阳虚、阴虚、痰湿、湿热、血瘀、气郁、特禀（**只记养生方向，不记方药**） |
| **常用保健方法** | 食疗、穴位按摩、八段锦、太极拳、五禽戏（**保健定位，不替代医疗**） |
| **康复治疗手段** | 物理治疗（PT）、作业治疗（OT）、言语治疗（ST）、康复护理、康复工程 |
| **康复流程** | 康复评定 → 制定目标 → 治疗与训练 → 再评定 → 调整 |

## 十、边界与合规（答题与工作都必守）

```text
不做诊断      → 指标异常一律“建议就医评估”
不开药、不调药 → 只做用药提醒与复诊提醒
不承诺疗效    → 不使用“治好、根治、替代药物”等表述
不越界操作    → 不针灸、不推拿治疗、不做治疗性康复操作
先授权后处理  → 健康信息属敏感个人信息，最小必要、脱敏保存
```

## 十一、考场分配

```text
理论（客观题）：单选 ≤40 秒/题；多选不确定先标记；留 10 分钟回看
技能（主观题）  ：先写骨架标题 → 逐条展开；每问至少 3~4 条；宁多勿漏
                所有方案写“频次 + 时长 + 复评时间”
                越界问题 → 写“建议就医”再转向生活方式与随访
```
