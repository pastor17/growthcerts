> **先记住三句话**：
> 1. 健康管理师**已退出国家职业资格目录**，现在是**职业技能等级认定**，由**经人社部门备案的评价机构**组织评价并发证；
> 2. **报考条件、可报等级、考核方式、批次时间各机构不同**——**以备案评价机构与当地人社部门当次通知为准**；
> 3. **证书必须能在技能人才评价工作网（[osta.org.cn](http://www.osta.org.cn)）查到**，**查不到的一律不认**。

## 等级与报考条件

**等级设置（一般口径）**：**三级（高级）→ 二级（技师）→ 一级（高级技师）**，**三级是主流报考级别**。

**报考条件（**常见口径，仅供参考**）**

| 等级 | 常见申报条件方向 | 说明 |
|------|----------------|------|
| **三级（高级）** | 医药卫生类专业**大专及以上学历**；或**非医药卫生类专业大专及以上学历 + 相关工作年限 + 规定培训学时**；或医药卫生类专业**中专学历 + 更长工作年限 + 培训** | 各评价机构的学历、专业、年限与培训要求**不一致** |
| **二级（技师）** | 一般要求**已取得三级证书 + 从事本职业工作一定年限**（部分机构另有学历/成果要求） | **多以逐级申报为主** |
| **一级（高级技师）** | 一般要求**已取得二级证书 + 更长从业年限**（部分机构要求业绩或培训成果） | 报考人数相对少 |

> ⚠️ **重点提醒**：
> - **上述仅为常见口径，不是全国统一标准**。**职业技能等级认定由各评价机构依据其评价规范执行**，**学历、专业、工作年限、培训学时、是否允许跨级申报都可能不同**；
> - **有些机构要求先完成规定学时的培训**，有些则允许符合条件的考生直接申报；
> - **不要相信“无条件报考”“零基础直接考二级/一级”**——**以备案评价机构与当地人社部门当次通知为准**，报名前**直接向评价机构索取当批次的申报条件原文**。

## 怎么找正规评价机构（osta.org.cn 查询）

**唯一可靠的判断标准**：**这家机构是否在人社部门备案、其颁发的证书能否在技能人才评价工作网查到。**

**查询与核实步骤（示意）**：

1. 打开**技能人才评价工作网**（[osta.org.cn](http://www.osta.org.cn)），找到**职业技能等级认定**相关栏目；
2. 查询**备案的用人单位和社会培训评价组织名单**（各地人社部门官网通常也会公示本地区备案机构名单）；
3. **核对机构全称**是否与你接触的招生方**完全一致**（注意“XX 教育科技”“XX 咨询”经常**只是代招生中介，不是评价机构本身**）；
4. 向机构索取：**备案证明/备案号、当批次评价公告、证书样本、查询方式**；
5. **打电话或到当地人社部门职业技能鉴定（评价）管理部门核实**该机构与该项目是否在备案范围内；
6. 拿到证书后，**再次在技能人才评价工作网查验**证书信息。

**核实时必须问清的六个问题**

| # | 要问的问题 | 为什么重要 |
|---|-----------|-----------|
| 1 | **评价机构的全称与备案号是什么？** | 判断它是不是**备案评价机构**，还是**中介** |
| 2 | **证书在哪查询？** | 正规答复**只能是技能人才评价工作网（osta.org.cn）** |
| 3 | **本批次申报条件原文？** | 学历/专业/年限/培训要求**必须看到书面文件** |
| 4 | **考哪两科、什么形式、多少分合格？** | 避免“只考一科”“线上包过”等异常安排 |
| 5 | **费用包含什么？** | 区分**评价费**与**培训费、教材费、补考费** |
| 6 | **不合格怎么办？能否补考？** | 正规流程**有明确的补考安排** |

> **判断锚点**：**“备案机构 + 官网可查 + 书面条件 + 明确补考”= 正规；“包过 + 免考 + 内部名额 + 只发证不考试”= 骗局**。

## 报名流程与材料

**流程（示意，具体以当次通知为准）**：

```text
① 确认条件（对照当批次申报条件原文）
   ↓
② 选择备案评价机构（核对备案资质）
   ↓
③ 提交报名材料 + 缴费（区分评价费与培训费）
   ↓
④ 参加规定培训（如该机构要求）
   ↓
⑤ 领取准考证/考试通知（核对时间、地点、形式）
   ↓
⑥ 参加理论知识与操作技能考核
   ↓
⑦ 查询成绩 → 合格者取得证书
   ↓
⑧ 在技能人才评价工作网查验证书信息
```

**常见材料（以当次通知为准）**

| 材料 | 说明 |
|------|------|
| **身份证明** | 身份证原件及复印件/扫描件 |
| **学历证明** | 毕业证书、学历认证材料（**按机构要求，部分需学信网材料**） |
| **工作年限证明** | 单位出具的在职/从业证明（**按机构要求，部分需社保记录**） |
| **培训学时证明** | 如该机构要求先培训，则需相应结业证明 |
| **照片与报名表** | 按机构规定的规格与格式提交 |
| **其他** | 部分机构要求健康承诺书、诚信承诺书等 |

> ⚠️ **提醒**：**材料造假后果严重**（取消成绩、撤销证书，严重的承担法律责任）。**不要接受任何“帮你包装条件”“代做工作证明”的服务**——**这是最常见的报名陷阱**。

## 考试形式（理论 + 操作技能）

**两科结构（一般口径）**

| 科目 | 一般考查内容 | 常见形式 |
|------|-------------|---------|
| **理论知识** | 健康管理概论、医学基础、常见慢性病、营养与食品安全、身体活动、心理健康、健康教育、健康信息学、健康风险评估、服务与营销、中医养生、康复医学、健康保险 | **客观题为主**（单选、多选、判断等） |
| **操作技能** | 健康信息采集与档案、健康风险评估与分析、健康教育与干预方案、随访与效果评价、中医养生与康复指导 | **案例/情景分析、技能操作类题目**（部分机构含现场或模拟操作） |

**常见考务要素（**均需以当次通知为准**）**

- **合格要求**：一般**两科均须合格**；**是否允许补考单科、成绩是否保留**，**各机构规定不同**；
- **考试形式**：**机考、纸笔、线上或现场实操**均可能出现，**不同机构差异很大**；
- **题型与题量**：以评价机构公布的**考核方案**为准；
- **合格标准**：常见为**百分制 60 分合格**的**一般口径**，**但各机构可能不同**，**以当次通知为准**。

> ⚠️ **重要提醒**：**本站不预设任何一家评价机构的考务细节**。报名后**务必索取该机构的考核方案（科目、题量、形式、时长、合格线、补考规则）**，按方案备考。**操作技能不是“背一背就能过”，要按流程动手练**（见 [大纲与教材](/jiankang-guanlishi/syllabus/) 与 [备考笔记](/jiankang-guanlishi/notes/)）。

## 证书查询与补贴政策

**证书查询**

- **唯一官方查询渠道**：**技能人才评价工作网**（[osta.org.cn](http://www.osta.org.cn)）；
- 查询需要**姓名 + 身份证号 + 证书编号**等信息；
- **查不到 = 证书无效**（或信息尚未上报，需向评价机构核实上报进度）；
- 部分机构同时发放**电子证书**，仍以**官网可查**为准。

**补贴、积分与个税（**均以当地政策为准**）**

| 政策 | 一般情况 | 必须注意 |
|------|---------|---------|
| **技能提升补贴** | 部分地区对**取得职业技能等级证书**的人员给予补贴 | **是否适用、补贴标准、申领时限与所需材料，以当地人社部门当次政策为准**；**通常要求证书在官网可查、且在规定时限内申领** |
| **积分落户/积分入学** | 部分地区将职业技能等级证书纳入积分 | **是否加分、加多少分、对等级与职业（工种）是否有限制，以当地积分政策为准** |
| **个税继续教育扣除** | 部分继续教育支出可按规定扣除 | **是否适用、扣除标准以现行税收规定与税务部门口径为准** |
| **企业/单位津贴** | 部分单位对持证人员发放岗位津贴或报销费用 | **以本单位制度为准** |

> ⚠️ **统一口径**：**任何补贴、积分、扣除与津贴，都可能因地区、年份、政策调整而变化**——**一律以当地人社部门及相关部门当次政策为准**，**报名前先看当地官方文件，不要相信招生方的口头承诺**。

## ⚠️ 防骗提醒

**这是本页最重要的一节。** 健康管理师因“已退出国家职业资格目录、改由评价机构认定”，成为**招生骗局高发领域**：

| 骗术话术 | 真相 |
|---------|------|
| **“包过”“保过”“不过退费”** | 正规评价**不存在包过**；所谓退费往往附带**苛刻条件**或机构直接跑路 |
| **“免考拿证”“不用考试直接出证”** | **假证或无效证**——正规证书**必须经过考核**并**在官网可查** |
| **“国家职业资格证书”“职业资格目录内证书”** | **错误表述**——健康管理师**已退出国家职业资格目录**，现为**职业技能等级证书**（**以当次政策为准**） |
| **“人社部直接发证”“人社部指定唯一机构”** | **不实**——由**备案评价机构**发证，**不存在唯一指定机构** |
| **“最后一批”“政策要取消，赶紧报”** | **常见的紧迫感逼单话术**，用“名额有限”“今天截止”催你交钱 |
| **“证书能挂靠，一年多赚几万”** | **虚假且违规**——健康服务类证书**无挂靠市场**，**挂靠存在法律与合规风险** |
| **“考完包就业/包推荐高薪工作”** | **无法兑现**——就业取决于**个人能力与市场**，任何“包就业”承诺都不可信 |
| **“先交钱占名额，条件我们帮你搞定”** | **材料造假风险由你承担**（取消成绩、撤销证书），且**费用难追回** |
| **“我们是官方授权招生点”** | **必须核实机构全称与备案情况**；**中介≠评价机构** |
| **“查询网站是他们给的那个链接”** | **只认技能人才评价工作网（osta.org.cn）**；**仿冒查询站是常见套路** |

**五条自保原则**

1. **只认官网**：报名前后**都在 osta.org.cn 核实**机构与证书；
2. **要书面材料**：**当批次评价公告、申报条件、考核方案、收费标准**，**要原件或官方链接**；
3. **不签“包过”协议**：**任何承诺结果的文件都不具有正当性**，签了也难维权；
4. **不造假材料**：**学历、工作年限一律真实**，“帮你包装”的一律拒绝；
5. **保留证据**：**合同、收据、聊天记录、转账凭证**全部留存，**遇到诈骗及时向当地人社部门与公安机关举报**。

> ⚠️ **最终口径**：**评价机构资质、报考条件、考核方式、证书范围、补贴与积分政策，一律以备案评价机构与当地人社部门当次通知为准**；**医学内容以现行临床指南与教材为准，本站不提供医疗建议**。
