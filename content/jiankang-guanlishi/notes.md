## 该记什么（理论与技能清单）

### ① 理论知识清单（按“必背 → 要懂 → 了解”分层）

| 层次 | 模块 | 必记的关键点 |
|------|------|-------------|
| **必背** | **健康管理概论** | 定义、**基本流程（信息采集 → 风险评估 → 干预）**、服务四特点（标准化/量化/个体化/系统化）、**三级预防** |
| **必背** | **常见慢性病** | 慢性病**共同特点**与**危险因素分类**；高血压、糖尿病、血脂异常、肥胖、痛风等的**危险因素 + 生活方式干预方向** |
| **必背** | **营养与食品安全** | **六大营养素 + 膳食纤维**的功能与主要来源；**平衡膳食与膳食宝塔层级**；**膳食调查方法**及优缺点；食源性疾病与食品污染类型 |
| **必背** | **健康风险评估** | **评估流程六步**（采集 → 识别 → 分层 → 报告 → 解读 → 建议/随访）、相对/绝对危险度概念、报告解读与风险沟通 |
| **必背** | **健康教育** | 健康教育与健康促进、**健康素养**、**知信行（KAP）**、三种行为改变理论的关键词 |
| **要懂** | **身体活动** | 身体活动分类、**运动处方 FITT**、**运动前风险筛查**、不同人群活动方向 |
| **要懂** | **健康信息学** | 采集内容与方法、**健康档案（个人/家庭/社区）**、**SOAP 格式**、数据质量与隐私保护 |
| **要懂** | **心理健康** | 心理健康标准维度、压力与应激、**常见心理困扰的识别与转介边界** |
| **要懂** | **服务与营销** | 服务内容与形式、**服务包设计**、客户沟通与效果评价、合规边界 |
| **了解** | **中医养生** | 养生原则、四季养生、**体质辨识九类方向**、常用保健方法（八段锦/太极/穴位按摩的**保健定位**） |
| **了解** | **康复医学** | **康复评定 + 物理/作业/言语治疗 + 康复护理 + 康复工程**的区别 |
| **了解** | **健康保险** | 健康险类型、健康管理与保险的结合 |

### ② 操作技能清单（按“动作 + 交付物”记）

| 技能方向 | 必须会做的动作 | 交付物（考试要写出来） |
|---------|--------------|---------------------|
| **信息采集与档案** | 问卷/问询、规范体测、体检报告解读、档案更新 | **一份 SOAP 健康档案记录** |
| **风险评估** | 危险因素识别、风险分层、报告解读、风险沟通 | **评估报告要点 + 分层结论 + 干预建议** |
| **健康教育** | 需求评估、方案设计、材料制作、组织实施、效果评价 | **一份健康教育方案（含评价方式）** |
| **干预与随访** | 定可测目标、写动作化方案、跟踪执行、处理依从性、调整方案 | **一份干预方案 + 随访计划表** |
| **中医养生与康复指导** | 讲养生原则与体质方向、指导保健锻炼、督促功能锻炼 | **养生/锻炼建议（保健层面，不涉治疗）** |

> ⚠️ **技能题铁律**：**流程要闭环（采集→评估→建议→随访）、动作要具体（频次/时长/复评时间）、边界要守住（不诊断、不开药、不承诺疗效）**。

## 记忆方法（口诀与表格化）

### ① 主线口诀（先记这条，其他都挂在上面）

> **“采集 → 评估 → 干预 → 随访”**（**了解健康 → 认识风险 → 改善健康 → 盯住结果**）

**健康管理三步骤** → **“查、评、管”**（采集信息、评估风险、管理干预）。

### ② 三级预防口诀

> **“一级防病因、二级三早查、三级防并发”**——**一级病因预防（健康教育/疫苗/控烟）、二级早发现早诊断早治疗（筛查/体检）、三级临床预防与康复（防并发症、促功能恢复）**。

### ③ 危险因素分类

> **“改不了的（年龄、性别、遗传）+ 改得了的（烟、酒、吃、动、胖、压、三高）”**——**考试与工作都围绕“改得了的”做干预**。

### ④ 慢病记忆法：一病一张“三格卡”

| 卡片格 | 写什么 |
|--------|-------|
| **格 1：是什么** | 一句话定义/特点（如“以慢性高血糖为特征的代谢性疾病”） |
| **格 2：危险因素** | 3~5 条（超重肥胖、不合理膳食、身体活动不足、家族史等） |
| **格 3：干预方向** | 3 条生活方式方向（膳食、运动、戒烟限酒/心理） |

> 用这张三格卡刷完 **高血压、糖尿病、血脂异常、肥胖、痛风**，慢病模块就稳了。

### ⑤ 膳食记忆法

> **“宝塔从下往上：谷薯 → 蔬果 → 肉蛋奶豆 → 油盐”**；**“六营养素 + 纤维：蛋白、脂、糖、维、矿、水 + 纤”**。

### ⑥ 运动处方 FITT

> **“频（Frequency）、强（Intensity）、时（Time）、型（Type）”**——**答题时四个都要写到，少一个就是丢分点**。

### ⑦ 行为改变理论关键词卡

| 理论 | 关键词 |
|------|-------|
| **知信行（KAP）** | **知识 → 信念/态度 → 行为**（**知不等于信，信不等于行**） |
| **健康信念模式** | **易感性、严重性、收益、障碍、自我效能、行动提示** |
| **跨理论模型** | **前意向 → 意向 → 准备 → 行动 → 维持**（**按阶段给不同干预**） |
| **社会认知理论** | **自我效能、观察学习、环境与行为互动** |

### ⑧ 档案 SOAP

> **“S 主观（客户说）、O 客观（测出来）、A 评估（判断风险方向）、P 计划（做什么、多久做）”**——**顺序不能乱**。

### ⑨ 体质辨识九类（记方向，不记方药）

> **“平和、气虚、阳虚、阴虚、痰湿、湿热、血瘀、气郁、特禀”**——**每一类只记 1~2 条养生方向**（如阳虚质注意保暖、少生冷；痰湿质清淡饮食、加强身体活动）。

### ⑩ 把口号变动作（技能题万能改写）

| 口号 | 改写为动作 |
|------|-----------|
| 加强运动 | 每周 3 次、每次 30 分钟快走（以个人耐受为准），4 周复评 |
| 少吃盐 | 用限盐勺、少吃腌制食品，记录 3 天饮食 |
| 早点睡 | 23:00 前上床、睡前 1 小时不看手机，记录 1 周 |

## 10 条避坑清单

| # | 坑 | 正确做法 |
|---|----|---------|
| 1 | 以为健康管理师**还是国家职业资格** | **已退出国家职业资格目录**，现为**职业技能等级证书**，由**备案评价机构**发证；**以当次政策为准** |
| 2 | 在**非备案机构**报名或相信“包过” | **先在 osta.org.cn 核实机构与证书可查性**；**包过/免考均为骗局** |
| 3 | 直接开始背细节，不建流程框架 | **先刻“采集 → 评估 → 干预 → 随访”主线**，再填知识点 |
| 4 | 只背慢病名称，不记危险因素与干预方向 | 用<strong>“三格卡”（是什么/危险因素/干预方向）</strong>逐病过一遍 |
| 5 | 把**具体指标数值**当绝对标准背死 | **以现行临床指南与教材为准**，记**参考口径与方向**，不背治疗目标 |
| 6 | 技能题只写建议，不写**采集与随访** | 技能题必须**闭环**：采集 → 评估 → 建议 → 随访，缺环节丢分 |
| 7 | 干预方案写成一堆口号 | **动作化**：谁、做什么、频次、时长、何时复评 |
| 8 | 越界答“诊断/用药/治疗” | **明确边界**：建议就医；健康管理师只做**生活方式与随访支持** |
| 9 | 忽视**隐私与授权** | 健康信息属**敏感个人信息**，**先授权、最小必要、脱敏**，按现行法规与机构制度执行 |
| 10 | 相信“有证必涨薪、必能领补贴” | **证是加分项**；**补贴与积分由当地政策决定**，**以当地人社部门当次政策为准** |

## 冲刺阶段安排

**考前 3 周**

| 时间 | 任务 |
|------|------|
| **第 1 周** | **回炉重点**：慢病（三格卡） + 营养 + 风险评估，各刷一遍错题 |
| **第 2 周** | **技能专项**：每天手写 1 套（评估报告要点 / 干预方案 / 健康教育方案 / SOAP 档案），限时 30 分钟 |
| **第 3 周** | **限时模拟 + 一页速记**：整卷模拟 2 次，其余时间只过 [一页速记](/jiankang-guanlishi/cheatsheet/) + 错题 |

**考前 3 天（只看这些）**

```text
① 一页速记（流程 + 慢病三格卡 + 营养素 + 评估六步 + FITT + SOAP）
② 错题本（只看得错过的题与解析）
③ 技能答题骨架（评估 / 干预 / 教育 / 档案 四套模板）
④ 边界提醒（不诊断、不开药、不承诺疗效、先授权）
```

**考场时间分配（理论）**

```text
单选：≤ 40 秒/题，先过一遍拿稳分
多选：不确定的先标记，别死磕（多选错一个常全错）
判断：读完立即作答，不反复改
留 10 分钟：回看标记题 + 检查答题卡
```

**考场时间分配（技能）**

```text
先写骨架标题，再逐条展开，保证“有结构分”
每个设问至少写 3~4 条，宁多勿漏
所有方案都写“频次 + 时长 + 复评时间”
遇到超范围问题（诊断/用药）→ 写“建议就医评估”并转向生活方式与随访
```

> **一句话策略**：**“主线流程 + 慢病三格卡 + 技能四套模板”**——**理论靠广度与框架，技能靠流程与动作化表述**。
>
> ⚠️ **最后一遍提醒**：**考核范围、题型与合格标准以备案评价机构与当地人社部门当次通知为准**；**医学内容以现行临床指南与教材为准，本站不提供医疗建议**。
