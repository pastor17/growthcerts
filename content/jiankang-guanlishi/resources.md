> **资源使用原则**：**官方渠道用来“核实”，权威机构资料用来“学知识”，本站精讲用来“抓重点、记得住”**。健康管理师**已转为职业技能等级认定**，**任何培训机构、博主整理的“考试范围”都不具备权威性**——**评价机构当次的通知与考核方案才是唯一依据**。

## 官方渠道

| 渠道 | 入口 | 用来做什么 |
|------|------|-----------|
| **技能人才评价工作网** | [osta.org.cn](http://www.osta.org.cn) | **核实备案评价机构**、**查询职业技能等级证书**（**唯一权威查询入口**） |
| **人力资源社会保障部** | [mohrss.gov.cn](https://www.mohrss.gov.cn) | 职业技能等级认定相关政策、国家职业资格目录（**核实“已退出目录”的口径**） |
| **当地人社部门官网** | 各省/市人社局网站 | **本地区备案评价机构名单、技能提升补贴与积分政策**（**以当地当次政策为准**） |
| **国家卫生健康委员会** | [nhc.gov.cn](https://www.nhc.gov.cn) | 健康中国行动、慢病防治、健康教育等**权威政策与科普口径** |
| **中国疾病预防控制中心** | [chinacdc.cn](https://www.chinacdc.cn) | 慢病、营养、免疫与公共卫生的**权威科普与监测信息** |
| **中国营养学会** | [cnsoc.org](https://www.cnsoc.org) | **《中国居民膳食指南》**、膳食营养素参考摄入量等**营养学权威口径** |
| **国家体育总局** | [sport.gov.cn](https://www.sport.gov.cn) | **全民健身指南**、身体活动与运动促进的**权威建议** |
| **国家法律法规数据库** | [flk.npc.gov.cn](https://flk.npc.gov.cn) | 个人信息保护、基本医疗卫生与健康促进法等**法律原文** |

> **核实顺序**：**先在 osta.org.cn 查机构 → 再到当地人社部门官网看政策 → 最后再谈报名交费**。**顺序错了，很容易先交钱后发现问题。**

## 免费学习资源

**优先顺序：权威公开资料 > 教材配套 > 公开课 > 自媒体**

| 资源类型 | 具体建议 | 注意 |
|---------|---------|------|
| **权威科普与指南** | 国家卫健委/中国疾控中心/中国营养学会/体育总局发布的**科普与指南（含膳食指南、身体活动建议）** | **指南版本会更新，以最新版为准** |
| **公开课与慕课** | 中国大学 MOOC 等平台的**营养学、运动医学、健康管理、流行病学、健康教育**入门课 | 选**有高校/机构署名**的课程，按需看，**不追求全看完** |
| **规范与标准文本** | 健康教育、健康档案、居民健康档案管理相关的**行业规范与标准**（公开可查） | 用于理解**档案与随访的规范要求** |
| **教材配套习题** | 官方/正规出版教材的**配套练习与模拟题** | **以正规出版教材为准**，来源不明的“真题”价值有限 |
| **科普图书** | 营养、运动、慢病管理方向的**大众科普读物** | 只用于**培养语感**，概念与数值以教材为准 |
| **本站资源** | [书籍库](/jiankang-guanlishi/books/) ｜ [题库](/jiankang-guanlishi/practice/) ｜ [备考笔记](/jiankang-guanlishi/notes/) ｜ [一页速记](/jiankang-guanlishi/cheatsheet/) | **本站为原创整理**，用于建框架、抓重点、练记忆，**不替代官方教材与考核方案** |

> ⚠️ **如实说明**：与软考等全国统考不同，**健康管理师的公开开源备考仓库生态非常薄弱**——网上流传的“整理版真题”“内部押题”“某某机构密卷”**多为营销产物，来源不可验证、与当次考核方案对不上**。**本站不以站外未经验证的题库作为推荐来源**，请以**官方渠道 + 正规教材 + 评价机构考核方案 + 本站精讲**为主。

## 实操练习建议

健康管理师的操作技能**靠练不靠背**，以下练习**几乎零成本，且能直接变成面试案例**：

**① 给自己或家人做一次完整评估（最有价值）**

```text
采集：身高体重、腰围、血压（规范测量）、作息与饮食记录 7 天、身体活动记录
   ↓
评估：算 BMI 与腰围，对照“一般参考口径”判断风险方向（以现行指南与教材为准）
   ↓
建议：写出 3 条具体可做的调整（吃什么、怎么动、几点睡）
   ↓
随访：执行 4 周，每周记录一次，最后复盘哪条做到了、哪条没做到、为什么
```

> 这套流程走完一遍，你就有了**一个完整、真实、能讲清楚的案例**——面试时比证书更能说明问题。

**② 练“把报告讲成人话”**

找一份**自己的体检报告**（注意隐私，勿外传），练习把每一项异常转成一句话：**“这个指标偏高意味着什么方向的风险 → 建议先改哪一项生活方式 → 多久后复查”**。**注意：不做诊断、不给治疗建议，异常项建议就医。**

**③ 练档案书写（SOAP）**

按 **主观资料 S / 客观资料 O / 评估 A / 计划 P**，把上面那次评估写成一份规范的健康档案记录，控制在 1 页内。**写完自查：信息是否完整、是否有时间、是否可追溯、是否含不必要的敏感信息。**

**④ 练健康教育（讲给别人听）**

选一个主题（如“高血压人群的生活方式要点”“一天怎么吃更均衡”），对着家人或同事**讲 5 分钟**，然后问对方“哪一句没听懂”。**讲不清 = 没学懂**，这是最有效的自测。

**⑤ 练干预方案的“动作化”**

把一句口号改写成可执行方案，例如：

| 口号（不可执行） | 动作化方案（可执行） |
|----------------|-------------------|
| “加强运动” | **每周 3 次、每次 30 分钟快走**（以个人耐受为准），**手机打卡记录**，4 周后复评 |
| “少吃盐” | **做菜用限盐勺、少吃腌制食品**，**记录 3 天饮食**，2 周后回顾一次 |
| “早点睡” | **设定 23:00 前上床**，睡前一小时不看手机，**记录睡眠时间 1 周** |

**⑥ 练边界感（技能题与面试都会考）**

遇到涉及**诊断、用药、治疗**的问题，练习固定回应：**“这属于医疗范围，建议您就医评估；我可以在生活方式与随访上帮您把方案落地。”**

## 避坑提醒

| 坑 | 正确做法 |
|----|---------|
| **在非备案机构报名** | **先在 osta.org.cn 核实机构备案情况**，**以备案评价机构与当地人社部门当次通知为准** |
| **相信“官方指定教材/官方题库”** | **不存在针对某个机构的“官方指定培训教材”统一口径**；**考核方案以该评价机构公布为准** |
| **买“内部押题/密卷”** | 来源不可验证、与当次方案对不上，**钱花了还可能背错**；用**正规教材 + 本站精讲 + 自己练** |
| **收藏一堆资料却不学** | **资源不在多而在用透**——**1 本教材 + 本站 8 章 + 1 个自测案例**足够 |
| **只看视频不动手** | 操作技能必须**手写练习**：评估流程、干预方案、SOAP 档案 |
| **把科普当教材** | 自媒体科普**可能有误或过时**，涉及指标与标准**一律回到指南与教材** |
| **在公开场合泄露客户/家人健康信息** | **健康信息属敏感个人信息**——**先授权、最小必要、脱敏处理**，按现行法规与机构制度执行 |
| **用本站内容替代就医** | **本站不提供医疗建议**，**医学判断以现行临床指南与教材为准**，身体不适请就医 |

> ⚠️ **最终提醒**：**评价机构、报考条件、考核方式、补贴与积分政策一律以备案评价机构与当地人社部门当次通知为准**；**医学内容以现行临床指南与教材为准，本站不提供医疗建议。**
