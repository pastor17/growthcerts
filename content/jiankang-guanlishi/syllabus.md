> ⚠️ **重要前提**：健康管理师已转为**职业技能等级认定**，**各备案评价机构的考核方案、题型与分值可能不同**。本页给出的是**教材与考试辅导中的常见框架（一般口径）**，用于**建立知识体系与安排复习**；**具体考试范围、题型、题量与合格标准以备案评价机构与当地人社部门当次通知为准**。**医学内容以现行临床指南与教材为准，本站不提供医疗建议。**

## 理论知识模块

**模块地图（按知识域归类）**

| 模块 | 核心考点 | 重要度 |
|------|---------|--------|
| **1. 健康管理概论** | 健康管理的定义与内涵、基本流程（采集 → 评估 → 干预）、服务特点（标准化/量化/个体化/系统化）、三级预防、健康管理与相关学科的关系、职业道德 | ★★★★★ |
| **2. 医学基础知识** | 人体基本结构与功能、临床医学与预防医学基础、健康与疾病、亚健康、疾病自然史、循证医学基本概念 | ★★★★☆ |
| **3. 常见慢性病** | 慢性病共同特点与危险因素；高血压、糖尿病、血脂异常、超重与肥胖、痛风与高尿酸、冠心病、脑卒中、慢阻肺、恶性肿瘤、骨质疏松的危险因素与生活方式干预方向 | ★★★★★ |
| **4. 营养与食品安全** | 六大营养素与膳食纤维的功能与来源、能量与能量系数、平衡膳食与膳食宝塔、膳食调查方法、特殊人群膳食要点（框架）、食源性疾病与食品污染、食品标签、HACCP | ★★★★★ |
| **5. 身体活动与运动处方** | 身体活动分类（有氧/抗阻/柔韧）、运动处方 FITT、运动前风险筛查、不同人群活动建议方向、运动损伤预防 | ★★★★☆ |
| **6. 心理健康** | 心理健康标准与评价维度、压力与应激、常见心理困扰的识别信号与转介边界、沟通与情绪支持原则 | ★★★☆☆ |
| **7. 健康教育与健康促进** | 健康教育与健康促进、健康素养、知信行（KAP）模式、行为改变理论（健康信念/跨理论/社会认知）、传播方法与材料制作 | ★★★★★ |
| **8. 健康信息学** | 信息采集内容与方法、健康档案（个人/家庭/社区）、SOAP 记录、数据质量、信息安全与隐私保护 | ★★★★☆ |
| **9. 健康风险评估与分析** | HRA 概念与目的、评估流程、危险因素识别、风险分层、相对/绝对危险度概念、报告解读与风险沟通、评估局限 | ★★★★★ |
| **10. 健康管理服务与营销** | 服务内容与形式、服务包设计、客户沟通与关系维护、效果评价、服务营销与合规边界 | ★★★☆☆ |
| **11. 中医养生** | 中医基础常识、养生原则、四季养生、体质辨识方向、情志与饮食调养、常用保健方法（八段锦/太极/穴位按摩的保健定位） | ★★★☆☆ |
| **12. 康复医学** | 康复评定、物理治疗、作业治疗、言语治疗、康复护理、康复工程的概念与区别、慢病康复与功能锻炼原则 | ★★☆☆☆ |
| **13. 健康保险** | 健康险基本概念与类型、健康管理与保险的结合、健康告知与服务对接 | ★★☆☆☆ |

> **记忆锚**：**“一条主线（采集→评估→干预）、两大技能（评估 + 干预）、三个基础（医学 + 营养 + 运动）、四类服务（教育 + 档案 + 随访 + 营销）”**。

## 操作技能模块

操作技能考的是**“能不能按流程做出来”**，一般包含以下五个方向：

| 方向 | 要会做的具体动作 |
|------|----------------|
| **① 健康信息采集与档案** | 设计/使用问卷；规范测量身高体重、腰围、血压等（**按规范操作，数值判断以现行指南与教材为准**）；解读体检报告；按 **SOAP** 书写与更新健康档案；核对信息完整性 |
| **② 健康风险评估与分析** | 采集信息 → 识别危险因素 → 风险分层 → 生成/解读评估报告 → 与客户做**风险沟通** → 给出干预建议 → 安排**随访复评** |
| **③ 健康教育与健康促进** | 做需求评估；设计讲座/小组/一对一方案；按知信行思路编排内容；制作通俗准确的材料；组织实施并做**过程与效果评价** |
| **④ 健康管理干预与随访** | 制定**可测量目标**的干预方案（膳食/身体活动/戒烟限酒/心理平衡/睡眠）；约定频次与责任人；跟踪执行、处理依从性问题；做效果评价与方案调整 |
| **⑤ 中医养生与康复指导** | 讲四季养生与饮食调养的一般原则；按体质辨识给**养生方向**；指导八段锦/太极等**保健性**锻炼；配合康复做**功能锻炼督促**（**不做治疗性操作、不开方药**） |

**操作技能的三条通用要求**

1. **流程完整**：评估类题目必须写全**“采集 → 评估 → 建议 → 随访”**闭环，只写建议会丢分；
2. **动作具体**：把“加强运动”写成**“每周 3 次、每次 30 分钟快走（以个人耐受为准），4 周后复评”**这类可执行表述；
3. **守住边界**：**不诊断、不开药、不承诺疗效**，异常指标**建议就医**，涉及隐私**先授权后处理**。

## 分值分布与题型

> ⚠️ **以下为常见口径（示意），不是官方固定标准**——**题型、题量与分值由各评价机构的考核方案确定**，**以备案评价机构与当地人社部门当次通知为准**。

**两科结构（示意）**

| 科目 | 常见题型 | 常见分值倾向 | 备考重心 |
|------|---------|-------------|---------|
| **理论知识** | 单选、多选、判断等客观题 | 覆盖面广，**慢性病、营养、运动、健康教育、风险评估**占比通常较高 | **广度优先**：考点多、单题分低，**别在偏题上耗时间** |
| **操作技能** | 案例分析、情景分析、方案设计类题目（部分机构含模拟操作） | 集中在**评估、干预方案、健康教育、档案与随访** | **流程优先**：背“答题骨架”，练“动作化表述” |

**理论知识常见占比倾向（示意）**

```text
常见慢性病与危险因素        ≈ 20% ～ 25%
营养与食品安全              ≈ 15% ～ 20%
健康风险评估与分析          ≈ 10% ～ 15%
健康教育与健康促进          ≈ 10% ～ 15%
身体活动与运动处方          ≈ 8% ～ 12%
健康管理概论 + 医学基础      ≈ 10% ～ 15%
健康信息学 + 服务营销        ≈ 8% ～ 12%
心理健康 + 中医养生 + 康复 + 保险 ≈ 8% ～ 12%
```

> **说明**：**以上比例只是复习时间分配的参考**，**不是官方分值表**。**若评价机构公布了考核方案，一律以该方案为准**。

## 备考路线图（零基础 → 三级）

**总时长建议：120~200 小时（约 2~4 个月，每周 8~12 小时）**——零基础偏上限，医药卫生/营养/体育背景可偏下限。

```text
第 0 步（1 天）：核实报名资格与考核方案
        ↓
第 1 阶段 · 打地基（第 1~3 周，约 40 小时）
   健康管理概论与流程 → 医学基础 → 三级预防
   目标：能说清“健康管理是什么、流程有哪几步”
        ↓
第 2 阶段 · 攻重点（第 4~7 周，约 60 小时）
   常见慢性病与危险因素 → 营养与食品安全 → 身体活动与运动处方
   目标：每个慢病能说出“危险因素 + 生活方式干预方向”
        ↓
第 3 阶段 · 补技能（第 8~10 周，约 40 小时）
   健康信息采集与档案 → 健康风险评估 → 健康教育 → 干预方案与随访
   目标：能独立写出“评估报告要点 + 干预方案骨架 + 随访计划”
        ↓
第 4 阶段 · 扫尾（第 11 周，约 20 小时）
   心理健康 → 中医养生 → 康复 → 健康保险 → 服务与营销
   目标：记住概念框架与边界，不求深挖
        ↓
第 5 阶段 · 冲刺（考前 1~2 周，约 20 小时）
   一页速记 + 错题 + 限时模拟 + 技能题手写练习
```

**三条零基础避坑原则**

1. **先建框架再填细节**：先把“采集 → 评估 → 干预 → 随访”的主线刻进脑子，再往里填知识点；
2. **慢病与营养优先**：这两块**内容最多、工作最常用**，值得花最多时间；
3. **技能题必须动手写**：**看懂 ≠ 写得出**，评估与方案题**限时手写**，练“得分点条数”与“动作化表述”。
