## 考点梳理

### 3.1 施工准备阶段的监理工作

1. **审查**施工组织设计、（专项）施工方案（含**安全技术措施**）；
2. 审查施工单位**现场管理体系**（质量、安全、技术管理体系与人员资格，特种作业人员持证）；
3. 审查**分包单位资格**（须经建设单位同意）；
4. 参加**设计交底与图纸会审**（由建设单位组织）；
5. 审查**测量放线成果**与**开工条件**；
6. 审查进场材料/构配件/设备的**质量证明文件**；
7. 主持召开**第一次工地会议**（监理规划与监理工作程序交底）；
8. 符合条件时，由**总监理工程师签发开工令**（按合同与规定程序）。

### 3.2 三大目标控制手段

| 目标 | 主要手段 |
|------|---------|
| **质量控制** | 审查方案与人员资格、材料设备**报验与见证取样**、**旁站/巡视/平行检验**、工序与隐蔽工程验收、检验批/分项/分部工程验收、质量缺陷与事故处理 |
| **进度控制** | 审查进度计划（总/年/季/月）、检查实际进度、对比分析与偏差纠正、**签发进度指令**、协调相关方、必要时要求调整计划 |
| **投资控制** | 工程**计量与支付签认**、审查变更费用、**审查索赔**、控制费用偏差、审核竣工结算 |

**共同手段**：**监理指令文件**（监理通知单、工程暂停令、复工令、监理报告）、**工地例会**、**监理月报**、**旁站与验收记录**。

### 3.3 安全生产管理职责（四步链）

依次为：

1. **审查**施工组织设计中的安全技术措施与专项施工方案（是否符合强制性标准）；
2. 发现**安全事故隐患** → **要求施工单位整改**（发监理通知单）；
3. **情况严重** → **要求暂时停止施工**（签发工程暂停令）并**报告建设单位**；
4. 施工单位**拒不整改/不停止施工** → **及时向有关主管部门报告**。

> **顺序、对象不能错**，这是案例题的"标准四步链"。

### 3.4 监理指令文件与暂停/复工

| 文件 | 签发人 | 适用情形 |
|------|-------|---------|
| **监理通知单** | 专业监理工程师/总监（按权限） | 一般问题要求整改 |
| **工程暂停令** | **总监理工程师**（签发前宜向建设单位报告，紧急情况除外） | 出现严重质量/安全隐患、擅自变更设计、擅自使用未经检验材料等 |
| **复工令** | **总监理工程师** | 停工原因消除、具备复工条件后 |
| **监理报告** | 项目监理机构 | 向建设单位或主管部门报告重大事项 |

**暂停施工后复工的条件**：施工单位完成整改 → 提交复工报审表 → **监理检查确认** → 总监签发复工令。

### 3.5 工地例会与组织协调

- **第一次工地会议**：由**建设单位主持**（监理协助），介绍各方机构与人员、明确监理程序与制度；
- **监理例会（工地例会）**：由**总监理工程师主持**（一般每周或按约定），检查上次会议决议落实情况、分析进度/质量/投资问题、明确下步措施与责任分工；
- **协调原则**：以**合同与事实**为依据、书面记录、及时沟通、必要时专题会议。

### 3.6 竣工验收阶段的监理工作

1. 审查施工单位提交的**竣工资料**；
2. 组织**竣工预验收**（总监组织，专业监理工程师参加），对发现的问题要求整改；
3. 编写**工程质量评估报告**（由总监与监理单位技术负责人签字）；
4. 参加**建设单位组织的竣工验收**；
5. 签署**竣工报验单**、参与工程移交与保修期管理（按合同约定）。

### 3.7 监理文件资料管理

**核心资料**：监理规划与实施细则、监理日志与监理月报、旁站记录、见证取样与平行检验记录、监理通知单及回复、会议纪要、工程暂停令与复工令、工程款支付证书、质量评估报告、竣工预验收与竣工验收记录。

> **作用**：既是监理履职的**证据**，也是案例题判断"监理是否尽责"的依据。

## 🧠 记忆工具箱

### 安全监理四步链

**"审查 → 要求整改 → 严重时暂停施工并报建设单位 → 拒不执行报主管部门。"**

### 三次关键会议

**"第一次工地会议由建设单位主持；监理例会由总监主持；专题会议按需召开。"**

### 暂停与复工

**"总监签暂停令、总监签复工令；停工原因消除+检查确认才复工。"**

### 竣工验收四件事

**"审资料 → 组织预验收 → 出质量评估报告 → 参加建设单位组织的竣工验收。"**

### 履职证据一句话

**"凡是说的话，都要落到纸面（日志、通知单、记录、纪要）。"**

## 🔍 深度精讲

### 深讲 1："发监理通知单"与"发工程暂停令"的分界线

这是案例题最常考的判断题，判断标准是**隐患的严重程度与紧迫性**：

| 情形 | 应采取的措施 |
|------|------------|
| 一般质量问题、管理不规范、资料不全 | **发监理通知单**，要求限期整改并回复 |
| 存在**安全事故隐患** | 要求整改（通知单）；**情况严重**时要求暂停施工并报建设单位 |
| **擅自变更设计、擅自使用未经检验的材料、不按图施工且拒不整改** | 可签发**工程暂停令**，报建设单位 |
| 施工单位拒不整改/不停工 | **报告有关主管部门** |
| 发生质量/安全事故 | 立即**报告建设单位与有关部门**，配合调查，保护现场 |

**答题要点**：写出"**判断严重程度 → 选择措施 → 明确对象（施工单位/建设单位/主管部门）**"，不要只写"要求整改"。

### 深讲 2：质量控制的"验收链"与监理角色

| 层次 | 组织者 | 监理角色 |
|------|-------|---------|
| **检验批** | **专业监理工程师**组织验收 | 主验，签署验收记录 |
| **分项工程** | 专业监理工程师组织 | 主验 |
| **分部（子分部）工程** | **总监理工程师**组织 | 主验；地基基础与主体结构分部应通知勘察设计单位参加 |
| **单位工程竣工预验收** | **总监组织** | 主验，编写**质量评估报告** |
| **单位工程竣工验收** | **建设单位组织** | 监理参加并签署意见 |

**常见案例错误**："由监理单位组织单位工程竣工验收"→ **错**，单位工程竣工验收由**建设单位**组织；监理组织的是**竣工预验收**。

### 深讲 3：进度控制的"检查—对比—纠偏"闭环

1. **检查**：实际进度（形象进度、工程量、关键节点完成情况）；
2. **对比**：与计划比较（横道图对比、S 曲线、**前锋线法**、挣值法）；
3. **分析**：偏差是否在关键线路上、是否超过总时差；
4. **纠偏**：要求施工单位调整计划（增加资源、调整工序搭接/平行作业）；必要时**签发监理通知单**；
5. **记录与报告**：写入监理日志与**监理月报**，重大偏差报告建设单位。

**答题提示**：出现"进度滞后但监理未分析原因、未要求调整计划"，应判为**监理履职不到位**，并写出完整的检查—分析—纠偏—报告链条。

## ⚠️ 易错提醒

- **单位工程竣工验收由建设单位组织**，监理组织的是**竣工预验收**；
- **工程暂停令与复工令只能由总监理工程师签发**；
- 安全监理是"**先整改、严重才停、拒不执行才报主管部门**"的顺序；
- **第一次工地会议由建设单位主持**，监理例会由总监主持——不要混；
- 监理通知单要有**整改要求与回复时限**，并跟踪闭环（只发不复查属于履职不到位）；
- 凡涉及结构安全的试块试件与材料，必须**见证取样**，监理须现场见证。
