## 考点梳理

### 1.1 质量控制的原则与依据

**原则**：坚持**质量第一**、**以人为核心**、**预防为主**、坚持质量标准、**公正守法**。

**依据**：法律法规与强制性标准、**设计文件**（施工图）、**合同文件**、监理规划与实施细则。

### 1.2 施工准备阶段的质量控制

1. 审查施工组织设计与（专项）施工方案；
2. 审查施工单位质量管理体系与人员资格（含**特种作业人员持证**）；
3. 审查分包单位资格（须经建设单位同意）；
4. 参加**图纸会审与设计交底**；
5. 审查测量放线（**复核控制点、轴线、标高**）；
6. 审查进场材料/构配件/设备的**质量证明文件**，对涉及结构安全的材料**见证取样送检**；
7. 审查施工机具设备与试验室条件；
8. 审查开工条件，**签发开工令**（总监）。

### 1.3 施工过程质量控制手段

| 手段 | 要点 |
|------|------|
| **巡视** | 日常巡回检查，覆盖面广 |
| **旁站** | 对**关键部位、关键工序**现场跟班监督（按监理规划确定的旁站范围） |
| **平行检验** | 监理利用自身手段**独立检验**，验证施工单位自检结果 |
| **见证取样** | 对涉及结构安全的试块、试件与材料取样过程**现场见证**并送检 |
| **报验与签认** | 材料进场报验、工序报验、隐蔽工程验收签认 |
| **指令文件** | 监理通知单要求整改，严重时暂停施工 |

### 1.4 验收层次与组织者（与一建/二建一致，必背）

| 层次 | 组织者 | 说明 |
|------|-------|------|
| **检验批** | **专业监理工程师** | 按工程量/楼层/施工段划分 |
| **分项工程** | 专业监理工程师 | 按工种/材料/工序划分 |
| **分部（子分部）工程** | **总监理工程师** | 地基基础与主体结构分部需勘察设计单位项目负责人参加 |
| **单位工程竣工预验收** | **总监理工程师组织** | 编写**工程质量评估报告** |
| **单位工程竣工验收** | **建设单位组织** | 监理参加并签署意见 |

**验收不合格的处理**：① 返工重做后重新验收；② 经有资质检测机构检测鉴定**能达到设计要求**的予以验收；③ 检测达不到要求但经**原设计单位核算认可**满足安全与使用功能的可予验收；④ 经返修加固仍不能满足安全使用要求的**严禁验收**。

### 1.5 质量缺陷与质量事故的处理

**质量缺陷（未构成事故）**：由**施工单位**提出处理方案（必要时经设计确认），监理审核同意后实施，处理后**重新验收**。

**质量事故处理程序（答题链）**：

1. **暂停施工**（必要时签发工程暂停令），采取防护措施防止事故扩大；
2. **报告建设单位**（重大事故按国家规定报告有关部门）；
3. 组织或参与**事故调查**，查明原因与责任；
4. 审查**事故处理方案**（由责任方或设计单位提出，必要时组织专家论证）；
5. 监督**处理方案实施**；
6. **重新验收与检测鉴定**（涉及结构安全的须检测鉴定）；
7. **签署处理结论**，形成事故处理报告并归档。

### 1.6 工程质量保修

- 保修期自**竣工验收合格之日**起算；
- 最低保修期限（法定）：**地基基础与主体结构 = 设计文件规定的合理使用年限**；**屋面防水、有防水要求的房间与外墙面防渗漏 = 5 年**；**供热与供冷系统 = 2 个采暖期/供冷期**；**电气管线、给排水管道、设备安装与装修工程 = 2 年**；
- 保修期内出现质量问题，**施工单位应履行保修义务**；监理可参与调查与处理（按合同约定）。

## 🔍 深度精讲

### 深讲 1：为什么"见证取样"是监理最常被考的履职点

见证取样的对象是**涉及结构安全的试块、试件与材料**（如混凝土试块、钢筋、砌筑砂浆等）。规范要求取样过程由**监理人员现场见证**，样品应**标识、封样并送有资质检测机构**。

**常见违规情形与判定**：

| 情形 | 判定 |
|------|------|
| 施工单位自行取样送检，监理未见证 | **监理履职不到位**，检测结果不具代表性 |
| 送检样品被替换（"做样子"试块） | 属**弄虚作假**，监理应拒绝签认并报告建设单位 |
| 未按规定比例见证取样 | 不符合规范要求，应补做 |
| 检测不合格但施工单位直接使用 | 监理应**拒绝签认**，要求退场或返工；已使用的应检测鉴定 |

**案例答法**："应要求施工单位按规定进行**见证取样送检**，监理旁站见证并做好记录；复试合格后方可签认使用；对已使用的不合格材料，应要求检测鉴定并作出处理。"

### 深讲 2：平行检验与"以施工单位自检代替检验"的区别

- **施工单位自检**是施工单位质量保证体系的一部分（自检、互检、专检的"三检制"）；
- **平行检验**是监理机构**独立**进行的检验，用于验证自检结果的真实性；
- 监理若**直接采用施工单位自检数据**作为验收依据，则丧失了独立验证的意义，属于**履职不到位**。

**答题提示**：题目若描述"监理仅凭施工单位提供的检测报告即签认隐蔽工程验收"，标准答案是"**应进行旁站/巡视与必要的平行检验，隐蔽前必须现场验收并形成记录**"。

### 深讲 3：质量事故与质量缺陷的处理差异

| 对比项 | 质量缺陷 | 质量事故 |
|--------|---------|---------|
| 严重程度 | 未造成事故后果（如蜂窝麻面、局部偏差） | 造成人员伤亡、结构安全受威胁或重大经济损失 |
| 处理主体 | 施工单位提出处理方案，监理审核 | **组织调查**（按事故等级与规定），监理参与 |
| 程序 | 处理 → 重新验收 | **暂停施工 → 报告 → 调查 → 审查方案 → 监督实施 → 重新验收 → 结论** |
| 报告 | 一般不需上报政府 | 按规定**报告建设单位与有关部门** |

**答题关键**：涉及**结构安全**的处理方案须经**设计单位确认**，涉及重大技术问题的应**组织专家论证**。

## ⚠️ 易错提醒

- **单位工程竣工验收由建设单位组织**，监理组织的是**竣工预验收**；
- **涉及结构安全的试块试件与材料必须见证取样**，监理须现场见证；
- 验收不合格**不得降级使用**；经返修加固仍不满足安全使用要求的**严禁验收**；
- 质量事故处理方案涉及结构安全的须经**设计单位确认**，重大方案需**专家论证**；
- 保修期自**竣工验收合格之日**起算（不是交付使用之日）；
- 监理**不得以施工单位自检结果替代平行检验**。
