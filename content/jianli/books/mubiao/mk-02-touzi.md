## 考点梳理

### 2.1 建设工程投资构成（速记）

```
建设工程总投资
├─ 建设投资
│   ├─ 工程费用（建筑安装工程费 + 设备及工器具购置费）
│   ├─ 工程建设其他费用
│   └─ 预备费（基本预备费 + 价差预备费）
└─ 建设期利息
    （流动资金另计）
```

**建筑安装工程费构成**（按造价形成）：**分部分项工程费 + 措施项目费 + 其他项目费 + 规费 + 税金**。

**措施项目费常见项**：安全文明施工费（**不可竞争费**）、夜间施工增加费、二次搬运费、冬雨期施工增加费、脚手架费、大型机械进出场及安拆费等。

### 2.2 各阶段投资控制重点

| 阶段 | 监理参与重点 |
|------|------------|
| 决策阶段 | 一般由建设单位主导（监理参与较少） |
| **设计阶段** | **对投资影响最大**（方案与限额设计）；监理协助审查设计概算 |
| 招投标阶段 | 参与审查工程量清单与合同价款条款 |
| **施工阶段** | **计量与支付、变更与索赔审查、费用偏差分析**——监理投资控制的主战场 |
| 竣工阶段 | **审核竣工结算**、参与决算 |

### 2.3 工程计量与支付（监理核心动作）

**计量原则**：按**合同约定的计量方法**与**实际完成的合格工程量**计量；**不合格工程不予计量**；计量应在**验收合格**后进行。

**支付程序（一般流程）**：

1. 施工单位按约定提交**已完工程量报告**（含计量资料）；
2. **专业监理工程师**复核工程量（现场计量、对照图纸与验收记录）；
3. **总监理工程师签署工程款支付证书**；
4. 报**建设单位**，由建设单位按合同约定支付。

> **关键点**：监理签署的是**支付证书**，**最终支付由建设单位决定并执行**；未经监理质量验收合格的工程，**不得计量与支付**。

### 2.4 工程变更与索赔费用审查

**变更费用审查要点**：工程量是否属实、单价是否按合同约定（有约定从约定，无约定按**类似项目单价**或**成本加利润**协商）、措施费是否增加合理、是否与索赔重复计算。

**索赔费用构成（可索赔项）**：

| 项目 | 说明 |
|------|------|
| **人工费** | 停工/窝工人工按**约定单价**计（不是全额工日单价） |
| **机械费** | 自有机械按**折旧费/不变费用**计，租赁机械按**租赁费**计 |
| **材料费** | 已进场材料的保管费、退货损失等 |
| **措施费** | 因变更增加的临时设施、降水、脚手架等按实计取 |
| **管理费与利润** | 管理费可按约定计取；**利润一般在发包方违约时可主张**，不可抗力不索赔利润 |

### 2.5 投资偏差分析（计算考点）

| 指标 | 公式 | 含义 |
|------|------|------|
| **费用偏差 CV** | **CV = 已完工程预算费用（BCWP/EV） − 已完工程实际费用（ACWP/AC）** | CV > 0 节约，CV < 0 超支 |
| **进度偏差 SV** | **SV = 已完工程预算费用（BCWP/EV） − 拟完工程预算费用（BCWS/PV）** | SV > 0 进度提前，SV < 0 滞后 |
| **费用绩效指数 CPI** | **CPI = EV / AC** | < 1 超支 |
| **进度绩效指数 SPI** | **SPI = EV / PV** | < 1 滞后 |

> 记忆锚：**CV 与 CPI 看"钱"，SV 与 SPI 看"活"；凡 < 1（或 < 0）均为不利**。

### 2.6 竣工结算审核

**审核内容**：工程量、单价与取费标准、变更与签证、索赔、暂列金额与暂估价、甲供材与扣款、工期与质量奖罚。

**审核要点**：① 结算资料是否齐全（图纸、变更单、签证、验收资料）；② 工程量是否重复计算；③ 单价与合同约定是否一致；④ 变更与索赔是否已包含在结算中（避免重复）；⑤ **未经监理签认的工程量不予结算**。

## 🔍 深度精讲

### 深讲 1：为什么"不合格工程不予计量"是监理的红线

计量与支付是**投资控制的闸门**，也是监理最容易被"攻关"的环节：

- 若对**未验收或验收不合格**的工程量签认支付，等于用建设单位资金为不合格产品买单；
- 若**重复计量**或对同一变更既在变更费中计取、又在索赔中主张，会造成建设单位损失；
- 监理签认后将**承担相应责任**（含赔偿责任）。

**案例标准答法**："应**拒绝签认**该部分工程量（依据：未经质量验收合格的工程不予计量）；要求施工单位整改并重新验收；已支付的应予以扣回；并报告建设单位。"

### 深讲 2：工期索赔与费用索赔的"监理审查要点"

**工期索赔审查**：

1. 事件是否在**关键线路上**？
2. 若在非关键线路上，拖延是否**超过该工作总时差**？可索赔天数 = **拖延天数 − 总时差**；
3. 有无**共同延误**（多方原因）？应分别分析，不能简单叠加。

**费用索赔审查**：

1. 责任归属与非己方举证；
2. 索赔项目是否**实际发生**且**非重复计算**；
3. 金额计算是否符合合同约定（窝工单价、机械不变费、租赁费）；
4. **是否与变更费用重复**（同一事项不能既算变更又算索赔）；
5. 是否在**时限内**提出（一般事件发生后 28 天内提交意向）。

**答题提示**：写出算式并说明取数来源（这是投资控制案例题拿满分的关键）。

### 深讲 3：投资偏差分析在案例中的应用

**示例**：某工程月度数据——拟完工程预算费用 PV = 200 万元，已完工程预算费用 EV = 180 万元，已完工程实际费用 AC = 210 万元。

- **CV = EV − AC = 180 − 210 = −30 万元** → **费用超支 30 万元**；
- **SV = EV − PV = 180 − 200 = −20 万元** → **进度滞后**（相当于少完成 20 万元工作量）；
- **CPI = 180/210 ≈ 0.857**（<1，超支）；**SPI = 180/200 = 0.9**（<1，滞后）。

**监理应采取的措施**：分析超支与滞后原因（工程量变化、单价变化、效率低下、变更未及时办理）；要求施工单位提交纠偏措施计划；核查是否存在未签认变更；必要时向建设单位报告并提出投资控制建议。

## ⚠️ 易错提醒

- **CV 与 SV 的符号含义相反**：CV<0 是**超支**，SV<0 是**进度滞后**，不要混；
- **索赔与变更费用不得重复计算**（高频陷阱）；
- 窝工人工费按**约定单价**计，不是按正常工日单价全额；
- 自有机械只计**不变费用（折旧等）**，租赁机械按**租赁费**；
- **不可抗力不索赔利润**，利润一般在**发包方违约**时可主张；
- 监理**签署支付证书**，最终支付由**建设单位**执行；未经监理签认的工程量**不予结算**。
