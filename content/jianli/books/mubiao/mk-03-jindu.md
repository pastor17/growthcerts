## 考点梳理

### 3.1 进度控制目标与计划体系

- **进度控制目标**：在满足质量与投资要求的前提下，实现**合同约定的工期**；
- **计划体系**：总进度计划（建设单位/监理审查）→ 年/季/月进度计划（施工单位编制，监理审查）→ 分部分项作业计划；
- **监理工作**：**审查进度计划的合理性与可行性**（工序逻辑、资源保障、关键线路、是否满足里程碑）→ 检查执行 → 偏差分析 → 要求调整 → 记录报告。

### 3.2 流水施工（工期计算）

| 组织方式 | 流水步距 K | 工期 T |
|---------|-----------|--------|
| **等节拍** | K = t | T =（m + n − 1）K |
| **成倍节拍** | K = 各节拍**最大公约数**，专业队数 bᵢ = tᵢ/K | T =（m + Σbᵢ − 1）K |
| **无节奏** | **累加数列错位相减取大差** | T = ΣK + 最后一个过程用时 |

> m 为施工段数，n 为施工过程数（成倍节拍用专业队总数 Σbᵢ）。

### 3.3 网络计划（进度控制的核心计算）

- **关键线路**：总持续时间**最长**的线路，决定计算工期；关键工作总时差为 0（计划工期等于计算工期时）；
- **总时差 TF**：不影响**总工期**的前提下可用的机动时间；
- **自由时差 FF**：不影响**紧后工作最早开始**的前提下可用的机动时间；**TF ≥ FF ≥ 0**；
- **时标网络图**：波形线表示**自由时差**；从起点到终点**无波形线**的通路为关键线路；
- **工期优化**：在关键线路上选择**赶工费用率最低**的工作压缩（同时注意不得压成非关键、不得低于最短持续时间、多条关键线路须同时压缩）。

### 3.4 进度检查与偏差分析

| 方法 | 用途 |
|------|------|
| **横道图比较法** | 直观比较计划与实际（适合粗看） |
| **S 形曲线比较法** | 以累计完成量对比计划，反映整体进度趋势 |
| **香蕉曲线** | 由 ES 曲线与 LS 曲线组成，判断实际进度是否在合理区间 |
| **前锋线比较法** | 在时标网络图上标出实际进度点，直观显示**超前/滞后**及对总工期的影响 |
| **挣值法** | 用 **SV = EV − PV、SPI = EV/PV** 量化进度偏差 |

### 3.5 工期索赔（监理审查要点）

1. **责任归属**：事件责任是否非承包方；
2. **线路判断**：受影响工作是否在**关键线路**上；
3. **时差判断**：非关键工作拖延是否**超过总时差**；
4. **计算**：可索赔工期 = **拖延天数 − 总时差**（关键工作则为拖延天数）；
5. **共同延误**：多方原因造成的延误应**分别分析**，按"对总工期最不利"或合同约定处理；
6. **结论**：提出审核意见报**建设单位**决定。

### 3.6 进度调整措施

| 类别 | 措施 |
|------|------|
| **组织措施** | 增加工作面、增加施工队伍、调整施工顺序与搭接 |
| **技术措施** | 改进施工工艺与方案、采用更高效的设备与工艺 |
| **经济措施** | 实行包干与激励、兑现奖惩（如提前工期奖励） |
| **合同措施** | 分包、调整合同工期（需建设单位同意）、索赔管理 |
| **资源措施** | 增加人机料投入、优化资源分配（**注意资源限量与成本**） |

## 🔍 深度精讲

### 深讲 1：为什么"前锋线法"在监理工地最常用

**前锋线法**在时标网络图上把各工作的**实际进度点**连成折线，与计划线对比，可以一眼看出：

1. 哪些工作**超前**（折线在检查日右侧）；
2. 哪些工作**滞后**（折线在检查日左侧）；
3. 滞后工作**是否在关键线路上**（决定是否影响总工期）；
4. 非关键工作滞后是否**消耗了总时差**、还剩多少机动时间。

**案例答法（标准四步）**：① 依据前锋线判断各工作超前/滞后天数；② 判断是否在关键线路上；③ 非关键工作计算"滞后天数 − 总时差"，得出对总工期的影响；④ 提出调整措施（组织/技术/经济/合同/资源）并要求施工单位提交调整后的进度计划。

### 深讲 2：进度滞后时的"分级处理"（监理动作）

| 滞后程度 | 监理应采取的措施 |
|---------|----------------|
| 一般偏差（不超过总时差、不影响里程碑） | 巡视/例会提醒，要求施工单位**自行纠偏**并加强进度管理 |
| 较大偏差（影响里程碑或消耗全部总时差） | **发监理通知单**要求限期提交纠偏措施计划并监督落实，纳入监理月报 |
| 严重滞后（可能影响总工期） | 要求施工单位**调整进度计划并加大资源投入**，书面报告**建设单位**，必要时召开专题会议 |
| 因非承包方原因造成 | 按合同**审查工期索赔**（计算影响天数），提出意见报建设单位 |
| 因承包方原因造成 | **不予顺延工期**，并可依合同约定主张违约责任（按约定处理） |

### 深讲 3：工期优化的"三条红线"（与一建/二建一致）

压缩关键工作工期时，必须同时满足：

1. **不得压成非关键工作**（否则关键线路转移，总工期不变）；
2. **不得低于该工作的最短持续时间**（受工艺与技术间歇限制）；
3. **多条关键线路须同时压缩**（否则其他关键线路成为制约）。

**答题要点**：写出"选择**关键线路上赶工费用率最低**且未达最短持续时间的工作压缩，压缩后**重新计算关键线路**，迭代至目标工期"，并注意**质量与安全底线不可突破**（如混凝土养护、拆模强度要求属不可压缩的技术间歇）。

## ⚠️ 易错提醒

- **总时差与自由时差**不要混用；判断工期索赔只认**总时差**；
- 成倍节拍流水的"加快"是相对**依次施工**，不必然短于等节拍；
- 无节奏流水求步距必须**错位相减取大差**；
- **SV < 0 表示进度滞后**（不是费用超支，费用看 CV）；
- 监理对工期索赔只有**审核与建议权**，最终由**建设单位**决定；
- 压缩工期不得突破**质量与安全底线**（技术间歇不可压）。
