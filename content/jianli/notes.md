## 一、本证该记什么（三类笔记）

### ① 最关键的一件事：**把立场切换过来**

同样的现场问题，施工方想"怎么干"，监理要想"**是否合规 → 依据是什么 → 应发什么指令**"。建议做一张**立场对照卡**：

| 施工方视角 | 监理视角（笔记里要写这个） |
|-----------|------------------------|
| 加班赶工抢工期 | 要求施工单位**提交调整后的进度计划**，审查可行性并监督实施 |
| 自检合格就报验 | 应**旁站/巡视与必要的平行检验**，隐蔽前现场验收并形成记录 |
| 材料先用、报告后补 | **拒绝签认**，要求**见证取样送检**，已使用的检测鉴定 |

### ② 四科"记什么"对照表

| 科目 | 只记这些 |
|------|---------|
| **建设工程合同管理** | 三种计价合同的风险归属、变更程序、**索赔成立三条件**、不可抗力费用分担、争议解决（仲裁一裁终局） |
| **监理基本理论和相关法规** | 委托定位、法定强制监理范围、**禁止行为五条**、总监专属职责、**安全监理四步链** |
| **目标控制** | 质量（验收组织者、见证取样与旁站/平行检验、不合格处理）、投资（**CV=EV−AC、SV=EV−PV**、计量支付程序、索赔费用项）、进度（流水三种工期、**TF ≥ FF**、前锋线法、工期索赔计算） |
| **案例分析** | 只记**答题骨架与措辞**（见下） |

### ③ 案例笔记：只记骨架与"红线用词"

| 应写 | 不应写 |
|------|-------|
| 签发**工程暂停令**并**报告建设单位** | 责令停工 |
| **拒绝签认**，要求退场处理 | 没收材料 |
| 审核后**报建设单位批准** | 批准索赔 |
| 组织**竣工预验收** | 组织竣工验收 |
| 拒不整改的**报告有关主管部门** | 直接处罚 |

**四步骨架**：**判断 → 依据 → 正确做法 → 补充措施**（每问写满 3~4 条）。

## 二、避坑清单（监理工程师专属 10 条）

| # | 坑 | 正确做法 |
|---|----|---------|
| 1 | 用施工方视角答案例题 | 全程用监理措辞（**应要求/应签发/应报告/应拒绝签认**），并按监理程序作答 |
| 2 | 把"监理"当政府监督 | 监理是**受建设单位委托**的社会化监督管理，无处罚权；行政处罚归主管部门 |
| 3 | 写"监理批准索赔/变更费用" | 监理只有**审核与建议权**，须报**建设单位**批准 |
| 4 | 写"监理组织竣工验收" | 监理组织**竣工预验收**；竣工验收由**建设单位**组织 |
| 5 | 忽略**专业类别**差异 | 交通与水利专业的《目标控制》《案例分析》技术要求不同，**教材别买错** |
| 6 | 四科一起硬拼 | 采用**两年四科**（第一年两门基础科目 + 第二年目标控制与案例），4 年滚动足够 |
| 7 | 案例题不手写 | 《案例分析》考 **4 小时**，考前必须**限时手写** 20~30 题，练"条数"与"速度" |
| 8 | 用旧版规范与验收标准 | 监理规范与验收标准近年有修订，**用现行有效版本**（可在标准平台核对状态） |
| 9 | 只背法规不做计算 | 网络计划时差、投资偏差（CV/SV）、索赔费用是**稳定计算考点**，必须手算熟练 |
| 10 | 忽略一建/二建的知识复用 | 合同管理、目标控制的质量/投资/进度与一建/二建高度重叠，**先盘点已有知识再补差异**（监理新增：旁站/巡视/平行检验、见证取样、监理程序与文件） |

## 五、一句话策略

> **"先切立场、再记程序、案例限时手写"**——监理考的是"**该发什么指令、依据是什么**"，不是施工技术本身。
