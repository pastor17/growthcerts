> 监理工程师考试实行**全国统一大纲**，官方教材由中国建筑工业出版社等出版（**土木建筑工程**方向较为通用）。**规范与标准更新频繁，请使用当年度教材与现行有效标准**。

## 一、四科结构与备考重心

| 科目 | 性质 | 备考重心 |
|------|------|---------|
| **建设工程合同管理** | 基础科目 | 合同订立与履行、工程变更与索赔、施工合同与监理合同要点 |
| **建设工程监理基本理论和相关法规** | 基础科目 | 监理制度与法规体系、监理工程师执业、监理组织与规划、监理工作内容与方法 |
| **建设工程目标控制** | 专业科目（3 专业） | 质量、投资、进度三大目标的控制方法与**计算**（网络计划、投资偏差、索赔费用） |
| **建设工程监理案例分析** | 专业科目（3 专业，**4 小时**） | 综合运用三控知识作答，**跨科目命题** |

> **分水岭在案例**：案例分析把质量、投资、进度、安全与合同问题混在一道题里，考的是"**能不能像监理一样判断并写出处理意见**"。

## 二、专业知识与实务体系（三控两管一协调）

```
目标控制（三控）        管理与协调（两管一协调）
├─ 质量控制             ├─ 合同管理
├─ 投资控制             ├─ 信息管理（含监理资料）
└─ 进度控制             └─ 组织协调 + 安全生产管理职责
```

**监理的法定工作方式**：**旁站、巡视、平行检验、见证取样**（这四项是监理区别于其他岗位的核心手段，也是高频考点）。

## 三、三个专业类别差异

| 专业类别 | 《目标控制》与《案例分析》的侧重 |
|---------|------------------------------|
| **土木建筑工程** | 房屋建筑与市政工程的施工质量、投资与进度控制（应用最广） |
| **交通运输工程** | 公路与水运工程的路基路面、桥梁隧道质量控制与计量支付 |
| **水利工程** | 水利水电工程的土石方、混凝土、闸坝质量控制与投资控制 |

> 选择建议见 [证书百科](/jianli/intro/)；**跨专业报考需按大纲对应专业的技术要求复习**，不能只学土木建筑内容。

## 四、官方教材与大纲获取

| 渠道 | 用途 |
|------|------|
| [中国人事考试网](https://www.cpta.com.cn) | **考试大纲**、报考条件、考试通告、成绩查询 |
| 中国建筑工业出版社等官方教材渠道 | 当年度四科教材（注意**专业类别**对应版本） |

## 五、与一建 / 二建的知识复用（省时间的关键）

| 监理科目 | 可复用的已有知识 |
|---------|----------------|
| **合同管理** | 一建《法规》合同部分 + 二建《施工管理》合同与索赔 |
| **基本理论与法规** | 一建《管理》组织与责任、安全管理；一建《法规》施工许可与发承包 |
| **目标控制·质量** | 一建/二建实务的验收层次、质量通病与处理；**监理的"旁站/巡视/平行检验"是新增考点** |
| **目标控制·进度** | 流水施工、网络计划（**总时差/自由时差**）、工期索赔——与一建/二建管理完全复用 |
| **目标控制·投资** | 一建《经济》造价构成、工程计量与支付；监理侧重点是**计量支付与索赔审查** |
| **案例分析** | 一建实务的"判断—依据—正确做法"骨架可直接迁移，但**立场要从"施工方"切换到"监理方"** |

## 七、备考提示

1. **先建"监理视角"**：同样的现场问题，施工方想"怎么干"，监理要想"**是否合规、依据是什么、应发什么指令**"；
2. **案例题必须手写**：4 小时 6 道题（按当年度题量），平均每题 40 分钟，写不完是常见失分原因；
3. **计算题集中在目标控制**：网络计划时差、投资偏差（**CV/SV**）、索赔费用与工期，务必手算熟练；
4. **标准与规范要记"关键指标"**：验收合格判定、见证取样比例、旁站范围等。
