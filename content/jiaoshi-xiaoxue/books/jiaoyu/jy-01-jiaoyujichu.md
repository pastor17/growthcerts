## 考点梳理

### 1.1 教育与社会、人的发展

- **教育与社会**：政治经济制度**决定**教育的性质与领导权；生产力制约教育发展水平、规模速度；文化影响教育内容；教育反作用于政治（政治功能）、经济（经济功能）、文化（文化功能：传承/选择/创新）。
- **影响人发展的四大因素**：遗传（提供可能性，前提）、环境（现实条件）、**学校教育（主导作用）**、个体主观能动性（内在动力）。
- **人的发展规律**（单选/简答高频）：
  - **顺序性** → 循序渐进、不可拔苗助长；
  - **阶段性** → 分阶段施教、注意衔接；
  - **不平衡性** → 抓**关键期/最佳期**（狼孩错过语言期）；
  - **互补性** → 扬长避短、"长善救失"；
  - **个别差异性** → 因材施教。

### 1.2 教育目的与学制

- **教育目的层次**：教育目的 → 培养目标 → 课程目标 → 教学目标（从抽象到具体）；
- 我国教育目的基本精神：培养**德智体美劳全面发展的社会主义建设者和接班人**；
- **学制演变（单选高频）**：
  - 壬寅学制（1902，清政府**颁布但未实施**，我国第一个现代学制）；
  - 癸卯学制（1904，**第一个正式实施**）；
  - 壬子癸丑学制（1912）；
  - 壬戌学制（1922，**"六三三"**，仿美，沿用时间长）。
  - 记忆：**"壬寅颁、癸卯行、壬戌六三三"**。

### 1.3 课程基础

- 类型辨析：**学科课程**（分科系统）vs **活动课程**（杜威，以经验为中心）；显性课程（课表上）vs **隐性课程**（校园文化、师生关系——潜移默化）；国家/地方/**校本课程**（本校开发）；
- 课程内容的三个层次：**课程计划 → 课程标准 → 教材**（课程计划是国家层面文件；课程标准是各科纲领，规定教学目标内容；教材即教科书）。

## 🧠 记忆工具箱

### 口诀速记

- 发展规律五句话：**"顺阶不互补，个差要记牢"**——顺序、阶段、不平衡、互补、个别差异，各自对应做法（循序渐进/分阶段/抓关键期/长善救失/因材施教）；
- 四大因素：**"遗环教主"**——遗传、环境、教育（主导）、主观能动性（动力）；
- 学制串：**"壬寅颁、癸卯行、壬子改、壬戌定"**（1922 壬戌定为六三三）。

### 简答/单选模板

问"某老师给学生贴标签（如'笨'）违背了什么" → **个别差异性→因材施教 / 或未用发展眼光**；问"小学低年级就教高深内容" → 违背**顺序性/阶段性**。**看到具体行为先对号入座五个规律**。

### 二、教育的功能与教育目的理论

- 教育功能：按性质分**正向/负向**；按呈现方式分**显性/隐性**；
- 教育目的理论：**个人本位论**（卢梭等，强调个体发展需要）与**社会本位论**（涂尔干等，强调社会需要）——我国强调两者统一，以培养全面发展的人为目标。

### 三、课程分类速记表

| 分类维度 | 类型 |
|---------|------|
| 内容组织 | 学科课程 / 活动课程 |
| 分科方式 | 分科课程 / 综合课程 |
| 修习要求 | 必修课程 / 选修课程 |
| 呈现方式 | 显性课程 / 隐性课程（校风、师生关系） |
| 管理主体 | 国家课程 / 地方课程 / 校本课程 |

课程内容三层次：**课程计划（国家文件）→ 课程标准（学科纲领）→ 教材（教科书）**。

### 四、典型例题（带解析）

**例题 1**：提出"教学的教育性"、被称为传统教育派代表人物的是？
A. 杜威　B. 赫尔巴特　C. 夸美纽斯　D. 卢梭
**答案 B**。解析：赫尔巴特提出教学的教育性原则并确立"教师、教材、课堂"传统三中心；杜威是现代派（儿童、经验、活动）。

**例题 2**：世界上最早的一部教育专著是？
A. 《论语》　B. 《学记》　C. 《大教学论》　D. 《普通教育学》
**答案 B**。解析：《学记》是中国古代也是世界上最早的教育专著；《大教学论》标志近代教育学形成、《普通教育学》标志教育学成为独立学科（示例口径）。

### 五、命题角度与背诵卡

- 命题角度：人物—观点匹配、最早/第一类排序题、教育功能分类、教育目的理论、课程类型与三层次；
- 背诵卡：**《学记》最早、夸美纽斯班级授课、赫尔巴特传统三中心、杜威现代三中心、陶行知教学做合一**；**课程三层次：计划→标准→教材**。

## ⚠️ 易错提醒

- "决定教育性质"的是**政治经济制度**，"制约发展水平/速度"的是**生产力**——两句话常互换设错；
- 第一个"颁布"是壬寅、第一个"实施"是癸卯；**六三三**对应 1922 **壬戌**学制；
- 隐性课程≠课外活动：它指**不在课表中却影响学生的因素**（校风、师生关系等）。
