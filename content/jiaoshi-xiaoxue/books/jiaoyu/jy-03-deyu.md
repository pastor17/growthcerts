## 考点梳理

### 3.1 德育原则（材料题大户，必背）

- **导向性原则**（政治方向）、**疏导原则**（循循善诱、以理服人）、**尊重学生与严格要求相结合**、**教育的一致性与连贯性**（家校社统一口径）、**因材施教**、**知行统一**（认识+实践）、**正面教育与纪律约束相结合**、**依靠积极因素克服消极因素（长善救失）**、**集体教育与个别教育相结合**（马卡连柯"平行教育"）。

> 口诀：**"导疏尊严一致材，知行正面长善救，集体个别平行来"**——看到材料先找"哪条原则"，再引材料。

### 3.2 德育方法

说服教育法（摆事实讲道理）、榜样示范法、实际锻炼法、情感陶冶法（环境熏陶）、品德评价法（表扬批评）、自我修养法（自我教育）。

### 3.3 德育途径

思想品德课与其他学科教学（**基本途径**）、课外校外活动、班会与团队活动、劳动与社会实践、班主任工作、校园文化环境（隐性）。

### 3.4 心理健康与辅导

- 小学生常见：入学适应、学习焦虑/考试焦虑、同伴冲突、网络依赖、多动倾向、说谎等；
- **心理辅导原则**：面向全体、预防与发展为主、尊重与理解、学生主体、个别化对待、保密（保密例外：伤害自己或他人风险时需报告）；
- 辅导方法：会谈、行为改变（正强化）、理性情绪疗法（ABC 理论：改变不合理信念）、放松训练等。

## 🧠 记忆工具箱

- 德育方法六个词：`说、榜、练、陶、评、自`（说服、榜样、实际锻炼、陶冶、品德评价、自我修养）；
- 心理辅导 ABC：**事件 A → 信念 B → 情绪 C**，改变的是**不合理信念 B**。

### 材料题模板（德育）

① 表态"材料体现了××原则/方法"；② 说内涵一句；③ 引材料一句；④ 总评。例："**疏导原则**强调循循善诱、以理服人。材料中，班主任没有当众训斥，而是私下与小明摆事实讲道理，正是疏导原则的体现。"

## 📚 深度精讲（重点精细版）

### 一、德育内容与德育过程四规律（简答高频）

德育内容：爱国主义教育、理想教育、集体主义教育、劳动教育、法制教育、心理健康教育（示例口径）。

**德育过程四条规律**：
1. **知、情、意、行统一**——知是基础、行是关键，需"晓之以理、动之以情、导之以行、持之以恒"；
2. **在活动和交往中形成**思想品德——德育不能只在课堂说教，要组织实践活动；
3. **内部矛盾转化**——把社会要求转化为学生自身需要，教育与自我教育结合；
4. **长期、反复、逐步提高**——品德形成是螺旋上升过程，允许反复、抓"反复抓"。

### 二、九条德育原则的"材料信号"对照

| 原则 | 材料里长什么样 |
|------|--------------|
| 导向性 | 结合爱国/集体主题引导方向 |
| 疏导 | 讲道理、循循善诱、不压制 |
| 尊重与严格要求结合 | 既尊重又提出明确要求 |
| 教育一致性与连贯性 | 家校社统一口径、前后一致 |
| 因材施教 | 针对不同学生用不同方法 |
| 知行统一 | 既讲道理又要求付诸行动 |
| 正面教育与纪律约束 | 表扬为主 + 明确纪律 |
| **长善救失** | 用学生的优点/特长克服缺点 |
| 集体教育与个别教育结合（平行教育） | 通过集体影响个人、个别教育反哺集体 |

### 三、心理健康与辅导

- 常见问题：学习困难、**考试焦虑**、人际交往障碍、多动倾向、品行问题、网络成瘾；
- 辅导原则：面向全体、**预防与发展为主**、尊重理解、学生主体、个别化、保密（自伤/伤人风险时须立即报告）；
- 常用方法：**认知疗法**（改变不合理信念，如考试焦虑的"我必须考第一"）、**行为疗法**（正强化、放松训练、系统脱敏）、来访者中心（倾听、共情、无条件积极关注）。

### 四、典型例题（带解析）

**例题 1**：教师在德育中既讲清道理，又组织实践活动并要求学生坚持养成习惯。这体现的德育过程规律是？
A. 知、情、意、行统一　B. 在活动和交往中形成品德　C. 内部矛盾转化　D. 长期反复逐步提高
**答案 A**。解析："晓之以理（知）、导之以行（行）、持之以恒（意）"综合体现知情意行统一规律。

**例题 2**：学生考前出现失眠、心慌、注意力难以集中，担心考不好。该生最可能的问题是？
A. 学习困难　B. 考试焦虑　C. 注意缺陷多动障碍　D. 抑郁症
**答案 B**。解析：与考试情境强相关的紧张、躯体反应与担忧，是考试焦虑的典型表现；可用放松训练与认知调整辅导。

### 五、命题角度与背诵卡

- 命题角度：德育过程规律辨识、德育原则场景匹配、心理健康问题判断、辅导方法选择；
- 背诵卡：**知是基础、行是关键**；**德育九原则"导尊疏一致，因材知行正纪，长善集体个别"**；**焦虑调认知、行为靠强化**。

## ⚠️ 易错提醒

- 德育**基本途径**是"思想品德课与其他学科教学"，不是"课外活动"；
- "尊重学生"≠"放弃要求"——尊重与严格要求是**结合**的（常考"只要尊重不要要求"的错误）；
- 心理辅导中，发现学生**有自伤/伤人风险**时保密原则要让位于生命安全，必须及时报告。
