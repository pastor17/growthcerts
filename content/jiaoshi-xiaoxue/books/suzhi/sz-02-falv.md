> 本章仅作考点框架与常考条文口径整理，请以**现行有效法律文本**为准。

## 考点梳理

### 2.1 核心法规与数字

| 法规 | 高频考点 |
|------|---------|
| 《教育法》 | 教育活动基本法；学校及其他教育机构的权利与义务 |
| 《义务教育法》 | 九年义务教育；**不收学费、杂费**；就近入学 |
| 《教师法》 | 教师权利义务、资格与任用、**待遇与奖励** |
| 《未成年人保护法》 | 家庭/学校/社会/网络/政府/司法六大保护；对未成年学生不得体罚 |
| 《预防未成年人犯罪法》 | 不良行为与严重不良行为的预防与矫治 |
| 《学生伤害事故处理办法》 | 事故责任归责 |

### 2.2 教师的权利与义务

- **权利**：教育教学权、学术研究权、指导评价权、报酬待遇权、民主管理权、进修培训权——"教（育教学）学（术）指（导评价）报（酬）民（主管理）进（修）"；
- **义务**：遵纪守法、履行教育教学职责、爱护尊重学生、制止有害行为、不断提高思想政治觉悟与业务水平。

### 2.3 学生权利保护（单选高频）

- **人身权**：生命健康权、人身自由权、人格尊严权（不得讽刺、侮辱、体罚）、隐私权（不得私拆信件/公开日记）、名誉权；
- **财产权**：不得乱收费、变相索要财物；
- **受教育权**：不得开除或变相剥夺（义务教育阶段不得开除）。

### 2.4 学生伤害事故责任（常考情形）

原则：**过错责任**为主——谁的过错谁担责：

| 情形 | 责任归属 |
|------|---------|
| 学校设施不符合标准致害 | **学校** |
| 教师体罚/失职（管理职责范围内） | **学校**（可向教师追偿） |
| 学生间打闹致伤、学校尽到管理职责 | 由**致害学生监护人**担责 |
| 校外第三人侵权 | 第三人担责；学校未尽管理职责的承担相应补充责任 |
| 假期/放学后学生自行活动、与学校职责无关 | 一般不属学校责任 |

## 🧠 记忆工具箱

### 口诀速记

- 教师权利六字诀：**"教学指报民进"**——教育教学、学术研究、指导评价、报酬待遇、民主管理、进修培训。
- 义务教育关键词：**"免学费杂费 + 就近入学 + 九年"**。
- 事故归责一句话：**"谁的错谁负责；校方错学校赔，学生错家长赔，第三人错第三人赔（学校按过错补）"**。

### 易混辨析 · 体罚与惩戒

| 维度 | 批评/合理惩戒 | 体罚/变相体罚 |
|------|--------------|--------------|
| 目的 | 教育学生 | 泄愤惩罚 |
| 手段 | 口头批评、适度纪律 | 打骂、罚站罚抄超限、侮辱 |
| 是否违法 | 允许（有边界） | **禁止**（侵犯人格尊严/健康权） |

## 📚 深度精讲（重点精细版）

### 一、教育法规体系层级（从高到低）

**宪法** → **教育法律**（教育法、义务教育法、教师法、未成年人保护法…） → **教育行政法规**（如学生伤害事故处理办法等） → **地方性法规/部门规章** → 学校规章制度（不得与上位法冲突）。

### 二、六部核心法规的高频考点

| 法规 | 必须记住的要点 |
|------|---------------|
| 教育法 | 教育基本法；学校权利与义务；教育经费与法律责任 |
| 义务教育法 | **免试就近入学**；**不收学费、杂费**；**不得开除**；**不得设重点班与非重点班**；不得体罚 |
| 教师法 | 教师六项权利与六项义务；教师资格与任用；待遇保障 |
| 未成年人保护法 | **家庭、学校、社会、网络、政府、司法六大保护**；防沉迷与未成年人模式；不得体罚与侮辱 |
| 预防未成年人犯罪法 | 不良行为与严重不良行为的预防、矫治与教育 |
| 学生伤害事故处理办法 | 事故责任归责与处理程序 |

### 三、教师六项义务（《教师法》口径，简记版）

① 遵纪守法、为人师表；② 贯彻教育方针、履行聘约、完成教育教学任务；③ 对学生进行思想品德、法制与科学文化教育，组织有益活动；④ 关心爱护全体学生、尊重人格、促进全面发展；⑤ **制止有害于学生的行为**、批评抵制有害现象；⑥ 不断提高思想政治觉悟与业务水平。

> 记忆锚：**守法、履职、育人、爱生、护生、进修**。

### 四、学生伤害事故：学校担责 vs 不担责

| 情形 | 责任 |
|------|------|
| 校舍设施不符合安全标准致害 | **学校担责** |
| 学校组织活动未采取必要安全措施 | **学校担责** |
| 教师体罚或履职中失职致害 | **学校担责**（可向教师追偿） |
| 学生间打闹致伤、学校已尽教育管理职责 | **致害学生监护人**担责 |
| 学生自行上学/放学途中、假期自行活动发生事故 | 一般**不由学校**担责 |
| 学生有特殊体质或疾病、家长未告知 | 学校一般不担责或按过错承担 |

### 五、典型例题（带解析）

**例题 1**：班主任为避免学生上课玩手机，没收手机并当众翻看学生聊天记录。该做法主要侵犯了学生的？
A. 受教育权　B. 隐私权　C. 人身自由权　D. 财产权
**答案 B**。解析：当众翻看聊天记录属于公开学生私密信息，侵犯隐私权（体罚/侮辱则侵犯人格尊严）。

**例题 2**：学生在假期自行到校外游泳发生意外，学校此前已多次开展安全教育。该事故责任应如何认定？
A. 学校承担全部责任　B. 学校已尽教育管理职责，一般不由学校承担责任　C. 班主任个人承担　D. 由教育行政部门承担
**答案 B**。解析：事故发生在学校职责范围之外，且学校已尽教育管理义务，责任由监护人或其他责任主体承担。

### 六、命题角度与背诵卡

- 命题角度：权利类型判断（隐私/人格尊严/受教育权）、事故归责、义务教育法数字与禁止行为、六大保护归属；
- 背诵卡：**免学费杂费、就近入学、不得开除、不设重点班**；**谁的错谁负责；校方错学校赔，学生错家长赔**；**未成年六大保护：家学社网政司**。

## ⚠️ 易错提醒

- 学校**可以**批评教育学生，但**不得**体罚、变相体罚或侮辱人格尊严——"罚站一整节课""讽刺挖苦"都是考点；
- 教师"体罚"造成伤害，对外先由**学校**承担（职务行为），学校再依规定追偿——别直接选"教师个人全责"；
- 义务教育阶段**不得开除**学生（开除=侵犯受教育权）。
