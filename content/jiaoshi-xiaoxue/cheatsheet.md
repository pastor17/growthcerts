> **用法**：考前 3 天起只过这一页 + 错题笔记；**科目一写作 50 分、材料分析 42 分**，两科都要动手写。

## 一、科目一《综合素质》

### 材料分析模板（14 分/题，写 3~4 点）

```
总评：该教师的做法符合（违背）××理念/职业道德的要求
分点：① 观点（术语）→ ② 材料事实（引用题干具体行为）→ ③ 简要分析（为什么体现/违背）
总结：作为教师应……
```

### 必背三观 + 职业道德

| 项目 | 内容 |
|------|------|
| **教育观** | 面向**全体**学生、促进**全面**发展、促进**个性**发展、以培养**创新精神与实践能力**为重点 |
| **学生观** | **"两独一发"**：独特的人、独立意义的人、发展的人 |
| **教师观** | 角色：促进者、建设者、研究者、开放教师；行为：尊重赞赏（对生）、帮助引导（对教）、反思（对己）、合作（对同事） |
| **职业道德** | **"三爱两人一终身"**：爱国守法、爱岗敬业、关爱学生；教书育人、为人师表；终身学习 |

### 写作（50 分，一般不少于 800 字）

```
结构：引（材料/名言 + 亮明观点）→ 议（2~3 个分论点，各配事例 + 分析）→ 联（联系小学教育实际）→ 结（升华回扣）
素材四主题：尊重与因材施教｜发展与等待｜创新与实践｜爱与责任
时间：审题 5 分钟 → 列纲 3 分钟 → 成文 30 分钟 → 检查 5 分钟
```

## 二、科目二《教育教学知识与能力》

### 人名—理论速查（高频）

| 人物 | 理论 |
|------|------|
| 皮亚杰 | 认知发展四阶段（感知运动/前运算/具体运算/形式运算） |
| 埃里克森 | 心理社会八阶段（学龄期=勤奋 vs 自卑） |
| 科尔伯格 | 道德发展三水平六阶段 |
| 马斯洛 | 需求层次（生理/安全/归属与爱/尊重/自我实现） |
| 布鲁纳 | 发现学习、认知结构 |
| 奥苏贝尔 | 有意义接受学习 |
| 韦纳 | 成败归因（**努力＝内部、不稳定、可控**最有利） |
| 班杜拉 | 观察学习、自我效能感（**成败经验**为主要来源） |
| 艾宾浩斯 | 遗忘曲线（**先快后慢**） |

### 简答题写法

- **1 点 2 分**：每点 8~15 字，分点编号；
- 常考方向：教学原则、德育原则与方法、班级管理模式、小学生身心发展特点、教学设计要素、班主任工作内容。

### 教学设计（40 分）

```
教学目标（知识与技能 / 过程与方法 / 情感态度与价值观）
→ 教学重难点 → 教学过程（导入、新授、巩固练习、小结、作业）→ 板书设计 → 教学反思
```

## 三、必背数字与结论

- 笔试成绩**报告分 120 分制、70 分及以上合格**；单科成绩有效期一般 **2 年**；
- 写作一般要求**不少于 800 字**（未达标直接扣分）；
- **遗忘先快后慢**；过度学习 **150%** 效果较佳；
- 个体身心发展五规律：**顺序（循序渐进）、阶段（不搞一刀切）、不平衡（抓关键期）、互补（长善救失）、个别差异（因材施教）**；
- **德育最基本方法=说服教育法**；最基本途径=思想政治课与其他学科教学。

## 四、面试要点（笔试后）

| 环节 | 时长 | 要点 |
|------|------|------|
| 结构化问答 | 5 分钟 | 突发事件处理、家校沟通、教育理念三类题 |
