> **先说结论**：教师资格证在 GitHub 上的开源资源**明显少于软考**，且多为中学/幼儿园学段或较早年份。因此本站建议：**官方《考试大纲》（ntce.neea.edu.cn 免费下载）+ 本站精讲与题库**为主，下列仓库作**补充素材**。下载后请遵守作者许可，仅供个人学习。

## 可用资源（已逐一核验）

### 1. 教资主观题记忆归纳（综合素质 / 教育知识与能力）
- 仓库：[Chen-Jialin/Teacher-Certification-Exam-Summary](https://github.com/Chen-Jialin/Teacher-Certification-Exam-Summary) ｜ 核验：**MIT 许可 · 2021 年最后更新 · 已归档只读 · 约 800KB**
- 内含：《国家教师资格证考试教育知识与能力归纳总结》《综合素质归纳》——**Markdown + PDF 双格式**，专攻主观题背诵
- 适合：考前背简答/材料题要点的补充清单（内容为 2021 版口径，最新法规表述请对照当年官方大纲）
- 说明：星标少但**内容真实对口、许可清晰**，作为"背诵小册子"够用

### 2. 教资真题试卷与解析（中学为主，含小学）
- 仓库：[NicknamedCoco/TeacherExamResources](https://github.com/NicknamedCoco/TeacherExamResources) ｜ 核验：**2023-02 更新 · 约 51MB · 无开源许可**
- 内含：**综合素质、教育知识与能力的历年真题试卷与解析**（README 说明含小学资料、以中学为主，另附网盘打包链接）
- 适合：找真题练手；小学考生挑小学卷使用
- 注意：无许可证 + 含网盘外链，**仅个人学习使用，不要转售**；网盘链接可能失效

### 3. 教资刷题平台（含 2026 上笔记文档）
- 仓库：[XIAOZHAOXSXH/edu_study](https://github.com/XIAOZHAOXSXH/edu_study) ｜ 核验：**2026-06 更新 · 约 4MB · 无开源许可**
- 内含：可自部署的**刷题系统**（顺序/随机/错题/收藏、自动组卷、AI 解析与主观题 AI 判分）+ **26 上 中学一轮/二轮笔记（综合素质、教育知识与能力 docx）**
- 适合：想要"自己的题库系统"的考生；笔记为**中学学段**，小学考生可借鉴科目一知识框架
- 注意：需要 Node.js 环境与模型 API Key 才能完整体验；无许可证，仅自用

### 4. 综合素质（幼儿园）备考系统（学段不同，作工具参考）
- 仓库：[sodalevy/ntce_exam](https://github.com/sodalevy/ntce_exam) ｜ 核验：**2026-07 更新 · 约 100KB · 无开源许可**
- 内含：纯前端备考网站（学习计划/知识点学习/章节刷题/错题本/进度追踪，本地存储）
- 适合：借鉴其"按考试日期自动生成学习计划"的思路；**内容为幼儿园学段**，小学考生仅作工具参考

## 官方资源（最该优先用的）

- **《中小学教师资格考试大纲》**：中小学教师资格考试网 → 资料下载栏目**免费下载**（含各学段各科目大纲）；
- 报名与成绩入口：[ntce.neea.edu.cn](https://ntce.neea.edu.cn)；
- 正版教材：选择与当年大纲匹配的最新版本。

## 避坑提示

- 站内检索"教资"时，GitHub 会混入大量**无关高星仓库**（编程教程、资料杂烩等），请以本页核验清单为准；
- 部分仓库**无开源许可证**：可以学习使用，但不要搬运、二次分发或商用；
- 注意**学段（小学/中学/幼儿园）与年份**是否匹配你的报考学段。
