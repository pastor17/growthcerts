## 考点梳理

### 3.1 教学的概念与意义

- **教学**是教育目的规范下、教师的教与学生的学共同组成的一种**双边活动**；
- **教学是学校教育的中心工作**，是学生获得系统知识、发展能力、形成品德的基本途径；
- **教学与教育的关系**：教学是教育的**组成部分**（教育还包括课外活动、社会实践等）；
- **教学与智育的关系**：教学是智育的**主要途径**，但不是唯一途径，教学也不只承担智育任务。

### 3.2 教学过程的基本规律（必背四条）

| 规律 | 含义 | 教育启示 |
|------|------|---------|
| **间接经验与直接经验相结合** | 学生以学习**间接经验（书本知识）为主**，并以直接经验为基础 | 理论联系实际，重视直观与实践活动 |
| **掌握知识与发展能力相统一** | 掌握知识是发展能力的基础，能力发展又是掌握知识的重要条件 | 反对"形式教育论"（只重能力）与"实质教育论"（只重知识）的片面性 |
| **教师主导作用与学生主体作用相统一** | 教师起主导，学生是学习主体 | 发挥两者积极性，反对教师中心与学生中心两种极端 |
| **传授知识与思想品德教育相统一**（教学的教育性规律） | 教学永远具有教育性 | 寓德育于教学之中，教书育人 |

### 3.3 教学过程的基本结构

**引起学习动机 → 领会知识（感知、理解教材，**中心环节**）→ 巩固知识 → 运用知识 → 检查与评价学习效果**。

### 3.4 中学教学原则（重点）

| 原则 | 依据与要求 |
|------|-----------|
| **直观性原则** | 利用实物、模像与语言直观；**防止直观滥用**，要与讲解结合 |
| **启发性原则** | 调动学生主动性，"不愤不启，不悱不发" |
| **循序渐进原则（系统性）** | 按学科逻辑与学生认识顺序教学 |
| **巩固性原则** | 及时复习，学以致用 |
| **因材施教原则** | 针对个别差异，**长善救失** |
| **理论联系实际原则** | 知识教学与生活实践结合 |
| **科学性与思想性相统一原则** | 保证内容科学正确，同时进行思想教育 |
| **量力性原则（可接受性）** | 内容难度适合学生发展水平，**最近发展区**内施教 |

### 3.5 中学教学方法

| 类别 | 方法 | 特点 |
|------|------|------|
| **以语言传递为主** | 讲授法、谈话法、讨论法、读书指导法 | 讲授法是**最常用**的方法 |
| **以直接感知为主** | 演示法、参观法 | 强调直观 |
| **以实际训练为主** | 练习法、实验法、实习作业法、实践活动法 | 强调动手与实践 |
| **以情感陶冶为主** | 欣赏教学法、情境教学法 | 强调体验 |
| **以引导探究为主** | 发现法（布鲁纳）、探究—研讨法 | 强调自主探究 |

> 选择依据：教学目标、内容特点、学生特点、教师素养、教学条件与时间。

### 3.6 教学组织形式

- **班级授课制**：**夸美纽斯**在《大教学论》中系统论述，我国最早出现于**1862 年京师同文馆**；特点是**班、课、时**，优点是大面积培养人才、利于发挥教师主导作用，缺点是难以兼顾个别差异、不利于个性发展；
- **个别教学制**：古代主要形式，效率低；
- **分组教学**：能力分组或作业分组；
- **现场教学、复式教学**（一位教师同时教两个以上年级）、**特朗普制**（大班上课 + 小班研究 + 个别教学）、**翻转课堂**与混合式教学。

### 3.7 教学工作的基本环节

**备课（三备：备教材、备学生、备教法；三种计划：学期教学进度计划、单元计划、课时计划即教案）→ 上课（**中心环节**）→ 作业布置与批改 → 课外辅导 → 学业成绩检查与评定**。

**上好一堂课的标准**：目标明确、内容正确、方法得当、表达清晰、**组织严密、气氛热烈**、学生主体性得到发挥。

### 3.8 教学评价

| 分类标准 | 类型 |
|---------|------|
| **作用与时间** | **诊断性评价**（教学前）、**形成性评价**（教学中）、**总结性评价**（教学后） |
| **评价标准** | **相对性评价**（常模参照，看排名）、**绝对性评价**（标准参照，看是否达标）、个体内差异评价 |
| **评价方法** | 定量（测验、量表）与定性（观察、评语、档案袋） |

## 🔍 深度精讲

### 深讲 1：四条教学规律在材料题中的识别信号

| 材料描述 | 对应规律 |
|---------|---------|
| 教师只讲书本知识，学生缺乏实践经验、不理解 | **间接经验与直接经验相结合**（缺少直接经验基础） |
| 教师让学生死记硬背，学生"高分低能" | **掌握知识与发展能力相统一** |
| 教师满堂灌、学生被动听；或教师完全放手、学生无所适从 | **教师主导与学生主体相统一** |
| 教师在学科教学中渗透价值观、结合时事进行思想教育 | **传授知识与思想品德教育相统一** |

**答题句式**："材料中教师××的做法，违背（体现）了教学过程中××相统一的规律，因为……因此教师应……"

### 深讲 2：中学课堂"启发性"怎么落地

启发性原则不是"多提问"，而是要**创设问题情境、引发认知冲突、留出思考时间**：

1. **设疑**：从学生已有经验与认知矛盾处提问（如"为什么同样是金属，钠与水反应却如此剧烈？"）；
2. **等待**：提问后**留 3~5 秒思考时间**，不急于点名学生回答；
3. **追问**：用"为什么""还有别的方法吗""如果条件改变会怎样"推进思维深度；
4. **归因**：对错误回答给出**建设性反馈**（指出思路中的合理部分），保护思考积极性；
5. **总结**：由学生归纳结论，教师补充与提炼。

**常见失分**：把"提问次数多"当作启发性；把"教师自问自答"当作启发。

### 深讲 3：班级授课制的"扬长避短"

**优势**：① 大面积、高效率培养人才；② 利于发挥教师主导作用；③ 利于学生间相互交流与集体教育；④ 利于教学管理与质量监控。

**局限**：① 难以兼顾个别差异，不利于因材施教；② 学生主动性与独立性受限，易"齐步走"；③ 偏重知识传授，实践与创新能力培养不足。

**改进路径（答题加分）**：**分层教学与小班化**、**走班制与选修课**、**小组合作与个别辅导结合**、**翻转课堂与混合式学习**、**分层作业与个性化评价**。

### 例题（带解析）

**例题 1**：教学过程中"掌握知识与发展能力相统一"的规律，要求我们反对？
A. 启发式教学　B. 形式教育论与实质教育论的片面性　C. 因材施教　D. 循序渐进
**答案 B**。解析：形式教育论只重能力训练、实质教育论只重知识传授，二者均割裂了知识与能力的关系，违背了该规律；启发式教学、因材施教与循序渐进是教学原则。

**例题 2**：我国最早采用班级授课制的学校是？
A. 京师大学堂　B. 京师同文馆　C. 南洋公学　D. 岳麓书院
**答案 B**。解析：我国最早采用班级授课制的是 1862 年创办的京师同文馆；夸美纽斯在《大教学论》中最早系统论述班级授课制。

**例题 3**：教师在教学过程中只强调知识灌输，学生"高分低能"。这主要违背了？
A. 直观性原则　B. 掌握知识与发展能力相统一规律　C. 巩固性原则　D. 量力性原则
**答案 B**。解析："高分低能"反映知识掌握与能力发展脱节，违背了**掌握知识与发展能力相统一**的教学规律。

## ⚠️ 易错提醒

- 教学是学校教育的**中心工作**，**上课是教学工作的中心环节**，两个"中心"不要混；
- 学生以学习**间接经验为主**（不是直接经验）；
- 形式教育论（重能力）与实质教育论（重知识）都片面，答题要点出"二者统一"；
- 班级授课制由**夸美纽斯系统论述**、我国最早于**京师同文馆（1862）**；
- 诊断性（前）、形成性（中）、总结性（后）评价的时间定位不能错；
- 启发性原则的核心是**引发思考**，不是"提问多"。
