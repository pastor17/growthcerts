## 考点梳理

### 6.1 品德的心理结构

**知情意行四要素**：**道德认识（基础与核心）、道德情感（内在动力）、道德意志（精神力量）、道德行为（衡量品德的重要标志）**。

- **道德认识**：对道德规范及其意义的认识，是品德形成的**基础与先导**；
- **道德情感**：伴随道德认识产生的内心体验，是品德形成的**内在动力**；
- **道德意志**：为实现道德目的而克服困难的毅力；
- **道德行为**：在一定道德认识与情感支配下的外部行动，是**衡量品德的重要标志**。

**品德形成的一般过程**：**依从（从众、服从）→ 认同 → 内化**。

### 6.2 道德发展理论（高频人物—阶段对应）

**皮亚杰道德发展阶段（对偶故事法）**

| 阶段 | 年龄 | 特征 |
|------|------|------|
| **自我中心阶段（前道德）** | 2–5 岁 | 规则无约束力 |
| **权威阶段（他律道德）** | 5–8 岁 | 服从权威，**只看结果不看动机** |
| **可逆性阶段（自律道德）** | 8–10 岁 | 认识到规则可协商，**开始考虑动机** |
| **公正阶段** | 10–12 岁 | 考虑情境与公平，追求平等 |

**科尔伯格道德发展三水平六阶段（道德两难故事法）**

| 水平 | 阶段 | 取向 |
|------|------|------|
| **前习俗水平** | ① 惩罚与服从取向；② 相对功利（朴素利己）取向 | 以避免惩罚、获得奖励为标准 |
| **习俗水平** | ③ "好孩子"（寻求认可）取向；④ **维护权威或社会秩序取向** | 以他人期望与社会规范为标准 |
| **后习俗水平** | ⑤ 社会契约取向；⑥ 普遍伦理（良心）取向 | 以契约、法律与普遍原则为标准 |

### 6.3 中学德育原则（重点）

| 原则 | 要求 |
|------|------|
| **导向性原则** | 坚持正确政治方向与价值导向 |
| **疏导原则（循循善诱）** | **讲明道理、疏导思想**，以理服人 |
| **尊重学生与严格要求相结合** | "**严慈相济**"，尊重人格同时提出合理要求 |
| **知行统一原则** | 重视道德认识与道德实践结合，言行一致 |
| **正面教育与纪律约束相结合** | 表扬鼓励为主，辅以必要纪律 |
| **依靠积极因素克服消极因素（长善救失）** | 用学生优点克服缺点 |
| **教育影响一致性与连贯性原则** | 校内外、各科教师与家长要求一致、前后连贯 |
| **因材施教原则** | 针对学生个性特点与年龄特征施教 |

### 6.4 中学德育方法

| 方法 | 特点 |
|------|------|
| **说服教育法** | 讲解、报告、谈话、参观，提高道德认识（**最基本方法**） |
| **榜样示范法** | 以榜样人物与教师身教引导 |
| **实际锻炼法** | 通过活动与日常行为训练形成品德 |
| **情感陶冶法** | 环境陶冶、艺术陶冶、人格感化（**潜移默化**） |
| **品德评价法（奖惩法）** | 表扬、奖励、批评、处分 |
| **自我教育法（指导自我修养）** | 自我反省、座右铭、写日记 |

**德育途径**：思想政治课与其他学科教学（**最基本、最经常、最有效**）、课外活动与社会实践、班主任工作、共青团与学生会活动、校园文化、家校社协同。

**德育模式**：**认知模式**（科尔伯格，重道德认知）、**体谅模式**（彼得·麦克费尔，重道德情感）、**社会学习模式**（班杜拉，重观察学习）、**价值澄清模式**（拉斯，重自主选择）。

### 6.5 班级管理与课堂管理

**班级管理的模式**：**常规管理、平行管理、民主管理、目标管理**。

**班级管理的原则**：方向性、**学生主体**、民主公正、**因材施教**、严慈相济、**疏导**。

**课堂管理要点**：
- **课堂气氛**：积极的课堂气氛表现为**秩序良好、师生互动活跃、学生参与度高**；
- **课堂纪律的形成阶段**：**反抗期 → 规范期 → 成熟期**（或"初创、稳定、成熟"等表述，按教材口径）；
- **问题行为处置**：**最小干预原则**（非言语暗示、走近、提问、幽默化解），避免当众严厉批评导致对抗升级；
- **课堂问题行为原因**：学生自身（厌学、注意力缺陷）、教师（教学单调、要求不当）、环境（座位、噪音）。

**班主任工作**：了解学生与研究学生（**前提**）、组织培养班集体（**中心工作**）、做好个别教育工作（含优生与后进生转化）、协调各方教育影响、开展班级活动、做好学生评价与操行评定、班主任工作计划与总结。

### 6.6 教师心理与专业发展

- **教师专业发展内容**：专业理想、专业知识、专业能力、专业自我；
- **教师专业发展阶段**（福勒与布朗的关注理论）：**教学前关注 → 早期生存关注 → 教学情境关注 → 关注学生**；
- **教师职业倦怠**（**马勒诗**）：三个维度——**情绪耗竭、去个性化（人格解体）、低个人成就感**；
- **缓解途径**：合理工作量与角色期望、**专业支持与督导**、教师团队互助、心理疏导与培训、改善评价与激励机制；
- **教师心理健康意义**：影响教学效果、影响学生心理健康与人格发展、影响教师自身生活质量。

## 🔍 深度精讲

### 深讲 1：皮亚杰与科尔伯格在材料题中的识别

两者都考"道德判断依据"，但层次不同：

| 材料中学生的话 | 对应理论与阶段 |
|--------------|--------------|
| "妈妈说不能这样做" | 皮亚杰**他律道德**；科尔伯格阶段③（好孩子取向）或①（服从权威） |
| "这样做会被罚" | 科尔伯格**前习俗水平阶段①（惩罚与服从）** |
| "这样做对我有利" | 科尔伯格**前习俗水平阶段②（相对功利）** |
| "规则是大家商量的，可以改" | 皮亚杰**自律道德（可逆性阶段）** |
| "法律是社会契约，若不合理可以修改" | 科尔伯格**后习俗水平阶段⑤（社会契约）** |
| "不管别人怎么看，我良心不安" | 科尔伯格**后习俗水平阶段⑥（普遍伦理）** |

**答题句式**："该学生的道德判断处于科尔伯格道德发展理论的××水平××阶段，因为其判断依据是××；据此，教师应通过××（道德两难讨论、榜样示范、角色扮演）促进其道德判断向更高水平发展。"

### 深讲 2：后进生转化的"标准动作"

中学德育与班主任工作的高频情境题是**后进生转化**，标准答题框架：

1. **关心爱护、尊重人格**：先建立信任（尊重与严格要求相结合原则）；
2. **一分为二地看待**：寻找闪光点，**长善救失**（依靠积极因素克服消极因素）；
3. **归因分析**：是学习基础、方法问题，还是家庭、同伴、情绪问题；
4. **因材施教**：制定**阶梯式目标**与个别辅导计划，让其获得**成功体验**；
5. **协同教育**：班主任、科任教师、家长与学生同伴形成**一致的要求**（教育与影响一致连贯）；
6. **长期跟进**：允许反复，及时强化，防止"一次失败就否定"。

> 常见失分：只写"多关心、多鼓励"，缺少**归因分析、阶梯目标与协同机制**。

### 深讲 3：教师职业倦怠的识别与干预（中学教师高频）

**三维度表现**：
- **情绪耗竭**：疲惫、无力、情绪资源被掏空；
- **去个性化**：对学生冷漠、讽刺、机械应付、把学生当"对象"；
- **低个人成就感**：觉得工作没意义、努力没有回报。

**成因**：工作负荷与班级规模、升学压力与考核压力、学生问题行为、家校冲突、职业发展通道不畅、社会支持不足。

**干预（按主体分层写，得分最全）**：
1. **学校层面**：合理工作量与考核机制、提供**专业督导与同伴支持**、改善办公与心理支持条件、畅通发展通道；
2. **教师个人层面**：调整认知（合理期望、接纳不完美）、时间管理与边界设定、锻炼与休息、发展专业兴趣与教研能力；
3. **社会与家庭层面**：提升教师职业声望与待遇保障、家校沟通机制、减少不合理非教学负担。

## ⚠️ 易错提醒

- 品德的**基础是道德认识、标志是道德行为**，两句话不能互换；
- 皮亚杰用**对偶故事法**、科尔伯格用**道德两难故事法**，方法归属常被互换；
- 德育的**最基本方法是说服教育法**，最基本途径是**思想政治课与其他学科教学**；
- 德育原则中"**长善救失**"对应"依靠积极因素克服消极因素"，不要与疏导原则混；
- 教师关注理论的顺序是"**教学前关注 → 生存关注 → 情境关注 → 关注学生**"，不要颠倒；
- 职业倦怠三维度中"**去个性化**"指对学生冷漠而非"个性消失"。
