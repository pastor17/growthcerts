## 考点梳理

### 2.1 教育法律体系与效力层级

**层级由高到低**：**宪法 → 教育法律（全国人大常委会）→ 教育行政法规（国务院）→ 教育部门规章（教育部等）→ 地方性教育法规/规章**。

**核心法律（中学常考）**

| 法律 | 定位与高频考点 |
|------|--------------|
| 《教育法》 | 教育**基本法**；教育方针、学校及其他教育机构的权利义务、教育投入 |
| 《义务教育法》 | 九年义务教育；**不收学费、杂费**；不得设置重点学校与重点班；**不得开除学生** |
| 《教师法》 | 教师**权利与义务**、资格制度、待遇与奖励、法律责任 |
| 《未成年人保护法》 | **家庭、学校、社会、网络、政府、司法**六大保护；**强制报告**制度；不得体罚或变相体罚 |
| 《预防未成年人犯罪法》 | 不良行为与严重不良行为的分级干预、专门教育 |
| 《民法典》（相关部分） | 无民事行为能力人（不满 8 周岁）、限制民事行为能力人（8 周岁以上未成年人）致害的责任承担 |

### 2.2 教师的权利与义务（必背）

**教师的六大权利**
1. **教育教学权**（进行教育教学活动，开展教育教学改革与实验）；
2. **科研权**（从事科学研究、学术交流，参加专业学术团体）；
3. **指导评价权**（指导学生学习与发展、评定学生品行与学业成绩）；
4. **报酬待遇权**（按时获取工资报酬，享受国家规定的福利待遇及寒暑假带薪休假）；
5. **民主管理权**（对学校教育教学、管理工作和教育行政部门工作提出意见与建议，参与民主管理）；
6. **进修培训权**（参加进修或其他方式的培训）。

**教师的六大义务**
1. 遵守宪法、法律与职业道德，为人师表；
2. 贯彻国家教育方针，遵守规章制度，执行学校教学计划，完成教育教学工作任务；
3. 对学生进行宪法确定的基本原则与爱国主义、民族团结、法制及思想道德等教育；
4. 关心爱护全体学生，尊重学生人格，促进学生在品德、智力、体质等方面全面发展；
5. 制止有害于学生的行为或其他侵犯学生合法权益的行为，批评和抵制有害于学生健康成长的现象；
6. 不断提高思想政治觉悟与教育教学业务水平。

### 2.3 学生的权利保护

| 权利 | 内容 | 常见侵权情形 |
|------|------|-------------|
| **受教育权** | 参加教育教学活动、使用教育教学设施 | 随意停课、劝退、开除（义务教育阶段**不得开除**） |
| **人身权** | 生命健康权、人格尊严权、隐私权、名誉权 | 体罚或变相体罚、当众羞辱、公开学生隐私与成绩排名 |
| **财产权** | 学生的合法财产受保护 | 没收不还、随意罚款 |
| **著作权等** | 学生的作品、发明创造 | 教师署名学生作品 |

### 2.4 学生伤害事故的责任归责（高频）

按《学生伤害事故处理办法》的思路，**关键看学校是否尽到教育、管理与保护职责**：

- **学校承担责任**：设施设备不符合安全标准、教师体罚、组织活动未采取安全措施、已知学生特殊体质未予必要注意、发现学生危险行为未制止等；
- **学校不承担责任**：**不可抗力**、学生自身原因或特异体质且学校不知情、学生自行上下学途中发生的事故（非学校组织）、第三人侵权（由第三人承担，学校有过错承担相应补充责任）；
- **监护责任不转移**：学生在校期间，**监护人的监护责任并不因此转移给学校**，学校承担的是**教育、管理职责**。

### 2.5 教师违法行为与法律责任

| 行为 | 后果 |
|------|------|
| 体罚或变相体罚学生，经教育不改 | 行政处分或解聘 |
| 侮辱、殴打学生，情节严重 | 依法承担相应法律责任（可能涉及治安或刑事责任） |
| 故意不完成教育教学任务造成损失 | 行政处分或解聘 |
| 品行不良、影响恶劣 | 行政处分或解聘 |
| 侵犯学生合法权益造成损失 | 责令赔偿损失 |

## 🔍 深度精讲

### 深讲 1：为什么"监护责任不转移"是核心考点

许多考生默认"孩子在学校，出了事学校全责"，这是错误的：

- **监护人**（通常是父母）依法对未成年人的人身、财产及其他合法权益承担**监护职责**，这一职责**不因学生在校而转移**；
- **学校**承担的是**教育、管理职责**：提供安全的教育教学环境、进行安全教育、组织活动时采取安全措施、发现危险及时制止与处理；
- 因此判断责任的关键是"**学校有没有过错**"——有过错（如设施破损未修、教师体罚、组织活动无安全措施）则承担相应责任；无过错则不承担。

**案例模型**：体育课上学生按教师要求完成规定动作时意外受伤 → 若教师已讲解示范、场地器材合格、及时救治，学校**一般不承担**责任；若器材老化未检、未做安全提示 → 学校**有过错需担责**。

### 深讲 2：强制报告制度在中学场景的应用

《未成年人保护法》确立了**强制报告制度**：国家机关、居民委员会、村民委员会、**密切接触未成年人的单位及其工作人员**（含学校与教师）在工作中发现未成年人身心健康受到侵害、疑似受到侵害或面临其他危险情形的，**应当立即向公安、民政、教育等部门报告**。

**中学常见情形**：发现学生身上有伤痕、长期情绪异常、疑似遭受家暴或性侵害、被遗弃或监护缺失。**正确做法**：① 保护学生安全；② **依法报告**（不是"先内部消化"或"先与家长沟通"）；③ 保护隐私、做好记录；④ 配合有关部门跟进。

### 深讲 3：数字与时效类考点整理

| 事项 | 要点 |
|------|------|
| 义务教育年限 | **九年** |
| 民事行为能力 | 不满 **8 周岁**为无民事行为能力人；8 周岁以上未成年人为限制民事行为能力人 |
| 教师申诉 | 对学校处理不服可向教育行政部门申诉（期限按现行规定） |
| 未成年人保护 | 六大保护 + **强制报告** |
| 学生伤害事故 | 学校担责以**过错**为前提 |

**记忆策略**：法规部分的年限与数字不多，但**易与其他科目混淆**（如把"8 周岁"记成"10 周岁"），建议单独做一张"法规数字卡"。

## ⚠️ 易错提醒

- **学校不承担监护责任**，只承担教育、管理职责——这是案例判责的前提；
- 义务教育阶段**不得开除学生**，也不得设重点学校与重点班；
- 教师六权中"**指导评价权**"是最容易被忽略的一项；
- 发现学生疑似受侵害时应**立即报告**，不是先做内部处理；
- 体罚与变相体罚（罚站过久、罚抄过量、不许上厕所等）都属于违法行为；
- 学生伤害事故责任看**学校有无过错**，不要一律判"学校全责"或"学校无责"。
