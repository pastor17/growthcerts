## 考点梳理

### 3.1 《中小学教师职业道德规范》六条（必背）

| 条目 | 核心要求 |
|------|---------|
| **爱国守法** | 热爱祖国，遵守教育法律法规，**依法履行教师职责**，不得有违背党和国家方针政策的言行 |
| **爱岗敬业** | 忠诚于人民教育事业，勤恳敬业、甘为人梯、**认真备课上课、认真批改作业、认真辅导学生**，不得敷衍塞责 |
| **关爱学生** | 关心爱护全体学生，**尊重学生人格**，平等公正对待学生；保护学生安全，关心学生健康，维护学生权益；**不讽刺、挖苦、歧视学生，不体罚或变相体罚学生** |
| **教书育人** | 遵循教育规律，**因材施教**；培养学生良好品行，激发创新精神，促进学生全面发展；**不违规加重学生课业负担**，不以分数作为评价学生的唯一标准 |
| **为人师表** | 严于律己，以身作则；**作风正派、廉洁奉公**；自觉抵制有偿家教，不利用职务之便谋取私利；尊重同事与家长，团结协作 |
| **终身学习** | 崇尚科学精神，**树立终身学习理念**，拓宽知识视野、更新知识结构，潜心钻研业务，勇于探索创新，不断提高专业素养与教育教学水平 |

> 口诀：**"三爱两人一终身"**——爱国守法、爱岗敬业、关爱学生（三爱）；教书育人、为人师表（两人）；终身学习。

### 3.2 教师职业行为准则中的禁止性要求（高频）

- **不得**在教育教学活动中及其他场合有损害党中央权威、违背党的路线方针政策的言行；
- **不得**损害国家利益、社会公共利益，或违背社会公序良俗；
- **不得**通过课堂、论坛、讲座、信息网络等渠道发表、转发错误观点，或编造散布虚假信息、不良信息；
- **不得**违反教学纪律，**敷衍教学**，或擅自从事影响教育教学本职工作的兼职兼薪行为；
- **不得**歧视、侮辱学生，**严禁虐待、伤害学生**；
- **不得**在教育教学活动中遇突发事件、面临危险时，**不顾学生安危擅离职守**；
- **不得**与学生发生任何不正当关系，严禁任何形式的猥亵、性骚扰行为；
- **不得**在招生、考试、推优、保送及绩效考核、岗位聘用、职称评聘、评优评奖等工作中**徇私舞弊、弄虚作假**；
- **不得**索要、收受学生及家长财物或参加由学生及家长付费的宴请、旅游、娱乐休闲等活动，**不得**向学生推销图书报刊、教辅材料、社会保险或利用家长资源谋取私利；
- **不得**组织、诱导学生有偿补课，或为校外培训机构和他人介绍生源、提供相关信息。

### 3.3 中学场景常见师德情境与判断

| 情境 | 判断要点 |
|------|---------|
| 教师利用周末给本班学生有偿补课 | 违背**为人师表**（廉洁从教、抵制有偿家教） |
| 教师按成绩排座位、公开排名羞辱后进生 | 违背**关爱学生**（尊重人格、平等公正）与**教书育人**（不以分数为唯一标准） |
| 教师对学生的提问不耐烦、说"你怎么这么笨" | 违背**关爱学生**（讽刺挖苦） |
| 教师备课敷衍、作业不批改 | 违背**爱岗敬业** |
| 教师发现学生危险行为及时制止并救助 | **符合**关爱学生、爱岗敬业 |
| 教师主动进修、学习新课标并改进教学 | **符合**终身学习 |
| 教师收受家长礼品与购物卡 | 违背**为人师表**（廉洁从教） |
| 教师把学生隐私（家庭情况、心理问题）在班会上公开 | 违背**关爱学生**与法律法规（隐私权） |

## 🧠 记忆工具箱

### 六条口诀

**"三爱两人一终身"**：爱国守法、爱岗敬业、关爱学生 + 教书育人、为人师表 + 终身学习。

### 关爱学生"三不"

**"不讽刺挖苦歧视、不体罚或变相体罚、不放弃任何一个学生。"**

### 为人师表"三不"

**"不有偿家教、不收受财物、不谋取私利。"**

### 师德材料分析题结构

**"判断师德行为是否恰当 → 对应职业道德条目 → 结合材料说明 → 提出正确做法"**（一般写 3~4 点）。

## 🔍 深度精讲

### 深讲 1：师德材料分析题的高分写法

**设问**："请从教师职业道德的角度评析材料中教师的行为。"

**答题模板**

1. **总评**：该教师的做法**符合/违背**《中小学教师职业道德规范》的要求；
2. **分点（每点三件套：条目 + 材料 + 分析）**：
   - **关爱学生**：材料中教师对××同学……（具体行为），体现了（或违背了）关心爱护全体学生、尊重学生人格、平等公正对待学生的要求；
   - **教书育人**：教师因材施教、不以分数作为唯一评价标准，符合循循善诱、促进学生全面发展的要求；
   - **为人师表**：教师拒收家长礼品、以身作则，体现了廉洁从教；
   - **爱岗敬业 / 终身学习**：教师认真备课、主动进修，符合相应要求。
3. **总结**：作为中学教师，应自觉践行"三爱两人一终身"，做到以德立身、以德施教。

**常见失分**：只写条目不对应材料（"空喊口号"）；条目写错（把"教书育人"写成"教学育人"）；不足 3 点。

### 深讲 2：中学阶段师德问题的特殊性

中学生处于**青春期**，自尊心强、情绪波动大、同伴影响显著，因此中学师德情境题常聚焦：

- **公开羞辱与排名**：中学最敏感，容易导致学生自尊受挫、厌学，直接违背"关爱学生"与"不以分数作为唯一标准"；
- **有偿补课与教辅推销**：中学阶段升学压力大，是此类违规的高发区，对应"为人师表"的廉洁从教要求；
- **师生关系边界**：中学阶段学生身心发展迅速，师德规范明确禁止任何不正当关系与性骚扰行为；
- **突发事件中的担当**：中学常有实验课、体育课、大型活动，遇到危险时教师**不得擅离职守**。

### 深讲 3："师德失范"与"教学能力不足"的区分

两者处理逻辑不同，答题时不要混淆：

| 类型 | 表现 | 处理逻辑 |
|------|------|---------|
| **师德失范** | 体罚、有偿补课、收受财物、歧视学生、性骚扰等 | 属于**违反职业道德与法律**，应依规给予处分直至解聘、追究法律责任 |
| **教学能力不足** | 教学方法单一、课堂效果不佳 | 应以**培训、教研、师徒结对、反思改进**为主，而非直接处分 |

**判断原则**：涉及**学生身心安全、人格尊严与利益输送**的行为属师德问题；单纯的教学效果问题应通过专业发展途径解决。**材料题中若把教学问题当作师德问题处理（如"效果不好就解聘"），或者把师德问题当作教学问题轻描淡写，都属不妥**。

## ⚠️ 易错提醒

- 六条规范口诀是"**三爱两人一终身**"，条目名称不要写错（"爱国守法"不是"爱国敬业"）；
- "**不得以分数作为评价学生的唯一标准**"属**教书育人**条目，不是"关爱学生"；
- 有偿补课、收受财物属"**为人师表**"（廉洁从教）的违反；
- 材料分析题要"**条目 + 材料 + 分析**"，只写条目不得分；
- 遇突发事件教师**不得擅离职守**，这是常考的正面/反面情境；
- 公开学生隐私、心理问题既违师德也违法律，答题时可两条并写。
