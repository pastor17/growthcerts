## 考点梳理

### 5.1 阅读理解能力

**材料类型**：多为教育类、人文社科类议论文或说明文，2 道小题（一般 4 分 + 10 分）。

**作答方法**

1. **先看题目再看材料**：明确问"含义""原因""观点"还是"评价"；
2. **定位关键词句**：题目关键词回到原文，**就近找答案句**；
3. **分层概括**：文中并列结构（首先、其次、再次）与总分结构是答案的天然分层；
4. **用自己的话整合**：不能整段照抄，要用"**要点 + 简要说明**"的方式作答；
5. **分值决定点数**：一般 **1 点 2 分**，10 分题通常写 4~5 点。

### 5.2 逻辑思维能力

**概念间关系**

| 关系 | 含义 | 示例 |
|------|------|------|
| **全同** | 外延完全重合 | 北京 / 中华人民共和国首都 |
| **包含（属种）** | 一个概念的外延包含另一个 | 学生 / 中学生 |
| **交叉** | 部分重合 | 教师 / 党员 |
| **全异（并列）** | 外延不重合 | 男人 / 女人（矛盾）；红 / 蓝（反对） |

**常用推理形式**

- **三段论**：大前提 + 小前提 → 结论（"所有金属导电；铁是金属；所以铁导电"）；
- **充分条件假言推理**：若 P 则 Q；P 真 → Q 真；**Q 假 → P 假**（否定后件式有效）；
- **必要条件假言推理**：只有 P 才 Q；Q 真 → P 真；**P 假 → Q 假**；
- **常见谬误**：**肯定后件**（若 P 则 Q；Q 真 → P 真 ✗）、**否定前件**（若 P 则 Q；P 假 → Q 假 ✗）。

**图形推理与类比推理**
- 图形推理看：**数量（点线面）、位置（平移旋转翻转）、样式（叠加、去同存异）、对称性、封闭开放**；
- 类比推理先判断**逻辑关系**（属种、并列、因果、条件、对应、象征），再选关系最匹配的选项。

### 5.3 信息处理能力

**Word 常用操作**：字体段落设置、**样式与自动生成目录**、查找与替换、页眉页脚与分节、表格与排序、批注与修订、邮件合并。

**Excel 常用操作**：单元格引用（**相对 A1 / 绝对 $A$1**）、常用函数（SUM、AVERAGE、COUNT、IF、RANK、MAX/MIN）、**排序与筛选、分类汇总、图表（柱形/折线/饼图）**、数据透视表。

**PPT 常用操作**：版式与母版、动画与切换、超链接与放映设置。

**网络与安全常识**：IP 地址、域名与 DNS、浏览器与搜索引擎、**病毒与木马防范、个人信息保护、网络道德与版权**（教学中引用他人资料应注明出处）。

### 5.4 写作能力（50 分，中学一般不少于 1000 字）

**评分关注**：**立意（是否切题、是否深刻）→ 结构（是否完整清晰）→ 内容（是否有理有据）→ 语言（是否通顺得体）→ 卷面（字数与书写）**。

**立意三步**
1. **抓关键词**：材料中的核心概念与情感倾向；
2. **选角度**：教育视角优先（教师、学生、教学、成长），也可从社会/人生角度切入但**必须回扣教育**；
3. **立观点**：一句话概括中心论点，力求**明确、正向、有教育味**。

**结构模板（五段式，1000 字左右）**

| 段落 | 内容 | 字数参考 |
|------|------|---------|
| 开头 | 引材料/名言 + 亮明中心论点 | 约 150 字 |
| 分论点一 | 观点 + 事例 + 分析 | 约 220 字 |
| 分论点二 | 观点 + 事例 + 分析 | 约 220 字 |
| 分论点三 | 观点 + 事例 + 分析 | 约 220 字 |
| 结尾 | 联系中学教育实际 + 升华回扣 | 约 150 字 |

**素材锚点（教育类）**：陶行知"四颗糖"、"捧着一颗心来，不带半根草去"、苏霍姆林斯基与"差生"、张桂梅、于漪、加德纳多元智能、成长型思维、"教育是慢的艺术"。

## 🔍 深度精讲

### 深讲 1：逻辑题的"两招"通用解法

**第一招：符号化**。把题干中的命题写成"若 P 则 Q"的形式，再套用有效式判断：

- ✅ 有效：**P → Q**；已知 P，得 Q（肯定前件）；已知非 Q，得非 P（否定后件）；
- ❌ 无效：已知 Q 得 P（肯定后件）；已知非 P 得非 Q（否定前件）。

**第二招：举反例**。若不确定某推理是否有效，试着构造一个"前提真而结论假"的例子；能构造出来即为无效推理。

**例**："只有努力学习，才能考上理想大学。"这是必要条件命题（努力 ← 考上）。因此可推出"**没努力学习 → 考不上**"（否定前件得否定后件，对必要条件有效）；但不能推出"努力学习了 → 一定考上"。

### 深讲 2：写作如何避免"跑题"与"素材堆砌"

- **跑题的根源**是不抓材料核心词，而凭"感觉"写教育；**对策**：先把材料缩成一句话（谁、做了什么、结果如何、褒贬倾向），再据此立意；
- **素材堆砌**指通篇罗列名人故事却不分析；**对策**：每段采用"**观点句 + 事例（2~3 句）+ 分析句（回扣论点）**"，分析句至少写 2 句；
- **字数不足**是最直接的扣分：中学要求**不少于 1000 字**，建议训练时按 1100 字写，留出余量；
- **卷面**：标题居中、段落分明、少涂改，阅卷感知分明显更高。

### 深讲 3：信息处理题在中学教学场景中的应用

信息处理不只是软件操作，还常以**教学应用**形式设题：

| 场景 | 正确做法 |
|------|---------|
| 用 Excel 统计班级成绩并排名 | 用 **RANK/排序/分类汇总**，注意用**绝对引用**固定统计区域 |
| 制作学科课件 | 合理使用**母版与版式**统一风格，图表清晰，避免堆砌动画 |
| 引用网络资料 | **注明出处、遵守版权**，不直接下载商用素材 |
| 班级成绩与学籍信息 | **注意个人信息保护**，不在公共网络随意传播学生信息 |
| 查找资料 | 使用关键词与逻辑运算符（如 `and`/`or`、引号精确匹配）提高效率 |

## ⚠️ 易错提醒

- 阅读理解题要**用自己的话整合**，整段照抄原文得分很低；
- 逻辑题最常考"**肯定后件/否定前件**"这两种无效推理，看到就判错；
- 充分条件与必要条件方向相反，**"只有…才…"是必要条件**；
- Excel 中统计区域固定要用**绝对引用**（$A$1），否则填充后会错位；
- 写作**必须不少于 1000 字**（中学），立意要**回扣教育**；
- 信息处理题中凡涉及**学生个人信息**的选项，一律以"保护隐私"为判断底线。
