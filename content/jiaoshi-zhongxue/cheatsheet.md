> **用法**：考前 3 天起只过这一页 + 错题笔记。中学**考三科**，科目二比小学更深、写作要求 **1000 字以上**。

## 一、三科结构（初高中公共科目同卷）

| 科目 | 题型 | 拿分要点 |
|------|------|---------|
| **综合素质（301）** | 单选 29×2 + 材料分析 3×14 + **写作 50** | 材料分析有固定模板；写作 ≥1000 字 |
| **教育知识与能力（302）** | 单选 21×2 + **辨析 4×8** + 简答 4×10 + 材料分析 2×18 | **辨析题先判断再写理由**；简答"1 点 2 分" |
| **学科知识与教学能力** | 按学科命题（含**教学设计**） | 必须准备：本学科知识 + 教案模板 |

## 二、科目一必背

| 项目 | 内容 |
|------|------|
| **教育观** | 面向**全体**、促进**全面**、促进**个性**、以培养**创新与实践能力**为重点 |
| **学生观** | **"两独一发"**：独特的人、独立意义的人、发展的人 |
| **教师观** | 角色：促进者、建设者、研究者、开放教师；行为：尊重赞赏/帮助引导/反思/合作 |
| **职业道德** | **"三爱两人一终身"**（爱国守法、爱岗敬业、关爱学生；教书育人、为人师表；终身学习） |
| **材料分析模板** | 总评 → 分点（**观点 + 材料事实 + 分析**）→ 总结（写 3~4 点） |
| **写作** | 引（亮观点）→ 议（2~3 分论点 + 事例 + 分析）→ 联（联系中学教育实际）→ 结（升华） |

## 三、科目二六模块（中学特有深度）

| 模块 | 必背 |
|------|------|
| **教育基础** | 教育起源四说（神话/生物（利托尔诺、沛西·能）/心理（孟禄）/劳动）；内发论（孟子、弗洛伊德、格塞尔、霍尔）vs 外铄论（荀子、洛克、华生）；**五规律→教育启示**（顺序→循序渐进、阶段→不搞一刀切、不平衡→抓关键期、互补→长善救失、差异→因材施教）；四因素（遗传前提、环境条件、**学校教育主导**、**主观能动性决定**） |
| **中学课程** | 课程类型（学科/活动、分科/综合、必修/选修、国家/地方/校本、**显性/隐性**）；布鲁纳（学科结构 + 发现学习）、杜威（学生经验 + 从做中学）；课程标准是**教材编写、教学、评估与命题的依据**；**三维目标** |
| **中学教学** | 教学过程四规律（间接直接、知识能力、主导主体、知识品德）；教学原则（直观、启发、循序渐进、巩固、因材施教、理论联系实际、科学思想、量力）；**班级授课制**（夸美纽斯系统论述、我国最早 1862 京师同文馆）；环节"备课—上课—作业—辅导—评价"（**上课是中心环节**） |
| **学习心理** | 四理论人物：行为（桑代克试误、斯金纳强化、班杜拉观察）、认知（苛勒顿悟、布鲁纳发现、奥苏贝尔有意义接受）、建构（皮亚杰、维果茨基）、人本（罗杰斯、马斯洛）；**韦纳归因**（努力＝内部/不稳定/可控）；**班杜拉自我效能感**四来源；**艾宾浩斯**遗忘先快后慢；高原现象 |
| **发展心理与辅导** | **青春期＝同一性 vs 角色混乱**；皮亚杰形式运算（11 岁起）；情绪两极性 + **内隐性**；辅导方法：**ABC 理性情绪疗法**、系统脱敏、来访者中心；**保密例外**（伤己、伤人、法律要求） |
| **德育与班级管理** | 品德四要素（**知为基础、行为标志**）；**皮亚杰对偶故事法 / 科尔伯格道德两难法**；德育原则（长善救失）；德育四模式（认知/体谅/社会学习/价值澄清）；班级管理四模式；课堂问题行为**最小干预**；教师关注理论四阶段；**职业倦怠三维度**（情绪耗竭、去个性化、低成就感） |

## 四、辨析题三步（8 分题，只判断约得 1~2 分）

```
① 判断：正确 / 错误（措辞明确）
② 理由：写出涉及的概念、规律或原理
③ 纠正：错误命题给出正确表述
```

**示例**："遗传素质决定人的发展" → 错误；遗传是**物质前提**（提供可能性），人的发展还受环境、学校教育与**个体主观能动性**（决定因素）影响。

## 五、学科科目（科目三）准备

```
教学设计模板：教学目标（三维）→ 教学重难点 → 教学过程（导入/新授/巩固/小结/作业）→ 板书设计 → 教学反思
准备 3~5 个常考课题的完整教案；熟悉本学科课程标准（核心素养表述）
```

## 六、面试与关键日期（2026）

| 环节 | 时长 | 要点 |
|------|------|------|
| 结构化问答 | 5 分钟 | 突发事件、家校沟通、教育理念 |
| **试讲** | 10 分钟 | 完整环节 + 板书 + 提问与评价语言 |
| 答辩 | 5 分钟 | 说明本课设计理由 |

| 事项 | 时间 |
|------|------|
| 上半年笔试 / 面试 | **3 月 7 日** / **5 月 16–17 日** |
| 下半年笔试 / 面试 | **9 月 12 日** / **12 月 5–6 日** |

**时间分配**：单选 ≤1 分钟/题；辨析每题 6~8 分钟；材料分析 12~15 分钟；**写作至少留 40 分钟（1000 字）**。

> 考前 3 天只看：**本页 + 错题笔记 + 自己写的作文提纲 + 教案模板**。
