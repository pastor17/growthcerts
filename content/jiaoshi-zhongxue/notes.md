## 一、本证该记什么（三科笔记分工）

### ① 科目一《综合素质》：模板 + 素材（同小学，但写作要求更高）

| 笔记 | 内容 |
|------|------|
| 材料分析模板 | "**总评 → 分点（观点 + 材料 + 分析）→ 总结**"，固定 3~4 点 |
| 职业道德口诀 | **"三爱两人一终身"** |
| 职业理念三观 | 教育观、学生观（**两独一发**）、教师观（促进者/建设者/研究者/开放教师） |
| **写作素材库** | 中学要求一般**不少于 1000 字**（比小学多 200 字），按 4 主题各攒 2 事例 + 2 名言 |

### ② 科目二《教育知识与能力》：比小学**更深一档**

中学多出并加重的模块，恰恰是主观题的主战场：

| 模块 | 笔记重点 |
|------|---------|
| **中学课程** | 课程类型（学科/活动、分科/综合、必修/选修、国家/地方/校本、显性/**隐性**）、课程流派（布鲁纳学科结构、杜威学生经验） |
| **中学教学** | 教学过程四规律、教学原则、教学方法、**班级授课制**（夸美纽斯系统论述、我国最早 1862 京师同文馆） |
| **学习心理** | 四大学习理论人物对应（桑代克试误/斯金纳强化/班杜拉观察；苛勒顿悟/布鲁纳发现/奥苏贝尔有意义接受；建构主义；人本）、归因理论（韦纳三维度）、自我效能感（班杜拉四来源）、遗忘曲线与高原现象 |
| **发展心理与心理辅导** | **青春期＝同一性 vs 角色混乱**、情绪两极性、心理辅导方法（ABC 理论、系统脱敏、来访者中心）、**保密例外** |
| **德育** | 品德四要素、皮亚杰与科尔伯格（**对偶故事 / 道德两难**别记混）、德育原则（长善救失）、四模式 |
| **班级管理与教师心理** | 班级管理模式、课堂问题行为处置（最小干预）、教师关注理论四阶段、**职业倦怠三维度** |

**主观题做法卡（中学必背）**：

- **辨析题三步**：判断 → 说明理由（涉及概念/原理）→ 纠正表述（8 分题，只判断约得 1~2 分）；
- **简答题**：分点编号，**1 点 2 分**；
- **材料分析**：原理名称 + 材料事实 + 分析，至少 3 点。

### ③ 科目三《学科知识与教学能力》：**必须单独准备**

- 笔记两条线：**学科知识**（本学科核心概念与解题方法）+ **教学设计**（教学目标三维 → 重难点 → 教学过程 → 板书 → 反思）；
- 建议准备 **3~5 个常考课题**的完整教案模板，考场直接套用。

## 二、避坑清单（中学教资专属 9 条）

| # | 坑 | 正确做法 |
|---|----|---------|
| 1 | 用小学资料复习科目二 | 中学《教育知识与能力》模块更深（课程、学习心理、发展心理与辅导、德育），**必须用中学大纲** |
| 2 | 裸考科目三 | 学科科目按学科命题，**含学科知识 + 教学设计**，不准备必然失分 |
| 3 | 辨析题只判断不写理由 | 辨析题是"判断 + 理由 + 纠正"三段，理由占分最多 |
| 4 | 写作按 800 字准备 | 中学一般要求**不少于 1000 字**，考场上写不够直接扣分 |
| 5 | 把皮亚杰与科尔伯格的方法混记 | **皮亚杰用对偶故事法、科尔伯格用道德两难法** |
| 6 | 同一性问题写错学段 | 青春期（约 12–18 岁）＝**同一性 vs 角色混乱**；勤奋 vs 自卑是学龄期 |
| 7 | 报名时科目漏选/选错 | 科目**一次性勾选、审核后不得更改**；初中与高中**公共科目同卷**，差异在学科科目与面试 |
| 8 | 忽略认定环节 | 通过笔试面试后还需普通话等级 + 体检 + **教师资格认定**（走 jszg.edu.cn） |
| 9 | 只看不写 | 科目二辨析/简答、科目一写作、科目三教学设计都是输出型，**必须限时手写** |
