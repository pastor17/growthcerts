## 考点梳理

### 2.1 公共财政的职能

| 职能 | 内容 |
|------|------|
| **资源配置** | 提供公共物品、纠正外部性、调整资源配置结构 |
| **收入分配** | 通过税收与转移支付调节收入差距 |
| **经济稳定与发展** | 通过财政政策熨平经济波动、促进增长与就业 |

**公共财政的特征**：弥补市场失灵、提供公共物品、非市场营利性、法制化与规范化。

### 2.2 财政支出

- **按功能分类**：一般公共服务、外交、国防、公共安全、教育、科学技术、文化旅游体育与传媒、社会保障和就业、卫生健康、节能环保、城乡社区、农林水、交通运输等；
- **按经济性质分类**：**购买性支出**（政府购买商品与服务，直接影响资源配置）与**转移性支出**（补助、社会保障支出，直接影响收入分配）；
- **规模影响因素**：经济发展水平、经济体制、政府职能范围、社会文化与人口因素；
- **增长理论**：**瓦格纳法则**（随经济发展，财政支出占 GDP 比重上升）、**梯度渐进增长理论**（皮科克与怀斯曼：社会动荡期支出跳跃上升）、**经济发展阶段增长理论**（马斯格雷夫）。

### 2.3 税收原理

**税收原则**：**公平**（横向公平、纵向公平）、**效率**（经济效率与行政效率）、**稳定**、**财政**原则。

**税负转嫁**（高频）：纳税人将税负转移给他人的过程。

| 转嫁方式 | 含义 |
|---------|------|
| **前转（顺转）** | 提高售价，转嫁给购买者（**最常见**） |
| **后转（逆转）** | 压低进价，转嫁给供应者 |
| **混转（散转）** | 前转与后转同时进行 |
| **消转** | 通过改善经营、降低成本自行消化 |
| **税收资本化** | 将未来税负折现从资产价格中扣除（如土地交易） |

**转嫁难易**：需求**弹性越小**、市场**垄断程度越高**、税基越宽，越容易转嫁。

### 2.4 税制结构与主要税种

**按征税对象分类**：

| 类型 | 说明 | 典型税种 |
|------|------|---------|
| **流转税** | 以商品与劳务流转额为征税对象 | 增值税、消费税、关税 |
| **所得税** | 以所得额为征税对象 | 企业所得税、个人所得税 |
| **财产税** | 以财产为征税对象 | 房产税、契税、车船税 |
| **资源税与行为税** | 特定资源与行为 | 资源税、环境保护税、印花税、城建税 |

**增值税要点**：以**增值额**为征税对象，属**价外税**；税率分档（基本税率与低税率，**具体税率以现行规定为准**）；进项税额抵扣机制避免重复征税。

**个人所得税要点**：**综合与分类相结合**——工资薪金、劳务报酬、稿酬、特许权使用费为**综合所得**按年计税；经营所得、利息股息红利、财产租赁、财产转让、偶然所得等分类计税；设**专项附加扣除**（子女教育、继续教育、大病医疗、住房贷款利息或住房租金、赡养老人、3 岁以下婴幼儿照护等）。

### 2.5 国债

- **功能**：弥补财政赤字、筹集建设资金、调节经济与货币供应；
- **分类**：按偿还期限（短期/中期/长期）、按发行区域（内债/外债）、按付息方式（附息/贴现）；
- **国债负担与限度**：受**认购者负担能力、政府偿债能力、宏观经济承受能力**制约；常用指标有**国债负担率、债务依存度、偿债率**；
- **国债市场**：发行市场（一级）与流通市场（二级）。

### 2.6 政府预算与财政体制

- **预算原则**：公开性、可靠性、完整性、统一性、年度性；
- **预算分类**：**一般公共预算、政府性基金预算、国有资本经营预算、社会保险基金预算**（"四本预算"）；
- **分税制**：按税种划分中央与地方收入、划分事权与支出责任，设**转移支付**（一般性转移支付与专项转移支付）平衡地区差异；
- **政府间财政关系**：**事权与支出责任相适应**是基本原则。

### 2.7 财政政策

| 工具 | 内容 |
|------|------|
| **支出政策** | 增加政府购买、增加公共投资、增加转移支付 |
| **收入政策** | 减税或增税、调整税率与税基 |
| **自动稳定器** | 累进所得税、失业救济与社保支出（**无需专门决策即自动发挥作用**） |
| **相机抉择** | 政府主动采取措施（扩张性/紧缩性财政政策） |

**扩张性财政政策**（经济衰退时）：增支 + 减税 → 刺激总需求；**紧缩性财政政策**（通胀时）：减支 + 增税。

## 🔍 深度精讲

### 深讲 1：税负转嫁怎么判断"能不能转、转多少"

判断三步：

1. **看市场结构**：完全竞争市场转嫁难，垄断市场转嫁易；
2. **看需求弹性**：需求**越缺乏弹性**，消费者越难"用脚投票"，越容易**前转**（如烟酒、食盐）；
3. **看税种性质**：**间接税（流转税）**易转嫁，**直接税（所得税）**通常难转嫁。

**案例**：某地提高卷烟消费税 → 卷烟需求缺乏弹性 + 市场集中度高 → 税负主要通过**提高售价前转**给消费者，销量下降有限，税收收入增加。

**答题提示**：题目若问"税负主要由谁承担"，回答需同时说明**弹性与市场结构**，不要只写"消费者承担"。

### 深讲 2：扩张性财政政策的作用与代价

**作用链条**：政府增加支出/减税 → 总需求增加 → 产出与就业上升。

**代价与制约**：

- **挤出效应**：政府支出增加 → 利率上升 → 私人投资减少，削弱刺激效果；
- **财政赤字与债务累积**：长期扩张会推高债务负担率；
- **时滞**：认识时滞、决策时滞、执行时滞会降低政策精准度；
- **通胀风险**：总需求过度扩张时可能引发需求拉动型通胀。

**答题要点**：评价财政政策要"**作用 + 制约 + 搭配**"三点齐全（与货币政策搭配是常见设问）。

### 深讲 3：把"税制"记成一张表

| 税种 | 征税对象 | 计税依据 | 易错点 |
|------|---------|---------|-------|
| 增值税 | 增值额 | 销售额（价外税） | 属**流转税**，进项可抵扣 |
| 消费税 | 特定消费品 | 销售额/数量 | 属**价内税**，多在生产/进口环节征收 |
| 企业所得税 | 应纳税所得额 | 收入 − 扣除项目 | 与会计利润**不相等** |
| 个人所得税 | 综合所得等 | 按年/按次 | **综合与分类相结合** |
| 房产税 | 房产 | 房产余值或租金 | 与契税、土地增值税区分 |
| 印花税 | 应税凭证 | 金额或件数 | 范围以**税目表**为准 |

> 记忆法：**先记"征什么（对象）"，再记"怎么算（依据）"，最后记"谁交、在哪交"**——三步定位，比死背书有效率。

## ⚠️ 易错提醒

- **购买性支出 vs 转移性支出**：前者直接影响资源配置，后者直接影响收入分配；
- **前转是提价转给消费者**（最常见），不要与后转（压价转给供应者）混；
- **自动稳定器**是"无需专门决策即自动发挥作用"，与相机抉择不同；
- 增值税是**价外税**、消费税通常为**价内税**；
- 企业所得税的计税依据是**应纳税所得额**，不是会计利润；
- 国债限度受**认购者负担能力、政府偿债能力、宏观经济承受能力**三方面制约。
