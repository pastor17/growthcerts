## 考点梳理

### 3.1 货币需求与货币供给

**货币需求理论**
- **费雪方程式（交易方程式）**：**MV = PT**（M 货币量、V 流通速度、P 物价、T 交易量）；
- **剑桥方程式**：M = kPY（k 为持币比例）；
- **凯恩斯货币需求**：**交易动机、预防动机、投机动机**（前两者与收入正相关，投机动机与利率负相关）——**流动性偏好理论**；
- **弗里德曼**：货币需求是**资产选择**的结果，受收入、机会成本与偏好影响，长期稳定。

**货币供给层次（一般口径，具体以官方统计口径为准）**：
- **M0**：流通中现金；
- **M1**：M0 + 单位活期存款（**狭义货币**）；
- **M2**：M1 + 单位定期存款 + 居民储蓄存款 + 其他存款（**广义货币**）。

**货币乘数**：基础货币（高能货币）通过银行体系派生存款，**货币供应量 = 基础货币 × 货币乘数**。

### 3.2 中央银行与商业银行

| 机构 | 主要职能 |
|------|---------|
| **中央银行** | **发行的银行、银行的银行、政府的银行**；制定与执行货币政策、维护金融稳定、经理国库、管理外汇与黄金储备 |
| **商业银行** | 吸收存款、发放贷款、办理结算；职能包括**信用中介、支付中介、信用创造、金融服务** |
| 政策性银行 | 贯彻政策目标，服务特定领域 |

**商业银行经营原则**：**安全性、流动性、盈利性**（"三性"原则，安全性为基础、流动性为条件、盈利性为目标）。

### 3.3 金融市场

| 分类 | 内容 |
|------|------|
| **按期限** | **货币市场**（≤1 年：同业拆借、票据、大额存单、回购等）与**资本市场**（>1 年：股票、中长期债券） |
| **按交易性质** | 发行市场（一级）、流通市场（二级） |
| **按工具** | 债券市场、股票市场、外汇市场、衍生品市场、黄金市场 |

**金融工具特征**：**期限性、流动性、风险性、收益性**（流动性与收益性通常反向）。

### 3.4 利率与汇率

- **利率分类**：名义利率/实际利率（**实际利率 = 名义利率 − 通胀率**）、固定/浮动、官定/市场；
- **利率决定理论**：古典（储蓄—投资）、凯恩斯（**流动性偏好**：货币供求决定）、可贷资金理论；
- **利率期限结构**：预期理论、市场分割理论、流动性溢价理论；
- **汇率标价**：直接标价法（**1 单位外币 = 若干本币**，我国采用）与间接标价法；
- **汇率制度**：固定汇率制与浮动汇率制（含管理浮动）；
- **影响汇率的因素**：国际收支、利率差异、通胀差异、经济增长、市场预期与政策干预。

### 3.5 货币政策

| 工具 | 说明 |
|------|------|
| **存款准备金政策** | 调整法定存款准备金率（**作用猛烈，一般不轻易使用**） |
| **再贴现政策** | 调整再贴现率与再贴现条件 |
| **公开市场操作** | 买卖国债等有价证券（**最常用、最灵活**） |
| 其他 | 利率政策、信贷政策、窗口指导、结构性工具 |

**传导机制**：政策工具 → 操作目标（基础货币、短期利率）→ 中介目标（M2、贷款利率等）→ 最终目标（物价稳定、经济增长、充分就业、国际收支平衡）。

**政策取向**：**扩张性**（降准、降息、买入证券）刺激需求；**紧缩性**（升准、加息、卖出证券）抑制通胀。

### 3.6 金融风险与监管

- **金融风险类型**：信用风险、市场风险（利率、汇率、股价）、操作风险、流动性风险、声誉与战略风险、系统性风险；
- **风险管理环节**：风险识别 → 计量 → 监测 → 控制；
- **金融监管目标**：维护金融稳定、保护存款人与投资者利益、提高金融效率；
- **监管内容**：市场准入、业务运营、资本充足、信息披露、市场退出；
- **巴塞尔协议核心**：**资本充足率**要求（分层次资本要求 + 杠杆率 + 流动性指标等）；
- **存款保险制度**：保护小额存款人、防范挤兑。

## 🔍 深度精讲

### 深讲 1：货币政策工具"怎么选"

| 情境 | 常用工具组合 | 原因 |
|------|------------|------|
| **需要微调流动性** | 公开市场操作（逆回购/正回购） | 灵活、可逆、对市场冲击小 |
| **需要明确宽松信号** | 降准（下调存款准备金率） | 释放长期资金、信号强 |
| **需要引导融资成本** | 政策利率调整（如 LPR 引导） | 通过利率传导影响贷款定价 |
| **需要定向支持** | 结构性工具（再贷款、专项支持） | 精准投向特定领域 |

**答题提示**：题目若问"央行应如何操作"，先判断**经济形势（通胀/衰退）** → 确定**政策取向（紧缩/扩张）** → 再选工具，并说明**传导路径**（工具 → 中介目标 → 最终目标）。

### 深讲 2：货币乘数与派生存款的计算

**简化模型**：在无现金漏损、法定准备金率 r 的条件下，**简单货币乘数 = 1 / r**。

**示例**：法定存款准备金率 10%，基础货币增加 100 亿元 →
- 简单货币乘数 = 1 / 0.1 = **10**；
- 理论上货币供应量最多增加 **1000 亿元**。

**现实中会小于该值**，因为存在：① **现金漏损**（公众持币）；② **超额准备金**；③ 定期存款与活期存款比例变化。

**答题要点**：写"理论上限 + 现实修正因素"，比只写公式更完整。

### 深讲 3：汇率变动对经济的影响（高频设问）

| 情形 | 影响 |
|------|------|
| **本币贬值** | 出口商品以外币计价更便宜 → **出口增加**；进口商品变贵 → 进口减少；**贸易收支改善**（在满足马歇尔—勒纳条件时）；外债负担加重；可能引发资本外流与输入型通胀 |
| **本币升值** | 出口竞争力下降、进口增加；对外购买力增强；外债负担减轻；可能抑制出口行业就业 |

**答题提示**：分析汇率影响要**区分主体**（出口企业/进口企业/居民/政府）与**时间**（短期资本流动 vs 中长期贸易结构），不要只答"有利于出口"。

## ⚠️ 易错提醒

- **M1 是狭义货币、M2 是广义货币**，M2 包含 M1；
- 央行三大职能不要漏"政府的银行"（经理国库、代表政府参与国际金融活动）；
- **公开市场操作最常用**，存款准备金政策"作用猛烈"；
- 实际利率 = 名义利率 − 通胀率（**费雪关系**），通胀高时实际利率可能为负；
- 我国汇率标价采用**直接标价法**；
- 商业银行"三性"中**安全性是基础**，不是盈利性。
