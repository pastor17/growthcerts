## 考点梳理

### 5.1 会计基本概念

- **会计**：以货币为主要计量单位，对单位经济活动进行**确认、计量、记录和报告**的管理活动；
- **会计基本假设**：**会计主体、持续经营、会计分期、货币计量**；
- **会计基础**：**权责发生制**（企业）与收付实现制（预算会计多用）；
- **会计信息质量要求**：可靠性、相关性、可理解性、可比性、**实质重于形式**、重要性、**谨慎性**、及时性。

### 5.2 会计要素与会计等式

| 要素 | 说明 |
|------|------|
| **资产** | 过去交易或事项形成、由企业拥有或控制、**预期会带来经济利益**的资源 |
| **负债** | 过去交易或事项形成的**现时义务**，履行会导致经济利益流出 |
| **所有者权益** | 资产扣除负债后由所有者享有的**剩余权益** |
| **收入** | 日常活动形成、会导致所有者权益增加、与所有者投入资本无关的经济利益总流入 |
| **费用** | 日常活动形成、会导致所有者权益减少、与向所有者分配利润无关的经济利益总流出 |
| **利润** | 一定会计期间的经营成果 = 收入 − 费用 + 直接计入当期利润的利得与损失 |

**会计等式**

- **基本等式（静态）**：**资产 = 负债 + 所有者权益**；
- **扩展等式（动态）**：**资产 = 负债 + 所有者权益 +（收入 − 费用）**；
- **记账规则**：**有借必有贷，借贷必相等**。

### 5.3 会计循环

**确认 → 计量 → 记录（填制凭证、登记账簿）→ 期末调整与结账 → 编制财务报表**

- **会计凭证**：原始凭证（业务发生时的原始证明）与记账凭证（据以登记账簿）；
- **会计账簿**：总账、明细账、日记账（现金与银行存款日记账）；
- **对账**：账证相符、账账相符、**账实相符**；
- **更正错账方法**：划线更正法、红字更正法、补充登记法。

### 5.4 财务报表（核心）

| 报表 | 反映内容 | 关键关系 |
|------|---------|---------|
| **资产负债表** | 某一**特定日期**的财务状况（时点报表） | 资产 = 负债 + 所有者权益 |
| **利润表** | 一定**期间**的经营成果（期间报表） | 收入 − 费用 = 利润 |
| **现金流量表** | 一定期间现金及现金等价物流入流出 | 分**经营、投资、筹资**三类活动 |
| **所有者权益变动表** | 一定期间所有者权益各组成部分增减变动 | 与利润表、与股东投入/分配相衔接 |
| **附注** | 报表项目的说明与重要会计政策 | 财务报告不可缺少的组成部分 |

### 5.5 会计确认与计量

- **计量属性**：**历史成本**（基本）、重置成本、可变现净值、现值、公允价值；
- **谨慎性应用**：计提资产减值准备、**不高估资产或收益、不低估负债或费用**；
- **实质重于形式应用**：**融资租入固定资产**视为自有资产核算。

### 5.6 财务分析指标（高频计算）

| 类别 | 指标 | 公式要点 |
|------|------|---------|
| **偿债能力** | 流动比率 | 流动资产 ÷ 流动负债（一般 2 左右较合理） |
| | 速动比率 | （流动资产 − 存货）÷ 流动负债 |
| | 资产负债率 | 负债总额 ÷ 资产总额 |
| **营运能力** | 应收账款周转率 | 营业收入 ÷ 平均应收账款 |
| | 存货周转率 | 营业成本 ÷ 平均存货 |
| **盈利能力** | 营业利润率 | 营业利润 ÷ 营业收入 |
| | 净资产收益率（ROE） | 净利润 ÷ 平均所有者权益 |
| | 总资产报酬率 | 净利润（或息税前利润）÷ 平均总资产 |

## 🔍 深度精讲

### 深讲 1：为什么"会计利润"与"应纳税所得额"不同

两者目标不同：

- **会计利润**依据**会计准则**计算，强调真实反映经营成果（含公允价值变动等）；
- **应纳税所得额**依据**税法**计算，强调税收公平与可征管性，需做**纳税调整**：
  - **调增**：超标准业务招待费、罚款支出、超范围捐赠等（会计上列支但税法不认）；
  - **调减**：国债利息收入等免税收入、符合条件的研发费用加计扣除等。

**答题提示**：题目若给"会计利润"并要求计算所得税，务必写出"**纳税调整**"这一步，而不是直接用会计利润 × 税率。

### 深讲 2：三大报表之间的勾稽关系（常考）

```
利润表：净利润
   ↓ 进入
资产负债表：所有者权益（未分配利润）
   ↓ 同时
现金流量表：经营活动现金流与净利润的差异需调节（间接法）

期末现金余额（现金流量表）= 资产负债表"货币资金"期末数
```

**关键勾稽点**：

1. **资产负债表"未分配利润"期末数** = 期初数 + 本期净利润 − 提取盈余公积 − 分配股利；
2. **现金流量表期末现金余额** = 资产负债表货币资金期末余额；
3. **利润表"净利润"** 是所有者权益变动表与现金流量表（间接法）的起点。

### 深讲 3：财务比率怎么"看懂"而不是背公式

| 指标 | 高说明什么 | 低说明什么 | 风险提示 |
|------|-----------|-----------|---------|
| 流动比率 | 短期偿债能力强 | 可能短期偿债压力大 | 过高说明资产闲置（存货积压、现金过多） |
| 资产负债率 | 杠杆高、财务风险大 | 财务风险低 | 过低可能未充分利用财务杠杆 |
| 净资产收益率 | 股东回报高 | 盈利效率低 | 高杠杆也会推高 ROE，需结合负债率看 |
| 存货周转率 | 周转快、效率高 | 可能滞销积压 | 过高也可能是库存过少、供货风险 |

**答题提示**：分析财务指标要"**数值 + 行业对比 + 趋势比较 + 风险解释**"，单说"越高越好"会被扣分。

## ⚠️ 易错提醒

- **资产负债表是时点报表**、利润表与现金流量表是**期间报表**，不要混；
- 会计等式是"**资产 = 负债 + 所有者权益**"，不是"资产 = 所有者权益 + 负债 + 收入"（后者是扩展式且需减费用）；
- **速动比率**要扣除**存货**（有时还扣预付款项等），不要与流动比率混；
- **融资租入固定资产**按实质重于形式原则视为自有资产；
- 谨慎性要求"**不高估资产收益、不低估负债费用**"，不是"尽量少计利润"；
- 现金流量表分**经营、投资、筹资**三类活动，购买固定资产属**投资**活动。
