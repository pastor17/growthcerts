## 考点梳理

### 6.1 法与经济法基础

- **法律体系层级**：宪法 → 法律 → 行政法规 → 地方性法规/部门规章 → 地方政府规章；
- **经济法调整对象**：国家在**组织、管理、协调经济运行**过程中发生的经济关系；
- **法律关系三要素**：**主体、客体、内容**（权利义务）；
- **法律事实**：法律事件（不以人意志为转移，如自然灾害）与法律行为（以意思表示为要素）；
- **诉讼时效**：普通诉讼时效 **3 年**（自权利人知道或应当知道权利受损及义务人之日起算）；**最长权利保护期间 20 年**；请求停止侵害、排除妨碍、消除危险及支付赡养费/抚养费等**不适用诉讼时效**。

### 6.2 民事主体与法律行为

| 主体 | 要点 |
|------|------|
| **自然人** | 民事权利能力始于出生、终于死亡；**不满 8 周岁**为无民事行为能力人；**8 周岁以上**未成年人为限制民事行为能力人 |
| **法人** | 依法成立、有财产或经费、有名称/组织机构/住所、能独立承担民事责任；法定代表人以法人名义从事活动，后果由法人承受 |
| **非法人组织** | 个人独资企业、合伙企业、专业服务机构等 |

**民事法律行为效力**

| 状态 | 情形 |
|------|------|
| **有效** | 主体适格、意思表示真实、不违反强制性规定与公序良俗 |
| **无效** | 违反强制性规定、违背公序良俗、恶意串通损害他人、虚假意思表示等 |
| **可撤销** | 重大误解、欺诈、胁迫、显失公平（由**受损害方**请求撤销，一般 **1 年**内，重大误解 **90 日**） |
| **效力待定** | 限制民事行为能力人订立、无权代理等（经**追认**后有效） |

**代理**：委托代理、法定代理；**表见代理**（相对人有理由相信行为人有代理权）→ 代理行为**有效**，被代理人承担责任后可追偿。

### 6.3 物权与债权

- **物权类型**：所有权（占有、使用、收益、处分）、**用益物权**（土地承包经营权、建设用地使用权、宅基地使用权、居住权、地役权）、**担保物权**（抵押权、质权、留置权）；
- **物权变动**：不动产以**登记**生效，动产以**交付**生效；
- **债的发生根据**：**合同、侵权、无因管理、不当得利**；
- **担保要点**：保证（一般保证享先诉抗辩权；约定不明按**一般保证**）、抵押（不动产登记生效）、质押（转移占有）、**定金不超过主合同标的额 20%**；
- **侵权责任**：过错责任、无过错责任（法律特别规定）、公平责任；产品责任、机动车事故责任等为常考领域。

### 6.4 合同法要点

| 环节 | 要点 |
|------|------|
| **订立** | **要约**（内容具体确定、表明受约束）与**承诺**（承诺生效时合同成立）；招标公告、商业广告一般为**要约邀请** |
| **形式** | 书面、口头或其他形式；电子合同同样有效 |
| **履行** | 全面履行、诚信履行；同时履行抗辩权、先履行抗辩权、不安抗辩权 |
| **变更与转让** | 协商变更；债权转让通知债务人；债务转移需债权人同意 |
| **违约责任** | 继续履行、采取补救措施、赔偿损失、支付违约金、定金罚则；**违约金与定金择一主张**；**不可抗力**可部分或全部免责（迟延履行后发生不可抗力不免责） |
| **减损义务** | 一方违约后对方应采取适当措施防止损失扩大，未采取措施致损失扩大的**不得就扩大部分索赔** |

### 6.5 公司法要点

- **公司类型**：有限责任公司与股份有限公司；
- **设立**：股东出资（认缴制为主）、章程、登记；
- **组织机构**：**股东会（权力机构）、董事会（执行机构）、监事会（监督机构）**；
- **股东权利**：资产收益、参与重大决策、选择管理者、知情权（查阅章程、会议记录、财务报告等）；
- **公司人格否认**：股东滥用法人独立地位与有限责任逃避债务、严重损害债权人利益的，应对公司债务承担**连带责任**；
- **利润分配**：依法提取**法定公积金**（按税后利润的 **10%**，累计达注册资本 50% 可不再提取）后再分配。

### 6.6 反垄断与消费者权益保护

- **垄断行为**：**垄断协议**（横向/纵向）、**滥用市场支配地位**、**经营者集中**（需申报审查）、滥用行政权力排除限制竞争；
- **消费者权利**：安全权、知情权、自主选择权、公平交易权、求偿权、结社权、获知权、受尊重权、监督权（**九项权利**）；
- **经营者义务**：保证质量与安全、真实信息告知、出具凭证、履行"三包"、不得设置不公平格式条款；
- **争议解决**：与经营者协商、请求消协或其他调解组织调解、向行政部门投诉、仲裁、诉讼。

## 🔍 深度精讲

### 深讲 1：可撤销合同"不撤销即有效"

**核心逻辑**：可撤销合同在**撤销前是有效的**，只有受损害方在法定期限内请求法院或仲裁机构撤销，才自始无效；逾期未行使，撤销权消灭，合同继续有效。

| 比较项 | 无效合同 | 可撤销合同 |
|--------|---------|-----------|
| 违法程度 | 违反强制性规定/违背公序良俗 | 意思表示不真实（误解、欺诈、胁迫、显失公平） |
| 主张主体 | 任何利害关系人，法院可主动认定 | **仅受损害方** |
| 期限 | 无时效限制 | **1 年**（重大误解 **90 日**） |
| 后果 | 自始无效 | 撤销前有效，撤销后自始无效 |

**答题提示**：遇到"受欺诈订立合同"，先问"**是否在 1 年内主张撤销**"——不主张则合同有效，这是高频陷阱。

### 深讲 2：违约责任与侵权责任的区分

| 比较项 | 违约责任 | 侵权责任 |
|--------|---------|---------|
| 前提 | 存在**合同关系** | 无合同关系或与合同无关的侵权 |
| 归责 | 一般为**严格责任**（不履行即担责，法定免责除外） | 一般**过错责任**（法律特别规定为无过错责任） |
| 赔偿范围 | 包括**可期待利益**（履行利益） | 以**实际损失**为主 |
| 竞合 | 同一行为同时构成两者时，**受损害方择一主张** | — |

**答题提示**：产品缺陷致人损害、运输中货物毁损等场景常考竞合，答案是"**当事人可选择其一主张，但不能同时获得双重赔偿**"。

### 深讲 3：公司法中"有限责任"的边界

**有限责任**指股东**以其认缴的出资额（或认购的股份）为限**对公司承担责任，公司以其全部财产对债务负责。但存在例外（**公司人格否认 / "揭开公司面纱"**）：

1. 股东**滥用法人独立地位与股东有限责任**逃避债务；
2. **严重损害债权人利益**。

此时股东对公司债务承担**连带责任**。此外，**一人公司**股东不能证明公司财产独立于自己财产的，也应对公司债务承担连带责任。

**答题提示**：见到"股东把公司资金挪作私用""公司与股东财产混同"等描述，标准答案是"**可否认公司人格，由股东承担连带责任**"。

## ⚠️ 易错提醒

- **不满 8 周岁**为无民事行为能力人，8 周岁以上未成年人为限制民事行为能力人（数字易与旧标准混淆）；
- **普通诉讼时效 3 年、最长保护期 20 年**；撤销权为 **1 年**（重大误解 90 日），三者不要混；
- 保证方式**约定不明按一般保证**（不是连带责任保证）；
- 定金上限为主合同标的额的 **20%**，且**定金与违约金择一**；
- **不动产登记生效、动产交付生效**，抵押不转移占有、质押转移占有；
- 法定公积金按税后利润的 **10%** 提取，累计达注册资本 **50%** 可不再提取。
