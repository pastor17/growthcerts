## 考点梳理

### 2.1 战略人力资源管理

- **核心观点**：人力资源管理应与**组织战略**匹配（垂直匹配）并**内部协同**（水平匹配），从而形成**持续竞争优势**；
- **两种视角**：**资源基础观**（人力资源是难以模仿的资源）与**人力资本理论**（投资于人的知识与技能）；
- **三种模式**：**控制型**（强调规则与效率）、**承诺型**（强调参与与忠诚）、**混合型**；
- **高绩效工作系统**：严格甄选、广泛培训、激励性薪酬、信息共享、参与决策、就业保障等组合。

### 2.2 人力资源规划

**内容**：需求预测 → 供给预测 → 供需平衡（缺口与冗余处理）→ 行动方案。

| 环节 | 常用方法 |
|------|---------|
| **需求预测** | **主观判断法**（管理者经验）、**德尔菲法**（专家多轮匿名）、**趋势分析法**、**比率分析法**、**回归分析法**、**计算机模拟** |
| **供给预测** | **技能清单（人员档案）**、**管理人员接续计划**、**马尔可夫转移矩阵**、外部劳动力市场分析 |
| **供需平衡** | 短缺：内部培训晋升、外部招聘、加班与外包、自动化；冗余：自然减员、减少加班、调岗、裁员 |

**人力资源规划的产出**：人员配置计划、招聘计划、培训计划、薪酬与继任计划。

### 2.3 工作分析

- **目的**：明确岗位的**职责、权限、任职资格与工作关系**；
- **方法**：观察法、访谈法、问卷法、**工作日志法**、**关键事件法**、**职位分析问卷（PAQ）**；
- **产出**：**职位说明书**（职责、权限、工作关系）+ **任职资格（工作规范）**；
- **原则**：以"**事**"为中心（对岗不对人）、职责明确、权责对等；
- **应用**：招聘标准、绩效指标、薪酬职位评价、培训需求的基础。

### 2.4 招募与甄选

**招募渠道比较**

| 渠道 | 优点 | 缺点 |
|------|------|------|
| **内部招募** | 成本低、上手快、激励士气 | 来源有限、易"近亲繁殖" |
| **外部招募** | 带来新观念、选择面广 | 成本高、适应期长 |
| 校园招聘 | 可塑性强、成本较低 | 培训投入大、留存风险 |
| 网络与猎头 | 精准、速度快 | 费用高（猎头）、信息真实性需核验 |
| 员工推荐 | 匹配度较高、成本低 | 易形成小圈子 |

**甄选方法与效度（高频）**

| 方法 | 说明 | 效度特点 |
|------|------|---------|
| **结构化面试** | 统一问题与评分标准 | **效度较高、公平性好** |
| 非结构化面试 | 随意提问 | 效度低、易受偏见影响 |
| **评价中心技术** | 情境模拟：公文筐、无领导小组讨论、角色扮演 | **对管理岗位效度较高**（成本高） |
| **能力与人格测评** | 认知能力测试、人格测验 | 认知能力对多岗位预测力较好 |
| **工作样本测试** | 直接做岗位典型任务 | 效度高、实操性强 |
| 背景调查与推荐信 | 核验经历 | 效度一般，需注意合规 |

**录用与配置**：人岗匹配、公平合规（**不得有就业歧视**）、试用期管理与入职引导。

## 🔍 深度精讲

### 深讲 1：为什么"结构化面试"更值得推荐

**非结构化面试**的问题：问题因人而异、评分标准不统一、易受**首因效应与晕轮效应**影响，**预测效度低**且容易引发公平性争议。

**结构化面试**的核心设计：

1. **基于工作分析**确定考察维度（如沟通、抗压、专业能力）；
2. **统一题目**（同一岗位问同类问题）与**统一评分标准**（锚定行为等级）；
3. **行为化提问**（如"请举一个你处理客户投诉的例子"，考察**过去行为**）；
4. **多面试官小组面试**减少个人偏见；
5. **记录与评分留痕**，便于复核与申诉。

**案例题答法**：当题目描述"招聘效果差、员工与岗位不匹配"时，答题要点通常包括"**完善工作分析 → 明确任职资格 → 采用结构化面试与评价中心技术 → 加强背景调查 → 设置试用期考核**"。

### 深讲 2：人力资源供需平衡的"组合拳"

| 情形 | 措施组合（按优先级） |
|------|-------------------|
| **短缺（短期）** | 加班与兼职、内部调配、外包、返聘退休人员 |
| **短缺（长期）** | 内部培训晋升、校园招聘与储备干部、外部招聘关键岗位、流程自动化 |
| **冗余（短期）** | 减少加班与临时用工、冻结招聘、自然减员 |
| **冗余（长期）** | 转岗培训、内部创业与分流、协商解除、**依法裁员**（最后手段，注意法定程序与经济补偿） |

**答题提示**：涉及"裁员"时必须写**合法合规**（程序、补偿、协商），并建议优先采用**转岗与培训**等柔性措施。

### 深讲 3：招聘中的合规红线

- **禁止就业歧视**：不得因性别、民族、宗教信仰、婚育状况等（与岗位无关的因素）区别对待；
- **信息真实**：岗位描述与薪酬信息应真实，避免虚假招聘；
- **个人信息保护**：简历与测评数据应**限定用途、妥善保管**；
- **未成年人保护**：不得招用童工（法律另有规定除外）；
- **录用条件明确**：录用条件应在录用前明确告知，便于试用期考核与解除的依据成立。

## ⚠️ 易错提醒

- **内部招募**并非一定优于外部：两者各有适用（激励 vs 引入新观念）；
- **马尔可夫矩阵用于供给预测**（人员转移概率），不是需求预测；
- **德尔菲法**是专家多轮匿名判断，不是问卷调查；
- **评价中心技术**效度高但**成本高**，适合管理岗位而非所有岗位；
- 工作分析以"**事**"为中心（对岗不对人）；
- 招聘环节要守住**反歧视与个人信息保护**两条合规红线。
