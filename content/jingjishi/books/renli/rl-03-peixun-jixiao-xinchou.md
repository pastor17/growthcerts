## 考点梳理

### 3.1 培训与开发

**培训需求分析三层次**

| 层次 | 分析内容 |
|------|---------|
| **组织分析** | 战略与目标、资源、组织氛围——确定"要不要培训、在哪里培训" |
| **任务分析** | 岗位职责与所需知识技能——确定"培训什么" |
| **人员分析** | 员工当前绩效与能力差距——确定"谁需要培训" |

**培训方法**

| 类型 | 方法 | 特点 |
|------|------|------|
| **在职培训** | 师带徒、工作轮换、特别任务、教练辅导 | 贴近实际、成本低 |
| **脱产培训** | 讲授法、研讨法、案例教学、角色扮演、情景模拟、拓展训练、网络课程 | 系统性强、可规模化 |

**培训效果评估（柯氏四级，必考）**

| 层级 | 评估内容 | 常用方式 |
|------|---------|---------|
| **反应层** | 学员满意度 | 问卷、访谈 |
| **学习层** | 知识技能掌握程度 | 测试、实操考核 |
| **行为层** | 工作行为改变 | 上级评价、观察、360 度 |
| **结果层** | 对业务结果的影响 | 绩效指标、成本收益分析 |

### 3.2 职业生涯管理

- **职业生涯阶段**：探索期、确立期、维持期、衰退期；
- **职业锚（施恩）**：技术/职能型、管理型、自主独立型、安全稳定型、创业型、服务型、挑战型、生活型；
- **组织责任**：提供职业信息、轮岗与晋升通道、导师制、继任计划；
- **继任计划**：为关键岗位储备候选人（与人力资源规划的供给预测衔接）。

### 3.3 绩效管理

**绩效管理与绩效考核的区别**：绩效管理是**闭环**（计划—辅导—考核—反馈—改进），绩效考核只是其中一环。

**常用工具**

| 工具 | 特点 |
|------|------|
| **目标管理（MBO）** | 上下共同设定目标，强调**结果导向**与自我控制 |
| **KPI** | 关键绩效指标，聚焦少数关键指标 |
| **平衡计分卡（BSC）** | 从**财务、客户、内部流程、学习与成长**四个维度衡量 |
| **360 度评价** | 上级、同事、下属、客户与自评多方反馈（适合**发展**，慎用于薪酬分配） |
| 关键事件法与行为锚定等级评价法 | 基于行为事实，减少主观性 |
| 强制分布法 | 按比例分级（易引发争议，需谨慎） |

**绩效反馈面谈**：以事实与数据为基础、双向沟通、聚焦改进（**对事不对人**）。

**常见考核偏差**：**晕轮效应、宽大/严格化倾向、居中趋势、近因效应、刻板印象、个人偏见**。

### 3.4 薪酬管理

**薪酬构成**：**基本薪酬 + 奖金 + 津贴补贴 + 福利**（含法定福利与企业补充福利）。

**薪酬体系设计步骤**：**职位分析 → 职位评价 → 薪酬调查 → 薪酬结构设计 → 薪酬水平定位 → 实施与调整**。

| 关键概念 | 说明 |
|---------|------|
| **职位评价** | 确定内部各职位相对价值（方法：排序法、分类法、**要素计点法**、因素比较法） |
| **薪酬调查** | 了解外部市场水平，保证**外部公平** |
| **薪酬结构** | 薪酬等级与幅度（宽带薪酬减少等级、鼓励发展） |
| **薪酬水平策略** | 领先型、跟随型、滞后型、混合型 |
| **内部公平 vs 外部公平** | 前者靠职位评价，后者靠薪酬调查 |

**激励性薪酬**

| 类型 | 形式 | 适用 |
|------|------|------|
| **个人激励** | 计件工资、销售提成、绩效奖金 | 产出可单独衡量 |
| **团队激励** | 团队奖金、收益分享 | 任务高度协作 |
| **组织激励** | 利润分享、员工持股、股票期权 | 长期绑定核心人才 |

### 3.5 福利管理

- **法定福利**：社会保险（养老、医疗、失业、工伤、生育）、法定节假日与带薪年休假等；
- **企业补充福利**：补充医疗与商业保险、企业年金、住房与交通补贴、弹性福利（**弹性福利计划**让员工在总额内自主选择）；
- **趋势**：福利个性化、关注员工体验与工作生活平衡。

## 🔍 深度精讲

### 深讲 1：为什么"考核结果不理想"往往不是考核本身的问题

绩效管理的常见失败原因（案例题高频）：

1. **指标设计问题**：指标与战略脱节、不可衡量、指标过多导致失焦；
2. **过程缺失**：只有年末考核，没有**过程中的辅导与反馈**；
3. **评价者问题**：晕轮效应、宽大化、居中趋势、近因效应；
4. **结果应用单一**：只用于扣钱，未与培训、晋升、发展衔接；
5. **沟通不足**：员工不清楚标准，也不认可结果。

**改进方案（答题模板）**：**战略对齐的指标体系（KPI/BSC）→ 目标共识与中期辅导 → 结构化评价与评价者培训 → 结果面谈与改进计划 → 结果应用于薪酬、培训与晋升**。

### 深讲 2：360 度评价"可以用在哪、不能用在哪"

- **适合**：**员工发展、领导力提升、培训需求识别**（多视角反馈有助于自我认知）；
- **慎用**：**薪酬分配与晋升决策**（可能出现人情分、报复性评价、互评交易），且评价者对被评者的某些维度并不了解；
- **实施要点**：明确评价维度与行为锚定标准、**匿名与保密**、提供反馈辅导、防止"打分游戏"。

**答题提示**：题目若问"360 度评价是否适用于绩效考核结果直接挂钩薪酬"，标准答案是"**不适宜**，宜用于发展性目的"。

### 深讲 3：薪酬公平感的三层结构

| 层次 | 含义 | 实现手段 |
|------|------|---------|
| **内部公平** | 同组织内不同职位间薪酬与贡献相称 | **职位评价**（要素计点法等） |
| **外部公平** | 与市场同类岗位水平相当 | **薪酬调查**与水平定位 |
| **个人公平** | 同岗不同人的差异有据可依 | 绩效与能力导向的**薪酬结构**、透明的调薪规则 |
| 程序公平（附加） | 规则透明、可申诉 | 制度公示、沟通与申诉渠道 |

**案例题答法**：出现"员工抱怨同工不同酬、离职率上升"，应从"**内部公平 → 外部公平 → 个人公平 → 程序公平**"四层依次诊断并给出措施。

## ⚠️ 易错提醒

- **培训需求分析的顺序**是组织 → 任务 → 人员，不要颠倒；
- **柯氏四级评估**由浅到深：反应、学习、行为、结果（"结果层"最难衡量）；
- **绩效管理 ≠ 绩效考核**：前者是闭环，后者只是其中一环；
- **360 度评价**适合发展目的，慎用于薪酬分配；
- **职位评价**解决**内部公平**，**薪酬调查**解决**外部公平**，不要混；
- **法定福利**（社会保险等）不可由企业自行取舍，补充福利才具弹性。
