> **用法**：考前 3 天起只过这一页 + 错题笔记。⚠️ 两科须**同年全部合格**（不滚动）；**各专业批次不同，以准考证为准**。

## 一、经济基础知识：六板块核心结论

| 板块 | 必记结论 |
|------|---------|
| **经济学基础** | 需求与价格**反向**、供给**同向**；最高限价→**短缺**、最低限价→**过剩**；弹性与收入（**富有弹性降价增收**）；MU₁/P₁＝MU₂/P₂；**MC 穿过 AVC 与 ATC 最低点**；四市场结构（完全竞争→完全垄断，控制力递增）；**GDP 支出法 C+I+G+NX** |
| **财政** | 购买性支出（影响配置）vs 转移性支出（影响分配）；**税负转嫁**五方式（前转最常见）；需求越缺乏弹性越易转嫁；税种四类（流转/所得/财产/资源行为）；**四本预算**；**自动稳定器**＝累进所得税 + 失业救济社保 |
| **货币与金融** | **M1 = M0 + 单位活期**（狭义）；M2 含定期与储蓄（广义）；央行三职能（发行的、银行的、政府的银行）；三工具（准备金"猛"、再贴现"条件"、**公开市场"常用"**）；**实际利率 = 名义 − 通胀**；直接标价法；本币贬值→出口增加 |
| **统计** | 中位数**不受极端值影响**；**跨组比较用离散系数**；抽样误差 **σ/√n**（误差减半→样本量 ×4）；**定基 = 环比连乘**、平均发展速度用**几何平均**；**拉氏用基期权数、帕氏用报告期权数**；CPI 是通胀核心指标 |
| **会计** | 四假设（主体/持续/分期/货币计量）；**资产 = 负债 + 所有者权益**；**有借必有贷**；资产负债表**时点**、其余**期间**；计量属性（**历史成本**为基本）；**融资租入固定资产**按实质重于形式 |
| **法律** | 层级（宪法>法律>行政法规>地方性法规>规章）；**不满 8 周岁**无行为能力；可撤销合同 **1 年**（重大误解 **90 日**）；普通诉讼时效 **3 年**；**定金 ≤20%**；公司三会；**法定公积金 10%**（累计达注册资本 50% 可不再提取） |

## 二、计算卡（必须手算）

| 考点 | 公式/要点 |
|------|----------|
| 需求价格弹性 | 点弹性＝需求变动% ÷ 价格变动%；弧弹性用**中点法**（ΔQ/平均Q ÷ ΔP/平均P） |
| 经济利润 | 总收益 − 总成本（**含隐成本**） |
| 离散系数 | **标准差 ÷ 均值**（跨组比较） |
| 抽样标准误 | σ / √n |
| 发展/增长速度 | 发展速度＝报告期/基期；增长速度＝发展速度 − 1 |
| 指数体系 | 销售额指数 = 价格指数 × 销售量指数 |
| 财务比率 | 流动比率＝流动资产/流动负债；速动比率＝（流动资产−**存货**）/流动负债；净资产收益率＝净利润/平均所有者权益 |

## 三、专业科目（以人力资源管理为例）

| 板块 | 必记 |
|------|------|
| 组织行为 | 双因素理论（**保健因素只消除不满、激励因素才有满意**）；期望理论（**激励力＝效价 × 期望值**）；公平理论（亚当斯）；归因（韦纳，**努力＝内部/不稳定/可控**）；**大五人格中责任心**对绩效预测最强 |
| 规划与招聘 | 需求预测（主观判断、德尔菲、趋势、比率、回归）；**供给预测用马尔可夫矩阵**；工作分析产出**职位说明书 + 任职资格**；**结构化面试效度高于非结构化**；**评价中心技术**适合管理岗（成本高） |
| 培训绩效薪酬 | 培训需求三层次（**组织→任务→人员**）；**柯氏四级**（反应/学习/行为/结果）；**360 度评价适合发展、慎用于薪酬**；**职位评价解决内部公平、薪酬调查解决外部公平**；绩效工具（MBO/KPI/BSC/360） |
| 劳动关系 | 书面合同 **1 个月内**；试用期三档（**1/2/6 个月**）；加班工资 **150/200/300%**（法定节假日**不得以补休替代**）；经济补偿"一、半、三倍、十二"；**仲裁前置**、时效 1 年（**追索报酬在关系存续期间不受 1 年限制**） |

## 四、机考与考场（2026 年 11 月 7、8 日）

- **四批次**：11/7 上下午、11/8 上下午；每科 **90 分钟**（上午 08:30–10:00 与 10:40–12:10；下午 14:00–15:30 与 16:10–17:40）；
- **各专业所属批次不同**，以**准考证**为准；**提前 30 分钟到场**并测试设备；
- 考前约 4 周开放**模拟作答系统**（熟悉界面与计算器）；
- 合格标准：各科目按满分 **60%**（近年满分 140 → **84 分**，以官方通知为准）。

## 五、时间分配

```
单选：≤40 秒/题（机考可标记回头）
多选：≤1 分钟/题，注意"多选、错选不得分，少选按比例给分"（以当年度考试说明为准）——**求稳不漏选**
案例分析（专业科目）：先读问题再看材料，边读边划关键数据
最后 5 分钟：检查未作答题目（不留空）
```

> 考前 3 天只看：**本页 + 错题笔记 + 数字卡与计算卡**；政策与税率一律以当年度教材与官方规定为准。
