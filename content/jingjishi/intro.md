## 是什么

**经济专业技术资格**是国家设立的**经济系列职称**，分**初级（助理经济师）、中级（经济师）、高级（高级经济师）**三个级别：

- **初级、中级**：**以考代评**——参加全国统一考试，成绩合格即取得相应级别职称**资格**；
- **高级**：**考试 + 评审**——需先通过高级经济专业技术资格考试，再按规定参加评审。

**中级考两科**：《经济基础知识》（公共科目）+《专业知识和实务》（**10 个专业类别选一**）。两科须在**一个考试年度内全部合格**。

## 10 个专业类别怎么选（职场人最关心）

| 专业类别 | 适合人群 |
|---------|---------|
| **工商管理** | 企业综合管理、运营、市场岗位；**报考人数最多、通用性最强** |
| **人力资源管理** | HR、行政、培训、组织发展岗位（与人力资源管理师知识重叠度高） |
| **金融** | 银行、证券、保险、投融资与风控岗位 |
| **财政税收** | 财税、审计、代理记账与企业税务岗 |
| **建筑与房地产经济** | 建筑、房地产、造价与工程管理岗位（与一建/二建知识有交叉） |
| **知识产权** | 法务、专利代理、科技管理岗位 |
| **农业经济 / 运输经济 / 旅游经济 / 保险** | 对应行业从业者 |

**选择原则**：① 选与**现岗位/目标岗位**最接近的；② 没有明确指向时选**工商管理**（通用、资料最多）；③ 与已有知识体系重叠越多，备考越省力。

## 与初级、高级的关系（晋升路径）

| 级别 | 报考要点（官方口径） |
|------|-------------------|
| **初级** | 从事经济专业工作，具备**高中（含中专、职高、技校）以上学历**即可报考 |
| **中级** | 见下方[含金量与难度](#含金量与难度职场人决策参考)及 [报考指南](/jingjishi/exam-guide/)（大专满 6 年 / 本科满 4 年等 6 类条件之一） |
| **高级** | 取得中级资格后按学历满足年限（专科满 10 年 / 硕士或本科满 5 年 / 博士满 2 年），**考试 + 评审** |

**资格互认（官方口径要点）**：取得导游资格、拍卖师、房地产经纪人协理、银行业专业人员**初级**职业资格，可**对应初级**经济专业技术资格；取得房地产估价师、咨询工程师（投资）、土地登记代理人、房地产经纪人、银行业专业人员**中级**职业资格，可**对应中级**经济专业技术资格；资产评估师、税务师等按规定对应初级或中级。

## 与"人力资源管理师"的区别（常见混淆）

| 对比项 | 中级经济师（人力资源） | 企业人力资源管理师 |
|--------|---------------------|------------------|
| 性质 | **职称**（经济系列） | **职业技能等级**（技能人才评价） |
| 用途 | 职称聘任、落户积分、岗位晋升、部分单位加薪 | 岗位技能证明、部分补贴政策 |
| 组织 | 全国统一考试（中国人事考试网） | 由评价机构组织（原国家职业资格已改革） |

> 若你的目标是**评职称/落户/单位聘任**，通常选**中级经济师**；若目标是**技能补贴**，需先确认当地补贴目录是否包含该职业技能等级证书。

## 含金量与难度（职场人决策参考）

### 一、含金量：它能给你带来什么

| 维度 | 说明 |
|------|------|
| **岗位用途** | **职称聘任**（中级职称）、岗位晋升与部分单位的职称津贴；国企、事业单位、金融机构与大型企业尤为看重 |
| **招聘认可度** | 招聘中常作为"中级职称"条件；也是**高级经济师**的必经台阶 |
| **职称对应** | 本身即**国家职称序列**（经济师），取得资格后可按规定参加单位聘任 |
| **个税与补贴** | 属专业技术人员职业资格，取得证书当年可按 **3600 元**申报继续教育专项附加扣除 |
| **落户/人才政策** | **多地积分落户与人才认定对中级职称有加分**（以当地政策为准）——这是职场人考它的重要动因 |
| **长期价值** | 覆盖经济、财政、金融、统计、会计、法律六大板块，知识通用；对管理与经营岗帮助明显 |
| **它的局限** | 是**职称资格**而非执业资格（不能用于执业签章类工作）；不同单位对"聘任"另有岗位条件 |

### 二、难度：需要投入多少

| 维度 | 评估 |
|------|------|
| **考试结构** | 两科：经济基础知识 + 专业知识和实务（**机考**，每科 90 分钟，两科通常同一半天先后进行） |
| **难度评级** | ★★★☆☆ — **难在"广度"**：经济基础覆盖六大板块；专业知识与实务（如人力资源）另需系统学习 |
| **合格标准** | 各科目按满分的 **60%** 相对固定（满分 140 分→**84 分**；以官方通知与当年度规定为准） |
| **成绩管理** | **两科须在一个考试年度内全部合格**（不滚动），因此"一年过两科"是硬要求 |
| **建议总学时** | 约 **200~350 小时**（在职约 3~5 个月；有财经基础可压缩） |
| **主要难点** | ① 经济基础概念与图形多（需求曲线、成本曲线、货币政策工具等）；② 计算类考点（弹性、统计、会计指标）必须动手算；③ 两科同期通过 |
| **考试频次** | 一年一次（**2026 年 11 月 7、8 日**；报名 7 月 22 日—8 月 12 日） |
| **适合谁** | 需要**中级职称**的国企/事业单位/金融与企业管理人员、HR、财务与工程管理岗人员、希望落户加分者 |
| **建议先别考的情形** | 单纯想"学经济知识"（可用书籍自学）；或所在单位/城市对中级职称无实际用途 |

### 三、一句话结论

> **职场人"评职称"的高性价比选择**：两科同年度通过是唯一硬约束，建议一次报两科、先攻经济基础的六大板块再攻专业科目。
