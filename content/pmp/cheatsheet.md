> **用法**：考前 3 天起只过这一页 + 错题笔记（尤其是"判断逻辑"错题）。PMP 的核心不是记忆，而是**情境判断**。

## 一、考试框架

| 项目 | 内容 |
|------|------|
| 领域 | **人员（People）、过程（Process）、业务环境（Business Environment）** |
| 绩效域 | 相关方、团队、开发方法与生命周期、规划、项目工作、交付、测量、不确定性 |
| 方法 | **预测型、敏捷、混合**（同一考试都考） |
| 题量时长 | 约 **180 题 / 230 分钟**（含 2 次休息，**以 PMI 官方说明为准**） |
| 报名门槛 | **35 小时项目管理培训证明** + 项目经验（按 PMI 要求） |
| 续证 | 每 **3 年 60 个 PDU** |

## 二、情境判断四原则（比知识点更重要）

1. **走流程**：变更、风险、质量都有既定流程——**不要跳步**；
2. **主动**：先分析、先沟通、先记录，而不是等待或只汇报；
3. **协作**：与团队/相关方一起解决，而不是独断；
4. **不越权**：先自行处理；确实超出权限或影响基准时才升级。

## 三、七类高频情境的优先动作

| 情境 | 优先动作 |
|------|---------|
| 相关方提新需求 | 记录 → 评估影响 → **走变更控制流程** |
| 团队冲突 | **合作/解决问题**（面对面、聚焦目标与数据） |
| 风险发生 | 执行**风险应对计划** → 更新风险登记册 → 记录经验教训 |
| 发现质量缺陷 | 先**分析根因** → 纠正措施 → 更新文件 |
| 进度落后 | 先分析原因（关键路径/资源）→ 再考虑赶工或快速跟进 |
| 相关方不满/未识别 | 更新**相关方登记册** + 调整沟通计划 + 主动沟通 |
| 资源被抽调 | 与职能经理协商 → 必要时升级（**先尝试自行解决**） |

## 四、计算卡

| 考点 | 公式 |
|------|------|
| 挣值 | **SV = EV − PV**、**CV = EV − AC**、**SPI = EV/PV**、**CPI = EV/AC** |
| 完工预测 | **EAC = BAC / CPI**；ETC = EAC − AC；VAC = BAC − EAC |
| 三点估算 | （乐观 + 4×最可能 + 悲观）/ 6 |
| 沟通渠道 | **n(n−1)/2** |
| 时差 | **TF ≥ FF**；工期影响看总时差 |

## 五、敏捷与混合术语

| 术语 | 要点 |
|------|------|
| 用户故事 | 遵循 **INVEST** 原则（独立、可协商、有价值、可估算、小、可测试） |
| 故事点与速率 | 相对估算；速率用于预测迭代交付量 |
| 燃尽/燃起图 | 展示剩余工作量趋势 |
| 迭代评审 vs 回顾 | 评审看**产品增量**；回顾看**团队过程改进** |
| 看板 | **WIP 限制**、拉动式流动 |
| Scrum 三角色 | 产品负责人、Scrum Master、开发团队 |
| 风险应对 | 威胁：规避/转移/减轻/接受/上报；机会：开拓/分享/提高/接受/上报 |
| 合同类型 | 总价（**卖方**风险大）/ 成本补偿（**买方**风险大）/ 工料（范围不明） |

## 六、易混对比

| 易混 | 判别 |
|------|------|
| 确认范围 vs 控制范围 | 前者**验收可交付成果**；后者**监督范围与变更** |
| 管理质量 vs 控制质量 | 前者关注**过程**（审计、改进）；后者关注**成果**（检验、偏差） |
| 应急 vs 管理储备 | 应急应对**已知-未知**（含在基准内）；管理储备应对**未知-未知**（不含在基准内） |
| 赶工 vs 快速跟进 | 赶工＝加资源（成本↑）；快速跟进＝并行（返工风险↑） |
| 领导 vs 管理 | 领导重**方向与激励**；管理重**计划与控制** |

## 七、考场节奏（230 分钟）

```
第一段（约 75 分钟）：前 60 题——先做有把握的，标记存疑题
休息 10 分钟
第二段（约 75 分钟）：中段 60 题——注意"下一步最恰当的行动"
休息 10 分钟
第三段（约 70 分钟）：后 60 题 + 回看标记题（留 15 分钟）
```

**答题技巧**：① 选项中出现"直接拒绝/越权决定/只汇报不行动"通常是错的；② 优先选"分析—沟通—按流程"的选项；③ 篇幅最长的不一定对，但**符合流程的通常对**。
