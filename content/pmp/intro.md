## 是什么

**PMP（项目管理专业人士）** 是 PMI 颁发的国际项目管理认证，全球通用。2021 年起考试依据新版**考试内容大纲（ECO）**，按三大领域考查：

- **人员（People）**：团队领导、冲突解决、干系人参与、赋能团队；
- **过程（Process）**：范围、进度、成本、质量、风险、采购等技术过程；
- **业务环境（Business Environment）**：合规、收益实现、组织变革、外部环境影响。

考试形式：**180 题、230 分钟**（含 5 题不计分预试题，示例口径），**预测型（瀑布）与敏捷/混合方法各约占一半**——这意味着只背 PMBOK 传统过程组已不够，必须掌握敏捷实践（迭代、站会、回顾、看板）。

## 证书价值（示例要点，请自行核实）

- **国际通用**：跨国企业、外企与出海项目普遍认可；
- **薪资与晋升**：项目经理岗位招聘常见"PMP 优先"；
- **体系化提升**：把零散经验整理成可复用的管理框架；
- **续证要求**：每 3 年需积累 **60 PDU** 并缴纳续证费用（示例口径，以 PMI 规定为准）。

## 适合人群

- 已带过项目、想把经验系统化的项目经理与团队负责人；
- 想进入外企/跨国项目、需要国际认证背书的工程师；
- 已考过软考中级/高级、希望补充敏捷与国际化视角的从业者。

## 与软考的关系

软考（系统集成/高项）偏向国内职称体系与 IT 集成场景；PMP 偏向国际通用项目管理与敏捷实践。**知识体系高度互补**：本站软考精讲的十大领域可直接迁移，PMP 部分重点补"三大领域 + 敏捷混合 + 情景题思路"。

> ⚠️ 报名条件、费用、考试安排请以 PMI 官网与中国国际人才交流基金会当次公告为准。

## 含金量与难度（职场人决策参考）

### 一、含金量：它能给你带来什么

| 维度 | 说明 |
|------|------|
| **岗位用途** | 项目经理、项目专员、交付与 PMO 岗位；外企、互联网、制造业与跨国公司招聘中常标「PMP 优先」 |
| **招聘认可度** | **市场化认可度高**（尤其外企与出海企业），是项目管理能力的通用语言 |
| **职称对应** | **不直接对应国内职称**；国内职称仍需通过软考、经济师等国内考试 |
| **个税与补贴** | PMP 属**国际认证**，不在国家职业资格目录内，**一般不能申报个税继续教育专项附加扣除**（以税务规定为准） |
| **落户/人才政策** | 少数城市与人才认定相关（以当地为准） |
| **长期价值** | 知识体系（原则 + 绩效域 + 敏捷/混合）可迁移性强；跨国团队协作加分 |
| **它的局限** | **需要续证**：每 3 年积累 60 个 PDU；报名还需 35 小时项目管理培训证明与项目经验 |

### 二、难度：需要投入多少

| 维度 | 评估 |
|------|------|
| **考试结构** | 情境题为主（按人员、过程、业务环境三领域组织，含预测型/敏捷/混合） |
| **难度评级** | ★★★☆☆ — **难在"情境判断"**：没有唯一"技术正确"答案，需按"项目经理下一步最恰当行动"来选 |
| **合格标准** | 无固定分数线，按领域表现评定（以 PMI 官方说明为准） |
| **建议总学时** | 约 **100~180 小时**（有项目管理经验者更快） |
| **主要难点** | ① 中英文题干的理解偏差；② 与国内"背诵型"考试思路不同；③ 需 35 小时培训与经验证明的报名门槛 |
| **考试频次** | 全年可约考（以 PMI 与考点安排为准） |
| **适合谁** | 外企/出海企业从业者、想系统学项目管理方法的人 |
| **建议先别考的情形** | 只为"国内职称"或"落户加分"（PMP 在这两项上作用有限） |

### 三、一句话结论

> **市场化认可强、职称属性弱**：认可它的是用人单位，不是国内职称体系；续证成本要提前算进计划。

> ⚠️ **关于数据的说明**：官方一般不公布统一通过率，上表「难度评级」与「建议学时」为本站依据考试结构、科目数与题型给出的**经验估计**，用于排期参考；**职称对应、补贴标准、落户积分等政策均以国家与你所在省份的最新规定为准**。
