## 一、本证该记什么（三类笔记）

### ① 情境判断卡（PMP 的核心，占绝对多数）

PMP 考的不是"哪个技术最完美"，而是"**项目经理下一步最恰当的行动**"。为高频情境准备判断规则：

| 情境 | 优先动作 |
|------|---------|
| 相关方提出新需求 | 记录并评估影响 → 走**变更控制流程**（不是直接做，也不是直接拒） |
| 团队冲突 | 优先**合作/解决问题**（面对面、聚焦目标与数据） |
| 风险发生 | 执行**风险应对计划** → 更新风险登记册 → 记录经验教训 |
| 质量缺陷 | 先**分析根因** → 采取纠正措施 → 更新相关文件 |
| 进度落后 | 先分析原因（关键路径/资源）→ 再考虑赶工或快速跟进 |
| 相关方不满/未识别 | 更新**相关方登记册**、调整沟通计划、主动沟通 |
| 资源被抽调 | 与职能经理协商（若为矩阵组织）→ 必要时升级，但**先尝试解决** |

**判断原则**：① 遵循流程（变更、风险、质量）；② 主动而非被动；③ 协作而非独断；④ 不越权（该升级时才升级）。

### ② 框架笔记：三领域 + 绩效域

- **ECO 三领域**：人员（People）、过程（Process）、业务环境（Business Environment）；
- **绩效域**：相关方、团队、开发方法与生命周期、规划、项目工作、交付、测量、不确定性；
- **开发方法**：预测型（瀑布）、敏捷（迭代/增量）、混合——**同一考试中都会考**，需能判断"哪种方法适合什么情境"。

### ③ 计算与敏捷术语卡

| 类型 | 内容 |
|------|------|
| **挣值（必手算）** | PV/EV/AC → SV、CV、SPI、CPI、EAC = BAC/CPI、ETC、VAC |
| **进度网络** | 关键路径、总时差与自由时差、提前量与滞后量 |
| **三点估算** | 期望值 =（乐观 + 4×最可能 + 悲观）/ 6 |
| **沟通渠道** | n(n−1)/2（团队规模变化时计算） |
| **敏捷术语** | 用户故事、**INVEST 原则**、故事点与速率、燃尽图、迭代评审与回顾、看板 WIP 限制、Scrum 三角色 |

## 二、避坑清单（PMP 专属 9 条）

| # | 坑 | 正确做法 |
|---|----|---------|
| 1 | 用"背知识点"的方式备考 | 情境题占主导，**必须练判断题**：做 500~800 道情境题并复盘判断逻辑 |
| 2 | 忽略敏捷与混合方法 | 现行考试含大量敏捷与混合情境，**不能只学预测型** |
| 3 | 报名材料没提前准备 | 需 **35 小时项目管理培训证明** + 项目经验（按 PMI 要求），提前整理，避免审核卡住 |
| 4 | 以为拿证就"一劳永逸" | PMP **需续证**：每 3 年积累 **60 个 PDU**，未续证会失效 |
| 5 | 把它当国内职称用 | PMP 属**国际认证**，不直接对应国内职称，也**一般不能申报个税继续教育专项附加扣除**（以税务规定为准） |
| 6 | 只做中文题 | 考试为中英对照，部分表述差异影响判断，**建议中英文题干都练一些** |
| 7 | 忽视"业务环境"领域 | 三领域都要覆盖，业务环境（合规、效益、组织变革）常被忽略 |
| 8 | 计算题不练 | 挣值、三点估算、沟通渠道是稳定考点，**手算到连续 3 题全对** |
| 9 | 赶考前一周才开始刷题 | 至少预留 **6~8 周**刷题 + 复盘（在职建议 100~180 小时） |

## 三、官方与资源入口

| 资源 | 入口 | 用途 |
|------|------|------|
| PMI 官网 | [pmi.org](https://www.pmi.org) | **考试资格、报名、续证（PDU）、考试大纲（ECO）** |
| PMI 授权培训机构 | 见 PMI 官网查询 | 获取 35 小时培训证明（**务必核实授权资质**） |
| PMBOK 指南 / 敏捷实践指南 | 正版出版物 | 知识体系来源（版本以 PMI 当前发布为准） |
| 站内 | [PMP 书籍](/pmp/books/) ｜ [题库](/pmp/practice/) ｜ [学习资源](/pmp/resources/) | 精讲与敏捷混合实战 + 44 题 |

> ⚠️ 提示：PMP 由 **PMI（美国项目管理协会）**组织，与国内职业资格考试体系不同——**报名入口、费用与续证规则一律以 PMI 官网为准**。
