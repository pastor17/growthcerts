> **重要提醒**：PMP 在 GitHub 上的开源资源**多数基于 PMBOK 第六版时代（2021 年前考纲）**，而现行考试已按 ECO 三大领域、并强化敏捷/混合内容。因此这些仓库最适合用作**刷题与思维导图参考**，概念与考纲口径请以 PMI 官方教材与 ECO 为准。下载后请遵守作者说明，**仅供个人学习**。

## 推荐资源（已逐一核验）

### 1. 8 套模拟试题 + 思维导图 + PMBOK 第六版教材
- 仓库：[emacle/pmp](https://github.com/emacle/pmp) ｜ 核验：**39★ · 最近更新 2025-06-19 · 约 92MB · 未标注开源许可证**
- 内含：**PMP 考点模拟试题 A/B/C/D 卷（PDF）**、**每日 10 题（约 200 题）**、PMBOK 第六版电子版与"标记版本"、**xmind 思维导图（五大过程组 + 十大领域 ITTO）**、考试重点流程图，另附在线题库入口
- 适合：需要**大量刷题**与快速复习过程组/ITTO 结构的考生
- 注意：内容基于第六版，敏捷部分需另配最新资料；无许可证仅自用

### 2. 章节真题与其他真题 + 教学视频索引
- 仓库：[xxlllq/pmp](https://github.com/xxlllq/pmp) ｜ 核验：**233★ · 最近更新 2021-12-24 · 约 11MB · 未标注开源许可证**
- 内含：**章节真题**与**其他真题**目录、教学视频网盘索引、通过考试的经验记录
- 适合：按章节做真题巩固（先看本站精讲建框架，再刷这里）
- 注意：更新停在 2021 年（第六版考纲时期）；网盘链接可能失效

### 3. PMBOK 解析工具站源码（学习型项目）
- 仓库：[xulayen/PMP](https://github.com/xulayen/PMP) ｜ 核验：**37★ · 最近更新 2023-01-25 · 约 21MB · 未标注开源许可证**
- 内含：PMBOK 6 与新版教材的解析型前端项目源码
- 适合：想通过"读代码里的知识点结构"来复习的开发者；普通考生可略过

## 官方与正版渠道（优先使用）

- **PMI 官网**（pmi.org）：考试大纲（ECO）、报名与续证、官方教材；
- **中国国际人才交流基金会**：中国大陆考试报名与考位安排；
- 正版《PMBOK 指南》与敏捷实践指南。

## 下载方式

```bash
git clone --depth 1 https://github.com/emacle/pmp.git   # 约 92MB，含 PDF 与模拟题
git clone --depth 1 https://github.com/xxlllq/pmp.git   # 约 11MB，含章节真题
```

> 使用建议：**先框架（本站精讲）→ 再真题（按章）→ 后限时模拟（A–D 卷 + 每日 10 题）→ 错题回炉**，最后再做 2 次完整 180 题限时模拟适应 230 分钟节奏。
