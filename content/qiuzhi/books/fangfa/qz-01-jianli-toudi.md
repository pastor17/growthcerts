## 考点梳理

### 1.1 简历的筛选逻辑

HR 初筛看三件事（顺序固定）：

1. **匹配度**：岗位名称、行业、关键技能是否对上（**关键词**）；
2. **贡献度**：你做出过什么可量化的结果；
3. **风险**：稳定性（跳槽频率）、经历断层、信息真实性。

**推论**：简历不是"自传"，而是**针对某个岗位的论证材料**。

### 1.2 一页结构与排版

```
① 基本信息（姓名/手机/邮箱/城市/求职意向岗位名）
② 一句话定位（X 年 + 领域 + 最亮成果）
③ 工作/实习经历（倒序，占半页以上）
④ 项目经历（1~3 个，与岗位相关）
⑤ 证书与技能
⑥ 教育背景（校招前置）
```

**排版三规则**：一页、倒序、统一格式（纯文本 + 加粗 + 项目符号；不用图表与文本框）。

### 1.3 量化四要素

**动词 + 对象 + 方法/工具 + 结果（量化）**

| 无数字时的替代维度 | 示例 |
|-----------------|------|
| 规模 | 客户 **80+** 家 / 团队 **6 人** / 数据 **TB 级** |
| 频率 | 每周 **3 份** 报告 / 每日处理 **200+** 单 |
| 范围 | 覆盖 **5 个** 城市 / **3 条** 产品线 |
| 难度 | **2 周** 内完成 **12 个** 部门需求调研 |

### 1.4 关键词与 ATS

- 从 JD 摘**高频技能名词** → 在技能栏与经历中各出现一次；
- 文件用 **PDF**、命名 `姓名-岗位-城市-年限.pdf`；
- 不用图片/表格排版（解析可能失败）。

### 1.5 证书与项目怎么写

**公式**：**证书 + 岗位关联 + 实践**
（示例见 [简历页](/qiuzhi/resume/)）

### 1.6 投递判断：没回音的四类原因

| 原因 | 特征 | 对策 |
|------|------|------|
| **匹配度不足** | JD 关键词覆盖 <50% | 按 JD 改写简历 |
| **硬伤** | 无量化、有错别字、格式乱、联系方式错 | 用 20 项自查清单 |
| **渠道低效** | 只用综合平台 | 加内推与官网直投 |
| **岗位虚假/过期** | 长期挂着的岗位、外包中介 | 只投近 7 天发布、有明确公司主体的岗位 |

## 🧠 记忆工具箱

### 简历三问

**"匹配吗（关键词）？有结果吗（量化）？有风险吗（稳定性/真实性）？"**

### 量化公式

**"动词 + 对象 + 方法 + 结果。"**

### 一页 + 倒序 + 统一

**排版三规则。**

### 投递组合

**"内推 3~5 + 官网 5~10 + 平台 10~20。"**

### 跟进一次

**"投递后 5~7 天礼貌询问一次，只问一次。"**

## 🔍 深度精讲

### 深讲 1：为什么"职责式描述"几乎没有竞争力

"负责××工作"只回答"你被安排做什么"，没有回答"**你做出了什么不同**"。招聘方关心的是**增量**：

- 职责式：负责客户维护；
- 结果式：维护 **80+** 客户，通过分层运营把**续费率从 62% 提升到 78%**，年增收入 **××万**。

**改写三问**：① 这件事的规模有多大？② 我用了什么方法/工具？③ 结果比之前好了多少（数字）？

### 深讲 2：关键词匹配的"度"

- **过度**：把 JD 全部词堆进简历 → 面试一问就露馅，反而减分；
- **不足**：只写"沟通能力强""学习能力好" → 系统筛不到、HR 看不出；
- **恰当**：每个关键技能**至少一处有事实支撑**（项目、数据、工具）。

**操作**：把 JD 拆成"必备 / 优先"两栏，必备项 100% 覆盖，优先项覆盖 60% 以上即可。

### 深讲 3：投递与跟进的时间规律

- **周日晚~周二上午**是 HR 处理简历的高峰，投递更容易被看到；
- **岗位发布 7 天内**投递回复率最高（越往后候选人池越大、HR 关注度越低）；
- **跟进只有一次**（5~7 天），过频会被标记为打扰；
- **记录表是必需品**：公司、岗位、渠道、日期、状态、下次跟进日——没有记录表，必然漏跟进或重复投递。

## ⚠️ 易错提醒

- 简历**不要写"负责/协助"而缺结果**；
- **一页**是硬约束（10 年以上可两页），不是"尽量短"；
- 关键词要**有事实支撑**，不要堆砌；
- 证书必须写**与岗位的关联与相关实践**，不要只列名称；
- 投递后**只跟进一次**，且要礼貌、给台阶；
- **不要虚构经历**——背景调查与面试追问很容易核实。
