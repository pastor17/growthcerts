## 考点梳理

### 2.1 面试考察的三件事

| 考察 | 面试官在判断 | 你的回答要体现 |
|------|------------|--------------|
| **能力** | 你能不能干 | 具体做法、工具、量化结果 |
| **动机** | 你愿不愿意干 | 对岗位与业务的理解、职业规划的一致性 |
| **协作** | 关系户会不会难带 | 冲突处理、跨部门协作、反馈接受度 |

### 2.2 STAR：讲经历的唯一可靠结构

**S 情境 → T 任务 → A 行动（占 60%）→ R 结果（量化）**

准备 **5~6 个故事**：成功项目、失败经历、冲突处理、跨部门协作、紧急救火、主动改进——**每个故事可套多个问题**。

### 2.3 高频问题的答题结构

| 问题类型 | 结构 |
|---------|------|
| 自我介绍 | 定位 → 最亮成果 → 为什么来 → 收尾 |
| 为什么应聘 | 岗位要求 × 我的匹配 × 业务理解 |
| 失败经历 | STAR + **明确反思与后续改进** |
| 冲突处理 | 理解对方目标 → 用事实沟通 → 该升级就升级 → 复盘 |
| 缺点 | 真实但可改进 + 已采取的改进措施 |
| 离职原因 | **发展方向与匹配**（不吐槽前公司） |
| 期望薪资 | 先问区间 → 给范围 → 说明依据 |
| 反问 | 岗位目标、团队协作、成长路径（必问 2~3 个） |

### 2.4 期望薪资的三种情景

| 情景 | 应对 |
|------|------|
| 对方先问期望 | **先反问区间**；坚持要给数字时给**范围**（下限＝底线），并说明依据 |
| 已知对方区间，想争取 | 说明"总包不下降/有提升"的合理诉求 + 你能承担的额外职责 |
| 对方报价偏低 | 表达差距 + 给出依据 + 询问**绩效目标、签字费、调薪节奏**等替代方案 |

### 2.5 薪资结构与总包换算

```
年度总包 ≈ 月薪 × 12 + 绩效/奖金 + 年终奖 + 补贴 + 公积金企业缴纳部分 + 股权年化价值
（绩效与年终奖按保守值估算）
```

**七项构成**：基本工资、绩效/奖金、年终奖、补贴、五险一金（**缴纳基数！**）、股权/期权、其他福利。

### 2.6 谈薪时机与筹码

- **时机**：业务面通过后 → HR 面或 offer 沟通阶段（**不要在初面谈钱**）；
- **筹码强度**：稀缺技能 > 可量化成果 > 内推背书 > 竞争 offer > 岗位急招；
- **无筹码时**：优先拿经验与成长，把谈判放到**转正或下次调薪**。

### 2.7 Offer 比较与签约确认

| 步骤 | 做法 |
|------|------|
| 比较 | 维度加权评分（总包、岗位成长、主管、通勤工时、稳定性…）；**分差 <10% 优先选岗位与主管更好的** |
| 确认 | 岗位职责、薪资结构、社保基数、试用期、工时加班、年假、竞业与保密、违约与离职条款 |
| 落地 | 关键待遇**写入合同或书面确认**（口头承诺不算数）；保留 offer letter 与沟通记录 |

## 🧠 记忆工具箱

### STAR 顺序

**"情境—任务—行动—结果"**（行动占 60%，结果必须量化）。

### 三件套

**"能力、动机、协作"**——所有回答都服务这三件事。

### 谈薪三步

**"先问区间 → 给范围不给单点 → 说依据（市场+成果）。"**

### 总包公式

**"月薪×12 + 绩效 + 年终 + 补贴 + 公积金企业部分 + 股权年化。"**

### 比较一句

**"分差 <10%，选岗位内容与直属主管更好的那个。"**

## 🔍 深度精讲

### 深讲 1：为什么"反问环节"不能省

面试尾声的"你有什么想问的"是**最后一次加分机会**：

- 问**岗位目标与成功标准** → 显示你关注结果；
- 问**团队协作与挑战** → 显示你关注落地；
- 问**成长路径** → 显示你打算长期做。

而回答"没有了"会被理解为"对岗位没兴趣"；问"加不加班""有没有双休"则显得只关心待遇（这些放到 offer 阶段问更合适）。

### 深讲 2：谈薪的"锚"从哪里来

谈薪不是凭感觉报价，而是给出**可验证的锚**：

1. **市场区间**：同城市同岗位的公开招聘信息（多看几家，去掉极端值）；
2. **你的现状**：当前总包（如被问及，建议如实，因为社保与背调可核）；
3. **你的增量价值**：能承担的额外职责与可量化成果。

**话术核心**：把"我想要更多"翻译成"**我能多做什么，因此希望评估为 X**"。

### 深讲 3：offer 比较里的"三年后视角"

多数人比较 offer 只看总包，但 3 年后的差距主要来自三件事：

1. **岗位内容**（是否在做有价值、可积累的事）；
2. **直属主管**（是否愿意教你、给你机会）；
3. **行业与公司趋势**（是否在增长赛道）。

**建议权重**：总包 ★★★★★、岗位内容 ★★★★★、主管 ★★★★、通勤工时 ★★★★、稳定性 ★★★、其他福利 ★★★。**分差小于 10% 时，把票投给"能让你 3 年后更值钱"的那个。**

## ⚠️ 易错提醒

- **不要在初面谈薪**，也不要在面试中先报底线；
- 报价给**范围**，别给单点；范围下限就是你能接受的底线；
- **不要虚构竞争 offer**（会被验证，且破坏信任）；
- 总包要**按保守值**估算年终与绩效，不要按"最高值"；
- **口头承诺不算数**：薪资结构、年终奖、岗位范围要写入合同或书面确认；
- 反向也要注意：**接受 offer 后反悔、违约**可能影响学校/行业声誉（三方协议另有约定）。
