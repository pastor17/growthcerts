## 考点梳理

### 3.1 入职 90 天的三个阶段

| 阶段 | 目标 | 关键动作 |
|------|------|---------|
| 第 1 周 | 搞清规则 | 明确团队目标与考核标准、我的职责边界、关键协作人、工具与流程 |
| 第 2~4 周 | 交付小成果 | 选一个 1~2 周能完成的任务，做出结果建立"靠谱"印象 |
| 第 2 个月 | 独立承担 | 完整负责一个小模块，主动同步进度，**带方案求助** |
| 第 3 个月 | 复盘提效 | 写"90 天复盘 + 下季度计划"，提 1~2 条流程改进建议 |

### 3.2 向上管理：汇报五段模板

```
【进展】本周完成…【结果】关键数据…【问题】遇到…我的建议方案 A/B【需要支持】…【下周计划】…
```

**三原则**：① **坏消息早说**；② **带方案不甩问题**；③ **请示边界清晰**（哪些能自定、哪些要审批）。

### 3.3 跨部门协作与边界

| 场景 | 处理 |
|------|------|
| 对方不配合 | 对齐共同目标与截止时间（用事实）→ 必要时请主管协调，不对抗 |
| 被要求做职责外的事 | 紧急支援可做并同步主管；长期越界要**书面确认优先级** |
| 被甩锅 | **留痕**（邮件/文档/纪要）+ 陈述事实与时间线，不评价人 |
| 会上被质疑 | 用数据回应；不确定就说"核实后回复"，不当场硬编 |
| 与主管意见不同 | 私下沟通给方案；决策后执行（涉合规红线除外） |

### 3.4 绩效沟通与加薪三段式

```
① 事实：过去一年完成了什么（量化、含超出预期部分）
② 价值：对团队/业务的影响（含他人或客户反馈）
③ 请求：希望调整到 X（区间）；若有困难，请明确下次评估时间与达标标准
```

**时机**：绩效评估期、完成关键项目后、职责扩大后；**避开**裁员/亏损期。

### 3.5 四类职场困局

| 困局 | 处理路径 |
|------|---------|
| 被边缘化 | 主动请示任务与优先级 → 争取能证明价值的小项目 → 建立跨部门联系 |
| 长期加班无成长 | 记录时间去向 → 提流程优化 → 无改善则用 6~12 个月准备转岗/跳槽 |
| 与主管不合 | 先对齐目标与预期 → 调整沟通方式 → 仍不行考虑内部转岗 |
| 想跳槽但犹豫 | **在职找工作**试水，拿到 offer 再决定；**不裸辞** |

### 3.6 长期竞争力三资产

| 资产 | 维护动作 |
|------|---------|
| **经验** | 每季度更新"成果清单"（可直接改写进简历） |
| **证书** | 按目标岗位反向选择（[怎么选证书](/zhichang/xuan-zheng/)） |
| **作品/影响力** | 每半年沉淀一个可展示成果（报告、系统、案例、分享） |

## 🧠 记忆工具箱

### 90 天节奏

**"第 1 周懂规则 → 第 2~4 周出小成果 → 第 2 月独立 → 第 3 月复盘提效。"**

### 汇报五段

**"进展、结果、问题（带方案）、需要支持、下周计划。"**

### 向上管理三原则

**"坏消息早说、带方案不甩问题、请示边界清晰。"**

### 加薪三段

**"事实 → 价值 → 请求（含替代方案）。"**

### 三资产

**"经验 + 证书 + 作品。"**

## 🔍 深度精讲

### 深讲 1：为什么"坏消息早说"反而更安全

很多人担心"报忧会被批评"，于是把问题压到最后。结果是：

- 问题错过解决窗口 → 代价成倍放大；
- 主管在最后一刻才知道 → 对你**判断力与可靠性**的评价下降。

**正确做法**：发现问题后**当天或次日**同步，并带上"**影响评估 + 我的两个方案 + 需要什么支持**"。这样的汇报会被视为"可托付"，而不是"添麻烦"。

### 深讲 2：绩效沟通的关键是"证据"，不是"努力"

加薪谈判的失败大多源于"讲感受"（我很辛苦、我经常加班）。有效的方式是**把努力翻译成结果**：

| 无效表述 | 有效表述 |
|---------|---------|
| 我经常加班到很晚 | 本月提前 **3 天**交付 XX 报告，并承接了 YY 的临时需求，未影响主线进度 |
| 我做了很多事 | 完成 A/B/C 三件事，其中 A 带来 **××** 效果（对比数据） |
| 我觉得该涨薪 | 我当前承担范围已扩展到××（对比入职时的职责），市场同类岗位为 A~B，希望评估为 B 附近 |

### 深讲 3：把"日常工作"沉淀成"可迁移资产"

每季度做一次 15 分钟的"资产盘点"：

1. 这季度我**独立负责**了什么？（写清规模与结果）
2. 有什么**可展示**的产出？（报告、流程、系统、模板）
3. 有哪些**可以讲成 STAR 故事**的事件？（含一次失败与一次冲突）
4. 我的**技能清单**新增了什么？（工具、方法、行业知识）

**价值**：加薪、跳槽、转行时，你需要的不是"回忆"，而是**已经写好的清单**。

## ⚠️ 易错提醒

- 入职前 90 天**先建立信任，再谈野心**（别急着提大改方案）；
- 汇报要**带方案**，不要只汇报问题；
- 被甩锅时**留痕**比争辩更有效，且陈述事实、不评价人；
- 加薪谈的是**成果与范围变化**，不是"我很努力"；
- 想跳槽时**在职找**，不要裸辞（现金流会迫使你接受更差的选择）；
- 不要**越级汇报成为习惯**（除非涉及合规与人身安全）。
