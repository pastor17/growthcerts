> **一句话结论**：**所有骗局都指向同一个动作——让你先付钱、先贷款、先交出隐私，或先免费干活**。记住这一条，能挡掉 90% 的坑。

> **免责声明**：本文为经验性风险提示，**不构成法律意见**。涉及劳动合同、试用期、三方协议、押金等问题，**一律以现行《劳动法》《劳动合同法》《个人信息保护法》等法律法规及你所在学校/地方的规定为准**；遇到纠纷请通过**官方渠道**（12333、劳动仲裁、公安）解决。

## 一、为什么求职者容易被骗

骗子利用的不是"你笨"，而是三种**真实处境**：

| 处境 | 被利用的方式 |
|------|------------|
| **着急**（毕业在即 / 长期空窗 / 急需收入） | 用"包过""保 offer""当天上岗"解决你的焦虑 |
| **信息差**（不懂行业薪资、不懂流程） | 用"内推名额有限""行业潜规则"制造稀缺 |
| **羞于启齿**（被骗后不好意思说） | 让你不敢报警、不敢告诉家人，方便二次收割 |

> **心理锚点**：**"凡是让你'今天就决定、名额只剩两个'的，先停 24 小时"**——**骗子最怕你冷静**。

## 二、9 类高频骗局，逐个拆

### 2.1 付费内推 / 保 offer

**套路**：声称"有内部名额，交 XXXX 元保你进大厂/国企"，收钱后失联，或给一个假面试然后说"你没通过"。

**真相**：**正规企业的内推是免费的**，内推人拿的是公司给的**推荐奖金**（入职后由公司发），**绝不向求职者收费**。

| 红旗信号 | 正确做法 |
|---------|---------|
| "付费内推""保 offer""保过" | 直接拒绝并举报 |
| 要求转账到**个人账户** | 任何招聘都不该发生 |
| "名额只剩 X 个"制造紧迫 | 冷静，去官网核实该岗位是否存在 |

> **红线**：**"向求职者收费的内推，100% 是骗局"**——没有例外。

### 2.2 培训贷（最危险，会背债）

**套路**：以"招聘"名义约你面试 → 说你**技能不达标** → 推荐"先参加内部培训，培训后包就业" → 引导你签**分期贷款**交学费 → 培训质量差或公司跑路，**贷款却要你自己还**。

**识别**：

```text
① 面试不谈岗位，只谈"你能力不足"
② 提出"先培训再上岗""培训费可以分期"
③ 让你用手机办贷款 / 扫二维码签分期协议
④ 承诺"培训完保底月薪 XX 元"
```

**应对**：**立刻离开**。真正的企业招聘不会要求候选人**先付费培训**才能入职。已签贷款的，保存合同与聊天记录，向 **12315（市场监管）**、**12333（人社）** 投诉，并向公安机关报案。

> **记忆锚**：**"招聘变培训，培训变贷款，贷款自己还"——看到这个链条立刻跑**。

### 2.3 皮包公司 / 虚假招聘（骗简历信息）

**套路**：公司无实际业务，长期挂大量岗位，主要目的是**收集简历（姓名/电话/身份证）转卖**，或为其他业务导流。

**识别**：

| 信号 | 说明 |
|------|------|
| 公司查不到 / 刚注册 / 无社保记录 | 用国家企业信用信息公示系统核实 |
| 岗位描述空泛、薪资异常高 | "无经验月薪 2 万+" 类 |
| 一聊就让你填**详细个人信息表**（含身份证、家庭住址、银行卡） | 入职前不需要这些 |
| 面试地点在**居民楼 / 咖啡厅**而非办公场所 | 高风险 |
| 岗位长期挂着不招满 | "僵尸岗位" |

### 2.4 境外高薪务工（极高危）

**套路**：以"境外高薪、包机票、月入数万"诱骗，实为**跨境电信诈骗、赌博园区**等非法活动，人身自由会被限制，**可能涉及刑事风险**。

**铁律**：

> **"凡是'境外高薪 + 包机票 + 低门槛'，一律按诈骗处理"**——**没有例外，不要抱侥幸心理**。

**应对**：不轻信、不转账、不交护照，**立即向公安机关举报**。

### 2.5 刷单 / 打字 / 点赞 / 试玩兼职

**套路**：先给**小额返利**建立信任（真的返几块），再诱导你**做大额任务**（垫付几千上万），最后以"任务未完成""需再充钱解冻"为由**持续收割**。

**识别**：**任何要求你先垫付资金的"兼职"，都是诈骗**。正规兼职不会让你先出钱。

### 2.6 试用期白嫖（合法边缘的坑）

**套路**：公司不停招人，用**超长试用期 + 低薪**使用劳动力，试用期快满时以"不符合录用条件"辞退，再招下一批。

**法律要点**（**以现行《劳动合同法》为准**）：

| 事项 | 规定要点 |
|------|---------|
| **试用期长度** | 与合同期限挂钩（如 3 个月以上不满 1 年 → 试用期不超过 1 个月；1 年以上不满 3 年 → 不超过 2 个月；3 年以上/无固定期限 → **不超过 6 个月**） |
| **试用期工资** | **不得低于本单位相同岗位最低档工资或约定工资的 80%，且不得低于当地最低工资标准** |
| **同一单位** | **只能约定一次试用期** |
| **违法解除** | 需有**证据证明"不符合录用条件"**，否则可能构成违法解除，需支付赔偿 |

**应对**：入职**当天就要签劳动合同**、明确**录用条件与考核标准（书面）**，保留**考勤与工作成果记录**。

### 2.7 押金 / 服装费 / 体检费 / 建档费

**套路**：以"入职需要"为名收取各种费用，收完就找理由不录用或直接失联。

**法律要点**：**用人单位招用劳动者，不得扣押证件，不得要求提供担保或以其他名义向劳动者收取财物**（**以现行法律为准**）。

> **红线**：**"入职前让你交任何钱（押金/服装费/培训费/建档费），都是违法的"**。

### 2.8 冒充 HR / 领导诈骗

**套路**：伪造企业邮箱/工牌/Offer，让你"配合走流程"转账、买购物卡、"垫付"费用；或冒充公司领导加你微信借钱。

**识别**：

- 邮箱域名**不是公司官方域名**（如 `@qq.com` 冒充大厂）；
- Offer 要求你先转账/买卡/提供银行验证码；
- 只通过**私人微信**沟通，拒绝官方渠道。

**应对**：**挂断，用官网公布的电话回拨核实**。任何"转账/验证码"要求都是诈骗。

### 2.9 传销式招聘

**套路**：以"招聘销售/储备干部"为名，实际拉你入伙，要求**交入门费 + 发展下线**，限制人身自由、集体洗脑。

**识别**：面试就要交钱、要求"拉人头"计酬、住宿集体管理不让单独外出。

**应对**：**设法离开并报警**。

## 三、红旗信号清单（出现 2 条以上就撤）

```text
[ ] 让你先付钱（内推费/培训费/押金/服装费/建档费）
[ ] 让你贷款 / 办分期 / 扫码签协议
[ ] 要身份证原件照片、银行卡、验证码（入职前）
[ ] 承诺"包过""保 offer""保底月薪"，不谈具体工作内容
[ ] 公司查不到、刚注册、无社保、办公地在居民楼
[ ] 薪资明显高于市场（无经验高薪）
[ ] "境外高薪 + 包机票 + 低门槛"
[ ] 只走私人微信，拒绝官方邮箱/电话
[ ] 要求"先垫付"做任务、刷单、试玩
[ ] 制造紧迫感："今天必须定""名额只剩 2 个"
[ ] 面试不让问公司业务，只催你签文件
[ ] 合同不让细看 / 不让带走 / 只有一份且公司留存
```

> **判断锚点**：**"钱、贷、证、急"四个字里出现任何一个，先停下来核实**。

## 四、投前背调 5 步（10 分钟做完）

```text
① 查工商：国家企业信用信息公示系统 → 成立时间、注册资本、经营状态、有无异常
② 查司法：中国裁判文书网 / 执行信息公开网 → 有无劳动纠纷、欠薪被执行
③ 查口碑：脉脉/看准类平台 + 搜索"公司名 + 欠薪/裁员/骗" → 看真实员工评价
④ 查一致性：招聘信息与官网/工商经营范围是否吻合（岗位是否真实存在）
⑤ 查地点：实地或地图核实办公地址（是否为居民楼/虚拟注册地址）
```

**加分项**：看公司**官网是否有该岗位**、**面试是否在正规办公场所**、**HR 用的是不是企业邮箱**。

## 五、被骗后怎么办（别沉默）

| 情形 | 找谁 |
|------|------|
| **诈骗/被威胁/限制人身自由** | **110 报警**（第一时间，保存证据） |
| **培训贷 / 消费欺诈** | **12315**（市场监管）+ 报警 |
| **欠薪 / 试用期违法 / 不签合同** | **12333**（人社）+ 当地**劳动监察**、**劳动仲裁** |
| **招聘平台上的虚假岗位** | **平台内举报**（各平台都有举报入口）+ 12315 |
| **个人信息被冒用** | 报警 + 向平台投诉要求删除 |
| **三方协议纠纷** | **学校就业办** + 依法处理 |

**证据清单（现在就养成习惯）**：

```text
✓ 招聘页面截图（含公司名、岗位、薪资、发布时间）
✓ 完整聊天记录（微信/BOSS/邮件，不要删）
✓ 转账凭证、贷款合同、收据
✓ Offer 邮件、劳动合同（拍照留存）
✓ 面试地点、时间、联系人信息
```

> **心理建设**：**被骗不是你的错，沉默才会让骗子继续害人**。越早报警，追回可能性越大。

## 六、法律保护要点（以现行法律法规为准）

| 事项 | 要点 |
|------|------|
| **劳动合同** | 用工之日起**应订立书面劳动合同**；超过一个月不满一年未订立的，**应支付二倍工资**（以现行法律为准） |
| **试用期** | 有**上限**、**只能约定一次**、工资**不低于 80% 且不低于最低工资** |
| **押金/证件** | 用人单位**不得收取财物、不得扣押证件** |
| **三方协议** | 具有法律约束力，**违约金等条款以协议约定与学校规定为准**，签约前逐条看清 |
| **竞业限制** | 适用于**高管/高级技术人员/保密义务人员**，且**需支付补偿**（以现行法律为准） |
| **个人信息** | 受《个人信息保护法》保护，**有权要求删除、拒绝过度收集** |

> **注意**：法律条款会修订，**具体适用请以最新法律法规与专业法律意见为准**。

## 七、与考证的衔接

**骗局最爱盯的两类人**：① **急着要"资格"的人**（用"包过""保拿证"骗）；② **急着要工作的人**（用"付费内推"骗）。

- **证书类**：正规证书**只有官方或授权机构**能发，**"包过""免考拿证"都是骗局**——报名入口见各证书的[学习资源页](/zhichang/mianfei/)与官方渠道；
- **求职类**：**内推免费、入职免费**——记住这两条，能避开绝大多数坑。

> **联动阅读**：[招聘平台全解](/qiuzhi/pingtai/)（选对平台）+ [投递与渠道](/qiuzhi/toudi/)（正确投递）+ 本页（避开陷阱）。

## ⚠️ 易错提醒

- **"付费内推能走捷径"**：**正规内推免费**，收费的 100% 是骗局；
- **"先培训后上岗很正常"**：**招聘不该要求你先付费培训**，涉及贷款立刻跑；
- **"境外高薪值得赌一把"**：**按诈骗处理，不要侥幸**；
- **"试用期随便辞退没办法"**：**违法解除可主张赔偿**，保留证据去劳动仲裁；
- **"押金交点无所谓"**：**收取押金本身违法**，交了钱反而被动；
- **"被骗了说出来丢人"**：**沉默 = 帮骗子**，越早报警越好；
- **"平台上的岗位都审核过"**：**平台只做形式审核**，真假仍需你自己核实。
