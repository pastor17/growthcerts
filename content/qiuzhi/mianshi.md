> **面试的本质**：面试官在判断三件事——**你能不能干（能力）**、**愿不愿意干（动机）**、**好不好共事（协作）**。所有回答都应为这三件事服务。

## 一、自我介绍模板（1 分钟版，背熟但别像背书）

```
① 我是谁 + 定位：我是 XX，X 年 XX 领域经验，主要做 XX（与岗位直接相关）。
② 一条最亮的成果：在 XX 公司/项目中，我负责 XX，做到了 XX（量化结果）。
③ 为什么来这里：我了解到贵司在 XX 方面……，与我的 XX 经历匹配，希望把 XX 能力用上。
④ 一句话收尾：以上是我的简单介绍，具体想了解哪部分我可以展开。
```

**禁忌**：背简历（把每段经历都念一遍）、讲家庭与性格、超过 2 分钟、空话（"我学习能力强"）。

## 二、STAR：讲经历的唯一可靠结构

**S（情境）→ T（任务）→ A（行动，重点）→ R（结果，量化）**

```
S：当时 XX 项目面临 XX 情况（背景一句话）
T：我负责/需要解决 XX（明确你的任务）
A：我做了三件事——① XX；② XX；③ XX（体现你的方法与思考，占 60% 篇幅）
R：最终 XX（量化结果）+ 我从中得到的经验（一句）
```

**准备方法**：提前写 **5~6 个故事**（成功项目、失败经历、冲突处理、跨部门协作、紧急救火、主动改进），**每个故事都能套多个问题**（这就是"故事库"）。

## 三、高频问题与答法（15 个）

| 问题 | 答法要点 |
|------|---------|
| 介绍一下你自己 | 见上面 1 分钟模板 |
| 为什么应聘这个岗位 | 岗位要求 × 你的匹配点 × 公司/业务理解（**不要只说"我喜欢"**） |
| 你最大的缺点 | 选**真实但可改进**的（如"对细节过度纠结，已用清单管理"），**不要**说"我太追求完美" |
| 讲一个你失败的经历 | STAR + **明确的反思与后续改进**（不怕失败，怕没复盘） |
| 与同事有分歧怎么办 | 先理解对方目标 → 用**数据/事实**沟通 → 必要时上升到负责人决策 → 事后复盘 |
| 你如何安排优先级 | 说明你的判断标准（影响面/截止时间/依赖关系），举例说明 |
| 压力大时怎么办 | 具体方法（拆任务、优先级、求助与沟通）+ 一个真实例子 |
| 为什么离开上一家公司 | **说发展方向与匹配**，**不吐槽**前公司/前领导 |
| 期望薪资 | 见 [谈薪页](/qiuzhi/tanxin/)（**先问区间，再给范围**） |
| 3~5 年规划 | 与岗位发展路径一致的**能力目标**（不要说"当总监"这种空目标） |
| 你对加班怎么看 | 表达**对结果负责** + 说明自己提高效率的方法（不要承诺"随便加"） |
| 你还面了哪些公司 | 如实但**不细说**，可表达"贵司是我的优先选择"（有理有据） |
| 你有什么问题问我们 | 见下方反问清单（**必须准备 2~3 个**） |
| 你的期望汇报对象/团队规模 | 说明你习惯的协作方式（体现自我认知） |
| 如果给你 offer，多久能到岗 | 如实说，涉及离职交接要**留出合规时间**（如提前 30 天通知，见 [避坑指南](/zhichang/bikeng/)） |

## 四、不同类型面试的侧重

| 类型 | 考察 | 准备重点 |
|------|------|---------|
| **HR 面** | 动机、稳定性、文化匹配、薪资预期 | 离职原因、职业规划、期望薪资话术 |
| **业务/技术面** | 硬能力与解决问题的方法 | 项目细节（**能讲清"为什么这么做"**）、现场题、工具使用 |
| **主管面** | 能否共事、独立承担 | 协作案例、主动性、边界感 |
| **群面（无领导讨论）** | 沟通、逻辑、推动力 | 抢**角色但别抢话**；做"归纳+推进"的人最吃香；**记录时间** |
| **终面/高管面** | 视野与长期匹配 | 行业理解、对业务的思考、长期规划 |

## 五、反问清单（面试收尾必问 2~3 个）

**了解岗位（加分）**
- 这个岗位未来 6~12 个月最核心的目标是什么？做到什么程度算优秀？
- 团队目前的构成与协作方式？我会和哪些角色配合最多？
- 目前团队面临的最大挑战是什么？

**了解成长（加分）**
- 团队对新人的培养方式与考核节奏？
- 这个岗位的成长路径通常是什么样的？

**避免问**（或放到 offer 阶段）
- 是否双休、加班多不多（可在 offer 阶段确认，面试阶段问显得只关心待遇）；
- 网上能查到的公司基础信息（显得没做功课）。

## 六、面试后：24 小时内做三件事

1. **发感谢信/微信**（简短、提一个具体交流点，**不要**催促结果）；
2. **写面试复盘**（见下表）；
3. **更新投递记录表**（状态、下次跟进日）。

**复盘表模板**

```
公司/岗位：__________  轮次：__  面试官：__
被问到的问题（凭记忆列出）：① ② ③ …
答得好的：__________（保留这套答法）
答得差的：__________（原因：没准备/结构乱/数据不熟）
必须补的知识点/准备的故事：__________
下一步：□ 等结果（跟进日__） □ 继续投递 □ 补作品
```

## 七、面试常见扣分项

| 扣分项 | 说明 |
|-------|------|
| 讲不清自己项目的细节 | 面试官会追问"为什么这么做""数据怎么来的"——**准备到能解释数字** |
| 吐槽前公司/前领导 | 直接减分（担心你入职后也这样） |
| 答"我不会"就结束 | 应改为"我没做过，但我会这样入手……" |
| 全程只讲团队成果 | 面试官想听**你的**贡献（用"我负责/我推动"） |
| 报价虚高又无依据 | 见 [谈薪页](/qiuzhi/tanxin/) |
| 反问环节说"没有了" | 显得对岗位没兴趣（**必须准备**） |

> **与考证结合**：如果面试官问"为什么考这个证"，答"**目标岗位需要××能力 → 我通过系统学习××证书建立了××知识框架 → 并在××项目中应用**"，而不是复述考试科目。
