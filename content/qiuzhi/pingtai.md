> **一句话结论**：**平台只是曝光渠道，匹配度才决定回复率**。不要在"哪个平台最好"上纠结，而要先确定**目标岗位 → 目标公司从哪招人 → 选 2~3 个主战场深耕**。同一份简历在不同渠道的回复率能差 3~5 倍。

> **时效声明**：招聘平台的业务、域名与规则会变化，本文按**平台类型**归纳通用规律；具体功能、收费与在营状态**以各平台官网当前公示为准**。涉及个人信息的处理，请遵守平台规则与《个人信息保护法》。

## 一、先想清楚：你要的是哪种"投递"

同样的"投简历"，目标不同，选择的平台完全不同：

| 你的目标 | 主战场 | 辅助 |
|---------|-------|------|
| 互联网/新经济**社招** | BOSS 直聘 | 猎聘（资深）、脉脉（内推） |
| **传统行业/职能岗**社招 | 智联招聘、前程无忧 | 公司官网 |
| **中高端/管理岗**（年薪 15w+） | 猎聘 | 脉脉、猎头、领英 |
| **蓝领/基层/服务业** | 58 同城、地方人才网 | 门店直招、劳务市场 |
| **应届生校招** | **24365（官方）+ 学校就业网 + 牛客（技术）** | 应届生求职网、实习僧 |
| **国企/央企** | **国聘** + 企业官网 | 24365、地方国资委 |
| **公务员/事业单位** | 各省人事考试网、人社局 | 中国公共招聘网 |
| **特定行业**（医疗/教师/建筑/设计） | 垂直平台 + 单位官网 | 行业社群 |
| **海外/外企** | LinkedIn、Indeed | Glassdoor、Handshake |

> **决策口诀**：**"先定岗，再看公司从哪招，最后选两三个主战场"**——**"广撒网不如精准打"**。

## 二、第一类：综合招聘平台（社招主力）

### 2.1 平台逐个看

| 平台 | 官网 | 定位 | 适合谁 | 核心特点 | 主要注意 |
|------|------|------|--------|---------|---------|
| **BOSS 直聘** | zhipin.com | 直聊模式，中小/互联网/新经济 | 社招主力、想快速沟通的人 | **和用人方（含老板）直接聊**，反馈快，简历完整度影响曝光 | 岗位质量参差，**注意分辨外包/中介**；"已读不回"很常见，别内耗 |
| **智联招聘** | zhaopin.com | 老牌综合，覆盖广 | 传统行业、国企、校招 | 岗位量大、行业全，**国企/传统企业发布多** | 回复较慢，需靠"简历刷新"维持曝光 |
| **前程无忧（51job）** | 51job.com | 老牌综合 | 外企、制造业、职能岗 | 老牌流量，**外企与制造业岗位较多** | 同上；注意区分"代招"（第三方发布） |
| **猎聘** | liepin.com | 中高端人才 | **3 年以上经验、管理岗、年薪 15w+** | 猎头 + 企业直招并行，**帮你谈薪** | 门槛较高，履历一般时曝光有限 |
| **58 同城（招聘）** | 58.com/job | 蓝领/基层/服务业 | 服务业、销售、技工、骑手等 | 基层岗位密度高、**本地化强** | **信息质量参差，诈骗密度相对高**，务必核验企业 |
| **中华英才网** | chinahr.com | 综合（校园 + 社招） | 校招+社招兼投 | 老牌平台，校园资源 | 岗位更新速度需自行判断 |

### 2.2 BOSS 直聘的"正确打开方式"

BOSS 直聘是"**聊天式求职**"，用不好会石沉大海。要点：

| 环节 | 做法 |
|------|------|
| **简历完整度** | 填到 **90% 以上**（工作经历、项目、技能、期望），完整度直接影响推荐与曝光 |
| **打招呼话术** | **别用默认"你好"**。模板：`您好，我做过 X 年 XX，主导过【与 JD 匹配的一件事 + 量化结果】。看到岗位要求 XX，我这边比较匹配，方便聊聊吗？` |
| **活跃时间** | **工作日 9:00-11:00、14:00-17:00** 在线，HR/老板活跃度最高 |
| **主动出击** | 每天**主动打招呼 10~20 个**精准岗位，别只等被联系 |
| **"已读不回"** | 正常现象（岗位可能已招满/不匹配）。**不要追问、不要刷屏**，直接投下一家 |
| **识别风险** | 一上来就让你"加微信详聊""发身份证""先交钱"→ **停**，走平台内沟通并核实企业 |

### 2.3 猎聘：让"猎头主动找你"

猎聘的逻辑是"**被找到**"，所以重点在简历的**可搜索性**：

- **关键词齐全**：岗位名、技能栈、行业、职级都要写全（猎头是按关键词搜人的）；
- **期望信息明确**：期望城市、薪资、到岗时间写清楚，否则猎头不会推；
- **保持在线**：设置"求职意向开放"，让猎头能看到你的活跃状态；
- **礼貌响应**：即使不感兴趣也简短回复，猎头会记住"可沟通的人"。

> **注意**：任何要求你**先付费**才能"对接猎头/解锁岗位"的，都是骗局——正规律所与猎头向**企业**收费，不向求职者收费。

## 三、第二类：校招/应届专属平台

校招和社招是**两套完全不同的系统**，应届生要优先用校招渠道。

| 平台 | 官网 | 定位 | 为什么重要 |
|------|------|------|-----------|
| **24365 国家大学生就业服务平台** | ncss.cn | **教育部官方** | **权威、免费、无中介**。含职位信息、专场招聘、重点领域、实习岗位、就业指导、**风险提示**，还能办**毕业去向登记** |
| **学校就业信息网 / 就业办** | 各校自有 | **本校官方** | **最被低估**：定向岗位（只对本校开放）、宣讲会、双选会、三方协议与派遣手续指导 |
| **牛客网** | nowcoder.com | **技术岗校招首选** | 笔试真题/在线编程、**面经**（含大厂真实面试题）、内推码、公司薪资爆料 |
| **应届生求职网** | yingjiesheng.com | 校招信息集散地 | 校招公告聚合、宣讲会信息、笔经面经 |
| **实习僧** | shixiseng.com | 实习为主 | 找实习、争取**转正**（最稳的校招路径） |
| **梧桐果 / 海投网** | — | 校招聚合 | 补充渠道，注意信息时效 |

**校招渠道优先级（应届生）**：

```text
① 学校就业网/就业办（定向岗位 + 手续指导）  ★★★★★
② 24365 官方平台（权威 + 免费）              ★★★★★
③ 目标公司官网/公众号校招入口                ★★★★★
④ 牛客网（技术岗：笔试 + 面经 + 内推）        ★★★★
⑤ 应届生求职网 / 实习僧                      ★★★
⑥ 综合平台校招频道                          ★★
```

> **应届生铁律**：**"校招看的是潜力，不是经验"**——没有实习就用**课程项目、竞赛、开源、证书 + 可展示作品**补位（见[校招专题](/qiuzhi/xiaozhao/)）。

## 四、第三类：官方与公共就业服务（免费、权威、常被忽略）

| 平台 | 官网 | 主管 | 覆盖 |
|------|------|------|------|
| **中国公共招聘网** | job.mohrss.gov.cn | 人力资源社会保障部 | 全国公共就业服务、岗位信息、就业政策 |
| **国聘** | iguopin.com | 央企国企招聘平台 | **央企、国企**岗位集中发布 |
| **各省人事考试网 / 人社局** | 各省自有 | 省级人社厅 | **公务员、事业单位、国企**招考公告**首发地** |
| **12333 人社服务热线** | — | 人社部 | 就业政策咨询、**劳动维权投诉** |
| **各地人才市场 / 人才服务中心** | 各地自有 | 地方政府 | 本地国企、事业单位、专场招聘会 |

> **为什么必看**：**公务员、事业单位、国企的招考公告，永远以官方渠道为准**。第三方平台转发的信息可能滞后、有误甚至被篡改。**认准"gov.cn"域名**。

> **防骗锚点**：**"官网域名带 gov.cn / 平台不收费 / 不走私人转账"**——三条同时满足，可信度才高。

## 五、第四类：垂直与行业平台

垂直平台岗位量少但**匹配度高**，适合"目标明确"的人。

| 行业 | 渠道 | 说明 |
|------|------|------|
| **互联网/技术** | 牛客网、各大厂招聘官网 | 技术岗以**官网 + 内推**为主，平台为辅 |
| **设计/创意** | 站酷、UI 中国等社区 + 公司官网 | **作品集比简历重要**，社区活跃度带来机会 |
| **医疗/医药** | 丁香人才等医疗垂直平台 | 医院官网/人事科公告同样是主渠道 |
| **教师/教育** | 中国教师人才网、各地教育局官网 | **教师招聘以地方教育局公告为准** |
| **建筑/工程** | 建筑英才网等行业平台 | 建造师等**执业资格**常是硬门槛（见[二建](/erjian/)/[一建](/yijian/)） |
| **法律** | 律所官网、法律行业社群 | 律所多走**官网 + 内推**，实习转正常见 |
| **财会** | 会计师事务所官网校招 | 四大/内资所**官网校招**是主入口（[CPA](/cpa/)） |
| **高校/科研** | 高校人才网等 | 教职/科研岗看**编制公告 + 学校人事处** |

> **通用规律**：**越是专业化的岗位，越依赖"官网 + 内推 + 垂直社群"，综合平台的作用越小**。

## 六、第五类：社交网络与内推

| 渠道 | 定位 | 用法 |
|------|------|------|
| **脉脉** | 职场社交 | 看公司真实评价/薪资爆料、**找内推**、了解部门情况 |
| **领英（LinkedIn）** | 外企/海外/中高端 | 完善英文档案、连接目标公司员工、被猎头发现 |
| **微信公众号** | 公司招聘官方号 | **关注目标公司招聘号**，首发岗位与宣讲会 |
| **微信社群** | 行业/校友群 | 内推码流通地，**先提供价值再求内推** |
| **校友网络** | 高校校友会 | 转化率最高的冷启动渠道之一 |

**内推话术**见[投递与渠道页](/qiuzhi/toudi/)——核心是"**先给具体问题或价值，不要一上来就要内推**"。

## 七、第六类：海外与留学求职

| 平台 | 适用 |
|------|------|
| **LinkedIn** | 全球通用，外企/跨国岗位 |
| **Indeed** | 全球最大职位聚合之一 |
| **Glassdoor** | 公司评价 + **薪资透明**（面试准备利器） |

## 九、平台使用 7 条通用原则

```text
① 多平台并行：2~3 个主战场 + 1 个官方渠道，别单点依赖
② 简历按岗位改：关键词对齐 JD（见简历页），一稿多投是回复率杀手
③ 优先投"近 7 天"发布的岗位：老岗位多半已招满
④ 投前先查公司：工商信息 + 口碑 + 招聘信息一致性（见避坑页）
⑤ 全程留痕：聊天记录、岗位截图、邮件都保存
⑥ 永不付费：任何"付费内推/保 offer/押金"都是骗局
⑦ 保护隐私：身份证、银行卡、验证码不轻易提供
```

> **记忆锚**：**"多渠道、改简历、投新岗、查公司、留痕迹、不付钱、护隐私"**——**七条守住，求职不亏**。

## 十、与考证的衔接

选平台之前，先确认**目标岗位认哪些证**：

1. **读 JD 的"任职资格"**：把"必须"与"优先"分开列出来；
2. **反向定证**：只考岗位真正要求的证（见[怎么选证书](/zhichang/xuan-zheng/)）；
3. **写进简历**：技能栏 + 项目里体现（见[简历页](/qiuzhi/resume/)）；
4. **答进面试**：用岗位语言解释"为什么考、解决了什么问题"（见[面试页](/qiuzhi/mianshi/)）。

> **本站已覆盖 24 个证书体系**——先看[行业岗位地图](/qiuzhi/hangye/)确认目标行业看重什么，再决定投哪些平台、补哪些证。

## ⚠️ 易错提醒

- **"只用一个平台"**：曝光量决定机会量，**至少 2~3 个主战场并行**；
- **"一份简历投所有岗位"**：关键词不匹配 → 简历库筛选第一关就被刷；
- **"只等平台推荐"**：BOSS/猎聘都奖励**主动行为**，被动等 = 低曝光；
- **"忽视官方渠道"**：公务员/事业单位/国企的公告**只在官方渠道首发**，错过就是错过；
- **"在 58 等同城平台裸投"**：信息质量参差，**投前必须核验企业**（见[避坑页](/qiuzhi/fangpian/)）；
- **"相信付费内推"**：**正规内推从不向求职者收费**——这条是红线；
- **"平台聊得投机就发身份证"**：**入职前不需要身份证原件照片**，要的多半有问题。
