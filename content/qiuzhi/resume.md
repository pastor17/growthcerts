> **前提**：HR 初筛平均只看 **15~30 秒**。简历的目标不是"写全"，而是"**让对方在 15 秒内判断你值得面试**"。所以：**一页、结构清晰、结果量化、与岗位强相关**。

## 一、一页简历的固定结构（社招/校招通用）

```
① 基本信息（1~2 行）：姓名 | 手机 | 邮箱 | 所在城市 | 求职意向（关键：写清岗位名）
   （可选项：作品集/主页/GitHub 链接——技术、设计、运营岗强烈建议放）
② 一句话定位（2 行内）：X 年 + 什么领域 + 最拿得出手的成果
③ 工作/实习经历（倒序，最重要，占半页以上）
④ 项目经历（1~3 个，与岗位相关）
⑤ 证书与技能（含目标岗位硬性要求的证）
⑥ 教育背景（校招前置；社招可后置或精简为一行）
```

**排版三条硬规则**：① **一页**（10 年以上经验可两页）；② **倒序时间**，每段统一格式；③ **留白与层级**——不要密密麻麻，也不要用花哨模板与图表（除非设计岗）。

## 二、经历怎么写：从"职责"改成"结果"

**公式**：**动词 + 对象 + 方法/工具 + 结果（量化）**

| 差（职责式） | 好（结果式） |
|------------|------------|
| 负责公司微信公众号运营 | 独立运营公众号（0→1）：**6 个月涨粉 1.2 万**，图文平均打开率由 2.1% 提升至 **5.8%**，带来线索 **300+ 条** |
| 参与 XX 系统开发 | 负责订单模块重构：接口平均响应从 **480ms 降至 120ms**，线上故障率下降 **60%** |
| 协助处理客户投诉 | 建立投诉分类与响应 SOP：平均处理时长由 **48h 缩短至 12h**，重复投诉下降 **35%** |

**没有数字怎么办**：用**规模、频率、范围、难度**替代——
- 规模：管理客户 **80+** 家 / 数据量 **TB 级** / 团队 **6 人**；
- 频率：每周输出 **3 份** 分析报告 / 每日处理 **200+** 单；
- 范围：覆盖 **5 个** 城市 / **3 条** 产品线；
- 难度：在 **2 周** 内完成对 **12 个** 部门的需求调研。

**每段经历写 3~5 条**，第一条放最亮的成果。

## 三、关键词与筛选（ATS 友好）

很多公司用系统（ATS）先做关键词筛选。做法：

1. 从**目标岗位 JD** 里摘出**高频名词与技能词**（如"数据分析 / SQL / 用户增长 / 项目管理"）；
2. 在简历里**自然地**出现这些词（技能栏 + 经历描述各出现一次）；
3. **不要**堆砌无关关键词；**不要**用图片/文本框排版（文本可能无法被解析）；
4. 文件用 **PDF**（除非公司要求 Word），命名规范：**姓名-岗位-城市-年限.pdf**。

## 四、证书怎么写（与考证打通）

**不要只写证书名称**，按"**证书 + 岗位关联 + 实践**"写：

| 差 | 好 |
|----|----|
| 一级建造师（已通过） | **一级建造师（建筑工程）**：具备大中型项目施工管理知识体系；在 XX 项目（3.2 万㎡）中负责进度与安全管理，配合完成 **2 次** 专项方案编制与验收 |
| 中级经济师（人力） | **中级经济师（人力资源管理）**：系统掌握薪酬与绩效设计方法；主导完成岗位说明书 **36 份** 与绩效指标库搭建 |
| 初级会计 | **初级会计职称**：能独立处理往来与费用核算；负责月度费用归集 **30+ 科目**，对账差错率 **0** |

**原则**：没有实践支撑的证书，就写在"证书与技能"栏并加一句"**可快速上手××工作**"，不要编造项目。

## 五、应届生"没有经历"怎么办（三个替代来源）

1. **课程/毕设项目**：按"目标—方法—结果"写，突出你**独立完成的部分**；
2. **竞赛/社团/志愿**：写清角色、规模与结果（如"组织 200 人活动，赞助落地 1.2 万元"）；
3. **自学与作品**：围绕岗位做一个**可展示的作品**（分析报告、小程序、作品集、公众号），比"熟悉 Office"有说服力。

**同时**：把与岗位相关的**证书**作为主要竞争力（校招中"持证"常是差异化项）→ [怎么选证书](/zhichang/xuan-zheng/)。

## 六、投递前 20 项自查清单（逐条打勾）

- [ ] 是否**一页**？字体与字号统一？
- [ ] 是否有**明确的求职意向岗位名**（与目标 JD 一致）？
- [ ] 手机号、邮箱**是否正确**（常见低级错误）？
- [ ] 每段经历是否**动词开头 + 有量化结果**？
- [ ] 是否**倒序**排列？时间是否连续（有空白期是否有解释）？
- [ ] JD 中的**关键词**是否已覆盖？
- [ ] 是否写了"**负责/协助**"过多而缺结果？
- [ ] 技能栏是否**分层**（熟练/了解）而非一锅端？
- [ ] 证书是否**与岗位相关**并写了实践？
- [ ] 是否有**错别字**（尤其公司名、岗位名、技术名词）？
- [ ] 文件是否为 **PDF**、命名是否规范？
- [ ] 是否删除了**无关信息**（身高体重、家庭情况、与岗位无关的爱好）？
- [ ] 是否避免了**夸张与造假**（背景调查会核）？
- [ ] 数字是否**真实可解释**（面试会追问）？
- [ ] 是否针对**这一家公司/岗位**做了微调？
- [ ] 作品集/链接是否**可正常打开**（自己先点一次）？
- [ ] 邮箱是否为**正式邮箱**（如 姓名拼音@ 而非网名邮箱）？
- [ ] 是否准备**两个版本**（技术/业务或大厂/中小企业侧重不同）？
- [ ] 是否让**一位朋友通读**并复述你的亮点？
- [ ] 投递记录是否已登记（公司/岗位/时间/渠道/状态）？

## 七、常见错误（直接对照删掉）

| 错误 | 后果 | 改法 |
|------|------|------|
| 大段自我评价（"本人勤奋踏实…"） | 占空间、无信息 | 换成一句定位 + 量化成果 |
| 职责抄 JD | 看不出你的贡献 | 写"你做了什么、产生什么结果" |
| 技能栏写"精通 Office" | 无区分度 | 写具体能力（数据透视表/函数建模/报告撰写） |
| 一段经历写 10 条 | 重点被淹没 | 精选 3~5 条，第一条最亮 |
| 用表格/图表排版 | ATS 解析困难、手机端错乱 | 纯文本 + 加粗 + 项目符号 |
| 一份简历投所有岗位 | 匹配度低 | 按岗位微调关键词与顺序 |
