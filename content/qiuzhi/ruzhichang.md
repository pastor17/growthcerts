> **入职前 90 天决定别人对你的长期印象**：这段时间你不是在"表现能力"，而是在**建立信任与预期**——让主管知道"交给你的事会放心"。

## 一、90 天计划表（按周拆）

| 阶段 | 目标 | 关键动作 |
|------|------|---------|
| **第 1 周** | 搞清楚"游戏规则" | 弄清：团队目标与考核标准、我的职责边界、关键协作人、常用工具与流程；**主动要一份岗位说明书或明确任务清单** |
| **第 2~4 周** | 交付第一个小成果 | 选一个**小而明确**的任务（1~2 周能完成）做出结果，建立"靠谱"印象 |
| **第 2 个月** | 独立承担模块 | 完整负责一个小模块/流程；主动同步进度，遇到阻塞**带方案求助** |
| **第 3 个月** | 复盘与提效 | 写一份"90 天复盘 + 下季度计划"给主管；提出 1~2 条流程改进建议 |

**每周固定动作**：① 周报（见下方模板）；② 与主管一次 15 分钟 1v1（对齐优先级与反馈）。

## 二、向上管理：汇报模板（直接抄）

```
【进展】本周完成：① … ② …
【结果】关键数据：…（尽量量化）
【问题】遇到：… ；我的建议方案：A / B（请确认）
【需要支持】需要您协调：…（明确要人/要资源/要决策）
【下周计划】① … ② …（按优先级排序）
```

**三条原则**：
1. **坏消息早说**（问题拖到最后才暴露，信任损失最大）；
2. **带方案不甩问题**（"我建议 A，理由是…，请您定"）；
3. **请示边界清晰**（哪些你能定、哪些要审批，入职第一周就问清）。

## 三、跨部门协作与边界感

| 场景 | 处理 |
|------|------|
| 对方不配合 | 先确认**共同目标与截止时间**（用事实沟通），必要时请主管协调，**不要情绪对抗** |
| 被要求做职责外的事 | 区分"紧急支援"与"长期越界"：前者做并要求同步主管；后者**书面确认优先级** |
| 被甩锅 | **留痕**（邮件/文档/会议纪要）；陈述事实与时间线，**不评价人** |
| 会上被质疑 | 用数据回应；不确定就说"我核实后回复"，**当场不要硬编** |
| 与主管意见不同 | 私下沟通、给方案与数据；**决策后执行**（除非涉及合规红线） |

## 四、绩效沟通与加薪

**绩效评估前**：把一整年的**成果清单**整理好（做了什么、量化结果、超出预期的部分、他人反馈）。

**加薪谈法（三段式）**

```
① 事实：过去一年我完成/超出的部分（量化）
② 价值：这些成果对团队/业务的影响（最好有他人或客户反馈）
③ 请求：基于岗位市场水平与我的贡献，希望调整到 X（区间）；若暂时有困难，能否明确下一次评估时间与达标标准？
```

**时机**：绩效评估期、完成关键项目后、职责扩大后；**不要**在公司裁员/亏损期谈。

## 五、四种常见职场困局

| 困局 | 表现 | 处理建议 |
|------|------|---------|
| **被边缘化** | 不给重要任务、信息不透明 | 主动请示任务与优先级 + 争取一个能证明价值的小项目 + 建立跨部门联系 |
| **长期加班但无成长** | 重复劳动、无人指导 | 记录时间去向 → 提出流程自动化/优化 → 若无改善，**用 6~12 个月准备转岗/跳槽** |
| **与主管不合** | 频道不同、被否定 | 先对齐目标与预期（问"您希望的结果是什么"）→ 调整沟通方式 → 仍无法改善再考虑内部转岗 |
| **想跳槽但犹豫** | 不确定时机与风险 | 先**用"在职找工作"**的方式试水（投递+面试），拿到 offer 再决定；**不裸辞** |

## 六、长期竞争力：经验 + 证书 + 作品

| 资产 | 说明 | 行动 |
|------|------|------|
| **经验** | 可讲清的成果（STAR 故事库） | 每季度更新一次成果清单 |
| **证书** | 岗位硬门槛或加分 | 按目标岗位反向选择（[怎么选证书](/zhichang/xuan-zheng/)） |
| **作品/影响力** | 报告、系统、案例、分享、内部分享 | 每半年沉淀一个可展示的作品 |

> **一句话**：**"定期把做过的事变成可展示的资产"**——这是加薪、跳槽、转行时最有力的筹码，比"我很努力"有说服力得多。

## 七、职场红线（别踩）

1. **简历与经历造假**（背调会核）；
2. **泄露前公司机密/客户资料**（可能违法，见 [版权与使用条款](/license/) 关于合规的态度）；
3. **越级汇报成为习惯**（除非涉及合规与人身安全问题）；
4. **在公开场合评价同事/主管**（社交平台尤甚）；
5. **不签或不懂合同条款就入职**（见 [谈薪页](/qiuzhi/tanxin/) 的"签约前 8 件事"）。
