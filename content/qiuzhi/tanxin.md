> **谈薪不是"讨价还价"，而是"把双方对价值的判断对齐"**。你不谈，对方就默认按最低预算给；但你乱谈，也可能丢掉机会。关键是：**用市场区间和你的价值说话，而不是用情绪**。

## 一、先看懂薪资结构（别只盯月薪）

| 组成 | 说明 | 常见坑 |
|------|------|-------|
| **基本工资（月薪）** | 固定部分，影响社保基数与加班费计算 | 有的公司把大部分钱放绩效，月薪很低 |
| **绩效/奖金** | 季度或月度，与考核挂钩 | 承诺"最高 3 个月"实际常年打折 |
| **年终奖** | 常见 1~6 个月不等（因公司而异） | 是否写入合同、发放条件（在职要求） |
| **补贴** | 餐补、交通、通讯、租房、外派 | 是否计入社保基数、是否长期 |
| **五险一金** | 缴纳基数与比例直接影响实际收入 | **按最低基数缴纳**是隐性降薪 |
| **股权/期权** | 长期激励 | 兑现条件、行权价、离职处理 |
| **其他** | 补充医疗、年假、弹性办公、培训 | 年假天数与是否带薪 |

**换算方法**：把 offer 换算成"**年度总包（TC）**"再比较：

```
年度总包 ≈ 月薪 × 12 + 绩效/奖金 + 年终奖 + 补贴 + 公积金企业缴纳部分 + 股权年化价值
（注意：绩效与年终奖按"保守值"估算，不要按"最高值"）
```

## 二、期望薪资怎么答（按场景选）

**场景 1：对方先问"期望薪资"（最常见）**

```
我想先了解一下这个岗位的薪资区间和结构，这样我们沟通会更有效率。
（若对方坚持要数字）根据我的了解，市场上同类岗位大致在 A~B 之间；
结合我的 XX 年经验和 XX 成果，我的期望是 B 附近，具体可以结合整体方案考虑。
```

**要点**：① **先反问区间**；② 给**范围不给单点**（范围下限就是你能接受的底线）；③ 报价**基于市场与自身价值**，能说出依据。

**场景 2：你已知道对方区间，想争取更高**

```
感谢认可。我对岗位本身很感兴趣。
有一点想沟通：我目前/上一份的年度总包是 X，期望在总包上不下降（或有一定提升）。
另外我在 XX 方面可以直接承担 XX 工作，是否可以在这个基础上评估？
```

**场景 3：对方报价低于预期**

```
谢谢反馈。这个数字和我的预期有一些差距（我的预期是 Y，依据是市场同类岗位与我的××经验）。
如果基本工资空间有限，是否可以看绩效目标、签字费或入职后的调薪评估节奏？
```
（**不要**情绪化、不要威胁"不给就不来"，除非你确实有其他 offer 且能承受结果。）

## 三、谈薪的时机与筹码

| 时机 | 说明 |
|------|------|
| **不要在初面谈薪** | 先让对方认可你的能力，再谈钱 |
| **最佳时机：业务面通过后、HR 面或 offer 沟通阶段** | 此时你已被"内部认可" |
| **有竞争 offer 时** | 筹码最大（但要**诚实**，不要虚构 offer） |

**你的筹码（按强度）**：① 稀缺技能/行业经验；② 可量化的成果；③ 内推背书；④ 竞争 offer；⑤ 岗位急招。

**几乎没有筹码时**（转行、无经验）：优先拿"**经验和成长**"，把薪资谈判放到**转正或下次调薪**。

## 四、Offer 比较表（技术性决策，别凭感觉）

| 维度 | A 公司 | B 公司 | 权重 |
|------|-------|-------|------|
| 年度总包（保守估算） | | | ★★★★★ |
| 基本工资/社保基数 | | | ★★★★ |
| 岗位内容与成长 | | | ★★★★★ |
| 直属主管与团队 | | | ★★★★ |
| 通勤与工时（含加班） | | | ★★★★ |
| 公司与行业稳定性 | | | ★★★ |
| 培训与晋升机制 | | | ★★★ |
| 落户/编制/长期福利 | | | 视个人情况 |

**用法**：给每项打 1~5 分 × 权重求和；**如果两个 offer 分差小于 10%，优先选"岗位内容与主管"更好的那个**（3 年后的差距主要来自这里）。

## 五、签约前必须确认的 8 件事

1. **岗位名称与职责**（是否与实际工作一致）；
2. **薪资结构**：月薪、绩效、年终奖的计算与发放条件；
3. **社保公积金**：缴纳基数与比例、起缴时间；
4. **试用期**：时长、试用期工资、转正标准（**法律规定试用期长短与合同期限挂钩**，以现行法律为准）；
5. **工时与加班**：是否有加班费/调休制度；
6. **年假与假期**：天数与带薪情况；
7. **竞业限制与保密**：是否适用、是否有补偿（**以现行法律规定为准**）；
8. **违约与离职条款**：提前通知期、是否有不合理违约金。

> ⚠️ **口头承诺不算数**：关键待遇（薪资结构、年终奖、岗位）**要求写入劳动合同或书面确认**（邮件/offer letter）。

## 六、入职前的收尾动作

- **离职交接**：按法定与合同约定的**提前通知期**提出离职（一般提前 30 天书面通知，试用期 3 天，以现行法律规定为准），做好交接记录；
- **背调准备**：确保简历与过往经历**真实一致**（薪资、职位、时间）；
- **入职材料**：身份证、学历学位、离职证明、体检报告、银行卡等（按公司要求）；
- **保留证据**：offer letter、薪资沟通记录、劳动合同各留一份。

## 七、常见问题速答

| 问题 | 答法 |
|------|------|
| 上一份薪资要如实说吗 | **建议如实**（背调与社保记录会核），但可强调**总包与期望**；不要虚构 |
| 对方问"最低能接受多少" | 不要报底线；回答"我更关注整体方案，具体看结构" |
| 拿到 offer 后还能谈吗 | 可以，**一次为限**，基于新信息（如竞争 offer、岗位范围扩大） |
| 谈崩了怎么办 | 保持礼貌与联系，**不要撕破脸**（行业内圈子很小） |
| 试用期可以谈薪吗 | 可在转正评估时谈，**用成果说话**（见 [入职 90 天](/qiuzhi/ruzhichang/)） |

> **与考证结合**：某些证书是**岗位硬门槛**或**薪酬档位依据**（如建造师、注安、教师、社工等）——报考前先确认单位是否认可，见 [证书百科的"含金量与难度"](/jianli/intro/) 与 [报名与政策实务](/zhichang/baoming/)。
