> 应届生最大的优势是**校招通道**（企业愿意培养、对经验要求低），最大的风险是**错过节奏**（秋招一旦错过，可选岗位会明显变少）。这一页按时间线给动作。

## 一、校招时间线（按学期倒排）

| 时间 | 你要做的事 | 备注 |
|------|-----------|------|
| **大三/研二 上学期（9–12 月）** | 确定方向（行业/岗位）、补技能与项目、找**寒假实习** | 方向越早定，简历越有针对性 |
| **大三/研二 下学期（3–6 月）** | 投**暑期实习**（重点！）；准备简历与笔试题库 | **暑期实习是转正与秋招的入场券** |
| **暑期（7–8 月）** | 实习 + 争取**转正机会**；同时更新简历 | 有转正 offer 会让秋招心态完全不同 |
| **秋招提前批（7–8 月）** | 投递提前批（竞争小、流程快） | 不必等"准备好"再投 |
| **秋招正式批（9–11 月）** | 集中投递 + 笔试 + 面试（**黄金期**） | 9 月是高峰，越早越好 |
| **秋招补录（11–12 月）** | 关注补录与"被毁约释放"的岗位 | 机会常出现在别人放弃时 |
| **春招（次年 3–4 月）** | 第二轮投递；部分企业仍有大量岗位 | 岗位少于秋招，但竞争也小 |
| **毕业前（5–6 月）** | 签约、办理三方/报到证/档案（**以学校就业办规定为准**） | 提前问清流程与截止时间 |

## 二、没有实习怎么办（三个替代方案）

1. **用项目替代实习**：课程设计、毕设、竞赛、开源项目、个人作品——写成"**目标—方法—结果**"，突出你独立完成的部分；
2. **用证书补足专业度**：校招中对"是否具备岗位基础知识"很看重，**持证**是低成本差异化项（如财会岗初级会计、工程岗二建/一建方向、教育岗教资、IT 岗软考/PMP）→ [怎么选证书](/zhichang/xuan-zheng/)；
3. **用可展示作品说话**：把学过的东西做成**一个能点开看的东西**（数据看板、分析报告、网站、作品集、公众号），比"熟悉××"有说服力。

> **注意**：不要编造实习经历（背调与面试追问会暴露）。宁可写"自学 + 项目"，也不要造假。

## 三、简历与项目的"应届生写法"

| 板块 | 应届生怎么写 |
|------|------------|
| 教育背景 | **前置**（学校、专业、GPA/排名若不错就写、相关课程 3~5 门） |
| 实习/项目 | 选中**与岗位最相关**的 2~3 段；每段 3 条，第一条最亮 |
| 证书 | 与岗位相关的证写在显眼位置（+ 一句"可快速上手××工作"） |
| 技能 | 分层写（熟练/了解）；工具类写具体（Excel 透视表/SQL/Python/PS/Axure 等） |
| 校园经历 | 只留与岗位能力相关的（组织、统筹、数据、沟通），删掉无关头衔 |

## 四、笔试与面试准备（校招特有）

- **笔试**：行测类（逻辑、数字、语言）+ 专业题 + 性格测评；**提前 1~2 周刷题**（尤其行测与专业基础）；
- **AI/视频面试**：环境安静、看镜头、**结构化回答**（STAR），控制在 1~2 分钟/题；
- **群面**：抢"**归纳者/推进者**"角色，别抢话；记录时间与关键点，最后做总结；
- **专业面**：把简历里每一项都能解释到**数字与细节**（"为什么这么做"必问）；
- **HR 面**：动机、稳定性、地域与到岗时间、薪资预期（见 [谈薪](/qiuzhi/tanxin/)）。

## 五、应届生身份：什么时候用、什么时候别浪费

| 用途 | 说明 |
|------|------|
| **校招通道** | 多数企业的校招只面向应届生（含毕业当年），**这是最宝贵的窗口** |
| **考公/考编/国企** | 很多岗位限定"应届毕业生"，**身份有时效**（以招聘公告为准） |
| **落户与人才政策** | 部分城市对应届生有落户便利（以当地政策为准） |
| **三支一扶/选调等** | 多要求应届或近几届，需看当年度公告 |

> **建议**：如果目标是考公考编，**不要为了"先随便找份工作"而浪费应届身份**；如果目标是企业就业，**尽早拿到 offer** 再考虑其他。

## 六、签约与报到注意（三方协议等）

- **三方协议**是学校、学生、企业之间的就业约定，**条款（含违约金）以协议文本与学校规定为准**——签约前逐条看清；
- **档案与户口**：确认转递方式与接收单位（问学校就业办与企业 HR）；
- **毁约**：可能涉及违约金与学校流程，**做决定前先问就业办**；
- **入职材料**：毕业证学位证、报到证（按当地要求）、体检、身份证等，提前备好。

> ⚠️ 以上流程各地各校差异较大，**一律以你学校就业办与用人单位当次通知为准**。

## 七、应届生常见坑

| 坑 | 正确做法 |
|----|---------|
| 等"准备好"再投秋招 | 边投边准备，9 月必须投出去 |
| 只投大厂 | 大厂 + 中型公司 + 国企/事业单位并行，保证有 offer 兜底 |
| 简历投所有岗位 | 按岗位分 2~3 个版本，关键词对应 JD |
| 忽视暑期实习 | 暑期实习是转正与秋招的最大加分项 |
| 不看三方条款就签 | 违约金、岗位、薪资、地点逐条确认 |
| 浪费应届身份 | 先明确目标（企业就业 vs 考公考编），再决定签约节奏 |
