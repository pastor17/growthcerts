## 一卡背诵

**网络图**
- 关键路径＝**最长路径**＝总浮动最小 → 决定最短工期；
- 总浮动 `TF = LS − ES`（或 LF − EF）；
- 压缩**只压关键路径**活动；压一次**重算全图**（次长路径可能变新关键路径）。

**挣值（EVM）**
- `SV = EV − PV`（进度）、`CV = EV − AC`（成本）——**E 永远被减**；
- `SPI = EV/PV`、`CPI = EV/AC`——**E 永远作分子**，>1 为优；
- 典型偏差 `EAC = BAC ÷ CPI`（按当前效率干完全程）；非典型 `EAC = AC + BAC − EV`。

**其他**
- 沟通渠道：`N(N−1)/2`；EMV 期望值：`概率 × 影响`。

## 🧠 记忆工具箱

做计算题**先默写公式再代数字**（过程分）；考前把六个挣值字母 PV/EV/AC 的关系画一遍。

## 📚 深度精讲（重点精细版）

### 一、公式总表（考前默写一遍）

| 类别 | 公式 |
|------|------|
| 网络图 | TF＝LS−ES＝LF−EF；关键路径＝最长路径 |
| 挣值 | SV＝EV−PV；CV＝EV−AC；SPI＝EV/PV；CPI＝EV/AC |
| 预测 | 典型 EAC＝BAC/CPI；非典型 EAC＝AC＋(BAC−EV)；ETC＝EAC−AC；VAC＝BAC−EAC |
| 绩效 | TCPI＝(BAC−EV)/(BAC−AC) |
| 期望值 | EMV＝概率 × 影响 |
| 沟通 | 渠道＝N(N−1)/2 |
| 三点估算 | 期望历时＝(O＋4M＋P)/6；标准差≈(P−O)/6 |
| 压缩 | 成本-时间斜率＝(赶工成本−正常成本)/(正常时间−赶工时间)，优先压斜率最小者 |

### 二、计算规范（避免"会做却丢分"）

- **先写公式再代数字**，每步保留过程；结果**保留两位小数**并带单位；
- 判断类问题**先算指标、再下结论**（如"进度落后、成本超支"）；
- 机考环境下用草稿纸列算式，避免只靠心算。

### 三、典型例题（带解析）

**例题 1**：某活动乐观历时 10 天、最可能 16 天、悲观 28 天。用三点估算求期望历时。
A. 16 天　B. 17 天　C. 18 天　D. 20 天
**答案 B**。解析：(10＋4×16＋28)/6＝(10+64+28)/6＝102/6＝**17 天**；A 是"最可能"值，C、D 无计算依据。

**例题 2**：某项目 EV＝90、PV＝120、AC＝100（万元）。SPI 与 CPI 分别是？
A. 0.75 与 0.90　B. 0.90 与 0.75　C. 1.33 与 1.11　D. 0.75 与 1.11
**答案 A**。解析：SPI＝EV/PV＝90/120＝0.75；CPI＝EV/AC＝90/100＝0.90。（C 是把分子分母颠倒的结果。）

### 四、自测清单

写出并解释：SV、CV、SPI、CPI、EAC（典型/非典型）、ETC、VAC、TCPI、TF、EMV、渠道数。

## ⚠️ 易错提醒

- EV 用"实际完成 % × BAC"，PV 用"计划完成 % × BAC"——别混；
- 问 EAC 先判断题干是"典型"还是"非典型"。
