## 一卡背诵

- **CIA**：`锁（保密）· 戳（完整）· 门（可用）`；篡改动"完整"，泄露动"保密"。
- **加密 vs 签名**：加密＝**上锁防偷看**（保密，用接收方公钥）；签名＝**盖章防抵赖**（私钥签名、公钥验证，保来源与完整）。
- **对称/非对称**：对称一个钥、快怕分发；非对称公/私钥、慢但解决分发。
- **设备×层次**：`路选网络、交换链路、集线物理`（路由器 IP 选路/交换机 MAC 转发/集线器物理层）。
- **TCP/UDP**：TCP＝打电话（可靠慢）；UDP＝寄平信（快不可靠）——视频直播用 UDP，网页/文件/邮件用 TCP。
- **OSI 七层自下而上**：物、数、网、传、会、表、应。
- **私有地址**：`10 / 172.16~31 / 192.168`；IPv6＝128 位。
- **备份恢复难度**：全量最简、增量最麻烦（全量+一串增量）、差异＝全量+最后一次差异。

## 🧠 记忆工具箱

安全题先判断"动了哪一性/用了哪把钥"，网络题先对"设备在哪层"。

## 📚 深度精讲（重点精细版）

### 一、信息安全速查（一张表记全）

| 主题 | 要点 |
|------|------|
| CIA | 保密（不泄露）、完整（不被改）、可用（随时用） |
| 访问控制 | DAC 属主定 / MAC 系统定 / RBAC 角色定；最小权限 + 职责分离 |
| 对称加密 | 一把钥、快；密钥分发难（AES/DES） |
| 非对称加密 | 公钥加密、私钥解密；慢（RSA/ECC） |
| 数字签名 | 私钥签名、公钥验证 → 真实性 + 完整性 + 不可抵赖 |
| 数字信封 | 对称加密数据 + 非对称保护密钥（又快又安全） |
| 等保 | 定级看"危害客体与程度"，流程：定级→备案→整改→测评→检查 |
| 备份 | 全量 / 增量（基准＝上次任意备份）/ 差异（基准＝上次全量）；RTO、RPO |

### 二、网络速查

| 主题 | 要点 |
|------|------|
| OSI | 物数网传会表应（自下而上） |
| 设备 | 集线器=物理层、**交换机=链路层（MAC）**、路由器=网络层（IP）、网关=高层 |
| 协议 | HTTP 网页 / FTP 文件 / SMTP 邮件 / DNS 解析 |
| 传输 | TCP 面向连接可靠（网页、文件、邮件）；UDP 快不可靠（直播、语音、DNS 查询） |
| 地址 | 私网 10 / 172.16–31 / 192.168；IPv6＝128 位 |
| 子网 | /24 划分两个子网 → /25（255.255.255.128），每子网 126 个可用地址 |

### 三、典型例题（带解析）

**例题 1**：下列 IP 地址中属于私有地址的是？
A. 8.8.8.8　B. 172.20.1.1　C. 202.108.22.5　D. 223.5.5.5
**答案 B**。解析：私有段为 10./172.16–31./192.168.；172.20.1.1 落在 172.16–31 区间内，其余为公网地址。

**例题 2**：接收方若要验证"消息确实来自声称的发送方且未被篡改"，应使用？
A. 用发送方公钥验证其私钥签名　B. 用发送方私钥解密　C. 只比对哈希值　D. 用对称密钥解密
**答案 A**。解析：数字签名由发送方私钥生成、用其公钥验证；哈希值本身不带身份信息，对称密钥用于加密而非身份验证。

### 四、自测清单

说出：CIA 三性、三类访问控制、签名与信封的区别、等保五级、三种备份的恢复方式、设备与层对应、私网三段。

## ⚠️ 易错提醒

- 签名不保密、加密不防抵赖——两把钥匙用途别混；
- 防火墙不是万能，DDoS 破坏的是**可用性**。
