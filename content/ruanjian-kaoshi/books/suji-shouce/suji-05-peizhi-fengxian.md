## 一卡背诵

- **配置三库**：开发库＝草稿随便改；受控库＝评审后进、改要批；产品库＝发布只读。
- **基线**＝某时点被冻结的版本集合，改动必须走变更控制。
- **变更五步**：`提（CR）→ 析（影响）→ 批（CCB）→ 干（实施）→ 验（验证归档）`——先批后干。
- **风险应对**：威胁＝`躲（规避）甩（转移）降（减轻）认（接受）`；机会＝`开（开拓）提（提高）分（分享）接（接受）`。
- **定性 vs 定量**：定性＝概率×影响矩阵**排序**（快）；定量＝EMV/决策树**算总账**（慢）。
- **干系人方格**：都高→重点管；权高利低→哄满意；权低利高→常汇报；都低→看着办。
- **转移≠减轻**：转移甩给第三方（保险/外包）；减轻自己降概率/影响。

## 📚 深度精讲（重点精细版）

### 一、配置与变更速查

| 主题 | 要点 |
|------|------|
| 三库 | 开发库（随便改）/ 受控库（改要批）/ 产品库（只读） |
| 基线 | 功能基线（需求）/ 分配基线（设计）/ 产品基线（交付物） |
| 变更五步 | 提（CR）→ 析（影响）→ 批（CCB）→ 干（实施）→ 验（验证归档） |
| 影响评估 | 范围、进度、成本、质量、风险（五维度） |
| 配置审计 | 功能配置审计（对需求）/ 物理配置审计（对清单） |
| 版本号 | V 主版本.次版本.修订号：重大变更升主、功能增强升次、纠错升修订 |

### 二、风险与干系人速查

| 主题 | 要点 |
|------|------|
| 风险七过程 | 规划→识别→定性→定量→规划应对→实施应对→监督 |
| 威胁应对 | 规避（躲）、转移（甩）、减轻（降）、接受（认） |
| 机会应对 | 开拓（开）、提高（提）、分享（分）、接受（接） |
| 定性 vs 定量 | 矩阵排序（快）/ EMV、决策树、蒙特卡洛（准） |
| 干系人方格 | 双高重点管、高权低利哄满意、低权高利常汇报、双低看着办 |
| 参与度 | 不知晓→抵制→中立→支持→领导 |

### 三、典型例题（带解析）

**例题 1**：配置库中，存放已正式发布、供交付使用版本的库是？其权限特点为？
A. 开发库，可自由修改　B. 受控库，需审批　C. 产品库，只读　D. 备份库，不可访问
**答案 C**。解析：产品库（发布库）存放正式发布/交付版本，一般只读；受控库存放基线内容、修改需审批。

**例题 2**：项目组决定放弃原定技术路线，改用成熟方案以避免某项技术风险发生。该策略属于？
A. 规避　B. 转移　C. 减轻　D. 接受
**答案 A**。解析："改变计划使风险事件不发生"是规避；减轻是降低概率或影响，转移是转给第三方，接受是自留并备储备。

### 四、自测清单

自问：三库权限差异？变更五步？功能审计与物理审计区别？威胁与机会各四策略？干系人四种策略对应哪种权力-利益组合？

## ⚠️ 易错提醒

- 配置审计查"版本构成一致"，质量审计查"过程合规"——两类审计别混；
- CCB 只审**重大变更**，细枝末节项目经理可批（不是所有变更都开会）。
