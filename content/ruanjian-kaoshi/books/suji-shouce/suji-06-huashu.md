## 一卡背诵

- **找错三段式**：`摘现象 → 指问题（对应管理原则）→ 给纠正`——先引用情景，再判断，后给方案。
- **主观题分点**：① 术语先行（"未执行变更控制"），每点 1–2 行，宁可多列点。
- **计算题**：先写公式 → 代数字 → 保留过程（过程分 > 结果分）。
- **高频错误点（见一个勾一个）**：无章程开工 / 口头加需求不走变更 / 计划无基准 / 重要事项口头化 / 无风险预案 / 改了代码没改文档 / 一人多岗无制衡 / 验收才让客户看。
- **口头需求三连防**：`合同化（落纸面）→ 评估化（背调+影响分析）→ 预案化（有备选/储备）`。
- **答题顺序**：先扫全卷 → **计算题优先**（确定性得分）→ 主观题按分点密度分配字数。

### 二、十一领域"一句话"（见错就写）

- 整体：未编计划、无授权 → 应补章程与计划；
- 范围：需求乱加 → 走变更、建基线；
- 进度：无里程碑 → 分解到工作包、识别关键路径；
- 成本：不知偏差 → 建成本基准、做挣值分析；
- 质量：靠最后测试 → 加过程审计与阶段检查；
- 资源：靠个别人 → 交叉培训、备份人员；
- 沟通：靠口头 → 书面化并确认理解；
- 风险：无预案 → 识别登记、规划应对与储备；
- 采购：合同不清 → 明确变更与验收条款；
- 配置：版本混乱 → 三库+基线+配置审计；
- 干系人：验收才沟通 → 识别登记、制定参与策略。

### 三、典型例题（带解析）

**例题 1**：案例题要求"给出应对措施"。下列写法得分最高的是？
A. 写一段长文说明"要加强管理"　B. 分点写"①建立变更控制流程并设 CCB ②每周跟踪 SPI/CPI ③超出阈值即启动纠偏"　C. 只写"应引起重视"　D. 复述题干
**答案 B**。解析：措施题按点给分且要求可执行：分点 + 具体动作（流程、工具、阈值）才能拿分。

**例题 2**：案例中"核心开发人员离职导致项目停滞两周"，最应指出的管理缺失是？
A. 未做成本估算　B. 未进行资源规划与风险应对（关键岗位无备份）　C. 未编制质量计划　D. 未开展验收测试
**答案 B**。解析：关键人员流失属于可识别风险，暴露资源规划与风险管理的缺失（无交叉培训、无备份人员）。

### 四、自测清单

给自己出一道题：随便看一则项目小故事，30 秒内说出"有哪些问题、分别属哪个领域、应如何纠正"。

## ⚠️ 易错提醒

- 找错只下结论不给依据/纠正 → 几乎不得分；
- 不编造案例没写的行为去批判（只批题里出现的）。
