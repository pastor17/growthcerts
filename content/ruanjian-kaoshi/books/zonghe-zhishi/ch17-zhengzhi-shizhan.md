## 考点梳理

### 17.1 EVM 公式速查（**"5 指标 + 2 预测"**）

| 指标 | 公式 | 含义 |
|------|------|------|
| **PV**（计划价值） | 计划完成工作的预算 | 到此刻"应该干完的" |
| **EV**（挣值） | 实际完成工作的预算 | 到此刻"实际干完的（按预算价）" |
| **AC**（实际成本） | 实际完成工作的花费 | 到此刻"真花了多少" |
| **SV**（进度偏差） | **EV − PV** | >0 提前 / <0 滞后 |
| **CV**（成本偏差） | **EV − AC** | >0 节约 / <0 超支 |
| **SPI**（进度绩效指数） | **EV ÷ PV** | >1 快 / <1 慢 |
| **CPI**（成本绩效指数） | **EV ÷ AC** | >1 省 / <1 超 |

> **记忆锚**：**"S/C 都是 EV 减（SV=EV−PV，CV=EV−AC）；S/C 比都是 EV 除（SPI=EV÷PV，CPI=EV÷AC）；EV 永远在'分子/被减数'位置"**。

### 17.2 趋势预测（**"3 公式"**）

| 指标 | 公式 | 适用 |
|------|------|------|
| **BAC** | 完工预算（总预算） | 基准 |
| **EAC**（完工估算） | **① BAC ÷ CPI**（偏差会持续） | 最常见考法 |
|  | **② BAC + ETC**（剩余按原计划） | 偏差是孤立的 |
|  | **③ (BAC − EV) ÷ (CPI × SPI) + AC**（双偏差） | 同时考虑进度 |
| **ETC**（完工尚需） | **EAC − AC** | 还剩要花多少 |
| **VAC**（完工偏差） | **BAC − EAC** | >0 总节约 / <0 总超支 |
| **TCPI**（完工绩效指数） | **① (BAC − EV) ÷ (BAC − AC)**（按 BAC） | 剩余工作要达到的 CPI |
|  | **② (BAC − EV) ÷ (EAC − AC)**（按新 EAC） | 按新预算 |

> **铁律**：**"没特别说明 → EAC 用 BAC÷CPI（偏差持续假设）"**。

### 17.3 判断口诀（**"案例题 30 秒判断"**）

```text
看 SPI：>1 进度好，<1 进度差
看 CPI：>1 成本省，<1 成本超
看 VAC：>0 整体省，<0 整体超
四象限：
  SPI>1 & CPI>1 → 又省又快（最好）
  SPI<1 & CPI<1 → 又超又慢（最差）
  SPI>1 & CPI<1 → 快但超支
  SPI<1 & CPI>1 → 慢但省钱
```

## 📝 深度精讲（6 道带解析算例）

### 例 1（基础）
某项目 BAC=200 万。某月末 PV=80 万，EV=70 万，AC=90 万。求 SV、CV、SPI、CPI 并判断。

**解析**：
- SV = 70 − 80 = **−10 万**（进度滞后 10 万）
- CV = 70 − 90 = **−20 万**（超支 20 万）
- SPI = 70 ÷ 80 = **0.875**（<1，进度慢）
- CPI = 70 ÷ 90 = **0.78**（<1，成本超）
- **结论**：又超又慢（最差象限）。**建议**：重点纠偏，分析超支原因（是效率低还是价格高）。

### 例 2（EAC）
接例 1，若偏差会持续到完工，求 EAC、ETC、VAC。

**解析**：
- EAC = BAC ÷ CPI = 200 ÷ 0.778 ≈ **257 万**
- ETC = EAC − AC = 257 − 90 = **167 万**
- VAC = BAC − EAC = 200 − 257 = **−57 万**（预计总超支 57 万）

### 例 3（TCPI）
接例 1，若管理要求最终仍按 BAC=200 万完成，剩余工作需达到的 TCPI？

**解析**：
- TCPI = (BAC − EV) ÷ (BAC − AC) = (200 − 70) ÷ (200 − 90) = 130 ÷ 110 ≈ **1.18**
- **含义**：剩余工作成本效率要达到 1.18（即每花 1 元挣 1.18 元）才能压回 BAC。1.18 偏高，说明"压回原预算"难度大，**建议申请追加预算或压缩范围**。

### 例 4（判断陷阱）
某项目 SPI=1.2，CPI=0.9。项目经理说"项目一切正常"，对不对？

**解析**：**不对**。SPI=1.2（进度快）但 CPI=0.9（成本超支）。"进度好"不等于"项目好"——**成本超支会侵蚀利润**。正确判断：**进度提前但成本超支，需控制成本**（如优化资源、减少返工）。**易错**：只看 SPI 就下"正常"结论。

### 例 5（EAC 三式区分）
BAC=100，EV=40，AC=50，CPI=0.8。
- ① 偏差持续：EAC = 100 ÷ 0.8 = **125**
- ② 剩余按原预算效率：ETC = (BAC − EV) = 60，EAC = AC + ETC = 50 + 60 = **110**
- **区别**：①认为"未来还按现在的低效率 0.8 干"→ 超更多；②认为"超支是孤立的，未来恢复 1.0 效率"→ 超少。

### 例 6（案例话术）
案例题问"项目经理发现成本超支，应如何管理？"

**标准答题框架**：
1. **分析原因**（挣值计算定位：CPI<1，超支 20 万）；
2. **纠正措施**（优化资源/提高生产率/减少返工/变更范围）；
3. **预防措施**（加强成本监控频率/更新估算/设置预警阈值）；
4. **跟踪**（重新计算 EAC/TCPI，每周复核）。

## 🧠 记忆工具箱

### 口诀速记

- 公式：**"S 减 C 减都是 EV 减，S 比 C 比都是 EV 比"**；
- 四象限：**"又快又省最好，又超又慢最差，快超/慢省看取舍"**；
- EAC：**"没说明用 BAC 除 CPI"**；
- TCPI：**"压回原预算，剩活要拼 1.几"**。

### 场景锚点

- EVM 想象"**"装修进度对账"**"：你**不是工人**（**不干活**），**你是"包工头对账的"**——**"PV = 按合同这周该干完的活（值 80 万）；EV = 这周实际干完的活按合同价算（值 70 万，干少了）；AC = 这周真付的钱（90 万，花超了）"**——**"SV 告诉你'活干没干够'，CV 告诉你'钱花没花超'，两个都要看，只看一个会被工人忽悠"**。

## ⚠️ 易错提醒

- **EV 是"完成工作的预算价"**：**"不是实际成本 AC"**（**"EV 永远按基准单价算"**）；
- **EAC 默认用 BAC÷CPI**：**"除非题目说'偏差是孤立的'"**（**"案例题 80% 用这式"**）；
- **TCPI 别用错分母**：**"压回 BAC 用 (BAC−AC)，按新 EAC 用 (EAC−AC)"**；
- **只看一个指数下结论 = 错**：**"SPI 和 CPI 必须一起看"**。
