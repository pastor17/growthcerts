> **用法**：考前 3 天起只过这一页 + 错题笔记；**机考两科连考 240 分钟**的节奏必须提前演练。

## 一、计算题公式（唯一的"硬分"）

| 考点 | 公式 |
|------|------|
| 挣值基本量 | PV（计划值）、EV（挣值）、AC（实际成本） |
| 进度偏差 | **SV = EV − PV**（<0 落后） |
| 成本偏差 | **CV = EV − AC**（<0 超支） |
| 绩效指数 | **SPI = EV/PV**、**CPI = EV/AC**（<1 不利） |
| 完工估算 | **EAC = BAC / CPI**；ETC = EAC − AC；VAC = BAC − EAC |
| 三点估算 | 期望值 =（乐观 + 4×最可能 + 悲观）/ 6 |
| 沟通渠道 | **n(n−1)/2** |
| 关键路径 | 总持续时间**最长**的线路（工期 = 其长度） |
| 时差 | **TF ≥ FF ≥ 0**；判断工期影响只看**总时差** |

## 二、十大知识领域"关键输出"速查

| 领域 | 必记输出 |
|------|---------|
| 整合 | **项目章程**（授权）、**项目管理计划**、变更请求与变更日志 |
| 范围 | 范围管理计划、**需求文件**、**WBS 与 WBS 词典**、范围基准 |
| 进度 | 活动清单与属性、**里程碑清单**、网络图、**进度基准** |
| 成本 | 成本估算、**成本基准**、项目资金需求 |
| 质量 | 质量管理计划、**质量报告**、测试与评估文件 |
| 资源 | 资源管理计划、**团队章程**、资源分配单 |
| 沟通 | 沟通管理计划、**项目沟通记录** |
| 风险 | **风险登记册**、风险报告 |
| 采购 | 采购管理计划、**协议/合同**、工作绩效信息 |
| 相关方 | **相关方登记册**、相关方参与计划 |

## 三、易混对比（丢分重灾区）

| 易混组 | 判别要点 |
|--------|---------|
| 确认范围 vs 控制范围 | 前者**正式验收可交付成果**；后者**监督范围状态与管理变更** |
| 质量保证（管理质量）vs 质量控制 | 前者关注**过程**（审计、改进）；后者关注**成果**（检验、偏差） |
| 关键路径 vs 关键链 | 前者看**总持续时间最长**；后者还要考虑**资源约束与缓冲** |
| 应急储备 vs 管理储备 | 应急储备应对**已知-未知**（含在成本基准内）；管理储备应对**未知-未知**（不在基准内） |
| 风险应对策略 | 威胁：规避/转移/减轻/接受/上报；机会：开拓/分享/提高/接受/上报 |
| 三种合同 | 总价（**卖方**风险大）/ 成本补偿（**买方**风险大）/ 工料（范围不明时） |
| 赶工 vs 快速跟进 | 赶工=加资源（成本↑）；快速跟进=并行（返工风险↑） |

## 四、机考与作答规则

- **两科连考**：基础知识 + 应用技术，作答总时长 **240 分钟**；基础知识最长 **120 分钟**、最短 **90 分钟**；
- 合格标准：各科目满分 75 分，**相对固定 45 分**（60%，以官网通告为准）；
- **先做有把握的题**，控制单题耗时；机考可用系统计算器，但公式要熟。

## 五、案例题骨架（应用技术）

```
① 问题判断：指出存在什么问题（按知识领域分条）
② 原因分析：过程缺失、工具技术未用、管理不到位
③ 措施建议：对应过程与工具技术（如"加强变更控制""实施挣值分析"）
④ 计算：写公式与过程（EVM、工期）
```

**写不出就用这四句**：走流程（变更/风险/质量）、用工具（WBS/网络图/挣值/风险登记册）、明确责任、形成记录与闭环。

## 六、考场节奏（240 分钟）

| 阶段 | 时间 | 动作 |
|------|------|------|
| 基础知识 | 90~110 分钟 | 客观题 ≤1 分钟/题，先易后难，标记存疑题 |
| 应用技术 | 剩余 130~150 分钟 | 案例题按分值分配，**计算题先做**，写清公式与结论 |

> 考前 3 天只看：**本页 + 错题笔记 + 各章"易错提醒"**。
