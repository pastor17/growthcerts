## 一、本证该记什么（三类笔记）

### ① 结构笔记（一张图搞定一科）

中心写"**十大知识领域**"，一级分支写各领域，二级分支只写**过程名 + 输出物**（如"制定项目章程→项目章程"）。**不要抄定义**，软考综合知识考的是"哪个过程产生哪个文件"。

### ② 记忆笔记（本证高频易混，做成对比表）

| 易混组 | 判别要点 |
|--------|---------|
| 确认范围 vs 控制范围 | 前者**正式验收可交付成果**，后者**监督范围状态与管理变更** |
| 质量保证 vs 质量控制 | 前者关注**过程**（审计、改进），后者关注**成果**（检验、偏差） |
| 关键路径 vs 关键链 | 关键路径看**总持续时间最长**；关键链还要考虑**资源约束与缓冲** |
| 风险应对策略 | 威胁：规避/转移/减轻/接受/上报；机会：开拓/分享/提高/接受/上报 |
| 三种合同类型 | 总价（卖方风险大）/成本补偿（买方风险大）/工料（范围不明时） |
| SPI 与 CPI | SPI = EV/PV（进度）；CPI = EV/AC（成本）；**<1 均为不利** |

### ③ 计算笔记（软考真正的分水岭）

必须手算到"**连续 3 题全对**"的题型：

1. **挣值**：PV/EV/AC → SV、CV、SPI、CPI、EAC（= BAC/CPI）、ETC、VAC；
2. **网络图**：关键路径、总时差与自由时差（**TF ≥ FF**）、工期压缩；
3. **进度与成本估算**：类比/参数/自下而上、三点估算（**期望值 =（乐观+4×最可能+悲观）/6**）；
4. **沟通渠道数**：n(n−1)/2（团队人数变化时的计算）；
5. **决策树/期望货币值**：各分支收益×概率求和。

> 计算题笔记只记"**公式 + 一道自己算过的例题 + 常见取值陷阱**"，不要抄推导。

## 二、避坑清单（软考中项专属 8 条）

| # | 坑 | 正确做法 |
|---|----|---------|
| 1 | 按"背知识点"备考，忽视**计算题** | 计算题每天 2 道，动手算到熟练 |
| 2 | 用纸笔习惯应对**机考** | 考前用官网**机考模拟练习平台**练 1~2 次，熟悉标记与作答界面 |
| 3 | 不知道**两科连考**的时长规则 | 基础知识 + 应用技术**连考**，作答总时长 240 分钟；基础知识最长 120 分钟、最短 90 分钟——**先做有把握的题，控制单题耗时** |
| 4 | 忽略**合格标准相对固定**（45 分/满分 75） | 按"稳过 45"配分：客观题尽量拿满，案例题保证结构与关键术语 |
| 5 | 案例题只写结论不写过程 | 案例题按"**问题判断 → 依据（过程/工具）→ 措施**"三段写，多写要点 |
| 6 | 用往年批次时间安排复习 | 批次与考期以**官网通告与准考证**为准（上半年通常在 5 月下旬分批次） |
| 7 | 只做本证题目，不管理论体系 | 中项与高项、PMP 知识高度重叠，可交叉巩固（见 [高项](/ruankao-gaoxiang/)、[PMP](/pmp/)） |
| 8 | 考前才看"输入输出" | 输入输出是高频考点，**每周固定过一次十大领域表** |
