## 下载方式

```bash

# 方式二：网页点 Code → Download ZIP（大仓库下载较慢）
```

> 提示：上述仓库体积较大（数百 MB 至 1GB+），建议**按目录选择性下载**（如只取"02. 历年真题及解析"），避免整仓下载占用空间。
