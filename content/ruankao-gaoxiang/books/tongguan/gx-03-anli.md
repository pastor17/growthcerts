## 考点梳理

### 3.1 高项案例"难"在哪

- 情境更"高层"：常考**企业/多项目/战略背景**下的管理决策，而非单一活动；
- 问法更深：不只"指出问题"，还会问"如果你是 PM 该如何决策/排序/协调"；
- 但仍以**十大领域知识**作答——只是要多一个"全局观"层次（组织、干系人、战略对齐）。

### 3.2 答题打法（升级版三段式）

1. **找错题**：`摘现象 → 指原则（知识领域）→ 给纠正`，每点带术语；
2. **决策题**：`亮决策 → 给理由（对齐目标/风险/资源）→ 给落地步骤`；
3. **计算题**：`先公式 → 代数字 → 留过程 → 下结论`（网络图/挣值），高项案例里计算约占 1 题，务必拿满；
4. **多项目/组合情境**：先点"这事放在组合层还是项目层"，再按层作答（体现高级视角，示例经验）。

## 🧠 记忆工具箱

### 口诀速记

- 案例四类题：`找错、决策、计算、补对策`——计算先手，其余按分点密度配字数；
- 高项加分视角：`先战略对齐，再项目执行，后风险储备`。

## 📚 深度精讲（重点精细版）

### 一、案例题型分类与答题框架

| 题型 | 提问方式 | 答题框架 |
|------|---------|---------|
| 找错题 | "指出存在的问题" | 摘现象 → 指原则（知识领域）→ 给纠正，分点写 4–6 条 |
| 简答题 | "应如何做/为什么" | 先概念后措施，分点 + 术语 |
| 计算题 | 给数据求指标 | 公式 → 代入 → 过程 → 结论，**先做** |
| 判断题 | "是否正确并说明理由" | **先表态**（正确/错误）再给依据 |
| 补充完善题 | "补充××内容" | 按过程/要素清单补齐（如风险登记册要素、变更流程步骤） |

### 二、案例高频主题与"必答要点"

| 主题 | 必答要点（写进去就得分） |
|------|----------------------|
| 进度 | 关键路径、总浮动、压缩只能在关键路径、压后重算 |
| 成本 | EVM 指标、EAC 典型/非典型、成本超支原因与措施 |
| 范围 | WBS/100% 规则、变更控制、蔓延与镀金 |
| 质量 | QA（过程审计）与 QC（检验）分工、质量成本 |
| 风险 | 识别—分析—应对（躲甩降认）、储备、责任人 |
| 采购合同 | 合同类型选择理由、索赔程序、变更书面化 |
| 配置变更 | 三库、基线、变更五步、配置审计 |
| 干系人 | 识别、参与度矩阵、权力-利益策略 |

### 三、书写与时间规范

- **分点作答、术语先行**：每条 1–2 行，宁可多列；不写大段议论；
- 计算题保留过程（公式与中间结果都给分）；
- 时间：计算 15–20 分钟，其余主观题每题 20 分钟左右，最后留 5 分钟检查是否答全"问的角度"。

### 四、典型例题（带解析）

**例题 1**：案例给出检查点数据 PV=200、EV=160、AC=190（万元）。最先应计算并说明的是？
A. 直接写整改措施　B. 计算 SV/CV 与 SPI/CPI 并判断进度与成本状态　C. 只算 EAC　D. 只写风险应对
**答案 B**。解析：先算偏差与绩效指数定性（SV=−40、CV=−30、SPI=0.8、CPI≈0.84：进度落后 + 成本超支），再据结论给措施；跳步直接写措施会丢过程分。

**例题 2**：案例题问"项目经理的做法是否正确，并说明理由"。规范作答的第一步是？
A. 直接罗列整改措施　B. 先明确表态"不正确"，再分点给依据　C. 复述题干情景　D. 只写"要加强管理"
**答案 B**。解析：判断类题目必须先给判断结论，再用原则/术语支撑理由；只写措施或复述题面均不得分。

### 五、命题角度与背诵卡

- 命题角度：题型识别与框架、计算优先、找错条数、术语匹配、补充完善要素；
- 背诵卡：**找错三段式：摘现象—指原则—给纠正**；**计算四步：公式—代入—过程—结论**；**判断题先表态**；**分点 + 术语 = 得分密度**。

## ⚠️ 易错提醒

- 决策题不要只写"应该做变更管理"一句话——要写出**决策依据 + 步骤**；
- 计算题在高项卷同样给过程分，只写结果会丢分；
- 主观题术语优先（"未执行变更控制/未做风险定性分析"），白话长段失分。
