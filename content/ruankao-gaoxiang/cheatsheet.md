> **用法**：考前 3 天起只过这一页 + 错题笔记 + **自己的论文素材卡**。⚠️ 软考**需同一次考试内全部科目合格**，不滚动。

## 一、三科结构与时间

| 科目 | 题型 | 及格 |
|------|------|------|
| 综合知识 | 客观题 | 满分 75 → **45 分**（相对固定 60%） |
| 案例分析 | 主观题 | 同上 |
| **论文** | 主观题 | 同上；**机考不得提前交卷** |

**机考提示**：初、中级两科连考；高级三科分别作答；**论文靠打字**，结构与速度并重。

## 二、论文（决胜科目）

**摘要（约 300 字）**：项目背景 + **本人角色** + 主要方法 + 效果
**正文（约 2000~2500 字）**

| 部分 | 字数 | 要点 |
|------|------|------|
| 项目背景 | 约 300 | 规模、周期、技术栈、我的职责（**真实感**） |
| 过程展开 | 1200~1500 | 按主题对应过程逐节写，"做什么—怎么做—效果" |
| 困难与解决 | 约 300 | 1~2 个具体问题 + 具体措施 |
| 总结 | 约 200 | 成效 + 不足 + 改进方向 |

**素材卡（考前必备）**：2~3 个真实项目，每个写清"投资/规模、我的角色、技术特点、最大困难与解决、量化效果"——**同一项目要能套多个主题**。

## 三、案例分析：六领域"病因—处方"卡

| 领域 | 常见病因 | 处方 |
|------|---------|------|
| 范围 | 需求未确认、范围蔓延、WBS 不全 | 需求确认 + 变更控制 + WBS 到可估算 + 范围基准 |
| 进度 | 未识别关键路径、资源未平衡 | CPM + 资源平衡 + 赶工/快速跟进（说明风险） |
| 成本 | 无基准、超支无预警 | 成本基准 + 挣值分析 + EAC 预测 |
| 质量 | 只检验不预防 | 规划质量 + 管理质量（审计）+ 控制质量（检验） |
| 风险 | 只列清单不应对 | 识别—分析—应对—监控闭环 + 风险登记册 |
| 沟通/相关方 | 无沟通计划、相关方未识别 | 相关方登记册 + 沟通管理计划 + 参与度评估 |

**答题骨架**：问题 → 原因 → 措施（措施要落到**具体过程与工具技术**）。

## 四、综合知识：关键输出速查

| 领域 | 必记输出 |
|------|---------|
| 整合 | **项目章程**、项目管理计划、变更日志 |
| 范围 | 需求文件、**WBS 与词典**、范围基准 |
| 进度 | 活动清单、里程碑清单、网络图、**进度基准** |
| 成本 | 成本估算、**成本基准** |
| 质量 | 质量管理计划、质量报告 |
| 资源 | 资源管理计划、**团队章程** |
| 沟通 | 沟通管理计划、项目沟通记录 |
| 风险 | **风险登记册**、风险报告 |
| 采购 | 采购管理计划、**协议/合同** |
| 相关方 | **相关方登记册**、相关方参与计划 |

## 五、计算与易混

| 项目 | 公式/结论 |
|------|----------|
| 挣值 | **SV = EV − PV**（<0 落后）；**CV = EV − AC**（<0 超支）；**SPI = EV/PV**、**CPI = EV/AC**（<1 不利） |
| 完工估算 | **EAC = BAC / CPI**；ETC = EAC − AC；VAC = BAC − EAC |
| 三点估算 | （乐观 + 4×最可能 + 悲观）/ 6 |
| 沟通渠道 | **n(n−1)/2** |
| 时差 | **TF ≥ FF**；判断工期影响只看总时差 |
| 确认范围 vs 控制范围 | 前者**验收可交付成果**，后者**监督范围与变更** |
| 应急 vs 管理储备 | 应急应对**已知-未知**（含在成本基准内）；管理储备应对**未知-未知**（不含在基准内） |

## 六、时间分配（按当年度题量调整）

```
综合知识：客观题 ≤1 分钟/题，先易后难
案例分析：每题 15~20 分钟，先列要点再展开，计算题写公式与过程
论文：审题 5 分钟 → 列提纲 5 分钟 → 成文 60~70 分钟 → 检查 10 分钟（务必写完！）
```

> 考前 3 天只看：**本页 + 论文素材卡 + 自己的错题与"病因—处方"卡**。
