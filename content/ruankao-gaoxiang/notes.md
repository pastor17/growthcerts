## 一、本证该记什么（三科笔记分工）

### ① 综合知识：一张"领域—过程—输出"总表

中心写**十大知识领域**，每个领域下列**过程名与主要输出物**；再单独抽一页写**数字与规则类考点**（如沟通渠道数 n(n−1)/2、三点估算公式、合同类型风险归属、冲突处理五法优劣排序）。**不抄定义**，只写"哪个过程产生什么、哪个工具用于什么场景"。

### ② 案例分析：**按领域准备"病因—处方"卡**

案例题几乎都是"指出问题 + 分析原因 + 给出措施"。为每个知识领域准备一张卡：

| 领域 | 常见"病因" | 对应"处方" |
|------|-----------|-----------|
| 范围 | 需求未确认、范围蔓延、WBS 不全 | 需求确认与变更控制、WBS 分解到可估算、范围基准 |
| 进度 | 未识别关键路径、资源未平衡、压缩无依据 | CPM + 资源平衡、赶工与快速跟进的风险说明 |
| 成本 | 无基准、超支无预警 | 成本基准 + 挣值分析（CV/SV/SPI/CPI）+ EAC 预测 |
| 质量 | 只检验不预防、标准不明 | 质量规划 + 管理质量（审计）+ 控制质量（检验） |
| 风险 | 只列清单不应对 | 识别—分析—应对—监控闭环 + 风险登记册更新 |
| 沟通/相关方 | 无沟通计划、相关方未识别 | 相关方登记册 + 沟通管理计划 + 参与度评估 |

### ③ 论文：**素材包 + 固定骨架**（决定成败的一科）

**素材包（考前必须准备 2~3 个真实项目）**：每个项目写清"项目规模与投资、组织与我的角色、技术特点、遇到的最大困难与解决、可量化效果"。**同一个项目要能套用多个主题**（范围/进度/风险/质量…）。

**骨架（约 2000~2500 字）**：

| 部分 | 字数参考 | 要点 |
|------|---------|------|
| **摘要** | 约 300 字 | 项目背景 + 本人角色 + 主要方法 + 效果 |
| 项目背景 | 约 300 字 | 规模、周期、技术栈、我的职责（**真实感**） |
| 过程展开 | 约 1200~1500 字 | 按主题对应的过程逐节写，**每节"做什么—怎么做—效果"** |
| 困难与解决 | 约 300 字 | 1~2 个具体问题 + 具体措施 |
| 总结 | 约 200 字 | 成效 + 不足 + 改进方向 |

## 二、避坑清单（高项专属 9 条）

| # | 坑 | 正确做法 |
|---|----|---------|
| 1 | 把论文当"背范文" | 准备**自己的项目素材**，现场按主题重组；背范文容易被判雷同、且套不上题 |
| 2 | 论文写不出细节 | 提前把项目的**规模、技术、数据**记成卡片，考场上才能写得像真的 |
| 3 | 摘要写成项目介绍 | 摘要=项目背景 + **本人角色与工作** + 方法 + 效果，约 300 字 |
| 4 | 案例题只写结论 | 按"**问题 → 原因 → 措施**"三段写，措施要具体到过程与工具 |
| 5 | 三科分年考（以为能滚动） | 软考需**同一次考试内全部科目合格**（不滚动），必须一次过三科 |
| 6 | 不熟机考 | 用官网**模拟练习平台**熟悉作答界面与输入效率（论文打字速度也是分数） |
| 7 | 综合知识只刷题不建框架 | 先建立"领域—过程—输出"总表，再刷题补细节 |
| 8 | 忽略"绩效域/新考点" | 以**当年度大纲**为准，旧资料可能不含新考点 |
| 9 | 考前才开始想论文 | 论文至少提前 6~8 周准备素材并**手打**练习 3 篇以上 |
