## 考点梳理

### 1.1 社会政策是什么

**社会政策**是政府为满足社会成员基本需要、解决社会问题、促进社会公平而制定的**行动准则与制度安排**，其核心特征是**以政府为主体、以福利性资源分配为手段、以社会公平为目标**。

**社会政策的目标**
- 满足社会成员的基本需要（尤其是困难群体）；
- 解决与预防社会问题（贫困、失业、老龄化、家庭解体等）；
- 促进社会公平与社会整合；
- 促进经济社会发展与人的发展。

**社会政策的主要领域**：社会保障（社会保险、社会救助、社会福利）、医疗卫生、劳动就业、教育、住房、妇女儿童与老年人、残疾人、社区与基层治理、慈善与志愿服务等。

### 1.2 我国法规体系的层级与效力

| 层级 | 制定主体 | 形式 | 效力 |
|------|---------|------|------|
| 宪法 | 全国人民代表大会 | 宪法 | 最高 |
| **法律** | 全国人大及其常委会 | 《××法》 | 次于宪法 |
| **行政法规** | 国务院 | 《××条例》《××规定》 | 次于法律 |
| **部门规章** | 国务院各部委 | 《××办法》 | 低于法规 |
| **地方性法规** | 省级、设区的市人大及其常委会 | 《××省××条例》 | 本行政区域内 |
| **地方政府规章** | 省级、设区的市政府 | 《××省××办法》 | 低于地方性法规 |
| **规范性文件** | 各级行政机关 | 通知、意见、办法 | 用于具体执行 |

**冲突适用规则**：上位法优于下位法；同一机关制定的，**新法优于旧法、特别法优于一般法**。

### 1.3 与社会工作密切相关的核心法律法规（框架记忆）

| 领域 | 主要依据（示例） |
|------|----------------|
| 社会救助 | 《社会救助暂行办法》及配套文件 |
| 老年人 | 《老年人权益保障法》 |
| 未成年人 | 《未成年人保护法》《预防未成年人犯罪法》 |
| 妇女 | 《妇女权益保障法》 |
| 残疾人 | 《残疾人保障法》 |
| 劳动就业 | 《劳动法》《劳动合同法》《就业促进法》《劳动争议调解仲裁法》 |
| 社会保险 | 《社会保险法》及工伤、失业保险等配套规定 |
| 慈善与志愿服务 | 《慈善法》《志愿服务条例》 |
| 社区治理 | 《城市居民委员会组织法》《村民委员会组织法》及中央关于城乡社区治理的文件 |
| 社会工作人才 | 社会工作者职业水平评价与人才队伍建设相关文件 |

> 记忆提示：**"人群 + 劳动 + 社保 + 救助 + 慈善 + 社区"** 六大板块覆盖本科目绝大多数考点。

### 1.4 社会工作者在政策过程中的角色

- **政策执行者/传递者**：把政策落地为具体服务；
- **政策评估与反馈者**：通过服务发现政策执行中的问题（如"漏保""手续过繁"）并反馈；
- **政策倡导者**：为服务对象群体争取资源与制度改善；
- **服务提供者与资源链接者**：直接提供服务、链接政府与社会资源；
- **政策研究与建议者**：参与调研、提出可行建议。

**重要边界**：社工**不是行政执法主体**，也不承担救助审批、资格核定等法定职权；社工做的是**专业服务、评估协助与倡导**。

### 法规层级口诀

**"宪法 → 法律 → 行政法规 → 部门规章 / 地方性法规 → 地方政府规章"**，冲突时"**上位优先、新法优先、特别法优先**"。

### 社会政策目标四句

**"满足需要、解决问题、促进公平、促进发展"**。

### 社工在政策中的五个角色

**"执行、反馈、倡导、服务、研究"**——**不含"审批"与"执法"**。

### 六大领域速记

**"救助、人群、劳动、社保、慈善、社区"**。

## 🔍 深度精讲

### 深讲 1：为什么社会政策要"以政府为主体"

社会政策解决的是**市场无法有效提供**的问题：

- 贫困救助、大病医疗、残疾康复等服务**缺乏盈利空间**，市场不愿提供；
- 弱势群体**支付能力不足**，靠个人无法获得基本保障；
- 社会问题具有**外部性**（如失业、流浪、犯罪预防），单个企业或家庭无法承担。

因此需要政府通过**立法与财政**来组织资源分配，实现"底线公平"。但"政府为主体"不等于"政府包办"——现代政策强调**政府主导、社会参与、专业支撑**（这正是社会工作与慈善力量的制度空间）。

### 深讲 2：社工为什么要懂政策——一个真实场景

**场景**：社工在社区服务中发现，某低保申请家庭因不识字、材料准备不全，连续两次被退回申请。

- **只做服务的社工**：帮他填表、安慰他，但下次遇到同样情况问题依旧；
- **懂政策的社工**：核查其是否符合条件 → 协助补全材料并说明办理渠道 → **把"流程复杂、告知不清"的执行问题反馈**给街道与民政部门 → 建议在社区设"帮办代办"窗口与政策明白卡。

第二类做法体现了社会工作"**个案—政策**"的双向价值：既解决个体问题，又推动制度改进。这正是"政策倡导者"角色的实际含义，也是中级法规科目的能力要求。

### 深讲 3：怎么判断该用哪部法规

处理实务问题时，可用"**三步定位法**"：

1. **定主体**：涉及谁？（老年人 / 未成年人 / 妇女 / 残疾人 / 劳动者 / 困难家庭 / 退役军人）
2. **定性质**：是**救助**（没钱没房没医）、**权益保护**（被侵害、被歧视）、**劳动关系**（工资、解雇）、**社会保障**（养老、医疗、工伤），还是**社会参与**（志愿服务、社区治理）？
3. **定责任主体与程序**：哪一级政府或部门负责、需要什么材料与时限、有无强制报告或保护令等特别程序。

**案例答题模板**：依据××法（条例）关于××的规定 → 服务对象享有××权利 → 应由××部门负责×× → 社工可提供××服务（评估/协助/转介/报告）。

## ⚠️ 易错提醒

- 社会政策的**主体是政府**，社工与慈善组织是**参与者与执行者**，不是政策主体；
- 法规层级中**行政法规（条例）高于部门规章（办法）**，不要颠倒；
- 社工**没有审批权与执法权**，不能承诺"一定给你办成"；
- 政策倡导的前提是**先掌握政策原文与执行口径**，不是凭感觉呼吁；
- 政策数据（标准、比例、金额）**必须按当年度与当地文件核对**，切勿套用旧数据。
