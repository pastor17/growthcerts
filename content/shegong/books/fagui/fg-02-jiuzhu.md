## 考点梳理

### 2.1 社会救助的基本原则与制度体系

**基本原则**：**托底线、救急难、可持续**；与其他社会保障制度相衔接；社会救助水平与经济社会发展水平相适应；**公开、公平、公正、及时**。

**制度体系（"8+1"）**

| 救助类型 | 主要对象 |
|---------|---------|
| 最低生活保障 | 家庭人均收入低于当地低保标准且财产状况符合规定的家庭 |
| 特困人员救助供养 | 无劳动能力、无生活来源且无法定赡养抚养扶养义务人（或义务人无履行义务能力）的老年人、残疾人、未成年人 |
| 受灾人员救助 | 因自然灾害导致基本生活受影响的人员 |
| 医疗救助 | 符合条件的困难群众（含重病、慢病导致支出型困难者） |
| 教育救助 | 各教育阶段家庭经济困难学生 |
| 住房救助 | 住房困难的低保家庭、分散供养特困人员等 |
| 就业救助 | 有劳动能力的救助对象 |
| 临时救助 | 因突发事件、意外伤害、重大疾病等导致基本生活暂时严重困难的家庭或个人 |
| ＋社会力量参与 | 慈善组织、社会工作服务机构、志愿服务等 |

### 2.2 最低生活保障

- **核心条件**：家庭**人均收入**低于当地低保标准，且**家庭财产状况**符合当地规定；
- **共同生活的家庭成员**范围、收入与财产的核定办法由地方按国家规定确定；
- **动态管理**：定期核查，家庭状况变化时应及时调整或退出（"应保尽保、应退尽退"）；
- 对**低保边缘家庭**中的重病、重残人员等，可按"**单人保**"（单独提出申请）等规定纳入（以现行国家与地方规定为准）。

### 2.3 特困人员救助供养

- **三项条件同时具备**：无劳动能力、无生活来源、无法定赡养抚养扶养义务人或其义务人无履行义务能力；
- **供养内容**：提供基本生活条件、照料服务、疾病治疗、办理丧葬事宜等；
- **供养形式**：**分散供养**（在家，由亲属或社区照料）与**集中供养**（供养服务机构），应**尊重本人意愿**；
- 与低保**不重复享受**（符合特困条件者纳入救助供养）。

### 2.4 临时救助

- **两类情形**：**急难型**（突发意外、灾害等需立即救助）与**支出型**（因大病、教育等刚性支出导致基本生活困难）；
- **特点**：**程序相对简化、办理要快**，可先行救助后补办手续（急难情形）；
- **方式**：发放临时救助金、实物救助、转介其他救助。

### 2.5 专项救助要点

- **医疗救助**：资助参保、门诊与住院救助、大病救助（与基本医保、大病保险衔接）；
- **教育救助**：学前教育资助、义务教育阶段资助、助学金与助学贷款等；
- **住房救助**：配租公租房、发放租赁补贴、农村危房改造等；
- **就业救助**：免费就业服务、技能培训、公益性岗位安置等，并**鼓励自救自立**（无正当理由拒绝接受就业服务的，按规定处理）。

### 2.6 申请审核程序（通用链条）

**申请（本人或代办）→ 受理与家庭经济状况核查（信息核对 + 入户调查 + 邻里访问 + 信函索证）→ 审核 → 公示 → 审批 → 发放 → 动态管理**

**社会工作者的角色**：政策宣讲、需求评估、**协助申请与材料准备**（不是审批）、能力建设与就业支持、心理支持、资源链接与转介、对不合理的执行问题**反馈与倡导**。

## 🧠 记忆工具箱

### 救助体系"8+1"口诀

**"低（低保）、特（特困）、灾（受灾）、医、教、住、就（就业）、临（临时）＋社会力量"**。

### 特困三条件口诀

**"无劳动能力、无生活来源、无人赡养抚养扶养（或义务人无能力）"**——**三条同时具备**。

### 临时救助两类

**"急难型（马上救）、支出型（因大病教育等刚性支出）"**。

### 程序链条

**"申请 → 核查 → 审核 → 公示 → 审批 → 发放 → 动态管理"**。

### 社工在救助中的"四个不是"

**"不是审批人、不是执法者、不是承诺者、不是替代签字者"**。

## 🔍 深度精讲

### 深讲 1："应保尽保"与"应退尽退"为什么同样重要

社会救助的资金来自公共财政，具有**有限性与排他性**：错保意味着真正困难的家庭得不到资源。

- **应保尽保**：防止"漏保"，重点解决**不会申请、不敢申请、行动不便**群体的可及性问题——这正是社工的价值（入户发现、协助申请、政策宣讲）；
- **应退尽退**：防止"错保"与**福利依赖**，通过动态核查实现公平；同时要避免"一刀切清退"造成新的困难（如家庭刚就业、收入尚不稳定即被立刻退出）。

**专业做法**：在退出前后提供**过渡性支持**（就业稳定期帮扶、技能提升、心理调适），把"退出救助"变成"实现自立"的过程，而不是把家庭重新推回困境。

### 深讲 2：特困人员救助供养为什么强调"尊重本人意愿"

特困人员中相当比例是**老年人、重度残疾人**，他们往往具备表达意愿的能力，但容易被"替其决定"：

- 有的地方倾向"一律集中供养"，方便管理，但老人可能因离开熟悉环境而出现适应障碍、抑郁甚至加速衰退；
- 专业做法是**评估其自理能力与照护需求 + 充分告知两种供养形式的条件与差异 + 由其自主选择**，并建立**定期回访与调整机制**（意愿可变更）。

这与社工的**自决原则**、"人在情境中"视角完全一致，也是本科目与社会工作实务的交叉考点。

### 深讲 3：救助"漏保"的三种典型原因与社工介入

| 原因 | 表现 | 社工介入 |
|------|------|---------|
| **信息不对称** | 不知道政策、以为"要关系"、担心被贴标签 | 政策宣讲、明白卡、社区公示、入户告知 |
| **能力障碍** | 不识字、不会用手机、行动不便、材料复杂 | 帮办代办、协助准备材料、联系上门服务 |
| **执行偏差** | 告知不清、反复退回、口径不一 | 记录个案、向街道与民政反馈、建议流程优化（政策倡导） |

> 答题提示：案例题中"社工最恰当的做法"通常是"**先评估需求与资格条件 → 协助申请 → 必要时链接其他救助 → 反馈制度性问题**"，而不是"直接承诺办成"或"只做安慰"。

### 例题（带解析）

**例题 1**：下列关于特困人员救助供养的说法，正确的是？
A. 只要家庭收入低于低保标准即可纳入特困人员救助供养
B. 需同时具备无劳动能力、无生活来源、无法定赡养抚养扶养义务人或其义务人无履行义务能力三个条件
C. 特困人员一律实行集中供养，本人无权选择
D. 特困人员救助供养可与其本人低保同时重复享受
**答案 B**。解析：特困人员救助供养需同时满足三项条件；供养形式分分散供养与集中供养，应尊重本人意愿；符合特困条件的按规定纳入救助供养，不与低保重复享受。

**例题 2**：某家庭因成员突发重大疾病，医疗支出巨大导致基本生活严重困难，最适宜的救助类型是？
A. 最低生活保障　B. 临时救助　C. 特困人员救助供养　D. 教育救助
**答案 B**。解析：因重大疾病等刚性支出导致基本生活暂时严重困难，属于临时救助（支出型）范围，可与医疗救助等专项救助衔接；低保针对收入长期低于标准的家庭，特困针对"三无条件"人员。

**例题 3**：社会工作者在社会救助服务中的正确做法是？
A. 核定申请人的家庭收入并决定是否给予低保
B. 开展需求评估、协助申请、能力建设与资源链接，并反馈执行中的制度性问题
C. 向服务对象承诺"一定能办成低保"
D. 代替服务对象在申请材料上签字确认
**答案 B**。解析：救助资格与标准由民政等部门依法核定，社工承担评估、协助、支持、链接与倡导等专业职能，不得越权审批、承诺或代替申请主体签字。

## ⚠️ 易错提醒

- 特困救助供养的三条件是"**同时具备**"，且与低保**不重复享受**；
- **临时救助 ≠ 低保**：临时救助针对突发或支出型困难，低保针对长期收入偏低；
- 集中/分散供养**须尊重本人意愿**，不能"一律集中"；
- 社工**无审批权**，也不能承诺"肯定批下来"、不能代签；
- 动态管理的目标是"应保尽保 + 应退尽退"，退出时应有**过渡性支持**；
- 各类救助的**具体标准、财产认定口径由地方规定**，必须按当地当年度文件核对。
