## 考点梳理

### 1.1 接案：中级要求"更专业的开场"

| 任务 | 中级加分点 |
|------|-----------|
| 建立专业关系 | 说明**保密原则及例外**、**服务边界**、**双方权利义务**；用同理与非评判建立信任 |
| 澄清期待 | 处理"非现实期待"（如要求社工搞定一切、要求社工代替其做决定） |
| 初步评估 | 快速判断**安全风险与紧急程度**，必要时启动危机介入（不等完整评估） |
| 决定接案/转介 | 超出服务范围或专业能力时**及时转介**，并做好转介衔接（不"一推了之"） |
| 服务协议 | 明确目标、频次、场地、双方责任与终止条件 |

**非自愿服务对象**（如矫正对象、被强制报告的家长、被要求参加服务的青少年）的接案要点：**承认其被动处境、解释服务的实际利益、给予选择空间、循序渐进建立信任**。

### 1.2 预估：中级要求"带理论框架的评估"

**资料收集维度**：个人（生理/心理/行为/认知）、环境（家庭/朋辈/社区/制度）、互动（人与环境的匹配程度）、**时间维度**（问题的发生与发展过程）。

**中级加分动作**：

1. **用理论组织资料**（而不是罗列信息）：用系统理论看子系统与边界、用优势视角看资源与潜能、用生态视角看多层环境；
2. **区分需要与诉求**：服务对象说出的诉求未必是其真实需要（如青少年说"我想退学"，真实需要可能是摆脱校园欺凌）；
3. **评估风险与保护因素**：自杀/自伤风险、暴力风险、监护能力、社会支持网络；
4. **与服务对象共同确认**：形成**预估结论**并请其确认，避免单方定性。

### 1.3 计划：目标必须"可测量"

- **总体目标**：方向性、长期性（如"提升家庭功能"）；
- **具体目标**：可操作、可测量、有时限（如"三个月内亲子冲突频次由每周 5 次降至 2 次以下"）；
- **介入策略**：对应目标逐条设计（目标—策略一一对应是评分关键）；
- **服务协议**：写明双方责任、时间安排与评估方式；
- **注意**：目标应由**服务对象参与确定**，社工包办设定会被扣分。

### 1.4 介入：直接 + 间接双线并行

| 类型 | 具体手段 |
|------|---------|
| **直接介入** | 个别会谈、家庭会谈、小组工作、危机干预、认知与情绪辅导、技能训练 |
| **间接介入** | 资源链接（救助、医疗、教育、就业）、环境改善（学校协调、社区支持）、政策倡导、志愿者与社区组织动员 |
| **综合介入** | 个人与环境同时介入（中级答案几乎都要写这一层） |

**中级加分点**：写明**介入顺序**（先安全→再情绪→再关系→再能力）与**责任分工**（社工做什么、服务对象做什么、其他机构做什么）。

### 1.5 评估：方法与指标要写出来

- **过程评估**：服务开展情况（次数、出席率、服务对象反馈）、社工技巧运用；
- **结果评估**：**基线测量**（介入前后对比）、**目标达成程度**、标准化量表、服务对象自评与他评；
- **评估设计**：单一个案设计（AB 设计：基线期 A—介入期 B 对比）；
- **注意**：评估要**可核查**（数据、记录、第三方反馈），不能只写"效果良好"。

### 1.6 结案与跟进

- 结案前**提前告知**、逐步减少接触频率；
- **处理离别情绪**（否认、倒退、愤怒、依赖）；
- **巩固改变**：回顾成功经验、制定复发应对计划、强化支持网络；
- **跟进**：安排回访或转介至社区/自助小组，避免"结案即断线"。

## 🧠 记忆工具箱

### 六阶段 + 中级关键词

| 阶段 | 中级关键词 |
|------|-----------|
| 接案 | **专业关系、保密及例外、非自愿对象** |
| 预估 | **理论框架、风险与保护因素、需要 vs 诉求** |
| 计划 | **可测量目标、目标—策略一一对应** |
| 介入 | **直接 + 间接 + 顺序与分工** |
| 评估 | **基线测量、目标达成度、可核查** |
| 结案 | **提前告知、处理情绪、复发应对、跟进** |

### 计划三件套

**"总体目标（方向）+ 具体目标（可测）+ 行动方案（谁做什么、何时做）"**。

### 评估两把尺

**"过程尺（怎么做的）+ 结果尺（有没有变好）"**，工具用**基线测量**。

### 介入顺序口诀

**"先安全 → 再情绪 → 再关系 → 后能力"**。

## 🔍 深度精讲

### 深讲 1：非自愿服务对象的接案怎么写

**案例**：一位因打骂孩子被强制接受家庭教育指导的父亲，第一次会谈时表示"我没错，是孩子不听话，你们别管我家事"。

**低分答法**：「指出其教育方式错误，要求其配合。」（评价指责、无从建立关系）

**高分答法**：
1. **承认处境**：理解其"被要求来"的感受，说明服务是**依法开展**，同时说明服务能带来的实际帮助（改善亲子关系、减少冲突对家庭的影响）；
2. **不辩论对错**：先不谈"是否打骂有错"，而**从其关心的目标切入**（"你希望孩子听话，我们一起看有没有更有效的方法"）；
3. **给予选择**：在**服务方式、时间、频次**上给予一定选择空间，增强其掌控感；
4. **明确边界与责任**：说明强制报告义务与服务记录要求；
5. **循序渐进的议题顺序**：先建立信任 → 谈具体冲突事件 → 再引入理念性内容（如儿童身心发展、非暴力沟通）。

### 深讲 2：怎么把"理论"写进答案（中级拉分点）

**示例**：一名初中生因遭校园欺凌而拒绝上学。

| 理论/视角 | 写在答案里的方式 |
|-----------|----------------|
| **系统理论** | 把家庭、班级、学校视为相互影响的子系统：欺凌发生在班级系统，家庭的情绪反应加剧了退缩行为，需同步干预班级规范与家庭沟通 |
| **人在情境中** | 拒绝上学不是单纯的"厌学"，而是对不安全环境的行为适应，评估需包含校园环境与人际互动 |
| **优势视角** | 该生仍有 2 位信任的同学、绘画特长突出，可作为建立支持与自我肯定的支点 |
| **增能** | 支持其学习表达拒绝与求助的技巧，参与制定"安全应对方案"，而不是被家长全程安排 |
| **社会支持网络** | 盘点多重支持（同伴、班主任、亲属、社区青少年中心），补足薄弱环节 |
| **危机干预** | 若出现自伤念头或严重恐惧反应，应先做风险处置与安全承诺 |

> 关键：**理论后面必须紧跟"用在该案例的哪一点"**，只写"运用系统理论"不给分。

### 深讲 3：目标写得"可测"才有分

| 不可测目标（低分） | 可测目标（高分） |
|------------------|----------------|
| 改善亲子关系 | 8 周内，通过每周 1 次家庭会谈，使亲子冲突（以家长-孩子周记录表计）由每周 5 次降至 2 次以内；家长掌握 3 种非暴力沟通表达方式并能举例说明 |
| 提升自信心 | 3 个月内参加 2 次小组活动并主动发言 ≥3 次；自我评价量表得分提升 20% 以上 |
| 帮助其就业 | 2 个月内完成简历 1 份、参加模拟面试 3 次、通过社区就业平台投递 10 个岗位并完成 2 次面试 |

**写法公式**：**时间 + 行为 + 数量/标准 + 验证方式**。

## ⚠️ 易错提醒

- 目标**不可测**是中级最普遍的失分点（"改善""提升""加强"必须配上数字与验证方式）；
- 预估阶段要写**风险与保护因素**，只写问题会丢分；
- 接案要写**保密原则及例外**，非自愿对象要写**关系建立策略**；
- 介入必须**直接 + 间接双线**，只写个人辅导不完整；
- 评估要写**方法与工具**（基线测量、目标达成度），不能只写结论；
- 结案要**提前告知 + 处理情绪 + 复发应对 + 跟进**，四件缺一即不完整。
