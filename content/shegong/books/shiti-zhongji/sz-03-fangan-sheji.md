## 考点梳理

### 3.1 方案设计的八要素框架（必背）

| 要素 | 写法要求 |
|------|---------|
| **① 背景与问题陈述** | 说明服务对象群体、需求评估依据（数据/走访/访谈结果）、问题的严重性与紧迫性 |
| **② 目标** | **总目标**（方向）+ **具体目标**（可测量：时间 + 行为 + 数量 + 验证方式） |
| **③ 服务对象** | 明确范围与人数、招募方式（谁推荐、如何筛选） |
| **④ 服务策略** | 采用的方法（个案/小组/社区/资源链接）与理论依据，说明"为什么用这个方法" |
| **⑤ 实施步骤** | 分阶段（准备期—实施期—巩固期—结束期），每阶段写清**内容、时间、负责人** |
| **⑥ 资源配置** | 人力（社工、志愿者、督导）、场地、经费来源、合作单位 |
| **⑦ 评估方法** | 过程评估（出席率、参与度、活动记录）+ 结果评估（基线测量、量表、目标达成度） |
| **⑧ 风险与应对** | 服务对象流失、伦理风险（保密、安全）、资源不足、突发事件的应对预案 |

> 记忆锚：**"背景、目标、对象、策略、步骤、资源、评估、风险"**——八项齐全即结构完整。

### 3.2 小组工作方案的标准结构

1. **小组名称与性质**（如"支持性成长小组"）；
2. **背景与需求**（为什么做这个小组，需求来源）；
3. **目标**（总目标 + 3 条以内具体目标）；
4. **组员**（人数 8–12 人、招募与筛选标准、是否同质）；
5. **时间与场地**（次数、每次时长、频率，一般 6–8 次）；
6. **理论基础与模式**（互动模式 / 发展模式 / 支持小组等）；
7. **每节活动安排**（节次—主题—目标—活动内容—社工角色）；
8. **评估**（过程 + 结果，含前后测量表）；
9. **风险与应对**（组员流失、冲突、保密、情绪危机处理）。

### 3.3 社区活动/社区工作方案的标准结构

1. **背景与需求**（社区调研数据、居民反映）；
2. **目标与指标**（参与人数、覆盖率、满意度、行为改变）；
3. **服务对象与范围**；
4. **活动内容与形式**（宣传发动、主题活动、议事协商、志愿服务）；
5. **实施时间表与责任分工**（含与居（村）委会、辖区单位、志愿者团队的分工）；
6. **资源与经费**（政府购买服务经费、社区资源、社会捐赠）；
7. **评估与可持续性**（居民满意度、社区组织是否留下、能否自主运转）；
8. **风险与应对**（天气、安全、参与不足、舆情）。

### 3.4 各领域方案设计的"专用抓手"

| 领域 | 专用抓手（写进方案能加分） |
|------|--------------------------|
| 儿童与家庭 | 家庭监护能力评估、亲子沟通训练、**强制报告**、学校—家庭—社区联动 |
| 老年 | 居家适老化改造、日间照料、**喘息服务**、认知障碍友好社区、防跌倒与防诈骗 |
| 医务与健康 | 患者与家属心理支持、慢病自我管理小组、医患沟通协助、临终关怀与哀伤辅导 |
| 社区治理 | 居民议事协商、社区社会组织培育、志愿者管理、**社区资源地图** |
| 矫正与社会融入 | 监督管理配合、就业支持、去标签化、同伴支持小组、家庭关系修复 |
| 救助与就业 | 需求评估与分层服务、就业技能培训、公益性岗位对接、**退出救助的过渡支持** |

## 🧠 记忆工具箱

### 八要素口诀

**"背景、目标、对象、策略、步骤、资源、评估、风险"**（背题时逐个自问"写了没有"）。

### 小组方案九件套

**"名称、背景、目标、组员、时空、理论、每节安排、评估、风险"**。

### 目标写法公式

**"时间 + 行为 + 数量/标准 + 验证方式"**。

### 可持续性三问

**"人留下了吗（社区骨干/组织）？机制留下了吗（制度/流程）？资源留下了吗（经费/场地）？"**

### 风险评估四类

**"流失、安全、伦理（保密）、资源不足"**。

## 🔍 深度精讲

### 深讲 1：从"需求"到"目标"的推导链

方案设计最容易被扣分的地方是**目标与需求脱节**。正确推导链如下：

**需求评估（数据）→ 需求归纳（哪一类问题最突出）→ 总目标（回应需求的方向）→ 具体目标（可测量的改变）→ 活动设计（为实现目标而设）→ 评估指标（检验目标是否达成）**

**示例（社区老年人跌倒预防）**：
- 需求数据：走访 120 位老人，其中 38% 近一年有跌倒经历，65% 家中浴室无扶手；
- 总目标：降低社区老年人跌倒风险，提升居家安全水平；
- 具体目标：① 3 个月内为 50 户家庭完成适老化评估并提出改造建议；② 开展 4 次防跌倒教育小组，参加者防跌倒知识知晓率由 40% 提升至 80%；③ 建立 1 支 10 人的邻里守望志愿队；
- 活动：入户评估与改造建议、教育小组、志愿队培训与结对；
- 评估：改造完成户数、知识问卷前后测、志愿队结对覆盖人数与半年内跌倒发生次数变化。

> 注意整条链的**数字一致性**：需求数据 → 目标数字 → 活动规模 → 评估指标，四处要能对上。

### 深讲 2：方案里必须体现的"专业细节"

| 细节 | 为什么是加分点 |
|------|---------------|
| **招募与筛选标准** | 体现小组同质性与目标匹配（如"失独父母"与"一般丧亲者"不宜混组） |
| **知情同意** | 小组开始前说明目标、形式、保密原则及例外、可随时退出 |
| **保密规范** | 明确"组内分享、组外不谈" |
| **个别跟进机制** | 对情绪危机、退出倾向者单独会谈与转介 |
| **督导与社工支持** | 涉及创伤议题时社工需督导支持，防止替代性创伤 |
| **结案与跟进** | 结案仪式、后续自助小组或社区活动衔接 |

### 深讲 3：可持续性怎么写得"不像口号"

低分写法："项目结束后由社区自行维持。"
高分写法（三留下）：

1. **人留下**：在项目期内培育 **10 名居民骨干**并完成 2 次带教，使其能独立组织月度活动；
2. **机制留下**：与居（村）委会共同形成《××活动组织流程》与《志愿者管理办法》，纳入社区常规工作；
3. **资源留下**：争取社区活动室固定使用时段、对接辖区单位年度支持、申请纳入下一年度街道民生项目。

## ⚠️ 易错提醒

- 方案**缺"风险评估"与"评估方法"**是最常见的结构性失分；
- 目标写成"提升意识""增强能力"而无**测量标准**，直接扣分；
- 活动内容与目标不对应（目标防跌倒，活动却是手工课）属逻辑错误；
- 忘记写**招募与筛选标准**、**知情同意**、**保密原则**，专业度不足；
- 只写活动、不写**资源与分工**，可操作性评价低；
- 可持续性必须落到"人/机制/资源"三项，空喊"长期坚持"不给分。
