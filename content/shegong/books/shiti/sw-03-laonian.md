## 考点梳理

### 3.1 老年期的主要变化与需求

| 维度 | 变化 |
|------|------|
| 生理 | 感官与体力衰退、慢性病增多、行动不便、跌倒风险高 |
| 心理 | 认知能力部分下降、失落与孤独感、对死亡的思考增多 |
| 社会 | 退休后角色丧失、收入下降、社会关系收缩、丧偶风险 |

**老年需求**：健康维护、经济保障、情感与陪伴、社会参与、尊重与自我价值、安全与照护。

### 3.2 老年学相关理论（了解关键词）

| 理论 | 核心观点 |
|------|---------|
| **活动理论** | 老年人应保持适度社会参与，参与越多、生活满意度越高（社工最常采用） |
| **撤离理论** | 老年人自然减少社会参与，社会也减少对其要求（有争议） |
| **连续性理论** | 老年期的适应取决于其一生形成的性格与生活方式是否延续 |
| **社会交换理论** | 老年人因资源（权力、收入、健康）减少导致地位下降 |
| **生命历程视角** | 个体的老年处境是其一生经历与社会环境的累积结果 |

### 3.3 老年社会工作的主要内容

- **生活照料与居家支持**：助餐、助洁、助浴、居家适老化改造；
- **健康与医疗协助**：慢病管理、用药安全、就医陪同、康复训练；
- **精神慰藉与心理支持**：孤独排解、丧偶哀伤辅导、生命意义探索；
- **社会参与**：老年小组、志愿服务、兴趣团体、社区议事；
- **权益保护**：防范诈骗、识别与干预老年虐待、协助法律维权；
- **照护者支持**：为家庭照护者提供知识培训与**喘息服务**。

### 3.4 老年社会工作的主要方法

| 方法 | 要点 |
|------|------|
| **个案工作** | 建立信任、放慢节奏、**生命回顾/缅怀往事**、尊重其生活节律与自主决定 |
| **小组工作** | **现实辨识小组**（帮助认知障碍者保持现实感）、**动机激发小组**（对抗退缩）、**支持性小组**（丧偶、慢病互助） |
| **社区工作** | 居家养老服务网络、社区日间照料中心、老年友好社区建设、邻里互助 |
| **间接服务** | 政策倡导（养老补贴、适老化改造政策）、资源整合 |

### 3.5 老年虐待的识别与处置

**类型**：身体虐待、精神/情感虐待、经济剥削（侵占财产、强迫转账）、忽视（不提供基本照料）、性虐待、自我忽视。

**识别信号**：不明原因的伤痕、营养不良或卫生状况差、异常恐惧或沉默、财产异常变动、照护者态度冷漠或推诿、老人反复"意外"受伤。

**处置原则**：
1. **安全第一**——评估紧急程度，必要时立即隔离危险源并送医；
2. **依法报告**——按法律规定履行报告义务，联系公安、民政、社区等；
3. **尊重意愿与能力评估**——有决策能力的老人有自决权，但涉及严重人身危险时应有限介入；
4. **综合干预**——法律援助、监护支持、照护替代安排、家庭辅导；
5. **持续跟进**——防止反复发生。

### 3.6 临终关怀与丧亲辅导

- **临终关怀**：以**减轻痛苦、维护尊严、提升生命最后阶段质量**为目标，内容包括疼痛与症状控制（配合医疗团队）、心理与灵性支持、家属陪伴支持、后事协助；
- **丧亲辅导**：允许并正常化哀伤反应、陪伴倾听、协助处理实务事务、识别复杂性哀伤并转介、在适当时机提供支持小组。

## 🧠 记忆工具箱

### 老年需求口诀

**"健、钱、情、参、尊、安"**——健康、经济、情感、参与、尊重、安全。

### 老年小组三种

**"现实辨识（防脱离现实）、动机激发（防退缩）、支持互助（抗孤独）"**。

### 老年虐待五类型

**"身、心、钱、忽、性"**（身体、精神、经济剥削、忽视、性虐待）＋**自我忽视**。

### 处置五步

**"保安全 → 依法报告 → 评估意愿与能力 → 综合干预 → 持续跟进"**。

### 生命回顾一句话

**"让老人讲一生的故事，从遗憾里找到意义"**——这是老年个案工作最常用的技巧。

## 🔍 深度精讲

### 深讲 1：为什么老年个案工作要"慢下来"

老年服务对象的沟通与节奏有特殊性，社工若按年轻人节奏推进，会出现"问三句答一句""反复讲同一件事""不愿谈某些话题"等情况，若社工急于推进，就会被老人感知为"敷衍、不耐烦"，专业关系随即破裂。

**专业做法**：
- **放慢节奏、留出沉默空间**，允许老人按自己的顺序讲述；
- **一次只处理一个核心议题**，不要在一次会谈中塞入多个问题；
- **使用生命回顾技巧**：从老照片、旧物件、家乡话题切入，让老人在叙述中重建自我价值；
- **注意感官与身体条件**：说话清晰、适当提高音量、选择安静场所、注意座椅舒适与如厕方便；
- **尊重其自决**：对住养老院、财产处置、治疗选择等，提供信息与选项，由其决定，并做好风险告知与记录。

### 深讲 2：老年虐待案例的标准处置链

**背景**：社工家访发现 78 岁独居老人手臂有多处新旧不一的淤青，其同住儿子近期频繁向老人索要存款，老人说话时反复看向儿子、声音很小。

**处置链条**：
1. **安全评估**：判断是否存在持续伤害风险（施虐者在场、老人无法自主表达）→ 必要时**先创造单独谈话机会**，或联系社区、公安介入；
2. **识别与记录**：详细记录伤情（可拍照留证，注意程序合法）、经济异常情况、老人陈述；
3. **履行报告义务**：按法律规定向有关部门报告（社区、民政、公安）；
4. **评估老人意愿与决策能力**：若老人有能力且有自决意愿，应在保障安全前提下尊重；若存在严重危险，应**有限介入**（临时庇护、监护干预）；
5. **综合干预**：法律援助（财产保护、赡养义务）、家庭辅导、照护替代安排（居家服务、日间照料、机构安置）；
6. **持续跟进**：建立定期回访与邻里观察机制，防止复发。

### 深讲 3：临终关怀与"放弃治疗"的区分

临终关怀**不是放弃**，两者的区别在于**目标不同**：

| 比较 | 积极治疗 | 临终关怀 |
|------|---------|---------|
| 目标 | 延长生命、治愈疾病 | **减轻痛苦、维护尊严、提升生命质量** |
| 手段 | 手术、化疗、抢救 | 疼痛与症状控制、心理与灵性支持、家属陪伴 |
| 结果预期 | 争取治愈或长期生存 | 接受生命末期，安宁离世 |

**社工角色**：参与**多学科团队**，负责心理社会评估与支持、协助家庭沟通与决策（知情同意与自决）、哀伤辅导、资源链接（安宁疗护机构、志愿者、宗教或文化资源）。**注意**：涉及医疗决策必须由医疗团队与患者（或依法有权代理人）决定，社工不越界替患者做医疗决定。

### 例题（带解析）

**例题 1**：社会工作者为一位刚入住养老院、情绪低落且不愿与人交流的老人提供服务，最适宜采用的小组工作类型是？
A. 治疗小组　B. 动机激发小组　C. 教育小组　D. 社会化小组
**答案 B**。解析：动机激发小组用于帮助因退缩、抑郁或角色丧失而不愿参与的老人重新建立兴趣与参与动机；现实辨识小组主要面向认知障碍老人，治疗小组面向有明确行为或心理问题需矫治者。

**例题 2**：社会工作者在家访中发现老人身上有多处不明伤痕，且其家属对老人态度粗暴。社会工作者首要的做法是？
A. 尊重家庭隐私，不做任何干预
B. 评估老人安全风险，必要时采取保护措施并依法报告
C. 仅口头提醒家属注意态度
D. 立即将老人送入机构安置且不再联系家属
**答案 B**。解析：疑似老年虐待应安全优先，评估风险并依法履行报告义务，同时综合运用法律援助、家庭辅导与照护支持；完全不干预或仅口头提醒都不足，擅自长期隔离老人也需依法与尊重意愿。

**例题 3**：临终关怀的主要目标是？
A. 尽可能延长患者生命　B. 减轻痛苦、维护尊严、提高生命最后阶段的生活质量
C. 劝患者放弃一切治疗　D. 由社工决定医疗方案
**答案 B**。解析：临终关怀以减轻痛苦、维护尊严与提高生命质量为目标，需要多学科团队协作；医疗决策由医疗团队与患者或其依法有权代理人决定，社工不越界。

## ⚠️ 易错提醒

- 老年虐待的类型要记全：**身体、精神、经济剥削、忽视、性虐待 + 自我忽视**；
- 处置老年虐待要**先安全、再报告**，且**评估老人意愿与决策能力**，不能简单"一刀切"；
- 现实辨识小组针对**认知障碍**，动机激发小组针对**退缩与兴趣丧失**，最易混；
- 生命回顾/缅怀往事是老年个案的常用技巧，可用于提升自我整合感；
- 临终关怀**不是放弃治疗**，社工不替患者做医疗决定；
- 为家庭照护者提供**喘息服务**是重要得分点，常被忽略。
