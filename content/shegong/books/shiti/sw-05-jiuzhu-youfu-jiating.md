## 考点梳理

### 5.1 社会救助体系

我国社会救助以**《社会救助暂行办法》**为基础，形成"**8+1**"体系：

| 救助类型 | 面向 |
|---------|------|
| **最低生活保障** | 家庭人均收入低于当地低保标准的居民 |
| **特困人员救助供养** | 无劳动能力、无生活来源且无法定赡养抚养扶养义务人（或义务人无履行能力）的老年人、残疾人、未成年人 |
| **受灾人员救助** | 因自然灾害受影响的人员 |
| **医疗救助** | 符合条件的困难群众医疗费用负担 |
| **教育救助** | 各教育阶段家庭经济困难学生 |
| **住房救助** | 住房困难的低保、分散供养特困人员等 |
| **就业救助** | 有劳动能力的救助对象 |
| **临时救助** | 因突发事件、意外伤害、重大疾病等导致基本生活陷入困境的家庭或个人 |
| **＋社会力量参与** | 慈善组织、社工机构、志愿服务等 |

**社会工作在社会救助中的角色**
- **需求评估与转介**：识别真实需求，防止"漏保""错保"；
- **申请协助与政策讲解**：帮助文化程度低、行动不便者完成申请；
- **能力建设与就业支持**：避免"福利依赖"，促进自立（增能）；
- **心理支持与社会融入**：缓解因贫困带来的羞耻感、孤立感；
- **资源链接与整合**：政府救助 + 慈善资源 + 社区互助。

> ⚠️ **重要边界**：社会工作者**不是救助审批主体**，救助资格与标准由民政等部门按政策核定；社工承担的是**评估、协助、支持与倡导**，不能承诺"一定给你办下来"。

### 5.2 优抚安置社会工作

**优抚对象**主要包括：现役军人及其家属、残疾军人、复员退伍军人、烈士遗属、因公牺牲军人遗属、病故军人遗属、军队离退休干部等（以现行法规口径为准）。

**主要内容**
- **抚恤优待**：残疾抚恤、定期抚恤、优待金、医疗与住房优待等（政策落实与协助）；
- **安置服务**：退役士兵、军队离退休人员的接收安置与转介；
- **就业创业支持**：技能培训、职业介绍、创业扶持、学历教育提升；
- **心理与社会适应**：角色转换（从军人到市民）、创伤与压力调适、家庭关系调适；
- **褒扬与荣誉**：烈士褒扬、荣誉宣传、纪念活动组织（重视尊严与荣誉感）；
- **权益维护**：协助依法维护优抚对象权益。

**服务要点**：尊重其**军人身份与荣誉感**，避免"居高临下"的施恩姿态；关注**隐性需求**（心理创伤、家庭适应）而不只是待遇发放。

### 5.3 家庭社会工作

**家庭生命周期**（常用划分）：**形成期 → 扩展期（生育养育）→ 稳定期 → 收缩期（子女离家）→ 空巢期 → 解体期（丧偶）**。

每个阶段的典型任务：新婚适应、育儿分工、子女教育、代际关系、更年期与退休适应、丧偶哀伤。

**主要内容**：婚姻辅导与夫妻关系调适、亲子关系与家庭教育指导、家庭暴力干预、单亲与重组家庭支持、家庭成员照顾与照护者支持、家庭经济与危机介入。

**常用方法**：家庭会谈与家庭评估（结构、角色、沟通模式、边界）、家庭治疗模式（**结构式**：调整家庭结构与边界；**系统式**：关注互动循环而非"病人"；**萨提亚模式**：沟通姿态与自我价值）、家庭小组与家庭教育、社区层面的家庭支持服务。

### 5.4 家庭暴力干预中的角色边界

- 社工可以：安全评估与安全计划、情绪支持、法律途径告知与协助、庇护与救助链接、教育与增能、必要时依法报告；
- 社工不可以：替受害人决定去留、把家暴当"夫妻矛盾"调解、向无关人员披露、单方"批评教育"施暴者就宣告问题解决。

## 🧠 记忆工具箱

**"低保、特困、受灾、医疗、教育、住房、就业、临时 + 社会力量"**。

> 口诀：**"低特灾、医教住、就临加社会"**。

### 社工在救助中的四个角色

**"评估、协助、增能、链接"**——**不承担审批**。

### 家庭生命周期六阶段

**"形成、扩展、稳定、收缩、空巢、解体"**。

### 家庭治疗三模式

**"结构式（调结构边界）、系统式（看互动循环）、萨提亚（重沟通与自我价值）"**。

**"政策落实 + 荣誉尊严"**，别只发钱不管心。

## 🔍 深度精讲

### 深讲 1：社会救助为什么强调"能力建设"而不只是"给钱"

单纯的现金与物资救助能解决**即时生存问题**，但若长期只做物质给付，可能产生两个后果：

1. **福利依赖**：劳动能力尚存者失去就业动力，退出救助后再度返贫；
2. **耻辱感与被动化**：救助对象被固化为"被帮助的人"，社会功能进一步退化。

因此专业救助服务强调**"救助 + 增能"**：在保障基本生活的同时，通过技能培训、就业链接、心理支持与社会参与，帮助其恢复自立能力。这也是社工区别于纯行政给付的核心价值。

**案例答题点**：面对"低保家庭中有劳动能力的成员长期不就业"，专业做法不是简单停保或指责，而是**评估就业障碍**（照护负担、健康、技能、岗位可获得性）→ 提供**就业救助与照护支持**（如托幼、日间照料）→ 制定渐进式自立计划并跟进。

### 深讲 2：家庭评估要看哪几样

**家庭评估的五个维度（案例可直接套用）**：
1. **结构**：成员构成、边界（谁被排除在外）、子系统（夫妻、亲子、同胞）；
2. **角色**：谁承担经济、照护、情感功能，是否存在角色缺失或过载；
3. **沟通**：表达方式（指责、讨好、打岔、超理智）、是否有倾听与澄清；
4. **权力**：决策权与资源控制（家暴往往体现为权力与控制）；
5. **资源与环境**：经济、住房、社区支持、亲属网络、政策资源。

**介入对应**：结构问题→家庭会谈调整边界；沟通问题→沟通训练；权力与控制问题→安全评估+法律途径；资源问题→链接与倡导。

### 深讲 3：优抚对象服务的"隐性需求"

退役与安置阶段，政策待遇之外最常见的三类隐性需求：

1. **角色转换困难**：从"有明确指令、集体生活、身份自豪"的环境转入日常社会，出现失落、目标模糊；
2. **心理与创伤问题**：服役期间的高压或创伤经历，常以睡眠障碍、易怒、回避社交等方式表现，本人不愿主动求助；
3. **家庭适应**：长期分离后的夫妻与亲子关系需要重建，家属也有独立的支持需求。

**专业做法**：主动、非标签化的接触（借活动、培训等场合建立信任）；**同伴支持**（老兵互助小组效果往往优于纯专业辅导）；同步开展**家属支持**；必要时转介专业心理或医疗机构。

### 例题（带解析）

**例题 1**：社会工作者在社会救助服务中的恰当角色是？
A. 核定救助资格并决定救助金额
B. 开展需求评估、协助申请、能力建设与资源链接
C. 承诺服务对象一定能获得低保
D. 代替服务对象填写全部材料并代其签字
**答案 B**。解析：救助资格与金额由民政等部门依法核定，社工的角色是需求评估、协助申请、增能支持与资源链接，不能越权承诺或代替申请主体作出决定。

**例题 2**：某家庭因突发重大疾病导致基本生活陷入困境，符合的救助类型是？
A. 最低生活保障　B. 临时救助　C. 特困人员救助供养　D. 住房救助
**答案 B**。解析：因突发事件、意外伤害、重大疾病等导致基本生活暂时出现严重困难的，属于临时救助范围；低保针对收入低于低保标准的长期困难家庭。

**例题 3**：社会工作者为退役军人开展服务时，除政策待遇落实外，还应重点关注？
A. 只关注经济补助是否到位
B. 角色转换、心理适应与家庭关系等隐性需求
C. 要求其尽快忘掉部队经历
D. 避免与其家属接触以保护隐私
**答案 B**。解析：优抚安置服务除政策落实外，应重视角色转换、心理创伤与家庭适应等隐性需求，可通过同伴支持小组、家属支持与专业转介提供服务，尊重其军人身份与荣誉感。

## ⚠️ 易错提醒

- 社会救助 **"8+1"** 中"**临时救助**"与"**低保**"的适用情形不要混；
- 社工**没有救助审批权**，不能承诺"一定能办下来"；
- 家庭生命周期六阶段与"婚姻阶段"易混，注意"空巢期"与"解体期"；
- 家庭评估要涵盖**结构与权力**（家暴案例中"权力与控制"是关键维度）；
- 优抚服务不能只做"发钱"，**荣誉感与心理适应**是得分点；
- 家暴处置中社工**不能充当调解人**，也不能替受害人决定去留。
