## 考点梳理

### 1.1 什么是社会工作

**社会工作**是以**利他主义**为指导，以**科学知识**为基础，运用**科学方法**进行的**助人服务活动**。三个关键词：

- **利他主义**——出发点是为他人、为社会，不是营利；
- **科学知识**——依托社会学、心理学、人类行为与社会环境等理论；
- **科学方法**——个案、小组、社区等专业方法，而非单纯的好心与热情。

**本质**：社会工作是一种**专业的助人活动**，其核心目标是**"助人自助"**——帮助服务对象获得自己解决问题的能力，而不是替他解决问题。

### 1.2 社会工作的五大构成要素（必背）

| 要素 | 含义 |
|------|------|
| **社会工作者** | 助人活动的**主体**，受过专业训练、遵循专业价值观 |
| **服务对象** | 助人活动的**客体/受助者**，可以是个人、家庭、群体或社区 |
| **价值观** | 社会工作的**灵魂**，决定"什么值得做、应该怎么做" |
| **专业方法** | 个案、小组、社区等**技术体系** |
| **助人活动** | 主体与客体围绕目标进行的**互动过程**（载体） |

> 记忆锚：**"人、对象、价值、方法、活动"**——缺一不可，价值观是灵魂。

### 1.3 目标与功能

**目标（两个层面）**
- 对**服务对象**：解救危难 → 缓解困难 → **促进发展**（层层递进）；
- 对**社会**：解决社会问题 → 促进社会和谐与公正。

**功能**

| 层面对 | 功能 | 说明 |
|--------|------|------|
| 对服务对象 | **解救危难** | 危机状态下的紧急救助（如灾害、家暴、自杀风险） |
| 对服务对象 | **缓解困难** | 恢复基本生活与社会功能 |
| 对服务对象 | **促进发展** | 提升能力，实现增能（赋权） |
| 对社会 | **解决社会问题** | 回应贫困、失业、老龄化等结构性问题 |
| 对社会 | **维持社会秩序** | 通过化解矛盾减少冲突（预防性、建设性） |
| 对社会 | **促进社会和谐/公正** | 关注弱势群体，推动资源合理分配 |

### 1.4 社会工作者的角色

- **直接服务角色**：服务提供者、支持者、倡导者、关系协调者；
- **间接服务角色**：资源筹措者（链接资源）、政策影响者（推动政策改变）、管理者、研究者；
- **复合角色**：在实务中往往同时扮演多个角色（如既做服务又做倡导）。

### 1.5 三大直接方法与间接方法

- **直接方法**（面对面服务于对象）：**个案工作、小组工作、社区工作**；
- **间接方法**（服务于服务体系）：**社会工作行政、社会工作督导、社会工作研究**。

### 1.6 主要服务领域（了解即可，实务科目要用）

儿童、青少年、老年、妇女、残疾人、矫正、优抚安置、社会救助、家庭、学校、医疗（医务）、企业、社区、农村、灾害、就业援助、禁毒戒毒、精神卫生等。

## 🧠 记忆工具箱

### 五大要素口诀

**"人（社会工作者）、象（服务对象）、值（价值观）、法（专业方法）、动（助人活动）"**——价值观是灵魂。

### 目标三层次

**"危难 → 困难 → 发展"**（先救命、再缓困、后成长）。

### 功能六项

对对象三项：**"救危、缓困、促发展"**；对社会三项：**"解题、维序、促和谐"**。

### 方法三分法

**直接三法**：个案、小组、社区；**间接三法**：行政、督导、研究。

### 角色速记

**"提供、支持、倡导、协调"**（直接）＋**"筹资、影响政策、管理、研究"**（间接）。

## 🔍 深度精讲

### 深讲 1："助人自助"到底是什么意思

**助人自助**包含两层：

1. **助人**：社会工作者确实要提供帮助——物质帮扶、情绪支持、资源链接，而不是冷眼旁观；
2. **自助**：最终目标是让服务对象**恢复并增强自己解决问题的能力**，能够独立应对未来的困难。

因此社工与"发救济的""做慈善的"最大区别是：**不以"我帮你解决"为终点，而以"你能自己解决"为目标**。这也是为什么社工强调**优势视角**（看到服务对象的潜能与资源）而不是只盯问题。

**典型考法**：给出情境问"社会工作者最恰当的做法"，凡是"包办代替""直接替服务对象决定"的选项基本都是错的。

### 深讲 2：为什么说价值观是社会工作的"灵魂"

同样一个事实——"一位老人独居且拒绝入住养老院"：

- 若只按行政管理逻辑：可认定为"不配合"，强制安排；
- 若按社会工作价值逻辑：尊重**自决**原则，先评估其安全风险，了解拒绝的原因（对陌生环境的恐惧、费用、舍不得老邻居），再提供**居家支持**（上门服务、社区活动、安装紧急呼叫）等替代方案，同时做好风险告知与记录。

可见**同样的技术（评估、资源链接）在不同价值观下会导向完全不同的结果**。价值观决定了服务的边界与方向，所以说它是"灵魂"，而方法只是"手脚"。

### 深讲 3：社会功能与"人在情境中"

社会工作的独特视角是**"人在情境中"（Person-in-Environment）**：一个人的困难往往不是纯粹的"个人问题"，而是**个人与环境互动的结果**。

例如一位青少年辍学：

- 只看个人：沉迷手机、厌学 → 处理方式是训诫、管控；
- 看情境：家庭冲突、校园欺凌、学业挫败感、缺乏支持网络 → 处理方式是家庭介入 + 学校协调 + 朋辈支持 + 生涯辅导。

**命题角度**：题目给出"只批评服务对象个人、不关注环境"的做法，通常判为不妥，正确做法是**个人与环境双线介入**。

### 例题（带解析）

**例题 1**：社会工作的出发点和最终目标是"助人自助"，其含义是？
A. 由社会工作者替服务对象解决全部问题
B. 帮助服务对象增强自己解决问题的能力
C. 只提供物质救助，不涉及心理支持
D. 服务对象必须自行解决所有问题，社工不介入
**答案 B**。解析："助人自助"强调在提供帮助的同时增强服务对象自身能力，使其能够独立应对困难；包办代替与完全不介入都不符合专业要求。

**例题 2**：下列属于社会工作构成要素的是？
A. 社会工作者、服务对象、价值观、专业方法、助人活动
B. 政府、企业、社会组织
C. 个案、小组、社区
D. 求助、评估、结案
**答案 A**。解析：社会工作的五大要素为社会工作者、服务对象、价值观、专业方法、助人活动；个案、小组、社区属于方法，求助与结案属于过程环节。

**例题 3**：某地遭遇洪灾，社会工作者第一时间参与紧急转移与临时安置，这主要体现了社会工作对服务对象的哪项功能？
A. 促进发展　B. 解救危难　C. 维持社会秩序　D. 政策影响
**答案 B**。解析：灾害、家暴、自杀风险等危机状态下的紧急救助体现**解救危难**功能；促进发展是提升能力与增能；维持社会秩序是对社会的功能；政策影响是间接角色。

## ⚠️ 易错提醒

- 五大要素中**价值观是灵魂**，专业方法是技术，不要混淆层次；
- 目标与功能要分层：**"危难/困难/发展"是对服务对象**，**"解决社会问题/维持秩序/促进和谐"是对社会**；
- **个案、小组、社区是直接方法**，行政、督导、研究是间接方法；
- "助人自助"不等于"不帮助"，也**不等于包办**；
- 社会工作的出发点是**利他主义**而非营利，注意与商业服务区分。
