## 考点梳理

### 2.1 社会工作的核心价值观

| 价值 | 含义 | 实务表现 |
|------|------|---------|
| **尊重** | 把服务对象当作有尊严的人 | 用语、态度、保护隐私 |
| **接纳** | 接受服务对象的现状与差异，不因其身份、行为而排斥 | 不歧视、不贴标签 |
| **个别化** | 每个人、每个家庭都是独特的 | 不用统一模板套所有人 |
| **自决** | 尊重服务对象自主选择与决定的权利 | 提供信息与选项，让其自己决定 |
| **保密** | 保护服务对象的隐私信息 | 不随意透露、妥善保管资料 |
| **不批判** | 不对服务对象的价值观与行为做道德评判 | 理解行为背后的原因 |
| **相信人能改变** | 相信服务对象有成长与改变的潜能 | 采用优势视角 |
| **同理/同感** | 设身处地理解服务对象的感受 | 准确回应其情绪 |

> 核心一句话：**"尊重、接纳、个别化、自决、保密、不批判"**——初级考试的"价值判断"几乎都从这六条出发。

### 2.2 专业伦理守则（五个面向）

| 面向 | 主要要求 |
|------|---------|
| 对**服务对象** | 尊重与接纳、保护隐私与保密、尊重自决、知情同意、避免伤害、公平对待 |
| 对**同事** | 尊重、协作、不贬损同行、妥善处理专业分歧 |
| 对**机构** | 遵守机构规定、忠诚于机构目标、合理使用机构资源 |
| 对**专业** | 维护专业形象、提升专业能力、参与继续教育与研究、遵守专业界限 |
| 对**社会** | 促进社会公正、关注弱势群体、推动社会政策改善 |

### 2.3 伦理难题的主要类型

- **保密 vs 保护生命/他人安全**：服务对象透露要伤害自己或他人；
- **自决 vs 家长作风（父权主义）**：服务对象的选择可能带来严重风险（如拒绝就医的独居老人）；
- **双重关系（多重关系）**：与服务对象既是专业关系又是朋友、亲属、商业伙伴；
- **价值中立 vs 价值介入**：社工的价值观与服务对象冲突（如对某些行为方式的看法）；
- **资源有限下的公平分配**：多个服务对象竞争有限资源；
- **知情同意与信息透明**：是否、何时、向谁披露信息。

### 2.4 伦理决定的处理原则与优先顺序

当价值与伦理发生冲突时，通行的判断顺序是：

1. **保护生命**（最高原则，生命安全优先于保密与自决）；
2. **差别平等**（对不同处境的人给予不同对待，以实现实质公平）；
3. **自由自主**（尊重自决，但以不伤害为前提）；
4. **最小伤害**（选择伤害最小的方案）；
5. **隐私保密**（在保护生命与法律允许范围内尽可能保密）；
6. **真诚/生活品质**（真诚对待服务对象，提升其生活质量）。

**决策步骤**：识别伦理问题 → 查阅伦理守则与法律 → 咨询督导与同行 → 列出可能方案及后果 → 选择并实施 → 记录与评估。

### 2.5 保密的例外情形（高频）

下列情形可以（或应当）突破保密：

- 服务对象有**伤害自己或他人的严重危险**（如自杀意图、扬言伤害他人）；
- 涉及**违法犯罪**或法律要求报告的事项（如虐待儿童、老年人、家庭暴力等强制性报告）；
- 服务对象**同意**披露（知情同意）；
- 因**专业协作**需要（多专业团队内必要范围内的信息共享，应限于必要信息）；
- 服务对象的**法定代理人**依法需要了解（如未成年人、无民事行为能力人）。

> ⚠️ 保密例外**必须限于必要范围**，并应做好记录与说明，而不是"全部公开"。

## 🧠 记忆工具箱

### 核心价值口诀

**"尊、纳、别、决、密、批"**——尊重、接纳、个别化、自决、保密、不批判。

### 伦理决定六原则顺序

**"生命 > 平等 > 自主 > 最小伤害 > 保密 > 真诚"**。

> 记法：**先保命，再讲公平，再尊重选择，然后才是减少伤害、保密与真诚。**

### 保密例外五条

**"伤己、伤人、违法、同意、协作"**。

### 双重关系一句话

**"专业关系之外的一切关系都要避免"**——包括朋友、亲属、商业、恋爱。

## 🔍 深度精讲

### 深讲 1：自决与"家长作风"的边界怎么把握

**自决**是社工的核心价值，但**自决不是绝对的**。判断标准是"**有无严重伤害风险 + 服务对象有无决策能力**"：

| 情形 | 处理原则 |
|------|---------|
| 有决策能力、风险可控 | **充分尊重自决**，提供信息与选项，做好风险告知与记录 |
| 有决策能力、风险极高（如拒绝紧急救治） | **有限度介入**：反复沟通、引入家属与专业人员、必要时依法报告，同时尽量尊重其选择 |
| 无决策能力（认知障碍、昏迷、严重精神症状发作） | 可**代理决定**，但须遵循"最有利于当事人"原则并履行法定程序 |

**案例标准答法**：先评估"决策能力 + 风险等级"，再选"尊重自决"或"有限介入"，并一律写上"**做好过程记录与风险告知**"。

### 深讲 2：一个完整的伦理困境处理示范

**背景**：服务对象是一名 16 岁少年，向社工透露他计划"教训"一位长期欺凌他的同学，并要求社工保密。

**处理链条**：
1. **识别**：这是"保密 vs 保护他人安全（及保护服务对象本人）"的典型伦理困境；
2. **排序**：按伦理优先顺序，**保护生命与人身安全高于保密**，因此不能简单承诺保密；
3. **沟通**：向服务对象**说明保密的边界**（在涉及人身安全时必须采取行动），避免"先答应后泄露"，否则会彻底破坏专业关系；
4. **行动**：评估风险紧迫性 → 必要时告知监护人、学校与相关部门 → 同时开展**欺凌干预**（学校层面）与**情绪与冲突管理辅导**（个人层面）；
5. **记录与督导**：全过程记录，向督导报告并寻求支持。

### 深讲 3："价值中立"在社工里不是"没有立场"

社工常被误读为"什么都不能评价"，实际上：

- **对服务对象的行为与处境：不批判**（接纳、理解原因）；
- **对社会不公与制度性障碍：要有立场**（倡导社会公正、争取资源）；
- **对伤害行为本身：明确反对**（如家暴、虐待儿童），并在法律与伦理框架内采取行动。

因此"价值中立"是**对服务对象的尊重**，"价值介入"是**对伤害与社会不公的态度**，二者并不矛盾。

### 例题（带解析）

**例题 1**：服务对象向社工透露自己有自杀计划并要求保密，社工最恰当的做法是？
A. 严格保密，不告知任何人
B. 保护生命优先，采取必要措施并告知相关方
C. 立即与服务对象解除专业关系
D. 在社区公开其情况以寻求帮助
**答案 B**。解析：当服务对象有伤害自己的严重危险时，保护生命原则高于保密原则，应采取必要干预措施并告知相关方（监护人、专业人员），但应限于必要范围。

**例题 2**：社会工作者的下列做法中，最符合"自决"原则的是？
A. 替服务对象决定是否离婚
B. 告诉服务对象"你这样想是错的"
C. 提供充分信息与可选方案，由服务对象自行决定
D. 因服务对象的选择与社工价值观不同而拒绝服务
**答案 C**。解析：自决原则要求提供信息与选项、由服务对象自主决定；替其决定违反自决，道德评判违反不批判原则，因价值观不同拒绝服务违反接纳与尊重原则。

**例题 3**：关于保密原则，说法正确的是？
A. 保密是绝对的，任何情况下都不得披露
B. 涉及违法犯罪、伤害他人等情形可以突破保密
C. 社工可向朋友随意谈论服务对象的情况
D. 保密仅限于口头信息，书面资料无需保护
**答案 B**。解析：保密不是绝对的，在服务对象有伤害自己或他人的危险、涉及违法犯罪、服务对象同意或专业协作必需等情形下可以突破；无论口头还是书面资料都应妥善保护。

## ⚠️ 易错提醒

- **保护生命优先于保密与自决**，这是伦理排序的第一条；
- 承诺保密前必须**先说明保密的边界**，不能"先答应后泄露"；
- 伦理难题处理要写"**咨询督导/同事**"这一步，许多考生会漏；
- 双重关系（朋友、亲属、商业合作）应避免，而非"只要不影响工作就行"；
- 保密例外也要**限于必要范围**，"全部公开"同样违规；
- "不批判"针对服务对象的行为与价值观，**不等于对伤害行为没有立场**。
