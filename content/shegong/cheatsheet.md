> **用法**：考前 3 天起只过这一页 + 错题笔记。初级两科须**同年全部合格**；中级三科**连续 2 个考试年度内**通过。

## 一、价值观与伦理（所有题的隐含前提）

| 价值 | 关键词 |
|------|-------|
| 尊重 / 接纳 / 个别化 | 不歧视、不贴标签、不用模板套所有人 |
| **自决** | 尊重选择权，但**以不伤害为前提** |
| **保密** | 有边界（见下） |
| 不批判 / 同理 | 理解行为背后的原因 |

**伦理优先顺序**：**保护生命 > 差别平等 > 自由自主 > 最小伤害 > 隐私保密 > 真诚**

**保密例外（三条）**：**伤己、伤人、法律要求**（虐待儿童/老人等强制报告）；且**接案时就要先说明界限**。

## 二、综合能力概念卡

| 卡片 | 内容 |
|------|------|
| **构成要素** | 社会工作者、服务对象、**价值观**、专业方法、助人活动 |
| **目标/功能** | 对对象：解救危难 → 缓解困难 → 促进发展；对社会：解决社会问题、维持社会秩序、促进社会和谐 |
| **人物—理论** | 马斯洛（需求层次）、埃里克森（八阶段，**青春期＝同一性 vs 角色混乱**）、皮亚杰（认知四阶段）、科尔伯格（道德三水平）、**布朗芬布伦纳（生态系统：微/中/外/宏）** |
| **个案六模式** | 心理社会（人在情境中）、认知行为、**理性情绪（ABC）**、任务中心（短、聚焦）、**危机介入六步**、人本（真诚/无条件积极关注/同理） |
| **危机介入六步** | 及时处理 → 限定目标 → 输入希望 → 提供支持 → 恢复自尊 → 培养自主能力 |
| **小组** | 五阶段（筹备/开始/**中期转折（冲突）**/后期成熟/结束）；四模式（社会目标/治疗/互动/发展） |
| **社区三模式** | 地区发展（居民参与）、社会策划（专家规划）、**社区照顾**（在/由/对社区照顾） |
| **督导三功能** | 行政、教育、支持 |

## 三、实务通用过程六阶段

```
接案（建关系、澄清角色、初步评估、决定接案、签协议）
→ 预估（个人/环境/互动 + 风险与优势资源）
→ 计划（总体目标 + 可测具体目标 + 行动方案）
→ 介入（直接 + 间接 + 顺序：先安全→情绪→关系→能力）
→ 评估（过程 + 结果，基线测量）
→ 结案（总结、巩固、处理离别情绪、跟进转介）
```

## 四、中级实务答题骨架（主观题）

| 设问 | 骨架 |
|------|------|
| 分析问题与需要 | **个人—家庭—环境**三层 + **必写优势与资源** |
| 理论应用 | 理论要点 + **与案例事实逐条对应**（只写名称不给分） |
| 介入策略 | 直接介入 + 间接介入；写"**谁 + 做什么 + 频次 + 预期成效**" |
| 方案设计 | 背景 → 目标（可测）→ 对象 → 策略 → 步骤 → 资源 → 评估 → 风险（**八要素**） |
| 是否恰当 | **判断 + 依据 + 正确做法** |

**动作化原则**：把"加强关爱"改成"**每周一次上门探访 + 协助申请临时救助**"。

## 五、领域专用抓手（案例高频）

| 领域 | 必写要点 |
|------|---------|
| 儿童 | **强制报告**（公安/民政/教育）+ 六大保护 + 儿童参与 |
| 老年 | **喘息服务**、生命回顾、老年虐待六类（身心钱忽性+自我忽视） |
| 妇女 | **安全优先**、制定安全计划、告知人身安全保护令；**不做调解** |
| 残疾人 | 社会模式、四类康复（医/教/职/社） |
| 矫正 | 监督管理 + 帮困扶助双轨、**去标签化** |
| 救助 | 8+1 体系、社工**无审批权**、退出救助的过渡支持 |

## 六、数字与合格标准

| 项目 | 数字 |
|------|------|
| 初级 | 两科须**一个考试年度内全部合格** |
| 中级 | 三科**连续 2 个考试年度内**通过；实务为**主观题** |
| 合格标准 | 各科满分 100 → **60 分**（60%）；**单独划线地区**按官方通告（2026 年：助理 **53**、中级 **59**、高级 **60**） |
| 2026 考试 | **5 月 23、24 日**（综合能力 5/23 上午；法规与政策 5/23 下午；实务初级/中级/高级 5/24 下午） |

## 七、考场分配

```
初级（客观题）：单选 ≤1 分钟/题；情境题先判断"违反哪条价值/处于哪个阶段"
中级实务（主观题）：先写骨架标题 → 逐条展开；每个设问至少 3~4 条
中级法规：数字卡先行（期限/比例/主体），不确定时用排除法
```

> 考前 3 天只看：**本页 + 错题笔记 + 价值观与伦理排序**；社会政策数据一律以官方当次发布为准。
