## 是什么

**社会工作者（简称"社工"）**是指遵循社会工作专业价值理念，运用**个案、小组、社区**等专业方法，为有需要的个人、家庭、群体与社区提供**困难救助、矛盾调处、心理疏导、关系调适、能力提升**等服务的专业人员。

**社会工作者职业资格**是国家对该专业能力的**水平评价**，分三级：

| 级别 | 定位 | 考试科目数 |
|------|------|-----------|
| 助理社会工作师（初级） | 一线服务岗的入门资质 | 2 科 |
| 社会工作师（中级） | 独立开展专业服务、带领项目 | 3 科 |
| 高级社会工作师 | 考试 + 评审，偏领军与研究 | 1 科 + 评审 |

## 社工主要做什么（服务领域）

按官方报考条件中对"相关领域"的界定，社工的服务领域非常广：

- **社会福利与社会救助**：低保、临时救助、特困供养的入户核查与帮扶；
- **社区建设与基层治理**：社区社会组织培育、居民议事、矛盾调解；
- **婚姻家庭与心理健康**：家庭关系调适、危机干预；
- **儿童青少年**：困境儿童保护、校园欺凌干预、青少年成长支持；
- **老年服务**：居家养老、老年小组、认知障碍照护支持；
- **残障康复、矫治帮教、禁毒戒毒、退役军人事务、职工服务、卫生健康**等。

**"专门性社会服务"**包括：生活帮扶与就业援助、情绪疏导与精神抚慰、矛盾纠纷调节与家庭关系调适、特殊困难群体的权益维护与资源链接、行为矫治与危机干预、推动社区发展与社会融入等。

## 证书价值（示例要点，请自行核实）

- **岗位准入与优先**：政府购买服务项目、社区工作者岗位、民政与群团组织岗位常将社工证作为优先或加分条件；
- **薪酬与补贴**：不少地区对持证社工给予**职业津贴**或一次性奖励（以当地政策为准）；
- **专业能力背书**：社会服务项目管理、公益基金会与社工机构的招聘硬指标；
- **继续教育与职业发展**：与督导、项目管理、机构负责人路径衔接。

## 适合人群

- 社区工作者、网格员、基层民政与群团组织工作人员；
- 公益机构、社工机构、基金会、养老与儿童服务机构从业者；
- 社工、社会学、心理学、教育学、公共管理等专业在校生（**社会工作专业本科应届毕业生可直接报考助理社工师**）；
- 希望转行进入社会服务领域的其他专业人士。

## 与相关概念的区分（易混点）

| 概念 | 与社工的关系 |
|------|-------------|
| **志愿者** | 志愿无偿服务，不属于职业资格体系；社工是**职业化、有薪酬、有专业方法**的服务 |
| **心理咨询师** | 侧重个体心理与咨询技术；社工强调**"人在情境中"**，兼顾个体与社会环境改善、资源链接 |
| **社区工作者** | 是一类**岗位**（可能在社区工作但未必持证）；社工证是**专业水平评价**，持证可从事社区工作岗位 |
| **社会工作者职业资格 vs 社会工作者职业水平证书** | 现行体系为"**职业资格**"考试，证书由人力资源社会保障部统一印制，全国有效 |

> ⚠️ 报考条件（学历与从事社会工作年限）、报名时间与合格标准请以**中国人事考试网**及当地考试机构当次通知为准。

## 含金量与难度（职场人决策参考）

### 一、含金量：它能给你带来什么

| 维度 | 说明 |
|------|------|
| **岗位用途** | 社区工作者、民政与群团组织、公益与社工机构、养老/儿童/医疗机构的社会服务岗；乡镇（街道）**社工站**岗位 |
| **招聘认可度** | 多地社区工作者与公益岗位招聘中「**持社工证优先或加分**」，部分岗位明确要求持证 |
| **职称对应** | 社会工作者职业资格与职称对应关系在多地已明确（以本省人社部门规定为准） |
| **个税与补贴** | 取得证书当年可按 **3600 元**申报继续教育专项附加扣除；不少地区对持证社工另行发放**职业津贴或一次性奖励**（标准与条件以当地民政/人社部门为准） |
| **落户/人才政策** | 与当地基层人才政策相关（以当地为准） |
| **长期价值** | 基层治理与社会服务领域的**专业化背书**；向督导、机构管理、项目负责人发展 |
| **它的局限** | 薪酬水平受地区财政与岗位性质影响较大；**证书不等于编制**（进编仍需参加招聘考试） |

### 二、难度：需要投入多少

| 维度 | 评估 |
|------|------|
| **考试结构** | **初级**：综合能力 + 实务（两科，**须在一个考试年度内全部合格**）；**中级**：综合能力 + 实务（**主观题**）+ 法规与政策（**连续 2 个考试年度内通过全部科目**）；高级：实务 + 评审 |
| **难度评级** | 初级 ★★☆☆☆（记忆为主，实务为情境判断）；中级 ★★★★☆（**实务主观题是主要分水岭**） |
| **合格标准** | 各科目满分 100 分，全国统一合格标准按满分的 **60%**（即 **60 分**）；**单独划线地区**按官方通告执行（2026 年：助理 53 分 / 中级 59 分 / 高级 60 分） |
| **建议总学时** | 初级约 **100~180 小时**；中级约 **250~400 小时**（含案例写作训练） |
| **主要难点** | ① 初级：实务情境题的"选最恰当做法"；② 中级：实务案例分析要求按"通用过程 + 理论视角 + 具体方法"作答；③ 法规与政策数字多 |
| **考试频次** | 一年一次（2026 年 **5 月 23、24 日**；2026 年成绩于 7 月 24 日公布） |
| **适合谁** | 社区工作者、民政/群团/公益从业者、想进入基层治理与社会服务领域者 |
| **建议先别考的情形** | 完全不接触社会服务领域且无从业计划（知识难以落地，中级主观题尤其吃力） |

### 三、一句话结论

> **基层岗位的"优先项"而非"万能钥匙"**：报考门槛相对宽松、与社区/公益岗位直接相关；若目标是进编，请同步准备**社区工作者招聘考试**。

> ⚠️ **关于数据的说明**：官方一般不公布统一通过率，上表「难度评级」与「建议学时」为本站依据考试结构、科目数与题型给出的**经验估计**，用于排期参考；**职称对应、补贴标准、落户积分等政策均以国家与你所在省份的最新规定为准**。
