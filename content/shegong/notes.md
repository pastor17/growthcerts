## 一、本证该记什么（三类笔记）

### ① 综合能力：概念卡 + 人物卡

| 卡片 | 必记内容 |
|------|---------|
| **价值观卡** | 尊重、接纳、个别化、自决、保密、不批判；**伦理排序**："生命 > 平等 > 自主 > 最小伤害 > 保密 > 真诚" |
| **人物—理论卡** | 马斯洛（需求层次）、埃里克森（八阶段，**青春期＝同一性 vs 角色混乱**）、皮亚杰（认知四阶段）、科尔伯格（道德三水平）、布朗芬布伦纳（生态系统） |
| **方法卡** | 个案六模式（心理社会/认知行为/理性情绪/任务中心/危机介入/人本）、小组四模式与五阶段、社区三模式（地区发展/社会策划/社区照顾） |

### ② 实务（初级）：通用过程链 + 领域抓手

- **通用过程链**：**接案 → 预估 → 计划 → 介入 → 评估 → 结案**，每个阶段写"任务 + 常见陷阱"；
- **领域抓手**（每个领域只记 3 条）：儿童（强制报告/六大保护/儿童参与）、老年（喘息服务/生命回顾/虐待六类）、妇女（安全优先/不做调解/增能）、矫正（监督管理 + 帮困扶助/去标签化）、救助（8+1/社工无审批权）。

### ③ 中级实务：只记"答题骨架"

| 设问 | 骨架 |
|------|------|
| 分析问题与需要 | 个人—家庭—环境三层 + **必写优势与资源** |
| 理论应用 | 理论要点 + **与案例事实逐条对应**（只写名称不给分） |
| 介入策略 | 直接介入 + 间接介入，写"谁 + 做什么 + 频次 + 预期成效" |
| 方案设计 | 背景→目标（可测）→对象→策略→步骤→资源→评估→风险（**八要素**） |

> 中级实务是主观题，**按点给分**：宁多勿漏、分点编号、动作化表述（把"加强关爱"改成"每周一次上门探访 + 协助申请临时救助"）。

## 二、避坑清单（社工专属 9 条）

| # | 坑 | 正确做法 |
|---|----|---------|
| 1 | 初级也按"滚动"复习 | 初级两科须在**一个考试年度内全部合格**（不滚动） |
| 2 | 中级三科一起硬拼 | 中级为**连续 2 个考试年度内**通过全部科目，可按"第一年综合 + 法规、第二年实务"分配 |
| 3 | 中级实务只看不写 | 实务是**主观题**，必须限时手写，练"得分点条数" |
| 4 | 案例题只分析问题不写优势 | "**优势与资源**"是独立得分点，漏写直接丢分 |
| 5 | 理论只写名称 | 必须写"理论如何解释该案例、指导哪一步介入" |
| 6 | 家暴/虐待案例写成"调解和好" | **安全第一**：评估风险、制定安全计划、告知法律途径，**不做调解** |
| 7 | 把"保密"当绝对原则 | 涉及**伤己、伤人、法律要求**时是保密例外，且接案时应**先说明界限** |
| 8 | 公示成绩按 60 分一刀切判断 | 全国统一线为满分 60%（60 分）；**单独划线地区**按官方通告（2026 年：助理 53、中级 59、高级 60） |
| 9 | 以为拿证就有补贴/编制 | 补贴与津贴**按地方政策**；进编仍需参加社区工作者等招聘考试 |
