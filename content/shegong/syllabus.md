> 社会工作者职业资格考试实行**国家统一大纲**。官方教材由**中国社会出版社**出版（《社会工作综合能力》《社会工作实务》《社会工作法规与政策》，分初、中、高级）。**大纲与教材版本请以当年度官方发布为准。**

## 一、科目、题型与分值结构

| 级别 | 科目 | 题型 | 说明 |
|------|------|------|------|
| 助理（初级） | 社会工作综合能力（初级） | **客观题**（单选、多选） | 单选每题 1 分、多选每题 2 分；满分 100 分 |
| 助理（初级） | 社会工作实务（初级） | **客观题**（单选、多选） | 以**情境判断**为主，考"遇到这种情况怎么做" |
| 中级 | 社会工作综合能力（中级） | 客观题（单选、多选） | 比初级更强调理论与模式辨析 |
| 中级 | 社会工作法规与政策 | 客观题（单选、多选） | 法规条文数字多，需成组记忆 |
| 中级 | 社会工作实务（中级） | **主观题（案例分析 + 方案设计）** | 难度最高，按点给分 |
| 高级 | 社会工作实务（高级） | 主观题（案例分析 + 方案设计） | 考试合格后参加评审 |

> 初级"实务"虽为客观题，但题干多为**案例情境**，考查的是"能否选对介入方法"，而非死记概念——这是与"综合能力"最大的区别。

## 二、初级两科章节主线（本站精讲对照）

### 《社会工作综合能力（初级）》

| 站内章 | 对应主线 |
|--------|---------|
| 第 1 章 | 社会工作的内涵、构成要素、目标功能与主要领域 |
| 第 2 章 | 社会工作价值观与专业伦理（含伦理难题处理） |
| 第 3 章 | 人类行为与社会环境（需求层次、人生发展阶段、生态系统理论） |
| 第 4 章 | 个案工作方法（模式与技巧） |
| 第 5 章 | 小组工作方法（类型、模式、阶段与领导技巧） |
| 第 6 章 | 社区工作方法＋社会工作行政与研究 |

### 《社会工作实务（初级）》

| 站内章 | 对应主线 |
|--------|---------|
| 第 1 章 | 社会工作实务的通用过程（接案—预估—计划—介入—评估—结案） |
| 第 2 章 | 儿童与青少年社会工作 |
| 第 3 章 | 老年社会工作 |
| 第 4 章 | 妇女、残疾人与矫正社会工作 |
| 第 5 章 | 社会救助、优抚安置与家庭社会工作 |
| 第 6 章 | 学校、医务、企业、社区社会工作与实务答题套路 |

## 三、教材与大纲获取（官方渠道）

| 渠道 | 用途 |
|------|------|
| [中国人事考试网](https://www.cpta.com.cn) | **考试大纲**栏目、报考条件、考试通告、成绩查询 |
| 中国社会出版社 | 官方教材（分级别、分科目） |
| 民政部 / 中央社会工作部 | 社会工作政策文件、行业规范与职业标准 |
| 当地民政局、社会工作协会 | 培训、继续教育、行业动态 |

## 四、使用建议

1. **先纲后书**：对照官方大纲在教材上做标记，明确"考什么"，避免全书平均用力；
2. **初级抓"两把钥匙"**：① **价值观与伦理**（几乎所有题都隐含价值判断）；② **通用过程六阶段**（实务题的组织骨架）；
3. **中级早启动实务**：中级实务为主观题，建议在学完综合能力后立即开始练习案例写作，不要拖到最后；
4. **法规科目单独做表**：把《社会工作法规与政策》中的**救助标准、社保缴费与待遇、劳动保护期限**等数字做成表格，考前反复过。
