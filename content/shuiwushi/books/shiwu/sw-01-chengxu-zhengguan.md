## 考点梳理

### 1.1 涉税服务的基本制度

涉税专业服务是指**涉税专业服务机构**接受委托，利用专业知识和技能，就涉税事项**提供税务代理、税务咨询、涉税鉴证等服务**。

| 项目 | 要点 |
|------|------|
| **服务主体** | 税务师事务所、会计师事务所、律师事务所等涉税专业服务机构及其从业人员 |
| **基本要求** | **依法、独立、客观、公正**；保守委托人商业秘密；**不得出具虚假报告** |
| **业务范围** | 纳税申报代理、涉税事项办理、涉税鉴证、税务咨询与筹划、税务行政复议代理等（**以现行执业规范为准**） |
| **与纳税人的关系** | 属于**委托代理关系**；**纳税义务与法律责任仍由纳税人承担**（代理人按约定与规定承担相应责任） |
| **监管** | 由税务机关与行业协会按规定实施**实名管理、业务信息采集与信用评价**（**以现行规定为准**） |

> 记忆锚：**「代理不转移纳税义务」**——这是涉税服务最底层的认知，也是主观题常考的得分点。

### 1.2 税务登记与信息报告

| 环节 | 要点 |
|------|------|
| **设立登记** | 企业在外出经营前依法办理；现多与市场监管登记**信息共享、一次采集** |
| **变更登记** | 登记事项发生变化时按规定办理 |
| **注销登记** | 办理注销前须**结清税款、缴销发票**并按规定的**清税程序**办理 |
| **跨区域涉税事项报告** | 跨区域经营按规定办理报告、报验与反馈 |
| **实名办税** | 办税人员按规定进行**身份信息采集与确认** |
| **信息确认与报告** | 银行账户、财务制度、会计核算软件等按规定向税务机关报告 |

> ⚠️ **注销不是「一走了之」**：**清税是前置条件**，未结清税款与发票无法完成注销。

### 1.3 账簿、凭证与发票管理

| 项目 | 要点 |
|------|------|
| **账簿设置** | 依法设置账簿；规模小、确无建账能力的可按规定**委托代理记账** |
| **凭证管理** | 合法有效凭证是**税前扣除与进项抵扣**的基础 |
| **发票领用与开具** | 按规定领用、按实际经营业务**如实开具**；**不得虚开、不得转借** |
| **发票红冲与作废** | 按现行规定的情形与流程办理 |
| **进项凭证审核** | 审核**票流、货流、资金流、合同流是否一致**（四流一致） |
| **资料保管** | 账簿、凭证与纳税资料按规定**期限保存**（**期限以现行规定为准**） |

> **审核清单（实务高频）**：

```text
① 凭证是否合规（发票种类、税率、项目名称与业务是否匹配）
② 业务是否真实（合同、资金、货物/服务是否对应）
③ 用途是否允许（是否用于简易计税、免税、集体福利或个人消费）
④ 时点是否正确（是否属于本期，有无跨期）
⑤ 是否有留存备查资料（优惠、资产损失等）
```

### 1.4 纳税申报代理与审核

| 环节 | 代理人的动作 |
|------|-------------|
| **资料收集** | 取得账簿、凭证、报表、合同与银行流水等基础资料 |
| **数据核对** | 核对账表、票表、纳税申报数据之间的**勾稽关系** |
| **税额计算** | 按现行税法计算各税种应纳税额，处理**税会差异与纳税调整** |
| **申报表填列** | 按申报表逻辑填列，注意**主表与附表的对应关系** |
| **申报与缴款** | 在规定期限内完成申报与缴款，取得凭证 |
| **后续处理** | 更正申报、补充申报、退税申请与优惠备案（留存备查） |

> 记忆锚：**「先核对、再计算、后填表、按期申报、留存证据」**——主观题按这五步作答不会漏点。

### 1.5 税款征收、担保与保全强制执行

| 制度 | 要点 |
|------|------|
| **税款征收方式** | 查账征收、查定征收、查验征收、定期定额征收等（**以现行规定为准**） |
| **延期缴纳** | 因特殊困难不能按期缴纳的，可依法**申请延期**（**条件与期限以现行规定为准**） |
| **纳税担保** | 保证、抵押、质押；适用于规定情形（**以现行规定为准**） |
| **税收保全** | 在规定的**前提条件与审批程序**下实施（冻结存款、扣押查封等） |
| **强制执行** | 规定条件下采取**扣划、拍卖变卖**等措施（**程序与顺序以现行规定为准**） |
| **代位权与撤销权** | 符合条件的，税务机关可依法行使（**以现行规定为准**） |

> ⚠️ **保全与强制执行是「程序题」重灾区**：**前提条件、审批权限、告知与救济**三者必须同时答到。

### 1.6 税务检查与涉税专业服务监管

| 项目 | 要点 |
|------|------|
| **检查权限** | 查账、实地检查、询问、调取资料、查询存款账户等，**各有法定条件与审批** |
| **检查程序** | 一般应出示**税务检查证件与通知书**；调取资料按规定办理手续 |
| **纳税人权利** | 有权要求出示证件、有权陈述申辩、有权依法申请**回避、复议与诉讼** |
| **检查结论** | 形成检查报告并按规定作出**处理决定或处罚决定** |
| **涉税服务监管** | 涉税专业服务机构按规定进行**实名信息报送与业务信息采集**，纳入**信用管理**（**以现行规定为准**） |

## 🧠 记忆工具箱

### 口诀速记

- **代理关系**：「**代理不转移纳税义务**」；
- **办税主线**：「**登记 → 账簿凭证 → 发票 → 申报 → 缴款 → 检查 → 救济**」；
- **审核五步**：「**凭证合规、业务真实、用途允许、时点正确、资料留存**」；
- **申报代理五步**：「**核对、计算、填表、申报、留证**」；
- **注销**：「**先清税、后注销**」；
- **四流一致**：「**票流、货流、资金流、合同流**」。

### 场景锚点

| 场景 | 你要做的动作 |
|------|-------------|
| 客户委托办理增值税申报 | 收集资料 → 核对账表票表 → 计算 → 填表 → 按期申报并留存底稿 |
| 客户要注销公司 | 提醒**先结清税款、缴销发票**，完成**清税**后办理注销 |
| 发现客户取得的发票项目与实际业务不符 | **不得作为抵扣或扣除凭证**，要求更换并评估风险 |
| 客户申请延期缴纳税款 | 判断是否符合**特殊困难**条件，按规定提交申请 |
| 税务机关调取客户账簿 | 核对**检查证件与调取手续**，配合并留存交接清单 |
| 客户被要求提供纳税担保 | 判断担保方式与适用范围（**以现行规定为准**） |

## ⚠️ 易错提醒

- **错误认知**：委托了税务师，纳税责任就转移给税务师了。**纠正**：**纳税义务与法律责任仍由纳税人承担**，代理人在约定与规定范围内承担相应责任。
- **错误认知**：注销登记随时可办。**纠正**：一般须**先结清税款、缴销发票**，完成**清税程序**后方可注销。
- **错误认知**：只要有发票就能税前扣除或抵扣。**纠正**：还须满足**业务真实、用途允许、凭证合规**等条件，**四流不一致**是典型风险。
- **错误认知**：税务检查可以直接冻结账户。**纠正**：**税收保全与强制执行**都有严格的**前提条件与审批程序**，并非检查即可实施。
- **错误认知**：申报错了就算了。**纠正**：可在规定范围内办理**更正申报或补充申报**，但**故意虚假申报**要承担法律责任。
- **错误认知**：代理申报只要把表填对就行。**纠正**：还须履行**资料核对、风险提示与工作底稿留存**等专业义务。

> ⚠️ 本章涉及的**程序期限、审批权限、担保与保全条件、申报表口径一律以现行有效税收法律法规与当年度官方教材为准**。
