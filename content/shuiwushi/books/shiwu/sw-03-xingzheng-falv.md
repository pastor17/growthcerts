## 考点梳理

### 3.1 行政法基本原则与行政行为

| 原则 | 含义 | 涉税场景 |
|------|------|---------|
| **合法行政** | 行政机关须有**法定依据**、在**法定权限**内行事 | 税务机关作出征税与处罚决定必须有法律依据 |
| **合理行政** | 公平公正、考虑相关因素、**比例原则** | 处罚幅度应与违法情节相当 |
| **程序正当** | **告知、回避、听取意见、说明理由** | 处罚前的告知与陈述申辩 |
| **信赖保护** | 保护相对人对合法行政行为的合理信赖 | 已作出的许可或承诺不得随意变更 |
| **权责统一** | 有权必有责、用权受监督 | 违法行政须承担赔偿责任 |

**行政行为分类**（涉税常见）：

| 类型 | 涉税例子 | 救济途径 |
|------|---------|---------|
| **抽象行政行为** | 制定税收规范性文件 | 一般不直接起诉，可在复议中一并提出审查（**以现行法律规定为准**） |
| **具体行政行为** | 征税决定、处罚决定、不予退税决定等 | **复议 + 诉讼** |
| **行政强制** | 税收保全、强制执行 | 复议 + 诉讼（**注意期限与前置规则**） |

### 3.2 税务行政处罚与程序

| 项目 | 要点 |
|------|------|
| **处罚种类** | 罚款、没收违法所得、停止出口退税权等（**以现行法律规定为准**） |
| **处罚前提** | 违法事实清楚、证据确凿、依据明确 |
| **告知义务** | 作出处罚决定前，应**告知**事实、理由、依据与当事人依法享有的权利 |
| **陈述申辩** | 当事人有权**陈述与申辩**；**不得因申辩而加重处罚** |
| **听证** | 符合法定条件的（如较大数额罚款）应告知**听证权利**，当事人申请后组织听证 |
| **一事不再罚** | 对同一违法行为**不得给予两次以上罚款** |
| **处罚时效** | 违法行为在**法定期限**内未被发现的，一般不再给予处罚（**期限与例外以现行法律规定为准**） |
| **裁量基准** | 处罚幅度按规定的**裁量基准**执行（**以现行规定为准**） |

> 记忆锚：**「先告知、听后说、不加重、不重复、有时效」**。

### 3.3 税务行政复议

| 项目 | 要点 |
|------|------|
| **复议范围** | 对征税行为、处罚行为、强制措施、不作为等不服（**具体范围以现行法律规定为准**） |
| **复议机关** | 一般向**上一级税务机关**申请（**以现行规定为准**） |
| **申请期限** | 应在**法定期限**内提出（**期限以现行法律规定为准**） |
| **前置规则** | 对**征税行为**不服的，一般须**先申请复议**，对复议决定不服再起诉（**以现行法律规定为准**） |
| **申请方式** | 可书面或口头申请；可委托代理人 |
| **审理与决定** | 一般采取书面审查，必要时调查；作出**维持、撤销、变更、责令履行**等决定 |
| **履行** | 复议决定生效后，双方应依法履行 |

> 记忆锚：**「征税先复议、处罚可直接诉」**（**具体范围与例外以现行法律规定为准**）。

### 3.4 税务行政诉讼

| 项目 | 要点 |
|------|------|
| **受案范围** | 对具体行政行为不服（**以现行法律规定为准**） |
| **被告** | 作出被诉行政行为的**税务机关**（复议改变的，复议机关可能为共同被告，**以现行法律规定为准**） |
| **举证责任** | **被告（税务机关）负举证责任**，须提供作出行为的证据与依据 |
| **起诉期限** | 应在**法定期限**内起诉（**期限以现行法律规定为准**） |
| **管辖** | 一般由**最初作出行政行为的税务机关所在地**法院管辖（**以现行法律规定为准**） |
| **判决类型** | 驳回、撤销、履行、给付、确认违法或无效等（**以现行法律规定为准**） |
| **执行** | 生效判决双方均应遵守；行政机关不履行的，可申请强制执行 |

### 3.5 民商法主干

| 板块 | 必记要点 |
|------|---------|
| **合同** | 要约与要约邀请的区分、合同成立与生效、效力瑕疵（无效、可撤销、效力待定）、违约责任与定金罚则 |
| **担保** | 保证（一般保证与连带责任保证）、抵押（不转移占有）、质押（转移占有）；物权变动与登记效力 |
| **公司** | 设立与出资、股东权利与义务、股东会与董事会职权、决议瑕疵、股权转让规则、清算与注销 |
| **破产** | 破产原因、管理人、债权申报、**清偿顺序**、撤销权与抵销权（**以现行企业破产法为准**） |
| **代理与诉讼时效** | 委托代理、无权代理与表见代理；诉讼时效期间与中断、中止（**以现行民法典为准**） |

### 3.6 刑事法律与涉税犯罪

| 罪名 | 构成要点（**以现行刑法规定为准**） |
|------|--------------------------------|
| **逃税罪** | 采取欺骗、隐瞒手段进行虚假纳税申报或不申报，逃避缴纳税款达到规定标准；注意**初犯补缴免刑**的特别规则（**以现行规定为准**） |
| **虚开增值税专用发票罪** | 为他人、为自己、让他人为自己、介绍他人虚开；**是否造成税款损失**影响处理 |
| **骗取出口退税罪** | 以假报出口等欺骗手段骗取国家出口退税款 |
| **抗税罪** | 以暴力、威胁方法拒不缴纳税款 |
| **逃避追缴欠税罪** | 转移、隐匿财产致使税务机关无法追缴欠税 |
| **单位犯罪** | 单位可构成涉税犯罪主体，实行**双罚制**（判处罚金并追究直接责任人员） |

> 记忆锚：**「逃税看手段与比例，虚开看行为与损失，骗税看假报出口，抗税看暴力威胁」**。

## 🧠 记忆工具箱

### 口诀速记

- **行政法五原则**：「**合法、合理、程序正当、信赖保护、权责统一**」；
- **处罚程序**：「**先告知、听后说、不加重、不重复、有时效**」；
- **救济路径**：「**征税先复议，处罚可直接诉**」；
- **举证责任**：「**行政诉讼，被告举证**」；
- **担保**：「**抵押不转移占有，质押转移占有**」；
- **涉税犯罪**：「**逃税、虚开、骗税、抗税、欠税**」五大类。

### 场景锚点

| 场景 | 你要做的判断 |
|------|-------------|
| 税务机关拟对企业罚款，未告知陈述申辩权 | 属**程序违法**，可据此申请复议或提起诉讼 |
| 企业对税务机关的征税决定不服 | 一般须**先申请行政复议**，对复议决定不服再起诉 |
| 企业被处以较大数额罚款 | 注意是否应**告知听证权利**并组织听证 |
| 税务机关在诉讼中被要求提供依据 | **被告负举证责任**，须提交证据与规范性文件 |
| 客户想虚增成本以少缴税款 | 提示可能构成**逃税**甚至**虚开发票**类犯罪的刑事风险 |
| 企业为关联方虚开发票走账 | 提示**虚开发票**的法律后果（行政责任与刑事责任） |

## ⚠️ 易错提醒

- **错误认知**：对税务机关的任何决定都可以直接起诉。**纠正**：对**征税行为**不服一般须**先复议后诉讼**（**前置范围以现行法律规定为准**）。
- **错误认知**：当事人申辩会被加重处罚。**纠正**：**不得因当事人陈述申辩而加重处罚**，这是程序正当的基本要求。
- **错误认知**：行政诉讼由原告（纳税人）举证。**纠正**：行政诉讼中**被告（税务机关）负举证责任**，须证明其行为合法。
- **错误认知**：只要补缴税款就一律不追究刑事责任。**纠正**：**逃税罪**在符合法定条件时有补缴免刑的特别规则，但**并非所有涉税犯罪都适用**，**以现行刑法与司法解释为准**。
- **错误认知**：行政处罚没有时效限制。**纠正**：违法行为在**法定期限**内未被发现的，一般**不再给予处罚**（**期限与例外以现行法律规定为准**）。
- **错误认知**：抵押和质押只是名称不同。**纠正**：**抵押不转移占有**（不动产抵押登记生效），**质押转移占有**（动产交付生效、权利质押登记），二者在生效条件与风险上完全不同。

> ⚠️ 本章涉及的**期限、前置规则、处罚种类与幅度、罪名构成与追诉标准一律以现行有效法律、法规、司法解释与当年度官方教材为准**。
