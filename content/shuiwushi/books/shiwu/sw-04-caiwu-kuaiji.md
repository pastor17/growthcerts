## 考点梳理

### 4.1 财务管理基础

**货币时间价值**（**公式符号以当年度教材为准**）：

| 指标 | 公式 / 要点 |
|------|-----------|
| **复利终值 / 现值** | FV = PV × (1 + i)^n ｜ PV = FV ÷ (1 + i)^n |
| **普通年金现值** | PVA = A × [1 − (1 + i)^−n] ÷ i |
| **普通年金终值** | FVA = A × [(1 + i)^n − 1] ÷ i |
| **预付年金** | 现值 = 普通年金现值 × (1 + i)；终值 = 普通年金终值 × (1 + i) |
| **永续年金** | PV = A ÷ i |
| **递延年金** | 先按普通年金折现，再折现到第一期期初 |

**风险与收益**：

- **期望收益率** = Σ（各情形收益率 × 概率）；
- **标准差**衡量**绝对**风险；**标准差率（变异系数）= 标准差 ÷ 期望值**，衡量**相对**风险；
- **必要收益率 = 无风险收益率 + 风险收益率**；资本资产定价模型体现**系统性风险**补偿（**以教材表述为准**）。

### 4.2 筹资、投资与营运资金管理

| 板块 | 要点 |
|------|------|
| **资本成本** | 债务资本成本注意**税后**口径；<strong>加权平均资本成本（WACC）</strong>按各来源比重加权 |
| **杠杆** | **经营杠杆**（边际贡献 ÷ 息税前利润）、**财务杠杆**（息税前利润 ÷ 税前利润）、**总杠杆** = 两者乘积 |
| **资本结构** | 权衡**负债的税盾效应**与**财务风险**（**以教材表述为准**） |
| **投资决策** | **NPV**（净现值 > 0 可行）、**IRR**（使 NPV 为 0 的折现率）、**回收期**、**现值指数**；NPV 与 IRR 冲突时一般**以 NPV 为准** |
| **营运资金** | 现金持有与周转期管理、**经济订货量**、**信用政策**（信用标准、信用条件、收账政策） |
| **利润分配** | 股利政策类型与影响因素（**以教材表述为准**） |

> 记忆锚：**「NPV 看绝对额、IRR 看收益率、冲突听 NPV」**。

### 4.3 财务分析与评价

| 指标类别 | 典型指标 |
|---------|---------|
| **偿债能力** | 流动比率、速动比率、资产负债率、利息保障倍数 |
| **营运能力** | 应收账款周转率、存货周转率、总资产周转率（**周转率 = 营业收入或营业成本 ÷ 平均余额**） |
| **盈利能力** | 销售净利率、总资产净利率、**净资产收益率（ROE）** |
| **发展能力** | 收入增长率、资本积累率等 |
| **综合体系** | **杜邦分析：ROE = 销售净利率 × 总资产周转率 × 权益乘数** |

> ⚠️ **杜邦分析是财会科最经典的综合题框架**——会拆解三个驱动因素，就能回答「为什么 ROE 变了」。

### 4.4 会计要素确认与计量

| 要素 | 确认与计量要点 |
|------|---------------|
| **资产** | 过去交易或事项形成、由企业**控制**、**预期带来经济利益**；注意**减值**与**公允价值**计量 |
| **负债** | 现时义务、**很可能导致经济利益流出**；区分流动与非流动 |
| **收入** | 按**控制权转移**判断确认时点或时段；注意**合同履约义务**与交易价格分摊 |
| **费用** | 与收入配比；区分**期间费用**与**计入资产成本**的支出 |
| **利润** | 收入 − 费用 + 直接计入当期利润的利得与损失 |

**高频资产的处理主线**：

- **存货**：成本构成、发出计价、期末按**成本与可变现净值孰低**计量；
- **固定资产**：初始计量、折旧方法（年限平均、工作量、**双倍余额递减**、年数总和）、后续支出与处置；
- **无形资产**：研究与开发阶段的区分、摊销与减值；
- **金融资产**：分类与计量、**预期信用损失**；
- **长期股权投资**：**控制 → 成本法**，**共同控制或重大影响 → 权益法**。

### 4.5 税会差异与递延所得税

```text
会计利润
  ± 纳税调整（永久性差异 + 暂时性差异的纳税影响部分）
  = 应纳税所得额 → × 适用税率 = 当期所得税费用

暂时性差异：
  账面价值 > 计税基础（应纳税暂时性差异）→ 递延所得税负债
  账面价值 < 计税基础（可抵扣暂时性差异）→ 递延所得税资产
```

| 概念 | 要点 |
|------|------|
| **永久性差异** | 会计与税法口径**永远不同**（如超标业务招待费、罚款支出），只影响当期 |
| **暂时性差异** | 未来期间**可转回**，需确认**递延所得税资产/负债** |
| **不确认递延所得税的情形** | 如商誉初始确认、部分权益法核算的差异等（**以现行准则为准**） |
| **递延所得税资产的可实现性** | 需评估**未来是否有足够应纳税所得额**供抵扣 |

> 记忆锚：**「账面大、未来多交税 → 递延所得税负债；账面小、未来少交税 → 递延所得税资产」**。

### 4.6 高频涉税账务处理（模板）

| 业务 | 账务处理方向（**科目名称以当年度教材为准**） |
|------|----------------------------------------|
| **计提当期增值税（转出未交）** | 借：应交税费—应交增值税（转出未交增值税） 贷：应交税费—未交增值税 |
| **缴纳增值税与附加税费** | 借：应交税费—未交增值税 / 应交附加 贷：银行存款 |
| **计提附加税费** | 借：税金及附加 贷：应交税费—应交城建税 / 应交教育费附加等 |
| **进项税额转出** | 借：相关成本费用或资产 贷：应交税费—应交增值税（进项税额转出） |
| **计提企业所得税** | 借：所得税费用 / 递延所得税资产 贷：应交税费—应交企业所得税 / 递延所得税负债 |
| **缴纳企业所得税** | 借：应交税费—应交企业所得税 贷：银行存款 |
| **代扣代缴个人所得税** | 借：应付职工薪酬 贷：应交税费—应交个人所得税；缴纳时借：应交税费 贷：银行存款 |
| **计提房产税、土地使用税、印花税** | 借：税金及附加 贷：应交税费—应交房产税等（**印花税也可不通过应交税费，以教材为准**） |

> ⚠️ **账务处理题的答题顺序**：**先判断税种与纳税义务 → 再算金额 → 再写分录 → 最后写缴纳**。

## 🧠 记忆工具箱

### 口诀速记

- **时间价值**：「**终值乘、现值除；年金看期数，预付乘一加 i**」；
- **投资决策**：「**NPV 大于零可行，冲突听 NPV**」；
- **杜邦分析**：「**净利率 × 周转率 × 权益乘数 = ROE**」；
- **周转率**：「**营业收入（成本）除平均余额**」；
- **递延所得税**：「**账面大出负债，账面小出资产**」；
- **长投**：「**控制成本法，共同控制与重大影响用权益法**」；
- **缴税分录**：「**先计提、再缴纳；计提走应交税费，缴纳走银行存款**」。

### 场景锚点

| 场景 | 你要做的判断 |
|------|-------------|
| 公司评估一个投资项目 | 算 **NPV**，为正则可行；再算 IRR 与回收期做补充 |
| ROE 同比下降 | 用**杜邦分解**：净利率降了？周转慢了？还是杠杆变了？ |
| 会计计提固定资产减值准备 | 会计上确认减值损失，**税法一般不得扣除**，形成**暂时性差异** |
| 期末计算所得税 | 先算**应纳税所得额**，再算**当期所得税**与**递延所得税** |
| 月末结转增值税 | 做**转出未交增值税**分录，下月缴纳时冲减 |
| 发放工资并代扣个税 | 计提工资 → 代扣个税 → 发放 → 申报缴纳（四步走） |

## ⚠️ 易错提醒

- **错误认知**：NPV 与 IRR 结论冲突时选 IRR。**纠正**：互斥项目决策一般**以 NPV 为准**，IRR 可能因规模与现金流模式产生误导。
- **错误认知**：标准差越大风险一定越大。**纠正**：比较不同期望值项目时应用**标准差率（相对指标）**，标准差只适合比较期望值相近的项目。
- **错误认知**：会计计提的减值准备可以在税前扣除。**纠正**：会计确认减值形成**可抵扣暂时性差异**，但**税法一般在实际发生损失时才允许扣除**，需做纳税调整。
- **错误认知**：递延所得税资产确认后一定能实现。**纠正**：需评估**未来是否有足够应纳税所得额**，否则不应确认或应减记。
- **错误认知**：附加税费直接计入管理费用。**纠正**：一般通过**税金及附加**科目核算（**科目名称与口径以当年度教材与准则为准**）。
- **错误认知**：收入按开票时点确认就行。**纠正**：会计收入确认看**控制权转移**，与开票时点、纳税义务发生时间**可能不同**，三者要分清。

> ⚠️ 本章涉及的**公式符号、科目名称、准则口径与税率一律以现行有效会计准则、税收法规与当年度官方教材为准**。
