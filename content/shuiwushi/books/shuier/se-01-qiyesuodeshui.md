## 考点梳理

### 1.1 纳税人与征税对象

| 类型 | 判定标准 | 纳税义务 |
|------|---------|---------|
| **居民企业** | 依法在境内成立，或**实际管理机构在境内** | **全面纳税义务**（境内外所得） |
| **非居民企业（设机构场所）** | 在境内设立机构、场所 | 就**该机构场所取得的所得**及**与所设机构场所有实际联系的境外所得**纳税 |
| **非居民企业（未设机构场所）** | 未设机构场所，或所得与机构场所无实际联系 | 就**来源于境内的所得**纳税（一般由**支付方代扣代缴**） |

> 记忆锚：**「居民看注册地与实际管理机构；非居民看机构场所与来源地」**。

### 1.2 应纳税所得额五步结构（**全科主干**）

```text
① 收入总额
② 减：不征税收入 + 免税收入
③ 减：各项扣除（含限额类扣除）
④ 减：允许弥补的以前年度亏损
⑤ = 应纳税所得额
→ 应纳税额 = 应纳税所得额 × 适用税率 − 减免税额 − 抵免税额
```

| 概念 | 要点 |
|------|------|
| **会计利润 ≠ 应纳税所得额** | 两者差异通过**纳税调整**处理（调增 / 调减） |
| **不征税收入** | 性质上不属于营利性活动带来的收入（**范围以现行规定为准**） |
| **免税收入** | 属征税范围但按规定免予征收（如符合条件的股息红利等，**以现行规定为准**） |
| **亏损弥补** | 一般可结转弥补以后年度所得，**结转年限以现行税法规定为准** |

> ⚠️ **做题第一步永远是「先算会计利润，再做纳税调整」**——跳过这一步直接套扣除限额，是这门课最常见的失分原因。

### 1.3 收入确认

| 收入类型 | 确认要点 |
|---------|---------|
| **销售货物收入** | 一般以**权责发生制**为基础，按商品控制权转移等条件确认 |
| **提供劳务收入** | 按完工进度或完成的工作量确认（**以现行规定为准**） |
| **转让财产收入** | 按转让收入扣除财产净值后的余额处理 |
| **股息、红利等权益性投资收益** | 一般以**被投资方作出利润分配决定**的日期确认 |
| **利息、租金、特许权使用费收入** | 一般按**合同约定的应付日期**确认 |
| **接受捐赠收入** | 按**实际收到**捐赠资产的日期确认 |
| **视同销售** | 非货币性资产交换、捐赠、赞助、职工福利等按规定**视同销售** |

### 1.4 扣除项目与限额类型（**高频考点**）

**扣除的基本原则**：**真实性、相关性、合理性 + 合规凭证**。

| 类型 | 判断抓手 | 典型项目 |
|------|---------|---------|
| **与收入（销售）挂钩型** | 先确定**基数**，再按规定比例计算限额 | 业务招待费、广告费和业务宣传费、手续费及佣金等 |
| **与利润挂钩型** | 以**会计利润**为基础计算限额 | 公益性捐赠支出等 |
| **据实扣除型** | 无比例限制，但须符合真实性、相关性、合理性与凭证要求 | 合理的工资薪金、按规定缴纳的社会保险费、利息支出等 |
| **不得扣除型** | 与取得收入无关、违法违规或资本性支出等 | 向投资者支付的股息红利、税收滞纳金、罚金罚款、超标准支出等 |
| **加计扣除型** | 在据实扣除基础上再按比例加计 | 研发费用等（**范围与比例以现行规定为准**） |

> 记忆锚：**「有基数的看基数，没基数的看凭证，违规的一律不扣，鼓励的还能加计」**。
>
> ⚠️ **所有比例、限额与加计口径一律以现行有效税收法规为准**，本页只给判断结构。

### 1.5 资产的税务处理

| 资产 | 税务处理要点 |
|------|-------------|
| **固定资产** | 按**计税基础**计提折旧；一般按**直线法**，符合条件可加速折旧（**范围与年限以现行规定为准**） |
| **无形资产** | 按**直线法**摊销；**不得计算摊销费用扣除的**情形须单独记忆 |
| **长期待摊费用** | 已足额提取折旧的固定资产改建支出、租入固定资产改建支出、大修理支出等按规定摊销 |
| **存货** | 按**成本**计价，发出计价方法（先进先出、加权平均等）一经选用**不得随意变更** |
| **投资资产** | 对外投资期间**投资资产的成本不得扣除**，转让或处置时按规定扣除 |
| **资产损失** | 须按规定的**清单申报或专项申报**方式扣除，并**留存相关证据资料** |

> ⚠️ **税会差异高发区**：折旧年限与方法、减值准备（**计提的减值准备一般不得税前扣除**）、公允价值变动损益等。

### 1.6 税收优惠与特别纳税调整

**优惠的主要类型**（**具体范围、条件与幅度以现行规定为准**）：

| 类型 | 说明 |
|------|------|
| **税率式优惠** | 对特定类型企业适用优惠税率（如小型微利企业、高新技术企业等） |
| **税基式优惠** | 加计扣除、减计收入、加速折旧、所得减免等 |
| **税额式优惠** | 税额抵免（如购置用于环境保护、节能节水、安全生产等专用设备） |
| **区域与产业优惠** | 特定区域、特定产业项目的定期减免 |
| **优惠管理方式** | 多为**自行判别、申报享受、相关资料留存备查**（**以现行规定为准**） |

**特别纳税调整**：

- **关联交易**须符合**独立交易原则**；不符合的，税务机关有权按合理方法调整；
- 主要工具：**转让定价、预约定价安排、成本分摊协议、受控外国企业、资本弱化**等；
- 一般有**同期资料**准备与报送要求（**门槛与内容以现行规定为准**）。

### 1.7 预缴与汇算清缴

```text
① 分月或分季预缴（按实际利润额或按规定方法计算）
② 年度终了后规定期限内进行汇算清缴，结清应缴应退税款
③ 纳税调整在汇算清缴中体现；多缴可申请退税或抵缴
```

| 要点 | 说明 |
|------|------|
| **纳税年度** | 一般为**公历 1 月 1 日至 12 月 31 日** |
| **纳税地点** | 一般向**企业登记注册地**税务机关缴纳（**以现行规定为准**） |
| **汇算清缴期限** | 年度终了后**规定期限内**办理（**以现行规定为准**） |
| **留存备查资料** | 享受优惠与扣除资产损失的关键证据须**按规定的期限保存** |

## 🧠 记忆工具箱

### 口诀速记

- **五步结构**：「**收入减不征免税，再减扣除和亏损**」；
- **扣除四型**：「**挂钩收入的看基数，挂钩利润的看利润，据实的看凭证，违规的一律不扣**」；
- **不得扣除**：「**股息红利、滞纳金罚款、超标准、无关支出**」；
- **资产差异**：「**减值准备不扣、公允变动不认、折旧摊销按税法**」；
- **优惠管理**：「**自行判别、申报享受、资料备查**」；
- **关联交易**：「**独立交易原则是底线**」。

### 场景锚点

| 场景 | 你要做的判断 |
|------|-------------|
| 会计利润为正，但有多项超标支出 | 先算**会计利润**，再逐项**纳税调整**得应纳税所得额 |
| 公司列支业务招待费 | 属**与收入挂钩型**，按基数与规定比例**取低扣除**（**比例以现行规定为准**） |
| 公司计提固定资产减值准备 | **不得税前扣除**，作**纳税调增** |
| 公司享受研发费用加计扣除 | 属**税基式优惠**，注意范围与留存备查资料 |
| 关联方之间低价销售 | 关注**独立交易原则**与**特别纳税调整**风险 |
| 年度终了 | 在**规定期限内**完成**汇算清缴**，结清应缴应退税款 |

## ⚠️ 易错提醒

- **错误认知**：会计利润就是应纳税所得额。**纠正**：两者必须通过**纳税调整**衔接，**先算利润再做调整**是标准动作。
- **错误认知**：计提的减值准备可以税前扣除。**纠正**：会计上计提的减值准备一般**不得税前扣除**，实际发生损失时按规定申报扣除。
- **错误认知**：所有捐赠支出都能据实扣除。**纠正**：公益性捐赠一般属**与利润挂钩型**，需在**规定限额内**扣除且须通过符合条件的渠道。
- **错误认知**：关联交易只要双方同意就行。**纠正**：关联交易须符合**独立交易原则**，否则税务机关有权调整。
- **错误认知**：享受优惠不需要留资料。**纠正**：多数优惠实行**留存备查**管理，**资料不全可能导致优惠被否定**。
- **错误认知**：预缴税款交多了就白交了。**纠正**：汇算清缴时**多退少补**，多缴可申请退税或抵缴。

> ⚠️ 本章涉及的**扣除比例、优惠范围、加速折旧条件、结转年限与申报期限一律以现行有效税收法规与当年度官方教材为准**。
