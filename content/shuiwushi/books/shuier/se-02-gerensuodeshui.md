## 考点梳理

### 2.1 居民个人与非居民个人

| 类型 | 判定标准（一般口径） | 纳税义务 |
|------|-------------------|---------|
| **居民个人** | 在**中国境内有住所**，或**无住所而一个纳税年度内在境内居住累计满规定天数** | **境内外所得**全部纳税 |
| **非居民个人** | 无住所且居住累计**未达规定天数** | 仅就**来源于境内**的所得纳税 |

**居住天数与「六年规则」**：无住所个人在境内居住年限不同，其**境外所得**的征免与**境外支付部分**的处理不同（**具体规则以现行税法规定为准**）。

> 记忆锚：**「有住所是居民；无住所看居住天数，天数决定征税范围」**。

### 2.2 所得项目划分（**判断的起点**）

| 类别 | 所得项目 | 计税方式 |
|------|---------|---------|
| **综合所得** | 工资、薪金所得；劳务报酬所得；稿酬所得；特许权使用费所得 | **按年合并计税**，**超额累进**；由扣缴义务人**预扣预缴**、次年**汇算清缴** |
| **经营所得** | 个体工商户、个人独资与合伙企业投资人、承包承租经营等 | **按年计算**，**超额累进**，**按季预缴、年度汇算**（**以现行规定为准**） |
| **分类所得** | 利息股息红利所得、财产租赁所得、财产转让所得、偶然所得 | **按次或按月**分别计算，一般为**比例**形式 |

> ⚠️ **判断顺序**：先判断「属于哪一类所得」，再选计税方法——**分类错了，后面全错**。

### 2.3 综合所得：预扣预缴与汇算清缴

```text
【预扣预缴】（由扣缴义务人办理）
工资薪金：累计预扣法 —— 累计收入 − 累计免税收入 − 累计减除费用
          − 累计专项扣除 − 累计专项附加扣除 − 累计其他扣除 → 按预扣率表计税 − 已预扣
劳务报酬 / 稿酬 / 特许权使用费：按次或按月按规定方法预扣预缴

【汇算清缴】（居民个人次年办理）
综合所得全年收入 − 减除费用 − 专项扣除 − 专项附加扣除 − 其他扣除
→ 应纳税所得额 → × 适用税率 − 速算扣除数 − 已预缴税款 = 应退或应补
```

| 扣除概念 | 内容 |
|---------|------|
| **基本减除费用** | 按年规定的**固定减除额**（**标准以现行税法规定为准**） |
| **专项扣除** | 基本养老保险、基本医疗保险、失业保险等社会保险费与**住房公积金**个人负担部分 |
| **专项附加扣除** | 子女教育、继续教育、大病医疗、住房贷款利息、住房租金、赡养老人、**3 岁以下婴幼儿照护**等（**项目与标准以现行规定为准**） |
| **其他扣除** | 企业（职业）年金、商业健康保险、税延养老保险、符合条件的公益慈善捐赠等（**以现行规定为准**） |

> 记忆锚：**「四项综合按年算，六项附加按条件扣，预扣预缴平时做，汇算清缴来结账」**。

### 2.4 专项附加扣除的实操要点

| 项目 | 常见判断点 |
|------|-----------|
| **子女教育** | 扣除主体与分摊方式（父母可选择一方扣或双方各半，**以现行规定为准**） |
| **继续教育** | 学历（学位）继续教育与技能人员/专业技术人员职业资格继续教育的区分 |
| **大病医疗** | 一般在**年度汇算清缴**时扣除，需注意**自付金额口径**（**以现行规定为准**） |
| **住房贷款利息** | 限于**首套住房贷款利息**，扣除期限与分摊方式按规定执行 |
| **住房租金** | 与住房贷款利息**不得同时享受**，按城市档次确定标准（**以现行规定为准**） |
| **赡养老人** | 独生子女与非独生子女的分摊规则 |
| **婴幼儿照护** | 按规定的标准与分摊方式扣除 |

> ⚠️ 专项附加扣除**需按条件与凭证要求如实申报**，虚假填报会被**追缴税款并影响纳税信用**。

### 2.5 经营所得与分类所得

| 项目 | 计税要点 |
|------|---------|
| **经营所得** | 以**每一纳税年度的收入总额**减除成本、费用、损失后的余额为应纳税所得额；**超额累进**计税；**按季预缴、年度汇算** |
| **利息、股息、红利所得** | 一般以**每次收入额**为应纳税所得额，**比例**形式计税；注意**差别化政策**（如上市公司股息红利按持股期限） |
| **财产租赁所得** | 每次收入按规定**减除费用或修缮费用**后计税（**口径以现行规定为准**） |
| **财产转让所得** | 转让收入 − **财产原值** − **合理费用** 后的余额计税 |
| **偶然所得** | 以**每次收入额**计税（如中奖、获奖等） |

### 2.6 汇算清缴与征管要点

| 要点 | 说明 |
|------|------|
| **扣缴义务** | 支付所得的单位或个人为**扣缴义务人**，须依法**代扣代缴** |
| **汇算清缴** | 居民个人综合所得一般需在**次年规定期限内**办理汇算清缴（**免于办理的情形以现行规定为准**） |
| **纳税人识别号** | 一般以**公民身份号码**为纳税人识别号 |
| **申报方式** | 可通过**个人所得税 APP、自然人电子税务局**等渠道办理 |
| **境外所得** | 居民个人取得境外所得，应按规定申报并可能适用**抵免**（**以现行规定为准**） |
| **纳税信用** | 申报不实、虚假扣除等会影响**纳税信用**并可能承担法律责任 |

## 🧠 记忆工具箱

### 口诀速记

- **纳税人**：「**有住所是居民，无住所看天数**」；
- **九类所得**：「**四项综合按年算，经营按年也预缴，其余四项按次月**」；
- **综合四扣**：「**基本减除、专项、专项附加、其他扣除**」；
- **汇算公式**：「**全年收入减四扣，乘税率减速算，减已缴得退补**」；
- **两项不兼得**：「**住房贷款利息与住房租金不得同时享受**」；
- **扣缴**：「**谁支付谁扣缴**」。

### 场景锚点

| 场景 | 你要做的判断 |
|------|-------------|
| 公司发放月度工资 | 按**累计预扣法**预扣预缴，注意专项附加扣除的采集与核对 |
| 员工取得年终奖 | 判断**计税方式选择**（**以现行政策与规定为准**） |
| 个人取得劳务报酬 | 属**综合所得**，由支付方**预扣预缴**，次年并入**汇算清缴** |
| 个人出租自有住房 | 属**财产租赁所得**，按次（月）计税，注意修缮费用与税费扣除口径 |
| 个体工商户经营所得 | 按**经营所得**计税，**按季预缴、年度汇算** |
| 员工大病医疗支出 | 一般在**年度汇算清缴**时按自付金额口径扣除 |

## ⚠️ 易错提醒

- **错误认知**：只要在中国境内工作就是居民个人。**纠正**：居民身份看**住所**或**居住天数**，不同身份**征税范围不同**。
- **错误认知**：劳务报酬和工资薪金一样按累计预扣法。**纠正**：劳务报酬、稿酬、特许权使用费按**各自规定的方法**预扣预缴，年度再并入综合所得汇算。
- **错误认知**：专项附加扣除随便填。**纠正**：须**按条件与真实性要求**申报，虚假填报会被追缴税款并影响**纳税信用**。
- **错误认知**：住房贷款利息和住房租金可以同时扣。**纠正**：两者**不得同时享受**，纳税人须自行判断选择。
- **错误认知**：经营所得和综合所得一样按年一次算。**纠正**：经营所得一般**按季预缴、年度汇算**，且适用**专门的税率表**。
- **错误认知**：企业只要代扣了就没事了。**纠正**：扣缴义务人须**依法履行代扣代缴、申报与资料保存义务**，未履行可能承担责任。

> ⚠️ 本章涉及的**减除费用标准、专项附加扣除项目与标准、税率表、汇算期限与境外所得规则一律以现行有效税收法规与当年度官方教材为准**。
