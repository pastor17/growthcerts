## 考点梳理

### 3.1 纳税人与征税范围

土地增值税对**转让房地产取得的增值额**征收，核心是「**转让 + 增值**」。

| 项目 | 要点 |
|------|------|
| **纳税人** | **转让国有土地使用权、地上建筑物及其附着物**并取得收入的单位和个人 |
| **征税范围** | 转让**国有土地使用权**、**地上建筑物及其附着物** |
| **不属于征税范围** | **出让**国有土地使用权（一级市场）；**未转让**的房地产（如自建自用） |
| **常见边界情形** | **合作建房**（分房自用 vs 转让）、**交换**房地产、**出租**（不征）、**继承与赠与**（部分情形不征，**以现行规定为准**） |

> 记忆锚：**「出让不征、转让才征；自用不征、出租不征；继承赠与看规定」**。

### 3.2 扣除项目（**全章核心**）

| 扣除项目 | 适用范围 | 要点 |
|---------|---------|------|
| **① 取得土地使用权所支付的金额** | 通用 | 地价款 + 按规定缴纳的有关费用 |
| **② 房地产开发成本** | 房地产开发企业 | 土地征用及拆迁补偿费、前期工程费、建筑安装工程费、基础设施费、公共配套设施费、开发间接费用 |
| **③ 房地产开发费用** | 房地产开发企业 | 销售费用、管理费用、财务费用；**按规定的两种方式之一计算**（**以现行规定为准**） |
| **④ 与转让房地产有关的税金** | 通用 | 转让环节缴纳的相关税金（**具体可扣税种以现行规定为准**） |
| **⑤ 加计扣除** | **仅限房地产开发企业** | 对取得土地使用权支付金额与开发成本之和按规定比例**加计扣除**（**比例以现行规定为准**） |
| **旧房及建筑物的评估价格** | 转让旧房 | 按**评估价格**扣除，并注意评估费用与购房发票两种口径（**以现行规定为准**） |

> ⚠️ **扣除项目是土地增值税主观题的主战场**：**谁能扣、按什么口径扣、能不能加计**，必须逐项判断。

### 3.3 计税结构

```text
① 转让房地产收入总额
② 减：扣除项目金额合计
③ = 增值额
④ 增值率 = 增值额 ÷ 扣除项目金额
⑤ 应纳税额 = 增值额 × 适用税率 − 扣除项目金额 × 速算扣除系数
   （适用税率与速算扣除系数按增值率对应的档次确定，属超率累进形式）
```

| 关键点 | 说明 |
|-------|------|
| **收入总额** | 包括货币收入、实物收入与其他收入；**不含增值税**（**口径以现行规定为准**） |
| **超率累进** | **增值率越高，适用税率档次越高**（**具体档次与系数以现行规定为准**） |
| **核算单位** | 一般按**项目**或**分期项目**为单位核算（**以现行规定为准**） |
| **一次转让多次取得收入** | 按合同约定或实际取得收入的时间确定纳税义务 |

### 3.4 预缴与清算

| 环节 | 要点 |
|------|------|
| **预缴** | 房地产开发企业**预售**房地产的，按规定**预缴**土地增值税（**预征率以当地与现行规定为准**） |
| **清算条件** | 符合法定条件（如项目全部竣工、销售比例达到规定标准、取得销售许可证满规定年限仍未销售完毕等）应进行**清算**（**条件以现行规定为准**） |
| **清算方式** | 分为**应当清算**与**可要求清算**两类情形 |
| **清算后再转让** | 按剩余房产的相关规定处理 |
| **核定征收** | 符合规定情形可**核定征收**（**适用范围与核定率以现行规定为准**） |

> 记忆锚：**「先预缴、后清算；清算看条件，条件分两类」**。

### 3.5 房地产开发企业的特殊处理

| 项目 | 要点 |
|------|------|
| **利息支出** | 能按项目分摊并提供金融机构证明的，可**据实扣除**；不能的按规定的**比例计算扣除**（**以现行规定为准**） |
| **加计扣除** | 房地产开发企业转让新建房可享受**加计扣除**（**非房地产开发企业不适用**） |
| **代收费用** | 代收费用是否计入收入并扣除，**按现行规定判断** |
| **拆迁安置** | 以房换房等安置方式有专门处理规则 |
| **普通标准住宅** | 符合条件的**普通标准住宅**可享受减免（**条件与口径以现行规定为准**） |

## 🧠 记忆工具箱

### 口诀速记

- **征免边界**：「**出让不征、转让才征；出租不征、自用不征**」；
- **扣除五项**：「**地价、成本、费用、税金、加计**」；
- **加计限制**：「**加计扣除只给房地产开发企业**」；
- **两步税**：「**先预缴、后清算**」；
- **超率累进**：「**增值率越高，税率档次越高**」；
- **旧房**：「**旧房转让看评估价格或购房发票口径**」。

### 场景锚点

| 场景 | 你要做的判断 |
|------|-------------|
| 房地产开发企业预售商品房 | 按规定**预缴**土地增值税，售完或达到条件后**清算** |
| 工业企业转让自有厂房 | 属**转让房地产**，扣除项目包括地价、旧房评估价格与相关税金（**不含加计**） |
| 企业以自有房产对外出租 | **不属于**土地增值税征税范围（属房产税等其他税种范畴） |
| 合作建房后分房自用 | 判断是否属于**征税范围**（**以现行规定为准**） |
| 转让旧房 | 按**评估价格**或**购房发票**口径确定扣除（**以现行规定为准**） |
| 项目达到清算条件 | 判断属**应当清算**还是**可要求清算**情形 |

## ⚠️ 易错提醒

- **错误认知**：只要是房地产交易就要交土地增值税。**纠正**：**出让**国有土地使用权不征，**转让**才征；出租、自用一般不征。
- **错误认知**：所有纳税人都能享受加计扣除。**纠正**：**加计扣除仅限房地产开发企业**转让新建房，其他主体不适用。
- **错误认知**：扣除项目就是实际发生的全部费用。**纠正**：扣除项目**限于法定范围与口径**，如开发费用有**两种计算方式**、利息支出有**据实与按比例**之分。
- **错误认知**：土地增值税按固定比例一次性计算。**纠正**：它是**超率累进**形式，需先算**增值率**再定档次与速算扣除系数。
- **错误认知**：预缴了就不用清算了。**纠正**：预缴只是过程，达到条件必须**清算**，多退少补。
- **错误认知**：收入按含税价直接填入。**纠正**：收入口径**不含增值税**，且应包含货币、实物与其他形式的全部收入。

> ⚠️ 本章涉及的**预征率、加计扣除比例、税率档次、速算扣除系数与清算条件一律以现行有效税收法规、当地规定与当年度官方教材为准**。
