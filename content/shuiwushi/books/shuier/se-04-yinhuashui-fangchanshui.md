## 考点梳理

### 4.1 印花税

印花税是<strong>「凭证税」</strong>——判断的第一步是<strong>「这张凭证属不属于应税凭证」</strong>。

| 项目 | 要点 |
|------|------|
| **纳税人** | **书立应税凭证**的单位和个人；**证券交易**的出让方与受让方（**以现行规定为准**） |
| **应税凭证** | 合同（借款、买卖、租赁、承揽等）、**产权转移书据**、**营业账簿**、**证券交易** |
| **计税依据** | 合同类按**所列金额**（不含增值税）；产权转移书据按**所列金额**；营业账簿按**实收资本与资本公积合计金额**；证券交易按**成交金额** |
| **税率形式** | **比例税率**为主，部分凭证实行**定额**（如权利、许可证照类，**以现行规定为准**） |
| **减免** | 特定主体或特定凭证的减免（如小微、特定合同等，**以现行规定为准**） |
| **纳税期限** | 一般**按季或按次**申报缴纳（**以现行征管规定为准**） |
| **纳税地点** | 一般向**纳税人所在地**税务机关申报（**以现行规定为准**） |

> 记忆锚：**「看凭证、定税目、按金额、比例或定额」**。
>
> ⚠️ 印花税**金额小但漏缴极常见**——合同台账不清、税目判定不准是实务中最典型的风险点。

### 4.2 房产税

房产税的核心判断是<strong>「从价还是从租」</strong>。

| 项目 | 从价计征 | 从租计征 |
|------|---------|---------|
| **适用情形** | 房产**自用**（含经营自用） | 房产**出租** |
| **计税依据** | 房产**原值一次减除规定比例**后的余值 | **租金收入** |
| **税率形式** | **比例** | **比例**（**两档税率具体数值以现行规定为准**） |
| **纳税义务发生时间** | 与房产的取得、建造、出租、终止等情形相关，按现行规定确定 | 同左 |
| **纳税期限** | 一般**按年计算、分期缴纳** | 同左 |

**征税范围**：**城市、县城、建制镇和工矿区**的房产（**不包括农村**）。

**常见特殊情形**：

- **房产原值**的确定包括与房屋不可分割的各种附属设备或一般不单独计价的配套设施（**口径以现行规定为准**）；
- **无租使用**、**融资租赁**、**投资联营**、**免收租金**等情形各有处理规则（**以现行规定为准**）；
- **纳税单位与免税单位**之间的房产使用关系需按规定判断。

> 记忆锚：**「自用从价、出租从租；房产原值减比例，租金收入直接算」**。

### 4.3 城镇土地使用税与耕地占用税

| 税种 | 纳税人 | 计税依据 | 税率形式 | 要点 |
|------|--------|---------|---------|------|
| **城镇土地使用税** | 使用应税土地的单位和个人 | 实际占用的**土地面积** | **定额（按面积分档）** | 按年计算、**分期缴纳**；范围同房产税（城市、县城、建制镇、工矿区） |
| **耕地占用税** | 占用**耕地**建房或从事其他非农业建设的单位和个人 | 实际占用的**耕地面积** | **定额（按面积分档）** | 按占用行为**一次性**征收；特定项目可减免（**以现行规定为准**） |

> 记忆锚：**「土地税按面积按年交，耕地占用税按面积一次性交」**——同是「按面积」，但**征收频率不同**。

### 4.4 契税

| 项目 | 要点 |
|------|------|
| **纳税人** | **承受**土地、房屋权属的单位和个人（**注意是承受方，不是转让方**） |
| **征税范围** | 土地使用权**出让、转让**，房屋**买卖、赠与、互换**等权属转移行为 |
| **计税依据** | 一般为**成交价格**；赠与等情形按规定确定；**不含增值税**（**口径以现行规定为准**） |
| **税率形式** | **比例税率**（**具体税率由地方按规定确定**） |
| **减免** | 婚姻关系存续期间变更、法定继承、特定住房等（**以现行规定为准**） |
| **纳税义务发生时间** | 一般为**签订权属转移合同或取得具有合同性质凭证的当天** |
| **纳税期限** | 一般应在**办理权属登记前**申报缴纳 |

> 记忆锚：**「契税看承受方，签合同当天起算，办证之前要交清」**。
>
> ⚠️ **「谁交契税」是高频送分题，也是高频失分题**——**承受方交，转让方不交**。

### 4.5 车船税

| 项目 | 要点 |
|------|------|
| **纳税人** | 应税车辆、船舶的**所有人或管理人** |
| **征税范围** | 依法应当在车船登记管理部门登记的车辆、船舶（**具体范围以现行规定为准**） |
| **计税依据** | 乘用车按**排气量**；客车按**辆**；货车等按**整备质量**；船舶按**净吨位** |
| **税率形式** | **定额税率**（按年税额） |
| **纳税期限** | 按年申报缴纳；**一般由保险机构在收取交强险时代收代缴** |
| **减免** | 新能源汽车、公共交通车船、捕捞养殖渔船等（**以现行规定为准**） |

### 4.6 财产行为税横向对比抓手

| 税种 | 纳税人 | 征税对象 | 税率形式 | 期限特征 |
|------|--------|---------|---------|---------|
| **印花税** | 书立应税凭证的单位和个人 | 应税凭证 + 证券交易 | 比例为主 + 定额 | 按季/按次 |
| **房产税** | 产权所有人、承典人、代管人等 | 城市等范围内的房产 | 从价或从租（均比例） | 按年计算、分期缴纳 |
| **城镇土地使用税** | 使用应税土地的单位和个人 | 应税土地面积 | 定额 | 按年计算、分期缴纳 |
| **耕地占用税** | 占用耕地的单位和个人 | 占用耕地行为 | 定额 | 一次性 |
| **契税** | **承受**权属的单位和个人 | 土地房屋权属转移 | 比例 | 办证前申报 |
| **车船税** | 车船所有人或管理人 | 应税车船 | 定额（按年） | 按年，常代收代缴 |

## 🧠 记忆工具箱

### 口诀速记

- **印花税**：「**看凭证、定税目、按金额；小税种、大风险、别漏缴**」；
- **房产税**：「**自用从价、出租从租；房产原值减比例**」；
- **土地使用税**：「**按面积、按年交**」；
- **耕地占用税**：「**按面积、一次性**」；
- **契税**：「**承受方交，办证前交**」；
- **车船税**：「**按排气量、按辆、按质量、按吨位，随交强险代收**」。

### 场景锚点

| 场景 | 你要做的判断 |
|------|-------------|
| 公司签订一份采购合同 | 判断是否属**应税凭证**与对应**税目**，按所列金额（不含增值税）计税 |
| 公司自有办公楼自用 | 房产税**从价**计征，按房产原值减除规定比例后的余值计算 |
| 公司将厂房出租 | 房产税**从租**计征，按租金收入计算 |
| 公司购买一栋厂房 | **契税由购买方（承受方）缴纳**，并在**办理权属登记前**申报 |
| 公司占用耕地建设厂房 | 缴纳**耕地占用税**（一次性，按面积） |
| 公司购入一辆货车并投保交强险 | 车船税一般由保险机构**代收代缴** |

## ⚠️ 易错提醒

- **错误认知**：契税由卖房方缴纳。**纠正**：契税的纳税人是**承受方**（买方/受赠方），**转让方不缴纳契税**。
- **错误认知**：房产出租也从价计征房产税。**纠正**：出租房产按**从租**计征（租金收入），自用按**从价**计征。
- **错误认知**：农村房产也要交房产税。**纠正**：房产税征税范围为**城市、县城、建制镇和工矿区**，**不包括农村**。
- **错误认知**：土地增值税与城镇土地使用税是一回事。**纠正**：**城镇土地使用税**按占用面积**按年**缴纳；**土地增值税**对**转让增值额**征收，两者完全不同。
- **错误认知**：印花税金额小，漏了也无所谓。**纠正**：印花税**合同台账不清导致漏缴**是实务高频风险，可能面临**补税与处罚**。
- **错误认知**：车船税要自己去税务局交。**纠正**：车船税一般由**保险机构在收取交强险时代收代缴**，但仍属纳税人义务。

> ⚠️ 本章涉及的**税率、定额标准、减除比例、减免范围与申报期限一律以现行有效税收法规、当地规定与当年度官方教材为准**。
