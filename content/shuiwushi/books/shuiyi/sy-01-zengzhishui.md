## 考点梳理

### 1.1 纳税人与扣缴义务人

增值税的判断起点是<strong>「谁在境内发生了应税行为」</strong>——先分清纳税人身份，再谈怎么算。

| 主体 | 判断要点 | 计税方法 |
|------|---------|---------|
| **一般纳税人** | 年应税销售额超过规定标准或自愿登记；会计核算健全 | 一般计税（销项 − 进项），特定情形可选简易计税 |
| **小规模纳税人** | 年应税销售额未超过规定标准、会计核算不健全 | 简易计税（按征收率计算，**不抵扣进项**） |
| **扣缴义务人** | 境外单位或个人在境内发生应税行为、在境内未设经营机构 | 由**境内购买方或代理人**代扣代缴 |
| **进口货物** | 进口货物的收货人或办理报关手续的单位和个人 | 在**海关**缴纳进口环节增值税 |

> ⚠️ 一般纳税人与小规模纳税人的**认定标准、征收率与登记规则以现行有效税收法规为准**，本页不写死数字。

### 1.2 征税范围与视同销售

**征税范围**：在境内**销售货物、劳务、服务、无形资产、不动产**以及**进口货物**。

**「境内」的三个判断角度**：

- 货物：**起运地或所在地**在境内；
- 服务、无形资产：**销售方或购买方**在境内（或与境内不动产、自然资源相关）；
- 不动产、自然资源：**所在地**在境内。

**视同销售**（**高频考点**，判断标准是**所有权是否转移或是否用于非应税/集体福利/个人消费**）：

| 情形 | 是否视同销售 | 判断锚点 |
|------|------------|---------|
| 将货物**交付他人代销**／**销售代销货物** | 是 | 代销链条两端都算销售 |
| **异地移送**用于销售（同一县市以外） | 是 | 移送环节视同销售 |
| 将**自产、委托加工**货物用于集体福利或个人消费 | 是 | 自产委托加工一律视同 |
| 将**购进**货物用于集体福利或个人消费 | **不视同销售**，但**进项不得抵扣**（已抵扣需转出） | 购进货物「对内」两种处理 |
| 将自产、委托加工或购进货物用于**投资、分配、无偿赠送** | 是 | 对外流出→视同销售 |
| 无偿提供服务、无偿转让无形资产或不动产（用于公益事业等除外） | 是 | 服务类无偿的兜底规则 |

> 记忆锚：**「自产委托加工对内对外都视同；购进的对内不视同但要转出、对外视同销售」**。

### 1.3 计税方法与计税结构

```text
一般计税：应纳税额 = 当期销项税额 − 当期进项税额（＋进项转出调整）
简易计税：应纳税额 = 销售额（不含税）× 征收率
进口环节：应纳税额 = 组成计税价格 × 适用税率
```

| 项目 | 要点 |
|------|------|
| **销售额是否含税** | 价外费用与零售价通常**含税**，须**价税分离**后再计算 |
| **价外费用** | 手续费、包装费、违约金等一般并入销售额（**代收代缴的消费税等符合条件的不并入**） |
| **折扣与折让** | 折扣额与销售额**在同一张发票金额栏**分别注明的，可按折扣后金额计税 |
| **以旧换新** | 一般按**新货物同期销售价格**确定销售额，不得减除旧货收购价 |
| **还本销售／以物易物** | 还本销售不得扣减还本支出；以物易物**双方都作购销处理** |

> ⚠️ **税率档位、征收率与具体口径以现行有效税收法规为准**，本页只讲结构不讲数字。

### 1.4 销项税额

- **销项税额 = 销售额（不含税）× 适用税率**；
- **纳税义务发生时间**决定销项「算在哪一期」——先开票的，为**开具发票当天**；
- 发生**销售折让、中止或退回**的，应按规定**冲减销项税额或销售额**；
- **视同销售**无同类售价时，一般按**组成计税价格**或**其他合理方法**确定销售额（**顺序以现行规定为准**）。

### 1.5 进项税额、不得抵扣与进项转出

| 分类 | 内容 |
|------|------|
| **准予抵扣** | 取得合规扣税凭证、用于**应税项目**的进项；含增值税专用发票、海关缴款书、农产品收购或销售发票、代扣代缴凭证等 |
| **不得抵扣** | 用于**简易计税、免税项目、集体福利或个人消费**的进项；**非正常损失**对应的进项；购进**贷款服务**等特定项目的进项（**以现行规定为准**） |
| **进项转出** | 已抵扣后**用途改变**或发生非正常损失，须按规定**转出**；无法划分的按公式分摊 |
| **留抵处理** | 当期销项小于进项形成**留抵税额**，按现行规定**结转下期或申请退还** |

> 记忆锚：**「三问定进项——用途是不是应税？凭证是否合规？有没有非正常损失？」**

### 1.6 纳税义务发生时间、地点与期限

| 项目 | 一般口径（**以现行规定为准**） |
|------|------------------------------|
| **纳税义务发生时间** | 收到销售款项或取得索取销售款项凭据的当天；先开具发票的为**开票当天**；进口货物为**报关进口当天** |
| **纳税地点** | 一般向**机构所在地或居住地**税务机关申报；不动产、自然资源所在地有特殊规则；进口货物在**报关地海关** |
| **纳税期限** | 按**固定期限**（月、季等）申报缴纳，具体期限与申报期以现行征管规定为准 |
| **预缴情形** | 跨地区提供建筑服务、不动产经营租赁与转让等按规定**异地预缴** |

> ⚠️ 预缴率、预缴地点与申报表填列口径**以现行有效税收法规与当年度教材为准**。

## 🧠 记忆工具箱

### 口诀速记

- **征税范围**：「**货劳服无房，进口也算上**」；
- **视同销售**：「**自产委托加工，对内对外都视同；购进对内不视同，进项一定要转出**」；
- **计税**：「**一般销减进，简易乘征收率，进口组价乘税率**」；
- **进项三问**：「**看用途、看凭证、看损失**」；
- **时点**：「**收款、取得凭据、先开票——三者看最早发生的那个**」。

### 场景锚点

| 场景 | 你要做的判断 |
|------|-------------|
| 公司把自产产品发给职工作福利 | **视同销售**，计销项，对应进项可抵 |
| 公司把购进的食用油发给职工作福利 | **不视同销售**，但**进项不得抵扣**（已抵扣要转出） |
| 收到一张专票，货物用于简易计税项目 | **不得抵扣**，做进项转出 |
| 仓库因管理不善造成货物毁损 | 属**非正常损失**，对应进项**转出** |
| 客户预付货款、货未发但发票已开 | 纳税义务发生时间为**开票当天** |
| 在外省提供建筑服务 | 按规定在**项目地预缴**、机构地申报 |

## ⚠️ 易错提醒

- **错误认知**：购进的货物用于集体福利也要视同销售。**纠正**：购进货物对内使用**不视同销售**，但**进项不得抵扣**；只有**自产、委托加工**的货物对内才视同销售。
- **错误认知**：小规模纳税人也能抵扣进项。**纠正**：简易计税**不抵扣进项**，按征收率直接计算应纳税额。
- **错误认知**：只要取得专票就能抵扣。**纠正**：还要看**用途**（简易计税、免税、集体福利或个人消费不得抵扣）与**损失情形**（非正常损失不得抵扣）。
- **错误认知**：销售额就是合同上写的金额，不用管含不含税。**纠正**：价外费用、零售价通常**含税**，必须先**价税分离**；折扣只有**同票金额栏注明**才能扣减。
- **错误认知**：留抵税额只能一直结转。**纠正**：留抵可按现行规定**结转下期或申请退还**，具体条件与程序**以现行规定为准**。
- **错误认知**：纳税义务发生时间就是收款时间。**纠正**：还要考虑**取得索取款项凭据**与**先开发票**两种更早情形，取**最早**者。

> ⚠️ 本章涉及的**税率、征收率、认定标准与优惠政策一律以现行有效税收法规与当年度官方教材为准**。
