## 考点梳理

### 2.1 纳税人与征税环节

消费税是**选择性征收**的流转税——只对**特定消费品**征收，且**多数税目在生产环节一次性征收**。

| 环节 | 纳税人 | 说明 |
|------|--------|------|
| **生产销售环节** | 生产应税消费品的单位和个人 | **最主要的征收环节**，出厂销售时缴纳 |
| **委托加工环节** | 委托方为纳税人，**受托方代收代缴**（受托方为个人时除外） | 受托方须按规定代收代缴 |
| **进口环节** | 进口应税消费品的收货人或办理报关手续的单位和个人 | 在**海关**缴纳 |
| **零售环节** | 特定税目（如金银首饰、超豪华小汽车等）的零售单位 | **仅限规定税目**，以现行规定为准 |
| **批发环节** | 特定税目（如卷烟批发）的批发企业 | **仅限规定税目**，以现行规定为准 |

> 记忆锚：**「生产为主、委托加工受托方代收代缴、进口在海关、零售批发看特例」**。

### 2.2 应税消费品范围

典型税目类别（**具体税目与子目以现行有效税收法规与当年度教材为准**）：

| 类别 | 典型税目 | 计税形式 |
|------|---------|---------|
| **有害健康类** | 烟（含卷烟、雪茄烟、烟丝）、酒（含白酒、黄酒、啤酒、其他酒） | 卷烟与白酒为**复合计税**；黄酒、啤酒为**从量** |
| **高档消费类** | 高档化妆品、贵重首饰及珠宝玉石、高尔夫球及球具、高档手表、游艇 | 多为**从价** |
| **资源消耗类** | 成品油、木制一次性筷子、实木地板 | 成品油多为**从量** |
| **交通工具类** | 摩托车、小汽车（乘用车、中轻型商用客车等） | 多为**从价** |
| **其他** | 电池、涂料 | 多为**从价**（并可能有免税政策） |

**易混边界**：需注意<strong>「高档」的界定标准</strong>（如高档化妆品与普通护肤护发品）、**「酒」中不同子目的区分**、**成品油子目的区分**——**具体界定以现行规定为准**。

### 2.3 计税方法

```text
从价计征：应纳税额 = 销售额（不含增值税）× 比例税率
从量计征：应纳税额 = 销售数量 × 定额税额
复合计征：应纳税额 = 销售额 × 比例税率 + 销售数量 × 定额税额
```

| 要点 | 说明 |
|------|------|
| **销售额** | 全部价款和价外费用，**不含增值税**；含税需换算 |
| **自产自用（用于连续生产应税消费品）** | **不纳税**（最终环节征税） |
| **自产自用（用于其他方面）** | 视同销售，按同类售价或**组成计税价格**计税：**（成本 + 利润）÷（1 − 比例税率）** |
| **包装物** | 随同销售的包装物并入销售额；**收取押金**是否并入**以现行规定为准** |
| **外币结算** | 按规定的汇率折算，**汇率口径以现行规定为准** |

> ⚠️ 公式中的**成本利润率与税率档位以现行有效税收法规为准**，本页只讲结构。

### 2.4 委托加工与进口环节

| 情形 | 计税依据 | 关键点 |
|------|---------|-------|
| **委托加工（从价）** | **（材料成本 + 加工费）÷（1 − 比例税率）** | 受托方**代收代缴**；委托方收回后**直接销售的不再缴纳**（另有规定除外） |
| **委托加工（从量）** | 按**收回数量**计算 | 受托方代收代缴定额税 |
| **进口（从价）** | **（关税完税价格 + 关税）÷（1 − 比例税率）** | 在海关缴纳，与进口增值税同环节 |
| **进口（复合）** | 组成计税价格 × 比例税率 + 数量 × 定额税 | 注意先算组成计税价格 |

> **已纳消费税扣除**：委托加工收回或外购的应税消费品，用于**连续生产应税消费品**的，可按**当期生产领用数量**扣除已纳消费税（**扣税范围与计算口径以现行规定为准**）。

### 2.5 出口与纳税申报

- **出口退（免）税**：出口应税消费品一般按规定**免征或退还**消费税（**范围与办法以现行规定为准**）；
- **纳税义务发生时间**：与销售结算方式相关，一般参照增值税的同类规则（**以现行规定为准**）；
- **纳税地点**：一般向**纳税人机构所在地或居住地**税务机关申报；委托加工由**受托方所在地**代收代缴；进口在**报关地海关**；
- **纳税期限**：按**固定期限**申报缴纳（**以现行征管规定为准**）。

## 🧠 记忆工具箱

### 口诀速记

- **三环节**：「**生产、委托加工、进口；零售批发看特例**」；
- **三形式**：「**从价乘价、从量乘量、复合两样都要算**」；
- **连续生产**：「**自产自用连续生产不纳税，其他用途视同销售**」；
- **委托加工**：「**材料加加工费除一减税率；受托方代收代缴**」；
- **进口**：「**完税价加关税，再除一减税率**」；
- **扣除**：「**外购委托加工连续生产，按领用数量扣已纳**」。

### 场景锚点

| 场景 | 你要做的判断 |
|------|-------------|
| 白酒厂销售自产白酒 | **复合计征**：销售额 × 比例税率 + 数量 × 定额税 |
| 卷烟厂批发卷烟 | 看在**批发环节**是否属规定税目，按规定处理 |
| 化妆品厂将自产化妆品用于职工福利 | **视同销售**，按同类售价或组成计税价格计税 |
| 委托加工白酒收回后继续勾兑白酒 | 受托方**代收代缴**；连续生产可按领用数量**扣除已纳消费税** |
| 进口小汽车 | 在**海关**按组成计税价格缴纳消费税与增值税 |
| 销售应税消费品同时收取包装物押金 | 判断是否并入销售额（**以现行规定为准**） |

## ⚠️ 易错提醒

- **错误认知**：所有消费品都要交消费税。**纠正**：消费税是**选择性征收**，只对**规定税目**征收，判断第一步是「属不属于应税消费品」。
- **错误认知**：自产自用一律要交消费税。**纠正**：用于**连续生产应税消费品**的**不纳税**；用于其他方面才视同销售。
- **错误认知**：委托加工由委托方自己缴纳消费税。**纠正**：一般由**受托方代收代缴**（受托方为个人的情形除外，**以现行规定为准**）。
- **错误认知**：组成计税价格直接用成本加利润。**纠正**：从价与复合计征时须<strong>除以（1 − 比例税率）</strong>换算为含税价，进口环节还要**先加关税**。
- **错误认知**：只要能抵就能把已纳消费税全部扣除。**纠正**：扣除**限于规定范围与用途**，且一般按**当期生产领用数量**计算，**口径以现行规定为准**。
- **错误认知**：销售额可以直接用含税收入。**纠正**：消费税计税依据**不含增值税**，含税收入必须先换算。

> ⚠️ 本章涉及的**税目范围、税率形式外的具体数字、扣除口径与优惠政策一律以现行有效税收法规与当年度官方教材为准**。
