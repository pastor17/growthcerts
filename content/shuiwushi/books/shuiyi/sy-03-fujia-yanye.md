## 考点梳理

### 3.1 城市维护建设税

城建税是**附加税**——它不单独对应某个经营行为，而是**跟着主税走**。

| 项目 | 要点 |
|------|------|
| **纳税人** | 实际缴纳**增值税、消费税**的单位和个人（**包括个体工商户与其他个人**，**以现行规定为准**） |
| **计税依据** | 实际缴纳的**增值税税额 + 消费税税额**（**不含滞纳金与罚款**） |
| **税率形式** | **地区差别比例税率**——按纳税人所在地不同分档（**具体分档与适用标准以现行规定为准**） |
| **与退税的关系** | 主税**退还**的，城建税**可同时退还**（**以现行规定为准**） |
| **减免** | 随主税减免而同步；**进口不征、出口不退** |

> 记忆锚：**「跟着主税走，主税免它就免，主税退它才退」**。

### 3.2 教育费附加与地方教育附加

| 项目 | 教育费附加 | 地方教育附加 |
|------|-----------|-------------|
| **性质** | **政府性基金**（非税收入），不是税 | 同为政府性基金 |
| **计征依据** | 实际缴纳的**增值税 + 消费税**税额 | 同左 |
| **征收比例** | 按国家规定的**比例**计征（**以现行规定为准**） | 由地方按规定确定（**以现行规定为准**） |
| **减免规则** | 随主税减免；**进口不征、出口不退** | 同左 |
| **申报方式** | 一般与主税**同期申报缴纳** | 同左 |

> ⚠️ **三项附加是最高频的「细节丢分点」**：它们**只跟着增值税与消费税**，**不影响**企业所得税、个人所得税、印花税等。

### 3.3 计税依据的四个关键判断

```text
① 基数是「实缴」的增值税 + 消费税，不是「应纳」或「销项」
② 不含滞纳金、罚款等非税款款项
③ 主税有减免 → 附加同步减免
④ 进口环节缴纳的增值税、消费税 → 不征收附加（进口不征）
⑤ 出口货物退还增值税、消费税 → 已征附加不退还（出口不退）
```

**关于「先征后返、先征后退、即征即退」**：

- 一般规定：**除另有规定外，对退还的增值税、消费税，已征的城建税与教育费附加不予退还**（**以现行规定为准**）；
- 但**直接减免**（如法定免税）情形下，因未实际缴纳税款，附加自然不产生。

### 3.4 烟叶税

| 项目 | 要点 |
|------|------|
| **纳税人** | 在中华人民共和国境内**收购烟叶**的单位 |
| **征税对象** | **烟叶**（含晾晒烟叶、烤烟叶） |
| **计税依据** | 收购烟叶的**收购金额**（含**价外补贴**，**具体口径以现行规定为准**） |
| **税率形式** | **比例税率**（**具体税率以现行规定为准**） |
| **纳税地点** | **烟叶收购地**税务机关 |
| **纳税义务发生时间** | **收购烟叶的当天** |
| **纳税期限** | 按次或按税务机关核定期限申报缴纳（**以现行征管规定为准**） |

> 记忆锚：**「烟叶税看收购方、按收购金额、在收购地、收购当天纳税」**。
>
> ⚠️ 烟叶收购**还涉及增值税进项口径**（收购发票或销售发票按规定计算），两者要分开判断、不要混算。

### 3.5 申报与常见处理

| 场景 | 处理要点 |
|------|---------|
| 当月有增值税应纳且有消费税应纳 | 附加按**两项实缴税额之和**计算 |
| 当月增值税为**留抵**、实缴为零 | **无附加**（未实际缴纳税款） |
| 小规模纳税人享主税减免 | 附加**同步减免**（**具体政策以现行规定为准**） |
| 进口货物缴纳增值税与消费税 | **不征**城建税与两项附加 |
| 出口退税 | 已征附加**不退还** |
| 异地预缴增值税 | 附加一般**随预缴同步缴纳**（**以现行规定为准**） |

## 🧠 记忆工具箱

### 口诀速记

- **计税依据**：「**实缴的两税，不含滞纳罚款**」；
- **两个不**：「**进口不征、出口不退**」；
- **同步规则**：「**主税免则附加免，主税退则附加退（另有规定除外）**」；
- **烟叶税**：「**谁收购谁交、按收购金额、在收购地、收购当天**」；
- **易漏点**：「**附加只跟增值税和消费税，其他税种一概不搭**」。

### 场景锚点

| 场景 | 你要做的判断 |
|------|-------------|
| 本月实缴增值税与消费税合计有一定金额 | 附加按**两者之和**计征，注意地区差别税率 |
| 本月增值税全部是留抵，未实际缴纳 | **不产生**附加税费 |
| 公司进口一批设备并缴了进口增值税 | 进口环节**不征**附加 |
| 公司出口货物并办理了退税 | 已缴附加**不退** |
| 烟草公司向农户收购烟叶 | 在**收购地**按收购金额缴纳烟叶税，并注意进项口径 |
| 收到税务机关退还多缴的增值税 | 判断附加是否**同步退还**（**以现行规定为准**） |

## ⚠️ 易错提醒

- **错误认知**：附加税费的计税依据是销项税额或应纳税额。**纠正**：基数是**实际缴纳**的增值税与消费税税额，**不含滞纳金与罚款**。
- **错误认知**：附加税费也跟企业所得税挂钩。**纠正**：附加**只跟增值税与消费税**，与所得税、财产行为税无关。
- **错误认知**：进口环节也要交城建税与教育费附加。**纠正**：**进口不征**，进口环节只缴增值税、消费税（及关税）。
- **错误认知**：出口退税时已缴的附加也一起退。**纠正**：**出口不退**，已征附加不予退还（**另有规定的除外**）。
- **错误认知**：烟叶税由农户缴纳。**纠正**：烟叶税的纳税人是**收购烟叶的单位**，不是出售烟叶的农户。
- **错误认知**：增值税留抵也算实缴，要计附加。**纠正**：留抵意味着**未实际缴纳税款**，**不产生**附加税费。

> ⚠️ 本章涉及的**税率分档、征收比例与减免政策一律以现行有效税收法规与当年度官方教材为准**。
