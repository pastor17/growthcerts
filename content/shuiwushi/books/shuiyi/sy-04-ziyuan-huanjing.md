## 考点梳理

### 4.1 资源税：纳税人与征税对象

资源税对**开采应税资源与生产盐**的行为征收，核心是「**对资源本身课征**」。

| 项目 | 要点 |
|------|------|
| **纳税人** | 在境内**开采**应税矿产品、**生产**盐（含部分试点地区取用水资源）的单位和个人 |
| **征税对象** | **应税矿产品与盐**；一般为**原矿或选矿**（**具体税目与子目以现行规定为准**） |
| **税率形式** | **比例税率**为主，部分税目实行**定额税率** |
| **计税依据** | 一般为**销售额或销售数量**；自用于非生产项目的**视同销售** |
| **扣缴义务人** | 收购未税矿产品的单位，可能为**扣缴义务人**（**以现行规定为准**） |

**计税结构**：

```text
从价计征：应纳税额 = 销售额 × 比例税率
从量计征：应纳税额 = 销售数量 × 定额税额
自用（非连续生产）：按同类售价或组成计税价格确定
```

### 4.2 资源税的减免与征管

| 减免类型 | 说明 |
|---------|------|
| **共伴生矿、低品位矿、尾矿** | 按规定**减征或免征**（**范围与幅度以现行规定为准**） |
| **开采原油过程中用于加热、修井的原油** | 一般**免征** |
| **因意外事故或自然灾害等原因遭受重大损失** | 可按现行规定申请**减免** |
| **衰竭期矿山** | 按规定**减征**（**以现行规定为准**） |
| **水资源税试点** | 试点地区按规定征收（**以现行规定为准**） |

> **纳税地点**：一般向**应税资源开采地或生产地**税务机关申报缴纳；**跨省开采**有专门规则。

### 4.3 环境保护税

环境保护税是<strong>「费改税」</strong>的产物，对**直接向环境排放应税污染物**的行为征收。

| 项目 | 要点 |
|------|------|
| **纳税人** | 直接向环境排放应税污染物的**企业事业单位和其他生产经营者** |
| **征税对象（四类）** | **大气污染物、水污染物、固体废物、噪声** |
| **计税依据** | 大气与水污染物按**污染当量数**；固体废物按**排放量**；噪声按**超过国家规定标准的分贝数** |
| **税率形式** | **定额税率**（按污染当量/吨/超标分贝） |
| **减免** | 排放浓度值低于规定标准一定比例的**减征**；符合规定的**综合利用**免税（**幅度以现行规定为准**） |
| **纳税期限** | 一般**按季申报缴纳**（**以现行征管规定为准**） |
| **不征情形** | 向依法设立的污水、垃圾集中处理场所排放；符合标准的贮存或处置（**以现行规定为准**） |

> 记忆锚：**「气水按当量、固废按吨、噪声按分贝；低于标准可减、综合利用可免」**。

### 4.4 车辆购置税

| 项目 | 要点 |
|------|------|
| **纳税人** | 在境内**购置**应税车辆的单位和个人 |
| **征税范围** | 汽车、有轨电车、汽车挂车、排气量超过规定的摩托车等（**以现行规定为准**） |
| **计税依据** | 一般为**不含增值税的计税价格**；进口自用为**组成计税价格**；自产自用等按规定确定 |
| **税率形式** | **比例税率**（**具体税率以现行规定为准**） |
| **一次性征收** | 车辆购置税**一次征收**，已税车辆不再征收 |
| **减免** | 新能源汽车、特定用途车辆等政策（**以现行规定为准**） |
| **纳税地点与期限** | 一般向**车辆登记地**或纳税人所在地申报；应在**规定期限内**申报缴纳 |

### 4.5 关税要点

| 项目 | 要点 |
|------|------|
| **纳税人** | 进口货物的**收货人**、出口货物的**发货人**、进境物品的**所有人** |
| **计税依据** | **关税完税价格**（进口一般以成交价格为基础按规定调整） |
| **税率形式** | **从价、从量、复合、滑准**等形式；并区分**最惠国、协定、特惠、普通**等税率适用 |
| **减免** | 法定减免、特定减免与临时减免（**以现行规定为准**） |
| **征管** | 由**海关**征收，随货物进出口环节办理；**关税是进口环节增值税与消费税的组成基础之一** |
| **补征与追征** | 有规定的期限与程序（**以现行规定为准**） |

> 记忆锚：**「关税算完，才轮到进口增值税与消费税」**——进口环节三税的**先后顺序**是高频判断点。

### 4.6 小税种横向对比抓手

| 税种 | 纳税人 | 征税对象 | 税率形式 | 纳税期限（一般口径） |
|------|--------|---------|---------|-------------------|
| **资源税** | 开采应税资源、生产盐的单位和个人 | 应税矿产品与盐 | 比例为主，部分定额 | 按期限申报（**以现行规定为准**） |
| **环境保护税** | 直接排污的企业事业单位 | 气、水、固废、噪声 | 定额 | 一般按季申报 |
| **车辆购置税** | 购置应税车辆的单位和个人 | 购置应税车辆的行为 | 比例 | 规定期限内一次申报 |
| **关税** | 进出口货物收发货人、进境物品所有人 | 进出境货物与物品 | 从价/从量/复合/滑准 | 随货物进出口办理（海关征收） |
| **烟叶税** | 收购烟叶的单位 | 收购烟叶的金额 | 比例 | 按次或核定期限 |

## 🧠 记忆工具箱

### 口诀速记

- **资源税**：「**开采就交，原矿选矿分清楚，自用非生产视同卖**」；
- **环境税**：「**气水当量、固废吨、噪声分贝；低于标准减、综合利用免**」；
- **车购税**：「**购置一次征，已税不再征**」；
- **关税**：「**完税价格打底，四种税率形式，海关征收**」；
- **进口顺序**：「**先关税，再消费税与增值税，组成价格层层套**」；
- **小税种四问**：「**谁交、对什么征、怎么算、什么期限**」。

### 场景锚点

| 场景 | 你要做的判断 |
|------|-------------|
| 矿山开采原矿并对外销售 | 按**销售额**从价计征资源税；注意共伴生矿等减免 |
| 企业将开采的原矿自用于非生产项目 | **视同销售**，按同类售价或组成计税价格计税 |
| 工厂向大气排放污染物 | 按**污染当量数**计算环境保护税，关注低排放减征 |
| 企业购置一辆新能源汽车 | 判断是否属**减免范围**（**以现行规定为准**） |
| 进口一批应税消费品 | **先算关税**，再由完税价格 + 关税推出消费税与增值税的组成计税价格 |
| 噪声超标排放 | 按**超标分贝数**计征环境保护税 |

## ⚠️ 易错提醒

- **错误认知**：资源税对「使用」资源的行为征收。**纠正**：资源税对<strong>开采（生产）</strong>应税资源的行为征收，核心环节是**开采与生产**。
- **错误认知**：开采的矿产品自用一律不交资源税。**纠正**：用于**连续生产应税产品**的一般不纳税；用于**其他方面**的**视同销售**。
- **错误认知**：环境保护税对排放的一切污染物都按同一方式计征。**纠正**：**气、水按污染当量，固废按排放量，噪声按超标分贝**，三类口径完全不同。
- **错误认知**：车辆购置税每年都要交。**纠正**：车辆购置税在购置环节**一次性征收**，已税车辆不再征收。
- **错误认知**：关税完税价格就是发票上的成交价。**纠正**：完税价格以成交价格为基础，**需按规定调整**（运费、保险费等），**以现行规定为准**。
- **错误认知**：进口环节只交关税。**纠正**：进口应税货物通常同时涉及**关税、消费税（限应税消费品）与增值税**，且**组成计税价格层层递进**。

> ⚠️ 本章涉及的**税目范围、税率、减免幅度与征管程序一律以现行有效税收法规与当年度官方教材为准**。
