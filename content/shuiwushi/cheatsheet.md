> **用法**：考前 3 天起只过这一页 + 错题本。
> ⚠️ 下表是**判断结构与记忆提示**，**不写死任何税率数字**——具体税率、扣除比例与优惠幅度**一律以现行有效税收法规与当年度官方教材为准**；报考与成绩规则**以中国注册税务师协会当次公告为准**。

## 一、流转与资源环境类税种（税一主线）

| 税种 | 纳税人 | 征税范围（要点） | 税率形式 | 关键优惠（类型） | 纳税期限（一般口径） |
|------|--------|----------------|---------|----------------|-------------------|
| **增值税** | 在境内发生应税销售行为、进口货物的单位和个人 | 销售货物/劳务/服务/无形资产/不动产 + 进口；含**视同销售**情形 | **比例税率（多档）** + 征收率（简易计税） | 小规模与小微优惠、特定项目免税、农产品与软件等专项政策 | 按**固定期限**（月/季）申报缴纳；进口环节在海关缴纳 |
| **消费税** | 生产、委托加工、进口应税消费品的单位和个人（部分环节另定） | 特定**应税消费品**，主要在**生产/进口/委托加工**环节 | **从价、从量、复合**三种形式 | 出口退免税、特定成品油/小汽车等专项政策 | 随增值税申报期同步（**以现行规定为准**） |
| **附加税费（城建税、教育费附加、地方教育附加）** | 实际缴纳增值税、消费税的单位和个人 | 以**实缴的增值税与消费税税额**为计税依据 | **比例形式** | 小规模与小微减免、进口不征、出口不退（**以现行规定为准**） | 与主税同期限 |
| **烟叶税** | 收购烟叶的单位 | 收购烟叶的**收购金额** | **比例形式** | 优惠较少，关注收购环节口径 | 按收购行为发生地申报 |
| **资源税** | 在境内开采应税资源或生产盐的单位和个人 | 应税**矿产品与盐**（含部分水资源试点） | **比例**为主，部分**定额** | 共伴生矿、低品位矿、开采回采率等减免 | 按期限申报 |
| **环境保护税** | 直接向环境排放应税污染物的企业事业单位 | 大气、水、固体废物、噪声四类 | **定额税率（按污染当量/吨/超标分贝）** | 达标排放减征、综合利用免税等 | 按季申报（**以现行规定为准**） |
| **车辆购置税** | 购置应税车辆的单位和个人 | 购置（含进口、自产自用、受赠等）应税车辆 | **比例形式** | 新能源汽车等专项政策（**以现行规定为准**） | 按购置行为及时申报 |
| **关税** | 进出口货物的收发货人、进境物品所有人 | 准许进出境的货物与物品 | **从价/从量/复合/滑准**等形式 | 特定区域、特定用途的减免 | 海关征收，随货物进出口办理 |

> 记忆锚：**「增值税看链条、消费税看环节、附加税费看主税、资源环境看对象、车购关税看行为」**。

## 二、所得税类税种（税二主线）

| 税种 | 纳税人 | 征税范围（要点） | 税率形式 | 关键优惠（类型） | 纳税期限（一般口径） |
|------|--------|----------------|---------|----------------|-------------------|
| **企业所得税** | 居民企业 + 非居民企业（来源地规则） | 生产经营所得、其他所得，**居民企业承担全面纳税义务** | **比例形式**（一般与优惠档） | 小型微利、高新技术、研发费用加计、农林牧渔、环境保护与节能节水等 | **分月或分季预缴 + 年度汇算清缴** |
| **个人所得税** | 居民个人 + 非居民个人 | 工资薪金、劳务报酬、稿酬、特许权使用费**综合所得**；经营所得；各类分类所得 | **累进（综合与经营）+ 比例（分类）** | 基本减除费用、**专项扣除/专项附加扣除**、特定补贴津贴免税等 | 综合所得**按年汇算清缴**；其他按次/按月 |
| **土地增值税** | 转让国有土地使用权、地上建筑物及其附着物并取得收入的单位和个人 | 转让房地产的**增值额** | **超率累进形式** | 普通标准住宅等特定情形减免（**以现行规定为准**） | **先预缴、后清算**（项目制） |
| **国际税收（税二板块）** | 涉及跨境所得的居民与非居民 | 境外所得抵免、转让定价、受控外国企业等 | 与所得税规则配套 | 税收协定待遇 | 随所得税申报 |

> 记忆锚：**「企业所得税看五步结构，个人所得税看所得项目，土增看扣除与清算，国际税收看抵免与协定」**。

**企业所得税「五步结构」速记**：

```text
① 收入总额 → ② 减：不征税收入 + 免税收入 → ③ 减：各项扣除（含限额类）
→ ④ 减：弥补以前年度亏损 → ⑤ = 应纳税所得额 → × 适用税率 − 减免 − 抵免
会计利润 ≠ 应纳税所得额：差异通过「纳税调整」处理
```

## 三、财产与行为类税种（税二主线）

| 税种 | 纳税人 | 征税范围（要点） | 税率形式 | 关键优惠（类型） | 纳税期限（一般口径） |
|------|--------|----------------|---------|----------------|-------------------|
| **印花税** | 书立应税凭证、进行证券交易的单位和个人 | **应税凭证**（合同、产权转移书据、营业账簿等）+ 证券交易 | **比例**为主 + **定额**（部分凭证） | 小微与特定凭证减免（**以现行规定为准**） | 按季/按次申报（**以现行规定为准**） |
| **房产税** | 产权所有人、经营管理单位、承典人、代管人等 | **城市、县城、建制镇和工矿区**的房产 | **从价（按房产原值一次减除后余值）** 或 **从租（租金收入）** | 自用与出租的不同处理、特定用途免税 | 按年计算、分期缴纳 |
| **城镇土地使用税** | 使用应税土地的单位和个人 | 城市、县城、建制镇、工矿区范围内的土地 | **定额（按面积）** | 特定用地减免 | 按年计算、分期缴纳 |
| **耕地占用税** | 占用耕地建房或从事非农业建设的单位和个人 | 占用**耕地**的行为 | **定额（按面积）** | 特定项目减免 | 按占用行为申报 |
| **契税** | 承受土地、房屋权属的单位和个人 | 土地使用权/房屋所有权的**转移**（买卖、赠与、互换等） | **比例形式** | 婚姻、继承、特定住房等减免（**以现行规定为准**） | 办理权属登记前申报 |
| **车船税** | 车辆、船舶的所有人或管理人 | 依法应登记的车辆与船舶 | **定额（按辆/整备质量/净吨位）** | 新能源、公共交通等减免 | 按年申报，通常随交强险代收代缴 |

> 记忆锚：**「印花看凭证、房产看原值或租金、土地看面积、契税看承受、车船看登记」**。

## 四、涉税服务程序与征管（实务主线）

| 环节 | 关键动作与要点 |
|------|---------------|
| **税务登记与信息报告** | 设立、变更、注销登记；实名办税与信息确认（**以现行征管规定为准**） |
| **账簿与凭证管理** | 依法设置账簿、凭证保管期限、会计制度备案 |
| **发票管理** | 领用、开具、红冲与作废、进项凭证的合规性审核（**四流一致**：票流/货流/资金流/合同流） |
| **纳税申报与更正** | 按期申报、预缴与汇算清缴、更正申报与补充申报 |
| **税款征收与担保** | 税款征收方式、纳税担保、延期缴纳申请（**以现行规定为准**） |
| **税务检查** | 检查权限与程序、调取账簿资料、询问与取证、检查结论处理 |
| **税收保全与强制执行** | 适用情形、审批程序与救济途径（**以现行征管法及其实施细则为准**） |
| **争议解决** | **陈述申辩 → 听证 → 行政复议 → 行政诉讼**；注意**前置与期限规则**（**以现行法律规定为准**） |

## 五、涉税鉴证与税收筹划（实务主线）

| 主题 | 必记要点 |
|------|---------|
| **涉税鉴证基本要求** | 鉴证对象、鉴证标准、**证据充分适当**、独立性与保密要求 |
| **鉴证程序** | 业务承接与约定 → 计划 → 证据收集 → 复核 → **出具报告**（含三级复核与工作底稿） |
| **报告类型** | 鉴证报告与相关服务报告的区分；报告要素与责任划分（**以现行执业规范为准**） |
| **税收筹划方法** | 主体选择、业务模式安排、时点安排、优惠政策适用、交易架构设计 |
| **筹划合规边界** | **不得虚构业务、不得违反实质课税与反避税规则**；筹划必须建立在**真实业务**之上 |
| **筹划成果表达** | 方案 + 测算 + 依据 + 风险 + 备选方案（**依据引用现行有效文件**） |

## 六、涉税法律与财会（法律 + 财会主线）

| 主题 | 必记要点 |
|------|---------|
| **行政法基本原则** | 合法行政、合理行政、程序正当、信赖保护（**以现行法律规定为准**） |
| **税务行政处罚** | 处罚种类、**告知与陈述申辩**、听证适用条件、一事不再罚 |
| **行政复议** | 复议机关、申请期限、**复议与诉讼的衔接规则**（**期限以现行法律规定为准**） |
| **行政诉讼** | 受案范围、举证责任（**被告负举证责任**）、判决类型 |
| **民商法主干** | 合同的订立与效力、公司治理与出资、物权变动与担保、破产清偿顺序 |
| **涉税犯罪** | 逃税、虚开发票、骗取出口退税等罪名的构成要点（**以现行刑法规定为准**） |
| **会计要素与报表** | 资产/负债/所有者权益/收入/费用/利润；资产负债表、利润表、现金流量表的勾稽 |
| **税会差异** | 会计利润 → 纳税调整 → 应纳税所得额；暂时性差异与递延所得税 |
| **高频涉税账务** | 计提与缴纳流转税、附加税费、所得税；进项转出；视同销售的账务处理（**科目名称以当年度教材为准**） |

## 七、考前 10 分钟清单

```text
□ 五科滚动：连续 5 个考试年度内全部合格（以当次公告为准）
□ 增值税：应纳税额 = 销项 − 进项；三问「是不是应税行为 / 凭证合规吗 / 用途允许抵扣吗」
□ 消费税：生产、委托加工、进口三个主要环节；从价、从量、复合三种形式
□ 企业所得税：五步结构；限额类先看基数；不得扣除记类型
□ 个人所得税：综合所得按年汇算；专项附加扣除按条件核对
□ 土地增值税：先预缴后清算；扣除项目要齐全
□ 小税种：印花看凭证、房产看原值或租金、土地看面积、契税看承受
□ 征管程序：申报 → 检查 → 申辩/听证 → 复议 → 诉讼（期限记准）
□ 鉴证：证据充分适当 + 工作底稿 + 报告要素
□ 筹划：真实业务 + 现行依据 + 风险与备选方案
□ 主观题：写步骤、写公式、写依据；空题一定不得分
```

> ⚠️ **最终提醒**：本页为**记忆与判断结构**的速记，**不含也不替代任何具体税率数字**；**税率、优惠、征管与期限一律以现行有效税收法规与当年度官方教材为准**，**报考条件、时间与合格标准以中国注册税务师协会当次公告为准**。
