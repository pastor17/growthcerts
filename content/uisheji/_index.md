> UI 设计职业技能等级证书由**人社部**指导，**第三方评价机构**（**"1+X 证书"**或**"职业技能等级"**）组织。本站按"视觉设计 + 交互设计 + 前端基础 + 输出"四模块组织原创精讲与题库；**报名时间、科目安排与合格标准以评价机构当次公告为准**。

**四模块结构（示例口径）**：

| 模块 | 核心内容 | 形式 |
|------|---------|------|
| **视觉设计** | **PS/AI/Figma**（**"3 种软件"**）+ **设计原则**（**"对齐/对比/重复/亲密性"**） | **实操**（**"设计 1 个页面"**） |
| **交互设计** | **线框/原型/可用性**（**"3 种"**）+ **交互原则**（**"反馈/一致性/可逆"**） | **实操**（**"画 1 个原型"**） |
| **前端基础** | **HTML/CSS/响应式**（**"3 种"**） | **理论**（**"单选/判断"**） |
| **输出** | **格式/规范/平台**（**"PNG/JPEG/SVG/图标规范"**） | **理论**（**"单选/判断"**） |

**报名门槛（示例口径）**：

- **1 级（入门）**：**初中及以上文化**（**"零基础"**可报）；
- **2 级（中级）**：**1 级证书 + 1 年工作经验**（**或本科及以上**）；
- **3 级（高级）**：**2 级证书 + 2 年工作经验**（**或本科 + 2 年**）；
- 另有政治素质、身体健康等通用条件。

**证书与执业**：

- **职业技能等级证书**：**"水平类"**——**"加分项"**（**"简历/求职/职称/补贴"**）；
- **1 级**：**"入门"**（**"助理 UI 设计师"**）；
- **2 级**：**"中级"**（**"UI 设计师"**）；
- **3 级**：**"高级"**（**"资深 UI 设计师/交互设计师"**）；
- **无"准入"属性**（**"不是必须"**），但**"加分"**（**"求职/职称/补贴"**）。

**本站已上线内容**：视觉设计（PS/AI/Figma）+ 交互设计（线框/原型/可用性）+ 前端基础（HTML/CSS/响应式）+ 输出（格式/规范/平台）考点精讲；备考笔记与避坑清单。

> 为什么值得考：**数字媒体行业的"加分项"**——**"求职/职称/补贴"**；且与 [短视频剪辑](/duanshipin/) 形成"设计 + 剪辑"组合。详见 [证书百科](/uisheji/intro/)。
