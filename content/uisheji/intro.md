## 是什么

**UI 设计职业技能等级证书**是数字媒体行业的**就业技能认证**（**"水平类"**，**"加分"**），由**人社部**指导，**第三方评价机构**（**"1+X 证书"**或**"职业技能等级"**）组织。通过考试 = 获得**职业技能等级证书**（**1~3 级**），用于**简历/求职/职称/补贴**。

## 1~3 级区别（**"水平"**）

| 级别 | 名称 | 适合谁 | 典型岗位 |
|------|------|--------|---------|
| **1 级** | **入门** | **零基础/在校生** | **助理 UI 设计师** |
| **2 级** | **中级** | **1 年工作经验/本科** | **UI 设计师** |
| **3 级** | **高级** | **2 年工作经验/本科 + 2 年** | **资深 UI 设计师/交互设计师** |

> **记忆锚**：**"1 级入门，2 级中级，3 级高级"**（**"水平"**，**"加分"**）。

## 考什么（**"4 模块"**）

### 1 视觉设计（**"实操"**）

| 模块 | 核心内容 |
|------|---------|
| **软件** | **PS/AI/Figma**（**"3 种"**，**"任选 1 种"**） |
| **设计原则** | **对齐/对比/重复/亲密性**（**"4 种"**） |
| **实操** | **设计 1 个页面**（**"1~3 个屏幕"**） |

### 2 交互设计（**"实操"**）

| 模块 | 核心内容 |
|------|---------|
| **线框/原型/可用性** | **线框/原型/可用性测试**（**"3 种"**） |
| **交互原则** | **反馈/一致性/可逆**（**"3 种"**） |
| **实操** | **画 1 个原型**（**"1~3 个流程"**） |

### 3 前端基础（**"理论"**）

| 模块 | 核心内容 |
|------|---------|
| **HTML** | **标签/结构**（**"2 种"**） |
| **CSS** | **选择器/盒模型/布局**（**"3 种"**） |
| **响应式** | **媒体查询/弹性布局/网格**（**"3 种"**） |

### 4 输出（**"理论"**）

| 模块 | 核心内容 |
|------|---------|
| **格式** | **PNG/JPEG/SVG**（**"3 种"**） |
| **规范** | **图标规范/命名规范/切图规范**（**"3 种"**） |
| **平台** | **Web/App/小程序**（**"3 种"**） |

> **题型**：**实操**（**"视觉设计/交互设计"**）+ **理论**（**"单选/判断"**，**"前端基础/输出"**）。

## 含金量与难度（职场人决策参考）

| 维度 | 说明 |
|------|------|
| **岗位用途** | UI 设计师/交互设计师（**"互联网/游戏/金融"**） |
| **行业地位** | **水平类**（**"加分项"**）——**"不是必须"**，但**"加分"**（**"求职/职称/补贴"**） |
| **职称对应** | **职业技能等级**（**1~3 级**）可对应**技能等级**（**"1~5 级"**，**以当地为准**） |
| **个税与补贴** | **职业技能等级**（**"水平类"**）可申报**个税继续教育专项附加扣除**（**480 元/年，以税务规定为准**）；**部分地区有补贴**（**以当地为准**） |
| **难度评级** | ★★★☆☆（**"实操 + 理论"**，**"软件操作"**是核心） |
| **建议总学时** | **1 级**：**200~300 小时**；**2 级**：**300~500 小时**；**3 级**：**500~800 小时** |
| **主要难点** | **软件操作**（**"PS/AI/Figma"**）+ **设计原则**（**"对齐/对比/重复/亲密性"**） |
| **适合谁** | **在校生/转行者**（**"1 级"**）；**在职 UI 设计师**（**"2 级/3 级"**） |
| **建议先别考的情形** | 仅因"想转行"（**"软件操作"**是核心，**"零基础"**需 3~6 个月）；时间无法保证每周 10 小时以上 |
