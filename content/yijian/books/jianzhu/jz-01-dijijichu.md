## 考点梳理

### 1.1 土方与基坑工程

| 项目 | 要点 |
|------|------|
| 降水方式 | 集水明排（浅）、**轻型井点**（渗透系数小、降水深 3~6m）、喷射井点（8~20m）、管井（水量大） |
| 支护结构 | 排桩（悬臂/锚拉/内支撑）、**地下连续墙**（刚度大、兼作止水与主体结构）、土钉墙（非软土、深度一般 ≤12m）、SMW 工法桩（型钢可回收） |
| 放坡 | 土质均匀、地下水位低于基坑底、深度不大时优先；软土与高水位慎用 |
| 验槽 | 观察法 + **钎探**（钢钎 φ22~25、锤重 8~10 磅、落距 50~70cm）；不能验槽时应**在基底预留 200~300mm 土层待验** |
| 回填 | 分层夯实，每层厚度与压实系数按设计；**不得用淤泥、腐殖土、冻土**回填 |

### 1.2 地基处理（按"改、密、压、桩"归类）

- **换填**：软弱土换填灰土/砂石/素混凝土，处理浅层；
- **密实**：强夯（碎石土、低饱和粉土）、挤密桩（砂石桩、灰土桩）；
- **预压**：堆载预压、真空预压（软黏土、工期长）；
- **复合地基**：CFG 桩（水泥粉煤灰碎石桩）、水泥土搅拌桩——**桩与桩间土共同承担荷载**。

### 1.3 桩基础

- 预制桩：锤击（有挤土与噪声）、静力压桩（城区常用）；**桩尖达到设计标高后应做最终贯入度/标高双控**；
- 灌注桩：泥浆护壁成孔（正/反循环）、干作业（地下水位以上）、套管成孔；
- **桩身完整性检测**：低应变（普查）、高应变（承载力校核）、**声波透射**（大直径）、钻芯（取芯验证）；
- 后注浆：提高端阻与侧阻，**注浆量与压力双控**。

### 1.4 混凝土结构施工（案例高频）

**模板**
- 跨度 ≥4m 的梁板应**起拱**（设计无要求时按跨度的 **1/1000~3/1000**）；
- 拆模强度（设计无要求时，同条件养护试块）：

| 构件 | 跨度 | 底模拆除强度 |
|------|------|------------|
| 板 | ≤2m | ≥50% |
| 板 | >2~8m | ≥75% |
| 板/梁/拱 | >8m | **≥100%** |
| 悬臂构件 | 任意 | **≥100%** |
| 侧模 | — | 保证棱角不损坏即可拆 |

**钢筋**
- 连接：绑扎搭接、焊接（闪光对焊、电渣压力焊用于竖向）、机械连接（直螺纹，**接头百分率受控**）；
- 同一连接区段内接头面积百分率：受拉区不宜 >25%（绑扎搭接），机械连接 ≤50%；
- 箍筋弯钩、弯弧内直径按钢筋级别；**不得用气割割断或烘弯钢筋**。

**混凝土浇筑与养护**
- 自由倾落高度 **≤3m**，超过用串筒、溜槽、导管；
- 施工缝：柱留在梁底、梁板留在次梁跨中 1/3 范围内、墙留在门洞过梁跨中 1/3；
- 后浇带：按设计留设，**一般至少保留 28d**（或按设计），用微膨胀混凝土浇筑；
- 养护：普通硅酸盐水泥 **≥7d**；掺缓凝剂、有抗渗要求 **≥14d**；
- 大体积混凝土：**温控三指标**（入模温度、内外温差 ≤25℃、降温速率 ≤2℃/d），分层浇筑、埋设测温孔、蓄热或循环水冷却。

### 1.5 砌体与钢结构

- 砌筑：砖应提前 1~2d 浇水湿润；砂浆**随拌随用**（水泥砂浆 3h 内、混合砂浆 4h 内用完，气温 >30℃ 缩短）；水平灰缝砂浆饱满度 **≥80%**；
- 构造柱：与墙体**先砌墙后浇柱**，沿墙高每 500mm 设 2φ6 拉结筋；
- 钢结构：高强螺栓**初拧→复拧→终拧**，终拧应在初拧后 **24h 内**完成；**不得用气割扩孔**，扩孔可用铰刀（≤1.2 倍螺栓直径）；焊缝按等级做超声/射线检测；涂装前除锈等级按设计。

## 🧠 记忆工具箱

### 拆模强度口诀

**"二五、八七五、一百"**：跨度 ≤2m 取 50%，2~8m 取 75%，>8m 与悬臂取 100%。

### 降水方法选择（一句话判断）

- 基坑浅、水量小 → **集水明排**；
- 土渗透性差、要求降水深 → **轻型井点**；
- 深基坑、水量大 → **管井**。

### 混凝土养护天数口诀

**"普通七、抗渗十四"**；大体积温控记 **"入模、温差二五、降速二"**。

### 对比表：三类桩身完整性检测

| 方法 | 作用 | 特点 |
|------|------|------|
| 低应变 | 查缺陷位置 | 快速、普查、定类（Ⅰ~Ⅳ类） |
| 高应变 | 查缺陷 + 估承载力 | 需较大锤击能量 |
| 声波透射 | 大直径桩内部缺陷 | 需预埋声测管 |
| 钻芯 | 直接取芯验证 | 直观但有损，用于验证 |

## 🔍 深度精讲

### 深讲 1：基坑失稳的"三条路"与对应措施

基坑事故无非三种机理：

1. **强度不足**——支护结构强度/刚度不够 → 加大桩径、加密支撑、减小支撑竖向间距；
2. **渗流失稳**——流砂、管涌、突涌 → 加深止水帷幕、坑内降水、设置反压；
3. **变形超限**——周边地表沉降、管线位移 → 分层分块开挖、**先撑后挖**（支撑未形成不得下挖）、信息化监测（每日/按频率观测位移与水位）。

> 命题角度：给出"未按要求先撑后挖""降水井提前停抽""监测数据超警未停工"等描述，要求判断是否妥当并说明理由。

### 深讲 2：大体积混凝土裂缝控制的完整链条

**裂缝成因**：水泥水化热 → 内部温升 → 内外温差大 → 表面拉应力超限 → 表面裂缝；后期降温收缩 + 约束 → 贯穿裂缝。

**控制链**：选低热水泥 + 掺粉煤灰/矿粉 → 优化配合比（降低水化热）→ 控制入模温度（夏季骨料遮阳、加冰）→ 分层浇筑（每层 300~500mm）、斜面分层、及时二次抹压 → 保温保湿养护（覆盖）→ 埋测温孔**前 3d 每 2h 一次**（按方案），温差超标立即保温/降温 → 设置后浇带或跳仓法释放约束。

### 深讲 3：模板支撑体系与危大工程联动

模板支架属于典型危大工程：**搭设高度 ≥8m、跨度 ≥18m、施工总荷载 ≥15kN/m²、集中线荷载 ≥20kN/m** 之一即为"超过一定规模"，**须组织专家论证**。支架失稳的三个高发原因：立杆间距超方案、扫地杆/剪刀撑缺失、混凝土浇筑顺序不当（应从中部向两端对称浇筑，避免偏载）。拆模前必须留同条件试块并达到上表强度，**不得凭经验拆模**。

### 例题（带解析）

**例题 1**：某现浇钢筋混凝土梁跨度 9m，设计无特殊要求，其底模拆除时同条件试块强度至少应达到设计强度标准值的？
A. 50%　B. 75%　C. 90%　D. 100%
**答案 D**。解析：跨度 >8m 的梁底模拆除需混凝土强度 ≥100%；2~8m 为 75%，≤2m 为 50%，悬臂一律 100%。

**例题 2**：关于大体积混凝土温控的说法，正确的是？
A. 混凝土内外温差不宜大于 25℃　B. 养护期间可停止测温　C. 表面裂缝主要由降温收缩引起　D. 入模温度越高越好
**答案 A**。解析：内外温差 ≤25℃（另有降温速率 ≤2℃/d 的控制要求）；测温须贯穿养护期；表面裂缝多由内外温差引起的表面拉应力产生；入模温度应尽量降低以削减温升峰值。

## ⚠️ 易错提醒

- **"先撑后挖"是基坑铁律**：支撑未形成或未达强度即下挖属重大违规；
- 验槽**不能省略**，基底应预留 200~300mm 待验土层；
- 拆模强度看**跨度**而非构件重要性，悬臂一律 100%；
- 施工缝位置记"**柱留梁底、梁板留跨中 1/3**"，与后浇带（至少 28d）区分；
- 高强螺栓**不得气割扩孔**、终拧 24h 内完成；
- 桩身完整性检测的**低应变是普查**，不能直接得出承载力结论。
