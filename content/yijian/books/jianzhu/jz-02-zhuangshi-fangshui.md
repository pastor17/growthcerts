## 考点梳理

### 2.1 装饰装修工程

| 分项 | 关键控制点 |
|------|-----------|
| 抹灰 | 分层施工：**底层（粘结）→ 中层（找平）→ 面层（装饰）**；每层厚度不宜过厚，总厚度按设计；水泥砂浆不得抹在石灰砂浆层上 |
| 地面 | 基层清理→找平→面层；**空鼓率**控制（板块面层空鼓不超过总数的 5% 且单块不超过 1/4）；木地板含水率控制 |
| 吊顶 | 吊杆间距按设计（一般 ≤1200mm）、主龙骨起拱（短向跨度 **1/200~1/300**）、重型灯具不得挂在吊顶龙骨上 |
| 饰面板 | 石材干挂需做**后置埋件拉拔试验**；湿贴石材应做防碱背涂 |
| 门窗 | 三项物理性能：**抗风压、气密、水密**；外窗安装后做**淋水试验**；密封胶饱满连续 |

### 2.2 建筑幕墙（案例常考）

- 常用类型：框支承（明框/隐框/半隐框）、全玻、点支承、单元式；
- **预埋件**优先，后置埋件必须做**拉拔力现场试验**；
- **结构胶**：硅酮结构密封胶须有**相容性试验报告**与**剥离试验**，且**不得在现场打注结构胶**（隐框、全玻幕墙的结构胶应在**洁净的室内**打注）；
- **幕墙三性（或四性）试验**：抗风压、气密、水密（＋平面内变形），送检试件应包含典型单元；
- 防火与保温：层间**防火封堵**（岩棉等不燃材料），同一幕墙单元**不宜跨越两个防火分区**；
- 防雷：幕墙金属框架与主体防雷体系**可靠连接**。

### 2.3 防水工程

**屋面防水**
- 找坡：结构找坡 **≥3%**、材料找坡 **≥2%**；
- 卷材铺贴方向：坡度 <3% 时平行屋脊铺贴；3%~15% 可平行或垂直；>15% 或受振动时应**垂直屋脊**铺贴；
- 搭接：高聚物改性沥青卷材长边搭接 ≥80mm、短边 ≥100mm；**上下层卷材不得相互垂直铺贴**；
- 细石混凝土保护层应设**分格缝**（间距 ≤6m），并做**隔离层**；
- 排气屋面设排气道与排气孔，排气孔间距按设计。

**地下防水**
- 结构自防水：防水混凝土抗渗等级**不低于 P6**（按埋深确定），且**不得留施工冷缝**；
- 施工缝设**止水钢板/遇水膨胀止水条**；穿墙管设止水环；
- 外防外贴法、外防内贴法、**多道设防**原则（防水混凝土 + 卷材/涂料）。

**室内防水**
- 厕浴间、厨房等**蓄水试验 24h**（深度不小于 20mm）；
- 淋浴间墙面防水高度 **≥1800mm**，其他墙面**≥300mm**；门口做**止水坎**。

### 2.4 建筑节能与防火

- 外墙外保温系统：EPS 板（薄抹灰）、XPS、岩棉、保温装饰一体化板、无机保温砂浆；
- **防火隔离带**：外保温系统每层设置，高度**不小于 300mm**，采用不燃材料；
- 锚固件：塑料锚栓数量与抗拉承载力按设计，**抹面前基层应做界面处理**，玻纤网搭接 ≥50mm（按系统要求）；
- 门窗节能指标：**传热系数 K、遮阳系数 SC、气密性**；外窗与墙体洞口间隙用保温材料填塞并打密封胶；
- 严禁薄抹灰外保温系统使用 **B3 级**保温材料（材料燃烧性能等级应与建筑高度匹配）。

### 2.5 常用建筑材料（速查）

| 材料 | 关键指标 |
|------|---------|
| 水泥 | 初凝 **≥45min**，终凝 **≤10h**（硅酸盐）；**安定性**不合格即废品；不得受潮结块 |
| 钢筋 | 抗震结构用钢筋：**强屈比 ≥1.25**、**屈标比 ≤1.30**、最大力总延伸率 **≥9%** |
| 混凝土外加剂 | 减水剂（提高强度/和易性）、缓凝剂（大体积/夏季）、早强剂（冬期/抢工）、引气剂（抗冻） |
| 砂浆 | 砌筑砂浆强度以**标准养护 28d 试块**评定；试块一组 3 块 |
| 防水卷材 | 按材料类别控制搭接宽度与铺贴方向；进场复验项目包括拉力、延伸率、耐热性 |

## 🧠 记忆工具箱

### 防水高度口诀

**"厕浴蓄水一昼夜、淋浴一千八、其余三百整"**（24h / 1800mm / 300mm）。

### 找坡数字记"三二"

**结构找坡 3%、材料找坡 2%**；卷材垂直屋脊铺贴的门槛是**坡度 >15%**。

### 幕墙四性/结构胶一句话

**"风、气、水、变形"四性试验；结构胶"相容性 + 不在现场打"**。

### 保温防火三条

1. 每层**防火隔离带 ≥300mm**；
2. 材料燃烧性能与建筑高度匹配，**禁用 B3**；
3. 锚栓 + 玻纤网 + 界面处理，缺一不可。

## 🔍 深度精讲

### 深讲 1：为什么"上下层卷材不得相互垂直铺贴"

卷材防水的可靠度取决于**搭接缝的连续性与密封性**。若上下层垂直交叉，则上层卷材的接缝正好横跨下层卷材的接缝，形成"缝上缝"的**十字薄弱点**；一旦上层接缝渗漏，水会沿下层接缝直接贯通到结构层。因此规范要求上下层卷材应**平行铺贴并错开接缝**（错缝宽度按材料要求），把接缝压力分散。

### 深讲 2：幕墙渗漏的全链条排查（案例标准答法）

1. **设计**：未设泄水孔/等压腔、胶缝宽度不足、变形缝未处理；
2. **材料**：结构胶过期或相容性不合格、密封胶与基材不相容；
3. **加工**：结构胶在施工现场打注（洁净度、温湿度不达标）；
4. **安装**：预埋件偏位后未做有效后置锚固、胶缝未清理干净就注胶、防火封堵缺失；
5. **验收**：未做**淋水试验与三性试验**；
6. **整改**：重做胶缝前清除旧胶、做粘结性试验，补做三性试验并复检。

### 深讲 3：外保温系统的"三个界面"失效

外保温脱落事故多发生在三个界面：

- **基层与粘结层**：基层未清理、未做界面剂，粘结面积率不足（薄抹灰系统粘结面积率按系统要求，一般不小于 40%，涂料饰面）；
- **保温板与抹面层**：板面未打磨/未涂界面砂浆，玻纤网未压入抹面砂浆中；
- **抹面层与饰面层**：腻子与涂料不配套、柔性不足导致开裂。

**锚固是补救而非主力**：锚栓主要抵抗负风压与提供安全冗余，粘结才是长期受力主体，两者不可互相替代。

### 例题（带解析）

**例题 1**：关于屋面卷材铺贴，说法正确的是？
A. 坡度 20% 时可平行屋脊铺贴　B. 上下层卷材应相互垂直铺贴　C. 受振动屋面卷材应垂直屋脊铺贴　D. 搭接缝无需错开
**答案 C**。解析：坡度 >15% 或屋面受振动时，卷材应**垂直屋脊**铺贴以防下滑；上下层卷材**不得相互垂直**铺贴；接缝应错开。

**例题 2**：某工程隐框玻璃幕墙施工，下列做法正确的是？
A. 结构胶在施工现场露天打注　B. 使用前核查结构胶相容性试验报告　C. 后置埋件不做拉拔试验　D. 幕墙金属框架不与主体防雷连接
**答案 B**。解析：硅酮结构密封胶必须有相容性试验报告，且应在洁净室内打注（现场露天打注会因粉尘、湿度影响粘结）；后置埋件须做拉拔试验；幕墙框架须与主体防雷可靠连接。

**例题 3**：厕浴间防水完成后应做的检验是？
A. 淋水试验 2h　B. 蓄水试验 24h　C. 闭水试验 48h（深度 50mm）　D. 无需检验
**答案 B**。解析：厕浴间等有防水要求的楼地面，应采用**蓄水 24h**（蓄水深度不小于 20mm）检验；淋水试验用于外墙/幕墙。

## ⚠️ 易错提醒

- **幕墙结构胶不得在现场打注**，这是最常被考"不妥之处"的点；
- 找坡百分比易混：**结构 3%、材料 2%**；
- 卷材**垂直屋脊**的门槛是坡度 >15% 或受振动；
- 外保温**防火隔离带每层 ≥300mm**，与"每层楼板处封堵"不是一回事；
- 淋浴墙防水 **1800mm** 是常见数字题；蓄水试验 **24h** 不要写成 48h；
- 抗震钢筋三指标：强屈比 ≥1.25、屈标比 ≤1.30、最大力总延伸率 ≥9%——**屈标比是"≤"**，易反向记错。
