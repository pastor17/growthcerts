## 考点梳理

### 3.1 流水施工参数

| 类别 | 参数 | 说明 |
|------|------|------|
| 工艺参数 | 施工过程数 n、流水强度 | 按施工顺序划分 |
| 空间参数 | 施工段数 m、施工层数 | m 应满足 m ≥ n（保证连续作业） |
| 时间参数 | 流水节拍 t、流水步距 K、工期 T、间歇时间 | 核心是 K 的确定 |

**三种流水组织**

1. **等节拍（固定节拍）**：t 全相等，**K = t**，T = (m + n − 1)K + Σ间歇 − Σ搭接；
2. **成倍节拍（加快的成倍节拍）**：各过程 t 不等但成倍数，取**最大公约数 K**，专业工作队数 **bᵢ = tᵢ / K**，总专业队数 n′ = Σbᵢ，T = (m + n′ − 1)K + Σ间歇 − Σ搭接；
3. **无节奏（分别流水）**：用**累加数列错位相减取大差法**求各步距，再累加求工期。

### 3.2 网络计划

- **关键线路**：总持续时间最长的线路；关键工作总时差为 0（计划工期等于计算工期时）；
- **总时差 TF**：不影响**总工期**的前提下可利用的机动时间；
- **自由时差 FF**：不影响**紧后工作最早开始**的前提下可利用的机动时间；
- 关系：**TF ≥ FF ≥ 0**；当某工作 TF = FF 时，其拖延会立即影响紧后最早开始；
- 时标网络图：波形线表示**自由时差**，从起点到终点无波形线的通路即关键线路。

### 3.3 工期优化与赶工

- 优化思路：在关键线路上选择**赶工费用率最低**的工作压缩，同时保证：
  1. 压缩后仍为关键工作（否则关键线路转移，压缩无效）；
  2. **不得超过该工作的最短持续时间**（受质量、安全、资源限制）；
  3. 注意**平行关键线路**——若存在多条关键线路，须同时压缩各条上的工作，否则总工期不变。
- 赶工措施：增加资源（人/机）、组织搭接与平行作业、采用早强混凝土或调整工艺、夜间施工（须考虑扰民与安全）。

### 3.4 工期索赔（案例必考）

**索赔成立三条件**：① 事件责任**非承包方**；② 造成**实际工期/费用损失**；③ 在合同约定时限内（一般为**28d**）提出。

**关键规则**
- 事件发生在**非关键线路**上，且拖延天数 **≤ 该工作总时差**：**工期不索赔**（但可能索赔费用）；
- 拖延天数 **> 总时差**：可索赔工期 = **拖延天数 − 总时差**；
- 事件发生在关键线路上：可索赔工期 = 拖延天数（在未采取赶工的前提下）；
- **不可抗力**：工期顺延，费用按"**工程本身损害由发包人承担、施工方人员机械损失自担**、发包人要求赶工的费用由发包人承担"分担；
- 多个事件并发（共同延误）：应**分别分析各自对工期的影响**，不能简单叠加。

## 🧠 记忆工具箱

### 流水工期公式总卡

| 组织方式 | 流水步距 K | 工期 T |
|---------|-----------|--------|
| 等节拍 | K = t | (m + n − 1)K |
| 成倍节拍 | K = 各 t 的最大公约数 | (m + Σbᵢ − 1)K |
| 无节奏 | 累加数列错位相减取大差 | ΣK + 最后过程用时 |

> 口诀：**"等节拍直接乘、成倍先约再折队、无节奏错位相减取大差"**。

### 时差关系记一句

**"总时差管总工期，自由时差管下家"**；**TF ≥ FF** 恒成立。

### 索赔三步判

**"先看责任在谁、再看有无损失、后看是否超时差"**。

### 不可抗力费用分担口诀

**"工程归发包人、施工机具自己扛、工期顺延、赶工费发包给"**。

## 🔍 深度精讲

### 深讲 1：成倍节拍流水为什么能"加快"

成倍节拍的本质是**给节拍长的工作配多个专业队**分流，使每个施工段上该工作的实际占用时间缩短为 K（即最大公约数），从而让所有工作在同一节拍下同步推进。因此：

- 组织前提是**各节拍之间存在大于 1 的公约数**（如 2、4、6 → K = 2，b 分别为 1、2、3）；
- 专业队总数 n′ = Σbᵢ 取代了原来的 n；
- 工期公式中 (m + n′ − 1) 的 n′ 变大，**工期未必比等节拍短**——"加快"是相对**不组织流水（依次施工）**而言，属常考陷阱。

### 深讲 2：一道完整的工期索赔计算

**背景**：某工程网络计划，A（3d）→ B（5d）→ D（4d）为关键线路；C 工作持续时间 4d，总时差 3d，与 B 平行。施工中：发包人图纸延误导致 C 拖延 5d；同期遇不可抗力致 D 停工 2d。

**分析**：
1. C 拖延 5d > TF = 3d → 影响工期 5 − 3 = **2d**，且责任在发包人 → **工期索赔 2d 成立**，另可索赔停工费用；
2. D 在关键线路上，不可抗力致停工 2d → **工期顺延 2d**，但**施工方机械闲置损失自担**（不可抗力费用按前述规则分担）；
3. 若两事件影响**重叠**，最终顺延取二者影响的合理组合（不能简单相加），通常按"对总工期最不利的组合"确定，本题若独立影响则为 **4d**，需结合重叠判断。

> 答题时务必写出：事件 → 是否在关键线路/总时差 → 影响天数 → 结论（工期/费用能否索赔）。

### 深讲 3：网络图压缩的"三条红线"

压缩关键工作实际是一条**约束优化**：

- **红线一：不能压成非关键**——压缩量以关键工作总时差（或与新关键线路的差值）为限，否则另一条线路成为关键线路，总工期不再缩短；
- **红线二：不能低于最短持续时间**——时间-费用曲线在"最短持续时间"处终止，再压会增加大量直接费；
- **红线三：不能突破质量安全底线**——如混凝土养护时间、模板拆除强度、焊接工艺要求，属**不可压缩的技术间歇**。

因此标准答法是：**"选择关键线路上赶工费用率最低且未达最短持续时间的工作压缩，压缩后重新计算关键线路，反复迭代至目标工期。"**

### 例题（带解析）

**例题 1**：某工程分 4 个施工段，3 个施工过程，流水节拍均为 3d，无间歇与搭接，等节拍流水工期为？
A. 15d　B. 18d　C. 21d　D. 24d
**答案 B**。解析：T = (m + n − 1)K = (4 + 3 − 1) × 3 = 18d。

**例题 2**：某工程 3 个施工过程流水节拍分别为 2d、4d、6d，4 个施工段，组织成倍节拍流水，工期为？
A. 16d　B. 18d　C. 20d　D. 22d
**答案 B**。解析：K = 各节拍最大公约数 = 2d；专业队数 b 分别为 2/2 = 1、4/2 = 2、6/2 = 3，Σbᵢ = 6；T = (m + Σbᵢ − 1)K = (4 + 6 − 1) × 2 = **18d**。

**例题 3**：某非关键工作总时差 4d、自由时差 1d，因发包人原因拖延 3d，则承包人可索赔？
A. 工期 3d　B. 工期 0d、费用可索赔　C. 工期 2d　D. 工期与费用均不可索赔
**答案 B**。解析：拖延 3d ≤ 总时差 4d，不影响总工期，故**工期索赔不成立（0d）**；但责任在发包人且造成实际延误与损失，**费用可索赔**。

## ⚠️ 易错提醒

- **非关键工作拖延 ≤ 总时差 → 工期索赔为 0**，这是案例最高频失分点；
- 自由时差与总时差不要混用：判断能否索赔工期只认**总时差**；
- 成倍节拍中"加快"是相对于**依次施工**，不要误答"比等节拍工期短"；
- 无节奏流水求步距必须**错位相减后取大差**，取小或直接相加都会错；
- 多条关键线路压缩时**必须同时压缩各条线路上的工作**；
- 索赔提出时限一般为**28d**，且需有索赔意向通知与证据链。
