## 考点梳理

### 2.1 桩基础（钻孔灌注桩）

**成孔**
- 泥浆护壁：控制**泥浆比重、黏度、含砂率**，保持孔内水头压力高于地下水位以防塌孔；
- 成孔设备：正循环/反循环回转钻、旋挖钻、冲击钻（适用不同地层）；
- **成孔后应清孔**，检查孔深、孔径、垂直度、沉渣厚度，合格后方可下钢筋笼与导管。

**水下混凝土灌注（案例高频）**
- 采用**导管法**，导管使用前应做**水密承压与接头抗拉试验**；
- **首批混凝土数量**须满足导管**埋深不小于 1.0m**（一般控制在 **2~6m**）的要求，灌注过程导管**埋深保持 2~6m**；
- 混凝土应**连续灌注**，不得中断；灌注顶面应**超灌 0.5~1.0m**，凿除浮浆后保证桩顶质量；
- 严禁导管提出混凝土面造成**断桩**；坍落度按规范控制（一般 180~220mm）。

### 2.2 承台与墩台

- 承台：基坑开挖后**凿除桩头浮浆至密实混凝土**，桩头钢筋按设计锚入承台；大体积承台按大体积混凝土温控要求施工；
- 墩台：模板刚度与稳定性验算、混凝土分层浇筑、**墩台身与承台接缝处理**（凿毛、清理）；
- 高处作业与支架安全：脚手架、模板支架按危大工程要求编制专项方案，达超危大标准须**专家论证**。

### 2.3 预应力施工（核心）

**先张法与后张法**
- **先张法**：在台座上张拉预应力筋 → 浇筑混凝土 → 放张（需混凝土达到规定强度）；
- **后张法**：浇筑混凝土 → 穿预应力筋 → **张拉** → **孔道压浆** → 封锚。

**后张法张拉要点**
- 张拉时混凝土强度应达到**设计规定值**（设计无规定时按规范，一般不低于设计强度标准值的 75%，具体依规范与设计）；
- 张拉程序：**对称、分级张拉**（如 0 → 初应力 → 控制应力，持荷后锚固）；
- **张拉顺序**：对称于构件截面中心，先中间后两侧（按设计规定），避免偏心受力；
- **伸长值校核**：实际伸长值与理论伸长值偏差应控制在允许范围内（一般为**±6%**），超差应查明原因；
- **孔道压浆**：应在张拉后**尽快进行**（按规范时限），水泥浆强度、稠度符合要求，压浆**饱满密实**；压浆后按规定封锚；
- 切割预应力筋应用**砂轮锯**，不得用电弧焊切割。

### 2.4 上部结构施工方法

| 方法 | 适用与要点 |
|------|-----------|
| 支架法（满堂支架） | 适用于旱地、低墩、地基可处理；须验算地基承载力与支架稳定性，**预压消除非弹性变形** |
| 预制安装法 | 梁段预制、运输、架桥机/起重机吊装；注意吊点位置、临时支撑与体系转换 |
| 悬臂浇筑法 | 用**挂篮**对称平衡浇筑，逐段前移；控制**挠度与线形**、合龙顺序与温度（合龙宜在低温时段） |
| 顶推法 | 适用于连续梁，需设置临时墩与导梁 |
| 转体法 | 跨既有线路，减少对交通影响 |

### 2.5 支座、伸缩缝与桥面系

- **支座**：安装位置与标高准确、不得偏压、四角受力均匀；活动支座应考虑温度位移方向；
- **伸缩缝**：按气温与安装温度调整缝宽，**不得在高温或低温极限时随意安装**；伸缩缝与桥面平顺、无跳车；
- **桥面防水**：防水层施工前基面应干燥、洁净、平整；防水层与铺装层、混凝土基层**粘结可靠**，不得空鼓；
- **桥面排水**：泄水孔、排水管畅通，避免桥面渗水侵蚀结构；
- **荷载试验**：成桥后进行**静载与动载试验**，检验承载能力与工作状态。

**"导管埋深 2~6m、首批必须够、灌注不得断、超灌 0.5~1m 再凿除。"**

### 后张法流程链

**"浇混凝土 → 穿筋 → 张拉（对称分级）→ 伸长值校核（±6%）→ 压浆 → 封锚。"**

### 张拉顺序口诀

**"对称分级、先中间后两侧、不偏心。"**

### 上部结构方法速判

- 地基好、墩不高 → **满堂支架**；
- 有预制场、能吊装 → **预制安装**；
- 跨大河、跨深谷、跨既有线 → **悬臂浇筑 / 顶推 / 转体**。

### 桥面系三条

**"支座不偏压、伸缩缝看温度、防水层要干燥洁净。"**

## 🔍 深度精讲

### 深讲 1：为什么必须保证导管埋深 2~6m

导管法灌注水下混凝土靠的是**"导管内混凝土柱压力 > 孔内泥浆压力"**，形成连续下料与顶托。埋深过小（<1.0m 尤其危险）会导致：

- 泥浆返入导管 → **混凝土夹泥**；
- 导管脱空 → 混凝土面断流 → **断桩**（最严重质量事故，需重新成桩或采取补强措施）。

埋深过大（>6m 以上）则：

- 导管拔出阻力大，易造成**埋管事故**；
- 混凝土面上升顶托阻力增大，可能诱发孔壁坍塌或钢筋笼上浮。

因此规范要求首批混凝土满足埋深 ≥1.0m，灌注过程中**埋深控制在 2~6m**，并**随时测量混凝土面高度、及时拆卸导管**。

### 深讲 2：预应力"伸长值校核"为什么能发现问题

张拉时千斤顶的油压表读数反映**张拉力**，而实际伸长值反映**预应力筋的真实受力状态**。两者理论上有对应关系，若实际伸长值与理论值偏差超限（一般 ±6%），说明存在下列问题之一：

- 预应力筋**实际弹性模量或截面积**与取值不符（材料问题）；
- 孔道**摩阻损失**异常（孔道不顺直、有堵塞、偏差）；
- 张拉设备**未标定或标定过期**（千斤顶与油表应配套定期标定，一般不超过规定周期）；
- 预应力筋**滑丝、断丝**或锚具问题。

**处置**：暂停张拉、查明原因。若是设备与操作问题，重新标定后复张；若是材料或摩阻异常，须由设计确认处理方案。**严禁在偏差超限情况下直接锚固**。

### 深讲 3：悬臂浇筑的线形控制

悬臂浇筑的难点不是强度而是**线形（挠度）**：

- 每个梁段浇筑后，已浇段会因自重与预应力产生下挠，后续段需**设置预拱度**；
- 合龙时两侧挠度差与温度变化会引起**附加内力**，故**合龙宜在一天中温度较低且稳定时段**进行，并按设计规定的顺序（先边跨或先中跨）与配重方案施工；
- 施工中应对**挠度、应力、温度**进行监测，与理论值对比并动态调整立模标高；
- 体系转换（由悬臂状态转为连续梁状态）阶段是受力最不利时刻，须严格控制临时约束的解除顺序。

### 例题（带解析）

**例题 1**：钻孔灌注桩水下混凝土灌注过程中，导管埋置深度宜控制在？
A. 0.5~1.0m　B. 1.0~2.0m　C. 2~6m　D. 6~10m
**答案 C**。解析：首批混凝土应满足导管埋深不小于 1.0m，灌注过程中导管埋深宜控制在 2~6m；埋深过小易断桩、夹泥，过大易埋管。

**例题 2**：后张法预应力筋张拉时，实际伸长值与理论伸长值的偏差一般应控制在？
A. ±2%　B. ±6%　C. ±10%　D. ±15%
**答案 B**。解析：实际伸长值与理论伸长值的偏差一般应控制在 ±6% 以内，超出应暂停张拉、查明原因后方可继续。

**例题 3**：关于悬臂浇筑施工，说法正确的是？
A. 合龙宜在一天中温度最高时段进行
B. 合龙宜在一天中温度较低且稳定时段进行
C. 挂篮无需进行荷载试验与预压
D. 悬臂浇筑不需要进行线形监测
**答案 B**。解析：合龙宜在温度较低且稳定时段进行，以减少温度变化引起的附加内力；挂篮应进行预压与试验以消除非弹性变形；施工中须进行挠度（线形）、应力与温度监测。

## ⚠️ 易错提醒

- 水下混凝土导管埋深是 **2~6m**（首批 ≥1.0m），不要写成 1~3m；
- 灌注顶面应**超灌 0.5~1.0m** 并凿除浮浆，不能"浇到设计标高即停"；
- 后张法张拉**先中间后两侧、对称分级**，不许单向顺序张拉；
- 伸长值偏差 **±6%**，不是 ±10%；
- 压浆应在张拉后**尽快**进行，切割预应力筋用**砂轮锯**而非电弧焊；
- 合龙时段是**低温稳定时段**，不是高温时段；
- 满堂支架必须**预压**消除非弹性变形并验算地基承载力。
