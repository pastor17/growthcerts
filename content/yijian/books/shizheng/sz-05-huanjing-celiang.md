## 考点梳理

### 5.1 生活垃圾填埋场工程

**防渗系统（核心）**
- **HDPE 膜**为主防渗层（高密度聚乙烯土工膜），膜下设置**黏土/膨润土防水毯**等保护层，膜上设土工布保护层；
- 常见结构：单衬层、**双衬层**（中间设渗漏检测层）；
- 施工要点：**基层平整、无尖锐物**；膜焊接采用**双缝热熔焊**并做**充气检漏/真空检漏**；焊缝应做**剥离与剪切试验**（按规范抽样）；**不得在大风、雨雪天施工**，铺设后及时压载防风。

**渗滤液与填埋气**
- 渗滤液收集导排系统：**盲沟 + 穿孔管 + 集液池**，及时导排防止膜上水头过高；
- 填埋气（甲烷）导排：**导气井 + 导气管网 + 火炬/利用系统**，防止聚集爆炸（甲烷易燃易爆）；
- **封场**：终场覆盖（排气层、防渗层、排水层、植被层），并长期监测渗滤液与填埋气。

### 5.2 施工测量

- **平面控制**：导线测量（附合导线、闭合导线）、GPS 静态测量；
- **高程控制**：水准测量，水准点应设在稳定位置并定期复测；
- **施工放样**：中线与边线放样、标高控制（水准仪 + 塔尺）、构筑物轴线定位；
- **竣工测量**：管道中线、管底高程、检查井位置与井底高程、道路中线与高程；**竣工图**应反映实际施工情况（与设计不符处按实际标注）；
- 测量精度按规范等级执行，仪器应**检定合格且在有效期内**。

### 5.3 城市施工组织与环境管理

**交通导行**
- 编制交通导行方案并报**交通管理部门批准**；
- 分阶段布置：警告区、上游过渡区、缓冲区、作业区、下游过渡区、终止区；
- 设置围挡、警示标志、夜间照明与反光设施，必要时设专人疏导。

**地下管线保护**
- 施工前**查阅管线资料 + 现场坑探/物探**核实管线位置、埋深、材质；
- 制定保护或改移方案，重要管线（燃气、高压电力、给水干管）**约请产权单位到场监护**；
- 距管线一定范围内（按规范与产权单位要求）**禁止机械开挖，改用人工开挖**；
- 管线**悬吊加固**、暴露管线的支撑与警示。

**绿色施工与文明施工**
- 扬尘：洒水、覆盖、硬化、车辆冲洗、渣土密闭运输；
- 噪声：低噪声设备、隔声屏障、夜间施工审批与公告；
- 废水与泥浆：沉淀池处理、泥浆外运合规处置；
- 现场围挡、材料堆放、临时设施与卫生管理。

### 5.4 市政案例答题要点（总结）

市政案例的"得分骨架"通常是四层：

1. **程序合规**（导行审批、方案审批、专家论证、交底、验收）；
2. **技术措施**（先撑后挖、同步注浆、对称回填、分级张拉等）；
3. **环境与安全保护**（管线保护、监测预警、交通疏解、应急预案）；
4. **试验与验收**（各类功能性试验 + 检测数据）。

## 🔍 深度精讲

### 深讲 1：填埋场为什么把防渗层做到"双衬层 + 检漏"

垃圾渗滤液含有高浓度有机物、重金属与盐类，一旦渗入地下含水层，**污染几乎不可逆**。单层防渗的失效风险来自：

- 施工期机械损伤与焊缝缺陷；
- 运行期不均匀沉降拉裂；
- 尖锐物刺穿。

因此高标准填埋场采用**双衬层**结构，并在两层之间设**渗漏检测层**：一旦主防渗层出现渗漏，渗滤液会进入检测层被及时发现并收集，而不是直接进入地下水。这与"渗漏监测井"配合构成**"防 + 检 + 修"**的多重屏障。

### 深讲 2：为什么填埋气必须主动导排

垃圾中有机物厌氧分解产生**甲烷（CH₄）与二氧化碳**，甲烷的特性是：

- **易燃易爆**（爆炸极限约 5%~15%），在填埋体与周边建筑物内聚集可能引发爆炸；
- **温室效应强**；
- 会**迁移**（沿地层与管道向周边扩散），可能进入建筑物地下室积聚。

因此必须设置**导气井 + 管网 + 火炬/利用系统**主动抽排，并定期监测甲烷浓度；封场后仍需长期导排与监测。**案例中若出现"封场后停止导气""导气井被垃圾堵塞未清理"，均属重大隐患。**

### 深讲 3：市政工程"管线破坏"事故的标准答法

**背景**：某道路施工机械开挖时挖断燃气管道，造成燃气泄漏。

**标准答法**：
1. **定性**：属违章作业，违反地下管线保护规定；
2. **正确做法**：施工前应查阅并核实管线资料，采用物探/**坑探**确认位置与埋深；在管线保护范围内**禁止机械开挖，改人工开挖**，并对暴露管线**悬吊加固**；重要管线应约请**产权单位到场监护**；
3. **应急处置**：立即**停止作业、撤离人员、划定警戒区、严禁烟火**，通知燃气与消防部门抢险，禁止一切可能产生火花的作业（不得随意开关电闸）；
4. **后续整改**：完善管线保护专项方案与交底、设置标志桩与警示、加强机械操作人员教育、建立开工前管线交底制度；
5. **责任**：施工单位承担主要责任，依法赔偿损失并接受处罚。

## ⚠️ 易错提醒

- HDPE 膜焊缝必须做**检漏 + 抽样剥离剪切试验**，"焊完即用"是重大隐患；
- 填埋气导排的目的是**防爆**，封场后**不得停止**；
- 交通导行方案须**报交通管理部门批准**，不是自行决定；
- 管线保护范围内必须**人工开挖**并**悬吊加固**，不是"小心点挖"；
- 竣工测量须记录**管底高程、井位与井底高程**等实际数据；
- 燃气泄漏应急处置的第一条是**严禁烟火、撤离警戒**，不是马上用土回填。
