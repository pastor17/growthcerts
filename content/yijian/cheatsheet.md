## 三、必背口诀与对比表

- **组织结构**：线性一个头、职能多个头、矩阵两个头；
- **动态控制**：**分收比纠**；纠偏四措施：组织、管理、经济、技术；
- **风险应对**：威胁=规避/转移/减轻/接受/上报；机会=开拓/分享/提高/接受/上报；
- **索赔三条件**：责任非己方 + 有实际损失/工期影响 + 时限内提出；
- **工期索赔只看总时差**（拖延 − 总时差 = 可索赔天数）；**费用索赔看责任归属**——两者结论可不同；
- **不可抗力**：工程损害发包担、施工机具自承担、工期顺延、赶工费发包给、**利润不索赔**；
- **危大 vs 超危大**：基坑 3m / **5m**；模板支架高度 5m / **8m**、跨度 10m / **18m**、总荷载 10 / **15kN/m²**、集中线荷载 15 / **20kN/m**；落地脚手架 24m / **50m**；吊装单件 10kN / **100kN**；
- **专家论证**：施工单位组织、专家 **≥5 名**、**参建各方人员不得以专家身份参加**；
- **验收组织者**：检验批与分项=专业监理工程师；分部=总监理工程师；单位工程=建设单位项目负责人。

## 四、实务案例五类骨架（写不出就用这个）

```
① 指出不妥：判断 → 依据 → 正确做法 → 补充措施（监测/验收/交底/记录）
② 事故原因：直接原因（人的不安全行为 + 物的不安全状态）+ 间接原因（管理/培训/技术）
③ 工期索赔：是否关键线路 → 是否超总时差 → 影响天数 → 结论
④ 费用索赔：责任归属 → 可索赔项（人工/机械/材料/措施/管理费/利润）
⑤ 计算题：列已知量 → 代公式（如 EAC = BAC/CPI）→ 结论
```

**考场措辞**：多写不扣分；分点编号；写规范名称与要求内容（编号记不住就写规范名称）。
