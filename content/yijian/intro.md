## 是什么

**一级建造师**是建设工程领域的**全国性执业资格**，取得后可担任**大、中型**工程施工项目的项目负责人（项目经理），是全国执业范围（二级建造师为省级）。

考试科目四科：

- **《建设工程经济》**：资金时间价值、方案评价、财务分析、工程估价；
- **《建设工程法规及相关知识》**：法律体系、施工许可与发承包、合同、安全与质量法规；
- **《建设工程项目管理》**：成本、进度、质量、安全、合同、信息管理；
- **《专业工程管理与实务》**：10 个专业（建筑、市政、机电、公路、水利水电、矿业、通信与广电、民航机场、港口与航道、铁路），含案例分析。

## 证书价值（示例要点，请自行核实）

- **执业资格**：大中型项目负责人的必备资格，企业资质与投标的核心指标；
- **收入与晋升**：持证后岗位与薪酬通常显著提升；
- **增项与专业拓展**：可增项其他专业方向；
- **人才政策**：部分地区与人才认定、补贴相关（以当地政策为准）。

## 适合人群

- 工程类/工程经济类专业毕业、已有若干年施工管理经验的技术人员；
- 已取得二级建造师、希望提升执业范围与层级的从业者；
- 施工企业技术负责人、项目管理人员。

## 与二级建造师的区别（高频对比）

| 维度 | 一级建造师 | 二级建造师 |
|------|-----------|-----------|
| 执业范围 | **全国** | 本省（区、市） |
| 考试科目 | **4 科**（含《建设工程经济》） | 3 科 |
| 学历与年限门槛 | 大专满 4 年 / 本科满 3 年 / 硕士 2 年 / 博士 1 年（示例口径） | 一般中专以上 + 满 2 年（各省差异大） |
| 承担项目规模 | 大、中型项目 | 中、小型项目 |
| 难度 | 明显更高（含经济科目） | 相对基础 |

> ⚠️ 报名条件、免试政策与考试安排请以**中国人事考试网**与各省人事考试机构当次通知为准。

## 含金量与难度（职场人决策参考）

### 一、含金量：它能给你带来什么

| 维度 | 说明 |
|------|------|
| **岗位用途** | **大、中型工程项目负责人（项目经理）**；企业资质、投标与项目备案的**核心指标** |
| **招聘认可度** | 建筑/市政/机电等行业硬性需求高；持证人员常获岗位与薪酬倾斜 |
| **职称对应** | 多地一级建造师可对应**工程师**职称（以本省人社部门规定为准），可用于职称申报 |
| **个税与补贴** | 取得证书当年可按 **3600 元**申报继续教育专项附加扣除 |
| **落户/人才政策** | 部分省市对一级建造师有较明确的积分与人才政策（以当地为准） |
| **长期价值** | 全国执业、可增项专业；是工程管理职业路径的**天花板级证书之一** |
| **它的局限** | 报考条件严（学历 + 专业 + 年限）；实务案例分析难度高；需持续满足继续教育与注册要求 |

### 二、难度：需要投入多少

| 维度 | 评估 |
|------|------|
| **考试结构** | 四科：建设工程经济 + 法规 + 项目管理 + **专业工程管理与实务（10 个专业，含 5 道案例，占 120 分）** |
| **难度评级** | ★★★★★ — **难在实务**：案例题占 75%，且综合技术、管理、法规与合同索赔 |
| **合格标准** | 各科目按满分的 **60%** 相对固定（经济 100 分→60；法规/管理 130 分→78；实务 160 分→96，以官方通知为准） |
| **成绩管理** | 考全科者成绩**滚动管理（连续 2 个考试年度内通过全部科目）** |
| **建议总学时** | 约 **400~700 小时**（在职通常需 6~12 个月） |
| **主要难点** | ① 实务案例的场景化作答；② 四科并行的时间管理；③ 规范与数字极多（易混、易忘） |
| **考试频次** | 一年一次（2026 年 **9 月 12、13 日**；报名 6 月 17 日—7 月 12 日） |
| **适合谁** | 工程类/工程经济类专业毕业、有 3~5 年项目经验、想走项目经理路线者 |
| **建议先别考的情形** | 年限或专业不符（建议先考 [二级建造师](/erjian/) 同方向，边积累年限边学） |

### 三、一句话结论

> **工程领域的"高投入高回报"证书**：真正决定成败的是**实务案例**，公共课只解决"够不够用"，实务决定"过不过"。

> ⚠️ **关于数据的说明**：官方一般不公布统一通过率，上表「难度评级」与「建议学时」为本站依据考试结构、科目数与题型给出的**经验估计**，用于排期参考；**职称对应、补贴标准、落户积分等政策均以国家与你所在省份的最新规定为准**。
