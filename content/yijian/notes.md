## 一、本证该记什么（三类笔记）

### ① 公共课：数字卡 + 对比表

| 科目 | 只记三类内容 |
|------|------------|
| **建设工程经济** | 公式（资金时间价值、方案评价、盈亏平衡、造价构成）+ 适用条件 + 1 道手算例题 |
| **法规** | 期限与比例（"3 个月开工、2×3 延期、1 年核验、15 日备案、28 天索赔"）+ 责任主体 + 例外情形 |
| **项目管理** | 四控（成本/进度/质量/安全）的**抓手清单** + 组织结构与责任划分 + 挣值指标 |

### ② 实务（建筑工程 / 市政公用工程）：**工序链 + 参数卡**

实务笔记的核心不是抄规范，而是两条线：

- **工序链**：把每类工程写成箭头串（如"基础验收→垫铁→找正找平→二次灌浆→复测"、"先撑后挖→支撑加预应力→拆撑先换撑"）；
- **参数卡**：每个工序只记**可考的数字**（拆模强度 50/75/100%、导管埋深 2~6m、超灌 0.5~1.0m、管顶回填 500mm、张拉伸长值 ±6%、防火隔离带每层 ≥300mm）。

### ③ 案例笔记：**只记"答法"，不记题**

为每类设问准备固定骨架（这是实务提分最快的一招）：

| 设问 | 骨架 |
|------|------|
| 指出不妥之处 | 判断 → 依据 → 正确做法 → 补充措施（监测/验收/交底/记录） |
| 事故原因 | 直接原因（人的不安全行为 + 物的不安全状态）+ 间接原因（管理、培训、技术） |
| 工期索赔 | 关键线路/总时差 → 影响天数 → 结论（工期可/不可索赔） |
| 费用索赔 | 责任归属 → 可索赔项（人工/机械/材料/措施/管理费/利润） |
| 计算题 | 列已知量 → 代公式 → 结论（如 EAC = BAC/CPI） |

## 二、避坑清单（一建专属 10 条）

| # | 坑 | 正确做法 |
|---|----|---------|
| 1 | 年限/专业不符硬报 | 查官网**报考条件**与**专业对照表**（含本科、硕博版本），按**报名年度当年年底**算年限后再报 |
| 2 | 一次报四科但实务没时间 | 若只能保证 2~3 科，**优先保实务 + 一门公共课**（成绩滚动 2 年：连续 2 个考试年度内通过全部科目） |
| 3 | 公共课刷题过万、实务没动笔 | 实务**限时手写**，每类题型至少 3 道，练"写得出条数" |
| 4 | 只记规范编号不记内容 | 记"**结论 + 依据方向**"，编号记不住时写规范名称与要求内容也能得分 |
| 5 | 案例题只判断不写正确做法 | 每题至少"判断+依据+做法"三点，缺一项丢分 |
| 6 | 忽略**专业方向差异** | 建筑与市政的工序、参数、案例场景完全不同，**别混着背**（本站两本实务书分开编排） |
| 7 | 按老版本教材学规范 | 规范与教材每年更新，**以当年度教材与现行规范为准** |
| 8 | 不做整卷限时训练 | 实务考 4 小时（14:00–18:00），考前至少完整模拟 2 次 |
| 9 | 忽略签字与流程类考点 | 专项方案审核签字、专家论证（≥5 名专家、参建人员不得以专家身份参加）、隐蔽验收等是"送分点" |
| 10 | 考完公共课就丢开 | **实务要贯穿全年**：公共课与实务的知识点互相引用，分开学等于重复劳动 |

> **"公共课靠数字卡，实务靠工序链 + 案例骨架"**——一建的分水岭在实务案例，公共课只需要"够用"。
