> **先说结论**：建造师类考试（一建/二建）在 GitHub 上**开源资源极其稀少**（检索"一级建造师"多被无关高星仓库与境外广告仓库占据）。本站建议：**官方大纲 + 正版教材（中国建筑工业出版社）+ 中国人事考试网指定渠道**为主，开源仓库仅作参考。下载后请遵守作者说明，仅供个人学习。

## 已核验的可用资源

### 1. 一级建造师公共课题库（Android 应用源码）
- 仓库：[longchr123/YiJian](https://github.com/longchr123/YiJian) ｜ 核验：**20★ · 未标注许可证 · 最近更新 2016-06-26 · 约 6.8MB**
- 内含：一建公共课（**建设工程经济、项目管理、法规**）题库与讲解的移动端应用源码（README 说明为"全真讲解题库"）
- 适合：需要大量客观题练手的考生（可自行编译或在源码中查阅题库数据）
- 注意：**年份很早（2016）**，规范与教材已多次更新；无许可证仅个人学习；部分功能依赖旧版 Android 环境

### 2. 一建智能考试系统（大模型知识问答）
- 仓库：[HOYF/yijian_ai](https://github.com/HOYF/yijian_ai) ｜ 核验：**1★ · MIT 许可 · 最近更新 2026-03-13**
- 内含：基于大模型的一建考试系统（知识问答、真题趋势分析、私有知识库）
- 适合：对 AI 辅助学习/自建知识库感兴趣的考生；**MIT 许可**可用于学习与二次开发
- 注意：仓库规模小（星标低），内容完整度有限

> 检索说明：GitHub 对中文关键词"一建/建造师"的检索结果混杂大量无关仓库（编程教程、书籍合集、境外学历广告等），本页只收录**经人工核验确实相关**的仓库，宁缺毋滥。

## 官方与正版渠道（务必优先）

| 渠道 | 用途 |
|------|------|
| [中国人事考试网](https://www.cpta.com.cn) | **报名入口、报考条件、考试时间、成绩查询**（一建全国统一组织） |
| 各省人事考试网 | 本省报名通知、资格审核与证书发放 |
| 住房和城乡建设部 | 建造师执业资格制度、注册管理规定 |
| 中国建筑工业出版社正版教材 | 与当年度大纲对应的权威内容（法规与技术规范以现行版本为准） |

## 使用建议

1. **经济科目重在算**：资金时间价值、方案评价、盈亏平衡、造价构成必须动手算，仅"看题"无效；
2. **法规/管理与二建对照学**：本站二建《法规》《施工管理》精讲已上线，可作为一建公共课的基础；
3. **实务是主战场**：案例分析要求"定性 + 依据 + 措施"，需结合所选专业规范练习书写；
4. 开源资料多陈旧，**不能替代当年度正版教材与真题**。
