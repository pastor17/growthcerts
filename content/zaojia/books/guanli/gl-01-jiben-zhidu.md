## 考点梳理

### 1.1 工程造价的两种含义

**工程造价**在不同语境下有两种含义，这是本科目最基础也最容易混的一对概念：

| 含义 | 视角 | 指向 | 典型说法 |
|------|------|------|---------|
| **第一种含义** | **业主/投资者**视角 | 建设一项工程**预期或实际支付的全部固定资产投资费用** | "这个项目造价多少"＝总投资 |
| **第二种含义** | **市场交易**视角 | 工程**承发包价格**，即建设一项工程预计或实际在市场上形成的**建筑安装工程价格** | "这个工程中标价多少"＝合同价 |

> **一句话区分**：**投资者说造价＝总投资；承发包双方说造价＝合同价**。命题常在同一题干里切换视角，先判断"谁在说"。

**工程造价的四个特点**

| 特点 | 含义 |
|------|------|
| **大额性** | 单个项目造价动辄千万、上亿，对经济影响大 |
| **个别性与差异性** | 每项工程**地点、用途、结构、环境**不同，造价必须**单件计价** |
| **动态性** | 从估算到决算，造价随**设计深化、市场价格、法规变化**不断调整 |
| **层次性** | 由**分部分项 → 单位工程 → 单项工程 → 建设项目**逐层汇总 |

### 1.2 工程造价管理的组织与内容

**管理主体与分工（以现行规定为准）**

| 主体 | 主要职责 |
|------|---------|
| **政府主管部门** | 制定计价规则与标准、发布造价信息、监管执业行为与咨询企业 |
| **行业协会** | 行业自律、培训与交流、协助制定执业规范 |
| **建设单位（业主）** | 全过程造价控制的主体，确定目标成本、组织编审造价成果 |
| **设计单位** | 通过**限额设计**对造价形成源头影响 |
| **施工单位** | 投标报价、成本控制、变更与索赔管理 |
| **造价咨询企业** | 接受委托编制或审核造价成果文件，**对其成果质量负责** |

**造价管理的两项基本内容**

- **合理确定**造价：在**不同阶段**用不同精度的方法确定造价（估算 → 概算 → 预算 → 结算 → 决算）；
- **有效控制**造价：以**设计阶段为重点**，进行**主动控制与全过程控制**。

> **关键认知**：造价控制的关键在**设计阶段**——施工图一旦出完，可优化的空间就大幅收窄。这是本科目反复出现的判断点。

### 1.3 造价工程师执业资格与注册管理

**执业资格与执业的对应关系**

| 概念 | 含义 |
|------|------|
| **执业资格** | 通过全国统一考试取得的一级造价工程师资格（考试与注册管理规定**以现行有效规定为准**） |
| **注册** | 取得资格后须经**注册**方能以造价工程师名义执业；注册有**有效期**与**继续教育**要求 |
| **执业范围** | 工程造价文件的**编制与审核**、造价咨询、造价纠纷鉴定等（**以现行规定为准**） |
| **签字与盖章** | 注册造价工程师应当在**本人负责的工程造价成果文件**上签字并加盖执业印章，**对成果质量负责** |
| **继续教育** | 注册期内须按规定完成继续教育，**以现行规定为准** |

**造价咨询企业的管理要点**

| 事项 | 要点 |
|------|------|
| **资质/备案管理** | 按现行规定实行相应的资质或备案管理（**以现行规定为准**） |
| **成果文件质量** | 咨询企业对其出具的**工程造价成果文件的质量负责** |
| **签字要求** | 成果文件须由**注册造价工程师**签字盖章方可有效 |
| **法律责任** | **出借资质、允许他人以本企业名义承揽业务、出具虚假成果**等均属违规，须承担相应责任 |

### 1.4 工程造价成果文件与责任

**谁签字、谁负责**

```text
编制人（注册造价工程师）→ 签字并加盖执业印章 → 成果文件生效
        ↓
审核人（注册造价工程师）→ 签署审核意见
        ↓
咨询企业 → 对成果文件质量承担相应责任
```

**责任划分的三条线**

- **技术责任**：造价成果的**数据与结论**由签字人负责；
- **企业责任**：咨询企业对**成果文件质量**负责，出借资质等违规由企业担责；
- **法律责任**：**出具虚假造价成果、串通投标、允许他人以本人名义执业**等，依法依规承担相应责任。

> ⚠️ **必须强调**：**严禁证书挂靠**。把自己的证书注册到并不实际工作的单位，属于**违法违规**；社保联网后大数据比对使"人证分离"极易被发现，一旦造价文件出问题，**签字人与持证人都要担责**。请坚持**证随人走、到岗履职**。

### 1.5 工程造价的计价特征与阶段对应

| 阶段 | 造价文件 | 精度定位 | 主要依据 |
|------|---------|---------|---------|
| 决策阶段 | **投资估算** | 最粗，用于立项决策 | 估算指标、类似工程数据 |
| 设计阶段 | **设计概算** | 较粗，控制总投资的依据 | 概算定额/概算指标 |
| 设计阶段 | **施工图预算** | 较细，招标控制价的基础 | 预算定额、清单计价规范 |
| 交易阶段 | **合同价** | 确定，双方约定 | 招标文件、投标报价 |
| 施工阶段 | **结算价** | 实际发生，逐笔调整 | 合同、变更、签证 |
| 竣工阶段 | **决算** | 最终，含全部建设费用 | 结算 + 其他建设费用 |

> **记忆锚**：**"估概预结决"**——**精度越来越细、依据越来越具体、责任越来越明确**。

## 🧠 记忆工具箱

### 口诀速记

- **两种含义**：**"投资方看总投资（第一种），交易方看合同价（第二种）"**；
- **四个特点**：**"大、别、动、层"**——**大**额性、**别**（个别性与差异性）、**动**态性、**层**次性；
- **五阶段造价**：**"估概预结决"**；
- **控制重点**：**"控造价，抓设计；设计定，造价定"**；
- **责任链**：**"谁签字、谁负责；企业出资质、企业担责"**；
- **成果文件三要件**：**注册造价工程师签字 + 加盖执业印章 + 企业盖章**。

### 场景锚点

| 场景 | 该想到的考点 |
|------|------------|
| 业主开会说"这个项目造价 3 个亿" | **第一种含义**（固定资产投资/总投资） |
| 施工方说"我们中标价 8000 万" | **第二种含义**（承发包价格/合同价） |
| 领导问"还能不能压造价" | 控制重点在**设计阶段**，且要找**限额设计** |
| 一份造价成果文件要生效 | **注册造价工程师签字 + 执业印章**；编制人、审核人各负其责 |
| 有人提出"证书放我公司，不用来上班" | **挂靠——违法违规**，社保联网后基本被堵死，签字要担责；坚持**证随人走、到岗履职** |
| 项目各阶段造价数字不一致 | 正常：**估算 ≤ 概算 ≤ 预算**是控制逻辑（**超概要按程序处理**） |

## ⚠️ 易错提醒

- **错误认知**：工程造价只有一种含义。**纠正**：有**投资者视角的总投资**与**市场交易视角的承发包价格**两种含义，命题常在同一题中切换视角，先判断"谁在说"。
- **错误认知**：造价控制的重点在施工阶段。**纠正**：控制重点是**设计阶段**——设计一旦定型，优化空间大幅收窄；施工阶段主要是**执行与调整**。
- **错误认知**：考过试就可以直接以造价工程师名义执业。**纠正**：取得资格后须**注册**方可执业，并须满足**继续教育**等要求，**具体规定以现行有效规定为准**。
- **错误认知**：造价成果文件盖公司章就行。**纠正**：须由**注册造价工程师签字并加盖执业印章**，签字人**对成果质量负责**。
- **错误认知**：把证书注册到朋友公司"帮个忙"没关系。**纠正**：这是**挂靠，违法违规**；社保联网后极易被查出，造价文件一旦出问题，**签字人与持证人都要担责**——**证随人走、到岗履职**才是正路。
- **错误认知**：估算、概算、预算、结算、决算可以混着用。**纠正**：五者**阶段不同、精度不同、依据不同、作用不同**，估算用于决策、概算控总投资、预算作交易基础、结算反映实际、决算反映全部建设费用。
