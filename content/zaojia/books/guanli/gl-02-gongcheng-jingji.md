## 考点梳理

### 2.1 资金时间价值与现金流量

**资金时间价值**：资金在**时间推移中产生的增值**。同一笔资金在不同时点**价值不等**，因此**不同时点的金额不能直接相加**。

**现金流量三要素**

| 要素 | 含义 |
|------|------|
| **大小** | 现金流量的金额 |
| **方向** | **流入（CI）**为正、**流出（CO）**为负 |
| **时点** | 现金流量发生的**时刻**（默认发生在**期末**） |

> **画现金流量图是解题第一步**：横轴为时间，向上为流入、向下为流出，**时点标清楚**——很多错误源于时点错一格。

### 2.2 六个等值计算公式（必背）

| 名称 | 公式 | 已知 → 求 | 系数名 |
|------|------|----------|--------|
| 一次支付**终值** | F = P(1 + i)ⁿ | P → F | 一次支付终值系数 |
| 一次支付**现值** | P = F(1 + i)⁻ⁿ | F → P | 一次支付现值系数 |
| 等额**年金终值** | F = A[(1 + i)ⁿ − 1] / i | A → F | 年金终值系数 |
| **偿债基金** | A = F·i / [(1 + i)ⁿ − 1] | F → A | 偿债基金系数 |
| 等额**年金现值** | P = A[(1 + i)ⁿ − 1] / [i(1 + i)ⁿ] | A → P | 年金现值系数 |
| **资金回收** | A = P·i(1 + i)ⁿ / [(1 + i)ⁿ − 1] | P → A | 资金回收系数 |

其中：**P** 现值、**F** 终值、**A** 年金、**i** 利率（折现率）、**n** 计息期数。

**六个公式的关系（只需记两个）**

```text
记两个母公式：
  ① F = P(1 + i)ⁿ
  ② F = A[(1 + i)ⁿ − 1] / i

其余四个都是"解方程"或"取倒数"得到的：
  现值 P = F(1 + i)⁻ⁿ            ← 由 ① 反解
  偿债基金 A = F ÷ 年金终值系数   ← 由 ② 反解
  年金现值 P = A × 年金现值系数   ← 由 ② 与 ① 组合
  资金回收 A = P ÷ 年金现值系数   ← 由上式反解
```

### 2.3 名义利率与实际利率

| 概念 | 含义 | 公式 |
|------|------|------|
| **名义利率 r** | 按年给出的利率，**未考虑年内计息** | — |
| **实际利率 i** | 考虑**年内复利**后的真实年利率 | **i = (1 + r/m)ᵐ − 1** |
| **计息期利率** | 每个计息周期的利率 | r / m（m 为**年计息次数**） |

> **判断要点**：**只有"年"计息一次时，名义利率 = 实际利率**；计息次数越多，实际利率越高（**m → ∞ 时为连续复利 eʳ − 1**）。

### 2.4 经济效果评价指标

| 指标 | 计算/含义 | 判据 | 特点 |
|------|----------|------|------|
| **净现值 NPV** | NPV = Σ(CI − CO)ₜ(1 + i)⁻ᵗ | **NPV ≥ 0** 可行 | 反映**超额收益现值**；受折现率影响 |
| **内部收益率 IRR** | 使 NPV = 0 的折现率 | **IRR ≥ 基准折现率**可行 | **不依赖外部折现率**，反映项目自身盈利能力 |
| **净年值 NAV** | 把 NPV 折算为等额年金 | **NAV ≥ 0** 可行 | **寿命期不同的方案比选**用它 |
| **静态投资回收期** | 累计净现金流量**首次 ≥ 0** 的时点 | 越短越好，与基准比较 | 不考虑资金时间价值，**粗略** |
| **动态投资回收期** | 用**折现后**累计净现金流量计算 | 同上 | 考虑时间价值，**长于静态** |
| **总投资收益率 / 资本金净利润率** | 收益 ÷ 投资 | 与行业基准比较 | 反映盈利水平 |

### 2.5 方案比选与价值工程

**互斥方案比选的三条常用方法**

| 情况 | 方法 |
|------|------|
| **寿命期相同** | 比较 **NPV**（或费用现值 PC），选最大（或费用最小） |
| **寿命期不同** | 比较 **NAV / 年值**（或费用年值 AC），**不能直接比 NPV** |
| **仅有费用流** | 比较 **费用现值 PC / 费用年值 AC**，选**最小** |

**价值工程**

- **价值 V = 功能 F / 成本 C**——提高价值的五条途径：

| 途径 | 功能 F | 成本 C |
|------|--------|--------|
| ① 功能提高、成本不变 | ↑ | — |
| ② 功能不变、成本降低 | — | ↓ |
| ③ 功能提高、成本降低 | ↑ | ↓ |
| ④ 功能大幅提高、成本小幅提高 | ↑↑ | ↑ |
| ⑤ 功能小幅降低、成本大幅降低 | ↓ | ↓↓ |

- **工作程序**：选择对象 → 功能分析（功能定义与整理）→ 功能评价（求功能评价值与价值系数）→ 方案创造 → 方案评价与实施。

## 🧠 记忆工具箱

### 口诀速记

- **六公式**：**"终值往前滚，现值往回缩；年金要摊平，回收是反算"**；
- **只需背两个**：**F = P(1+i)ⁿ** 与 **F = A[(1+i)ⁿ−1]/i**；
- **名义与实际**：**"一年多计息，实际必高于名义；一年计一次，两者才相等"**；
- **指标判据**：**"NPV 大于零、IRR 超基准、回收期越短越好"**；
- **方案比选**：**"寿命相同比现值，寿命不同比年值，只花不比就选费用小"**；
- **价值工程五途径**：**"功升本不变、功不变本降、功升本降、功大升本小升、功小降本大降"**；
- **价值公式**：**"价值 = 功能 ÷ 成本"**。

### 场景锚点

| 场景 | 该想到的考点 |
|------|------------|
| 老板问"这笔钱现在付还是分 5 年付" | **资金时间价值**——把两种方式折到**同一时点**比较 |
| 银行说"年利率 12%，按月计息" | 名义 12%，**实际 = (1+1%)¹² − 1 > 12%** |
| 两个方案，一个能用 5 年、一个能用 8 年 | **寿命期不同 → 用 NAV/年值比较**，不能直接比 NPV |
| 设备更新决策：旧设备继续用还是换新 | 比较**费用年值 AC**，注意旧设备**沉没成本不参与** |
| 方案评审会上有人主张"功能越多越好" | **价值工程**：功能要**与成本匹配**，V = F/C |
| 项目评审要一个"不依赖外部折现率"的指标 | **IRR** |

## ⚠️ 易错提醒

- **错误认知**：不同时点的钱可以直接相加。**纠正**：必须**先折算到同一时点**（现值或终值）再比较，这是工程经济全部计算的前提。
- **错误认知**：名义利率就是实际利率。**纠正**：只有**一年计息一次**时二者相等；年内多次计息时 **i = (1 + r/m)ᵐ − 1 > r**。
- **错误认知**：寿命期不同的方案直接比 NPV。**纠正**：NPV 受寿命期长短影响，**寿命期不同应用净年值（NAV）或费用年值（AC）比较**。
- **错误认知**：回收期短就一定优于回收期长的方案。**纠正**：回收期**不考虑回收期之后的收益**，也（静态口径下）不考虑资金时间价值，**只能作辅助指标**。
- **错误认知**：IRR 越大方案一定越优。**纠正**：IRR 是**相对指标**，**互斥方案比选应以 NPV（或 NAV）为准**；且 IRR 在现金流多次变号时可能**不唯一**。
- **错误认知**：旧设备的原值要计入继续使用的成本。**纠正**：旧设备**原值属沉没成本，不参与**更新决策；应比较**继续使用的费用年值**与**新设备的费用年值**。
