## 考点梳理

### 3.1 项目资本金制度与融资方式

**项目资本金**

- **含义**：投资项目**总投资中由投资者认缴的出资额**，是**非债务性资金**，项目法人**不承担这部分资金的还本付息责任**；
- **作用**：作为项目融资的**信用基础**，降低债权人风险；
- **比例与来源**：具体比例与来源要求**以现行有效规定为准**（不同行业可能有不同要求）。

**两类融资方式对比**

| 维度 | **权益融资（资本金融资）** | **债务融资** |
|------|------------------------|------------|
| 资金性质 | 非债务性资金，无需还本付息 | 需**还本付息** |
| 常见方式 | 股东出资、发行股票、政府投资 | 银行贷款、债券、融资租赁、国外贷款 |
| 资金成本 | 通常**较高**，且**股利不能税前扣除** | 通常**较低**，且**利息可税前扣除** |
| 风险承担 | 投资者承担经营风险 | 债权人优先受偿 |
| 对控制权影响 | **可能稀释控制权** | 一般不稀释控制权 |

**资金成本**

```text
资金成本 = 资金占用费 + 资金筹集费
资金成本率 = 资金占用费 / (筹资金额 − 资金筹集费)
```

> **债务资金成本低于权益资金成本**的根本原因：**利息可在所得税前扣除**，而股利不能。

**资本结构决策的常用方法**

- **比较资金成本法**：选**加权平均资金成本最低**的方案；
- **每股收益无差别点法**：找到两种融资方式**每股收益相等**的收益水平，再据预计收益判断；
- **公司价值分析法**：以**公司价值最大**为目标。

### 3.2 建设工程合同类型与选择

**按计价方式划分的三种合同**

| 合同类型 | 计价依据 | 风险归属 | 适用情形 |
|---------|---------|---------|---------|
| **总价合同** | 以**总价**结算（固定总价/可调总价） | **固定总价**下**承包人**承担价格与工程量风险 | 工程量明确、设计深度够、工期较短 |
| **单价合同** | 按**实际完成工程量 × 单价**结算 | **工程量风险由发包人**承担，**单价风险由承包人**承担 | 工程量大、工程量不确定（**最常见**） |
| **成本加酬金合同** | 按**实际成本 + 约定酬金** | **发包人**承担绝大部分风险 | 工程内容不确定、紧急工程、新型项目 |

> **选择逻辑**：**工程量越不确定 → 越靠近成本加酬金；工程量越确定 → 越可采用总价合同**。

**合同文件的优先解释顺序（一般口径，以合同约定为准）**

```text
合同协议书 → 中标通知书 → 投标函及其附录 → 专用合同条款
→ 通用合同条款 → 技术标准和要求 → 图纸 → 已标价工程量清单 → 其他
```

> **要点**：**专用条款优先于通用条款**；**已标价工程量清单在图纸之后**——这是争议判定的关键顺序（**以合同实际约定与现行示范文本为准**）。

### 3.3 招标投标程序与时限

**主要程序**

```text
招标（公开招标 / 邀请招标）
  → 编制招标文件与招标控制价
  → 发布招标公告 / 发出投标邀请书
  → 发售招标文件、组织踏勘与答疑（澄清、修改）
  → 投标人编制并递交投标文件（含投标保证金）
  → 开标（公开进行）
  → 评标（评标委员会）
  → 中标候选人公示 → 确定中标人 → 发出中标通知书
  → 签订合同（同时提交履约担保、退还投标保证金）
```

**关键时限（法定口径，现行法律法规为准）**

| 事项 | 时限 |
|------|------|
| 招标文件开始发出 → 投标截止 | **最短不得少于 20 日** |
| 招标文件澄清/修改（影响投标文件编制的） | 一般在**投标截止时间前 15 日**发出（**以现行规定为准**） |
| 中标候选人公示 | **不少于 3 日** |
| 中标通知书发出 → 签订合同 | 一般在**30 日内**（**以现行规定为准**） |
| 投标有效期 | 由招标文件规定，从**投标截止**起算 |

**评标方法**

| 方法 | 要点 | 适用 |
|------|------|------|
| **经评审的最低投标价法** | 在**满足招标文件实质性要求**的前提下，选**评标价最低**者 | 技术含量不高、标准化程度高 |
| **综合评估法** | 按**技术、商务、价格**等综合打分，得分最高者中标 | 技术复杂、需综合评价 |

**废标/否决投标的常见情形**

- 投标文件**未按要求密封、签署、盖章**；
- **未按招标文件要求提交投标保证金**；
- **不满足招标文件的实质性要求**（资质、业绩、工期、质量、技术标准）；
- 投标人**串通投标、以他人名义投标或以其他方式弄虚作假**；
- 报价**低于成本**且不能合理说明（**以现行规定为准**）。

> ⚠️ **串通投标、挂靠投标都是违法行为**——不仅投标无效，还可能被追究法律责任。

### 3.4 合同履行、变更与违约责任

| 事项 | 要点 |
|------|------|
| **履约担保** | 中标人提交，形式与金额**以招标文件与现行规定为准** |
| **合同变更** | 需**双方协商一致**并**书面确认**，涉及价款与工期按约定调整 |
| **违约责任** | 继续履行、采取补救措施、赔偿损失、支付违约金/定金（**按合同约定与法律规定**） |
| **不可抗力** | 一般**各自承担各自损失、工期相应顺延**（**以合同约定与法律规定为准**） |
| **争议解决** | 协商 → 调解 → **仲裁或诉讼**（**二者不能同时约定**） |

**不可抗力的费用分担（常见口径，以合同约定为准）**

| 损失类型 | 承担方（常见口径） |
|---------|-----------------|
| 工程本身损害、第三方人员伤亡与财产损失、运至现场的材料设备损害 | **发包人** |
| 承包人的施工机械设备损坏 | **承包人** |
| 停工损失 | **承包人**（部分口径下由发包人承担部分，**以合同约定为准**） |
| 照管工程的费用增加 | **发包人** |
| 工期 | **相应顺延** |

## 🧠 记忆工具箱

### 口诀速记

- **资本金**：**"资本金是非债务，不还本、不付息"**；
- **资金成本**：**"债务利息能抵税，所以债务成本低"**；
- **三种合同**：**"量确定用总价，量不定用单价，量都没定用成本加酬金"**；
- **风险归属**：**"固定总价，承包人扛；单价合同，量归发包人；成本加酬金，发包人全扛"**；
- **招投标时限**：**"二十日投标准备、三日公示、三十日签约"**；
- **评标方法**：**"技术简单看最低价，技术复杂打综合分"**；
- **文件顺序**：**"协议书、通知书、投标函、专用条款、通用条款、技术要求、图纸、清单"**；
- **争议解决**：**"仲裁与诉讼，只能选一个"**。

### 场景锚点

| 场景 | 该想到的考点 |
|------|------------|
| 老板问"这个项目拿银行贷款还是找股东增资" | **债务资金成本低（利息抵税）**，但要考虑**财务风险与控制权** |
| 图纸不全、工程量说不清，要签合同 | 选**单价合同**或**成本加酬金合同**，别签固定总价 |
| 招标文件发出后 10 天就要求投标截止 | **违反最短 20 日的规定**（**以现行法律法规为准**） |
| 中标结果刚出就有人质疑 | 关注**中标候选人公示不少于 3 日**的程序要求 |
| 合同里同时约定了仲裁和诉讼 | ⚠️ **只能选一种**，同时约定会导致条款效力争议 |
| 施工中现场被洪水淹了，问损失谁承担 | **不可抗力**：工期顺延，**各自损失各自承担**（具体**以合同约定为准**） |
| 有人提出"用某公司的资质投标，给点管理费" | ❌ **挂靠投标违法**，投标无效还可能被追责 |

## ⚠️ 易错提醒

- **错误认知**：项目资本金就是借来的钱；权益融资一定比债务融资便宜。**纠正**：资本金是**投资者认缴的非债务性资金**，项目法人**不承担还本付息责任**；借来的钱属于债务融资。；**债务资金成本通常更低**，因为**利息可税前扣除**而股利不能；但债务会提高财务风险。
- **错误认知**：固定总价合同对承包人最有利。**纠正**：固定总价下**价格与工程量风险主要由承包人承担**，工程量或价格波动大时**对承包人风险很高**。
- **错误认知**：专用合同条款和通用条款冲突时，按通用条款执行。**纠正**：**专用条款优先于通用条款**，这是合同解释的基本规则。
- **错误认知**：招标可以随时缩短投标准备时间。**纠正**：自招标文件开始发出之日起至投标截止**最短不得少于 20 日**（**以现行法律法规为准**），压缩时限可能影响招标效力。
- **错误认知**：争议解决条款可以既约定仲裁又约定诉讼。**纠正**：**仲裁与诉讼只能选择其一**；同时约定会使条款陷入争议，通常按法律规定处理。
- **错误认知**：借别人的资质投标只是"行业惯例"。**纠正**：**挂靠投标属违法行为**，会导致投标无效并可能被追究责任——与**证书挂靠**同理，都是违法违规的高风险行为。
