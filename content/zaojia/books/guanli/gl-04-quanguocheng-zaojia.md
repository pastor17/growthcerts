## 考点梳理

### 4.1 全过程造价管理的五个阶段

| 阶段 | 造价文件 | 核心任务 | 控制要点 |
|------|---------|---------|---------|
| **决策阶段** | **投资估算** | 判断项目**该不该上** | 估算精度直接影响决策质量 |
| **设计阶段** | **设计概算、施工图预算** | **限额设计**，把总投资分解到专业与单位工程 | **控制造价的关键阶段** |
| **招投标阶段** | **招标控制价、投标报价、合同价** | 通过市场竞争**形成合同价** | 清单完整、特征清楚、程序合规 |
| **施工阶段** | **结算价（动态）** | 执行合同、处理变更签证索赔 | **过程留痕 + 动态台账** |
| **竣工阶段** | **竣工结算、竣工决算** | 结清价款、核定**全部建设费用** | 结算审核、决算反映实际投资 |

> **关键认知**：**设计阶段是造价控制的关键**——决策阶段决定"要不要做"，设计阶段决定"花多少钱做"，施工阶段主要是"按约定执行与调整"。

### 4.2 决策阶段：投资估算

**投资估算的编制方法（按精度与资料条件选择）**

| 方法 | 思路 | 适用 |
|------|------|------|
| **生产能力指数法** | 依据**生产能力比值**与指数关系估算 | 已建类似项目数据充分 |
| **比例估算法** | 以**主要设备费**为基数按比例推算 | 设备投资占比高的项目 |
| **系数估算法（朗格系数法）** | 以**主体工程费/设备费**乘系数推算 | 快速匡算 |
| **指标估算法** | 按**估算指标 × 工程量/规模**估算 | 常用，精度相对较好 |
| **类似工程预算法** | 类比已建工程并调整差异 | 有类似工程资料 |

**建设投资构成与建设期利息**

```text
建设投资 = 工程费用 + 工程建设其他费用 + 预备费
  ├ 工程费用 = 建筑安装工程费 + 设备及工器具购置费
  ├ 工程建设其他费用（土地、建设管理、勘察设计、联合试运转等）
  └ 预备费 = 基本预备费 + 价差预备费
建设项目总投资 = 建设投资 + 建设期利息 + 流动资金
```

**建设期利息（分年计算，当年借款取一半）**

```text
当年应计利息 = (年初借款本息累计 + 当年借款额 ÷ 2) × 年利率
各年利息相加 = 建设期利息合计
```

> **易错点**：当年借款**只计一半利息**（视为年中均匀借入），这是分年计算的核心，也是案例题高频陷阱。

### 4.3 设计阶段：限额设计与设计优化

**限额设计**

- **含义**：按批准的**设计任务书与投资估算**控制初步设计，按批准的**初步设计总概算**控制施工图设计，同时**各专业按分配的投资额控制设计**；
- **两条主线**：**纵向**（估算控概算、概算控预算）＋**横向**（各专业按限额分解控制）；
- **关键**：限额设计**不是一味压低造价**，而是在**功能满足的前提下**控制投资——与**价值工程**目标一致。

**设计阶段造价管理要点**

| 要点 | 说明 |
|------|------|
| **推行限额设计** | 从估算到概算再到预算**层层控制** |
| **标准化设计** | 采用标准图与通用设计，降低造价与周期 |
| **设计方案优化** | 用**价值工程**分析功能与成本 |
| **概算审查** | 审查概算的**完整性、准确性、合规性** |
| **超概算的处理** | 一般需**按规定程序报批**，不得擅自突破（**以现行规定为准**） |

### 4.4 招投标阶段：从清单到合同价

| 环节 | 成果 | 要点 |
|------|------|------|
| 编制**招标控制价** | 招标控制价 | 依据清单、计价规范、造价信息与市场价格；**不得随意上调或下调** |
| 编制**投标报价** | 投标报价 | 自主报价，但**不得低于成本**（**以现行规定为准**） |
| 开标评标 | 中标候选人 | 程序合规，评标方法按招标文件执行 |
| 签订合同 | **合同价** | 中标价与合同价一致；**不得另行订立背离实质内容的其他协议** |

> ⚠️ **"阴阳合同"违法**：招标人与中标人另行订立**背离合同实质性内容**的其他协议，属违法行为，且**以备案的中标合同作为结算依据**（**以现行法律规定为准**）。

### 4.5 施工阶段：成本控制与动态管理

**施工阶段造价管理的五件事**

```text
① 合同价款管理：预付款、进度款、质量保证金按约定支付
② 变更管理：走书面变更程序，及时计价
③ 现场签证：事前留痕，数量与费用书面确认
④ 索赔管理：在合同约定时限内发出索赔意向与报告
⑤ 动态台账：实际成本 vs 目标成本，月度偏差分析
```

**成本控制的常用方法**

| 方法 | 要点 |
|------|------|
| **目标成本分解** | 按**阶段、专业、单位工程**分解，责任到人 |
| **动态台账与偏差分析** | 定期对比**实际发生 vs 目标**，及时纠偏 |
| **费用偏差分析（挣值思路）** | 分析**进度偏差与费用偏差**，判断是"进度落后"还是"成本超支" |
| **过程结算** | 按约定周期确认已完工程量与价款，**减少竣工时的集中争议** |

### 4.6 竣工阶段：结算与决算

| 概念 | 含义 | 作用 |
|------|------|------|
| **竣工结算** | 承包人与发包人**结清工程价款**（合同价 ± 变更、签证、索赔、调价） | 确定**实际工程价款** |
| **竣工决算** | 反映建设项目**从筹建到竣工的全部实际建设费用** | 核定**新增资产价值**，办理资产移交 |
| **质量保证金** | 按约定预留，缺陷责任期满后按规定返还 | 保障缺陷责任期内的维修 |

> **易错点**：**结算 ≠ 决算**。**结算**是**承发包之间的价款结清**；**决算**是**建设单位对全部建设费用的最终核定**（含土地、建设管理、勘察设计等其他费用）。

## 🧠 记忆工具箱

### 口诀速记

- **五阶段**：**"估概预结决"**对应**"决策、设计、招投标、施工、竣工"**；
- **控制重点**：**"决策定生死，设计定造价，施工定执行"**；
- **建设投资**：**"工程费用 + 其他费用 + 预备费"**；
- **总投资**：**"建设投资 + 建设期利息 + 流动资金"**；
- **建设期利息**：**"当年借款算一半，年初余额全额算"**；
- **限额设计**：**"估算控概算，概算控预算；总额控专业，纵向加横向"**；
- **施工五件事**：**"款、变、签、索、账"**——进度款、变更、签证、索赔、动态台账；
- **结算与决算**：**"结算结价款，决算核投资"**。

### 场景锚点

| 场景 | 该想到的考点 |
|------|------------|
| 初步设计概算超了投资估算 | **限额设计失效**——回到设计优化，超概须**按规定程序处理** |
| 会计问"建设期利息怎么算" | **分年计算，当年借款取一半**，各年相加 |
| 项目经理说"变更先干了，回头补签" | ⚠️ **变更必须走书面程序**，事后补签主张价款风险极大 |
| 老板说"跟中标单位再签一份降价协议" | ❌ **"阴阳合同"违法**，结算一般**以备案的中标合同为依据** |
| 结算和决算的数字不一样 | 正常：**结算 = 工程价款**，**决算 = 全部建设费用**（含其他费用） |
| 月度成本会上要回答"钱花超了没有" | **动态台账 + 偏差分析**：对比实际成本与目标成本 |
| 想降低项目造价，问从哪下手 | **设计阶段 + 价值工程**，而不是只在施工阶段压价 |

## ⚠️ 易错提醒

- **错误认知**：造价控制主要在施工阶段；限额设计就是尽量压低造价。**纠正**：控制重点是**设计阶段**，施工阶段主要是**执行与调整**；设计一旦定型，优化空间大幅收窄。；限额设计是在**功能满足的前提下**控制投资，与价值工程一致；一味压低可能导致功能不达标而返工，反而增加总成本。
- **错误认知**：建设期利息按全部借款整年计息。**纠正**：**当年借款只计一半利息**（视同年中均匀借入），**年初借款本息累计按全额计息**，分年相加。
- **错误认知**：施工中先干变更、事后再补签证也一样。**纠正**：**变更与签证必须走书面程序并事前留痕**，事后补签在结算审核中极易被否，**"事实存在"不等于"价款能拿到"**。
- **错误认知**：竣工结算和竣工决算是同一件事。**纠正**：**结算**是承发包之间**结清工程价款**；**决算**是建设单位核定**全部实际建设费用**（含工程建设其他费用等），两者范围不同。
- **错误认知**：为了"更优惠"可以再签一份背离中标结果的协议。**纠正**：这属于**"阴阳合同"，违法**；结算通常**以备案的中标合同为结算依据**（**以现行法律规定为准**）。
- **错误认知**：变更和索赔只是走过场，口头说一声就行。**纠正**：变更与索赔**都有程序与时限**，**超过时限可能丧失主张价款的权利**（**以合同约定与现行规定为准**）。
