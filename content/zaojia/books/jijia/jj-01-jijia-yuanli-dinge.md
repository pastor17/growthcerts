## 考点梳理

### 1.1 工程造价的构成（五段骨架）

**任何一份造价文件的骨架都是这五段**：

| 序号 | 组成 | 内容 | 关键规则 |
|------|------|------|---------|
| ① | **分部分项工程费** | Σ（工程量 × 综合单价） | 主体部分，量价分离 |
| ② | **措施项目费** | 可计量措施 + 不可计量措施 | **安全文明施工费不得作为竞争性费用** |
| ③ | **其他项目费** | 暂列金额、暂估价、计日工、总承包服务费 | 暂列金额由**发包人**掌握使用 |
| ④ | **规费** | 按规定的**取费基数 × 费率** | **不得作为竞争性费用** |
| ⑤ | **税金** | 按现行税率与计税方法 | **不得作为竞争性费用** |

**不可竞争费用（必背三项）**：**安全文明施工费、规费、税金**。

**其他项目费的四个组成部分**

| 组成 | 谁定/谁用 | 要点 |
|------|----------|------|
| **暂列金额** | 招标人给定，**发包人掌握使用** | 用于施工中可能发生的变更、调价、索赔等；**余额归发包人** |
| **暂估价** | 招标人给定 | 包括**材料/设备暂估价**与**专业工程暂估价**；实际采购后**按实际调整** |
| **计日工** | 投标人自主报价 | 用于合同外零星工作，按**实际签证**结算 |
| **总承包服务费** | 投标人自主报价 | 总承包人对**发包人分包的专业工程**提供服务与配合的费用 |

### 1.2 综合单价的组成与计算

```text
综合单价 = 人工费 + 材料费 + 施工机具使用费 + 企业管理费 + 利润
          （并考虑一定范围内的风险费用）
```

| 组成 | 计算方式 | 说明 |
|------|---------|------|
| **人工费** | Σ（工日消耗量 × 人工单价） | 注意**人工单价**的口径 |
| **材料费** | Σ（材料消耗量 × 材料单价） | 材料单价含**原价 + 运杂费 + 运输损耗 + 采购保管费** |
| **施工机具使用费** | Σ（机械台班消耗量 × 台班单价） | 含**折旧、大修、经常修理、燃料动力、人工、税费**等 |
| **企业管理费** | 取费基数 × 费率 | 取费基数**以现行规定为准** |
| **利润** | 取费基数 × 利润率 | 由企业自主确定（**以现行规定为准**） |

> **口诀：人材机管利 + 风险**。**"量"来自定额/清单，"价"来自市场与规定**——这是"量价分离"的核心。

### 1.3 定额的分类与作用

**按用途与编制层次分类**

| 定额类型 | 编制对象 | 主要作用 |
|---------|---------|---------|
| **施工定额** | 工序/分项 | 企业内部管理、编制作业计划（**最细**） |
| **预算定额** | 分项工程 | 编制**施工图预算**、确定造价的基础 |
| **概算定额** | 扩大的分项工程 | 编制**设计概算** |
| **概算指标** | 单位工程/单项工程 | 编制**设计概算**、快速估价 |
| **投资估算指标** | 建设项目/单项工程 | 编制**投资估算**（**最粗**） |

**按内容分类（三大消耗量）**

| 消耗量 | 含义 | 单位 |
|--------|------|------|
| **人工消耗量** | 完成合格产品所需**工日** | 工日 |
| **材料消耗量** | 合格产品所需材料（含**净用量 + 损耗量**） | m³/t/kg/m² 等 |
| **机械台班消耗量** | 完成合格产品所需**台班** | 台班 |

> **层次记忆锚**：**"估算指标 → 概算指标 → 概算定额 → 预算定额 → 施工定额"**，**从粗到细**，正好对应**估算 → 概算 → 预算 → 施工**的阶段精度。

### 1.4 定额的换算与补充

**三种常见换算**

| 换算类型 | 情形 | 处理思路 |
|---------|------|---------|
| **材料换算** | 实际材料品种/规格与定额不同 | 换出原定额材料、换入实际材料，**只调整价差（与消耗量）** |
| **配合比换算** | 混凝土/砂浆强度等级不同 | 按实际配合比的**材料用量与单价**替换 |
| **乘系数换算** | 定额规定按系数调整（如层高、难度） | 对**人工/机械/某种费用**乘以规定系数 |

```text
换算后单价 = 原定额单价 − 应换出费用 + 应换入费用
（若乘系数：换算后 = 原定额 × 规定系数，注意系数适用的项目范围）
```

**补充定额**

- 当**实际做法在现行定额中没有对应项目**时，可编制**补充定额**；
- 补充定额需**按程序报批或经双方确认**后方可使用（**以现行规定与合同约定为准**）；
- 补充定额的计算依据要**写清**：人材机消耗量的来源与单价依据。

### 1.5 计价依据体系与造价信息

| 计价依据 | 内容 | 说明 |
|---------|------|------|
| **计价规范** | 工程量清单计价规范 | 清单计价的总规则 |
| **各专业计量规范** | 房屋建筑与装饰、通用安装、市政、园林绿化、公路、水利等 | 计量规则的最终依据 |
| **预算定额 / 费用定额** | 消耗量与取费标准 | 各地可能有本地版本 |
| **造价信息** | 人工、材料、机械价格信息（信息价） | 由造价管理机构发布，**定期更新** |
| **市场价格** | 实际询价、供应商报价 | 与信息价可能不同，**以合同约定与规定为准** |
| **企业定额** | 企业自身数据 | 反映企业竞争力 |

> **信息价 vs 市场价**：**信息价是参考价，市场价是实际成交价**。投标报价可用市场价体现竞争力；合同价款调整按**合同约定的方法**执行（**以合同与现行规定为准**）。

## 🧠 记忆工具箱

### 口诀速记

- **造价构成**：**"分措其规税"**——分部分项、措施项目、其他项目、规费、税金；
- **综合单价**：**"人材机管利（+风险）"**；
- **不可竞争**：**"安全文明、规费、税金——三项不许竞争"**；
- **其他项目费**：**"暂列、暂估、计日工、总承包服务费"**；
- **定额层次**：**"估指、概指、概定、预定、施定"**——从粗到细；
- **三消耗**：**"人工、材料、机械"**；
- **材料单价**：**"原价 + 运杂 + 损耗 + 采购保管"**；
- **换算公式**：**"换出减掉、换入加上"**。

### 场景锚点

| 场景 | 该想到的考点 |
|------|------------|
| 拿到一份投标报价，要拆它的结构 | 按**"分措其规税"**五段拆；再看综合单价里的**"人材机管利"** |
| 招标文件里有一笔"暂列金额" | 由**发包人掌握使用**，**余额归发包人**，投标人不能随意动用 |
| 现场要用的材料规格与定额不同 | 做**材料换算**：换出原定、换入实际，调价差 |
| 现场出现定额里没有的做法 | 编**补充定额**，按程序报批或双方确认 |
| 甲方问"信息价和市场价用哪个" | **信息价是参考，市场价是实际**；调整**按合同约定的方法** |
| 有投标人把安全文明施工费压得很低 | **安全文明施工费属不可竞争费用**，不得作为竞争性费用 |
| 想知道某个阶段该用哪本定额 | 决策用**估算指标**，概算用**概算定额/概算指标**，预算用**预算定额** |

## ⚠️ 易错提醒

- **错误认知**：安全文明施工费可以自由竞争。**纠正**：**安全文明施工费、规费、税金均为不可竞争费用**，必须按规定计取，压低或取消都属违规。
- **错误认知**：暂列金额是给投标人自由支配的。**纠正**：**暂列金额由发包人掌握使用**，用于可能发生的变更、调价、索赔等，**余额归发包人**，投标时不能当作自己的收入。
- **错误认知**：定额里的材料单价就是材料的原价；定额换算就是把单价换成实际价格。**纠正**：材料单价 = **原价 + 运杂费 + 运输损耗费 + 采购及保管费**，漏项会直接算错综合单价。；换算要同时处理**消耗量与单价**（如配合比换算需替换材料用量），并且**只调整应调整的项目**，不要连带改动其他费用。
- **错误认知**：没有对应定额项目就不能计价。**纠正**：可编制**补充定额**，但需**按程序报批或经双方确认**，并写清消耗量与单价的依据（**以现行规定与合同约定为准**）。
- **错误认知**：信息价就是必须执行的结算价。**纠正**：**信息价是参考价**，结算调整应**按合同约定的调整方法**执行（如调值公式或按造价信息调整差额），**以合同与现行规定为准**。
- **错误认知**：企业管理费和利润的取费基数是固定的。**纠正**：取费基数与费率**以现行规定与招标文件为准**，不同地区、不同专业的口径可能不同，**不能凭记忆套用**。
