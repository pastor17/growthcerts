## 考点梳理

### 2.1 工程量清单的五要素

| 要素 | 要求 | 常见错误 |
|------|------|---------|
| **项目编码** | 按规范规定的**分类与顺序**编码，补充项目按规则编写 | 编码乱编、补充项目未按规定标识 |
| **项目名称** | 按规范附录的项目名称确定 | 自造名称导致**缺项或重复** |
| **项目特征** | **必须描述清楚**，是**组价与结算的依据** | 描述不全 → 投标人可主张**重新组价** |
| **计量单位** | 按规范规定的单位 | 单位错 → 量价全错 |
| **工程量** | 按**现行计量规范的计算规则**计算 | 扣减关系算错（**最高频失分点**） |

> **记忆锚**：**"编名特量单"**。其中**项目特征是最容易引争议的一项**——特征写不清，结算时就是一笔糊涂账。

**项目特征的作用（三条）**

1. **决定综合单价的组成**——特征不同，人材机消耗与单价就不同；
2. **区分清单项目**——避免同一名称不同做法的项目混在一起；
3. **结算争议的判定依据**——实际做法与特征描述不符时，据此判断是否调整价款。

### 2.2 工程量清单的组成

```text
工程量清单
├ 分部分项工程量清单（项目编码、名称、特征、计量单位、工程量）
├ 措施项目清单（可计量措施 + 不可计量措施）
├ 其他项目清单（暂列金额、暂估价、计日工、总承包服务费）
├ 规费项目清单
└ 税金项目清单
```

**编制人**：工程量清单由**具有编制能力的招标人或受其委托的造价咨询人**编制（**以现行规定为准**）。

### 2.3 招标控制价与投标报价

| 对比项 | **招标控制价** | **投标报价** |
|--------|---------------|-------------|
| 编制主体 | **招标人**（或受委托的造价咨询人） | **投标人** |
| 性质 | 招标人**能接受的最高投标价格** | 投标人的**自主报价** |
| 依据 | 清单、现行计价规范、造价信息、市场价格、施工方案 | 企业定额/消耗量、市场询价、竞争策略、施工方案 |
| 关键限制 | **不得随意上调或下调**；应按规定公布 | **不得低于成本**（**以现行规定为准**） |
| 作用 | 超过者应作废标处理（**以招标文件与现行规定为准**） | 形成合同价的基础 |

**投标报价的三种常用策略（了解）**

| 策略 | 适用情形 |
|------|---------|
| **不平衡报价** | 总价不变前提下调整各分项单价。⚠️ 过度不平衡可能被认定为**不合理报价**（**以招标文件与现行规定为准**） |
| **多方案报价** | 招标文件不明确时，按不同方案分别报价 |
| **增加建议方案** | 提出能降低造价或缩短工期的优化方案 |

> ⚠️ **不平衡报价要谨慎**：恶意不平衡可能被**否决投标**或在结算时被调整，**以招标文件与现行规定为准**。

### 2.4 四个专业的计量规则要点

**计量四动作**：**算面积、算体积、算长度、处理扣减与不增加**（口诀 **"面体长扣增"**）。

| 专业 | 主要计量对象 | 常用单位 | 要点 |
|------|------------|---------|------|
| **土木建筑工程** | 土方、基础、砌体、混凝土构件、钢筋、门窗、楼地面、屋面防水、装饰面层 | m³、m²、m、t | 构件交接处**归属规则**、洞口**扣减** |
| **安装工程** | 机械设备、电气（配管配线、灯具、配电箱）、给排水、采暖、通风空调、消防 | 台、m、m²、kg、系统 | **系统/回路**划分与**界面划分** |
| **交通运输工程** | 路基、路面、桥涵、隧道 | m³、m²、m、座 | 按**结构部位**分段计量 |
| **水利工程** | 土石方、混凝土、砌石、基础处理、金属结构 | m³、m²、t | 按**部位与工序**计量 |

**工程量计算的基本规则（通用要点）**

| 规则 | 说明 |
|------|------|
| **以图示尺寸为准** | 按**设计图示尺寸**计算，不按实际施工偏差计算 |
| **扣减关系明确** | **应扣除**（如孔洞、构件占位）、**不扣除**（如小孔洞）、**不增加**（如施工损耗）三类必须分清 |
| **计量单位统一** | 同一项目只能用规范规定的单位 |
| **净量与总量区分** | 清单工程量一般按**图示净尺寸**计算，施工损耗在**综合单价**中考虑 |

**高频扣减示例（具体以现行计量规范为准）**

| 对象 | 常见规则（示意） |
|------|----------------|
| **建筑面积** | 按现行建筑面积计算规范；结构层高达到规定高度计全面积，低于该高度计半面积（现行规范常用界限为 **2.20 m**） |
| **平整场地** | 一般按设计图示尺寸以**建筑物首层建筑面积**计算 |
| **挖基础土方** | 清单口径一般按**基础垫层底面积 × 挖土深度**计算（放坡与工作面在**定额/施工方案**中考虑） |
| **混凝土构件** | 按图示体积计算，**扣除**规定范围内的孔洞与型钢占位 |
| **装饰面层** | 按图示面积计算，**扣除**门窗洞口等规定项，洞口侧壁是否并入按规则执行 |
| **钢筋** | 按设计图示长度 × 单位理论质量，搭接与锚固是否另计**按现行规则** |

> ⚠️ **一切计量规则以现行有效的各专业工程量计算规范为准**——不同专业规范口径不同，教材与旧资料可能与现行规范存在差异。

### 2.5 措施项目费的计算方式

| 方式 | 适用 | 计算 |
|------|------|------|
| **按工程量计算** | 可计量的措施（如脚手架、模板、垂直运输） | 按计量规范计算工程量 × 综合单价 |
| **按"项"计算** | 不可计量的措施（如安全文明施工费、夜间施工、二次搬运、冬雨季施工） | 按规定费率或按"项"报价 |

> **安全文明施工费**：一般按规定基数与费率计取，**属于不可竞争费用**，不得压价；**以现行规定为准**。

### 口诀速记

- **清单五要素**：**"编名特量单"**；
- **特别提醒**：**"特征写不清，结算必扯皮"**；
- **招标控制价**：**"招标人能接受的最高价，超了作废标"**；
- **投标报价**：**"自主报价，但不得低于成本"**；
- **计量四动作**：**"面体长扣增"**；
- **三类关系**：**"该扣的扣、不该扣的不扣、不增加的不增加"**；
- **措施费两算法**：**"能量算量、不能量算项"**；
- **三层量**：**"清单算净量，定额含量含损耗，结算按实际"**。

### 场景锚点

| 场景 | 该想到的考点 |
|------|------------|
| 拿到一份清单，先看什么 | 先看**项目特征**——它决定综合单价与后续调价 |
| 结算时施工方说"实际做法和清单不一样" | 回到**项目特征**判断：特征未描述的项目**可主张重新组价**（**以合同与现行规定为准**） |
| 投标报价被人质疑"太低" | 关注**是否低于成本**（**以现行规定为准**） |
| 要算一面墙的装饰面积 | 先定**计量单位与规则**，再处理**门窗洞口扣除**与侧壁是否并入 |
| 要算基础土方 | 清单口径按**垫层底面积 × 深度**；**放坡与工作面**在定额/方案里考虑 |
| 甲方要求把安全文明施工费压下来省钱 | ⚠️ **不可竞争费用**，不得作为竞争性费用，不能压 |
| 乙方想把某项单价调高、另一项调低（总价不变） | 这是**不平衡报价**，过度不平衡可能被否决或调整（**以招标文件与现行规定为准**） |

## ⚠️ 易错提醒

- **错误认知**：项目特征只是描述一下，不影响价格。**纠正**：**项目特征直接决定综合单价的组成**，也是结算时判断能否调整价款的核心依据，**写不清就会扯皮**。
- **错误认知**：清单工程量要把施工损耗也算进去。**纠正**：清单工程量一般按**设计图示尺寸的净量**计算，**施工损耗在综合单价中考虑**，两者不能混。
- **错误认知**：平整场地按建筑面积之外另算一块场地面积；挖基础土方要把放坡和工作面算进清单量。**纠正**：一般按设计图示尺寸以**建筑物首层建筑面积**计算（**以现行计量规范为准**）。；清单口径一般按**基础垫层底面积 × 挖土深度**计算，**放坡与工作面**通常在**定额或施工方案**中体现（**以现行规范为准**）。
- **错误认知**：招标控制价可以由招标人随意上下浮动。**纠正**：招标控制价**不得随意上调或下调**，应按规定编制与公布；超过控制价的投标通常按废标处理（**以招标文件与现行规定为准**）。
- **错误认知**：不平衡报价是通用技巧，用得越极端越好。**纠正**：合理运用可以，但**过度不平衡可能被认定为不合理报价而被否决或调整**（**以招标文件与现行规定为准**）。
- **错误认知**：计量规则记个大概就行。**纠正**：**计量规则差一点，算量结果就错一片**——扣减关系必须精确到"应扣、不扣、应增、不增"四类，并且**以现行有效的计量规范为准**。
