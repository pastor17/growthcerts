## 考点梳理

### 3.1 合同价款调整的五大情形（必背）

| 情形 | 触发原因 | 调整思路 | 关键动作 |
|------|---------|---------|---------|
| **工程变更** | 设计变更、施工方案调整、新增或取消工作 | 按变更程序确认后调整**工程量与单价** | **书面变更指令 + 及时计价** |
| **物价波动** | 人工、材料、机械价格涨跌 | 按合同约定的**调值公式**或**按造价信息调整差额** | 明确**基准日**与**风险幅度** |
| **法规变化** | 基准日后法律法规、政策变化引起费用增减 | 按合同约定**分担或调整** | 关注**基准日**这个分界点 |
| **工程量偏差** | 实际工程量与清单工程量偏差超规定幅度 | **超出部分**的综合单价按规则调整 | 记住**幅度界限**（常见口径 ±15%，**以现行规范为准**） |
| **索赔与现场签证** | 非己方原因造成损失或额外工作 | 按合同与证据**计算工期与费用** | **在约定时限内**提出并留痕 |

> **记忆锚**：**"变调签索偏"**——**变更、调价（物价）、签证、索赔、偏差**。这五类情形**各有程序、各有时限、各有计算公式**。

### 3.2 物价波动的调整方法

**方法一：价格调整公式（调值公式）**

```text
P = P₀ × [ a₀ + a₁·(A/A₀) + a₂·(B/B₀) + a₃·(C/C₀) + … ]

P  —— 调整后的合同价款（或需调整部分）
P₀ —— 基准日的合同价款（或需调整部分）
a₀ —— 不调值部分（固定系数）的权重
a₁,a₂,a₃… —— 各可调因子（人工、材料、机械等）的权重，Σ 权重 = 1
A,A₀ 等 —— 现行价格指数 / 基准日价格指数
```

**方法二：按造价信息调整差额**

```text
材料价差 = 实际采购价（或信息价） − 合同约定基准价
只对超出约定风险幅度的部分进行调整（风险幅度以合同约定为准）
```

> **两个关键点**：**① 权重之和为 1**（含不调值部分）；**② 只调整超出约定风险幅度的部分**，风险幅度内的涨跌由承包人承担（**以合同约定为准**）。

### 3.3 工程量偏差的调整

**调整逻辑（常见口径，以现行规范与合同约定为准）**

| 偏差情况 | 调整方向 |
|---------|---------|
| 实际工程量 **增加超过规定幅度** | 其**增加部分的综合单价适当调低** |
| 实际工程量 **减少超过规定幅度** | 其**减少后剩余部分的综合单价适当调高** |

```text
原理：工程量偏差改变了单位工程量的固定费用分摊
  → 量增加，承包人固定费用被摊薄，超出部分应调低单价
  → 量减少，承包人固定费用摊到更少的量上，剩余部分应调高单价
```

> **常见幅度口径为 ±15%**（清单计价规范长期沿用的口径），**具体幅度与调整方法以现行计价规范与合同约定为准**——答题时**写明依据**比死记数字更稳。

### 3.4 进度款、质量保证金与竣工结算

**进度款支付**

| 要点 | 说明 |
|------|------|
| 支付周期 | 按合同约定的周期（如按月）申报与审核 |
| 申报内容 | 已完工程量、工程质量证明、相应价款 |
| 支付比例 | 按合同约定（**以合同与现行规定为准**） |
| **预付款** | 按约定支付与**抵扣**（抵扣方式与起扣点以合同约定为准） |

**质量保证金**

- 按合同约定从应付工程款中**预留**，用于缺陷责任期内的维修；
- **预留比例与返还期限以现行规定与合同约定为准**；
- 缺陷责任期满且无质量问题，按规定**返还**。

**竣工结算流程**

```text
承包人编制并提交竣工结算文件（附完整资料）
        ↓
发包人（或受托造价咨询人）审核 → 提出审核意见
        ↓
双方核对、协商 → 达成一致 → 签署结算文件
        ↓
按约定支付结算款 → 进入缺陷责任期
```

**结算审核的重点（也是审计最常扣减的地方）**

| 审核重点 | 常见问题 |
|---------|---------|
| **工程量** | 计量规则用错、扣减关系算错、重复计算 |
| **综合单价** | 组价依据不足、换算错误、与清单特征不符 |
| **变更与签证** | 无书面依据、程序不全、超出合同范围 |
| **索赔** | 超时限、责任归属判断错误、证据不足 |
| **取费与税金** | 费率套用错误、基数错误、不可竞争费用被压低 |
| **材料价差** | 风险幅度未扣除、基准价与信息价混用 |

### 3.5 竣工决算

| 概念 | 范围 | 作用 |
|------|------|------|
| **竣工结算** | 承发包之间的**工程价款**结清 | 确定实际工程价款 |
| **竣工决算** | 建设项目**从筹建到竣工的全部实际建设费用** | 核定**新增资产价值**，办理资产移交 |

**竣工决算的组成（一般口径）**：竣工财务决算报表 + 竣工财务决算说明书 + 工程造价对比分析资料等（**以现行规定为准**）。

## 🧠 记忆工具箱

### 口诀速记

- **五大调整情形**：**"变调签索偏"**——**变**更、**调**价、**签**证、**索**赔、**偏**差；
- **调值公式**：**"权重和为一，只调超幅度"**；
- **偏差调整方向**：**"量增超幅，超出部分调低；量减超幅，剩余部分调高"**；
- **常见幅度**：**"±15%"**（**以现行规范与合同约定为准**）；
- **进度款三件套**：**"量、质、款"**——已完工程量、质量证明、相应价款；
- **结算审核六查**：**"量、价、变签、索赔、取费、价差"**；
- **结算与决算**：**"结算结价款，决算核投资"**。

### 场景锚点

| 场景 | 该想到的考点 |
|------|------------|
| 钢筋价格半年涨了不少，乙方要求调价 | **物价波动**：看合同是**调值公式**还是**按造价信息调差额**，并**扣除约定风险幅度** |
| 实际挖方量比清单多了 30% | **工程量偏差**：超出规定幅度的部分**综合单价调低**（常见幅度 ±15%，**以现行规范与合同约定为准**） |
| 现场多干了一段挡墙，施工前只有口头指令 | ⚠️ **变更/签证必须书面**；口头指令的价款主张风险极大，应补办且**尽量事前留痕** |
| 审计提出审减 20%，乙方不服 | 逐条对照**工程量、综合单价、变更签证、索赔、取费**六项，区分**规则差异 / 依据缺失 / 计算错误** |
| 甲方问"缺陷责任期的钱什么时候退" | **质量保证金**：缺陷责任期满且无质量问题按规定**返还**（**以现行规定与合同约定为准**） |
| 结算和决算的数字不一致 | 正常：**结算 = 工程价款**；**决算 = 全部建设费用**（含工程建设其他费用） |
| 有人提议"用调值公式算一下，但权重随便填" | ⚠️ 权重之和必须为 1，且权重要**与合同约定和实际构成相符** |

## ⚠️ 易错提醒

- **错误认知**：物价涨了就该全额补偿。**纠正**：只调整**超出合同约定风险幅度**的部分，**风险幅度内的涨跌由承包人承担**（**以合同约定为准**）。
- **错误认知**：调值公式里的权重可以随便取，加起来不必等于 1。**纠正**：**各可调因子权重与不调值部分权重之和必须等于 1**；权重取值应与合同约定及费用构成相符。
- **错误认知**：工程量增加时综合单价应调高（因为干得多）。**纠正**：方向常记反——**工程量增加超过幅度时，超出部分的综合单价适当调低**（固定费用被摊薄）；**减少超过幅度时，剩余部分调高**。
- **错误认知**：变更和签证只要有事实就能结算；索赔时限可以"事后补"。**纠正**：变更与签证**必须走书面程序**；无书面依据、程序不全的变更和签证在结算审核中**极易被扣减**。；索赔有**约定时限**（常见口径为知道或应当知道索赔事件发生后 **28 天内**发出索赔意向），**超时限可能丧失索赔权利**（**以合同约定与示范文本为准**）。
- **错误认知**：材料价差直接用"实际价 − 信息价"。**纠正**：应以**合同约定的基准价**为基准，并**扣除约定风险幅度**；基准价、信息价与市场价的适用口径**以合同约定与现行规定为准**。
- **错误认知**：结算审减就是审计在压价，可以直接对抗。**纠正**：应**逐条对照规则与依据**分类回应——**规则差异**用规范条文谈，**依据缺失**补资料，**计算错误**认账整改；**用证据说话比情绪对抗有效得多**。
