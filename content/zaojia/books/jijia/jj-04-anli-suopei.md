## 考点梳理

### 4.1 案例分析通用五步解题法

```text
① 读题圈条件：时间、金额、利率、工程量、比例、期限——全部圈出来
② 写「已知 / 所求 / 依据」：明确算什么、依据哪条规则或公式
③ 分步列式：一步一行，写清单位与来源
④ 计算并检查：单位是否统一、小数位是否符合要求、有无漏问
⑤ 结论句：给出明确结论（可行/不可行、调增/调减、索赔成立/不成立）
```

> **核心认知**：**案例题是"步骤分"考试**——写清步骤比只给答案得分高得多。**答题模板化，考场不思考顺序。**

### 4.2 投资估算与财务评价

**建设项目总投资构成**

```text
建设项目总投资 = 建设投资 + 建设期利息 + 流动资金
  建设投资 = 工程费用 + 工程建设其他费用 + 预备费
    工程费用 = 建筑安装工程费 + 设备及工器具购置费
    预备费 = 基本预备费 + 价差预备费
```

**基本预备费与价差预备费**

```text
基本预备费 = (工程费用 + 工程建设其他费用) × 基本预备费率
价差预备费：按建设期分年投资额与价格上涨指数逐年计算
```

**建设期利息（分年、当年取半）**

```text
第 t 年利息 = (年初借款本息累计 + 第 t 年借款额 ÷ 2) × 年利率
建设期利息 = Σ 各年利息
```

**财务评价的解题顺序（不能乱）**

```text
① 算建设投资与建设期利息 → 形成固定资产原值
② 编制还本付息表（等额还本 / 等额本息，按题意）
③ 计算总成本费用（经营成本 + 折旧 + 摊销 + 利息）
④ 计算利润与所得税
⑤ 计算财务指标（NPV / IRR / 投资回收期 / 总投资收益率）
⑥ 给结论：可行 / 不可行
```

> **易错点**：**总成本费用中的利息来自还本付息表**，所以**必须先算还本付息**；顺序颠倒会连环出错。

### 4.3 设计概算与施工图预算

| 环节 | 编制思路 | 常见考法 |
|------|---------|---------|
| **设计概算** | 单位工程概算 → 单项工程综合概算 → 建设项目总概算 | 概算的组成与审查 |
| **施工图预算** | 按计价程序：分部分项 → 措施 → 其他 → 规费 → 税金 | 组价、取费、算总额 |
| **限额设计** | 估算控概算、概算控预算 | 判断是否超限、如何处理 |

**预算编制的三步骨架**

```text
第一步：算量——按现行计量规范算清单工程量（注意扣减关系）
第二步：组价——综合单价 = 人材机管利（+风险），注意定额换算
第三步：取费——按计价程序汇总到单位工程造价
```

### 4.4 索赔的成立判断与计算

**索赔成立的两个必答问题**

```text
① 责任在谁？——不是己方原因（对方原因、不可抗力、法规变化等）
② 是否影响？——工期索赔看是否影响关键线路；费用索赔看是否造成实际损失
```

**索赔成立性判断表**

| 事件原因 | 工期索赔 | 费用索赔 |
|---------|---------|---------|
| **发包人原因**（图纸延误、指令错误、未按时提供场地） | **成立**（若影响关键线路） | **成立** |
| **不可抗力** | **成立（工期顺延）** | **各自损失各自承担**（**以合同约定为准**） |
| **异常恶劣天气** | 视合同约定（可能顺延工期） | 一般**不成立**（**以合同约定为准**） |
| **承包人原因**（施工方案不当、质量问题返工） | **不成立** | **不成立** |
| **第三方原因** | 按合同约定，一般先由发包人承担后追偿 | 按合同约定 |

**工期索赔的计算（关键线路法）**

```text
① 找出原计划的关键线路与总工期
② 把可索赔事件的持续时间加入相应工作
③ 重新计算总工期 → 比较
工期索赔天数 = 新总工期 − 原总工期（即真正被延误的天数）
```

> **要点**：**只有影响关键线路（或使非关键工作变为关键）的延误才能索赔工期**；非关键工作有总时差，延误在时差内**不影响总工期**。

**费用索赔的计算**

```text
可索赔费用 = 人工费 + 材料费 + 机械费 + 管理费 + （按合同约定的其他费用）
注意：
  ① 只计算「实际发生的额外费用」，不含未发生的利润（除非合同约定可计）
  ② 机械闲置费与机械台班费口径不同，按题意区分
  ③ 现场管理费与总部管理费按合同约定的方式计算
```

### 4.5 案例答题的得分要点

| 要点 | 说明 |
|------|------|
| **写依据** | 每个判断都写"依据××规范/合同条款/公式" |
| **写单位** | 金额、面积、体积都要带单位 |
| **写步骤** | 一步一行，不要跳步合并 |
| **写结论** | 明确给出"成立/不成立""调增/调减多少" |
| **小数位** | 按题目要求保留（无要求时金额一般保留两位小数） |
| **时间分配** | 先做会的、能拿步骤分的先写；单题超时就切题 |

## 🧠 记忆工具箱

### 口诀速记

- **五步法**：**"圈条件、写依据、分步算、回头查、下结论"**；
- **总投资**：**"建设投资 + 建设期利息 + 流动资金"**；
- **建设期利息**：**"当年取一半，年初算全额"**；
- **财务评价顺序**：**"先还本、再成本、后利润、末指标"**；
- **预算三步**：**"算量、组价、取费"**；
- **索赔两问**：**"责任在谁？影响不影响？"**；
- **工期索赔**：**"只看关键线路，时差之内不赔工期"**；
- **不可抗力**：**"工期顺延，各自损失各自扛"**；
- **答题五写**：**"写依据、写单位、写步骤、写结论、写小数位"**。

### 场景锚点

| 场景 | 该想到的考点 |
|------|------------|
| 甲方图纸晚给 20 天，乙方要索赔 | **索赔两问**：责任在甲方（成立）；再看**是否在关键线路上**决定能否索赔工期 |
| 工地遭遇台风停工 5 天 | **不可抗力**：工期一般顺延，**费用各自承担**（**以合同约定为准**） |
| 乙方自己施工方案不当导致返工 | ❌ 责任在承包人，**工期与费用索赔均不成立** |
| 连续下雨导致停工 | 看合同是否属于"异常恶劣天气"，**工期可能顺延，费用一般不给**（**以合同约定为准**） |
| 题目要算项目是否可行 | 走**财务评价顺序**：还本付息 → 总成本费用 → 利润 → NPV/IRR → 结论 |
| 题目给"借款在年中均匀投入" | **建设期利息当年借款取一半** |
| 结算争议要一条条谈 | 用**六查**：量、价、变签、索赔、取费、价差——每条都写依据 |

## ⚠️ 易错提醒

- **错误认知**：案例题只要答案对就给满分。**纠正**：案例题是**步骤分**考试，**不写依据、不写单位、不写步骤**即使答案对也会大量失分。
- **错误认知**：建设期利息按借款全额整年计息；财务评价可以先算利润再算利息。**纠正**：**当年借款只计一半利息**（视同年中均匀投入），**年初累计按全额计息**，分年相加。；**总成本费用中的利息来自还本付息表**，必须**先算还本付息**，否则整条计算链都错。
- **错误认知**：只要发生延误就能索赔工期。**纠正**：**只有影响关键线路（或使非关键工作变为关键）的延误才能索赔工期**；在总时差范围内的延误**不影响总工期，不能索赔工期**。
- **错误认知**：不可抗力的全部损失都可以索赔。**纠正**：不可抗力一般**工期顺延，损失各自承担**（工程本身、第三方、运至现场的材料设备损害由发包人承担，承包人机械损坏由承包人承担）——**具体以合同约定为准**。
- **错误认知**：索赔费用里应该把预期利润都算上。**纠正**：费用索赔一般**只计算实际发生的额外费用**；利润是否可计**按合同约定**，不能想当然地全算。
- **错误认知**：计算中保留几位小数无所谓。**纠正**：小数位与单位**影响得分**，按题目要求执行；无要求时金额一般保留**两位小数**，面积与体积按计量规范规定的精度。
