> **用法**：考前 3 天起只过这一页 + 自己的错题本。公式要**默写**而不是"看着眼熟"；数字临界值要能**说出条件**。**合格标准、滚动周期与各项时限规定，一律以中国人事考试网及当地考试机构当次公告、现行法律法规为准。**

## 一、资金时间价值与工程经济（必默写）

| 名称 | 公式 | 已知 → 求 |
|------|------|----------|
| 一次支付**终值** | F = P(1+i)ⁿ | P → F |
| 一次支付**现值** | P = F(1+i)⁻ⁿ | F → P |
| 等额**年金终值** | F = A[(1+i)ⁿ − 1] / i | A → F |
| **偿债基金** | A = F·i / [(1+i)ⁿ − 1] | F → A |
| 等额**年金现值** | P = A[(1+i)ⁿ − 1] / [i(1+i)ⁿ] | A → P |
| **资金回收** | A = P·i(1+i)ⁿ / [(1+i)ⁿ − 1] | P → A |
| **名义 → 实际利率** | i = (1 + r/m)ᵐ − 1 | r（名义，年）→ i（实际） |
| **建设期利息**（当年） | 当年利息 = (年初借款本息累计 + 当年借款 ÷ 2) × 利率 | 分年计算再求和 |
| **净现值 NPV** | NPV = Σ(CI − CO)ₜ (1 + i)⁻ᵗ（i 为基准折现率） | 判据：**NPV ≥ 0 可行** |
| **内部收益率 IRR** | 使 NPV = 0 的折现率 | 判据：**IRR ≥ 基准折现率可行** |
| **静态投资回收期** | 累计净现金流量首次 ≥ 0 的时点（含小数补齐） | 越短越好 |
| **价值工程** | **V = F / C**（价值 = 功能 ÷ 成本） | V 越大越优 |
| **寿命周期成本** | LCC = 建设成本 + 使用维护成本 | 方案比选用 |

**公式记忆锚**：**"终值往前滚，现值往回缩；年金要摊平，回收是反算"**——六个公式互为倒数关系，只需牢牢记住 **F = P(1+i)ⁿ** 与 **F = A[(1+i)ⁿ−1]/i** 两个，其余**全部能推出**。

## 二、造价构成与计价程序（骨架）

**工程造价五段骨架**

| 序号 | 组成 | 要点 |
|------|------|------|
| ① | **分部分项工程费** | ＝ Σ（工程量 × 综合单价），主体部分 |
| ② | **措施项目费** | 可计量措施按量计；不可计量按"项"计。**安全文明施工费不得作为竞争性费用** |
| ③ | **其他项目费** | 暂列金额、暂估价、计日工、总承包服务费 |
| ④ | **规费** | 按规定的**取费基数 × 费率**，**不得作为竞争性费用** |
| ⑤ | **税金** | 按现行税率与计税方法计算，**不得作为竞争性费用** |

**综合单价组成**：**人工费 + 材料费 + 施工机具使用费 + 企业管理费 + 利润**（并考虑一定范围内的**风险费用**）。

> 口诀：**"人材机管利 + 风险"**；造价构成：**"分措其规税"**。

**单位工程造价计算程序（顺序不能乱）**

```text
分部分项工程费 = Σ（清单工程量 × 综合单价）
        ↓
措施项目费（可计量 + 不可计量）
        ↓
其他项目费（暂列金额/暂估价/计日工/总承包服务费）
        ↓
单位工程造价 = ① + ② + ③ + 规费 + 税金
        ↓
单项工程造价 = Σ 单位工程造价 + 相关费用
        ↓
建设项目总造价 = Σ 单项工程造价 + 预备费 + 建设期利息 + 流动资金（按口径）
```

**清单五要素**：**项目编码、项目名称、项目特征、计量单位、工程量** —— **"编名特量单"**。
> **项目特征是组价与结算争议的焦点**：特征描述不清，投标人可主张重新组价。

## 三、计量规则要点（扣减关系是命门）

**建筑面积与主要构件（口诀：面体长扣增）**

| 项目 | 计算要点 | 易错点 |
|------|---------|--------|
| **建筑面积** | 按现行建筑面积计算规范；**结构层高达到规定高度**才计全面积，低于该高度计半面积 | 层高与净高的**判断界限**（现行规范为 **2.20 m**，以现行规范为准） |
| **平整场地** | 一般按设计图示尺寸以**建筑物首层建筑面积**计算 | 与"挖土方"的界限别混 |
| **挖基础土方** | 按设计图示尺寸以**基础垫层底面积 × 挖土深度**计算（清单口径） | 是否放坡、工作面按**定额/施工方案**另计 |
| **土方回填** | 按图示回填体积计算，**扣减**基础、构筑物等埋入体积 | 扣减项漏算 |
| **混凝土构件** | 按图示尺寸以**体积**计算，**扣除**孔洞、型钢等规定项 | 梁柱板交接处的**归属规则** |
| **钢筋** | 按设计图示**长度 × 单位理论质量**，区分规格与等级 | 搭接、锚固、弯钩是否另计（**按现行规则**） |
| **装饰面层** | 按图示尺寸以**面积**计算，**扣除**门窗洞口等规定项 | 洞口侧壁是否增加 |
| **安装工程** | 按**系统/设备/管线**分类计量，长度、数量、重量各有规则 | 与土建的**界面划分** |

**三条保命原则**

1. **先定规则、再算数**——同一构件在**清单规范**与**定额**下的口径可能不同，写清依据；
2. **扣减关系列清单**——把"应扣、不扣、应增、不增"四类做成一张表贴在书桌；
3. **以现行有效版本的计价与计量规范为准**——旧资料里的规则可能已变。

## 四、价款调整与索赔（情形 → 依据 → 时限）

| 情形 | 处理要点 | 时限/依据（以合同与现行规定为准） |
|------|---------|-------------------------------|
| **工程量偏差** | 偏差超过规定幅度时，**超出部分的综合单价**按规则调整（增加过多调低、减少过多调高） | 现行计价规范规定幅度（常引 **±15%**），以现行规范为准 |
| **物价波动** | 按合同约定的**价格调整公式**调差，或按造价信息调整差额 | 调值公式：P = P₀[a₀ + a₁(A/A₀) + a₂(B/B₀) + …] |
| **法规变化** | 基准日之后法规变化引起费用增减，按合同约定分担 | 关注**基准日**这个分界 |
| **工程变更** | 走**变更程序**：提出 → 审批 → 计价 → 调整合同价款 | 未按程序办理的变更**难以主张** |
| **现场签证** | 书面确认事实、数量与费用，**事前留痕** | 事后补签风险极大 |
| **索赔（工期/费用）** | 提出索赔意向 → 提交索赔报告与证据 → 协商或仲裁 | 承包人一般应在知道或应当知道索赔事件发生后 **28 天内**发出索赔意向（**以合同与示范文本约定为准**） |
| **进度款** | 按合同约定周期与比例支付，附已完工程量与质量证明 | 比例限制以合同与现行规定为准 |
| **质量保证金** | 按约定预留，缺陷责任期满后按规定返还 | 预留比例与期限**以现行规定为准** |
| **竣工结算** | 承包人提交结算文件 → 发包人审核（或委托造价咨询审核）→ 双方确认 | 审核期限**以合同约定与现行规定为准** |

> **记忆锚**：**"变调签索偏"**——变更、调价、签证、索赔、偏差，五类情形**各有程序与时限**；**时限过了，事实还在，权利可能就没了**。

## 五、案例分析解题步骤模板（照着走）

**通用五步法**

```text
① 读题圈条件：把「时间、金额、利率、工程量、比例、期限」全部圈出来
② 写「已知 / 所求 / 依据」：明确要算什么、依据哪条规则或公式
③ 分步列式：一步一行、写清单位与来源（步骤分比答案重要）
④ 计算并检查：单位是否统一、小数位是否符合要求、有无漏问
⑤ 结论句：给出明确结论（可行/不可行、应调增/应调减、索赔成立/不成立）
```

**六类高频题型的抓手**

| 题型 | 解题抓手 |
|------|---------|
| **投资估算** | 建设投资构成拆清 → **建设期利息**分年算（当年借款取一半）→ 流动资金按规则估 |
| **财务评价** | 先算**还本付息表** → 再算总成本费用 → 再算利润与指标（顺序不能乱） |
| **设计概算 / 施工图预算** | 按**计价程序**走：分部分项 → 措施 → 其他 → 规费 → 税金 |
| **清单计价与计量** | 先算**工程量**（计量规则）→ 再组**综合单价** → 再乘 → 再取费 |
| **合同价款调整** | 判断**属于哪类情形**（变调签索偏）→ 找依据 → 套公式 → 给结论 |
| **索赔** | 先判**责任归属**（谁的原因）→ 再判**工期可否索赔**（是否影响关键线路）→ 再算**费用** |
| **方案比选** | 统一到**同一时点**比较（现值/年值/寿命周期成本）→ 给选择结论 |

> **"索赔两问"**：**① 责任在谁？② 是否影响关键线路？**——责任不在对方、又不影响总工期，索赔通常不成立（或只赔费用不赔工期）。

## 六、必背数字与临界值（说得出条件才算会）

| 数字 | 含义 | 备注 |
|------|------|------|
| **60%** | 各科目合格标准一般按满分的 60% 相对固定 | **以当次公告为准** |
| **4 个年度** | 考全科者**连续 4 个考试年度内**通过全部科目 | **以当次公告为准** |
| **2 个年度** | 免二科者**连续 2 个考试年度内**通过应试科目 | **以当次公告为准** |
| **4 个专业** | 土木建筑、交通运输、水利、安装 | 技术与计量、案例分析分专业 |
| **4 科** | 管理、计价、技术与计量、案例分析 | 后两科分专业 |
| **2.20 m** | 建筑面积计算中结构层高的判断界限（现行规范口径） | **以现行规范为准** |
| **±15%** | 工程量偏差调整综合单价的常见幅度口径 | **以现行计价规范与合同约定为准** |
| **28 天** | 索赔意向通知的常见时限 | **以合同与示范文本约定为准** |
| **20 日** | 招标文件开始发出至投标截止的最短期限（法定口径） | **以现行法律法规为准** |
| **3 日** | 中标候选人公示期的最短期限（法定口径） | **以现行法律法规为准** |
| **3600 元** | 取得证书当年可申报的继续教育专项附加扣除额度 | **以现行税收政策为准** |

> ⚠️ **上表数字是"考试与实务的常见口径"，凡是比例、期限、幅度，一律以现行法律法规、现行计价计量规范、合同约定及官方当次公告为准**——答题时**写明依据**，比背一个数字更安全。

## 七、考场最后 30 分钟清单

```text
□ 公式默写：六个资金时间价值公式 + 建设期利息 + NPV/IRR 判据
□ 骨架默写：分措其规税 / 人材机管利 / 编名特量单
□ 口诀默写：估概预结决 / 变调签索偏 / 面体长扣增
□ 案例模板：读题圈条件 → 已知所求依据 → 分步列式 → 检查 → 结论句
□ 三不准：安全文明施工费、规费、税金——不得作为竞争性费用
□ 心态：先做会的、写步骤、写单位、写结论；时间到就切题
```

> ### ⚠️ 底线提醒
>
> **严禁证书挂靠**——挂靠违法违规，社保联网后基本被堵死，造价文件一旦出问题，**签字人与持证人都要担责**。取得证书后请**证随人走、到岗履职**，用**独立出具的造价成果**换取职业回报。
