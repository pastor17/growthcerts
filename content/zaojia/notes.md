> 通用方法见 [备考笔记怎么用](/zhichang/biji/)；本页只讲**一级造价专属**内容。**涉及报考条件、时间、合格标准与注册管理规定，一律以中国人事考试网及当地考试机构当次公告为准。**

## 该记什么（四科必背清单）

**《建设工程造价管理》**

| 模块 | 必背内容 | 记忆方式 |
|------|---------|---------|
| 造价管理基本制度 | 造价工程师执业范围、注册与继续教育、造价咨询企业管理相关要求 | 关键词对照（**以现行规定为准**） |
| 工程经济 | **资金时间价值**公式（现值、终值、年金、偿债基金）、名义利率与实际利率换算 | **公式 + 单位**，必动手推 |
| 经济效果评价 | NPV、IRR、静态/动态回收期、互斥方案比选方法 | 判据记"**符号与比较对象**" |
| 价值工程 | 价值 = 功能 / 成本、功能评价与改进方向 | 一句话公式 + 应用场景 |
| 投融资 | 项目资本金、融资方式、资金成本、资本结构 | 分类表格化 |
| 合同管理 | 合同类型与选择、权利义务、违约责任、索赔与争议解决 | **对比表**（工期/费用/风险归属） |
| 招投标 | 招标方式、程序时限、评标方法、废标情形 | **时间节点 + 情形清单** |
| 全过程造价管理 | 决策/设计/招投标/施工/竣工各阶段造价工作内容与限额设计 | **阶段-动作**两列对照 |

**《建设工程计价》**

| 模块 | 必背内容 | 记忆方式 |
|------|---------|---------|
| **造价构成** | 分部分项工程费、措施项目费、其他项目费、规费、税金 | **五段骨架**，任何造价文件都按它拆 |
| **计价程序** | 综合单价组成、单位工程造价计算程序、取费基数 | **程序表**（顺序错就错） |
| **定额** | 定额分类、消耗量（人材机）、定额换算与补充 | 记**换算方向**（增/减、乘系数） |
| **清单计价** | 清单五要素（项目编码/名称/特征/计量单位/工程量）、项目特征的作用、招标控制价与投标报价 | **五要素口诀** + 特征描述的作用 |
| **投资估算与设计概算** | 估算方法、概算编制与审查、**限额设计** | 方法名称 + 适用阶段 |
| **合同价款调整** | 工程量偏差、物价波动、法规变化、工程变更、索赔、现场签证 | **情形 → 调整公式** 对照表 |
| **结算与决算** | 进度款、竣工结算、质量保证金、竣工决算构成 | **时间节点 + 比例限制**（以现行规定为准） |
| 计价依据 | 预算定额、费用定额、造价信息、市场价格 | 分清**信息价 vs 市场价** |

**《建设工程技术与计量》（按所选专业）**

| 模块 | 必背内容 | 记忆方式 |
|------|---------|---------|
| **识图** | 平立剖面与详图关系、**平法**表示规则、构件编号与配筋表达 | **看图说话**：拿一张真实图纸逐项说 |
| **工程构造** | 基础、墙体、楼板、屋面、门窗、装饰、楼梯等做法与分层 | **构造层次图**（从上到下/从里到外） |
| **工程材料** | 常用材料性能、规格与适用部位 | 分类 + 关键词 |
| **施工技术** | 土方、桩基、混凝土、砌筑、防水、装饰、安装等主要工艺 | **工序链**记忆（先什么后什么） |
| **计量规则** | 面积/体积/长度计算规则、**扣减关系**、不扣除与不增加的情形 | **口诀 + 扣减清单**，必背 |
| 专业专属 | 各自专业的构件分类、系统组成、计量要点 | 按专业教材章节逐条过 |

**《建设工程造价案例分析》**

| 模块 | 必背内容 | 记忆方式 |
|------|---------|---------|
| **投资估算** | 建设投资构成、**建设期利息**、流动资金估算 | 公式 + 计算顺序 |
| **财务评价** | 还本付息、总成本费用、利润、财务指标计算 | **报表结构**（先算什么后算什么） |
| **设计概算 / 施工图预算** | 概算编制方法、预算编制（清单 + 组价 + 取费） | 走一遍**完整算例** |
| **清单计价与计量** | 清单编制、综合单价组价、措施费与其他项目费计算 | 计量规则 + 组价步骤 |
| **合同价款管理** | 变更、调价、偏差、**索赔（工期与费用）**、现场签证 | **情形 → 依据 → 计算** 三步 |
| **结算与决算** | 结算编制与审核、审减处理、质量保证金 | 按流程列清单 |
| **方案比选** | 价值工程、寿命周期成本、多方案经济比较 | 判据 + 计算模板 |

> **一条经验**：**前三科记"规则"，案例分析记"步骤"**——案例题不是选择题，**步骤分比答案重要**，把每类题型的解题步骤写成固定模板，考场照着走。

## 记忆方法（口诀与表格化）

**口诀速记**

| 口诀 | 对应内容 |
|------|---------|
| **"分措其规税"** | 造价构成五段：**分**部分项、**措**施项目、**其**他项目、**规**费、**税**金 |
| **"编名特量单"** | 清单五要素：项目**编**码、项目**名**称、项目**特**征、工程**量**、计量**单**位 |
| **"估概预结决"** | 五阶段造价：投**资估算** → 设计**概算** → 施工图**预算** → 工程**结算** → 竣工**决算** |
| **"管规价计案"** | 四科简称：造价**管**理、计价、技术与计量、**案**例分析（后两科分专业） |
| **"招投评合签"** | 交易链条：**招**标 → **投**标 → **评**标 → 定标签**合**同 → 履**签**变更 |
| **"变调签索偏"** | 价款调整五大情形：**变**更、**调**价（物价波动）、**签**证、**索**赔、**偏**差（工程量） |
| **"人材机管利"** | 综合单价组成要素：**人**工、**材**料、**机**械、**管**理费、**利**润 |
| **"面体长扣增"** | 计量四动作：算**面**积、算**体**积、算**长**度、处理**扣**减与不**增**加 |

**表格化记忆（比背段落有效得多）**

- **对比表**：合同类型对比（工期/费用/风险归属）、估算 vs 概算 vs 预算 vs 结算（阶段/依据/精度/用途）；
- **流程表**：招投标程序与时限、索赔程序、结算流程——**顺序是考点**；
- **对照表**：计量规则中的<strong>"应计算/不计算""扣除/不扣除""增加/不增加"</strong>做成三列清单；
- **公式卡**：资金时间价值与财务评价公式写在一张卡上（见[一页速记](/zaojia/cheatsheet/)），每天默写一遍。

**三个提升效率的动作**

1. **错题归类而不是抄题**——错因只写三类：**规则没记住 / 公式用错 / 读题漏条件**；
2. **用真实图纸练计量**——找一张做过或公开的图纸，按规则**手算一遍**并与软件结果对比；
3. **费曼式复述**——对每个高频考点，用 3 句话讲给外行听，讲不清就是没懂。

## 10 条避坑清单

1. **❌ 只背重点不做案例题**——**案例分析是分水岭**，前三科过、案例不过是最常见的失败模式；
2. **❌ 用旧版规范备考**——计量规则与项目特征随规范更新变化，**以现行有效版本为准**；
3. **❌ 不看大纲先买资料**——先按大纲搭地图，再选资料，否则容易被机构营销牵着走；
4. **❌ 计价程序靠理解不靠背**——取费基数与顺序**必须背准**，理解不能替代精确；
5. **❌ 计量规则记大概**——扣减关系差一点，算量结果就错一片；**规则要精确**；
6. **❌ 专业方向随便选或中途改**——专业与识图、计量规则绑定，**跨专业等于从零学**；
7. **❌ 报名信息"差不多就行"**——实行**告知承诺制**，虚假承诺会导致**成绩无效、记入诚信档案**；
8. **❌ 相信"包过""押题""代报名"**——全国统一命题，**没有人能保证结果**，这些都指向骗局或违规；
9. **❌ 想着"考完挂靠收钱"**——**挂靠违法违规**，社保联网后基本被堵死，**签字要担责**；请**证随人走、到岗履职**；
10. **❌ 考前一周还在开新题**——冲刺期只做三件事：**过速记页、过错题、调状态**。

## 冲刺阶段安排

**考前 4 周：从"学"切到"考"**

| 时间 | 重点 | 每天安排（在职参考） |
|------|------|-------------------|
| **考前 4 周** | 案例题型定型 | 1 道完整案例（限时手写）+ 1 章客观题错题回看 |
| **考前 3 周** | 计量规则回炉 | 计量扣减清单过 2 遍 + 计价程序表默写 |
| **考前 2 周** | 客观题提速 | 每科 1 套限时模拟 + 错题归类（三类错因） |
| **考前 1 周** | 只看自己的东西 | 速记页 + 错题本 + 公式卡，**不开新资料** |
| **考前 3 天** | 状态管理 | 过速记页、核对待考证件与考场路线，**不熬夜、不做新题** |
| **考前一晚** | 清单确认 | 准考证、身份证件、计算器（**按考场规定**）、文具 |

**考场策略（主观案例题）**

```text
① 先通读全卷，按「会的先做、能拿步骤分的先写」排序
② 每道案例先写「已知/所求/依据」，再动笔计算——步骤本身就是分
③ 计量与计价计算写明单位与公式来源，避免"答案对但没分"
④ 时间到就切题，不要在单题上耗到后面空白
⑤ 全部答完后回看：有没有漏问、有没有单位与小数位错误
```

**最后三条提醒**

- **合格标准一般按满分 60% 相对固定，但以当次公告为准**——目标定在**高于合格线一档**，不要压线备考；
- **滚动周期是"连续年度"**：考全科 **4 个年度内**、免二科 **2 个年度内**（**以当次公告为准**），**做一张四年进度表**记清每科合格年份；
- **职业底线**：**严禁证书挂靠**——违法违规、社保联网后基本被堵死、出事故要担责；**证随人走、到岗履职**才是唯一正路。
