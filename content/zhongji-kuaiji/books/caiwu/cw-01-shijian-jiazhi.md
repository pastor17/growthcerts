## 考点梳理

### 1.1 资金时间价值：六个基本公式

设现值 PV、终值 FV、利率 i、期数 n、年金 A。

| 名称 | 公式 | 用途 |
|------|------|------|
| **复利终值** | FV = PV × (1 + i)^n | 今天的钱 N 年后值多少 |
| **复利现值** | PV = FV ÷ (1 + i)^n | N 年后的钱今天值多少 |
| **普通年金终值** | FVA = A × [(1 + i)^n − 1] ÷ i | 每期等额存入，到期总额 |
| **普通年金现值** | PVA = A × [1 − (1 + i)^−n] ÷ i | 每期等额收付，折算到今天 |
| **预付年金现值** | 普通年金现值 × (1 + i) | 期初收付（比普通年金多一期利息） |
| **永续年金现值** | PV = A ÷ i | 无限期等额收付 |

**预付年金与递延年金的处理口诀**：

- **预付年金**（期初收付）：在普通年金基础上**乘 (1 + i)**；或「期数减 1、系数加 1」；
- **递延年金**（前 m 期无收付）：先按普通年金折到**第一次收付的前一期**，再折现 m 期到今天。

> **系数关系速记**：复利终值系数与复利现值系数**互为倒数**；年金终值系数与偿债基金系数互为倒数；年金现值系数与资本回收系数互为倒数。

### 1.2 风险与收益的衡量

| 指标 | 公式 / 含义 | 适用 |
|------|-----------|------|
| **期望收益率** | Σ（各情形收益率 × 该情形概率） | 衡量**预期**收益水平 |
| **方差 / 标准差** | 各情形收益率与期望值离差的加权平方和开方 | 衡量**绝对**风险 |
| **标准差率（变异系数）** | 标准差 ÷ 期望值 | 衡量**相对**风险，**期望值不同时用它比较** |
| **β 系数** | 衡量**系统风险**（不可分散风险） | 资本资产定价模型的核心参数 |

**风险分类**：

- **系统风险**（市场风险）——影响所有资产，**不能通过分散消除**，用 β 衡量；
- **非系统风险**（特有风险）——可通过**投资组合分散**降低。

### 1.3 资本资产定价模型（CAPM）

```text
必要收益率 = 无风险收益率 + β ×（市场组合收益率 − 无风险收益率）
                        └──────── 市场风险溢价 ────────┘
```

| 情形 | 结论 |
|------|------|
| β = 1 | 与市场同步波动 |
| β > 1 | 波动大于市场（进攻型） |
| β < 1 | 波动小于市场（防御型） |

### 1.4 资本成本

| 来源 | 计算要点 |
|------|---------|
| **债务资本成本** | 税后成本 = 税前利率 × (1 − 所得税税率)（利息可抵税） |
| **优先股成本** | 优先股股利 ÷ 筹资净额（股利**不能**抵税） |
| **普通股成本** | 常见方法：**股利增长模型**（D₁ ÷ P₀ + g）、**CAPM 法** |
| **留存收益成本** | 与普通股成本思路相近，但**不考虑筹资费用** |
| **加权平均资本成本（WACC）** | Σ（各类资本**账面/市场价值比重** × 该类资本成本） |

> 记忆锚：**「债务成本要乘（1 − T），权益成本不抵税」**。

### 1.5 三大杠杆

| 杠杆 | 公式 | 含义 |
|------|------|------|
| **经营杠杆 DOL** | 边际贡献 ÷ 息税前利润（EBIT） | 销售变动对 EBIT 的放大作用，源于**固定经营成本** |
| **财务杠杆 DFL** | EBIT ÷ (EBIT − 利息) | EBIT 变动对每股收益的放大作用，源于**固定财务费用** |
| **总杠杆 DTL** | DOL × DFL | 销售变动对每股收益的综合放大作用 |

**关键关系**：

```text
EBIT = 边际贡献 − 固定经营成本
边际贡献 = 销售收入 − 变动成本
息税前利润 − 利息 = 税前利润 → 减去所得税 → 净利润 → 每股收益
```

## 🧠 记忆工具箱

### 口诀速记

- **时间价值**：「**终值往前滚，现值往回折；预付乘一加 i，递延先折再折**」；
- **风险比较**：「**期望值相同比标准差，期望值不同比标准差率**」；
- **CAPM**：「**无风险打底，β 拿风险溢价**」；
- **资本成本**：「**债要抵税，股不抵税**」；
- **杠杆**：「**经营杠杆看固定成本，财务杠杆看固定利息，总杠杆两者相乘**」。

### 场景锚点

| 场景 | 你要用的方法 |
|------|-------------|
| 分期付款方案比较（首付 + 月供） | 把月供折成**年金现值**，加首付与一次性付款比较 |
| 银行贷款利率 6%，所得税 25% | 税后债务成本 = 6% × (1 − 25%) |
| 两个项目期望收益不同 | 用**标准差率**比较风险 |
| 计算项目折现率 | 用 **CAPM** 或 **WACC** |
| 判断公司经营风险 | 看**经营杠杆系数**与固定成本占比 |
| 永续债、优先股估值 | 用**永续年金现值**公式 |

## ⚠️ 易错提醒

- **错误认知**：期望值不同时直接比标准差。**纠正**：期望值不同应比**标准差率**（变异系数），否则会得出误导结论。
- **错误认知**：预付年金直接套普通年金公式。**纠正**：预付年金要**乘 (1 + i)**（或「期数减 1、系数加 1」），因为它比普通年金多计一期利息。
- **错误认知**：债务资本成本直接用利率。**纠正**：债务利息可抵税，应用**税后成本 = 税前利率 × (1 − T)**。
- **错误认知**：优先股股利可以抵税。**纠正**：**股利不能税前扣除**，权益类资本成本均不考虑抵税。
- **错误认知**：财务杠杆只看负债规模。**纠正**：财务杠杆系数取决于**EBIT 与利息的关系**，同样负债下 EBIT 越低，杠杆效应越强、风险越大。
- **错误认知**：非系统风险无法消除。**纠正**：**非系统风险可通过分散投资降低**，**系统风险才是不可分散的**。
