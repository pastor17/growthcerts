## 考点梳理

### 2.1 预算编制方法

| 方法 | 特点 | 适用 |
|------|------|------|
| **固定预算** | 按某一业务量水平编制 | 业务量稳定时 |
| **弹性预算** | 按**多个业务量水平**编制，可随业务量调整 | 业务量波动大 |
| **增量预算** | 以**上期实际**为基础调整 | 变化不大时（易继承低效） |
| **零基预算** | **一切从零**开始，逐项审议必要性 | 费用控制、资源重新配置 |
| **定期预算** | 按固定期间（如年度）编制 | 常规 |
| **滚动预算** | 预算期**逐期向后滚动**，始终保持固定长度 | 需要持续预测 |

### 2.2 预算体系与编制顺序

```text
① 销售预算（起点，决定一切）
   ↓
② 生产预算（预计销量 + 期末存货 − 期初存货）
   ↓
③ 直接材料 / 直接人工 / 制造费用预算
   ↓
④ 销售与管理费用预算
   ↓
⑤ 现金预算（经营 + 投资 + 筹资 → 期末现金余额）
   ↓
⑥ 预计利润表、预计资产负债表
```

| 预算 | 关键公式 |
|------|---------|
| **生产预算** | 预计生产量 = 预计销量 + 预计期末存货 − 预计期初存货 |
| **材料采购预算** | 预计采购量 = 生产需用量 + 期末材料存货 − 期初材料存货 |
| **现金预算** | 期末现金 = 期初现金 + 经营/投资/筹资现金流入 − 流出（不足则安排融资） |

### 2.3 量本利分析（CVP）

| 概念 | 公式 |
|------|------|
| **边际贡献** | 销售收入 − 变动成本 |
| **单位边际贡献** | 单价 − 单位变动成本 |
| **边际贡献率** | 边际贡献 ÷ 销售收入 = 单位边际贡献 ÷ 单价 |
| **变动成本率** | 变动成本 ÷ 销售收入；**变动成本率 + 边际贡献率 = 1** |
| **保本销售量** | **固定成本 ÷ 单位边际贡献** |
| **保本销售额** | 固定成本 ÷ 边际贡献率 |
| **安全边际量** | 实际（预计）销售量 − 保本销售量 |
| **安全边际率** | 安全边际量 ÷ 实际（预计）销售量 |
| **目标利润销售量** | （固定成本 + 目标利润）÷ 单位边际贡献 |

> 记忆锚：**「保本点就是让边际贡献刚好覆盖固定成本的那个销量」**。

### 2.4 标准成本与差异分析

| 差异 | 公式 |
|------|------|
| **直接材料价差** | （实际单价 − 标准单价）× **实际用量** |
| **直接材料量差** | （实际用量 − 标准用量）× **标准单价** |
| **直接人工工资率差异** | （实际工资率 − 标准工资率）× **实际工时** |
| **直接人工效率差异** | （实际工时 − 标准工时）× **标准工资率** |
| **变动制造费用耗费差异** | （实际分配率 − 标准分配率）× 实际工时 |
| **变动制造费用效率差异** | （实际工时 − 标准工时）× 标准分配率 |

> 记忆锚：**「价差用实际量，量差用标准价」**——这是差异分析最常考的口诀。

### 2.5 作业成本法（ABC）

| 概念 | 含义 |
|------|------|
| **作业** | 消耗资源的活动（如机器调试、质量检验、订单处理） |
| **成本动因** | 引起作业成本变动的因素（如调试次数、检验次数、订单数） |
| **与传统成本法差异** | 传统法常按**单一数量动因**（如直接人工工时）分配；ABC 按**多动因**分配，**产量低、复杂度高的产品成本会被低估纠正** |
| **适用场景** | 产品种类多、间接费用占比高、复杂度差异大 |

## 🧠 记忆工具箱

### 口诀速记

- **预算起点**：「**销售预算一发动全身**」；
- **生产预算**：「**销 + 末 − 初 = 产**」；
- **保本点**：「**固定成本 ÷ 单位边际贡献**」；
- **差异分析**：「**价差乘实量，量差乘标价**」；
- **弹性 vs 零基**：「**弹性随量变，零基从头算**」。

### 场景锚点

| 场景 | 你要用的方法 |
|------|-------------|
| 编制年度预算 | 从**销售预算**出发，逐级推到预计报表 |
| 老板问「卖多少才不亏」 | 算**保本销售量 = 固定成本 ÷ 单位边际贡献** |
| 预算现金流出现缺口 | 用**现金预算**安排融资时点与额度 |
| 材料成本超支查原因 | **价差**（采购价格）还是**量差**（生产耗用） |
| 车间人工成本超预算 | 区分**工资率差异**与**效率差异** |
| 间接费用高、产品种类多 | 考虑**作业成本法** |

## ⚠️ 易错提醒

- **错误认知**：保本点用「固定成本 ÷ 单价」。**纠正**：应除以**单位边际贡献**（单价 − 单位变动成本），否则漏掉变动成本。
- **错误认知**：差异分析里价差和量差都乘实际数。**纠正**：**价差乘实际用量，量差乘标准单价**，这是标准公式。
- **错误认知**：预算起点是利润预算。**纠正**：起点是**销售预算**，其余预算都由销量推导而来。
- **错误认知**：弹性预算就是在上期基础上调。**纠正**：那是**增量预算**；弹性预算是按**多个业务量水平**分别编制。
- **错误认知**：零基预算等于「砍预算」。**纠正**：零基预算是**逐项审议必要性**，重点在资源重新配置而非简单削减。
- **错误认知**：作业成本法一定更准确、应普遍采用。**纠正**：ABC 有**实施成本高**的问题，适用于间接费用占比高、产品复杂度差异大的场景。
