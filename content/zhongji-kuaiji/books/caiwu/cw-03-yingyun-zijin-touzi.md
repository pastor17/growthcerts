## 考点梳理

### 3.1 营运资金管理总览

```text
营运资金 = 流动资产 − 流动负债
现金周转期 = 存货周转期 + 应收账款周转期 − 应付账款周转期
```

**目标**：在**流动性与收益性**之间权衡——营运资金过多降低收益，过少则加大偿债风险。

| 策略 | 特点 |
|------|------|
| **激进型（紧缩）** | 流动资产占比低、短期负债多 → 收益高、风险大 |
| **保守型（宽松）** | 流动资产占比高、长期资金多 → 风险低、收益低 |
| **适中型** | 在风险与收益间平衡 |

### 3.2 现金管理

| 模型 | 要点 |
|------|------|
| **成本分析模型** | 权衡**机会成本、管理成本、短缺成本**，总成本最低时持有量最优 |
| **存货模型（鲍莫尔）** | 现金持有量 = √(2 × 一定期间现金需要量 × 每次转换成本 ÷ 有价证券利率) |
| **随机模型（米勒—奥尔）** | 设定上限与下限，达到上限买入证券、降至下限卖出证券 |

**现金持有动机**：交易性、预防性、投机性。

### 3.3 存货管理

| 概念 | 公式 / 要点 |
|------|-----------|
| **经济订货量（EOQ）** | √(2 × 年需求量 D × 每次订货成本 K ÷ 单位储存成本 Kc) |
| **相关总成本** | 订货成本 + 储存成本（EOQ 处两者相等） |
| **再订货点** | 平均日需求 × 交货时间 |
| **保险储备** | 应对交货延迟或需求波动 |
| **ABC 分类法** | A 类（品种少、价值高）重点管理；C 类（品种多、价值低）简化管理 |

### 3.4 应收账款管理

| 要素 | 内容 |
|------|------|
| **信用标准** | 是否给予信用的门槛（常用 **5C**：品质、能力、资本、抵押、条件） |
| **信用条件** | 信用期 + 现金折扣（如「2/10，n/30」） |
| **收账政策** | 催收力度与方式，需权衡**收账成本**与**坏账损失** |
| **决策方法** | 比较不同信用政策的**收益增加**与**成本增加**（机会成本 + 坏账损失 + 收账费用 + 折扣成本） |
| **账龄分析** | 按欠款时间分档，识别高风险客户（考试常结合坏账计提） |

### 3.5 短期融资方式

| 方式 | 特点 |
|------|------|
| **商业信用** | 应付账款、应付票据；放弃现金折扣的**机会成本**通常很高 |
| **短期借款** | 周转信贷协定、补偿性余额（**实际利率上升**） |
| **票据贴现 / 应收账款保理** | 快速回笼资金，但承担贴现息或保理费 |

### 3.6 项目投资决策

**现金流估算三步**：

```text
① 初始现金流量：固定资产投资、营运资金垫支、旧资产变现及税负影响
② 营业现金流量：营业收入 − 付现成本 − 所得税（或用「净利润 + 折旧」）
③ 终结现金流量：残值回收、营运资金收回
```

| 指标 | 公式 | 决策规则 |
|------|------|---------|
| **净现值 NPV** | 未来现金净流量现值 − 原始投资额现值 | **NPV ≥ 0 可行**（互斥项目选 NPV 最大） |
| **内含报酬率 IRR** | 使 NPV = 0 的折现率 | **IRR ≥ 必要报酬率可行** |
| **现值指数 PI** | 未来现金净流量现值 ÷ 原始投资额现值 | **PI ≥ 1 可行** |
| **静态回收期** | 累计现金净流量 = 原始投资所需时间 | 越短越好，**未考虑时间价值** |
| **折现回收期** | 累计折现现金净流量回收投资的时间 | 考虑了时间价值 |

**NPV 与 IRR 冲突时**：**以 NPV 为准**（NPV 直接反映价值增加额，且假定再投资报酬率为资本成本）。

**固定资产更新决策**：通常比较**继续使用旧设备**与**购置新设备**的**年均成本（等额年金成本）**，取较低者；注意旧设备变现价值与其账面价值的**所得税影响**。

## 🧠 记忆工具箱

### 口诀速记

- **营运资金**：「**现金周转期 = 存货 + 应收 − 应付**」；
- **EOQ**：「**根号下 2DK 除以 Kc**」；
- **投资决策**：「**NPV 是王，冲突听 NPV**」；
- **三阶段现金流**：「**初始投、期间营、期末收**」；
- **信用决策**：「**收益加、成本减，机会成本别忘掉**」。

### 场景锚点

| 场景 | 你要用的方法 |
|------|-------------|
| 该留多少现金 | **成本分析模型 / 存货模型 / 随机模型** |
| 采购批量多大最省 | **经济订货量 EOQ** |
| 客户要求延长账期 | 比较**收益增加**与**机会成本 + 坏账损失增加** |
| 是否上一条新产线 | 算 **NPV / IRR**，NPV 优先 |
| 旧设备要不要换 | 比较新旧设备的**年均成本** |
| 库存怎么管 | **ABC 分类法** + 再订货点与保险储备 |

## ⚠️ 易错提醒

- **错误认知**：NPV 与 IRR 结论冲突时按 IRR 决策。**纠正**：**以 NPV 为准**（IRR 隐含再投资报酬率假设不现实，且规模差异下会误导）。
- **错误认知**：回收期考虑了时间价值。**纠正**：**静态回收期不考虑**时间价值，只有**折现回收期**才考虑。
- **错误认知**：投资决策只看利润。**纠正**：决策依据是**现金流量**，不是会计利润；折旧本身不是现金流出，但会影响所得税。
- **错误认知**：旧设备变现价值可以忽略。**纠正**：更新决策中旧设备变现价值是**机会成本**，且变现价与账面价值的差额会产生**所得税影响**。
- **错误认知**：补偿性余额不影响借款成本。**纠正**：补偿性余额使**可用资金减少、实际利率上升**。
- **错误认知**：EOQ 处订货成本最小。**纠正**：EOQ 处**订货成本与储存成本之和最小**，两者恰好相等。
