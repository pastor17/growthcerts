## 考点梳理

### 4.1 四大能力指标速查

**① 偿债能力**

| 指标 | 公式 | 说明 |
|------|------|------|
| **流动比率** | 流动资产 ÷ 流动负债 | 短期偿债能力，一般参考值 2 左右（**行业差异大**） |
| **速动比率** | （流动资产 − 存货）÷ 流动负债 | 剔除变现最慢的存货 |
| **现金比率** | （货币资金 + 交易性金融资产）÷ 流动负债 | 最保守 |
| **资产负债率** | 负债总额 ÷ 资产总额 | 长期偿债能力与财务风险 |
| **产权比率** | 负债总额 ÷ 所有者权益 | 资本结构 |
| **权益乘数** | 资产总额 ÷ 所有者权益 = 1 ÷ (1 − 资产负债率) | 杠杆倍数 |
| **利息保障倍数** | 息税前利润 ÷ 利息费用 | 付息能力 |

**② 营运能力**

| 指标 | 公式 |
|------|------|
| **应收账款周转率** | 营业收入 ÷ 平均应收账款；**周转天数 = 360 ÷ 周转率** |
| **存货周转率** | 营业成本 ÷ 平均存货（**注意用成本而非收入**） |
| **流动资产周转率** | 营业收入 ÷ 平均流动资产 |
| **总资产周转率** | 营业收入 ÷ 平均总资产 |

**③ 盈利能力**

| 指标 | 公式 |
|------|------|
| **营业净利率** | 净利润 ÷ 营业收入 |
| **总资产净利率（ROA）** | 净利润 ÷ 平均总资产 |
| **净资产收益率（ROE）** | 净利润 ÷ 平均所有者权益 |
| **成本费用利润率** | 利润总额 ÷ 成本费用总额 |
| **每股收益（EPS）** | 归属于普通股股东的净利润 ÷ 发行在外普通股加权平均数 |

**④ 发展能力**

| 指标 | 公式 |
|------|------|
| **营业收入增长率** | 本期营业收入增加额 ÷ 上期营业收入 |
| **总资产增长率** | 本期总资产增加额 ÷ 期初总资产 |
| **资本保值增值率** | 期末所有者权益 ÷ 期初所有者权益 |

### 4.2 杜邦分析体系（必考）

```text
净资产收益率（ROE）= 营业净利率 × 总资产周转率 × 权益乘数
                    └ 盈利能力 ┘  └ 营运能力 ┘  └ 财务杠杆 ┘
```

**因素分析（连环替代法）**：依次替换各因素，**每次只替换一个**，用「替换后 − 替换前」确定该因素的影响额；**替换顺序会影响各因素影响额，但不影响总差异**。

**杜邦分析的价值**：把「股东回报高低」拆成**赚钱能力、资产效率、杠杆水平**三条可改进的路径，是管理层沟通与经营分析会最常用的工具。

### 4.3 综合绩效评价

| 方法 | 要点 |
|------|------|
| **综合评分法** | 各指标按权重打分汇总（如沃尔评分法） |
| **经济增加值（EVA）** | EVA = 税后净营业利润 − **资本成本（含权益资本成本）**；**EVA > 0 才真正创造价值** |
| **平衡计分卡（BSC）** | 四个维度：**财务、客户、内部流程、学习与成长** |
| **关键绩效指标（KPI）** | 从战略目标分解为可量化指标 |

> **EVA 的核心意义**：会计利润为正**不等于**创造价值——只有**超过全部资本（含权益）成本**的收益才是真正的价值增加。

## 🧠 记忆工具箱

### 口诀速记

- **偿债**：「**流动比看短期，资产负债率看长期，利息保障看付息**」；
- **营运**：「**应收用收入，存货用成本**」；
- **杜邦**：「**净利率 × 周转率 × 权益乘数 = ROE**」；
- **权益乘数**：「**资产 ÷ 权益，也等于 1 ÷ (1 − 资产负债率)**」；
- **EVA**：「**利润超资本成本才叫创造价值**」。

### 场景锚点

| 场景 | 你要用的方法 |
|------|-------------|
| 月度经营分析会 | **杜邦分解**说明 ROE 变化来自哪一项 |
| 客户回款变慢 | 看**应收账款周转天数**与账龄结构 |
| 库存积压 | 看**存货周转率**（用营业成本）与 ABC 分类 |
| 判断公司是否真赚钱 | 算 **EVA**，与会计利润对比 |
| 设计部门考核 | **平衡计分卡**四维度 + KPI |
| 评估扩张是否靠杠杆 | 看**权益乘数**与**资产负债率**趋势 |

## ⚠️ 易错提醒

- **错误认知**：流动比率越高越好。**纠正**：过高说明**流动资产闲置**、资金效率低，应在流动性与收益性间权衡。
- **错误认知**：存货周转率用营业收入作分子。**纠正**：**存货周转率用营业成本**（存货按成本计价），应收账款周转率才用营业收入。
- **错误认知**：杜邦分析只算一个 ROE 就够。**纠正**：要**因素分解**，找出是净利率、周转率还是权益乘数在变化，才能提出改进动作。
- **错误认知**：连环替代法的替换顺序可以随意。**纠正**：**顺序会影响各因素的影响额**，应按规定或合理顺序（通常先数量后质量、先基础后派生）并保持一致。
- **错误认知**：会计利润为正就是创造价值。**纠正**：只有 **EVA > 0**（超过全部资本成本）才是真正创造价值。
- **错误认知**：财务指标可以直接跨行业比较。**纠正**：**行业差异极大**（如零售与重资产制造业），应**与同行业、与自身历史**比较，**并以企业实际数据与公开披露为准**。
