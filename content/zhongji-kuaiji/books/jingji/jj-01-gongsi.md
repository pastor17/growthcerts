## 考点梳理

### 1.1 公司的两种基本形式

| 维度 | 有限责任公司 | 股份有限公司 |
|------|-------------|-------------|
| **股东人数** | 一般由**一定人数以下**股东出资设立（**以现行公司法为准**） | 发起人符合法定人数（**以现行公司法为准**） |
| **股权/股份形式** | 出资证明书，**股权转让受限** | 股票，**股份转让相对自由** |
| **组织机构** | 股东会、董事会（或执行董事）、监事会（或监事） | 股东大会、董事会、监事会 |
| **信息公开** | 相对封闭 | 相对公开（上市公司另有披露义务） |
| **典型场景** | 中小企业 | 拟上市、公众公司 |

### 1.2 出资规则

| 项目 | 要点 |
|------|------|
| **可以出资** | 货币、实物、知识产权、土地使用权等可以用货币估价并可依法转让的财产 |
| **不得出资** | 劳务、信用、自然人姓名、商誉、特许经营权、设定担保的财产等（**以现行公司法与登记规定为准**） |
| **非货币出资** | 应评估作价、依法办理财产权转移手续；**不得高估或低估** |
| **出资责任** | 未按期足额缴纳的，应向公司补足并对其他股东承担**违约责任**；设立时其他股东可能承担**连带责任**（**以现行公司法为准**） |
| **抽逃出资** | 股东不得抽逃出资，违者需返还并承担相应责任 |

### 1.3 组织机构与决议规则

| 机构 | 主要职权 |
|------|---------|
| **股东会 / 股东大会** | 决定经营方针与投资计划、选举更换董事监事、审议批准财务预算与利润分配、增减注册资本、合并分立解散、修改章程 |
| **董事会** | 执行股东会决议、决定经营计划与投资方案、内部管理机构设置、聘任高级管理人员 |
| **监事会** | 检查财务、监督董事与高管、提议召开临时股东会、列席董事会 |
| **经理（高级管理人员）** | 主持生产经营管理、组织实施董事会决议 |

**决议表决**（**具体比例以现行公司法与公司章程为准**）：

- **普通决议**：一般由出席会议的股东**所持表决权过半数**通过；
- **特别决议**：修改章程、增加或减少注册资本、合并、分立、解散、变更公司形式等，一般需**三分之二以上**表决权通过。

> 记忆锚：**「重大事项三分之二，一般事项过半数」**。

### 1.4 股权转让

| 情形 | 规则要点 |
|------|---------|
| **股东之间转让** | 一般可自由转让（**以公司章程约定为准**） |
| **向股东以外的人转让** | 一般需**其他股东过半数同意**，且其他股东在同等条件下有**优先购买权**（**以现行公司法为准**） |
| **人民法院强制执行股权** | 应通知全体股东，其他股东在同等条件下有优先购买权 |
| **股份公司股份转让限制** | 发起人、董监高等持股转让有**期限与比例限制**（**以现行公司法为准**） |

### 1.5 董事、监事、高级管理人员的义务

- **忠实义务**：不得利用职权收受贿赂、侵占公司财产、挪用资金、违规担保、自我交易（未经程序）；
- **勤勉义务**：应尽到管理者应有的注意；
- **违反后果**：所得收入归公司所有，造成损失应予赔偿；构成犯罪依法追责。

### 1.6 合伙企业：普通 vs 有限

| 维度 | **普通合伙企业** | **有限合伙企业** |
|------|----------------|----------------|
| **合伙人类型** | 全部为普通合伙人（GP） | 至少 1 个 GP + 至少 1 个 LP（**人数以法律为准**） |
| **责任形式** | 全体承担**无限连带责任** | GP 承担**无限连带责任**，LP 以**认缴出资额为限** |
| **事务执行** | 全体共同执行或委托部分合伙人执行 | **仅 GP 执行事务**，LP **不执行**合伙事务、不得对外代表 |
| **LP 的限制** | — | LP 不得以劳务出资；若 LP 越权执行事务致第三人信赖，可能承担与 GP 相同的责任 |
| **出资** | 可用劳务出资 | GP 可用劳务出资，**LP 不可**（**以合伙企业法为准**） |
| **利润分配** | 按合伙协议约定；未约定按实缴出资比例；无法确定则平均分配 | 有限合伙企业**不得将全部利润分配给部分合伙人**（**以法律为准**） |

**入伙与退伙**：

- **入伙**：新合伙人对入伙前的合伙企业债务承担**无限连带责任**（普通合伙人）；
- **退伙**：退伙人对退伙前发生的债务仍承担**无限连带责任**（普通合伙人）；
- **当然退伙/除名**：法定情形出现时依法处理。

## 🧠 记忆工具箱

### 口诀速记

- **决议**：「**改章增减并分解，三分之二才通过**」；
- **出资禁区**：「**劳务信用姓名商誉，特许经营权担保物**」（**公司**股东不得用于出资）；
- **合伙责任**：「**GP 无限连带，LP 出资为限**」；
- **GP vs LP**：「**GP 管事担无限，LP 出钱不理事**」；
- **转让**：「**内部自由外部受限，老股东有优先购买权**」。

### 场景锚点

| 场景 | 你要做的判断 |
|------|-------------|
| 股东想用「自己的名气」出资 | **不得**以姓名、信用、劳务出资（公司） |
| 公司要修改章程 | 属**特别决议**，一般需三分之二以上表决权 |
| 大股东要卖股权给外人 | 看章程约定与其他股东的**优先购买权** |
| 有限合伙的 LP 想参与管理 | **不得执行合伙事务**，否则可能承担 GP 责任 |
| 新合伙人入伙 | 对入伙前债务承担**无限连带责任** |
| 公司减资 | 需走**特别决议 + 法定程序**（含债权人保护） |

## ⚠️ 易错提醒

- **错误认知**：公司股东可以劳务出资。**纠正**：**公司**股东不得以**劳务、信用、姓名、商誉、特许经营权**等出资；劳务出资只适用于**普通合伙人**。
- **错误认知**：股东会所有决议都只需过半数。**纠正**：修改章程、增减注册资本、合并分立解散、变更形式属**特别决议**，一般需**三分之二以上**表决权。
- **错误认知**：向外部人转让股权无需其他股东同意。**纠正**：一般需**其他股东过半数同意**，且其他股东享有**同等条件下的优先购买权**（**以现行公司法与章程为准**）。
- **错误认知**：有限合伙人可以随便代表企业签合同。**纠正**：**LP 不执行合伙事务、不得对外代表企业**；越权致第三人信赖可能**承担与 GP 相同责任**。
- **错误认知**：退伙后就与合伙债务无关。**纠正**：普通合伙人对**退伙前**发生的债务仍承担**无限连带责任**。
- **错误认知**：公司可以用资本公积弥补亏损。**纠正**：**资本公积不得用于弥补亏损**（**以现行公司法为准**），弥补亏损应按法定顺序使用**当年利润、法定/任意公积金**等。
