## 考点梳理

### 2.1 合同订立：要约与承诺

| 概念 | 判断要点 |
|------|---------|
| **要约** | 内容**具体确定**、表明经受要约人承诺即受约束 |
| **要约邀请** | 希望他人向自己发出要约（**招标公告、拍卖公告、招股说明书、商业广告**等一般属要约邀请） |
| **要约生效** | 一般**到达**受要约人时生效 |
| **要约撤回** | 在要约**到达前或同时**到达受要约人 |
| **要约撤销** | 承诺前可撤销，但有例外（如确定了承诺期限、受要约人已合理准备履行） |
| **承诺** | 受要约人同意要约的意思表示；承诺生效一般即**合同成立** |
| **承诺迟到 / 逾期** | 超过承诺期限到达，一般视为**新要约**（**以民法典规定为准**） |

> 记忆锚：**「具体确定是要约，招股招标是邀请」**。

### 2.2 合同效力

| 类型 | 常见情形 |
|------|---------|
| **有效** | 当事人具有相应民事行为能力、意思表示真实、不违反强制性规定与公序良俗 |
| **无效** | 违反法律强制性规定、违背公序良俗、**恶意串通损害他人**、以合法形式掩盖非法目的等 |
| **可撤销** | **重大误解、欺诈、胁迫、显失公平**（乘人之危） |
| **效力待定** | 限制民事行为能力人订立的合同、**无权代理**订立的合同（经追认有效） |

**可撤销合同的特点**：撤销权由**受损害方**行使，需在**法定期间**内行使（**以民法典规定为准**）；未撤销前合同**有效**。

### 2.3 合同履行与保全

| 制度 | 要点 |
|------|------|
| **同时履行抗辩权** | 无先后履行顺序时，对方未履行可拒绝自己的履行 |
| **先履行抗辩权** | 应先履行一方未履行，后履行一方可拒绝 |
| **不安抗辩权** | 应先履行一方有证据证明对方**丧失或可能丧失履行能力**时，可中止履行并通知 |
| **代位权** | 债务人怠于行使其债权、影响债权人到期债权实现时，债权人可**以自己名义**代位行使 |
| **撤销权** | 债务人以明显不合理低价转让财产、放弃到期债权等损害债权人利益时，债权人可请求撤销 |

### 2.4 违约责任与定金

| 项目 | 要点 |
|------|------|
| **违约形态** | 预期违约（明示/默示）、实际违约（不履行、不完全履行、迟延履行） |
| **责任形式** | 继续履行、采取补救措施、**赔偿损失**、支付**违约金** |
| **定金罚则** | 给付定金方违约 → **无权要求返还**；收受方违约 → **双倍返还** |
| **定金 vs 违约金** | 一般**不能同时适用**，当事人可选择其一（**以民法典规定为准**） |
| **定金数额限制** | 不得超过主合同标的额的**法定比例**（**具体比例以法律规定为准**） |
| **不可抗力** | 因不可抗力不能履行合同的，**部分或全部免除责任**，但应及时通知并提供证明 |

### 2.5 典型合同要点

| 合同 | 关键考点 |
|------|---------|
| **买卖合同** | 标的物**风险转移**（一般交付时转移，另有约定除外）、检验期间、瑕疵担保 |
| **租赁合同** | 租赁期限限制、**买卖不破租赁**、转租需出租人同意、承租人的**优先购买权** |
| **借款合同** | 利息不得预先扣除、**禁止高利放贷**（**以法律规定为准**） |
| **保证合同** | **一般保证**（先诉抗辩权）与**连带责任保证**；未约定或约定不明一般按一般保证（**以民法典规定为准**） |
| **承揽 / 建设工程合同** | 定作人可随时解除承揽合同；建设工程**优先受偿权** |

### 2.6 物权与担保

| 维度 | **抵押** | **质押** |
|------|---------|---------|
| **是否转移占有** | **不转移**占有 | **转移**占有 |
| **标的** | 不动产、动产（可抵押财产范围内） | 动产、权利（如股权、应收账款、知识产权） |
| **生效要件** | 不动产抵押**登记生效**；动产抵押一般**合同生效即设立**，未登记不得对抗善意第三人 | 动产**交付生效**；权利质押一般**登记或交付**生效 |
| **典型场景** | 房产抵押贷款、设备抵押 | 股权质押融资、应收账款质押 |

**其他担保要点**：

- **留置**：债权人合法占有债务人动产，债务人不履行到期债务时可留置并**优先受偿**（如修理费、保管费）；
- **保证 vs 物的担保**：**担保方式以约定为准**，无约定或约定不明时的实现顺序**以民法典规定为准**；
- **物权变动**：不动产一般**登记生效**，动产一般**交付生效**。

## 🧠 记忆工具箱

### 口诀速记

- **要约 / 邀请**：「**招股招标拍卖广告，都是要约邀请**」；
- **可撤销四情形**：「**重大误解、欺诈、胁迫、显失公平**」；
- **抗辩权**：「**同时履行看双方，先履行看先后，不安抗辩怕对方跑**」；
- **定金**：「**给付方不退，收受方双赔**」；
- **抵押 vs 质押**：「**抵押不交物，质押交到手**」；
- **物权变动**：「**不动产登记，动产交付**」。

### 场景锚点

| 场景 | 你要做的判断 |
|------|-------------|
| 公司发招标公告 | 一般属**要约邀请**，不是要约 |
| 签合同后发现对方欺诈 | 受损害方可请求**撤销**（可撤销合同） |
| 对方经营状况急剧恶化 | 可能行使**不安抗辩权**中止履行并通知 |
| 收了定金后自己违约 | **双倍返还**定金 |
| 公司用股权融资担保 | **权利质押**（需依法登记） |
| 承租的门面被房东卖掉 | **买卖不破租赁**，可继续承租 |

## ⚠️ 易错提醒

- **错误认知**：商业广告一律是要约。**纠正**：商业广告一般属**要约邀请**；只有内容**具体确定**且表明受约束时才可能构成要约。
- **错误认知**：可撤销合同自始无效。**纠正**：可撤销合同在**被撤销前有效**，由**受损害方**在法定期间内行使撤销权。
- **错误认知**：定金与违约金可以同时主张。**纠正**：一般**择一适用**，当事人可选择定金罚则或违约金（**以民法典规定为准**）。
- **错误认知**：抵押也要把物交给债权人。**纠正**：**抵押不转移占有**，**质押才转移占有**；这是两者最核心的区别。
- **错误认知**：动产抵押不登记也完全无效。**纠正**：动产抵押一般**合同生效即设立**，但**未登记不得对抗善意第三人**。
- **错误认知**：保证责任一律是连带责任。**纠正**：**未约定或约定不明时一般按一般保证处理**（保证人享有先诉抗辩权），**以民法典规定为准**。
