## 考点梳理

### 3.1 增值税：纳税人与征税范围

| 项目 | 要点 |
|------|------|
| **纳税人** | 在境内销售货物、劳务、服务、无形资产、不动产以及进口货物的单位和个人；分为**一般纳税人**与**小规模纳税人** |
| **征税范围** | 销售货物、加工修理修配劳务、销售服务、销售无形资产、销售不动产、进口货物 |
| **视同销售** | 将自产、委托加工的货物用于集体福利或个人消费、无偿赠送等情形（**具体范围以现行规定为准**） |
| **税率结构** | 分为基本税率、低税率与征收率等**多档**（**具体税率以现行有效政策为准**） |
| **小规模纳税人** | 一般按**征收率**简易计税，不得抵扣进项税额 |

> ⚠️ **税率免责**：增值税税率与征收率**经多次调整**，本表不列具体数字，**答题一律以当年度教材与现行有效政策为准**。

### 3.2 一般计税方法：销项与进项

```text
应纳税额 = 当期销项税额 − 当期进项税额
销项税额 = 销售额（不含税）× 适用税率
销售额 = 含税销售额 ÷ (1 + 适用税率)
```

| 概念 | 要点 |
|------|------|
| **销项税额** | 按销售额与适用税率计算，向购买方收取 |
| **进项税额** | 购进货物、劳务、服务等支付或负担的增值税额，凭**合法扣税凭证**抵扣 |
| **抵扣凭证** | 增值税专用发票、海关进口增值税专用缴款书、完税凭证、农产品收购发票或销售发票等（**以现行规定为准**） |
| **进项税额不足抵扣** | 可结转下期继续抵扣 |

**不得从销项税额中抵扣的进项税额**（常见情形）：

| 情形 | 说明 |
|------|------|
| **用于简易计税方法计税项目** | 该部分对应的进项不得抵扣 |
| **用于免征增值税项目** | 同上 |
| **用于集体福利或个人消费** | 含交际应酬消费 |
| **非正常损失** | 因管理不善造成的被盗、丢失、霉烂变质等，以及违法被依法没收、销毁的货物 |
| **购进贷款服务、餐饮服务、居民日常服务、娱乐服务** | 一般不得抵扣（**以现行规定为准**） |
| **未取得合法扣税凭证** | 扣税凭证不合规不得抵扣 |

### 3.3 纳税义务发生时间与征收管理

| 情形 | 纳税义务发生时间 |
|------|----------------|
| **一般销售** | 收到销售款项或取得索取销售款项凭据的**当天** |
| **先开具发票** | 为**开具发票的当天** |
| **进口货物** | 报关进口的当天 |
| **视同销售** | 货物移送的当天（**以现行规定为准**） |

> 记忆锚：**「收钱、要钱、开票，三者取其先」**。

### 3.4 企业所得税：纳税人

| 类型 | 纳税义务 |
|------|---------|
| **居民企业** | 就**境内外全部所得**纳税 |
| **非居民企业** | 一般就**来源于中国境内**的所得，及与其境内机构场所有实际联系的所得纳税（**以税法规定为准**） |

### 3.5 应纳税所得额与税率结构

```text
应纳税所得额 = 收入总额 − 不征税收入 − 免税收入 − 各项扣除 − 允许弥补的以前年度亏损
应纳税额 = 应纳税所得额 × 适用税率 − 减免税额 − 抵免税额
```

| 概念 | 要点 |
|------|------|
| **不征税收入** | 如财政拨款、依法收取并纳入财政管理的行政事业性收费与政府性基金等 |
| **免税收入** | 如国债利息收入、符合条件的居民企业之间的股息红利等权益性投资收益 |
| **各项扣除** | 与取得收入有关的、合理的成本、费用、税金（不含增值税与企业所得税本身）、损失等 |
| **亏损弥补** | 亏损可结转以后年度弥补，**结转年限以现行税法规定为准**（一般企业为 5 年，特定情形另有规定） |
| **税率** | 基本税率 + 小型微利企业等优惠税率（**具体税率与优惠以现行有效政策为准**） |

### 3.6 不得税前扣除的项目（高频）

| 项目 | 说明 |
|------|------|
| **向投资者支付的股息、红利等权益性投资收益款项** | 属税后分配，不得扣除 |
| **企业所得税税款** | 不得扣除 |
| **税收滞纳金、罚金、罚款和被没收财物的损失** | 不得扣除（但**经营性罚款**如违约金一般可扣除，**以规定为准**） |
| **超过规定标准的捐赠支出** | 公益性捐赠在限额内可扣，超部分不得扣除 |
| **赞助支出** | 与生产经营无关的赞助不得扣除 |
| **未经核定的准备金支出** | 除税法规定外，会计计提的准备金不得扣除 |
| **与取得收入无关的其他支出** | 不得扣除 |

**限额扣除的常见项目**（**具体比例以现行税法规定为准**）：职工福利费、工会经费、职工教育经费、业务招待费、广告费和业务宣传费、公益性捐赠支出。

## 🧠 记忆工具箱

### 口诀速记

- **增值税**：「**销项减进项，凭证要合法**」；
- **纳税义务时间**：「**收钱、要钱、开票，取其先**」；
- **不得抵扣**：「**简易免税福利消费，非正常损失贷款餐饮**」；
- **所得税计算**：「**收入减不征减免税，再减扣除和亏损**」；
- **不得扣除**：「**所得税款滞纳金，罚金罚款赞助费，未经核定准备金**」。

### 场景锚点

| 场景 | 你要做的判断 |
|------|-------------|
| 采购取得专票 | 合规凭证的进项税额**可抵扣** |
| 购进货物用于职工食堂 | 属**集体福利**，进项**不得抵扣** |
| 赠送客户自产产品 | 可能**视同销售**，需计销项税额 |
| 收到客户预付款并当月开票 | 纳税义务时间为**开票当天** |
| 计算所得税费用 | 先算**应纳税所得额**，再做**纳税调整** |
| 支付税收滞纳金 | 属**不得税前扣除**项目，需**纳税调增** |

## ⚠️ 易错提醒

- **错误认知**：所有进项税额都能抵扣。**纠正**：用于**简易计税、免税项目、集体福利或个人消费**，以及**非正常损失**等情形不得抵扣。
- **错误认知**：含税销售额可以直接乘税率。**纠正**：要先换算为**不含税销售额 = 含税销售额 ÷ (1 + 税率)**，再乘税率。
- **错误认知**：没收到钱就不用交增值税。**纠正**：纳税义务时间取「**收钱、要钱、开票**」中的**最早**者，开票就可能触发纳税义务。
- **错误认知**：会计计提的减值准备可以税前扣除。**纠正**：**未经核定的准备金支出不得扣除**，需做纳税调增（实际发生损失时再按规定扣除）。
- **错误认知**：罚款和违约金都不能扣除。**纠正**：**行政性罚款、税收滞纳金不得扣除**；与经营相关的**违约金一般可扣除**（**以现行规定为准**）。
- **错误认知**：亏损可以无限期结转。**纠正**：亏损弥补有**法定结转年限**（一般 5 年，特定情形另有规定），**以现行税法为准**。

> ⚠️ **政策免责**：本章涉及的**税率、扣除比例、优惠条件与结转年限**均由现行税收法规规定并可能调整，**一律以当年度教材与国家税务总局现行有效文件为准**。
