## 考点梳理

### 4.1 票据的种类

| 票据 | 出票人 | 付款人 | 常见特点 |
|------|--------|--------|---------|
| **汇票** | 出票人 | 承兑人 / 付款人 | 分**银行汇票**与**商业汇票**（商业汇票又分银行承兑、商业承兑） |
| **本票** | 出票人 | **出票人自己** | 我国票据法上的本票主要指**银行本票** |
| **支票** | 存款人 | 银行等金融机构 | 见票即付，分为现金支票、转账支票、普通支票 |

> 记忆锚：**「本票自己付，支票银行付，汇票谁承兑谁付」**。

### 4.2 票据行为与记载事项

| 项目 | 要点 |
|------|------|
| **出票** | 签发并交付票据，**必须记载事项**欠缺则票据无效 |
| **背书** | 转让票据权利；**背书应当连续**（前手被背书人与后手背书人一致） |
| **承兑** | 汇票付款人承诺在到期日付款（**商业汇票需承兑**） |
| **保证** | 票据债务人以外的人为票据债务提供担保 |
| **必须记载事项** | 表明票据种类字样、无条件支付委托/承诺、确定金额、付款人名称、收款人名称、出票日期、出票人签章等（**以票据法为准**） |
| **不得转让背书** | 背书人记载「不得转让」，其后手再背书转让的，原背书人对后手的被背书人**不承担保证责任** |

### 4.3 期限（丢分重灾区）

| 票据 | 提示付款期限（**以票据法与现行规定为准**） |
|------|----------------------------------------|
| **支票** | 自出票日起**较短**期限内提示付款（**具体天数以法律规定为准**） |
| **银行汇票** | 自出票日起**一定期限**内提示付款 |
| **银行本票** | 自出票日起**一定期限**内提示付款 |
| **商业汇票** | 付款期限由交易双方约定，但**最长不得超过法定上限** |

> ⚠️ **数字必查教材**：支票、银行汇票、银行本票、商业汇票的提示付款期与最长期限是**历年高频考点**，但数字属法定条款，**本表不列具体天数，一律以当年度教材与《票据法》现行条文为准**。

### 4.4 追索权

- **行使对象**：出票人、背书人、承兑人、保证人（**对其中任何一人、数人或全体**行使）；
- **行使条件**：票据到期被拒绝付款、到期前被拒绝承兑、承兑人或付款人死亡逃匿、被依法宣告破产等；
- **追索金额**：票据金额 + 利息 + 相关费用；
- **期限限制**：持票人对前手的追索权有**法定行使期限**（**以票据法为准**）。

### 4.5 诉讼时效

| 项目 | 要点 |
|------|------|
| **普通诉讼时效** | **3 年**，自权利人**知道或应当知道**权利受到损害以及义务人之日起计算 |
| **最长保护期** | 自权利受到损害之日起超过**法定最长期限**的，人民法院不予保护（有特殊情况可申请延长，**以民法典为准**） |
| **中止** | 在时效期间**最后六个月内**因不可抗力等障碍不能行使请求权的，时效**中止**，障碍消除后满六个月届满 |
| **中断** | 因**提起诉讼、申请仲裁、请求履行、义务人同意履行**等，时效**中断**，**重新计算** |
| **不适用诉讼时效** | 如请求停止侵害、排除妨碍、返还财产（不动产物权和登记的动产物权）等（**以民法典规定为准**） |

> 记忆锚：**「中止是暂停（最后六个月），中断是清零重算」**。

### 4.6 仲裁

| 项目 | 要点 |
|------|------|
| **基本原则** | **自愿**、**独立**、**一裁终局** |
| **适用范围** | 平等主体之间的**合同纠纷和其他财产权益纠纷** |
| **不能仲裁** | **婚姻、收养、监护、扶养、继承**纠纷；依法应由行政机关处理的行政争议 |
| **仲裁协议** | 有效的仲裁协议**排除法院管辖**（法院一般不予受理，但仲裁协议无效的除外） |
| **裁决效力** | 裁决作出后，当事人就同一纠纷再申请仲裁或向法院起诉的，**不予受理** |

### 4.7 行政复议与行政诉讼

| 项目 | 要点 |
|------|------|
| **行政复议** | 对行政机关具体行政行为不服，可申请复议；申请期限一般为**知道该行为之日起 60 日**（**以行政复议法为准**） |
| **行政诉讼** | 直接起诉一般为**6 个月**；经复议的一般为收到复议决定书之日起**15 日**（**以行政诉讼法为准**） |
| **复议与诉讼关系** | 一般为**选择制**，法律规定复议前置的须先复议（**以法律规定为准**） |

## 🧠 记忆工具箱

### 口诀速记

- **三种票据**：「**本票自己付，支票银行付，汇票承兑付**」；
- **背书**：「**背书要连续，不得转让则后手无保证**」；
- **追索对象**：「**出票、背书、承兑、保证**，一个都跑不掉」；
- **时效**：「**普通三年，中止暂停，中断重算**」；
- **仲裁**：「**一裁终局，婚姻收养监护扶养继承不能裁**」；
- **复议 / 诉讼**：「**复议六十日，诉讼六个月**」。

### 场景锚点

| 场景 | 你要做的判断 |
|------|-------------|
| 收到客户背书的商业汇票 | 核对**背书是否连续**、有无「不得转让」字样 |
| 汇票到期被拒付 | 向**出票人、背书人、承兑人、保证人**行使**追索权** |
| 应收账款拖了两年多 | 关注**诉讼时效 3 年**，及时催收留证以**中断**时效 |
| 合同里写了仲裁条款 | 纠纷应**申请仲裁**，法院一般不予受理 |
| 被税务处罚不服 | 注意**复议 60 日 / 诉讼 6 个月**的期限 |
| 离婚财产纠纷想仲裁 | **不能仲裁**，应通过诉讼解决 |

## ⚠️ 易错提醒

- **错误认知**：本票由银行付款。**纠正**：**本票由出票人自己付款**（我国票据法上的本票主要是银行本票，但付款人仍是出票人）。
- **错误认知**：背书不连续只是瑕疵，不影响权利。**纠正**：**背书应当连续**，不连续可能影响持票人行使票据权利。
- **错误认知**：诉讼时效届满后债权就消灭了。**纠正**：时效届满**消灭的是胜诉权**，债权本身仍存在，义务人自愿履行后不得反悔。
- **错误认知**：中止和中断是一回事。**纠正**：**中止是暂停**（障碍消除后继续计算），**中断是重新计算**（如提起诉讼、义务人同意履行）。
- **错误认知**：所有纠纷都能仲裁。**纠正**：**婚姻、收养、监护、扶养、继承纠纷**及行政争议**不能仲裁**。
- **错误认知**：有仲裁协议还能随便起诉。**纠正**：有效仲裁协议**排除法院管辖**，且仲裁**一裁终局**，同一纠纷不能再诉。
