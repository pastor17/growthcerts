## 考点梳理

### 1.1 先判断：控制、共同控制还是重大影响

做长投题的第一步**不是写分录，而是判断关系**——关系决定后续用哪种方法。

| 关系 | 判断要点 | 后续计量方法 |
|------|---------|-------------|
| **控制** | 有权决定被投资方财务与经营政策、能据以获取可变回报并影响回报 | **成本法** |
| **共同控制** | 按合同约定共享控制，相关活动须**分享控制权的各方一致同意** | **权益法** |
| **重大影响** | 能参与决策但不能控制或共同控制（如派董事、参与政策制定） | **权益法** |
| **无控制/共同控制/重大影响** | 一般属金融资产范畴 | 按金融工具准则处理 |

> 判断锚：**「控制看权力，共同控制看一致同意，重大影响看能否参与」**。持股比例是线索不是结论，**最终看实质**。

### 1.2 初始计量（成本法 / 权益法共用起点）

| 取得方式 | 初始投资成本 |
|---------|-------------|
| **同一控制下企业合并** | 按取得被合并方所有者权益在**最终控制方合并报表中的账面价值份额**确定（差额调整资本公积等） |
| **非同一控制下企业合并** | 按付出对价的**公允价值**确定（与可辨认净资产公允价值份额差额确认为**商誉**） |
| **非企业合并方式取得**（如追加投资形成重大影响） | 按付出对价公允价值 + 相关税费确定 |

**权益法的初始调整**：

- 初始投资成本 **>** 享有被投资方可辨认净资产公允价值份额 → 差额为**内含商誉**，**不调整**；
- 初始投资成本 **<** 该份额 → 差额计入**营业外收入**，同时调增长投账面价值。

### 1.3 成本法（控制）

- 日常**只在实际收到现金股利（或利润）时**确认投资收益；
- 被投资方实现净损益**不做账**；
- 期末**按成本与可收回金额孰低**进行减值测试（减值不得转回）。

### 1.4 权益法（共同控制 / 重大影响）

| 步骤 | 处理 |
|------|------|
| ① 初始确认 | 比较初始成本与享有份额，负商誉计营业外收入 |
| ② 被投资方**净损益** | 调整长投，确认**投资收益**（注意**内部交易未实现损益**抵销、公允价值与账面价值差异调整） |
| ③ 被投资方**其他综合收益** | 调整长投，计入**其他综合收益** |
| ④ 被投资方**其他权益变动** | 调整长投，计入**资本公积—其他资本公积** |
| ⑤ 分派**现金股利** | 冲减长投账面价值（**不确认投资收益**） |
| ⑥ 超额亏损 | 一般以长投账面价值及其他实质上构成投资的长期权益减至零为限，仍有义务的继续确认 |

### 1.5 核算方法转换（高频难点）

| 转换方向 | 关键处理 |
|---------|---------|
| 金融资产 → 权益法 | 原股权按**公允价值重新计量**，差额计入当期损益 |
| 金融资产 → 成本法（非同一控制） | 原股权按**公允价值重新计量**，差额计入损益；合并成本 = 原股权公允价值 + 新增对价公允价值 |
| 权益法 → 成本法（非同一控制） | 合并成本 = 原股权账面价值 + 新增对价公允价值（**不追溯**） |
| 权益法 → 金融资产 | 剩余股权按**公允价值重新计量**，与账面价值差额计入当期损益 |
| 成本法 → 权益法（丧失控制但仍有重大影响） | 剩余股权按**公允价值重新计量**，并**追溯调整**剩余股权视同自始采用权益法 |

> 记忆锚：**「跨界就重新计量」**——凡是跨出/跨入「金融资产—权益法—成本法」三条赛道的转换，通常要按公允价值重新计量。

### 1.6 合并范围与合并报表三步

**合并范围**：以**控制**为基础（权力 + 可变回报 + 运用权力影响回报），**不只看持股比例**；结构化主体、协议控制同样可能纳入合并。

**合并三步抵销**：

```text
① 调整：按购买日可辨认资产/负债的公允价值调整子公司报表
② 抵权益：抵销母公司长期股权投资与子公司所有者权益，确认少数股东权益
③ 抵内部：抵销内部交易、内部债权债务与期末存货/固定资产中的未实现损益
```

| 抵销内容 | 常见分录方向（示意） |
|---------|-------------------|
| 长投与子公司权益 | 借：股本/资本公积/盈余公积/未分配利润（子公司）＋商誉 贷：长期股权投资 + 少数股东权益 |
| 子公司当期净损益 | 借：投资收益 + 少数股东损益 贷：未分配利润—年末（及提取盈余公积等） |
| 内部应收应付 | 借：应付账款 贷：应收账款；同时抵销坏账准备与信用减值损失 |
| 内部销售收入与成本 | 借：营业收入 贷：营业成本 + 存货（未实现毛利部分） |

> ⚠️ 报表格式与抵销科目的**具体名称以当年度教材为准**；机考中多考抵销逻辑与金额计算，而非死记科目名。

## 🧠 记忆工具箱

### 口诀速记

- **方法判断**：「**控制成本法，共控重大影响用权益**」；
- **权益法顺序**：「**先调初始，再认损益，后认其他**」；
- **内部交易**：「**顺流全额抵，逆流按比例抵**」（顺流交易抵销母公司投资收益，逆流交易抵销少数股东损益）；
- **转换**：「**跨界重新计量，不跨界按账面**」；
- **合并**：「**调账面 → 抵权益 → 抵内部**」。

### 场景锚点

| 场景 | 你要做的判断 |
|------|-------------|
| 公司买了一家公司 60% 股权 | **控制 → 成本法**，合并日进入合并范围 |
| 派了一名董事、持股 25% | **重大影响 → 权益法** |
| 两个股东各 50%、约定须一致同意 | **共同控制 → 权益法** |
| 集团做月度合并报表 | 走**合并三步**，重点看内部往来与未实现损益 |
| 收到子公司分红 | 成本法下**确认投资收益**；权益法下**冲减账面** |

## ⚠️ 易错提醒

- **错误认知**：持股超过 50% 就一定是控制。**纠正**：控制看**实质权力**，协议控制、潜在表决权都可能影响判断，比例只是线索。
- **错误认知**：权益法下收到现金股利要确认投资收益。**纠正**：权益法下收到股利**冲减长期股权投资账面价值**，不确认收益。
- **错误认知**：初始投资成本小于享有份额的差额计入营业外支出。**纠正**：差额计入**营业外收入**（负商誉），同时调增长投。
- **错误认知**：合并报表只要把两张报表相加。**纠正**：必须做**抵销**，否则内部交易会虚增收入与资产。
- **错误认知**：合并就是按持股比例简单相乘。**纠正**：先**全额并入**子公司资产负债与损益，再通过**少数股东权益/损益**体现比例。
- **错误认知**：丧失控制后剩余股权继续按原账面核算。**纠正**：剩余股权一般按**公允价值重新计量**，成本法转权益法还需**追溯调整**。
