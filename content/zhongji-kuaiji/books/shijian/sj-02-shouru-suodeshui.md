## 考点梳理

### 2.1 收入确认五步法

| 步骤 | 做什么 | 关键判断 |
|------|--------|---------|
| ① 识别与客户订立的**合同** | 判断合同是否成立（各方批准、权利义务明确、支付条款、商业实质、对价很可能收回） | 不满足则**不确认收入** |
| ② 识别**单项履约义务** | 判断商品或服务是否**可明确区分** | 可区分则分别核算 |
| ③ 确定**交易价格** | 考虑可变对价、重大融资成分、非现金对价、应付客户对价 | 可变对价按**最可能发生金额或期望值**估计，并受限于「极可能不发生重大转回」 |
| ④ **分摊**交易价格 | 按各履约义务**单独售价的相对比例**分摊 | 单独售价不可观察时需估计 |
| ⑤ 履行义务时确认收入 | 判断是**时点**还是**时段**确认 | 核心是**控制权转移** |

### 2.2 时点确认 vs 时段确认

| 类型 | 判断标准 | 确认方式 |
|------|---------|---------|
| **时段确认** | 满足其一：客户在履约同时即取得并消耗利益；客户能控制在建商品或服务；履约成果**不可替代**且企业有权就已完成部分收款 | 按**履约进度**确认（产出法或投入法） |
| **时点确认** | 不满足时段条件 | 在**控制权转移时点**确认（如交付、验收、签收） |

**控制权转移的迹象**：企业享有现时收款权利、已转移法定所有权、已转移实物、主要风险和报酬已转移、客户已接受该商品。

### 2.3 特定交易（高频）

| 交易类型 | 处理要点 |
|---------|---------|
| **附有销售退回条款** | 按**预期不会退回**的部分确认收入，同时确认<strong>预计负债（退款负债）</strong>与**应收退货成本** |
| **附有质量保证** | 区分**保证类**（按或有事项处理）与**服务类**（作为单项履约义务分摊） |
| **主要责任人 vs 代理人** | 主要责任人按**总额**确认收入，代理人按**净额**（佣金）确认 |
| **附有客户额外购买选择权** | 构成重大权利的作为单项履约义务分摊交易价格 |
| **售后回购** | 按回购价格与原售价关系判断是**租赁、融资**还是**附退回条件的销售** |
| **建造合同 / 履约进度** | 按履约进度确认收入与成本，预计损失**当期全额确认** |

### 2.4 所得税：计税基础与暂时性差异

| 概念 | 含义 |
|------|------|
| **资产的计税基础** | 未来期间可**税前扣除**的金额 |
| **负债的计税基础** | 账面价值 − 未来期间可税前扣除的金额 |
| **应纳税暂时性差异** | 未来期间**应纳税**增加 → 确认**递延所得税负债** |
| **可抵扣暂时性差异** | 未来期间**可抵扣**减少 → 确认**递延所得税资产**（以很可能取得足够应纳税所得额为限） |

**常见差异来源**：

- 资产减值准备（会计计提、税法一般不允许当期扣除）；
- 固定资产折旧年限与方法差异；
- 预计负债（如产品质量保证、诉讼赔偿）；
- 可结转以后年度的亏损与税款抵减；
- 公允价值变动（如交易性金融资产）。

### 2.5 递延所得税的确认与计量

| 事项 | 处理 |
|------|------|
| **税率** | 按**预期收回资产或清偿负债期间的适用税率**计量（即未来转回期间的税率） |
| **不计入损益的情形** | 与企业合并、直接计入所有者权益的交易（如其他综合收益）相关的递延所得税，**对应计入相应科目** |
| **不予确认的情形** | 商誉初始确认；既不影响会计利润也不影响应纳税所得额的**初始确认**交易（除企业合并外） |
| **不确认递延所得税负债的特例** | 对联营/合营企业投资等，若能控制转回时间且很可能不转回 |
| **当期所得税费用** | 当期所得税 + 递延所得税费用（收益） |

**所得税费用结构（示意）**：

```text
所得税费用 = 当期所得税（应交所得税） + 递延所得税费用
当期应交所得税 = 应纳税所得额 × 当期适用税率
应纳税所得额 = 会计利润 + 纳税调增 − 纳税调减
```

## 🧠 记忆工具箱

### 口诀速记

- **五步法**：「**合同 → 义务 → 价格 → 分摊 → 确认**」；
- **控制权**：「**风险报酬转、法定所有权转、实物转、收款权有、客户已接受**」；
- **递延方向**：「**资产账面大（于计税基础）→ 应纳税 → 递延负债**」；
- **递延资产**：「**可抵扣差异才敢认资产，且要有未来利润兜底**」；
- **总额净额**：「**自己主导是主要责任人走总额，只是撮合走净额**」。

### 场景锚点

| 场景 | 你要做的判断 |
|------|-------------|
| 卖设备并负责安装 | 设备与安装**是否可明确区分** → 是否拆分履约义务 |
| 年底发货、次年客户验收 | 判断**控制权何时转移**，决定跨年收入归属 |
| 工程类项目按进度收款 | 属**时段确认**，按履约进度确认收入 |
| 计提坏账准备 | 形成**可抵扣暂时性差异** → 递延所得税资产 |
| 固定资产加速折旧（税法） | 形成**应纳税暂时性差异** → 递延所得税负债 |
| 销售附退货权 | 只确认**预期不退回**部分，同时确认退款负债 |

## ⚠️ 易错提醒

- **错误认知**：开了发票就要确认收入。**纠正**：收入确认看**控制权转移**，发票只是税务凭据，二者可能不在同一期间。
- **错误认知**：所有商品销售都在交付时一次确认收入。**纠正**：满足**时段**条件（如在客户场地上建造不可替代资产）的应按**履约进度**确认。
- **错误认知**：可变对价一律全额计入交易价格。**纠正**：可变对价须满足**极可能不发生重大转回**的限制条件，否则要扣减。
- **错误认知**：所有暂时性差异都确认递延所得税。**纠正**：商誉初始确认等**特殊情形不确认**；递延所得税资产还需以**未来很可能取得足够应纳税所得额**为前提。
- **错误认知**：递延所得税一律按现行税率计算。**纠正**：应按**预期转回期间的适用税率**计量。
- **错误认知**：递延所得税全部计入所得税费用。**纠正**：与**其他综合收益、企业合并**相关的部分应计入对应科目，而非当期损益。
