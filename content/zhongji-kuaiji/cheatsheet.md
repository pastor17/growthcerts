> **用法**：考前 3 天起只过这一页 + 错题本。三科须在**连续 2 个考试年度内**全部合格；**主观题必须动笔**，光看不算等于没学。
> ⚠️ 下方涉及金额比例、税率、扣除限额与期限的数字为**记忆提示**，**一律以当年度官方教材与现行有效法规为准**。

## 一、《中级会计实务》——分录与判断主线

| 主题 | 一句话要点 |
|------|-----------|
| **存货** | 成本含买价、相关税费、运输装卸；发出计价：先进先出、加权平均、个别计价 |
| **固定资产折旧** | 年限平均、工作量、**双倍余额递减**（最后两年改年限平均）、年数总和；当月增加当月不提、当月减少当月照提 |
| **金融资产三分类** | 以摊余成本计量（AC）、以公允价值计量且变动计入其他综合收益（FVOCI）、以公允价值计量且变动计入当期损益（FVTPL） |
| **预期信用损失** | 应收账款等按**预期信用损失**计提减值，不再以「已发生损失」为唯一标准 |
| **长期股权投资** | **控制 → 成本法**；**共同控制或重大影响 → 权益法**；追加投资导致转化时按规则追溯或按公允价值重新计量 |
| **权益法三步** | 初始成本调整（含商誉/负商誉）→ 按被投资方**净损益与其他综合收益/权益变动**调整 → 分派现金股利冲减账面 |
| **收入五步法** | ① 识别与客户订立的合同 ② 识别**履约义务** ③ 确定交易价格 ④ 分摊交易价格 ⑤ 履行义务时（**控制权转移**）确认收入 |
| **时点 vs 时段** | 客户取得控制权为时点确认；在履约期间连续取得利益为**时段确认**（履约进度法） |
| **所得税** | 账面价值 vs **计税基础** → 暂时性差异 → 应纳税差异为**递延所得税负债**、可抵扣差异为**递延所得税资产** |
| **租赁（承租人）** | 确认**使用权资产 + 租赁负债**（不再区分经营/融资，短期与低价值资产豁免除外）；使用权资产计提折旧、租赁负债确认利息 |
| **合并报表三步** | ① 按公允价值调整子公司账面 ② 抵销长投与子公司所有者权益、确认少数股东权益 ③ 抵销内部交易、内部往来与未实现损益 |
| **合并范围** | 以**控制**为基础（权力、可变回报、运用权力影响回报），不只看持股比例 |
| **政策变更 / 差错** | 政策变更 → **追溯调整法**；估计变更 → **未来适用法**；前期重大差错 → **追溯重述法** |
| **日后事项** | 调整事项（资产负负债表日已存在情况）调报表；非调整事项只**披露** |
| **资产负债表列报** | 流动/非流动划分、一年内到期的非流动负债重分类 |

## 二、《财务管理》——核心公式

| 模块 | 公式 / 要点 |
|------|-----------|
| **复利现值 / 终值** | PV = FV ÷ (1+i)^n ｜ FV = PV × (1+i)^n |
| **普通年金现值** | PVA = A × [1 − (1+i)^−n] ÷ i |
| **年金终值** | FVA = A × [(1+i)^n − 1] ÷ i |
| **预付年金** | 现值 = 普通年金现值 × (1 + i)；终值 = 普通年金终值 × (1 + i) |
| **永续年金** | PV = A ÷ i |
| **期望收益率** | Σ（各情形收益率 × 概率） |
| **标准差率** | 标准差 ÷ 期望值（衡量**相对**风险） |
| **CAPM** | 必要收益率 = 无风险利率 + β ×（市场组合收益率 − 无风险利率） |
| **债务资本成本** | 税后 = 税前利率 × (1 − 所得税税率) |
| **WACC** | Σ（各资金来源比重 × 该来源资本成本） |
| **经营杠杆** | DOL = 边际贡献 ÷ 息税前利润 |
| **财务杠杆** | DFL = 息税前利润 ÷ (息税前利润 − 利息) |
| **总杠杆** | DTL = DOL × DFL |
| **NPV** | 未来现金净流量现值 − 原始投资额现值；**NPV > 0 可行** |
| **IRR** | 使 NPV = 0 的折现率；与 NPV 冲突时**以 NPV 为准** |
| **回收期** | 累计现金净流量等于原始投资所需时间（越短越好，未考虑时间价值） |
| **边际贡献** | 销售收入 − 变动成本 |
| **保本销售量** | 固定成本 ÷ 单位边际贡献；**保本销售额** = 固定成本 ÷ 边际贡献率 |
| **安全边际率** | 安全边际量 ÷ 实际（预计）销售量 |
| **经济订货量 EOQ** | √(2 × 年需求量 × 每次订货成本 ÷ 单位储存成本) |
| **现金周转期** | 存货周转期 + 应收账款周转期 − 应付账款周转期 |
| **杜邦分析** | **ROE = 销售净利率 × 总资产周转率 × 权益乘数** |
| **周转率** | 周转率 = 营业收入（或营业成本）÷ 平均资产（或平均存货/应收） |
| **标准成本差异** | 直接材料价差 =（实际价 − 标准价）× 实际用量；量差 =（实际用量 − 标准用量）× 标准价 |

> ⚠️ 公式的**符号、口径与教材表述**请以当年度官方教材为准（不同版本对年金符号写法略有差异，**按教材写**）。

## 三、《经济法》——条文与数字

| 主题 | 记忆要点 |
|------|---------|
| **诉讼时效** | 一般**3 年**，自权利人知道或应当知道权利受损害及义务人之日起算；有最长保护期限制（**以法条为准**） |
| **仲裁** | **一裁终局**；婚姻、收养、监护、扶养、继承纠纷**不能仲裁** |
| **行政复议 / 行政诉讼** | 申请行政复议一般为**60 日**；提起行政诉讼一般为**6 个月**（**以法条为准**） |
| **公司法出资** | 可用货币、实物、知识产权、土地使用权等出资；**不得**以劳务、信用、姓名、特许经营权等出资（**以现行公司法为准**） |
| **股东会决议** | 修改章程、增减注册资本、合并分立解散、变更公司形式一般需**特别多数**通过（**以公司法与章程为准**） |
| **公司法财务会计** | 法定公积金按规定比例提取，达注册资本一定比例可不再提取；**资本公积不得用于弥补亏损**（**以现行公司法为准**） |
| **合伙企业** | 普通合伙人承担**无限连带责任**、执行合伙事务；有限合伙人以**出资额为限**、不执行事务 |
| **合同订立** | **要约**（内容具体确定、受约束）与**要约邀请**（如招标公告、拍卖公告、商业广告）区分 |
| **合同效力** | 无效、可撤销（重大误解、欺诈、胁迫、显失公平）、效力待定（限制行为能力人、无权代理） |
| **定金** | 数额由当事人约定，**不得超过主合同标的额的一定比例**（**以法律规定为准**）；定金罚则：给付方违约不退、收受方违约双倍返还 |
| **保证** | 一般保证与连带责任保证；未约定或约定不明按**一般保证**处理（**以民法典规定为准**） |
| **抵押 vs 质押** | 抵押**不转移占有**（不动产抵押登记生效）；质押**转移占有**（动产交付生效、权利质押登记） |
| **增值税** | 应纳税额 = **当期销项税额 − 当期进项税额**；不得抵扣：用于简易计税、免税项目、集体福利与个人消费等（**以现行规定为准**） |
| **增值税纳税义务时间** | 一般以**收到销售款项或取得索取销售款项凭据**的当天；先开具发票的为开具发票当天（**以现行规定为准**） |
| **企业所得税** | 应纳税所得额 = 收入总额 − 不征税收入 − 免税收入 − 各项扣除 − 允许弥补的以前年度亏损 |
| **不得税前扣除** | 税收滞纳金、罚金罚款、超标准捐赠与业务招待费等（**限额以现行规定为准**） |
| **亏损弥补** | 一般可结转弥补以后年度所得，**结转年限以现行税法规定为准** |
| **票据期限** | 支票提示付款期、银行汇票、银行本票、商业汇票付款期限各不相同，**逐项记准确天数**（**以票据法为准**） |
| **票据追索** | 持票人可向**出票人、背书人、承兑人、保证人**行使追索权，**背书需连续** |

## 四、考前 10 分钟清单

```text
□ 三科滚动周期：连续 2 个考试年度内全部合格，超期第一年成绩清零
□ 实务：控制→成本法，重大影响→权益法；合并三步（调账面→抵权益→抵内部）
□ 实务：收入看「控制权转移」；所得税看「暂时性差异」；租赁上表
□ 财管：NPV>0 可行；冲突时以 NPV 为准；ROE = 净利率 × 周转率 × 权益乘数
□ 财管：保本量 = 固定成本 ÷ 单位边际贡献；EOQ = √(2DS/H)
□ 经济法：诉讼时效 3 年、仲裁一裁终局、抵押不转移占有 / 质押转移占有
□ 经济法：增值税 = 销项 − 进项；所得税先算「应纳税所得额」
□ 主观题：写步骤、带单位、分条作答；不确定的先标记、不纠缠
□ 交卷前：检查未作答题目，确认三科时间分配
```

> ⚠️ **最终提醒**：报考条件、时间安排、合格标准与成绩滚动细节**以当年度全国会计资格评价网及当地财政部门公告为准**；税法与准则数字**以当年度教材与现行有效法规为准**。
