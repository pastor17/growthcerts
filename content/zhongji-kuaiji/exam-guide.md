> 本页按**全国会计资格评价网**（kzp.mof.gov.cn）公开信息整理为一般口径。**报考条件、工作年限认定、审核方式、继续教育与信息采集要求，各地执行细节不同——一律以当年度全国会计资格评价网及当地财政部门公告为准。**

## 报考条件（官方口径）

### 一、基本条件

1. 遵守《中华人民共和国会计法》和国家统一的会计制度等法律法规；
2. 具备良好的职业道德，无严重违反财经纪律的行为；
3. 热爱会计工作，具备相应的会计专业知识和业务技能；
4. 具备国家教育部门认可的**学历（学位）**，并满足**相应会计工作年限**。

### 二、学历与工作年限（一般口径）

| 学历 / 学位 | 从事会计工作年限（一般要求） |
|------------|---------------------------|
| 大学专科 | 满 **5 年** |
| 大学本科（学士学位） | 满 **4 年** |
| 第二学士学位 或 研究生班毕业 | 满 **2 年** |
| 硕士学位 | 满 **1 年** |
| 博士学位 | **无年限要求** |

> ⚠️ **年限计算口径、截止日期、以及是否要求先完成会计人员信息采集和继续教育，各地规定不同**；报名前请**逐条对照当年度当地财政部门报名公告**，不要照搬他省经验。

## 工作年限怎么认定

工作年限是中级报名**最容易出问题的一环**，通常关注四个点：

| 关注点 | 一般口径 | 需要做什么 |
|--------|---------|-----------|
| **起算时间** | 一般自**取得规定学历（学位）后**从事会计工作之日起算 | 核对自己的毕业时间与首次从事会计工作时间 |
| **截止时间** | 一般为**当年度考试报名年度年底**（**以当次公告为准**） | 报名前确认自己是否「满 N 年」 |
| **工作内容** | 一般限定为**会计工作**（核算、报表、税务、财务分析等） | 与单位沟通岗位名称与工作内容表述 |
| **证明材料** | 常见为**单位工作证明、社保缴纳记录、劳动合同、学历（学位）证书**等（**各地要求不同**） | 提前向单位人事部门申请开具 |

**常见问题**：

- **在校实习算不算年限？** 一般以**取得规定学历后**从事会计工作起算，在校实习通常不计入（**以当地口径为准**）；
- **换过单位怎么算？** 通常**累计计算**，需要各段工作证明或社保记录衔接；
- **非全日制学历怎么算？** 国家教育部门认可的学历一般予以认可，但**起算与认可口径以当地公告为准**；
- **会计工作年限与继续教育挂钩吗？** 部分地区将**继续教育记录**作为年限或信息采集的辅助材料（**以当地公告为准**）。

> ⚠️ 本站不提供「保证通过审核」的判断。**请以当年度全国会计资格评价网及当地财政部门公告为准**，必要时拨打当地财政部门公布的咨询电话核实。

## 报名流程与告知承诺制

### 一般流程

```text
① 关注公告（全国会计资格评价网 + 当地财政部门）
   ↓
② 完成会计人员信息采集（部分地区要求，按当地公告执行）
   ↓
③ 登录全国会计资格评价网报名系统 → 注册/登录、填写报考信息
   ↓
④ 上传学历（学位）证书、照片及要求的证明材料
   ↓
⑤ 选择报考省份、考区与科目（可一次报一科、两科或三科）
   ↓
⑥ 资格审核（网上审核 / 现场审核 / 考后审核，各地不同）
   ↓
⑦ 网上缴费（缴费成功方视为报名成功）
   ↓
⑧ 考前打印准考证 → 按准考证时间地点参加无纸化机考
```

### 告知承诺制

- 多数地区实行**报名证明事项告知承诺制**：考生**承诺**所填信息与材料真实、准确、完整，**无须现场提交全部纸质材料**；
- **代价**：若承诺不实（学历造假、年限虚报等），**考试成绩与资格证书可能被取消，并记入专业技术人员资格考试诚信档案库**；
- **考后审核**：部分地区在成绩公布后进行**考后资格审核**，未通过者**成绩作废、不予发证**。

> ⚠️ **报考信息务必真实**。中级属于职称类考试，**资格造假后果严重**，不要相信任何「代报名」「包审核」的中介承诺。

## 考试时间与科目安排

| 环节 | 一般规律（**以当次公告为准**） |
|------|------------------------------|
| 报名 | 一般在**每年 3 月**（各地开放时段不同） |
| 准考证打印 | 一般考前 1~2 周（各地不同） |
| 考试 | 一般在**每年 9 月**，无纸化机考、可能分批次进行 |
| 成绩查询 | 考后一般在当年度内公布 |
| 合格标准 | 各科目满分 100 分，合格标准一般为 **60 分** |

**科目与时长（示例口径，以当次公告为准）**：

| 科目 | 常见考试时长 | 常见题型 |
|------|-------------|---------|
| 《中级会计实务》 | 约 165 分钟 | 单选、多选、判断、计算分析题、综合题 |
| 《财务管理》 | 约 135 分钟 | 单选、多选、判断、计算分析题、综合题 |
| 《经济法》 | 约 120 分钟 | 单选、多选、判断、简答题、综合题 |

> 三科通常**同一天或相邻批次**安排，**具体批次、场次与时间以准考证为准**。中级考试为**无纸化机考**，建议考前用官方模拟系统熟悉作答界面与计算器。

## 合格标准与成绩管理

- **合格标准**：各科目满分 100 分，合格标准一般为 **60 分**（**以当年度官方通知为准**）；
- **滚动周期**：须在**连续 2 个考试年度内**通过全部三科，方可取得资格证书；
- **滚动示例**：

| 情形 | 结果 |
|------|------|
| 第 1 年过 3 科 | 当年度即可取证 |
| 第 1 年过 2 科，第 2 年过剩下 1 科 | 取证 |
| 第 1 年过 2 科，第 2 年剩下 1 科未过 | **第 1 年成绩失效**，第 3 年需重新报考失效科目（滚动周期重新计算） |
| 第 1 年过 1 科，第 2 年过另外 2 科 | 取证 |

- **证书形式**：一般提供**电子证书**与纸质证书（领取方式与时间**以当地财政部门通知为准**）。

> ⚠️ **成绩有效期与滚动规则的具体执行以当年度全国会计资格评价网公告为准**。

## 报名常见问题

| 问题 | 一般答复（**以当次公告为准**） |
|------|------------------------------|
| 可以分几年考吗？ | 可以，**连续 2 个考试年度内**全部合格即可 |
| 一年可以只报一科吗？ | 一般可以，按自己节奏报考；但要注意滚动周期只有 2 年 |
| 报名后能改科目或考区吗？ | 缴费后一般不能随意更改，**以当地公告与报名系统说明为准** |
| 学历证书没下来能报吗？ | 需符合当地对学历取得时间的要求，**以当地公告为准** |
| 需要先做信息采集吗？ | 部分地区要求**先完成会计人员信息采集**，**以当地公告为准** |
| 继续教育有影响吗？ | 部分地区将继续教育情况作为报名或年限参考，**以当地公告为准** |
| 报名费能退吗？ | 一般缴费后不退，**以当地公告为准** |
| 考后审核没通过怎么办？ | 成绩与资格可能作废，**务必确保报名信息真实** |

## ⚠️ 以当次公告为准

- 本页所有**报考条件、学历年限、材料要求、审核方式、报名与考试时间、合格标准、成绩滚动细节**均为**一般口径整理**；
- **各地差异大**：工作年限认定、信息采集、继续教育、考后审核、证书领取方式**均可能不同**；
- **每年可能调整**：考试批次、题型分值、机考安排可能变化；
- **最终依据**：**当年度全国会计资格评价网公告 + 你所在省份财政部门（会计管理机构）报名公告**。

> 📌 **行动建议**：报名季先看**全国会计资格评价网**，再查**本省财政部门公告**，把「学历 + 年限 + 材料 + 审核方式」四项逐一确认后再填表缴费。
