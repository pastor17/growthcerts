> 通用方法见 [备考笔记怎么用](/zhichang/biji/) 与 [避坑指南](/zhichang/bikeng/)；本页只讲**中级会计专属**内容。三科须在**连续 2 个考试年度内**全部合格，**任何一科拖到第三年都会清零第一年成绩**，所以笔记要服务于「稳定拿分」而不是「学得好看」。

## 该记什么（三科必背清单）

### ①《中级会计实务》

| 类型 | 必背内容 |
|------|---------|
| **分录主线** | 存货与固定资产、金融资产、长期股权投资（成本法/权益法）、收入五步法与特定交易、所得税递延、租赁使用权资产、合并抵销分录 |
| **判断口诀** | 控制 → 成本法；共同控制/重大影响 → 权益法；控制权转移 → 确认收入；暂时性差异 → 递延所得税 |
| **计算公式** | 折旧（年限平均/双倍余额递减/年数总和）、资产可收回金额、履约进度法确认收入、使用权资产与租赁负债、递延所得税 |
| **合并三步** | ① 调整子公司账面（公允价值）② 抵销长投与子公司权益 ③ 抵销内部交易与往来 |
| **变更与更正** | 会计政策变更 → 追溯调整法；前期差错 → 追溯重述法；日后调整事项 → 调整报告期报表 |

### ②《财务管理》

| 类型 | 必背内容 |
|------|---------|
| **时间价值** | 复利现值/终值、普通年金与预付年金、递延年金、永续年金；**年金与复利的互换关系** |
| **风险与收益** | 期望收益率、标准差与标准差率、β 系数、资本资产定价模型（CAPM） |
| **资本成本** | 债务资本成本（税后）、普通股成本、加权平均资本成本（WACC）；**经营杠杆、财务杠杆、总杠杆** |
| **投资决策** | 净现值（NPV）、内含报酬率（IRR）、回收期、现值指数；**NPV 与 IRR 冲突时以 NPV 为准** |
| **成本管理** | 量本利分析（**边际贡献、保本点、安全边际**）、标准成本差异（价差/量差）、作业成本法 |
| **预算** | 销售预算起点、生产预算、材料与人工预算、**现金预算、预计资产负债表/利润表** |
| **营运资金** | 现金持有量模型、存货经济订货量（EOQ）、**应收账款信用政策与账龄分析** |
| **财务分析** | 偿债能力、营运能力、盈利能力、发展能力指标；**杜邦分析：ROE = 销售净利率 × 总资产周转率 × 权益乘数** |

### ③《经济法》

| 类型 | 必背内容 |
|------|---------|
| **公司法** | 出资形式与期限、股东会/董事会/监事会职权、决议表决比例、**股权转让规则**、董监高忠实勤勉义务 |
| **合伙企业法** | 普通合伙人（GP）与有限合伙人（LP）的权利差异、入伙退伙、**债务承担方式**、利润分配约定 |
| **合同法** | 要约与承诺、合同效力（无效/可撤销）、履行抗辩权、**违约责任与定金规则**、保证与担保 |
| **物权与担保** | 抵押（不转移占有）与质押（转移占有）、登记效力、留置权 |
| **增值税** | 纳税人与征税范围、**销项税额与进项税额**、不得抵扣情形、征收率、纳税义务发生时间 |
| **企业所得税** | 应纳税所得额结构、**不得扣除项目**、税前扣除凭证、亏损弥补、税会差异与纳税调整 |
| **票据** | 汇票/本票/支票的期限与提示付款期、**背书连续性**、承兑、追索权 |
| **程序法** | **普通诉讼时效 3 年**（最长保护期）、仲裁一裁终局、行政复议与行政诉讼期限 |

> ⚠️ **数字免责**：税率、扣除限额、比例与期限**每年可能调整**，本表只给「要记什么」，**具体数字一律以当年度官方教材与现行有效法规为准**。

## 记忆方法（口诀与表格化）

### 方法一：把条文变成「对比表」

经济法最大的敌人是「相似概念记混」，**凡是成对出现的概念，一律做成两列表**：

| 对比对 | 关键区分句 |
|--------|-----------|
| 成本法 vs 权益法 | 看**是否控制**：控制用成本法，重大影响用权益法 |
| 抵押 vs 质押 | 抵押**不转移占有**，质押**转移占有** |
| 普通合伙人 vs 有限合伙人 | GP 执行事务、承担**无限连带责任**；LP 不执行事务、以**出资额为限** |
| 会计政策变更 vs 会计估计变更 | 政策变更用**追溯调整法**，估计变更用**未来适用法** |
| 递延所得税资产 vs 负债 | 资产＝未来可抵扣（先多缴），负债＝未来应纳税（先少缴） |

### 方法二：把公式变成「一句话逻辑」

- **年金现值**：把未来每期同样多的钱，一次性折算到今天值多少；
- **NPV**：把项目未来的钱折现回来，减去今天投进去的钱，**正数才做**；
- **杜邦分析**：赚钱能力 × 资产效率 × 杠杆倍数 = 股东回报；
- **保本点**：**固定成本 ÷ 单位边际贡献**——卖到多少个才不亏。

### 方法三：把分录变成「模板卡」

每个高频业务只写一张模板卡，**只写借贷方向与科目名**，不抄题干：

```text
收入确认（时段履约）：借 合同结算/应收账款  贷 主营业务收入 + 应交税费（销项）
成本结转：            借 主营业务成本      贷 合同履约成本/库存商品
所得税：              借 所得税费用        贷 应交税费—应交所得税
                      借/贷 递延所得税资产/负债（差额）
租赁（承租人）：      借 使用权资产        贷 租赁负债 + 银行存款（预付）
```

### 方法四：把时间点做成「期限轴」

- **滚动周期轴**：第 1 年 → 第 2 年（**超过就清零**）；
- **票据期限轴**：出票 → 承兑 → 提示付款 → 追索；
- **诉讼时效轴**：知道权利受损之日起算 → 3 年 → 最长保护期。

### 方法五：错题按「科目 + 章节 + 错因」三列

财管错题多因「公式不熟/算错」，实务多因「准则判断错」，经济法多因「数字记混」——**把错因写在旁边**，第 4 天与第 15 天各二刷一次。

## 10 条避坑清单

| # | 坑 | 正确做法 |
|---|----|---------|
| 1 | 以为三科要**一年全过** | 中级是**连续 2 个考试年度滚动**，但要算清周期，别把两科都压到最后一年 |
| 2 | 以为可以**慢慢考** | 第三年第一年成绩清零，**规划上按「两年内必过」倒排** |
| 3 | 只学经济法（因为好背） | 实务与财管主观题权重高，**先攻硬科目，经济法放碎片时间** |
| 4 | 只看不写、只背不算 | 实务与财管必须**动笔做计算分析和综合题**，看懂 ≠ 会做 |
| 5 | 不做**成套限时模拟** | 财管题量大，**不掐表练习就会「会做但做不完」** |
| 6 | 用**旧教材**（准则与税率更新快） | 买**当年度官方教材**，注意新增与修订章节（往往是当年考点） |
| 7 | 不熟悉**机考系统** | 用官方机考模拟系统练公式输入与计算器，避免操作失分 |
| 8 | 报名信息**随意填写** | 实行**告知承诺制 + 考后审核**，年限与学历不实会**成绩作废并记入诚信档案** |
| 9 | 忽视**工作年限与信息采集**要求 | 报名前对照**当年度本省公告**逐项核对，**以当地财政部门公告为准** |
| 10 | 以为拿证就涨薪 | 证是**门槛与职称背书**，涨薪靠能独立担责的成果（见 [职场需求](/zhongji-kuaiji/demand/)） |

## 冲刺阶段安排

### 考前 30 天

| 时间 | 任务 |
|------|------|
| 第 1 周 | 三科各过一遍**错题本** + 重做主观题；确认考试批次与考场 |
| 第 2 周 | **成套限时模拟 3 套**（按真实时长），订正并统计失分模块 |
| 第 3 周 | **专项补漏**：实务的合并报表与所得税、财管的投资与成本、经济法的税法与合同法 |
| 第 4 周 | 只过[一页速记](/zhongji-kuaiji/cheatsheet/) + 错题 + 公式表；调作息，不再碰新题 |

### 考前 3 天

- **不复盘新难点**，只滚动速记清单与错题；
- 熟悉机考作答流程（登录、公式输入、标记疑题、交卷）；
- 备齐**准考证、身份证件**与考试允许的物品（**以准考证与考生须知为准**）；
- **按科目分块复习**：一天一科，实务→财管→经济法循环。

### 考场策略

1. **先拿稳分**：单选、多选、判断快速过，不确定的标记不纠缠；
2. **主观题分步写**：计算题**写清步骤与单位**，即使结果错也可能得分；
3. **经济法简答写要点**：先给结论再给依据，**分条书写**；
4. **留足检查时间**：机考交卷前检查未作答题目，避免漏答。

> ⚠️ 本页所有时间安排、考试批次与考场规则**以当年度全国会计资格评价网公告及准考证、考生须知为准**。
