## 考点梳理

### 1.1 法律体系与效力层级

**层级由高到低**：

| 层级 | 制定主体 | 示例 |
|------|---------|------|
| **宪法** | 全国人民代表大会 | — |
| **法律** | 全国人大及其常委会 | 《安全生产法》《消防法》《职业病防治法》《特种设备安全法》 |
| **行政法规** | 国务院 | 《安全生产许可证条例》《生产安全事故报告和调查处理条例》《危险化学品安全管理条例》 |
| **地方性法规** | 省级、设区的市人大及其常委会 | 各省安全生产条例 |
| **部门规章** | 国务院各部委 | 应急管理部令、部门规范性文件 |
| **地方政府规章** | 省级、设区的市政府 | 地方实施办法 |
| **标准** | 国家标准（GB/GB/T）、行业标准（AQ 等） | 强制性标准必须执行 |

**适用规则**：上位法优于下位法；同一机关制定的，**新法优于旧法、特别法优于一般法**；**强制性标准必须执行**。

### 1.2 《安全生产法》核心要点

- **方针**：**安全第一、预防为主、综合治理**；
- **责任体系**：**管行业必须管安全、管业务必须管安全、管生产经营必须管安全**；强化和落实**生产经营单位主体责任**与**政府监管责任**；
- **主要负责人**：是本单位安全生产**第一责任人**，负责建立健全并落实**全员安全生产责任制**、组织制定规章制度与操作规程、保证投入、组织培训、督促检查、组织制定并实施事故应急救援预案、及时如实报告事故；
- **安全生产管理机构与人员**：按规定设置机构或配备专职/兼职安全生产管理人员，并保障其履职；
- **安全生产费用投入**：由生产经营单位**决策机构、主要负责人或个人经营的投资人**予以保证，并对因投入不足导致的后果承担责任；
- **"三同时"**：安全设施与主体工程**同时设计、同时施工、同时投入生产和使用**。

### 1.3 政府与部门监管职责

- **综合监管**：应急管理部门对全国/本行政区域安全生产工作实施**综合监督管理**；
- **行业监管**：交通运输、住房和城乡建设、水利、民航等部门在各自职责范围内**监督管理**；
- **属地监管**：地方各级人民政府加强领导，建立健全安全生产工作协调机制；
- **监管手段**：行政许可（如安全生产许可）、监督检查、行政处罚、查封扣押、停产停业整顿、关闭等。

### 1.4 相关单行法要点（与注安考试密切相关）

| 法律 | 关键点 |
|------|-------|
| **《消防法》** | 单位消防安全职责、火灾隐患整改、消防设施维护、灭火救援义务 |
| **《职业病防治法》** | 用人单位职业病防治责任（前期预防、劳动过程防护、职业健康监护"**三同时**"） |
| **《特种设备安全法》** | 特种设备**使用登记、定期检验、作业人员持证**；禁止使用未经检验或检验不合格的设备 |
| **《危险化学品安全管理条例》** | 危化品生产储存使用经营运输的许可与安全管理要求 |
| **《生产安全事故报告和调查处理条例》** | **事故等级划分、报告时限、调查权限**（详见第 4 章） |

### 1.5 安全生产标准体系

- **国家标准**（GB 强制性 / GB/T 推荐性）、**行业标准**（如 AQ）、地方标准、企业标准；
- **强制性标准必须执行**；推荐性标准被法律法规引用或企业自我声明采用后即具约束力；
- 常见关键标准方向：机械安全、电气安全、防火防爆、有限空间作业、危险作业审批、个体防护装备配备等。

## 🔍 深度精讲

### 深讲 1：为什么"主要负责人"是高频考点

《安全生产法》把责任压在**主要负责人**（通常是法定代表人、实际控制人或厂长经理）身上，原因是他掌握资源与决策权。考点集中在两处：

1. **职责清单**（要能列举）：建立并落实全员安全生产责任制、组织制定规章制度与操作规程、保证安全投入、组织教育培训、督促检查并及时消除事故隐患、组织制定并实施应急救援预案、及时如实报告事故；
2. **责任后果**：因**投入不足**导致事故的，由决策机构、主要负责人或个人经营的投资人承担责任；未履行管理职责导致事故的，依法给予处分、罚款，构成犯罪的追究刑事责任。

**案例答题模板**："**谁**（主要负责人/安全管理人员/从业人员）的**什么职责**未履行 → 违反**哪部法律法规的什么要求** → 导致**什么后果** → 应承担**什么责任**（行政/民事/刑事）。"

### 深讲 2：企业主体责任 vs 政府监管责任怎么区分

| 主体 | 核心职责 | 常见设问 |
|------|---------|---------|
| **生产经营单位** | 落实**主体责任**：责任制、投入、培训、隐患治理、应急管理 | "企业还应做什么" |
| **主要负责人** | 第一责任人职责 | "谁应承担第一责任" |
| **安全生产管理人员** | 组织或参与拟订制度、组织培训、排查隐患、制止违章、督促整改 | "安全管理人员的职责边界" |
| **政府与部门** | 综合监管与行业监管、许可与执法 | "应由哪个部门监管/处罚" |
| **从业人员** | 遵章守规、接受培训、报告隐患、拒绝违章指挥 | "从业人员权利与义务"（见第 3 章） |

**答题提示**：题目常给一段"事故经过"，要求"指出各方责任"——按**上表五个主体逐条对应**写，比笼统写"管理不到位"得分高得多。

### 深讲 3：法律层级题怎么快速判断

遇到"某文件与某法律不一致，应适用哪个"，按三步：

1. **先看层级**（宪法 > 法律 > 行政法规 > 地方性法规 > 规章）；
2. **层级相同看时间**（新法优于旧法）；
3. **层级相同、时间相同看特别性**（特别法优于一般法）。

**举例**：某地方性法规与《安全生产法》（法律）对同一事项规定不一致 → **适用《安全生产法》**（上位法优于下位法）；若两部法律对同一事项规定不同且均为同一机关制定 → 看是否为特别规定（如《特种设备安全法》对特种设备的规定优先于一般性规定）。

## ⚠️ 易错提醒

- **方针**是"安全第一、预防为主、综合治理"，不要漏"综合治理"；
- **第一责任人**是**主要负责人**，不是安全生产管理人员；
- **"三同时"**是"同时设计、同时施工、同时投入生产和使用"，与环保"三同时"表述相似但适用法律不同；
- **强制性标准必须执行**，推荐性标准并非"可无视"（被引用或采用后具约束力）；
- 层级冲突按"**上位优先 → 新法优先 → 特别法优先**"顺序判断；
- 部门职责要区分**综合监管（应急管理部门）**与**行业监管（各行业主管部门）**。
