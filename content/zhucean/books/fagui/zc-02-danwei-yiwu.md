## 考点梳理

### 2.1 全员安全生产责任制

- **要求**：生产经营单位应建立健全**全员安全生产责任制**，明确各岗位的责任人员、责任范围与考核标准，并加强监督考核；
- **主要负责人**负责组织建立并落实；**安全生产管理人员**负责组织实施与监督检查；
- **特点**：覆盖**全体人员与全部岗位**（不仅是安全部门），体现"安全生产人人有责"。

### 2.2 安全生产投入与条件

- **安全投入**由生产经营单位的**决策机构、主要负责人或个人经营的投资人**予以保证；
- **投入不足的后果**：由上述主体对由此导致的后果承担责任；
- **基本安全生产条件**：不具备法定安全生产条件的，**不得从事生产经营活动**；
- **安全生产费用**：按规定提取和使用，专项用于安全生产（如安全设施、防护用品、培训、隐患治理等）。

### 2.3 组织机构与人员配备

- 矿山、金属冶炼、建筑施工、运输单位和危险物品的生产、经营、储存、装卸单位等，应**设置安全生产管理机构或配备专职安全生产管理人员**；
- 其他单位从业人员超过一定数量的应设机构或配专职人员，数量较少时可配**专职或兼职**人员；
- **安全生产管理人员职责**：组织或参与拟订规章制度、操作规程与应急预案；组织或参与安全教育培训；督促落实重大危险源安全管理措施；组织或参与应急救援演练；检查安全生产状况、排查事故隐患、提出改进建议；**制止和纠正违章指挥、强令冒险作业、违反操作规程的行为**；督促落实整改措施；
- **履职保障**：生产经营单位**不得因安全生产管理人员依法履职而降低其工资、福利等待遇或解除劳动合同**。

### 2.4 安全生产教育培训（高频）

| 对象 | 要求 |
|------|------|
| **主要负责人与安全生产管理人员** | 应具备与本单位所从事的生产经营活动相应的安全生产知识与管理能力 |
| **从业人员** | **三级安全教育**（厂级、车间级、班组级）；新工艺、新技术、新材料、新设备投入使用前应专门培训 |
| **特种作业人员** | 必须按国家规定**经专门的安全作业培训并取得相应资格**后，方可上岗作业（如电工作业、焊接与热切割、高处作业、制冷与空调、危险化学品安全作业等） |
| **被派遣劳动者、实习学生** | 应纳入本单位从业人员统一管理并进行培训 |
| **培训档案** | 应如实记录培训时间、内容、参加人员及考核结果 |

### 2.5 危险作业审批与相关方管理

- **危险作业**（动火、有限空间、高处、临时用电、吊装、动土、断路、盲板抽堵等）应履行**审批手续**，落实作业方案、监护人、防护措施与应急准备；
- **有限空间作业**："**先通风、再检测、后作业**"，设专人监护，**严禁盲目施救**；
- **发包、出租管理**：不得发包或出租给**不具备安全生产条件或相应资质**的单位与个人；应在合同中明确各自的安全生产管理职责，并进行**统一协调管理**；
- **同一作业区域内多个单位作业**：应签订安全生产管理协议，明确各自职责并指定专职安全生产管理人员进行安全检查与协调。

### 2.6 重大危险源与安全警示

- **重大危险源**：应**登记建档、定期检测评估监控**，并按规定**备案**；应制定应急预案并告知从业人员与相关人员在紧急情况下的应对措施；
- **安全警示标志**：在有较大危险因素的生产经营场所和有关设施、设备上设置明显的**安全警示标志**；
- **安全设备**：应经常性维护保养并定期检测，**保证正常运转**；维护、保养、检测应作记录并由有关人员签字。

### 2.7 安全生产许可与"三同时"

- **安全生产许可**：矿山企业、建筑施工企业和危险化学品、烟花爆竹、民用爆炸物品生产企业实行**安全生产许可**制度，未取得许可证不得从事生产活动；
- **建设项目安全设施"三同时"**：安全设施应与主体工程**同时设计、同时施工、同时投入生产和使用**；
- **安全评价**：矿山与用于生产、储存危险物品的建设项目应进行**安全条件论证和安全预评价**，竣工投产前进行**安全验收评价**。

## 🔍 深度精讲

### 深讲 1：安全生产管理人员的"职责与保护"是案例题常考点

**职责**（记六项即可）：拟订制度规程预案、组织培训、督促重大危险源管理措施、组织应急演练、检查隐患并提出建议、**制止违章指挥与强令冒险作业**。

**关键保护条款**：生产经营单位**不得因安全生产管理人员依法履行职责而降低其工资、福利等待遇或者解除与其订立的劳动合同**。

**典型设问**："安全员发现重大隐患要求停产整改，被企业降薪调岗，企业做法是否合法？"
**标准答案**："**不合法**。安全生产管理人员依法履行职责受法律保护，企业不得因此降低其工资、福利等待遇或解除劳动合同；同时企业应落实隐患排查治理责任，立即整改重大隐患。"

### 深讲 2：相关方（承包、承租、交叉作业）管理的答题模板

事故案例中，相当比例涉及**外包与交叉作业**。标准答题框架：

1. **资质审查**：不得发包或出租给不具备安全生产条件或相应资质的单位、个人；
2. **协议明确**：签订专门的安全生产管理协议或在合同中约定各自的安全生产管理职责；
3. **统一协调**：对承包单位、承租单位的安全生产工作**统一协调、管理**；
4. **交叉作业**：同一作业区域内多单位作业的，应签订协议、**指定专职安全生产管理人员**进行安全检查与协调；
5. **教育培训与交底**：对进场人员进行安全教育培训与书面安全技术交底；
6. **过程监督**：作业审批、监护人到位、隐患排查与违章纠正、应急联动。

**提示**：凡题干出现"外包/分包/多家单位同时在现场"，**先把上面六条写上去**，再结合具体事实补细节。

### 深讲 3：教育培训类题目的"分层应答"

| 对象 | 培训要点 |
|------|---------|
| 主要负责人与安全管理人员 | 相应安全生产知识与管理能力（内容侧重**管理职责与法规**） |
| 新员工 | **三级教育**（厂级讲法规与制度、车间级讲工艺与危险因素、班组级讲岗位操作与防护） |
| 换岗、离岗后重新上岗 | 重新进行**车间级与班组级**安全教育与岗位技能培训 |
| "四新"（新工艺、新技术、新材料、新设备） | **专门培训**，了解掌握安全技术特性与防护措施 |
| 特种作业人员 | **专门安全作业培训 + 取得资格 + 持证上岗** |
| 被派遣与实习人员 | 纳入统一管理并培训 |

## ⚠️ 易错提醒

- **安全投入**的保证主体是**决策机构、主要负责人或个人经营的投资人**（不是安全管理人员）；
- **特种作业人员**必须"经专门培训并取得相应资格"后上岗，不能以"有经验"替代；
- **三级安全教育**的顺序是厂级 → 车间级 → 班组级；
- 安全生产管理人员**有权制止违章指挥与强令冒险作业**，且**不得因履职被降薪、解除合同**；
- 有限空间作业是"**先通风、再检测、后作业**"，且**严禁盲目施救**（多人伤亡常发生在施救环节）；
- 重大危险源要"**登记建档 + 检测评估监控 + 备案 + 应急预案与告知**"，缺项即扣分。
