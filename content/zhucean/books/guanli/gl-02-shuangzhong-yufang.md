## 考点梳理

### 2.1 双重预防机制的逻辑

**两道防线**：

1. **第一道：风险分级管控**——在事故发生**之前**，识别危险源、评估风险、分级并落实管控措施（**管住"因"**）；
2. **第二道：隐患排查治理**——对管控措施**是否失效**进行检查，发现隐患立即治理（**管住"失"**）。

**逻辑关系**：

```
危险源辨识 → 风险评估（可能性 × 后果）→ 风险分级（红橙黄蓝）
      → 制定并落实管控措施 → 措施失效即形成"隐患"
      → 隐患排查（检查措施是否有效）→ 隐患治理 → 闭环验证
```

> 一句话：**风险管控是"不让它出错"，隐患排查是"发现它已出错并修好"。**

### 2.2 危险源辨识

| 类型 | 说明 | 示例 |
|------|------|------|
| **第一类危险源** | 存在的**能量或危险物质**本身（决定后果严重度） | 高压容器、易燃气体、高处作业高度、运转设备 |
| **第二类危险源** | 导致能量意外释放的**因素**（决定事故可能性） | 人的不安全行为、设备缺陷、环境不良、管理缺陷 |

**辨识范围与方法**：
- **范围**：所有场所、设备设施、作业活动（常规与非常规作业、检修与受限空间）、相关方活动、周边环境；
- **方法**：**安全检查表（SCL）**、**工作危害分析（JHA/JSA）**、**危险与可操作性分析（HAZOP）**、故障类型与影响分析（FMEA）、故障树分析（FTA）、事件树分析（ETA）；
- **输出**：危险源清单（含位置、可能事故类型、现有措施、风险等级）。

### 2.3 风险评估方法

| 方法 | 说明 |
|------|------|
| **风险矩阵法（LS）** | 风险值 R = **可能性 L × 严重性 S**，按矩阵定级 |
| **作业条件危险性评价法（LEC）** | **D = L × E × C**（L 事故发生可能性、E 暴露于危险环境的频繁程度、C 后果严重度）；按 D 值分级 |
| **风险程度分析法（MES）** | 类似 LEC，考虑控制措施状态 |
| 定性与半定量结合 | 现场多用，便于分级与公示 |

**风险分级（常见四色）**：**红色（重大/重大风险）→ 橙色（较大）→ 黄色（一般）→ 蓝色（低）**；对应管控层级：公司级 / 部门级 / 班组级 / 岗位级。

### 2.4 风险管控措施

按"**消除 → 替代 → 工程控制 → 管理控制 → 个体防护**"优先级制定，并落实"**责任、措施、资金、时限、预案**"五落实（针对重大风险与重大隐患）。

**风险公告与告知**：设置**风险告知卡/安全风险四色分布图**、岗位风险告知牌，向从业人员告知风险与防范措施（对应从业人员的**知情权**）。

### 2.5 隐患排查治理

**隐患分级**：**一般隐患**（危害和整改难度较小，发现后能立即整改）与**重大隐患**（危害和整改难度较大，应全部或局部停产停业，并经过一定时间整改治理方能排除，或因外部因素影响致使生产经营单位自身难以排除）。

**重大隐患治理方案内容（六要素）**：**治理的目标和任务、采取的方法和措施、经费和物资的落实、负责治理的机构和人员、治理的时限和要求、安全措施和应急预案**。

**隐患治理闭环**：排查发现 → 登记建档 → 评估分级 → 下达整改通知（定措施、定责任人、定时限、定资金、定预案）→ 整改实施（含临时管控措施）→ 复查验证 → 销号 → 统计分析与考核。

## 🔍 深度精讲

### 深讲 1：为什么"风险管控"与"隐患排查"不能互相替代

常见的管理误区及后果：

| 误区 | 后果 |
|------|------|
| 只做风险辨识，不做日常排查 | 措施失效无人发现（如防护罩被拆、联锁被短接），风险持续累积 |
| 只做隐患排查，不做风险评估 | 隐患治理缺乏优先级，资源平均分配，**重大风险未被优先管控** |
| 隐患整改"只下通知、不复查" | 整改落空，隐患长期存在，事故概率上升 |
| 风险告知卡"贴了就完" | 从业人员不知情（侵害知情权），应急时不知如何处置 |

**正确做法**：形成"**风险清单 → 管控措施 → 检查表（照措施查）→ 隐患治理 → 措施修订**"的循环——即**用风险清单生成检查表**，这是双重预防机制落地的关键动作。

### 深讲 2：LEC 法怎么算与怎么用

**D = L × E × C**：

| 因子 | 含义 | 常见取值思路 |
|------|------|------------|
| **L** | 事故发生的可能性 | 完全可能（10）→ 极不可能（0.1） |
| **E** | 暴露于危险环境的频繁程度 | 连续暴露（10）→ 非常罕见（0.5） |
| **C** | 发生事故可能造成的后果 | 大灾难（100）→ 引人注意（1） |

**示例**：某作业 L = 3（可能但不经常）、E = 6（每周一次）、C = 15（严重伤害）→ **D = 3 × 6 × 15 = 270**。

按常见分级表，D 值越大风险越高（如 D > 320 为极其危险；160~320 为高度危险，需立即整改）——**具体分级阈值以教材给定表格为准**。

**答题提示**：计算题要写出**取数依据**（为什么取这个分值），并给出**分级结论与对应管控层级**，只写数字不得满分。

### 深讲 3：重大隐患"五落实"与"六要素"别混

- **五落实**（针对风险管控与隐患治理的措施落地）：**责任、措施、资金、时限、预案**；
- **六要素**（重大隐患治理方案的内容）：**目标和任务、方法和措施、经费和物资、机构和人员、时限和要求、安全措施和应急预案**。

**记忆技巧**：**"五落实"是要求（落实到五个方面），"六要素"是方案（写成一份方案要包含六块内容）**。

## ⚠️ 易错提醒

- **两类危险源**：第一类是能量/危险物质（决定**后果严重度**），第二类是导致意外释放的因素（决定**可能性**）；
- **一般隐患**可立即整改；**重大隐患**需停产停业或经一定时间治理，且要制定**治理方案**；
- 重大隐患治理方案是**六要素**，日常整改要求是**五落实**，不要混；
- 风险管控措施必须按"**消除优先、个体防护最后**"排序；
- 隐患排查要"**照风险管控措施逐项查**"，否则检查缺乏针对性；
- 风险告知是法定义务（对应从业人员**知情权**），不能"内部掌握"。
