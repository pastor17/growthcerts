## 考点梳理

### 3.1 应急预案体系

| 层级 | 内容 | 特点 |
|------|------|------|
| **综合应急预案** | 总体思路、组织体系、应急响应分级、保障措施 | 从总体上阐述应急方针、政策与体系 |
| **专项应急预案** | 针对**具体事故类型**（火灾、爆炸、中毒窒息、坍塌、泄漏等） | 明确特定风险的处置程序 |
| **现场处置方案** | 针对**具体装置、场所或岗位** | 最具体、可操作（岗位人员可直接执行） |

**编制要点**：风险评估与应急能力评估为基础；成立编制工作组；**评审与发布**（按规定组织评审或论证并备案）；定期**修订**（法规变化、组织与工艺变更、演练或事故暴露问题后）。

**与从业人员的衔接**：应向从业人员告知应急预案中的**应急措施与撤离路线**（对应知情权与紧急撤离权）。

### 3.2 应急演练

| 类型 | 说明 | 常见频次要求 |
|------|------|------------|
| **桌面演练** | 口头/图上推演，成本低 | 可较频繁 |
| **功能演练** | 针对特定功能（如通信、疏散） | 中等 |
| **全面演练** | 全流程实战 | 要求较高（按法规与行业规定） |

**演练要点**：编制演练方案 → 组织实施 → **评估与总结**（发现问题）→ **修订预案与整改**。
**演练目的**：检验预案的**可行性**、锻炼队伍、完善准备、磨合机制、教育公众。

### 3.3 应急资源与救援队伍

- **应急物资与装备**：消防器材、堵漏与吸附材料、个体防护装备（含**正压式空气呼吸器**）、检测仪器、急救器材、照明与通信设备；应**定期检查维护**，确保完好可用；
- **应急救援队伍**：按规定建立专（兼）职救援队伍或与专业救援机构签订协议；人员应接受培训；
- **应急联动**：与周边单位、园区、属地政府及专业救援力量建立联动机制。

### 3.4 事故现场处置要点（案例高频）

**通用处置顺序**：

1. **报警与报告**：立即报警（119/120/属地应急部门），并向单位负责人报告；
2. **切断与控制**：在确保安全前提下**切断电源、关闭阀门、停止进料**，控制事故扩大；
3. **人员疏散与警戒**：按预案疏散无关人员，划定**警戒区**，**严禁烟火**（易燃气体泄漏时）；
4. **科学施救**：**救援人员必须佩戴相应防护装备**，进入受限空间或毒性环境前**先通风检测**；
5. **防止次生事故**：防止泄漏扩散、爆燃、坍塌、触电、中毒；
6. **保护现场与配合调查**：除抢救人员、防止事故扩大外，**保护事故现场与相关证据**。

> **最关键的答题点**：**严禁盲目施救**——大量群死群伤发生在未做防护的施救人员身上。

### 3.5 事故后的恢复与调查配合

- **善后处理**：伤员救治、家属安抚与赔偿、工伤保险待遇落实；
- **现场恢复**：清理、检测（如有毒有害残留）、设备检修与安全确认后方可复产；
- **整改落实**：按调查报告要求落实**防范和整改措施**，并接受监督；
- **配合调查**：如实提供资料，不得**迟报、漏报、谎报、瞒报**事故，不得**伪造或故意破坏现场**、毁灭证据。

## 🧠 记忆工具箱

### 预案三层

**"综合预案（总）+ 专项预案（按事故类型）+ 现场处置方案（按岗位场所）。"**

### 演练三类

**"桌面、功能、全面。"**

### 演练四步

**"方案 → 实施 → 评估总结 → 修订预案。"**

### 现场处置六步

**"报警报告 → 切断控制 → 疏散警戒 → 科学施救 → 防次生 → 保护现场。"**

### 救援铁律

**"先通风检测、后进入施救；严禁盲目施救。"**

## 🔍 深度精讲

### 深讲 1：有限空间事故为什么总是"一次事故、多人伤亡"

**典型链条**：

1. 作业人员**未通风、未检测**即进入有限空间 → 中毒或缺氧昏迷；
2. 同伴**未做任何防护**直接下去施救 → 同样昏迷；
3. 更多人员连续施救 → **伤亡人数成倍增加**。

**正确处置顺序（答题必背）**：

1. **立即停止作业并撤离**非救援人员；
2. **报警**并通知专业救援与企业应急组织；
3. **强制通风**（不得用纯氧通风）并**持续检测**氧含量、可燃气体、有毒气体；
4. 救援人员**佩戴隔绝式呼吸防护装备**、系安全带与安全绳，**外部设专人监护**；
5. 配备提升装置将伤者**快速转移至通风处**，并立即急救（心肺复苏等）；
6. **严禁未防护人员进入施救**。

### 深讲 2：应急预案"编而不用"的典型问题与整改

| 问题 | 表现 | 整改 |
|------|------|------|
| 预案与风险不匹配 | 预案内容与本企业工艺风险无关 | 以**风险评估**为基础重新编制 |
| 预案"抽屉化" | 编制后未培训、未演练 | 组织培训与演练，纳入考核 |
| 处置方案不可操作 | 现场处置方案没有**具体步骤与责任人** | 按岗位编"**谁、在多少分钟内、做什么**" |
| 演练走过场 | 演练无方案、无评估、无整改 | 按"方案—实施—评估—修订"闭环管理 |
| 应急物资失效 | 呼吸器过期、灭火器失压、检测仪失效 | **定期检查维护**并记录，建立台账 |

### 深讲 3：事故报告与现场保护的边界

**既要抢救、又不能破坏现场，怎么处理？**

- **可以做的**：抢救受伤人员、防止事故扩大（如切断危险源）、维持秩序与警戒；
- **应做的**：尽量**标记与拍照记录**现场状态、**记录变动情况**（哪些位置因抢救被移动）、保存监控与台账资料；
- **禁止做的**：伪造或故意破坏事故现场、转移隐匿资金财物、毁灭有关证据、迟报漏报谎报瞒报。

**答题提示**：涉及"事故后企业做法是否合法"，标准结构是"**报告是否及时如实 + 现场是否依法保护 + 是否配合调查 + 是否落实整改**"四条逐一评判。

## ⚠️ 易错提醒

- 应急预案三层结构中，**现场处置方案最具体**（按岗位/装置），不要与专项预案混；
- 演练的闭环是"**演练 → 评估 → 修订预案与整改**"，只演练不评估等于没演练；
- 有限空间救援必须"**先通风检测、佩戴隔绝式呼吸器、专人监护**"，**严禁盲目施救**；
- 进入有毒性或缺氧环境**不得使用过滤式面具**（须用隔绝式呼吸防护装备）；
- 事故现场应保护，但**抢救人员与防止事故扩大**属法定允许的例外（并应记录变动）；
- 应急物资要**定期检查维护**，过期失效的呼吸器、灭火器在实战中会直接导致伤亡。
