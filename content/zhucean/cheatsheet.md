> **用法**：考前 3 天起只过这一页 + 错题笔记。四科可在**连续 4 个考试年度内**通过（免试 1 科 3 年、免试 2 科 2 年）；建议**分两年考**。

## 一、法规数字链条（必背）

| 事项 | 数字 |
|------|------|
| 事故等级 | 死亡 **3/10/30**；重伤 **10/50/100**；直接经济损失 **1000 万/5000 万/1 亿**（三项**取最高档**） |
| 事故报告 | 现场人员**立即**报；单位负责人接到报告后 **1 小时内**报县级以上应急管理部门 |
| 调查主体 | 特大→**国务院及授权部门**；重大→**省级**；较大→**设区的市级**；一般→**县级** |
| 调查期限 | 一般自事故发生之日起 **60 日内**提交报告（可延长，延长不超过 60 日） |
| 补报 | 一般 **30 日内**；道路交通、火灾 **7 日内** |
| 事故处理原则 | **四不放过**（原因、责任、整改、教育） |

**法律层级**：宪法 > 法律 > 行政法规 > 地方性法规 > 部门规章/地方政府规章；**强制性标准必须执行**。

**三管三必须**：管行业必须管安全、管业务必须管安全、管生产经营必须管安全。
**三同时**：安全设施与主体工程**同时设计、同时施工、同时投入生产和使用**（≠"五同时"）。

## 二、管理：双重预防机制与应急

| 考点 | 要点 |
|------|------|
| **两类危险源** | 第一类＝**能量或危险物质本身**（定后果）；第二类＝导致意外释放的因素（定可能性） |
| **LEC** | **D = L × E × C**（示例：3×6×15 = **270**） |
| **风险四色** | 红（重大）橙（较大）黄（一般）蓝（低） |
| **重大隐患治理方案六要素** | 目标与任务、方法与措施、经费与物资、机构与人员、时限与要求、**安全措施与应急预案** |
| **隐患治理** | 排查 → 登记 → 分级 → 定人定责定时限 → 整改 → 复查 → 销号 |
| **五同时** | 计划、布置、检查、总结、评比生产工作时**同时**做好安全工作 |
| **应急预案三层** | 综合预案 + 专项预案 + **现场处置方案**（最具体） |
| **演练闭环** | 方案 → 实施 → **评估总结 → 修订预案** |
| **海因里希法则** | **1 : 29 : 300**（重伤死亡 : 轻伤 : 无伤害/未遂）→ 重视未遂事件 |
| **风险控制优先级** | **消除 > 替代 > 工程控制 > 管理控制 > 个体防护** |

## 三、技术参数与判别卡

| 考点 | 必记 |
|------|------|
| 燃烧三要素 | **可燃物、助燃物、点火源** |
| **爆炸极限** | 浓度在上下限**之间**才爆炸；动火前必须检测合格 |
| 临电 | **三级配电、两级保护**、一机一闸一漏一箱；末端漏电保护 **≤30mA / ≤0.1s** |
| 有限空间 | **先通风、再检测、后作业**；持续检测 + 专人监护 + **隔绝式呼吸防护装备**；**严禁盲目施救** |
| 特种设备 | **使用登记 + 定期检验 + 持证操作 + 安全附件定期校验 + 严禁带病运行** |
| 电气火灾 | **先断电**，用**二氧化碳或干粉**（不得用水/泡沫） |
| 高处作业 | 安全带**高挂低用**；"四口五临边"防护 |
| 辐射防护三原则 | **时间、距离、屏蔽** |

## 四、专业实务：案例三段式（核心）

```
① 辨识：存在哪些隐患/不符合项（按人、物、管理分类）
② 依据：违反哪部法律法规、标准或规程的什么要求
③ 措施：技术措施（消除/隔离/警示）+ 管理措施（责任制、培训、作业审批、隐患闭环、应急预案）
```

**高频场景速答**

| 场景 | 措施要点 |
|------|---------|
| 有限空间 | 审批 + 通风检测 + 专人监护 + 隔绝式呼吸器 + 应急救援 |
| 动火作业 | 审批 + 清除可燃物 + 检测可燃气体 + 灭火器材 + **看火人** |
| 相关方（外包/交叉） | 资质审查 + 协议明确职责 + 统一协调 + 安全交底 + 监督 |
| 特种作业 | 持证上岗 + 设备定期检验 + 安全附件校验 |
| 隐患整改 | 五落实（责任/措施/资金/时限/预案）+ 闭环验证 |

## 六、免试与报名要点

- **免试 2 科**：具有**高级或正高级工程师职称**并从事安全生产业务满 **10 年**（免《安全生产管理》《安全生产技术基础》）；
- **免试 1 科**：本科毕业时所学**安全工程专业经全国工程教育专业认证**（免《安全生产技术基础》）；
- **增项**：已取得中级注安资格者报其他专业类别，可免试公共科目；
- 2026 年报名：**8 月 4 日—8 月 25 日**（告知承诺制，学历学位验证提前完成）。
